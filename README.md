Long解压把日常文件处理放在一个顺手的工作区里。收到一批压缩包，可以一起解压；只想找里面某个文件，可以直接浏览；需要分享资料，可以打包、加密和分卷。图片、视频与 PDF 的体积优化也有各自独立的入口。

## 🚀 三步开始使用

1. **下载安装。** 打开 [Releases](https://github.com/Longyuyeee/long_Decompress/releases/latest)，下载 Windows x64 的 `setup.exe` 安装程序。
2. **选择工作区。** 归档进入解压中心、压缩中心或文件浏览器；图片、视频和 PDF 进入特殊压缩。
3. **添加文件并开始。** 拖入文件，确认输出位置与参数，启动任务；完成后直接打开或定位结果。

| 你想做什么 | 从哪里开始 | 操作要点 |
| --- | --- | --- |
| 连续看图片包 | 文件浏览器 | 继续阅读、找图搜索与跨页选择；按目录/整包翻阅缩放，在弹窗配置后取回所选 |
| 比较两份资料 | 资料对比 | 选择文件夹或 ZIP/完整分卷，查看候选、按需核对内容，再取回或组成新 ZIP |
| 解压一批文件 | 解压中心 | 拖入压缩包，设置目录；常用密码可交给保险箱尝试 |
| 打包文件和文件夹 | 压缩中心 | 按用途选兼容分享、体积优先、加密或分包方案，再微调密码、名称等参数 |
| 继续更新 ZPAQ 备份 | 压缩中心 | 添加新资料，另存完整新包或原生多部分组，保留原件与历史 |
| 只提取包里的几个文件 | 文件浏览器 → 打开压缩包 | 搜索并勾选条目，再解压所选内容 |
| 不记得文件在哪个包里 | 归档资源库 → 添加资料并建索引 | 标签/收藏与保存搜索，跨包查找文件名/路径，多选后统一配置并取回 |
| 整理 ZIP 内容 | 文件浏览器 → 打开普通 ZIP → 编辑内容 | 添加/替换、删除/改名/批量移动，复核后另存新包 |
| 改格式、密码或分卷 | 压缩中心 → 转换压缩包 | 带入原包，选择新包格式与保存位置 |
| 压缩图片、视频或 PDF | 特殊压缩 | 选择文件类型，调整对应参数并查看结果 |
| 失败后调整并继续 | 原任务详情 / 任务栏 | 看原因，带入配置创建新任务，确认后启动；原失败保留 |
| 找回以前的输出 | 历史任务 | 搜索记录，打开结果或恢复配置创建新任务 |

**运行环境：** Windows 10 1809 及以上 / Windows 11，x64。视频功能暂不保证兼容 Windows N。

后续更新可在设置中心检查；正在处理任务时，请先完成或停止任务再安装更新。

## 🗃️ 常用格式，一张表看清

| 能力 | 主要格式与说明 |
| --- | --- |
| 创建归档 | ZIP（Deflate / Zstandard / BZip2 / PPMd / LZMA）、ZIPX（XZ）、7Z（LZMA2 / LZMA / Bzip2 / Deflate / PPMd）、RAR（需要 WinRAR）、ZPAQ（日志式、原生密码、数字分卷与保留历史的增量更新）、TAR / TGZ / TBZ / TXZ / TZST、TAR.LZ4 / TAR.BR / TAR.LZIP / TAR.LZMA、GZ、BZ2、XZ、ZST、LZ4、Brotli、LZMA、LZIP、WIM（存储/XPRESS/LZX/LZMS/固实）、ESD（LZMS 固实），两者支持数字分卷；SWM（仅存储/XPRESS/LZX 原生资源分包） |
| 读取与解压 | ZIP / ZIPX、7Z、RAR、ZPAQ（流式当前内容/日志式历史快照、原生多部分确认读取、版本对比与变化提取）、ALZ、EGG（基础方法、AZO、固实、传统及 AES/LEA 密码与已验证原生分卷）、自解压 SFX、TAR 系列、GZIP/BZIP2/XZ/Zstandard 多段压缩流、LZIP、LZ4、Brotli、ARJ、Unix `.Z`，原生 SWM（Copy/XPRESS/LZX 整组读取），以及 CAB、ISO、UDF、DMG、VHD / VHDX 等镜像与容器 |
| 密码与分卷 | ZIP 密码数字卷/标准 `.z01/.zip`、7Z 密码数字卷、RAR 原生密码卷、ZPAQ 原生密码数字切卷及原生多部分只读；十七种 Long 自有 AES 格式数字切卷；7Z / RAR 可加密文件名 |
| 转换归档 | ZIP / ZIPX、7Z、RAR、TAR 系列（含 LZ4/Brotli/LZIP 组合及八种 TAR 自有 AES 密码分卷目标及三种新增单文件加密目标）、WIM / ESD / SWM、ZPAQ（含改密与数字分卷）；密码和分卷随目标格式提供 |
| 清单校验 | SFV/MD5/SHA256 逐文件状态与原因、待补列表、按需复查；匹配表示与清单一致 |
| 内部预览 | ZIP/TAR 系列及普通 GZIP/BZIP2/XZ/Zstandard 流、ZPAQ 日志式所选快照中的受支持图片与文本；7Z Bzip2 普通/密码、非固实/固实包支持完整文本 ≤1 MiB、图片 ≤8 MiB，含内容/文件名加密和完整数字卷，共享压缩/解码各 ≤64 MiB；Bzip2 非固实/固实大文本可先看前 1 MiB，前置与开头合计 ≤64 MiB，明确未校验整文件并可提取全文；7Z Deflate64 普通/密码非固实及固实包支持完整文本 ≤1 MiB、图片 ≤8 MiB，含内容/文件名加密和完整数字分卷；固实共享压缩/解码分别 ≤64 MiB；非固实及固实大文本可先看前 1 MiB，固实前置内容与开头合计 ≤64 MiB，明确未校验整文件并可提取全文；7Z Deflate 普通/密码包支持完整图文（文本 ≤1 MiB、图片 ≤8 MiB，含固实、内容/文件名加密与数字分卷；共享压缩/解码各 ≤64 MiB）；大文本可先看前 1 MiB，含固实（前置内容与开头合计 ≤64 MiB），标明未校验整文件并可提取全文；7Z PPMd 普通/密码包均支持非固实及小型固实的完整图文，非固实及固实大文本可读前 1 MiB（明确未校验整文件；固实前置与开头合计 ≤64 MiB，完整块压缩/解码各 ≤64 MiB）；7Z LZMA/LZMA2 的普通或密码包均支持完整小文本、图片及大文本前 1 MiB，兼容非固实与固实包（大文本明确未校验整文件，固实前置范围 ≤64 MiB）；ALZ Store/Deflate/Bzip2 支持完整小文本、大文本前 1 MiB（明确未校验整文件）、8 MiB 以内受支持图片及原连续阅读入口；EGG 非固实小文本和图片可直接预览并沿原入口连续阅读；密码和完整原生卷沿原入口使用，预览超出读取范围时可先提取后打开 |
| 图片压缩 | JPEG、PNG、WebP；质量、尺寸与格式按对应编码能力调整 |
| 视频压缩 | MP4、MOV、AVI、WMV、WebM、MKV、M4V 等受支持输入，输出 MP4 / H.264 |
| PDF 优化 | 分析结构、优化体积；是否适合处理会在分析后显示 |

内置归档引擎，日常解压无需另装 7-Zip。**解压 RAR 不需要 WinRAR；创建 RAR 需要自行安装 WinRAR。**

<details>
<summary><strong>更多格式与使用范围</strong></summary>

- 还可读取已支持的应用包、传统归档、文件系统与安装容器，例如 APK、APPX、JAR、DEB、RPM、MSI、LZH、CPIO、XAR、APFS、EXT、HFS/HFSX。具体能力以应用的实际检测和 [格式支持说明](long-compress-assistant/docs/FORMAT_SUPPORT_LEVELS.md)为准。
- ZIP 默认保留 `.zip.001` 数字切卷，可主动选择标准 `.z01/…/.zip`（入口为 `.zip`）；7Z 创建 `.7z.001`，RAR 创建 `.partN.rar`。解压时把整组放在同一目录。普通 TAR/流格式数字切卷的外部兼容能力不同；密码需求可选择对应 `.aes` 组合或 7Z；普通 TAR.LZMA 无原生密码。`.aes` 属于 Long 自有容器，十七种格式可创建密码数字卷；整组同目录可从任意卷打开，接收方请使用 Long解压。
- ZIP/ZIPX 已验证常用 Store、Deflate、Deflate64、BZip2、LZMA、XZ、PPMd 及部分 Zstandard 读取组合；不等于支持所有 ZIPX 专有算法。
- 创建 ZIP 可选 Deflate、Zstandard、BZip2、PPMd、LZMA，ZIPX 固定 XZ；密码、转换与配置保存保持方法，二者均支持数字卷与标准卷。接收方需支持对应方法、密码编码与卷型，ZIPX 标准卷兼容范围见格式说明。PPMd 与 LZMA 字典随等级增长，界面就近显示；LZMA 6级8MiB、9级64MiB，编码总内存更多，不自动替换默认方法。
- 可直接浏览、解压和转换 ZIP/7Z/RAR 自解压 EXE；好压论坛 ZIP 分卷按整组读取，支持已核对的明文与 ZipCrypto 密码样本。收到多个分卷时，把整组放在同一目录即可。具体格式范围见[支持说明](long-compress-assistant/docs/FORMAT_SUPPORT_LEVELS.md)。
- LZIP（单文件）与 TAR.LZIP（目录/多文件）支持创建、浏览、解压、检查和转换，兼容 `.lz`、`.tar.lz`、`.tlz`；支持连续多成员 LZIP 与数字切卷创建，普通格式不提供密码；全部卷需放在同一目录，数字切卷不同于原生成员。
- ZIP 默认 AES-256，可主动选择 ZipCrypto；与 Windows 7-Zip 交换非 ASCII 密码的归档时，可显式选择匹配的 Windows 密码编码。
- EGG 只读支持已验证的 Store、Deflate、Bzip2、LZMA、AZO、固实 Deflate/LZMA、ZipCrypto、AES/LEA 与原生卷，可浏览、所选/整包提取、检查和转换。大 LZMA 已流式读取，字典仍限 256 MiB；v1.5.11 验证二十组普通中文密码组合并补编码失败指引。加密固实、全局/文件名加密、创建和修复不承诺，工具互通边界见[本版说明](long-compress-assistant/docs/RELEASE_NOTES_1.5.11.md)。
- 密码 ZIP 可尝试救回完整文件：目录可读或丢目录后仍能确定本地文件边界时，提供密码救回通过校验的文件；新包沿用填写的密码，统一使用 AES-256 / UTF-8，并显示部分恢复及未恢复原因。
- DOCX、XLSX、PPTX、ODT、ODS、EPUB 属于文档容器，不作为普通压缩包导入。
- 预览、嵌套浏览及压缩参数随格式而异。体积优化效果取决于文件内容，已充分压缩的文件可能没有明显收益。

</details>

## 🔒 文件留在本机，处理过程看得见

文件处理、归档浏览、密码匹配和完整性校验在本机完成。密码保险箱加密保存常用解压密码，任务展示当前阶段与日志；遇到同名文件可选择覆盖、跳过或保留两份。文件完整性中心还提供校验、ZIP/RAR 诊断与修复；v1.4.8 增加批量处理，恢复结果保存到新位置后可继续加入解压队列。

ZIP 目录损坏时可尝试救回可靠的完整条目；坏文件和未恢复原因会明确列出，原包保留。标准 ZIP `.z01/…/.zip` 缺少首卷或中间卷时，若目录仍完整可读，可以先救出现有连续卷中的完整文件，支持普通、AES 和 ZipCrypto 密码包。已恢复文件和未恢复原因按需展开，新包可直接加入解压队列。

部分恢复不代表全部找回。缺卷救援仍需要完整可读的目录；终卷或目录缺失、未知数字切卷长度及无法确定的加密边界需补齐来源后再处理。具体范围见 [格式支持说明](long-compress-assistant/docs/FORMAT_SUPPORT_LEVELS.md)。

## 💬 常见问题

<details>
<summary><strong>升级后，设置和常用密码还在吗？</strong></summary>

正常覆盖安装会保留应用数据。重要密码可以通过保险箱导出备份。

</details>

<details>
<summary><strong>为什么任务暂时没有百分比变化？</strong></summary>

点击任务行查看当前阶段与日志。归档扫描、密码尝试、校验及大量小文件处理不一定能给出线性进度；如长时间没有新日志，可取消并附上诊断信息反馈。

</details>

<details>
<summary><strong>密码明明正确，旧 ZIP 为什么仍打不开？</strong></summary>

旧工具可能使用不同的密码编码。v1.4.16 可在“ZIP 密码编码”中明确选择日文 CP932、简体 CP936 或繁体 CP950；只在已知原包编码时指定，通常保持自动兼容。它不改变文件名编码，也不能修复损坏或缺失的数据。转换时原包与新包编码分开设置，新包默认 UTF-8。

</details>

<details>
<summary><strong>Windows 提示安装程序的发布者未知，怎么办？</strong></summary>

当前安装程序未使用商业 Windows 代码签名证书。请从本仓库 [Releases](https://github.com/Longyuyeee/long_Decompress/releases/latest)下载，核对来源后决定是否继续；应用内更新包另有签名校验。

</details>
