Long解压把日常文件处理放在一个顺手的工作区里。收到一批压缩包，可以一起解压；只想找里面某个文件，可以直接浏览；需要分享资料，可以打包、加密和分卷。图片、视频与 PDF 的体积优化也有各自独立的入口。

## 🚀 三步开始使用

1. **下载安装。** 打开 [Releases](https://github.com/Longyuyeee/long_Decompress/releases/latest)，下载 Windows x64 的 `setup.exe` 安装程序。
2. **选择工作区。** 归档进入解压中心、压缩中心或文件浏览器；图片、视频和 PDF 进入特殊压缩。
3. **添加文件并开始。** 拖入文件，确认输出位置与参数，启动任务；完成后直接打开或定位结果。

| 你想做什么 | 从哪里开始 | 操作要点 |
| --- | --- | --- |
| 解压一批文件 | 解压中心 | 拖入压缩包，设置目录；常用密码可交给保险箱尝试 |
| 打包文件和文件夹 | 压缩中心 | 选择 ZIP/7Z 等格式，按需设置密码、分卷和名称 |
| 只提取包里的几个文件 | 文件浏览器 → 打开压缩包 | 搜索并勾选条目，再解压所选内容 |
| 改格式、密码或分卷 | 压缩中心 → 转换压缩包 | 带入原包，选择新包格式与保存位置 |
| 压缩图片、视频或 PDF | 特殊压缩 | 选择文件类型，调整对应参数并查看结果 |
| 找回以前的输出 | 历史任务 | 搜索记录，打开结果或恢复配置创建新任务 |

**运行环境：** Windows 10 1809 及以上 / Windows 11，x64。视频功能暂不保证兼容 Windows N。

后续更新可在设置中心检查；正在处理任务时，请先完成或停止任务再安装更新。

## 🗃️ 常用格式，一张表看清

| 能力 | 主要格式与说明 |
| --- | --- |
| 创建归档 | ZIP（Deflate / Zstandard）、ZIPX（XZ）、7Z、RAR（需要 WinRAR）、TAR / TGZ / TBZ / TXZ / TZST、TAR.LZ4 / TAR.BR / TAR.LZIP、GZ、BZ2、XZ、ZST、LZ4、Brotli、LZMA、LZIP、WIM |
| 读取与解压 | ZIP / ZIPX、7Z、RAR、自解压 SFX、TAR 系列、LZIP、LZ4、Brotli、ARJ、Unix `.Z`，以及 CAB、ISO、UDF、DMG、VHD / VHDX 等镜像与容器 |
| 密码与分卷 | ZIP 支持密码数字切卷与标准 `.z01/.zip` 分卷；7Z 支持密码数字卷；RAR 支持原生密码分卷；7Z / RAR 可加密文件名 |
| 转换归档 | ZIP / ZIPX、7Z、RAR、TAR 系列（含 LZ4/Brotli/LZIP 组合和既有 AES 包装）、WIM；密码和分卷随目标格式提供 |
| 图片压缩 | JPEG、PNG、WebP；质量、尺寸与格式按对应编码能力调整 |
| 视频压缩 | MP4、MOV、AVI、WMV、WebM、MKV、M4V 等受支持输入，输出 MP4 / H.264 |
| PDF 优化 | 分析结构、优化体积；是否适合处理会在分析后显示 |

内置归档引擎，日常解压无需另装 7-Zip。**解压 RAR 不需要 WinRAR；创建 RAR 需要自行安装 WinRAR。**

<details>
<summary><strong>更多格式与使用范围</strong></summary>

- 还可读取已支持的应用包、传统归档、文件系统与安装容器，例如 APK、APPX、JAR、DEB、RPM、MSI、LZH、CPIO、XAR、APFS、EXT、HFS/HFSX。具体能力以应用的实际检测和 [格式支持说明](long-compress-assistant/docs/FORMAT_SUPPORT_LEVELS.md)为准。
- ZIP 默认保留 `.zip.001` 数字切卷，可主动选择标准 `.z01/…/.zip`（入口为 `.zip`）；7Z 创建 `.7z.001`，RAR 创建 `.partN.rar`。解压时把整组放在同一目录。普通 TAR/流格式数字切卷的外部兼容能力不同；它们使用密码时可改用 7Z 容器，既有 `.aes` 属于本应用包装。
- ZIP/ZIPX 已验证常用 Store、Deflate、Deflate64、BZip2、LZMA、XZ、PPMd 及部分 Zstandard 读取组合；不等于支持所有 ZIPX 专有算法。
- 创建 ZIP 时可选 Zstandard，创建 ZIPX 时使用 XZ；密码、转换与配置保存保持所选方法。ZIP Zstandard 支持数字卷与标准卷，ZIPX 暂只提供数字卷；接收方需要支持对应压缩方法。
- 可直接浏览、解压和转换 ZIP/7Z/RAR 自解压 EXE；好压论坛 ZIP 分卷按整组读取，支持已核对的明文与 ZipCrypto 密码样本。收到多个分卷时，把整组放在同一目录即可。具体格式范围见[支持说明](long-compress-assistant/docs/FORMAT_SUPPORT_LEVELS.md)。
- LZIP（单文件）与 TAR.LZIP（目录/多文件）支持创建、浏览、解压、检查和转换，兼容 `.lz`、`.tar.lz`、`.tlz`；支持连续多成员 LZIP，不提供这两种格式的密码或分卷创建。
- ZIP 默认 AES-256，可主动选择 ZipCrypto；与 Windows 7-Zip 交换非 ASCII 密码的归档时，可显式选择匹配的 Windows 密码编码。
- 密码 ZIP 可尝试救回完整文件：目录可读或丢目录后仍能确定本地文件边界时，提供密码救回通过校验的文件；新包沿用填写的密码，统一使用 AES-256 / UTF-8，并显示部分恢复及未恢复原因。
- DOCX、XLSX、PPTX、ODT、ODS、EPUB 属于文档容器，不作为普通压缩包导入。
- 预览、嵌套浏览及压缩参数随格式而异。体积优化效果取决于文件内容，已充分压缩的文件可能没有明显收益。

</details>

## 🖱️ 从 Windows 右键直接开始

在设置中启用资源管理器菜单后，可以直接浏览归档、解压到同名文件夹或当前目录、测试完整性、打包为 ZIP/7Z，以及进入转换格式、密码和分卷调整。

Windows 11 请在 **“显示更多选项”** 中使用经典菜单；当前公开包不包含第一层菜单所需的可信签名身份包。

## 🔒 文件留在本机，处理过程看得见

文件处理、归档浏览、密码匹配和完整性校验在本机完成。密码保险箱加密保存常用解压密码，任务展示当前阶段与日志；遇到同名文件可选择覆盖、跳过或保留两份。文件完整性中心还提供校验、ZIP/RAR 诊断与修复；v1.4.8 增加批量处理，恢复结果保存到新位置后可继续加入解压队列。

ZIP 目录损坏时可尝试救回可靠的完整条目；坏文件和未恢复原因会明确列出，原包保留。标准 ZIP `.z01/…/.zip` 缺少首卷或中间卷时，若目录仍完整可读，可以先救出现有连续卷中的完整文件，支持普通、AES 和 ZipCrypto 密码包。已恢复文件和未恢复原因按需展开，新包可直接加入解压队列。

部分恢复不代表全部找回。缺卷救援仍需要完整可读的目录；终卷或目录缺失、未知数字切卷长度及无法确定的加密边界需补齐来源后再处理。具体范围见 [格式支持说明](long-compress-assistant/docs/FORMAT_SUPPORT_LEVELS.md)。

## 💬 常见问题

<details>
<summary><strong>升级后，设置和常用密码还在吗？</strong></summary>

正常覆盖安装会保留应用数据。重要密码可以通过保险箱导出备份。

</details>

<details>
<summary><strong>为什么任务暂时没有百分比变化？</strong></summary>

点击任务行查看当前阶段与日志。归档扫描、密码尝试、校验及大量小文件处理不一定能给出线性进度；如长时间没有新日志，可取消并附上诊断信息反馈。

</details>

<details>
<summary><strong>密码明明正确，旧 ZIP 为什么仍打不开？</strong></summary>

旧工具可能使用不同的密码编码。v1.4.16 可在“ZIP 密码编码”中明确选择日文 CP932、简体 CP936 或繁体 CP950；只在已知原包编码时指定，通常保持自动兼容。它不改变文件名编码，也不能修复损坏或缺失的数据。转换时原包与新包编码分开设置，新包默认 UTF-8。

</details>

<details>
<summary><strong>Windows 提示安装程序的发布者未知，怎么办？</strong></summary>

当前安装程序未使用商业 Windows 代码签名证书。请从本仓库 [Releases](https://github.com/Longyuyeee/long_Decompress/releases/latest)下载，核对来源后决定是否继续；应用内更新包另有签名校验。

</details>
