# 历史材料归档

该目录用于收纳项目早期散落在仓库根目录的阶段性材料。文件仅重新分类，没有删除，Git 历史仍可追溯。

| 目录 | 内容 |
| --- | --- |
| `legacy-root/documents/` | 早期修复计划、阶段审计、旧路线图、收口与验收清单 |
| `legacy-root/release-notes/` | v1.0.x 早期发布说明与发布报告 |
| `legacy-root/tools/` | 已退出当前构建流程的一次性 PowerShell 测试生成脚本 |
| `legacy-root/samples/` | 旧 Python/Rust/SQL 验证样例及其依赖清单 |

当前有效的源码位于 `long-compress-assistant/`，当前开发文档位于 `long-compress-assistant/docs/`。新增功能或发布说明不应继续放回仓库根目录。
