# Long解压 v1.0.13

本版本集中优化压缩、解压和密码归档的流式性能、取消响应与大量小文件处理效率。

## 归档性能

- ZIP、7Z、GZ、BZ2、XZ、Zstandard 与密码 ZIP 的主要复制路径统一使用可复用的 256 KiB 缓冲。
- 原生 ZIP 解压按每 4 MiB 最多发送一次字节级进度，文件完成事件保持不变，减少大文件任务的 Tauri IPC。
- IO 缓冲池保留已扩容缓冲的容量，连续处理相近大小的归档条目时不再重复分配。
- 通用 7-Zip 引擎降低完整暂存目录的资源扫描频率，同时继续每秒检查磁盘安全余量。
- 解压后的布局整理和最终资源计数合并，减少一次完整目录遍历。
- 文件筛选通配符改为每个任务预编译一次，避免为每个归档条目重复创建正则表达式。

## 可靠性

- ZIP、7Z 和密码 ZIP 的大文件复制过程均可在块边界及时响应取消。
- 保留文件数量、展开体积、压缩比、符号链接、重解析点、磁盘空间、冲突策略和事务回滚防护。
- 密码 ZIP 创建与解压继续使用 AES-256，并通过真实密码归档回归。

## 性能基线

- 100 MiB 随机数据：ZIP 压缩约 48.30 MiB/s，解压约 1301.19 MiB/s。
- 1 GiB 随机数据：ZIP 压缩约 48.78 MiB/s，解压约 1364.07 MiB/s。
- 10,000 个 4 KiB 文件：压缩约 3,235 文件/秒，解压约 4,660 文件/秒。
- 三组测试均校验解压内容 CRC32；额外峰值工作集分别约为 5.14 MiB、2.40 MiB 和 2.96 MiB。

性能数据用于同一测试机器的回归参照，不代表所有硬件、磁盘和安全软件环境下的绝对速度。

## 验证

- Rust 全目标 Release 测试与 Clippy 严格检查通过。
- 真实归档格式矩阵、密码识别、分卷、事务回滚和资源保护回归通过。
- 前端类型检查、单元测试、生产构建与 Chromium E2E 通过。
- Windows Shell Extension 与无签名 NSIS 安装包构建通过。
