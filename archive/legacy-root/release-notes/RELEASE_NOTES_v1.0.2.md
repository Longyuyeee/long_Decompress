# 胧解压·方便助手 v1.0.2

v1.0.2 是一次稳定性、交互和发布完整性更新。

## 主要改进

- 补齐压缩、解压、校验、密码生成和分卷检测的前后端命令链路
- 修复任务进度、取消、重试、文件冲突和密码请求状态
- 优化压缩中心、解压中心、任务列表、弹窗焦点和键盘操作
- 修复密码生成器、文件完整性校验文件解析与导出
- 改善页面切换、拖放反馈、减少动效和无障碍体验
- 修复加密 ZIP 密码传递，并验证正确密码与错误密码行为
- 明确非原生加密格式的 7Z 输出，避免格式和文件路径不一致
- 安装包现已内置 7-Zip 命令行组件

## 安装

下载 `胧解压·方便助手_1.0.2_x64-setup.exe` 并运行安装程序。

支持 Windows 10 1809+ 和 Windows 11 x64。创建 RAR 文件仍需安装 WinRAR。

> 当前安装包未进行商业代码签名，Windows SmartScreen 可能显示保护提示。请仅从本项目 GitHub Releases 页面下载。
