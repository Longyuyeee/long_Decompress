# 胧解压·方便助手 v1.0.4

v1.0.4 聚焦桌面交互、Windows 系统集成和加密解压闭环，完成本阶段需求对齐。

## 主要更新

- 缩小默认窗口，重新整理小窗口布局，修复全局任务栏遮挡和多个操作区文字溢出。
- 调整压缩中心目标格式与高级设置的展示方式，使用更清晰的名称和说明。
- 配置组管理与保存使用标准弹窗，补齐保存校验、持久化和错误反馈。
- 密码生成窗口与主窗口保持一致的尺寸、背景和透明度；密码错误后可以重新输入并继续解压。
- 支持关闭到系统托盘，并可在设置中关闭该行为。
- 扩展 Windows 资源管理器右键菜单，加入一键解压、解压到此处、解压到同名目录、压缩和归档测试操作。
- 引入 Windows 11 原生 Shell Extension，并处理注册、升级刷新、卸载清理及旧菜单兼容。
- 后台命令统一使用隐藏窗口方式启动，解决黑色控制台窗口一闪而过的问题。
- 接通应用原生 AES 加密归档的识别、密码验证和解压链路。

## 验证

- Rust 全量测试、AES 专项测试通过。
- 前端单元测试、TypeScript 类型检查通过。
- Cargo Clippy `-D warnings` 和 Git 差异检查通过。
- Windows 11 Shell Extension 注册、COM 激活、7 个子命令及卸载清理生命周期验证通过。

## 安装

从 GitHub Release 下载名称以 `x64-setup.exe` 结尾的 Windows 安装程序。可直接覆盖安装旧版本，现有设置和密码保险箱数据会保留。

安装包尚未进行商业代码签名；若 SmartScreen 显示保护提示，请确认安装包来自本项目官方 Release 页面。
