# 胧解压·方便助手 v1.0.5

v1.0.5 聚焦 Windows 11 右键菜单稳定性、压缩配置组体验和格式能力一致性，是 v1.0.4 桌面交互升级后的收尾版本。

## 主要更新

- Windows 11 仅注册原生 `IExplorerCommand` 菜单，升级时主动清理旧式级联菜单，避免“显示更多选项”出现重复或错乱。
- 右键菜单启用状态改为单一、串行的同步流程；启动检测只修复注册状态，不再反向覆盖用户设置。
- 重做配置组管理和选择弹窗，统一视觉样式、嵌套层级、滚动区域、字段说明及保存/删除反馈。
- 增加配置组名称校验和格式能力联动，不支持的密码、分卷与固实参数会被隐藏并清理。
- 对齐 RAR 前后端能力：继续支持加密 RAR 解压；创建 RAR 时不再提供密码选项，历史异常配置会被安全拒绝。
- 修复小窗口下配置弹窗遮挡、重复标题 ID、内容溢出和操作按钮可用性问题。

## 验证

- 前端 13 个测试文件、80 项单元测试全部通过。
- Rust Release 全量测试 179 项全部通过。
- TypeScript 类型检查、生产构建和 Cargo Clippy `-D warnings` 通过。
- Windows 11 原生 Shell Extension 注册状态、旧菜单清理、COM 激活和 7 个子命令枚举验证通过。
- NSIS x64 安装包完整构建通过。

## 安装

从 GitHub Release 下载名称以 `x64-setup.exe` 结尾的 Windows 安装程序。支持覆盖安装 v1.0.4，现有设置和密码保险箱数据会保留。

安装包尚未进行商业代码签名；若 SmartScreen 显示保护提示，请确认安装包来自本项目官方 Release 页面。
