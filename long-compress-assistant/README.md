# Long解压

面向 Windows 的本地压缩与解压工具，使用 Vue 3、TypeScript、Tauri 和 Rust 构建。支持批量任务、密码本、智能密码尝试、托盘运行、资源管理器右键菜单与一键解压。

## 当前开发能力

- 压缩与解压真实执行路径新增统一资源预检：开始前读取目标卷可用空间、文件系统、SSD/HDD/移动设备/网络位置等可证明信息；解压优先使用归档元数据估算展开体积，压缩复用当前智能分析或普通文件保守估算，并固定预留 128 MiB。
- 空间明确不足时任务会在调用引擎前进入失败状态；网络盘、移动盘、容量或输出体积未知时展示警告并继续依赖原有事务式暂存、运行时容量检查和失败回滚。预检报告同步进入压缩/解压详情与实时日志，不改变现有默认并发参数。
- Windows Release 桌面门禁已覆盖真实一键打包/一键解压的本机卷报告、非空 ZIP 元数据估算、两类可见卡片、无横向溢出及可靠不足阻断；可用 `npm.cmd run test:e2e:desktop:resource-preflight` 独立复验。
- 性能趋势工具新增 I/O 拓扑模式：可显式指定源卷和目标卷，区分同卷、同盘跨卷与跨物理盘，记录可证明的 SSD/HDD、文件系统和容量；单大文件与大量小文件均按源端→目标端完成真实 ZIP 压缩/解压和内容校验，空间或磁盘身份不足时拒绝制造无效基线。
- 压缩配置组支持导出和导入版本化任务模板；导入前展示源规则、输出规则、压缩参数、密码策略、风险提示与 SHA-256，并且必须再次确认才会创建配置组，不会自动执行任务。
- 任务模板严格限制为 256 KiB 和受控字段；固定密码、保险箱分类绑定、删除源文件、额外引擎参数与自动写入保险箱不会跨设备携带，自动匹配规则导入后默认停用。
- 配置组和任务模板现在支持包含/排除 glob，排除规则优先；从模板创建草稿时由 Rust 重新读取最多 1000 个显式选择文件的真实元数据，缺失项、重复项和未命中项会在确认前列出原因。
- 模板草稿只进入现有压缩中心的等待分组，确认创建也不会自动开始；密码始终清空、删除源文件始终关闭。规则型模板首阶段不递归展开目录，目录必须先显式展开为文件，避免把预览规则误写成后台监控。
- 配置组支持“文件夹规则只读预览”：仅扫描用户当次选择的目录，以两次元数据快照识别稳定文件，并列出通过/排除原因；扫描上限为 1000 个普通文件和 32 层目录，不跟随符号链接或 Windows 重解析点，不保存监控、不创建草稿、不启动压缩。
- 只读预览可由用户进一步明确保存为监控授权，并独立启动、暂停、停用或删除；启用时现有文件只作为去重基线，之后的新文件经 900 ms 事件合并、稳定性复查和路径/大小/修改时间去重后写入持久待确认批次。应用启动后只把批次转换为现有压缩中心草稿，仍不携带密码、不删除源文件、不自动压缩。
- 真实 Windows Release Tauri 门禁已贯通模板导出、审计导入、显式文件草稿、文件夹只读预览和持久监控生命周期；实际文件事件覆盖启动、暂停、恢复基线、托盘后台、进程重启恢复、停用、重新启用与删除后无残留监听器，草稿始终不带密码、不删除源文件、不绑定任务也不自动启动。可用 `npm.cmd run test:e2e:desktop:watch-folder` 独立复验。
- 压缩包浏览中心新增归档内图片受限预览：ZIP/TAR 系列中的 PNG、JPEG、GIF、WebP、BMP 经魔数、8 MiB 解压体积、8192 单边和 1600 万像素限制后以内存数据 URL 展示，不创建临时文件。
- SVG、扩展名伪装内容及超限图片不会渲染；7Z/RAR 在尚无可证明的有界单条目读取前保持预览禁用，不作虚假安全承诺。
- 文件完整性中心新增归档诊断模式：展示实际格式、加密/分卷、缺卷、条目统计、CRC/截断分类和可恢复性，并支持复制不含密码的诊断报告。
- ZIP 修复不再调用不可靠的外部修复命令；现在只把仍可完整读取的安全条目重建到用户选择的新文件，发布前再次完整校验，取消或失败不会修改原包或留下输出。
- 压缩中心新增可取消的智能压缩分析：最多读取 2 MiB 内容样本，估算输出体积与典型耗时，并识别图片、音视频、文档和既有归档等低收益内容。
- 分析建议直接映射到既有格式、压缩等级和 7Z 固实压缩设置，默认只建议不自动修改；压缩完成后回填实际体积和预测误差。
- 新增压缩包浏览中心：无需完整解压即可查看结构化目录和文件信息，支持搜索、类型筛选、精确多选与选择性解压。
- ZIP、7Z、RAR 的元数据和密码在进程内处理；留空密码时可复用密码保险箱候选，其他格式不会把密码暴露到命令行。
- 选择性解压继续经过原有暂存、路径安全、资源限制、冲突处理、来源标记和原子提交事务。

## 归档能力

应用内置完整的 7-Zip 26.02 Windows x64 引擎，并在运行时读取引擎实际报告的格式能力。需要完整引擎的格式只会在当前环境确实可用时出现，避免界面宣称支持、实际机器却无法处理。

设置中心会显示当前引擎版本、可读取后缀数、可创建格式数和 RAR 编码器状态，并支持手动重新检测。

### 创建归档

- 常用格式：ZIP、7Z、TAR、TGZ、TBZ、TXZ、TZST
- 单文件流格式：GZ、BZ2、XZ、Zstd、LZMA
- Windows 映像：WIM（由动态能力检测决定是否显示）
- 密码格式：加密 ZIP、7Z、RAR，以及 TAR/GZ/BZ2/XZ/Zstd 的 `.aes` 安全封装
- RAR：必须使用用户安装的 WinRAR/Rar.exe；支持普通与密码 RAR，不随应用分发专有编码器

创建密码 RAR 前会明确提示：受 WinRAR 命令行接口限制，密码可能在执行期间短暂出现在本机进程参数中。用户可以继续创建、改用 7Z 或取消任务。

### 解压与浏览

除上述格式外，第一批完整引擎扩展覆盖：

- 镜像与虚拟磁盘：ISO、IMG、DMG、VHD/VHDX、QCOW/QCOW2、VDI、VMDK
- 安装包与容器：CAB、DEB/UDEB、RPM、MSI/MSP/MSM、NSIS
- 文件系统与固件：APFS、EXT2/3/4、FAT、NTFS、HFS/HFSX、GPT、MBR、UEFI、CramFS
- 传统归档：AR/A、LZH/LHA、CPIO、SquashFS、XAR、IHex
- 应用归档与安装容器：JAR、APK、APPX 等；Office/OpenDocument/EPUB 文档容器不在解压中心中作为压缩包导入

具体能力以当前引擎动态检测结果为准。某些镜像或文件系统格式只支持读取和解压，不支持创建。

## RAR 创建策略

选择 RAR 后，如果系统没有可用的 Rar.exe，应用会暂停当前任务并提供以下选择：

1. 将本次 RAR 任务改为 7Z，并继续原任务；
2. 通过 winget 安装官方 WinRAR，安装完成后重新检测并继续；
3. 打开 WinRAR 官方下载页；
4. 取消本次任务。

应用不会静默安装第三方软件，也不会拆分或转售 RAR 编码器。WinRAR 的试用期与商业许可由 RARLAB 管理。
