## 调整要点

- 沿用当前蓝色强调色、浅色背景、圆角卡片和导航，标题尺寸与其他页面一致。
- 分组标题集中、配置名称对齐，减少过大留白和重复外框。
- 主题、色块、字体与色觉选项更紧凑，开关右对齐，说明文字保持清楚。
- 性能区双列排版减少空白，行为区统一行距；更新与格式信息沿用相同样式。
