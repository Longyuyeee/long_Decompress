# v1.6.60 规划 · LZOP 多成员资料读取

仅规划、尚未开发。完整数字切卷接通后，下一步处理同一个 LZOP 文件携带多个成员的资料，让用户先看清内容再取回，继续格式与真实兼容主线。

1. 先确认官方 lzop 多文件/多成员原件与 `-N` 的实际行为，记录成员名称、边界、每成员校验和独立回解。简单拼接样本只能证明边界测试，不能冒充真实应用原件；官方返回警告时保留警告及退出码，不能记成无条件成功。
2. 在原双栏中列出可确认的成员，接通所选图文/前缀预览、完整检查与按需取回。多成员文件不盲目拼成一个单文件，不自动当成 TAR；名称重复、缺名称和路径冲突给出可操作结果。
3. 接通 ZIP/7Z 转换、原始来源与结果/历史；数字切卷复用 v1.6.59 的完整组读取，缺成员尾部、坏校验、取消不发布未完成产物。
4. 先支持实际证实的普通成员序列。原生 multipart 标志、额外过滤器、创建或密码功能分别评估，证据不足保留明确限制，不混为一种能力。

只检查新增与受影响路径，复用已通过的普通单成员、TAR.LZO 和数字卷证据；保持单条展开、多选弹窗、自然继承、左右等宽、主题和快捷键。ALZ/EGG 缺有效外部原件的项目继续保留，拿到原件后按用户影响排序。
