# 下一版：v1.5.34 ZIP BZip2 创建与流程接续

2026-10-20，接续v1.5.33。本文件仅规划，尚未开发；本轮发布等待期间不启动下一版运行时。

## 用户要解决的问题

WIM方法补齐后，把新增方法回到更常用的ZIP场景。用户可在原有Deflate、Zstandard之外尝试BZip2，继续使用同一个ZIP、多文件、密码与分卷工作流。默认仍为兼容性更好的Deflate，不根据文件类型自动替用户切换。BZip2并非所有系统内置解压器都支持，应在方法帮助里说明。

## 实施依据和顺序

1. 项目已有zip 8.6的bzip2特性；随仓库vendor/zip/src/compression.rs定义Bzip2为ZIP方法12，write.rs已有相应编码分支。先确认普通真实产物的方法号、完整独立回解、目录/空文件/空目录及源数据统计；不能只改后缀，也不能把已有.bz2/TAR.BZ2能力当成ZIP BZip2已完成。
2. 在现有ZIP方法选择增加BZip2，明确强度语义（有效范围1–9，0级选择策略需在实现时保持方法与说明一致）；旧Deflate和Zstandard任务不改，ZIPX继续原有XZ。同步单条展开、多选弹窗、配置组/模板、预设、草稿与历史，方法单独批量修改只作用于ZIP，不改变其他任务的自然继承。
3. 接通普通、AES-256、ZipCrypto及数字/标准分卷。先用独立实现确认实际方法12或AES扩展中对应的真实方法，再开放组合；正确/错误密码、缺卷补回、任意成员浏览/有界预览/完整检查/所选及整包、密码原包双向转换、取消/失败与统一结果只检查新BZip2影响链，不重跑旧方法全矩阵或真实盘满。
4. 检查常用和窄窗、50/50及滚动，保留单条展开、多选弹窗与原布局；整理README、中文Release、范围和交接，推进至可发版。

ZIP LZMA/PPMd、WIM固实/ESD或SWM创建、ZPAQ增量/原生追加多部分/损坏事务抢救、ALZ方法3和EGG加密固实保留为分开的研究项，有可靠正面依据再定功能范围。本版不改默认ZIP兼容性，不预先承诺通用压缩率或所有外部工具互通。
