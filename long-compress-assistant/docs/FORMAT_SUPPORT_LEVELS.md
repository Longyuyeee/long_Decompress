# 归档格式支持等级（当前权威口径）

## v1.5.49 资料分类与批量取回

沿 v1.5.48 既有索引和读取范围，增加来源标签/收藏、保存搜索、跨包多选及批量取回配置。按来源进入原队列，保留所选条目与索引版本，来源不符先处理，不扩大为整包。草稿和历史保留范围；结果主动入库，未新增解码算法。镜像/快照仍是默认目录索引，非所有历史或镜像。见[计划](ARCHIVE_ROADMAP_1.5.49.md)、[封板](LIBRARY_RETRIEVAL_FREEZE_1.5.49.md)与[说明](RELEASE_NOTES_1.5.49.md)。

## v1.5.48 资料库维护与来源范围

资料库添加/扫描沿当前引擎可浏览后缀，列目录、密码/编码、分卷与预览/提取复用原能力；同组归为一份，未解锁/缺卷/不可读就地显示。已有索引支持离线查找，使用前按当前整组大小/修改时间核对，支持定位及只更新变化来源。镜像/快照先索引原浏览器默认目录，不宣称全部镜像或历史快照。见[计划](ARCHIVE_ROADMAP_1.5.48.md)、[封板](LIBRARY_MAINTENANCE_FREEZE_1.5.48.md)与[说明](RELEASE_NOTES_1.5.48.md)。

## v1.5.47 归档资源库第一阶段

资源库覆盖独立未加密 ZIP 与普通 TAR 的元数据索引、跨包文件名/路径搜索、原浏览器定位/预览与单项提取；原包缺失或大小/修改时间变化先处理并手动刷新。密码、分卷、压缩 TAR 和更多格式索引按 v1.5.48；原浏览/提取支持范围保持。见[本版计划](ARCHIVE_ROADMAP_1.5.47.md)与[封板](ARCHIVE_LIBRARY_FREEZE_1.5.47.md)。

## ZIP 编辑、密码与草稿（v1.5.44～v1.5.46）

原浏览器支持独立、原条目为 Store/Deflate 的普通 ZIP，以及 AES-128/192/256 和 ZipCrypto 密码内容的添加、替换、删除、改名、批量移动与另存。保留模式沿各原条目加密方案/公开状态，新增沿统一原方案、混合方案默认 AES-256；替换沿被替换条目方案。可明确设置 AES-256/ZipCrypto 新密码或不加密，输出密码编码默认 UTF-8，可指定代码页。密码条目重新写入，保留方法、内容、有效时间、备注及空目录，不承诺原压缩字节或体积不变。

编辑草稿保存引用与配置，不保存密码；重启后核对来源并可定位/确认，恢复不自动另存，已完成记录返回原结果。原包与已有输出保留。分卷、自解压、嵌套临时来源、特殊路径/链接、重复/大小写冲突、其他原方法仍不进入编辑；同包需一份凭据可读全，空 ZIP 无文件可加密。下面的创建/读取等级不因编辑范围而缩小。


后续开发以[五模块分阶段路线](ARCHIVE_ROADMAP_1.5.44_TO_1.5.59.md)为准：ZIP 编辑后继续资源库、工作流、对比与图片阅读，再回归格式/算法/容错兼容主线。排期不改变本页已发布能力，未排期研究项不计为已支持；下方单版“下一版”描述为历史快照。

## 等级定义

| 等级 | 用户可见含义 | 必须具备的证据 |
| --- | --- | --- |
| A：完整闭环 | 可以由 Long解压创建并重新解压 | Windows Release Tauri 创建非空归档、重新解压、逐字节或 SHA-256 比对；密码、分卷或外部编码器限制必须单独验证 |
| B：真实只读 | 可以导入、浏览或解压，但不声明可创建 | 固定或可复现的非空样本、已知载荷、Windows Release Tauri 解压、逐字节或 SHA-256 比对 |
| C：引擎可识别 | 当前随包引擎报告了解码器，但尚无完整用户路径证据 | 只允许在动态能力诊断中出现；README 不得写成“完整支持” |
| D：不作为归档导入 | 文档容器或尚未公开的格式 | 解压中心主动过滤，或给出明确不支持诊断 |

后缀识别、文件头识别、空镜像、损坏样本、仅 CLI 成功或仅单元测试均不能把格式提升到 A/B。

### C：仅动态能力

随包 7-Zip 运行时报告、但未出现在当前严格真实矩阵中的处理器或后缀均属于 C。它们可以用于诊断和后续样本准备，不应自动进入公开导入白名单。
