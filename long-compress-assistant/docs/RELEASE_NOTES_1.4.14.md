# v1.4.14 · ZIP / ZIPX 压缩方法增强

发布草案：当前分支候选，尚未正式发布。2026-10-16 按用户要求暂停全部工作；功能与候选安装器已完成，合并及正式发布尚未执行，见 [暂停交接](DEVELOPMENT_PAUSED_1.4.14_2026-10-16.md)。

- **ZIP 可选 Zstandard。** 在目标格式旁选择压缩方法，兼容 ZIP 继续沿用原有默认行为。
- **新增 ZIPX（XZ）创建。** 支持文件与目录、空文件、AES-256 / ZipCrypto 密码和数字分卷；可继续浏览、解压及转换。
- **密码、分卷和转换接通。** ZIP Zstandard 支持数字卷与标准 ZIP 卷；转换时可更改方法、密码和分卷，原包保留。
- **设置跟随任务保留。** 批量配置、配置组、任务模板、快速预设、草稿恢复和历史再次执行保留所选方法；智能分析使用对应方法。
- **保持熟悉的界面。** 单条点击行内展开、多选弹窗及左右等宽布局保持，方法说明按需查看。

ZIPX 标准分卷创建本版暂不提供，需要标准分卷时请选择 ZIP。Zstandard / XZ 的接收方需使用支持相应方法的解压软件；具体效果取决于文件内容，不代表支持全部 ZIPX 专有算法。Windows N 暂不保证支持。
