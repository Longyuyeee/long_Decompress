# v1.6.22 · 7Z 加密固实图片与原阅读器

## 本版范围

按[路线](ARCHIVE_ROADMAP_1.6.22.md)将 AES + LZMA/LZMA2 固实 PNG/JPEG/GIF/WebP/BMP 接入原双栏图片弹层与原阅读器，覆盖内容/文件名加密、原手动密码/保险箱与完整数字卷。只开放已确认的完整图片范围，不改 vendor、通用解压/创建和密码验证默认值。

复用 v1.6.21 的预览专用 AES 与 v1.6.19 的完整共享块接口：所选图片 ≤8 MiB、单边 ≤8192、总像素 ≤1600 万；共享压缩数据与解码总量分别 ≤64 MiB，元数据/载荷实际输入合计 ≤64 MiB、每次请求候选整体 30 秒。AES 明文完整消费、密文长度/零填充/结束和全部共享大小/CRC/编码结束通过后才显示，只留当前图片、不解开临时整包或读无关大块。原 AES 参数/字典/头大小范围、密钥计算取消/截止保持，不记整包密码成功或使用次数。

原阅读器按需当前页和有限缓存，7Z 不预读下一页，保留翻页/停止/关闭取消、坏图跳过、缩放/适应、定位与准确提取当前页。元数据沿原有界密码入口，条目共享标记、原等待提示、来源前后绑定和迟到丢弃保持；帮助收在问号。单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键及格式数量保持。小文本、非固实密码图片和未加密固实图片沿原范围。

## 来源与验证

四组原版 7-Zip 26.02：内容加密 LZMA、LZMA2、文件名加密 LZMA2 与文件名加密 LZMA 数字卷；官方 26.04 独立回解逐文件 SHA-256 核对，包含五类真实栅格、有效归档中的坏图和文字/无关内容。另有原版加密 8 MiB 边界、图片/共享超限与尺寸超限，受控密文损坏、65 MiB 无关 COPY 块损坏而所选加密共享块有效的范围样本；后两项不冒称原工具损坏包。见 `tests/fixtures/archives/sevenz-encrypted-solid-image-1622/manifest.json`。

四项新前端已通过：加密固实图片的原弹层/共享等待/帮助，关闭取消与迟到丢弃，按需当前页不预读，停止共享阅读不显示迟到图片。五项新 Rust、构建与最终候选已通过；新增 Rust 测试驱动先修正目录模型无 revision 字段的接口引用，再实际执行，不重复已过的前端结果。Shell 首次外层 Windows PowerShell 脚本策略拒绝执行，沿当前 PowerShell 正常调用后构建及八处身份通过，未修改系统策略。

桌面分发脚本初次启动前修正顶层 return 为既有完成标记，未执行业务场景；随后最终候选五组实际执行均通过，已过场景无需重跑。

五组实际桌面完成：加密目录沿原保险箱打开后精确像素、1100×650/760×520 CSS 窗口等宽预览，原阅读器翻页/缩放/坏图跳过/定位，当前页准确提取，两种方法与非首文件名加密数字卷的预览/阅读命令，损坏/超限/取消/来源和无关 65 MiB 损坏块跳过。三张宽窄截图已实际查看，无横向溢出，关闭和图片操作可见。候选 SHA-256 `f87ffd633bddc08b788c87db734892c64b2bc382debd1ab83f8c54d1bd28d999`，见[证据](evidence/sevenz-encrypted-solid-image-1.6.22/checks.json)。
