# v1.4.12 LZIP 与 TAR.LZIP 实施

## 当前状态（2026-10-16）

从已发布 v1.4.11 / 发布后文档提交 `0bc3779` 接续，分支 `codex/lzip-tar-lzip-1-4-12`。版本及 Shell 资源统一为 1.4.12，功能、原生命令与实际页面均已收口。最后只接续该分支 PR 最终提交的普通 Windows 安装包，见 [封板记录](LZIP_AND_TAR_LZIP_FREEZE_1.4.12.md)；尚未合入或正式发布。

## 用户能够完成的操作

1. 从现有入口导入 `.lz`、`.tar.lz`、`.tlz`，浏览内容、选择解压、检查、转换到已有格式，清楚显示损坏或截断原因。
2. 在现有压缩及转换配置中选择 LZIP（单文件）或 TAR.LZIP（目录/多文件），保留文件名、中文目录、空目录及原有结果入口。
3. 普通 LZIP 不显示可用的密码或分卷配置；首版不追加容器包装或原生多卷承诺。单条行内展开、多选弹窗及既有等宽/窄窗口布局保持。

## 实施顺序

1. 接入内置编解码器、格式识别和可靠的校验结束处理，复用已有流格式、事务及取消路径。
2. 打通浏览/预览、解压、完整性检查与格式转换，核对 `.tlz` 别名和多成员 LZIP。
3. 接入单文件 LZIP 与 TAR.LZIP 创建、等级和输出命名；配置能力前后端一致，禁用本版不提供的密码/分卷。
4. 使用独立工具生成非空输入并回解应用输出，只验证本版受影响的用户链；查看常用/窄窗口的真实页面。既有 ZIP/SFX/好压证据直接复用，不重跑无关矩阵。
5. 记录实际完成、失败及边界，统一版本并更新 README、中文 Release 和交接；最终普通安装包通过才具备发版条件。

## 技术参考

- [LZIP 官方格式](https://www.nongnu.org/lzip/manual/lzip_manual.html#File-format)：单/多成员、CRC32、内容长度与成员长度校验。
- [lzma-rust2 0.22.0](https://docs.rs/lzma-rust2/0.22.0/lzma_rust2/)：Apache-2.0，原生 LZIP 编解码，不引入运行时外部程序依赖。

历史发布与下一批格式路线见 [多版本路线](ARCHIVE_FORMAT_AND_WORKFLOW_ROADMAP_2026-10-16.md)。本版不同时启动 v1.4.13 损坏包部分抢救。

## 已实施

- 新增内置 `lzma-rust2 = 0.22.0` 的 LZIP 读写；使用与已有流格式相同的取消、暂存、校验及结果发布路径。随包附 Apache-2.0 原文，独立 GNU 工具不随软件分发。
- `.lz` 单文件、`.tar.lz` / `.tlz` TAR 组合的后缀与文件头识别、浏览、所选解压、TAR 文本预览、检查和双向转换。多成员 LZIP 连续解码，完整核对 CRC32、数据长度和成员长度；空输入不被当作有效压缩包。
- 创建时保留中文文件名、空文件与空目录；小文件按大小缩小字典，不为几个字的内容申请完整等级字典。压缩分析使用实际 LZIP 编码抽样。
- 选择新格式时关闭不支持的密码、分卷、固实或文件名加密；不会把输出悄悄改成 7Z。恢复的密码草稿改选 LZIP 时清除不再适用的密码必填状态。
- 原有批量压缩弹窗增加 TAR.LZIP，并说明密码和分卷会关闭；批量转换可选择 TAR.LZIP。保持单条展开和自然配置继承，仅打开有效配置不触发独立设置。
- 导入过滤、归档浏览/嵌套能力及经典右键识别同步 `.lz` / `.tlz`，未更改软件图标或整体布局。
