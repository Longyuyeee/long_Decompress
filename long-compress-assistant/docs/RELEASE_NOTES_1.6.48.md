# v1.6.48 · 7Z 新增 PPMd 创建

- 创建或转换 7Z 时，可在原压缩方法选择 PPMd（PPMdH），尝试文本归档；默认仍为 LZMA2。
- 接通密码、隐藏文件名、固实与完整数字分卷，生成后继续预览图文、提取或转换；可在 7Z PPMdH 与 ZIP PPMd8 间转换。
- 多选弹窗、配置组/预设/模板、草稿恢复、历史和工作流保留方法；体积分析按真实所选编码抽样，改方法后提示重新分析。

强度 1～9 对应受控阶数/内存，内存最高 64 MiB。普通刷新不截断范围编码，结束写入与后续 AES 明确完成，终止失败直接返回。保留单条展开、编辑后自动独立、多选弹窗、左右等宽布局及主题/工具/快捷键。

新增适配/前后端、四组独立新输出回解和实际桌面通过，宽窄窗口已实看。未重复旧矩阵、安装或盘满。见[本版记录](SEVENZ_PPMD_CREATE_FREEZE_1.6.48.md)。

正式附件由标签发布流水线自动生成，实际状态在本版 PR 接续。下一阶段 [7Z 仅归档与不可压缩文件建议](ARCHIVE_ROADMAP_1.6.49.md)仅规划。
