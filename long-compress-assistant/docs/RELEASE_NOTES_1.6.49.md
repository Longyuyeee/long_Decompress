# v1.6.49 · 7Z 快速仅归档

- 7Z 新增「仅归档（Copy）」：直接打包已有数据，可继续加密、隐藏文件名、固实、分卷、预览和转换。
- 选仅归档后收起强度，切回压缩方法时恢复原值；配置组/预设/模板、草稿、历史和工作流保留所选方法，默认仍是 LZMA2。
- 实际内容抽样收益不足 2% 时，在分析结果中提供可选建议。点击后只改当前方法，密码、固实、分卷和全局配置保持；不会自动执行。仅归档的预计体积不再误报压缩收益。
- 修复 7Z 空流与 CRC 为 0 时的包头校验信息写入，覆盖仅空项固实和 CRC 为 0 的非空内容。

保留单条展开、多选弹窗、左右等宽及原主题/工具/快捷键。新增/受影响检查和实际桌面通过，宽窄窗口已实看；已通过且未受影响的结果继续复用，未重复旧矩阵、安装或盘满。见[本版记录](SEVENZ_COPY_CREATE_FREEZE_1.6.49.md)。
