# 下一版：v1.5.40 原生 SWM 创建与整组结果

2026-10-21，接续 v1.5.39。本文件仅规划，尚未开发运行时；继续更多格式、分包和完整处理流程的既定方向。

## 用户要解决的问题

已有原生 SWM 读取和 WIM/ESD 数字切片后，让需要与支持 WIM 的工具交换分包内容的用户，可以明确创建真正的 SWM 组，并能找到、检查和取回整组。数字字节切片与原生分包要清楚区分，不能只换后缀。

## 推进顺序

1. **先确认真实分包与读取能力。** 核对随包 wimlib split 的限制与头部总卷数、卷号、同组标识；生成非固实 Store/XPRESS/LZX 样本，用独立实现完整回解与核对全部内容。现有原生 SWM 读取范围先保持，LZMS 若不能独立贯通不先开放。大文件/资源可能使单个成员超过请求大小，需要按实际语义解释；固实 WIM/ESD 不能直接走该分包路径，不静默转码或伪装成原生 SWM。
2. **接熟悉的创建与转换入口。** 在当前格式与分包配置处提供明确选择，方法、真实编码/分包阶段、暂停/停止、输出冲突和取消后暂存清理接通。不新增 WIM 原生密码，不触碰原归档；单条展开、多选弹窗、自然继承与左右等宽保持。
3. **打通整组流程。** install.swm、install2.swm 等成员作为同一结果组，从任意成员浏览、预览、完整检查和所选/整包提取；缺首/中/尾卷明确提示具体文件，补齐后创建待确认新任务。原包密码输入与新 SWM 结果、SWM 转密码 ZIP 接原转换入口；预设、模板、草稿、历史与多选保存实际分包方式。
4. **按新增范围封板。** 只补本次创建及整组流程的依据，查看宽/窄界面和结果显示，更新 README、中文 Release、格式等级、范围与发布收据。已通过的旧矩阵和真实盘满不重复运行。

## 保留后续

SWM 创建只承诺内容归档互通，不等于 Windows 部署、启动镜像制作、ACL/重解析点或系统备份保证。ALZ 方法3、EGG 加密固实、ZPAQ 原生追加多部分与损坏事务抢救继续单独研究，不和本版混做。
