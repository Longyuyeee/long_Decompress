# v1.4.16 · 旧 ZIP 密码跨系统兼容

安装器、签名更新包和更新清单见 [v1.4.16 正式 Release](https://github.com/Longyuyeee/long_Decompress/releases/tag/v1.4.16)，准确版本及产物摘要见[封板记录](LEGACY_ZIP_PASSWORD_FREEZE_1.4.16.md)。

- **正确密码也能跨系统使用。** ZIP/ZIPX 密码编码增加日文 CP932、简体 CP936、繁体 CP950，贯通解压、所选提取、浏览预览、嵌套、检查修复、压缩和转换。已知旧包编码时可以明确选择，不再依赖接收电脑的本机代码页。
- **原包与新包分开设置。** 转换分别保留两侧密码编码；批量配置按实际源格式和目标格式应用，不影响无关的 7Z/RAR 任务。配置组、模板、草稿、历史再次执行保留选择，密码仍需重新填写。
- **修复后可以继续处理。** 单条及批量恢复结果保存生成时的编码；之后修改原包设置不会改变结果。退出重开可恢复工作区，重填结果密码后浏览或继续解压，保留输出设置及原失败记录。结果文件不可用时明确说明。
- **页面细节修正。** 修复窄窗口下拉横向溢出、分卷标题挤成竖排，以及转换原包/新包字段错行；说明保留在就近问号中。

默认行为不变：读取仍为原有自动兼容，新包默认 UTF-8，不自动轮试所有新代码页。字符无法无损表示时明确报错，不冒充密码错误或文件损坏；完整内容校验保持。

本版不新增格式或特殊卷型，不开放 ZIPX 标准多卷；Windows N 暂不保证支持，智能目录和 ZIP 并行仍默认关闭。实现、真实原包和独立回解范围见[实施审计](LEGACY_ZIP_PASSWORD_ENCODING_1.4.16.md)，发布身份见[封板记录](LEGACY_ZIP_PASSWORD_FREEZE_1.4.16.md)。
