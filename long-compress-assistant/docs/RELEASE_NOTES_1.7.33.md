# v1.7.33 · 流式 BZip2 ZIP 丢目录部分取回

收到的 BZip2 ZIP 中央目录损坏或丢失、文件尺寸又只写在数据流末尾时，现在可通过原诊断与恢复入口取回仍能完整确认的文件。

- 接通未加密 ZIP32 / ZIP64、普通及可选签名数据描述符、空文件和明确目录，支持完整数字切片从非首卷进入。
- 只在解码结束、尺寸和 CRC 均吻合时接续下一条；遇到损坏、截断或未知边界停止，前面已确认的文件另存为经验证的新包，原件保留。
- 尚未找到完整文件时给出明确提示并禁用恢复，避免无效操作。
- 结果保持“部分取回”，原总文件数无法确认；沿现有结果、历史和失败重试流程，界面与交互保持。

本版没有增加格式数量或密码流未知边界支持，也不跨缺卷缺口扫描。见[本版范围](ARCHIVE_ROADMAP_1.7.33.md)、[实现与检查](ZIP_BZIP2_RESCUE_FREEZE_1.7.33.md)。下一阶段 [v1.7.34 流式 LZMA ZIP 部分取回](ARCHIVE_ROADMAP_1.7.34.md)仅规划。
