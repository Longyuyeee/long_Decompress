# v1.7.12 · 取回目录保留原修改时间

从损坏或缺卷 TAR.LZO 取回资料后，明确记录且实际选中的目录也能按原修改时间整理。

- 等所有子项写完，再从深到浅保存目录时间，避免创建文件把原目录时间覆盖成当天；多层目录、空目录和仅取回目录均接通。
- 沿用普通/GNU/PAX 时间规则；自动创建但未选中的父目录不补造原时间。目标范围、精度或写入限制独立提示，已取回内容继续保留。
- 原结果详情默认折叠显示逐项时间，原历史详情分别保留文件与目录统计；旧记录保持可读，保留单条展开、多选弹窗和等宽双栏。

本版未扩大权限、所有者、链接、稀疏文件救援或缺口后扫描范围。见 [本版范围](ARCHIVE_ROADMAP_1.7.12.md)、[实现与检查](TAR_DIRECTORY_TIME_FREEZE_1.7.12.md)。下一阶段 [v1.7.13 旧 GNU 稀疏文件部分取回](ARCHIVE_ROADMAP_1.7.13.md)仅规划。
