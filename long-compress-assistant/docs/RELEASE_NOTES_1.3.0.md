# Long解压 v1.3.0

v1.3.0 是界面密度、配置可理解性与本地密码工作流的集中收口版本。归档压缩、解压和特殊压缩继续沿用已有安全执行与事务边界。

## 配置与任务交互

- 压缩与解压的“全局 / 单独”切换统一放在批次底部配置区，不再散落到每个任务内部；任务详情的操作按钮、左侧配置和表头滚动边界同步整理。
- 压缩设置恢复始终可识别的分卷配置。ZIP 普通文件可以直接启用并设置每卷 MiB；格式、密码或任务类型不兼容时会说明原因，不再静默隐藏。
- 压缩密码输入框联动本机密码保险箱：点击即可按名称选择，自动填入密码并记录使用次数，同时保留手动输入和密码生成器。
- 解压列表分离删除、暂停/停止和展开按钮；被截断的名称与路径使用统一主题浮窗显示全文。

## 密码与隐私可见性

- 密码保险箱默认显示密码正文；只有用户主动锁定全部或单个条目时才以星号遮挡。
- 解压密码尝试和成功信息显示实际使用的密码，让用户明确知道本次任务采用了哪个候选。
- 密码生成器改为受限尺寸弹窗，固定标题与底部操作，仅中间内容滚动；标准、易记和 PIN 模式使用统一紧凑布局。

## 工作区与文件浏览

- 双栏文件浏览器新增可输入路径的主题化位置选择器；粘贴有效目录并回车即可跳转，常用位置仍可直接选择。
- 图片、视频和 PDF 特殊压缩的批量操作按钮统一尺寸与排列。
- 文件完整性页面重构为紧凑工具工作区：模式栏、算法、文件选择和结果列表不再使用大面积卡片，诊断与修复能力保持不变。
- 解压中心“添加压缩包”默认只显示软件支持的归档格式，并保留 `.001`、`.z01`、`.r00` 等常见首卷入口。

## 验证

- 发布候选完成 56 个前端测试文件、314 项测试，全数通过。
- TypeScript 类型检查与 Vite 生产构建通过。
- Release workflow 继续以真实 Windows NSIS 与 updater 构建、版本身份和公开更新清单为正式发布门禁。

## 已知边界

- 当前分卷创建仅支持未加密 ZIP 普通文件；不支持的组合会在界面中明确说明。
- Windows N 暂不支持；Windows 11 第一层菜单仍需要生产代码签名身份。
