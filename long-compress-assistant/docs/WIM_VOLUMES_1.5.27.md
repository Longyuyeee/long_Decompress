# v1.5.27 WIM 数字分卷实施

2026-10-20，从正式 v1.5.26（PR #221，标签 e699a7011c9c6daa033e0cd9da9a986e7723588e）接续。v1.5.26 四附件、中文说明与更新清单已核对。本版已按范围完成并封板，进入普通受保护合入与正式发布。

## 范围与顺序

1. 用独立 WIM 原件确认数字切片的读取、压缩方法、多镜像目录与内容选择语义；优先复用随包 7-Zip 跨卷，不先复制完整大包。若必须临时合并，须明确空间、进度与取消，不能仅改能力开关。
2. 接通普通 WIM 数字卷创建，任意成员浏览、有界文本/图片预览、完整检查、所选/整包、密码 ZIP 互转、缺卷原因、补齐后的新任务与整组结果清单。
3. WIM 不支持原生密码；保留现有主动切换加密目标流程，不清掉原配置来伪装成功。数字 `.wim.001` 不是原生 `.swm`，不承诺系统部署兼容或 Windows 元数据完整还原。
4. 保留单条展开、多选弹窗、自然继承、左右等宽和窄窗滚动。只补本版受影响链，不重跑 ZPAQ、旧密码/格式矩阵或已通过真实盘满。

## 实现与依据

复用固定随包 7-Zip 26.04 的 `WIM.SPLIT` 读取，任意成员先沿既有检测器归为首卷。没有完整临时压缩包拼接。普通创建沿已有通用切卷/事务发布，保留所有实际产物。新建 WIM 由随包引擎存储并去重，显式使用 `-mx0`；原强度 1～9 不产生对应编码，已在单条、多选与转换界面停用无效控件，而非宣称新增压缩方法。

[上游 WIM 写出实现](https://raw.githubusercontent.com/ip7z/7zip/main/CPP/7zip/Archive/Wim/WimHandlerOut.cpp)与随包程序实际输出一致：新资源采用 Copy，不把能读 XPRESS/LZX/LZMS 当成可创建这些方法。独立回读原件由 [wimlib 1.14.5](https://wimlib.net/downloads/) 捕获，官方包 SHA256 `2f446d6fa3866582175f1a22a7be198eeee0aec7aba5b4e04ad25c99eae2d265`；工具身份与原件摘要固定在 `tests/fixtures/archives/wim-volumes-1527/manifest.json`，wimlib 不随产品分发。

Copy、XPRESS、LZX 双镜像、LZMS 固实四个原件包含实际压缩内容、中文、同名子路径、PNG、空文件和空目录，均经独立 verify/apply 及 SHA256 确认。多镜像编号目录保留，`[1].xml` 摘要由 wimlib 独立抽出原 XML 资源取得。转换保留内容视图，目标为新归档，不承诺重建原镜像属性或系统部署。

WIM 所选提取将规范化的精确路径交给原引擎，关闭通配解释，不先解出无关镜像再删。完整解压仍走原暂存/冲突/提交流程。格式保留 WIM，避免数字后缀把普通 WIM 当成需试密的通用 ZIP 路径。元数据使用明确 UTF-8；目录的空 Size 字段通过 WIM 元数据路径正确计为目录，修正前置资源统计错误，压缩大小按整组实际字节计算。

预览只读取选中条目的 stdout，不落盘临时文件或完整包；目录响应最多 16 MiB、提示最多 64 KiB，文本条目最多 64 MiB 且显示前 1 MiB，图片最多 8 MiB 并沿原像素限制。每个预览进程 256 MiB 内存、单线程、30 秒等待，超限/大小不符明确提示先解压。读取及解码由外部引擎随机访问，不宣称全部输入读取量严格不超过 64 MiB。

多选保留各条分卷大小；若所选包含仍有密码/需补密码的任务，整批提示并保持原配置，请用户先明确处理。没有新增全局/单独模式或更换原交互。

## 进度

九项不同 Rust 和八项不同前端已通过；六条真实公共原生链与六条实际 UI 链完成，二十张宽/窄页面已实看。首轮资源统计空 Size 失败只补相关项；实际新建的 Copy 方法被误当成压缩方法的检查已按真实能力纠正，已通过原件与普通创建不重跑。最终显示、候选和发布由[封板记录](WIM_VOLUMES_FREEZE_1.5.27.md)接续。

新建 WIM 不附带可选的整包 integrity table。独立工具提示跳过该表不作为成功依据，仍需解出全部文件并与源 SHA256 核对；不是只看退出码或目录能列出。
