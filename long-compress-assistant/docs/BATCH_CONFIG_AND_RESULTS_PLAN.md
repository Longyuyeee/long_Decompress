# 批量配置与结果操作开发计划

批准日期：2026-10-12。开发基线：v1.4.0，master `814b12f`。功能完成后，用户批准收尾封板并发布 v1.4.1。

## 用户目标

选中一部分任务后一次调整配置，避免逐条重复操作；完成后在当前入口直接找到结果。Windows 文件资源管理器可直接进入压缩包转换、密码和分卷调整。

## 2026-10-12 发布后交互调整

用户查看界面后明确：所选任务的批量配置应在点击按钮后进入弹窗，不能铺开占用任务列表。压缩、解压两处共享入口已同步调整，列表仅显示紧凑的选择数量、修改按钮和取消选择；单条任务仍点击后在行下方展开。弹窗打开时各项回到“保持各自设置”，取消不修改任务，成功应用后关闭，配置错误在弹窗内说明。

这是 v1.4.1 标签推送后的开发调整，随下一版交付；下方首次实现与检查保留为当时记录，不修改已发布的版本说明。

## 当前交互约定

- 点击任务行仍在行下方展开详情，支持同时展开多条，不改为任务详情弹窗。
- 全局设置作为默认；单条编辑和所选项批量编辑自然形成该条配置，不出现“全局/单独”模式按钮。
- 批量编辑的每一项初始为“保持各自设置”。用户明确指定哪些项，就只修改哪些项；保留其他设置、密码、文件名及未选中的任务。
- 勾选任务后显示紧凑操作栏，点击“修改所选配置”打开弹窗，不在列表内展开大面积批量表单。单条详情继续行内展开。
- 选择仅作用于未提交/未开始的任务。列表变化后清理失效选择，执行时保留现有任务提交行为。
- 结果操作复用已有页面，不增加新结果中心。仅已完成结果显示结果操作；旧结果移动或删除时给出可读提示。
- Windows 右键复用现有转换表单；原文件带入，不自动开始转换。

## 本轮实现与检查（2026-10-12）

- 压缩文件/组支持选择全部、取消选择，配置栏在列表内展开；解压配置栏也放在任务列表的同一滚动区域，避免窄窗口单独滚动隐藏标题。压缩批量格式先支持常用 ZIP/7Z，其他格式继续在单条设置中选择。
- 只修改显式指定字段，保留各自密码、名称、分卷等参数。修改后固定当时的有效设置；明确选择源目录时不再被应用默认输出目录替代。已启用 7Z 文件名加密的任务改为 ZIP 时说明需先处理该项，不悄悄关闭它，也不先修改其他条目。
- 统一结果操作直接出现在当前页面；分卷产物清单在当前卡片展开。全局任务面板汇总所有已完成结果，按 Windows 路径大小写/分隔符去重输出目录。没有产物的图片跳过任务不显示新结果按钮。
- Windows 经典级联菜单与原生扩展都增加“转换压缩包格式…”、“修改密码 / 调整分卷…”；CLI、应用路由、转换草稿及卸载清理接通。多选原包时可逐个切换配置，不自动批量执行；已有草稿/运行任务不会被新右键请求覆盖。新增菜单随下次应用构建/安装生效，未替换本机已安装版。
- 前端构建和类型检查通过；相关 store/view/component 定向测试共 151 项通过。Windows 菜单定向测试 14 项、原生扩展 5 项通过。三组浏览器场景通过：压缩文件/组批量修改与行内详情，解压修改与结果目录去重，右键请求带入多选转换草稿。
- 已实际查看 1100/920 与 760 像素窗口的批量配置、全局结果操作和转换表单。页面样例使用模拟任务/IPC，只证明界面和参数交接，不冒充真实转换或安装验证。
- 页面查看发现并修正解压批量栏嵌套滚动；旧测试的菜单按钮定位改为完成结果操作，图片节省字节断言改为真实样本大小计算。浏览器输出目录改用子目录，避免清理同级图片测试样本。未修改产品行为迁就测试。
