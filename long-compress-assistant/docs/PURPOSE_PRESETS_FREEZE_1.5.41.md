# v1.5.41 用途配置功能封板

[计划与范围](ARCHIVE_ROADMAP_1.5.41.md) · [中文 Release](RELEASE_NOTES_1.5.41.md) · [实际检查记录](evidence/purpose-presets-1.5.41/)。这是合入前功能快照，正式合入、标签和发布资产的收据在本版 PR 接续。

## 交付范围

四种用途共用参数定义和紧凑组件，接入压缩/转换的单条、默认配置和原多选弹窗。选择后先看参数，再确认应用；加密必须填写或明确沿用密码，分包必须给有效整数 MiB。未指定的名称、目录、原包密码、删除原件等设置保留。兼容 ZIP 方案明确关闭不适用的文件名加密；体积优先不承诺压缩比例。

单条展开、多选弹窗、自然继承、左右等宽、原预设/配置组/模板与高级参数保持。用途只填配置，不自动启动任务。多选填入方案后仍可取消，确认弹窗才批量应用。格式被进一步手动调整为不支持密码/文件名加密的目标时，压缩批量修改在修改前给出说明，不部分改动其他条目。

## 必要检查与实际显示

- 160 项相关前端检查通过（六个文件，含八项本版场景），覆盖空密码、确认、参数保留、原包凭据、继承、多选取消和批量实际修改。
- 前端类型检查、Vite 构建、Shell 版本资源与八处版本身份通过。桌面程序以 `custom-protocol,desktop-e2e` 及前端 E2E 桥构建，程序 SHA-256 见证据；正式包由 CI 另行构建，不把测试程序当正式安装器。
- 五条真实桌面流程通过：单条确认与加密创建、多选取消与标准 ZIP 分包、密码原包转兼容 ZIP、转换多选与默认继承、全局保存/取消与单条自然继承。前三条产物均用独立 7-Zip 完整回解并核对文件 SHA-256。
- 六处界面各查看 1100×700 与 760×520：单条方案、结果、多选弹窗、转换方案、转换多选、全局配置。横向与方案内部溢出为 0，宽窗左右两列等宽；窄窗文字换行、原滚动路径和确认按钮可使用。

最后整理时补齐连续填入多个方案的参数保留与 ZIP 卷型编辑，仅补一项受影响的前端检查（原 159 项保留，累计 160 项）；桌面依据保持原程序 SHA 与源码哈希，补丁哈希另记，正式候选编译最终源码。

脚本最初读取被滚动裁切的文字，以及定位到弹窗背后的同名控件，已调整为正确文本读取和前景弹窗定位；随后接续剩余步骤。最后全局步骤遇到一次 WebDriver 会话断开，新会话续完该步骤，产品程序未因此改动。已通过步骤未重跑；原始记录保留布局接续项。未重跑旧格式/密码矩阵、真实盘满、无关媒体和安装流程，也没有新增 Rust 编解码逻辑。
