# 解压密码统计语义审计（2026-08-21）

## 本次对齐

密码保险箱保存的是压缩文件的解压密码，不是网站或账户登录凭证。因此统计界面只使用软件能够从真实归档解锁流程中取得的数据。

- 整体全景：条目总量、累计调用、30 天活跃、尚未使用、调用频率层级、使用趋势、归档分类、标签/备注覆盖、最近使用时效、长期活跃和高频排行。
- 单条档案：累计调用、最近使用、创建/维护日期、最近 14 天使用趋势、归档分类、收藏、标签和备注来源。
- 明确移除：传统密码强度、安全评分、风险雷达、到期轮换、正文长度等无法表达归档解锁效果的指标。

## 数据可信边界

- “调用”来自真实自动解压成功命中或用户主动复制所记录的原子使用事件；界面不把主动复制伪装成已经成功解压。
- 图表按用户本地自然日聚合；没有历史事件时不制造趋势数据。
- 分类、标签、收藏和备注只表达用户维护的归档线索，不推导为安全结论。
- 单条详情与整库全景使用独立模板，避免把全库数据误认为当前条目的统计。

## 验收基线

1. 使用保险箱中的密码成功解开真实加密 7Z。
2. 整库当天和 7 天累计调用均增加 1，并显示解压场景统计；传统密码统计不得出现。
3. 打开该密码的单条档案，累计调用和 14 天趋势必须包含本次事件。
4. 单条档案必须展示归档线索，且不得出现整库调用层级或分类分布。
