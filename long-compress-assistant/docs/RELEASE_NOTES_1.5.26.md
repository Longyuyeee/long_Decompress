# Long解压 v1.5.26

ZPAQ 现在可以按指定大小分卷分享，原生密码、查看内容和后续处理连在一起。

- **大包按大小拆分**：普通和原生密码 ZPAQ 均可创建 `.zpaq.001/.002/…` 数字卷。单条展开直接修改，多选仍在原有弹窗内配置，各条密码和分卷大小继续保留。
- **从任意一卷打开**：集齐整组后，可从首卷、中卷或尾卷浏览、检查与解压。读取直接跨卷进行，不必先拼接一个完整临时包。
- **先看需要的内容**：日志式当前文件支持有界文本和图片预览。大小未知或超过预览范围时会提示先解压；不把部分读取当成完整预览。
- **密码和格式一起调整**：密码 ZPAQ 分卷可转为密码 ZIP，密码 ZIP 也可转为新的密码 ZPAQ 分卷。源密码和新密码分别设置。
- **缺卷后接着处理**：补齐后沿原入口创建新任务，保留旧失败记录。完成结果可以带入整组实际产物，主动生成校验清单。
- **配置不再被加载过程改掉**：修复格式能力尚未载入时，打开配置可能清掉继承分卷设置的问题；多选格式列表补入 ZPAQ。

保留单条展开、多选弹窗、自然继承、左右等宽与小窗口滚动。数字切片需要集齐全部成员，不是 ZPAQ 原生追加多部分；分享给其他工具时可先按序合并。增量更新、历史恢复与损坏数据修复不在本版范围。
