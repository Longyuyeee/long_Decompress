# 胧解压 1.0.9

本版本重点升级 Windows 11 资源管理器集成，为高频压缩与解压操作提供新式右键菜单入口。

## 主要更新

- 使用签名稀疏 MSIX 包和原生 `IExplorerCommand` 接入 Windows 11 新式右键菜单。
- 新增“一键解压到同名文件夹”，从资源管理器直接解压所选归档。
- 新增“一键打包为 ZIP”，支持把单个或多个文件、文件夹打包到当前目录。
- 打通资源管理器命令、单实例应用唤醒、前端任务分发与 Rust 压缩后端。
- 安装器支持注册和卸载新式菜单扩展，应用启动时可修复注册状态。
- 发布流水线构建并验证两个签名的 Windows 11 菜单身份包。

## 使用提示

Windows 可能缓存新安装或更新后的资源管理器扩展。如果更新后新命令没有立即出现，请重启“Windows 资源管理器”进程，或在下一次正常重启电脑后再次检查。

## 验证状态

- 两个身份包的构建、签名、验签和 COM 激活测试通过。
- 前端参数解析、任务分发、Rust 注册逻辑与 Shell 扩展单元测试通过。
- 新式菜单的最终无缓存视觉验收将在正常重启电脑后继续进行。
