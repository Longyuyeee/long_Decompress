# Long解压 1.0.9

本版本完成 Windows 11 资源管理器新式右键菜单的代码基础，并交付可直接使用的一键解压和一键打包命令。由于项目未配置 Windows 代码签名证书，公开安装包暂不携带新式菜单身份包。

## 主要更新

- 完成稀疏 MSIX 包和原生 `IExplorerCommand` 的 Windows 11 新式右键菜单接入实现。
- 新增“一键解压到同名文件夹”，从资源管理器直接解压所选归档。
- 新增“一键打包为 ZIP”，支持把单个或多个文件、文件夹打包到当前目录。
- 打通资源管理器命令、单实例应用唤醒、前端任务分发与 Rust 压缩后端。
- 安装器支持注册和卸载新式菜单扩展，应用启动时可修复注册状态。
- 发布流水线在无生产代码签名证书时跳过 Windows 11 菜单身份包，继续生成主程序安装包和应用内更新包。

## 使用提示

v1.0.9 公开安装包仍通过“显示更多选项”提供传统右键菜单。Windows 11 最外层菜单属于已完成但未随本次公开安装包启用的功能。

## 验证状态

- 两个身份包使用开发测试证书完成了构建、签名、验签和 COM 激活测试。
- 前端参数解析、任务分发、Rust 注册逻辑与 Shell 扩展单元测试通过。
- 正式发布流程已验证在没有 Windows 代码签名证书时不会误带身份包，也不会阻塞主程序发布。
