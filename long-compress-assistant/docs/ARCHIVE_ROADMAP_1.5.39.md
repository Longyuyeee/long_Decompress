# 下一版：v1.5.39 固实 WIM / ESD 与内容流程

2026-10-21，接续 v1.5.38。本文件只规划，尚未开发运行时；继续更多格式方法、分卷和完整处理流程的方向。

## 用户要解决的问题

已有 WIM 的 XPRESS、非固实 LZX/LZMS 创建后，让需要保存大量相似文件的用户可以明确选择固实归档，并能正常浏览、检查、取回与转换收到的 ESD 内容。先弄清实际能力，再提供有效选项，不靠改扩展名冒充支持。

## 推进顺序

1. **先确认固实内容读写与独立互通。** 当前 wim_writer.rs 与随附 wimlib 来源说明只覆盖非固实创建；先核对现有 wimlib 编码方式及当前读取器对固实资源、ESD 标记的支持。用独立工具生成与完整回解中文路径、普通/空文件、空目录、同名层级和多镜像样本；检查解码的真实内容，不能只读目录就声称全流程支持。若现有读取器不足，先接完整读取，再开放创建。
2. **接原压缩和转换入口。** 原 WIM 方法位置增加明确的固实选择及适用说明，按实际能力决定 ESD 输出入口；保留默认仅存储、XPRESS、非固实 LZX/LZMS。显示实际阶段，沿用暂停/停止、暂存发布及统一结果，不承诺固定节省率或速度。固实内容的选择性提取可能需要读取其他数据块，应就近说明。
3. **打通读取与工作接续。** 浏览、搜索、预览、完整检查、所选/整镜像提取与双向转换接通，多镜像编号保持。现有数字切卷与缺卷补齐后新任务按新模式确认；数字切卷不冒充原生 SWM。配置组、模板、预设、草稿、历史及多选保留方法。WIM 不新增原生密码或改成自有加密容器。
4. **按新增范围封板。** 只补受影响方法与读写流程，查看宽/窄界面；单条展开、多选弹窗、自然继承和 50/50 保持。复用已有检查，不重跑旧格式/密码矩阵与真实盘满，更新 README、中文 Release、范围和发布收据。

## 保留后续

原生 SWM 创建与 Windows 部署、ACL/系统备份保证仍单独规划；本版先处理内容归档。ALZ 方法3、EGG 加密固实、ZPAQ 原生追加多部分和损坏事务救援继续独立研究。ZIP LZMA、现有密码与分卷按 v1.5.38 范围保持，不同时扩展其他 ZIP 编码器。
