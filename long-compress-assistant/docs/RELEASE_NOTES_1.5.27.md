# Long解压 v1.5.27

WIM 现在可以分卷分享，并从任意一卷接着查看、提取和转换。

- **按大小分卷**：创建 `.wim.001/.002/…` 数字切片，结果集中保留整组文件，可直接带入生成校验清单。读取直接跨卷，不必先复制成完整临时包。
- **多镜像看得清**：沿用目录树，按 1、2 等编号进入不同镜像，预览文本、图片或只提取选中的内容；根目录可能显示的 `[1].xml` 是镜像说明。
- **格式与密码分开处理**：WIM 可转为密码 ZIP，密码 ZIP 也可转为普通 WIM 分卷。源密码独立填写，WIM 新包不带原生密码；转换保留当前目录视图，不维护原系统镜像的部署属性。
- **补齐后继续**：缺卷时说明原因，补回后创建新的待执行任务；由你确认启动，旧失败记录保留。
- **配置更准确**：新建 WIM 明确采用“仅存储与去重”，停用无效的压缩强度；多选仍在原弹窗调整并保留各条卷大小，带密码的任务不会被批量操作悄悄清掉密码。修复 WIM 目录空大小导致前置检查失败的问题。

保留单条展开、多选弹窗、自然继承、左右等宽和小窗口滚动。预览沿既有文本/图片上限，并限制子进程内存与等待时间；超限请先解压。XPRESS、LZX、LZMS 等已验证原件可读取，本版未增加这些方法的编码器。数字切片需集齐整组，不是部署用原生 SWM，不提供 WIM 原生密码或缺卷部分救援。
