# Long解压 v1.3.3

本版聚焦解压失败说明、历史找回和跨页面任务控制，不增加新格式或自动重跑。

- 截断 ZIP 直接说明归档结构损坏或不完整，保留底层详情，不把结构损坏误导为密码问题。
- 同名文件等待用户选择时保持待处理，不提前写成失败历史。
- 历史筛选无结果时可重置筛选，明确目前只检索已加载的最多 500 条记录。
- 历史失败记录可创建新的解压草稿；旧记录保留，用户确认后才执行。
- 压缩中心批量取消、清理只处理归档，不影响特殊压缩；历史未保存时不会先丢掉对应文件行。
- 图片批次离开页面再回来仍保留进度和取消控制，避免重复启动同一批次。

验证包括 379 项前端单测、真实截断/完整 ZIP 同队列与历史重试、重启历史核对，以及 100 张 JPEG/PNG/WebP 与归档并发取消隔离。选择器路径响应由测试桥提供，不宣称覆盖原生文件选择窗口；发行包使用不含测试桥的正常构建。

Windows N 暂不支持；Windows 11 第一层菜单仍有代码签名身份限制。后续计划见 [下一版路线](NEXT_VERSION_AFTER_1.3.3.md)。
