# v1.7.10 · GNU/PAX 混合名称记录取回

TAR.LZO 中的 GNU 长名称和局部 PAX 连续出现时，后续损坏或缺卷也可以继续选择此前完整、已校验的普通文件与目录。

- 支持两种记录顺序及交替排列；局部 PAX 未改路径或名称一致时，长目录、同名叶文件和长文件名均沿原取回弹窗处理。
- PAX 大小用于对应文件，控制记录使用各自物理大小；名称用完清空，元数据不会显示成文件。
- 兼容 GNU 名称声明内的零填充，正常浏览和取回得到同一个文件名；复制仍使用原包中的实际位置。
- 正常浏览、预览、所选解压、密码 ZIP 转换、失败诊断、结果和部分历史保持衔接。
- 保留单条展开、多选弹窗、左右等宽双栏及原主题，没有新增常驻配置区。

GNU 与局部 PAX 路径冲突、混合记录中的空路径删除、重复或孤立记录明确停止。链接、稀疏文件部分取回、缺口后扫描及全部元数据恢复仍未扩展。

见 [本版范围](ARCHIVE_ROADMAP_1.7.10.md)、[实现与检查](TAR_MIXED_NAMES_FREEZE_1.7.10.md)。下一阶段 [v1.7.11 保留取回文件修改时间](ARCHIVE_ROADMAP_1.7.11.md)仅规划。
