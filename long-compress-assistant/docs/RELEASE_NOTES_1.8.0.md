# Long解压 v1.8.0

本版集中完善 Windows 文件右键入口，让小窗口弹窗和任务页面更清楚、更好用。

## Windows 文件右键，按内容分类

- 修复经典菜单出现两个同名 Long解压入口、前一个入口功能不全的问题，统一为一个分类菜单。
- 普通文件和文件夹提供 ZIP、7Z、自定义、加密、分卷压缩；压缩包增加浏览、解压到此处、同名目录和自选目录。
- 压缩包的普通打包收进“压缩打包”，测试、尝试修复、转换格式、调整密码和分卷收进“更多操作”。
- JPG、JPEG、PNG、WebP 优先显示图片压缩、转换 WebP 和缩小尺寸，同时保留普通打包；支持的校验清单可直接核对。
- 设置中显示菜单实际位置，并提供“修复菜单”，处理旧入口、版本目标不一致和部分注册残留。

Windows 11 公开安装包的完整菜单在 **显示更多选项 → Long解压**。需要时可在 **设置 → 行为 → Windows 文件右键菜单**中修复。

## 小窗口和缩放适配

- 修复“打开压缩包”被长路径撑宽、选项右侧裁切和出现横向滚动的问题。
- 长路径最多显示两行，悬停可查看完整内容；窗口较矮时中间选项区可以滚动，关闭和底部操作保持可见。
- 保留当前目录、同名目录、自选目录、双栏浏览四种打开方式及“记住我的选择”，补齐双栏查看图标。
- 修复开启“减少动画”后整个窗口右移、开关无法操作的问题，保留已保存的偏好。

## 主区域留给任务

- 删除解压中心重复的“本次运行”统计和“查看成功结果”入口；两中心的批量结果操作统一放在“成功结果”分类。
- 历史任务取消多选勾选和批量重做，统一行首对齐；单条详情、再次执行和结果菜单继续就近提供。
- 压缩、解压中心保持单条展开、多选弹窗配置和左右等宽布局。

覆盖安装会保留现有设置和应用数据。菜单功能及检查范围见[本版核对记录](https://github.com/Longyuyeee/long_Decompress/blob/v1.8.0/long-compress-assistant/docs/RELEASE_AUDIT_1.8.0.md)。
