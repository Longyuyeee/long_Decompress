# v1.5.50 · 手动顺序工作流

## 重复步骤，保存一次就能再用

- 新增“工作流中心”，提供“解压后重新打包”“按日期归档资料”模板，也可以从空方案开始。
- 将筛选文件、解压、打包压缩和转换格式组成最多 8 个顺序步骤。点击步骤原位展开，修改名称、移动顺序或删除；保存、复制后可反复使用。
- 压缩和转换复用原配置面板与配置组，归档名支持来源名、日期、时间和步骤序号占位符。

## 先确认来源，再开始处理

- 运行弹窗集中选择文件/目录、保存位置、来源密码和 ZIP / ALZ / EGG 编码；输出密码按步骤填写，也可从保险箱选择。
- 后一步接收上一步的实际目录或新包。分卷按原有能力归组，结果显示实际成员与位置；本次生成密码包的凭据可带给后续转换和解压。
- 每次建立独立运行目录，步骤产物分别保留，原文件和已有结果不覆盖。扫描外部来源时避开其中的输出目录，避免重复打包旧运行资料。

## 看清每一步到了哪里

- 显示步骤来源、状态、当前任务进度、执行日志和实际产物，可直接打开目录、定位归档、复制路径或转到任务历史。
- 任一来源失败即停在当前步骤，后续步骤保持未开始；停止当前运行后不再派发后续任务，已完成结果保留。
- 保存方案和最近 100 次运行摘要，重开应用可查看结果；未完成运行显示中断，不自动重新执行。密码只在当前会话使用。
- 宽窗分区、窄窗顺排，配置、长路径和日志保持可滚动。原单条展开、多选弹窗、自然继承及压缩/解压左右等宽布局保持。

本版只提供手动线性方案，主动选择最多 1000 处来源，筛选最多扫描 10 万个位置、保留 5 万个文件。不新增格式/算法，不执行脚本或自动删除来源；失败步骤接续、跨次恢复执行、目录触发与定时执行按后续版本推进。包内筛选请先解压，格式、密码和分卷仍按现有引擎能力处理。
