# v1.6.31 · PPMd 非固实大日志开头预览

## 完成范围

按[路线](ARCHIVE_ROADMAP_1.6.31.md)接通普通或 AES 密码非固实 PPMd7/PPMdH 7Z 的大文本前 1 MiB。复用现有显式 read_single_entry_prefix 和部分 AES 路径，允许单 PPMd 或有序 AES → PPMd，提前确认唯一普通非固实映射、逐项/总大小、方法顺序、单打包流、PPMd 阶数 2～64 和字典 2048 字节～64 MiB；只保留所选开头，不读额外符号，不调用完整 finish 或 CRC。不把未读尾部当成完整成功，完整目录头等已登记 AES 消费条件仍保持。

原手动密码/保险箱、内容/文件名加密及完整数字卷贯通，手动错误不回退，不记整包密码成功。实际元数据/载荷合计 ≤64 MiB、AES 参数、候选整体 30 秒、块内取消与来源前后绑定保持，不扫描无关大文件。声明总量大于 64 MiB 的非固实日志可读开头，声明总量不是分配量。UTF-8/BOM、UTF-16、GBK 截断沿既有字符边界处理，原窗口显示“部分内容 / 未校验整文件”、滚动及提取后打开入口；精确 1 MiB 小文本仍完整读取。

原完整小文本/图片、PPMd 完整结束与 CRC、固实前缀方法范围、LZMA/LZMA2 和通用提取保持。PPMd 固实大文本、未知过滤器仍给提取下一步，无新增依赖或格式计数变化。只扩展原问号说明，单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键保持。

## 本版必要检查

原版 7-Zip 26.02 生成普通、AES 内容加密、文件名加密（阶数 12/16 MiB）及完整数字卷四组非固实 PPMd 原件，包内官方 26.04 独立逐文件回解 SHA-256，列表确认 PPMd/Solid -。包含方括号/相邻路径、精确 1 MiB 和刚超出、五种编码截断、二进制，以及独立 65 MiB 日志和固实/Store 不支持范围。普通/密码单流尾部受控损坏经独立工具确认完整性失败，开头保持部分读取口径；另有开头损坏。65 MiB 无关 COPY 块先独立检查后受控损坏，所选前缀不扫描该块。脚本保留已提交原件，新检出只补建忽略的大块样本。见 tests/fixtures/archives/sevenz-ppmd-text-prefix-1631/manifest.json。

两项新接通单元通过：短读/未读 PPMd 结束与 CRC 不妨碍显式部分结果，但部分载荷不能豁免已创建完整 AES 流的消费回执；参数、映射、AES 对齐、大小及取消保持。五组后端通过：四组/每个卷成员准确开头与五种编码、精确边界；保险箱和手动错误/计数；普通/密码未读尾部和完整读取区分、小文本 CRC/不支持/二进制；取消/来源/缺卷、65 MiB 无关块及大总量；参数/映射、读取中取消和未验证 CRC 的明确口径。因通用前缀方法范围变化，仅补一项旧 LZMA 连续性，不重复旧矩阵、完整 AES/PPMd 单元、安装或真实盘满。

类型/Vite、八处身份与新 Shell DLL 通过。四组实际 Tauri 桌面通过：保险箱文件名加密开头与滚动/提取入口；普通/内容加密/非首卷、五种编码、手动正确密码与大总量；未读尾部仍部分而完整校验失败、不支持/二进制/错误手动密码与小文本；取消/来源/新请求和无关块跳过。1100×650、760×520 两张截图已实看，正文/关闭/提示与提取入口可见，无横向溢出，底层双栏等宽。候选 SHA-256 `1893d6dd9c61ef5a84497c6f661e7bbd3e30b997bd1bc32db699aad0a1cbf619`，见[证据](evidence/sevenz-ppmd-text-prefix-1.6.31/checks.json)。桌面 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置不改；入口 node scripts/test-tauri-desktop.mjs --sevenz-ppmd-text-prefix-1631-only。
