# v1.4.7 功能封板记录

## 冻结范围

- RAR 恢复记录修复、已有 `.rev` 的缺失/损坏数据卷重建；在副本中运行本机 Rar.exe，组装完整卷组并逐条读取验证，保存到新的 `.repaired` 目录。
- 修复结果保持原密码和加密方式；错误密码、恢复数据不足或完整校验失败不产出不完整结果。原件及原失败记录保留，可沿用修改后的输出目录/子目录/密码加入待处理队列，再由用户开始解压。
- RAR 创建可选 3/5/10% 恢复记录，默认关闭；单条、多选弹窗、转换、配置组/模板、草稿与历史配置贯通。
- Windows 经典/原生右键菜单新增“检查与尝试修复”，支持 RAR 分卷和 `.rev`，多选可在检查页切换；完善菜单卸载清理。
- 损坏加密 RAR 的密码预检失败不再直接断言密码错误。单条展开、多选弹窗、自然配置继承与已有等宽/滚动布局保持；新增选项默认折叠，窄窗口信息可读。

## 明确留后续

本轮恢复证据为 RAR5。需本机 Rar.exe、至少一个同组数据卷及足够可用恢复数据；加密文件名恢复卷补卷受本机 OEM 密码编码约束。RAR4 恢复、创建 `.rev`、标准 ZIP 分卷丢目录与未知数据描述符变体留后续，不作为本版漏项。内容校验在当前条目结束后响应取消，取消后不发布结果。
