# v1.5.8 原厂 SFX 模块兼容

从 `6950ec9` 接续[十版路线](ARCHIVE_ROADMAP_1.5.6_TO_1.5.15.md)。本版补齐原厂 7-Zip 19.00、23.01、26.04 GUI 独立加载器；24.09 保留回归。内嵌 7Z 仍通过有效头和相对偏移读取，RAR 仍走原生只读链，不执行任何输入 EXE，不新增自解压创建功能。

## 原包与范围

[原包清单](../tests/fixtures/archives/sfx-158/manifest.json)记录七个模块的来源、大小、SHA-256、原厂许可和生产器身份。7-Zip 三个版本分别覆盖独立加载器/内嵌归档、普通/内容密码/文件名密码，18 组；WinRAR 6.24 的 Default、Default64、WinCon、WinCon64 四种原厂模块分别覆盖三种密码状态，12 组。32 位模块使用原生 RAR4 旧卷名，64 位模块使用 RAR5 现代卷名。这是 6.24 模块验证，不宣称覆盖所有历史 RAR 模块。

30 组固定原包由原工具生成，以当前 26.04 独立读取并核对自有载荷的完整哈希、中文路径、空文件和空目录。测试密码公开，仅用于夹具。7-Zip 模块从[官方下载页](https://www.7-zip.org/download.html)和官方 GitHub 发布取得；[WinRAR 6.24 原厂安装器](https://www.rarlab.com/rar/winrar-x64-624.exe)沿用 v1.4.19 已保存的来源和安装器哈希。RAR 许可不允许单独再分发模块，因此只保存其身份、许可和已生成的 SFX 原包，不提交裸 RAR 模块或生产器。

## 验证顺序

先在未修改实现时确认新增独立加载器不能识别，再增加大小和完整 SHA-256 白名单；不依据 PE 版本号、文件名或伴随卷放宽。随后验证每一成员浏览、检查、整包和所选提取、密码拒绝、转换及原卷保留。缺首/中/尾卷分别核对，RAR 加密头隐藏尾卷数量时只能在带正确密码解码后确认，不能提前编造缺卷结论。

真实桌面验证包括收到 EXE 和全部卷时归为一组、中卷导入、执行前卷被移走、最终原因写入历史、补回原卷后创建新任务、纠正密码、只取中文文件以及转换 ZIP 后独立回解。常用/窄窗页面必须实看；不注入任务成功，不为测试降低内容或错误断言。

修改前运行 `cargo test --manifest-path src-tauri/Cargo.toml original_158_gui_modules_are_exact_loaders -- --nocapture`，一项测试真实失败，完整列出九组未识别输入（三个新模块各三种密码状态）；未改实现，没有把失败替换为预期成功。其他内嵌和 RAR 能力按实际回归结果记账，不冒充新增。

本版实施和最终验证结果将在封板时回填，未完成前不计为已发布。智能目录/ZIP 并行默认关闭，不恢复快速打包，Windows N 暂不保证支持。
