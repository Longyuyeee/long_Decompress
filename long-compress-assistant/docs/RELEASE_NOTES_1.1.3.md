# Long解压 v1.1.3

本版本完成 v1.1.2 产品增强能力的 Windows 候选桌面验收，并修复精确选择解压中文 ZIP 路径时发现的真实兼容问题。

## 修复与改进

- ZIP 浏览与解压统一使用支持 Unicode Path Extra Field 的路径语义；未设置 UTF-8 标志的中文深层路径不再按 CP437 错误解释。
- 明确选择归档条目后，如果事务最终没有匹配到任何文件，任务会失败并保留原始状态，不再把空输出报告为完成。
- 归档浏览桌面门禁覆盖中文八层长路径 ZIP、密码及文件名加密 7Z、固定加密 RAR，并验证搜索、精确单选、未选文件不落盘和输出内容哈希。
- 智能压缩桌面门禁覆盖高可压缩目录与 PNG/MP4 类低收益组合，验证受限采样、可解释建议和采用现有配置。
- Mark-of-the-Web 桌面门禁使用真实 NTFS `Zone.Identifier`，验证默认传播、设置关闭和事务输出。
- 压缩后校验门禁验证最终 ZIP 完整性和内容；启用删除源文件时，界面及提交任务都会强制校验，源文件只在归档发布成功后删除。
- 间接依赖 `nanoid` 从 3.3.16 更新到 3.3.18，修复零长度自定义生成器可能无限循环的高危公告项。

## 验收

- Rust：229 项通过，1 项固定机器性能基准按设计忽略；Clippy 通过。
- 前端：191 项单元测试通过；类型检查与生产构建通过。
- 浏览器：32 项通过，13 项按当前环境能力跳过；官方生产依赖安全审计为 0。
- Windows Release Tauri：智能压缩、归档浏览、Mark-of-the-Web、压缩后校验，以及诊断、修复、预览、资源预检、模板、监控目录、托盘和真实重启完整回归通过。

## 已知限制

公开安装包不使用 Windows 商业代码签名证书，因此不会分发 Windows 11 新式第一层右键菜单身份包；资源管理器经典右键菜单继续可用。固定机器 HDD 性能样本仍是后续研究项，不影响本版本功能正确性，也不会触发默认并发调整。
