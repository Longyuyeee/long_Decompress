# Long解压 v1.2.5

本版本集中修复无边框窗口的拖动、缩放状态和最小高度侧栏显示问题。

## 修复

- 补齐 Tauri 标题栏拖动所需的编译能力与运行权限，空白标题栏现在会显式启动原生窗口拖动。
- 窗口控制按钮不会误触发标题栏拖动。
- 修复鼠标在窗口外松开后，再次移入会自动恢复缩放的问题。
- 缩放会在指针松开、取消、窗口失焦或 pointer capture 丢失时可靠结束。
- 修复高 DPI 环境中物理指针位移与逻辑窗口尺寸混用导致的缩放偏差。
- 调整小高度侧栏布局；在 920×520 最小窗口下，8 个导航入口完整可见且不出现导航滚动条。

## 说明

- 图片、视频与 PDF 继续位于“特殊压缩”；压缩中心继续只处理归档压缩。
- Windows N 暂不在支持范围内。
