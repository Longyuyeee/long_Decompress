# v1.5.51 工作流纠正、接续与重跑封板

[实施计划](ARCHIVE_ROADMAP_1.5.51.md) · [中文 Release](RELEASE_NOTES_1.5.51.md) · [记录与界面](evidence/workflow-recovery-1.5.51/)。候选、正常合入、标签与正式附件收据在本版 PR 接续。

## 用户交付

运行记录可“纠正并继续”，成功或未完成步骤均可“从本步重跑”。弹窗按原单条点击展开修改本次来源、保存位置、读取密码、输出密码和步骤参数，复用原压缩面板、配置组与保险箱。上游配置或原始来源变化会提前重做范围，只改显示名称不影响复用；本次修改不覆盖原方案。

新运行保存无密码执行快照、实际输入/输出及内容依据。开始时一次核对前缀的真实内容、目录结构和整组分卷，不能仅凭旧成功状态或大小/修改时间跳过。变化、缺失、无依据时定位步骤，可提前重跑或补齐文件后再继续；核对显示真实读取进度并可停止，停止不创建后续任务。读取已有密码产物的密码与后续新包密码分开，沿用原来源编码。

接续建立独立运行目录和新记录，前面成功步骤标为沿用原产物并关联原运行，后续使用真实旧产物。整组分卷进入后续筛选/压缩，不只传首卷。旧运行、已有部分成功和来源保留。执行、停止、日志、历史和结果操作继续使用原任务链。正常关闭前等待记录保存，重启后手动继续；快照独立于已保存方案，不自动执行。v1.5.50 旧摘要继续查看，没有恢复依据时明确带入当前方案新运行。

原单条展开、多选弹窗、自然继承、压缩/解压 50/50 与滚动保持。接续弹窗删除重复步骤预览；没有密码项时来源/输出区占满一列，需要凭据时宽窗分列、窄窗顺排。长路径换行，正文滚动、底部操作可达。

## 完成依据

37 项不同前端（原工作流 13、新接续 14、退出保存 10）、5 项新增 Rust 通过。类型/Vite、Shell、八处身份与原生构建通过。Rust 覆盖同大小/同时间内容变化、缺失产物/旧摘要、目录与筛选范围、取消读取及快照清理/保存。前端覆盖前缀/下游派发、参数/来源变动、凭据、重启快照、分卷和退出等待。

七条实际桌面流程通过：旧摘要与明确新运行；普通源成功而密码源失败的部分结果保留；保险箱纠正密码和保存位置后只接失败步骤及下游；只重打包并应用原配置组；同大小/同修改时间的内容变化阻断并提前重跑；实际三卷传递、缺卷阻断及补卷后继续；正常关闭和同目录重启、512 MiB 来源核对取消与接续、原方案删除后继续。输出用独立 7-Zip 回解/内容哈希比对，原件、旧记录和部分成功保持。

## 范围及后续
