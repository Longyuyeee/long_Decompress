# v1.7.22 · TAR.LZO 链接内容转换

已确认目标的 TAR.LZO 链接内容接入原归档转换入口，可以连同普通文件和目录一起生成新包，原目标与副本均保留为独立逻辑文件。

- 沿用现有目标格式、压缩方法、密码和分卷设置，接通最终结果清单与历史重试。
- 新包先完成创建和校验，再确认原包、卷组没有变化，最后保存到所选名称；取消、原包变化或目标冲突时保留原件，清理本次暂存内容。
- 保存期间明确显示“正在保存新包”，最终提交前保持进行中，不提前报告转换完成。

保留单条展开、多选配置弹窗及原界面样式。本版未增加格式数量，不创建系统链接；时间与稀疏元数据沿目标格式原有能力，不保证保留源 TAR 的全部元数据。前向/歧义目标、任意链接链条、符号链接与嵌套打开继续分期。

见 [本版范围](ARCHIVE_ROADMAP_1.7.22.md)、[实现与检查](TAR_LINK_CONVERSION_FREEZE_1.7.22.md)。下一阶段 [v1.7.23 嵌套压缩包链接浏览](ARCHIVE_ROADMAP_1.7.23.md)仅规划。
