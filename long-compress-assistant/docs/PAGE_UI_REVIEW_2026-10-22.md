# 全页面文案、空间与操作审查

本轮按用户的实际操作逐页调整：主要区域用于列表、文件、配置、步骤或结果；导航与操作优先合并到标题旁的空白处。介绍文字不占用常驻区域，必要说明通过圆形问号悬停查看，也支持键盘聚焦、点击保留与 Escape 关闭。错误、当前状态、选择范围、删除/覆盖后果继续直接显示。

## 页面清单

| 页面 | 主要区域 | 调整 |
| --- | --- | --- |
| 解压中心 | 任务列表、单条展开配置、执行结果 | 标题介绍转问号；缩短空态格式列表；同目录输出不再重复显示相同文字。原单条展开、多选弹窗及左右等宽不变。 |
| 压缩中心 | 压缩任务、配置与执行结果 | 标题介绍转问号；公共配置弹窗增加可用高度、压紧头尾；用途、密码、级别及原设置流程保留。 |
| 图片压缩 | 图片列表、设置、原图/结果图 | 类型切换与批量设置/开始按钮共享顶部；简化内部技术措辞，保留预计与实际大小的区分。 |
| 视频压缩 | 视频列表、参数与执行进度 | 顶部合并操作；缩短空态介绍，输入事实改为原视频；保留有损流变化与结果信息。 |
| PDF 压缩 | 文件分析、处理选择与结果 | 顶部合并操作；去除 qpdf、标准输入等内部实现介绍；数字签名限制和有损确认继续可见。 |
| 双栏文件浏览器 | 两栏文件/包内目录 | 删除重复副标题和常驻规则横条；说明合并到标题问号。两栏、嵌套包、文本/图片预览与所选取回保留。 |
| 资料对比 | 差异列表与所选处理 | 收起来源的原结构保留；支持范围并入标题问号，实际核对解释改为提示；统计和核对共用一行，选择工具条压紧。 |
| 工作流中心 | 方案步骤、结果和队列 | 页签移入标题工具区，合并重复帮助；步骤说明按需查看，模板/方案/规则的二级结构保留。 |
| 归档资源库 | 跨包搜索结果、来源列表 | 页签移到标题旁；选择、结果数量、刷新与批量取回合为紧凑工具条，减少列表上方占高。 |
| 密码保险箱 | 密码表格 | 统计入口移至标题操作区，移除列表预留的底部空间；搜索、导入导出及条目操作保留。 |
| 文件完整性 | 摘要结果、校验条目、诊断结果 | 三模式移至标题旁；算法横排，取消每项重复介绍；结果横跨整个内容宽度。 |
| 历史任务 | 历史记录与详情 | 统计继续使用原弹窗，过滤器紧凑换行；结果操作保留主要按钮，其余收进“更多”，避免一行记录被挤成大卡片；删去重复装饰标题。 |
| 设置中心 | 当前分类的控件 | 按外观、辅助显示、压缩与解压、行为、更新、格式支持分组显示；切换不销毁控件，恢复默认移至标题旁。 |

图片、视频、PDF 属于一个导航页的三个子工作区；共覆盖全部 11 个产品导航入口。未注册到产品路由的开发用 DiagnosticView 保留诊断数据，不作为用户入口。

## 二级界面与共用组件

- 共用 Modal 压紧标题和尾部，最大高度由 78vh 提高至 88vh；主体继续独立滚动，窄窗按钮可换行。只有显式标记的介绍才收进问号，动态文件名、所选数量、退出和删除后果保留可见。
- 转换、全局/多选配置、配置组、密码生成、资料密码、所选取回、图片取回、ZIP 整理/密码、快照对比、工作流定时/目录规则的常驻解释逐项审阅，26 段纯介绍改为按需提示。没有隐藏失败处理、范围核对或删除确认。
- 图片阅读保留取回、选择、查找、翻页与缩放；快捷键和读取范围收进问号。包内预览去掉重复的预览类别和底部介绍，编码、大小、完整/截断状态保留。
- 主区域不通过全局缩小字体或隐藏控件来腾空间；继承原主题、单条展开、多选弹窗和双栏 50/50。
