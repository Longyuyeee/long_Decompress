# v1.7.17 · 已确认硬链接内容取回

TAR.LZO 后段损坏或缺卷时，指向前面已确认文件的硬链接内容也可以取回，原目标无需一并选中。

- 支持普通头与局部 PAX 长目标名称，普通、空文件和稀疏目标均保存为独立内容文件，保留空洞与原修改时间。
- 同一来源在实际复制阶段顺序读取，后续所选条目从本次已写入并核对的文件取内容，避免为每个链接反复解码原包；不借用输出目录里的已有文件。
- 原选择列表增加简短来源提示，完整来源放在折叠结果内；逻辑大小、文件数和部分历史保持衔接，单条展开、多选弹窗及等宽双栏保留。

本版扩展部分取回。未确认或有歧义的目标、链接链条、GNU K 长目标记录、符号链接及带正文的硬链接仍明确停止；正常完整解压的链接规则未改动。

见 [本版范围](ARCHIVE_ROADMAP_1.7.17.md)、[实现与检查](TAR_HARDLINK_FREEZE_1.7.17.md)。下一阶段 [v1.7.18 GNU 长链接目标](ARCHIVE_ROADMAP_1.7.18.md)仅规划。
