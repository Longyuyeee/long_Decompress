# v1.5.20 LZIP 数字分卷

2026-10-19，从正式 v1.5.19 `efd0810` 接续，按既定三版路线实施。本版正在开发，不把以下目标视为已交付。

## 范围与真实缺口

现有 LZIP/TAR.LZIP 编解码、多成员与连续卷读取已有；前后端能力表仍禁止分卷，批量配置硬性清除分卷，提示也称不支持。首先固定真实禁用入口，再复用现有切卷、事务及卷组路径，接通首/中/尾卷浏览、有界预览、检查、所选/整包、转换、结果及补卷后新任务。

数字卷是完整压缩流按字节切片，不是 LZIP 原生成员；收到分卷需将全部成员放在同一目录。普通 LZIP 无密码，不新增原生密码承诺。保留单条展开、多选弹窗、自然继承、左右等宽和窄窗滚动。
