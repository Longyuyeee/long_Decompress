# v1.5.20 LZIP 数字分卷

2026-10-19，从正式 v1.5.19 `efd0810` 接续，按既定三版路线实施。本版功能已完成，进入候选与正式发布。

## 范围与真实缺口

现有 LZIP/TAR.LZIP 编解码、多成员与连续卷读取已有；前后端能力表仍禁止分卷，批量配置硬性清除分卷，提示也称不支持。首先固定真实禁用入口，再复用现有切卷、事务及卷组路径，接通首/中/尾卷浏览、有界预览、检查、所选/整包、转换、结果及补卷后新任务。

数字卷是完整压缩流按字节切片，不是 LZIP 原生成员；收到分卷需将全部成员放在同一目录。普通 LZIP 无密码，不新增原生密码承诺。保留单条展开、多选弹窗、自然继承、左右等宽和窄窗滚动。

## 完成的用户流程

- 普通 LZIP/TAR.LZIP 支持数字切卷，`.tlz` 同路由；保留原有事务切卷、输出结果与自然配置继承。批量 TAR.LZIP 保留分卷设置与大小，仅清除不支持的加密/固实等选项。
- GNU 原件单文件、TAR、`.tlz` 和连续多成员切成数字卷后，从首/中/尾卷浏览、完整检查、有界文本预览和整包提取；TAR 所选文件独立提取。独立创建样本的中文目录、空文件及空目录均保留。
- 接通普通 LZIP 文本/图片预览：复用既有 1 MiB 文本保留、64 MiB 扫描、8 MiB 图片预算；浏览超过 8 MiB 显示大小未知，不为列表整包展开。小范围预览不等于完整检查，后段 CRC 错误仍失败。
- 实际单条 LZIP 配置与 1 MiB 分卷创建、两个草稿的多选弹窗、尾卷 TAR 与多成员 LZIP 预览、来源中卷撤回后的失败与补卷新任务、密码 ZIP → TAR.LZIP 数字卷 → 密码 ZIP 数字卷完成。
- GNU lzip 1.24.1 / GNU tar 全内容回解应用普通/目录创建、界面创建与转换产物；密码 ZIP 用独立 7-Zip 全内容回解。检查所有文件哈希与空目录，不以能列目录代替内容通过。
