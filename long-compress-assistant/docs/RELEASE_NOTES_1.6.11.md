# v1.6.11 · ALZ 大文本前缀预览

查看较大的 ALZ 日志、说明和配置时，现在可以直接读取开头，无需先完整解压。

- **沿原位置查看**：继续使用双栏里的双击、预览按钮和只读弹层，文本可在弹层内滚动，另一栏的位置与选择保留。
- **清楚地区分结果**：大文本最多显示前 1 MiB，明确标注“部分内容 · 未校验整文件”；UTF-8、UTF-16 等截断时尽量保留完整字符。小文本仍完整校验后显示。
- **接通原有密码和卷组**：复用手动密码、保险箱、显式编码和完整原生卷，密码候选只读取所选前缀，不先完整验证大文件。关闭取消，来源变化提示刷新；超过读取范围时给提取指引。

本版接通 ALZ Store/Deflate/Bzip2。前缀读取最多扫描 64 MiB 实际所选压缩数据，读取和密码尝试有时间范围；原图片预览、连续阅读、单条展开、多选弹窗和左右等宽布局保持。

前缀可读不代表整个文件或密码已完整验证。提取、检查和转换仍走原完整大小、CRC 和压缩流终止检查。本版不增加格式数量、ALZ 创建/修复、方法 3 或 EGG 加密固实支持；新增组合为明确标注的受控回归，不外推全部历史来源。详见[本版范围与记录](https://github.com/Longyuyeee/long_Decompress/blob/master/long-compress-assistant/docs/ALZ_TEXT_PREFIX_FREEZE_1.6.11.md)。
