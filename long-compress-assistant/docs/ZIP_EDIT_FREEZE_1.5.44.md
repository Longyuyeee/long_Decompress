# v1.5.44 ZIP 添加、替换与另存封板

[单版计划](ARCHIVE_ROADMAP_1.5.44.md) · [中文 Release](RELEASE_NOTES_1.5.44.md) · [检查记录](evidence/zip-edit-1.5.44/)。候选 CI、正常合入、标签与正式资产收据在本版 PR 接续。

## 已交付

原浏览器提供编辑入口，在当前包内目录添加文件/文件夹或拖入；单个文件可勾选替换，也可右键替换。待保存清单统一复核，同名项明确选择替换、跳过或保留两份，跳过可改回；目录保留两份携带全部子项。逐项撤销、放弃全部修改、切页保留本次会话状态和另存贯通。

未修改条目沿原编码复制，保留内容、名称、目录、空目录、有效 ZIP 时间和备注；新增/替换可选 Deflate 0～9 或仅存储。原包不改，已有输出不覆盖。保存沿原进度、日志和停止；失败/停止不清空修改，任务栏返回原编辑后可改名另存，旧失败记录保留。成功用紧凑结果展示定位、复制、校验及浏览新包入口，继续预览、所选提取与历史来源。

单条展开、多选弹窗、自然继承、压缩/解压 50/50 与原滚动保留。新增复核弹窗宽窗左右等宽、窄窗顺排，长名称/路径换行，清单和内容可滚动；成功后收起空清单与不可再编辑的保存选项。

## 第一阶段边界

仅支持独立、未加密且原条目为 Store/Deflate 的普通 ZIP。密码、分卷、自解压、嵌套临时来源、特殊路径/链接、包内重复或大小写冲突及其他方法不编辑，仍沿原有浏览/提取；不静默去密码、转换方法或丢内容。当前会话编辑状态可接续，跨应用重启的编辑操作清单尚未持久化；历史仅保留来源和结果身份，重新启动后从原包开始编辑，不宣称自动回放旧修改。

原包及新包完整读取并核对条目，发布前重查来源，写入检查停止并清理中间文件。输出使用既有不覆盖发布；这些行为随功能实现，不另立重复验收版本。
