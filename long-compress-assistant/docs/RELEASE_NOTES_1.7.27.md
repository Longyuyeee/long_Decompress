# v1.7.27 · 7Z 目录结构与目录时间

7Z 打包现在为每份来源保留明确根目录：不同位置的同名文件夹按整个子树统一改名，内容不再混放；同一来源重复加入只收录一次。

- 非空、空顶层文件夹均写入自身条目，解压最终提交后恢复目录修改时间，支持已有 7Z 日期精度。
- 接通普通与固实压缩、内容密码、文件名加密、完整数字卷以及 TAR.LZO 内容转密码 7Z / 分卷的流程。
- 冲突确认沿原暂存和目录时间清单继续，无需重新解压。只选文件、扁平、关闭时间或包内没有明确日期时，不套用父目录时间。
- 修复选中嵌套文件后平铺解压可能遗漏文件的问题；取回空目录成功时不再误报“没有匹配条目”。
- 保留原界面、单条展开、多选弹窗、等宽双栏与结果入口；ZIP / TAR 及扁平创建规则保持。

本版不增加格式数量。见[本版范围](ARCHIVE_ROADMAP_1.7.27.md)、[实现与检查](SEVEN_ZIP_DIRECTORY_LAYOUT_FREEZE_1.7.27.md)。下一阶段 [v1.7.28 TAR.LZO 前向硬链接兼容提取](ARCHIVE_ROADMAP_1.7.28.md)仅规划。
