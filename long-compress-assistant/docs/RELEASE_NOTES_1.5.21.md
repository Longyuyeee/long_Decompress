# Long解压 v1.5.21

LZ4、Brotli 和 LZIP 也可以直接选择 Long AES 加密组合，保留原来的压缩编码，并按需要拆成分卷。

- **六种新加密组合**：新增 LZ4.AES、BR.AES、LZIP.AES，以及 TAR.LZ4.AES、TAR.BR.AES、TAR.LZIP.AES。单文件和目录/多文件各有对应选项；支持密码与数字分卷，TAR.LZIP.AES 兼容 `.tlz.aes` 别名。
- **集齐分卷后，从任意卷继续处理**：认证后可以浏览内容、预览文本或图片、完整检查、提取所选文件或整包解压。普通 LZ4/Brotli 也接入有界内部预览，修正普通 LZIP 的公共完整性入口分派。
- **转换与结果接通**：可将新组合转换为密码 ZIP，或从密码 ZIP 转换成 TAR 加密分卷；单文件加密流之间也可改格式。完成后从原结果入口定位卷组，来源压缩包保留。
- **配置更清楚**：LZ4 加密组合显示快速模式，压缩分析按实际内层编码抽样；单文件转换提前说明适用范围，目录和多文件请选择 TAR 组合。补齐缺卷后沿原弹窗创建新任务，旧失败历史保留。

单条展开、多选弹窗、自然配置继承、左右等宽和窄窗滚动保持。新组合沿用既有 Long AES V2 和密码规则；这是 Long 自有包装，并非 LZ4/Brotli/LZIP 的原生密码标准，接收方请使用 v1.5.21 或更新的 Long解压。全部数字卷需放在同一目录；认证读取需要临时空间，预览受既有预算限制，不等同整包完整检查。
