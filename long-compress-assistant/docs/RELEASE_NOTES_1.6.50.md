# v1.6.50 · ZIP 快速仅存储

- ZIP 原方法选择新增「仅存储（Store）」：直接打包，不再重复压缩；支持 AES / ZipCrypto 密码、数字与标准分卷、预览、提取和转换。
- 选 Store 后收起强度，切回时恢复；预设/配置组/模板、草稿、历史和工作流保留方法。默认 Deflate、旧强度 0 与其他方法原有映射保持。
- 实际样本压缩收益不足 2% 时提供可选的仅存储建议，点击才只改当前任务的方法，保留密码、强度和分卷，不改全局、不自动执行。Store 的体积和耗时分析按实际方法计算。
- 修复转换界面切换方法后被旧值覆盖的问题，单条、默认和多选配置均能保留新选择，涵盖现有 ZIP 与 7Z 方法。

保留单条展开、多选弹窗和左右等宽。9 类普通/密码/分卷新输出独立完整回解，新增/受影响检查及实际桌面通过，宽窄界面已实看；不重复旧矩阵、安装或盘满。见[本版记录](ZIP_STORE_CREATE_FREEZE_1.6.50.md)。
