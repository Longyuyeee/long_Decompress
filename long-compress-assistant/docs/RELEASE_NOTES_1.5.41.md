# Long解压 v1.5.41 · 按用途配置压缩

不用先研究一堆格式参数：在原来的压缩和转换配置区选择用途，查看实际参数，确认后继续微调。

- **兼容分享**：ZIP / Deflate / 强度 6；已有密码和分卷设置保留，接收方仍需支持相应加密或卷型。
- **体积优先**：7Z / 强度 9，适合归档；可能更耗时间和内存，实际体积取决于内容。
- **加密分享**：7Z / 强度 6 / 密码与文件名加密。填写新包密码或明确沿用已有密码后才能应用；接收方需要支持加密 7Z 的工具。
- **按大小分包**：填写每卷大小，生成标准 ZIP 的 .z01、.z02、…、.zip；分享与提取需保留整组文件。

方案复用现有配置、预设和保存流程。单条仍点击展开，多选仍在原弹窗填入方案、最终确认后生效；默认配置自然继承，编辑一条自动形成单条配置。名称、输出目录、转换的原包密码等未指定参数保持，原有高级选项继续可改。

保留左右等宽与窄窗滚动；选择方案不会打开新的任务弹窗，也不会因打开页面或进行分析而自动切换格式。本版不增加新算法，不承诺固定压缩率或系统自带解压器支持所有密码和卷型。
