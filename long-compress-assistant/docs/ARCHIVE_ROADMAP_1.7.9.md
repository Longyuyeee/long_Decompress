# v1.7.9 规划 · 全局 PAX 与完整 TAR 流程一致性

状态：仅规划，尚未开发。接续 v1.7.8 的 GNU 长名称部分取回；从原扩展元数据计划中拆出，保证正常流程与恢复流程使用相同名称和内容边界。

## 用户目标

含常见全局 PAX 元数据的 TAR / TAR.LZO，正常浏览、解压、转换、诊断和部分取回对文件名与大小的理解一致。元数据不显示成用户文件；遇到无法支持的布局，保留此前已确认的资料并说明停止位置。

## 按序推进

1. 取得独立 GNU tar / Python tarfile / 官方 lzop 原件及完整内容依据，确定全局状态、局部覆盖、空值删除、状态重置与扩展记录自身大小的语义。
2. 修正完整 TAR 读取的共享元数据处理，再接恢复读取。评估采用上游 TAR 解析修正，明确普通条目大小覆盖与 GNU/PAX 扩展记录的边界，避免不同解析器产生不同清单。
3. 先支持普通文件/目录的常见全局字段及局部覆盖，未知或稀疏语义不直接忽略。接通原浏览、所选解压、转换、失败诊断、恢复结果和历史。
4. 使用独立清单和 SHA 比较完整结果与损坏前缀结果，覆盖元数据截断、跨卷、来源替换；复用已通过的非相关流程，不重跑完整格式矩阵。

保留单条展开、多选弹窗、左右等宽、原双栏结构和恢复二级弹窗。仍不承诺链接/稀疏部分取回或缺口后扫描。按用户要求使用后台测试和截图，不接管桌面。
