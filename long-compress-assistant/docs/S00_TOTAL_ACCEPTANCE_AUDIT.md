# S-00 基础能力语义收口总验收

日期：2026-08-27

分支：`codex/archive-media-roadmap`

公开版本：`v1.1.14`（本节点不升版）

## 开发目标

1. 跨步骤复验 S-00.1 至 S-00.4，而不是只引用各阶段旧结果；
2. 用真实 Windows DPAPI、真实加密归档、真实 WebView2/Tauri、完整进程重启和正式 NSIS 覆盖安装证明用户路径；
3. 验证密码正文保护、自动命中、当天趋势、历史持久化、用户数据、经典菜单和归档工作区没有因收口发生回归；
4. 把首次实际与预期差异转为可重复、安装前失败的测试前置门禁；
5. 总验收通过后关闭 S-00，下一阶段只进入 B-00 架构门禁，不提前实现媒体编码器。

## 需求对齐结论

S-00 没有用媒体新功能替代基础压缩解压质量，也没有削弱用户已确认的无主密码体验。密码正文现在受当前 Windows 用户保护，自动命中和统计保持真实；运行任务与历史数据源唯一；格式声明有证据等级；旧工程不再混入产品源码。总验收没有发现产品功能回归，唯一差异属于安装测试前置条件，现已前移为无损预检。

S-00 至此关闭。下一步进入 B-00，只完成统一任务/历史模型、迁移、第三方编码器身份与许可、事务边界和真实媒体夹具基线；B-00 审计通过前不新增图片、视频或 PDF 编码界面与引擎。本节点没有新增用户可见能力，因此不提升版本、不创建 Release。
