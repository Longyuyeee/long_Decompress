# v1.5.57 整包图片阅读：缩略图与连续翻阅（已完成功能封板）

2026-10-22，承接资料对比三阶段。本版于 2026-10-22 开始实现；不改变既定 v1.5.58 阅读记忆和所选取回、v1.5.59 起回归格式与容错主线的顺序。

## 用户任务

打开扫描件、漫画或设计素材包后，在同一个阅读视图连续查看图片，不必逐个关闭预览再打开下一张。

## 推进顺序

1. **从现有图片预览进入阅读。** 先审计现有浏览器、图片预览和缓存能力；复用受支持归档的条目列表与读取接口。按当前目录或整包选择阅读范围，自然数字排序，保留包内路径和回到原列表的位置。
2. **完整翻阅操作。** 当前页/总数、上一张/下一张、键盘翻页、适应窗口、原始大小和缩放。缩略导航按需读取，当前图片保持主要空间；工具栏可换行，窄窗保留完整操作和可滚动区域，不占用原任务的配置/日志布局。
3. **慢读与不可读内容。** 显示加载进度和明确原因，可重试或跳过；只预取少量相邻图片，离开后取消无关读取并释放缓存。密码、卷组、固实或大图片沿现有真实可预览边界说明，受限条目继续原提取后打开流程。
4. **接回原工作区。** 从阅读器回到同一来源和所选条目，保留现有预览、提取及结果入口；不为了阅读引入新的配置体系。

## 封板范围

- 首版需交付受支持归档中可连续翻阅的图片流程，不能只交付缩略图外观。明确加载失败与来源变化，原件保留。
- 只检查新增读取/取消、排序与页数、连续切换、返回定位、实际宽窄显示和相关资源释放。复用未受影响的格式、密码与分卷依据，不重复旧矩阵、盘满、媒体压缩或个人安装。
- 重启阅读记忆、大包导航维护、资料库命中定位与多选素材取回留在 v1.5.58；不承诺本版新增图片解码器、PDF、OCR 或图片编辑器。

资料对比完成后直接转入本阶段，不继续添加没有明确用户收益的对比完善版。后续格式/算法主线仍按 [总路线](ARCHIVE_ROADMAP_1.5.44_TO_1.5.59.md) 接续。

## 实施选择（编码前）

- 保留原单张图片/文本预览，在原浏览器和图片预览中增加连续阅读入口；当前目录或整包自然数字排序，当前页/页数、跳页、前后翻阅、键盘、适应窗口/原始大小/缩放，退出保留原列表与选择，另可定位当前图片或沿原提取流程取出。
- 单独阅读视图采用大图为主、工具栏与相邻缩略导航；窄窗工具栏换行，舞台独立滚动。不更改原单条展开、多选弹窗与任务 50/50。
- 复用现有 PNG/JPEG/GIF/WebP/BMP 的有界解码路线与原限制。增加可取消的图片读取和实际读取事件，TAR 显示扫描阶段，WIM/ZPAQ 沿现有进程取消；不为固实/受限来源扩大预算。
- 浏览清单绑定整组来源版本，阅读/缓存命中都确认版本，变化后停止复用并返回刷新。密码/编码/快照沿原来源，仅会话；未支持或坏图片有清楚原因、重试/跳过和原提取出口。
- 最多缓存 3 张、原始图片字节合计 16 MiB、像素合计 2400 万，仅预读下一张；缩略导航最多 7 项。使用可释放对象 URL，切换取消无关请求，关闭释放全部。长列表、大包维护和阅读记忆仍留 v1.5.58。
