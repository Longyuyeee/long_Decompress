# v1.7.27 · 7Z 目录结构与目录时间封板

日期：2026-10-28。

## 实现与用户行为

7Z 创建由旧逐条名称收集改用已发布 ZIP / TAR 的根名称分配器。非空/空顶层文件夹均有显式条目；不同位置的同名根、文件与目录根冲突统一映射整个子树，同一规范来源去重。扁平创建继续使用旧命名和重复选择策略，ZIP / TAR 行为保持。

现有 7Z 解压回调同步收集明确目录时间，沿原暂存整理筛出仍保留的目录，再在最终提交和暂存清理后由深到浅恢复。冲突等待保留相同时间清单，用户确认后无需重解压或重读日期。只选文件、扁平、关闭时间以及隐含/大小写重复歧义目录不编造父目录时间；无日期目录与 anti 条目不当作可信目录日期。

目录信息没有新增归档头重读或整包读取。已有密码检查、进度总量和冲突文件时间读取仍保持。选择/筛选沿原包身份，暂存整理再扁平，修复嵌套所选文件在平铺解压中丢失的问题；空目录成功创建也计入匹配数，避免错误的“没有匹配条目”提示。创建与读取沿现有 7Z 时间表达，实际核对 100 纳秒精度。

覆盖普通/固实、内容密码/文件名加密、完整数字卷及 TAR.LZO 已确认链接内容转换到密码 7Z / 数字卷。另以同一连续字节流重命名为现有好压论坛命名规则，确认目录流程可沿该读取路由；此例是命名兼容检查，不冒称本版新增真实好压生产者原件。源包/卷组版本检查、取消、同名、结果与历史入口保持。UI 未改，不增加格式数、权限/所有者或新的链接能力。

- 相关旧 2 项通过：7Z 归档头完整范围/截断/损坏判定、保留时间和仅提取较新模式的文件日期。末尾仅补空目录匹配计数，不重跑已通过内容矩阵。
