# v1.7.16 · PAX 0.0 稀疏文件部分取回

TAR.LZO 后段损坏或缺卷时，已校验连续前缀内的完整 GNU PAX sparse 0.0 文件也可以取回。

- 按原顺序处理重复的稀疏偏移/长度属性，保留全部数据段；支持长名称、全零文件和大空洞。
- 核对配对顺序、声明段数、逻辑大小、包内数据量及完整填充，缺失、乱序或冲突布局明确停止。
- 取回保留空洞与原修改时间，继续使用原选择列表、折叠结果和部分历史；单条展开、多选弹窗、等宽双栏保持原交互。

旧 GNU 与 PAX 0.0/0.1/1.0 的已确认完整前缀取回现已衔接。链接救援、缺口后扫描和完整权限恢复未扩展，目标目录须支持稀疏文件。

见 [本版范围](ARCHIVE_ROADMAP_1.7.16.md)、[实现与检查](TAR_PAX00_FREEZE_1.7.16.md)。下一阶段 [v1.7.17 已确认硬链接内容取回](ARCHIVE_ROADMAP_1.7.17.md)仅规划。
