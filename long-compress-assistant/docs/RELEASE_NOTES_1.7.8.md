# v1.7.8 · TAR.LZO GNU 长文件名与长目录部分取回

损坏或缺卷的 TAR.LZO，遇到 GNU `L` 长名称记录时，可以继续识别此前完整、已校验的普通文件和目录，沿用现有“选择完整条目部分取回”弹窗。

- 支持 GNU 长文件名、长目录和 UTF-8 路径；名称只用于下一条文件或目录，不会错套到后面的文件，也不会把名称元数据显示成文件。
- 名称记录、对应文件头、内容与填充均完整后才提供取回；跨数据块、记录截断和缺中卷时，保留此前已确认条目，不跳过缺口。
- 继续使用目录联选、筛选、独立结果位置和“已部分取回”历史；补齐或更换来源后需重新检查。
- 恢复列表优先展示真正的文件名，目录放在下一行，悬停查看完整路径；长目录下的同名文件更容易区分，宽窄窗口沿用原布局。
- 完整 GNU 包仍可正常浏览、文本预览、解压与完整诊断，损坏前缀不会显示成整包成功。需要兼容名称编码时沿用原编码选项。

本版不扩展链接、稀疏文件或缺口后扫描。GNU/PAX 混合叠加、重复名称记录和全局 PAX 等尚未支持的恢复布局会明确停止。全局 PAX 对正常浏览、解压、转换及恢复的一致处理已拆为 [v1.7.9](ARCHIVE_ROADMAP_1.7.9.md)，仍仅规划。

见 [本版范围](ARCHIVE_ROADMAP_1.7.8.md)与 [实现和检查](TAR_LZO_GNU_NAME_FREEZE_1.7.8.md)。
