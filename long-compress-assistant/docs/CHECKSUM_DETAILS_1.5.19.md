# v1.5.19 逐文件校验与待补列表

2026-10-19，接续已正式发布的 v1.5.18（47a41ab），分支 codex/v1.5.19-checksum-details。这是既定三版路线的最后一项，现已完成功能封板，最终候选/正式状态见[封板记录](CHECKSUM_DETAILS_FREEZE_1.5.19.md)和本版 PR/Release。下文“当前”问题为开工时依据，完成范围以封板为准。

## 用户问题与实施范围

当前 verify_checksum_file 只返回 valid/message，服务层把缺失、内容不符、读取错误归为 false，界面只能展示一个总失败提示。已有 CRC32/MD5/SHA256、SFV/MD5/SHA256 清单导入/导出不重复开发。

本版返回逐行文件路径、预期/实际摘要和匹配、缺失、内容不符、无法读取、清单项有误、未检查状态。界面在原校验页展示紧凑列表，单条点击行内展开详情；复制缺失/内容不符的待补文件列表、复查问题项或所选项，不后台重复全包哈希。未复查项保留注明的上次结果，未检查项不能计通过；清单变化时放弃旧摘要结果并明确提示。

归档条目可接续已有诊断，补齐来源后进入解压中心的失败纠正弹窗建立新任务；不自动覆盖旧任务或把摘要匹配称为归档内容完整性通过。保留既有单条展开、多选弹窗、自然继承、左右等宽与窄窗滚动。

只做受影响的服务/组件与实际界面检查，复用已通过且未改动的格式、密码分卷证据。v1.5.18 的真实 256 MiB NTFS VHD 盘满补测已由运行 39212555499 完成，不重复该补测。ALZ 方法 3、EGG 加密固实、Windows N 原边界保持。
