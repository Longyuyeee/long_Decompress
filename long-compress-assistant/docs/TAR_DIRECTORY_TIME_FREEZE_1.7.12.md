# v1.7.12 · TAR.LZO 取回目录时间封板记录

日期：2026-10-27。

## 已完成

扫描明确记录的目录时沿用 v1.7.11 的普通/GNU/PAX 有效时间解析，包含全局继承、局部覆盖与空值删除。内容复制完成后，按实际目标路径深度从深到浅应用所选目录时间并回读。Windows 使用目录句柄的 read/write attributes 和 backup semantics，不请求修改目录内文件的访问能力。自动建立但未选中的父目录不套用原包时间；原名、内容及发布流程不变。

目录时间缺失、不可精确表达、超出范围、精度不足或句柄打开/写入失败时在对应项单独提示，已取回内容不改判失败。目录阶段每项检查取消，重复字节进度按批次合并，来源最后仍重新确认；取消或来源变化不发布暂存结果。

原结果默认折叠显示时间与提示，文件/目录分别统计；仅取回目录时也显示时间摘要。原历史详情保存可选的一对目录计数，前后端校验数量和，不为旧记录补造“目录时间已恢复”。无新增页面、常驻面板或操作切换，单条展开、多选弹窗、等宽双栏与主题保留。

## 独立依据

两份自编资料的 Python tarfile GNU/PAX 生产者原件位于 `tests/fixtures/archives/tar-directory-time-1712/`，固定 SHA 官方 lzop 压缩并完整回解核对。包含多层目录、父目录条目在子文件之后、空目录、仅有隐式父目录的文件、大文件及负数/小数/范围/精度时间。GNU/Python 对清单和文件内容一致，目录时间以 Python/Decimal 和 GNU 完整时间清单核对。

GNU 1.35 对负数小数的已知分歧继续记录在 manifest，不重复研究、不冒称所有工具时间一致；沿用 v1.7.11 的整体负数语义。局部/全局删除、未知时间的构造边界单独说明，不冒充第三方原件。没有改动正常完整读取器或时间数值解析器。
