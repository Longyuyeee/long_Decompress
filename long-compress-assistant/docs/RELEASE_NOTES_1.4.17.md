# v1.4.17 · 好压论坛 7Z 密码分卷兼容

- **从任意一卷继续。** 支持好压原生 `.haozipNN.7z` 论坛分卷，兼容内容密码与文件名加密。乱序选择整组只加入一项任务，浏览、解压、完整性检查和转换共用完整卷组；无需手工改名或合并文件。
- **先说明缺卷和损坏，再处理密码。** 缺首卷、中卷时列明文件名；缺尾卷、截断和起始头校验失败在密码解码前说明原因，不再把这些结构问题变成反复要求密码。历史与最终日志保留真实原因，补回原卷后可创建新任务继续，保留原失败记录和输出设置。
- **输出名称更干净。** 论坛 7Z 的预览和实际同名目录去掉卷号，避免把 `.haozip01` 带入输出文件夹。
- **普通 7Z 的失败提示更准确。** 显式输入密码后重新浏览也会检查起始头和声明长度；窄窗口的长错误说明保持在卡片内部并可正常滚动。

本版以好压 GUI 实际生成的两组原卷、独立回解和真实桌面流程验证，保留现有 ZipCrypto 论坛 ZIP 支持；暂不承诺好压 AES ZIP 论坛卷，不新增 7Z 有界内容预览、特殊卷创建或缺卷数据修复。用户明确委托后按原工具实际能力收口，不将普通数字卷改名当兼容证据。

智能目录和 ZIP 并行仍默认关闭，Windows N 暂不保证支持。实现与原卷、页面及测试范围见[本版审计](SPECIAL_VOLUME_COMPATIBILITY_1.4.17.md)；发布身份与资产见[封板记录](SPECIAL_VOLUME_FREEZE_1.4.17.md)，下载见 [v1.4.17 Release](https://github.com/Longyuyeee/long_Decompress/releases/tag/v1.4.17)。
