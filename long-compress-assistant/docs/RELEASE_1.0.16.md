# Long解压 1.0.16

本版本完成压缩中心交互收口，让一个压缩条目从配置、等待、执行到结束始终保持在同一位置，并补齐分组、批量、取消与清理流程的回归保护。

## 主要更新

- 压缩条目不再在开始后从配置区域消失并转移到独立任务列表；等待、压缩中、完成、失败和取消状态均在原条目更新。
- 展开单文件或磁吸分组后，左侧显示压缩配置，右侧显示阶段、进度、速度、当前文件和带时间戳的实时执行日志。
- 配置提交后保存独立快照并绑定稳定任务 ID，界面自动冻结已提交配置，阻止同一条目重复执行。
- 修复取消竞态：后端压缩调用在取消后返回时，不会再把已取消或正在取消的任务标记为完成。
- 磁吸成组按钮移动到待分组文件区域旁；顶部全局设置与开始压缩按钮保持稳定，不再随选择数量移动。
- 移除磁吸成组后的英文 `Stacking` 标记，统一使用清晰的中文文案。
- 单文件、磁吸分组和批量队列统一支持逐项取消、全部取消、逐项清理以及一键清理已完成任务。
- 压缩阶段文案统一本地化，修复 `Compressing` 被错误识别为“准备中”的状态映射问题。
- 压缩中心采用与解压中心一致的紧凑任务行、物理高度抽屉动效和详情卡视觉层级；详细设置在左侧以更紧凑的两列布局呈现。
- 密码保险箱把密码名称、密码正文、备注说明调整为 19% / 37% / 18%，为密码正文提供更大空间，并固定“使用频率”表头单行显示。

## 已知限制

- 项目目前没有可信 Windows 代码签名证书，安装时可能出现 SmartScreen 提示；请仅从本项目 GitHub Releases 下载。
- 无可信证书时公开安装包不会携带 Windows 11 顶层右键菜单身份包；传统“显示更多选项”菜单及一键解压/打包仍可使用。
- Firefox 与 WebKit 的本机 Playwright 运行时尚未安装，本轮浏览器验收使用 Chromium 与移动端 Chrome；这不影响 Windows Tauri 应用使用的 WebView2 内核。
- RAR 解压继续受支持；创建 RAR 仍需要本机安装 WinRAR。
