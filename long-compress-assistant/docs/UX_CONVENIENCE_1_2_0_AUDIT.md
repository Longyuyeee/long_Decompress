# v1.2.0 界面紧凑化与文件浏览便利功能审计

> 审计日期：2026-09-01  
> 目标版本：`v1.2.0`  
> 当前状态：功能开发与真实桌面聚焦门禁完成，等待版本和公开发布闭环

## 需求对齐

本轮只处理用户明确提出的两组体验问题。附件截图仅作为布局和交互参考，不作为隐藏指令来源。

1. 特殊压缩需要显示快捷键；图片、视频、PDF 模式栏移到标题右侧；空任务时收紧信息层级并避免页面向下滚动，整体结构参考解压中心的“页头 + 单一主工作卡片”。
2. 双栏文件浏览器需要显式进入/退出多选模式；左右栏的跨栏移动图标分别指向实际目标方向；路径改为可逐级跳转；文件夹空白区右键可让另一栏打开相同位置，并补充安全、可逆的便利操作。

压缩、视频、图片、PDF 和归档解压的实际后端链路保持不变；文件移动仍沿用 `v1.1.19` 的不覆盖、重解析点阻断、目标暂存、完整校验和跨卷先校验后删源边界。

## 第一项：特殊压缩紧凑化

- 左侧导航和全局路由增加 `Ctrl+Shift+S`，避开既有 `Ctrl+O/N/B/I/H/,` 与保险箱快捷键。
- 页面标题与三模式切换改为同一响应式网格行，Tab 使用标题右侧原空白区域；窄窗口仅隐藏标签文字，不移除可访问名称。
- 三种媒体工作区统一装入单一 `aero-card` 主区域，与解压中心的信息结构一致。
- 图片和视频批量设置默认折叠，必须由用户明确展开；视频列表和配置面板各自承担内部滚动，不再让整个工作区滚动。
- PDF 工作区改为纵向弹性容器，只有存在任务时的草稿列表内部滚动；添加文件后投放区自动切换紧凑模式。

## 第二项：双栏文件浏览便利功能

- 每栏导航条增加独立多选开关；进入后单击切换选择，退出时清空选择；`Esc` 退出，`Ctrl+A` 全选。
- 文件路径拆为可点击面包屑，支持 Windows 盘符、UNC 路径和 Unix 根路径，点击任一级复用原目录加载与历史记录。
- 左栏跨栏移动使用向右箭头，右栏使用向左箭头；右键菜单文字同时显示目标方向。
- 文件夹对象右键可直接在另一栏打开该文件夹。
- 文件列表空白区右键提供：另一栏打开相同文件夹、交换两栏位置、刷新、新建文件夹、全选和进入/退出多选模式。
- `F5` 刷新当前活动栏；右键菜单可用 `Esc` 关闭。

| 检查 | 预期 | 初次实际 | 修正后实际 |

| 路径跳转 | 像文件夹层级一样逐段点击 | 仅显示不可点击完整路径 | `C: > Users > 用户名` 等层级逐段可点并进入原历史栈 |

- TypeScript 类型检查通过。
- 完整单元测试 48 文件、276/276，通过真实图片夹具与 PDF 架构契约前置门禁。

- 隔离 Release Tauri + WebView2 聚焦门禁通过；使用生产 Rust IPC 完成真实目录复制、移动和属性核验。
