# v1.7.41 · Windows 右键菜单与弹窗修复

候选说明，尚未正式发布。

- 修复经典右键菜单出现两个同名 Long解压入口、点入通用小菜单后看不到完整功能的问题。按普通文件、压缩包、图片和校验清单，由单一入口提供适用操作。
- 压缩包保留浏览与三种解压入口，5 项压缩收进“压缩打包”，完整性、修复、转换、密码和分卷收进“更多操作”。图片优先显示图片压缩、WebP 和尺寸操作，同时保留普通压缩。
- 校验操作统一进入 Long解压菜单；补齐 Windows 11 原生命令和完整菜单包声明。无有效原生身份时，完整菜单位于“显示更多选项”。
- 设置显示实际菜单入口，并增加“修复菜单”；修复注册交错、旧注册误判和部分菜单关闭后残留的问题。
- 修复开启“减少动画”后窗口整体右移、无法再操作开关的问题，保留已保存设置。
- 修复“打开压缩包”在小窗口、不同缩放和长路径下的横向溢出。内容可上下滚动，关闭和底部操作保持可见；共用弹窗一起适配，补齐双栏查看图标。[检查记录](DIALOG_RESPONSIVE_FIX_1.7.41.md)。

保持单条展开、多选弹窗和等宽双栏。菜单功能数按叶子命令计算：普通文件 6、文件夹 5、压缩包 14、支持的图片 9、校验清单 7。[核对范围与限制](EXPLORER_MENU_AUDIT_1.7.41.md)。
