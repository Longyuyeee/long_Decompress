# v1.7.23 · TAR.LZO 嵌套压缩包链接浏览封板

日期：2026-10-28。

## 用户行为与实现

本期允许已确认目标的 TAR.LZO 压缩包副本沿原双击、Enter 与右键“进入压缩包”继续浏览。复用完整确认计划，仅将所选副本取到原会话缓存，原目标不需要选中；普通嵌套文件继续调用原提取器。普通头、局部 PAX、GNU 长目标/自身名称均沿既有身份规则，不创建系统链接，不增加格式数量。

嵌套请求携带当前原件版本和独立请求编号。准备、目录读取、内容复制后与缓存提交前重查来源；卷组继续使用原完整来源身份。真实格式头、所选大小、完整 SHA、层数和缓存祖先身份核对后才返回。身份哈希按块可取消；出错自动删除本次目录并归还缓存额度。沿用三层、单文件 64 MiB、会话 256 MiB / 64 份上限。

移除前端对压缩包副本的拦截，其他链接的外部默认打开限制保留。嵌套前后使用同一栏导航与列表，返回恢复目录、选择、焦点路径和滚动位置，另一栏不动；当前面包屑在长路径及缩放时保持可见。底栏提供轻量打开状态和取消；取消/卸载后的迟到结果不改变当前页，内层继续单独填密码。没有增加页面、常驻说明或配置大区。

## 原件和检查

- 项目自编 ZIP（含第三层 ZIP 内容）、文件名加密 7Z 与伪 ZIP 通过真实 Linux 硬链接交给 GNU tar 1.35，分别输出 GNU/PAX 原件；固定 SHA 的 lzop 编码往返，独立 Python TAR 读取确认逻辑内容。GNU 长目标与长自身名称均超过短头容量，不把项目原件称为额外第三方格式认证。
- 新原生 4 项通过：GNU/PAX ZIP、加密 7Z、长名称、完整外层数字卷；源版本变化、复制期间来源变化、取消和注入磁盘错误 112；伪 ZIP、坏尾、缺卷与深度不符的清理；普通嵌套回退与身份哈希取消。相关旧原生 2 项通过：服务端层数/祖先重复和四层边界。既有缓存上限函数保持。
- 7 份实际取回结果与生产者 TAR 的完整逻辑字节/来源 SHA 比对，均为独立普通文件；独立 7-Zip 读回 ZIP 与加密 7Z，继续核对 ZIP 内的第三层内容，加密输出拒绝错误密码。原生先确认 Windows 文本的原始字节，独立文本展示比较兼容换行符。
- 前端新增 4 项、相关旧 4 项通过：请求绑定、同栏进入/返回和滚动/选择、取消迟到结果、来源变化提示、原内外密码/编码隔离、三层上限及返回后迟到目录结果。首次两项失败分别修正定位选择器和来源变化提示被通用文案覆盖的问题，只补查失败项。
- 后台真实 Vue/CSS 原生值回放 4 组通过，覆盖等宽双栏、嵌套/返回/文本预览、取消与独立内层密码。1200×760 和 900×600 无横向溢出，另一栏路径/内容/选择保持；六张截图已查看。实看后补当前面包屑可见性，再查受影响页面；未控制桌面，回放不替代真实物化检查。
- 类型/Vite、Shell DLL、八处版本身份与差异空白检查通过。未重复无关矩阵；错误 112 为受控注入，未重做真实盘满实验。正式安装器与签名自动更新附件由对应提交 CI/Release 接续。
