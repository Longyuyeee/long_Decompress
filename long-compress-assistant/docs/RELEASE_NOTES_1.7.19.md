# v1.7.19 · 完整 TAR.LZO 硬链接目录与预览

完整 TAR.LZO 包中指向前面内容文件的硬链接，现在可以在原双栏浏览器里查看正确大小，并直接预览文字和图片。

- 支持普通头、局部 PAX linkpath 及 GNU L/K 长名称组合，衔接普通、空文件和已支持的稀疏目标；搜索和目录导航沿用原操作。
- 按需重读包内目标，两遍读取共用 64 MiB 扫描额度，保留文本前 1 MiB、图片 8 MiB 的预览限制，并接通取消和来源变化提示。
- 列表用简短标记区分链接内容，完整来源收进详情并换行展示。双栏等宽、单条展开及多选弹窗保持不变。

本版为只读目录与预览。链接提取、整包解压及转换继续分期，菜单对尚未接通的操作给出只读提示；不创建系统链接。前向、歧义或未确认目标、链条、符号链接及其他非普通条目仍明确限制。

见 [本版范围](ARCHIVE_ROADMAP_1.7.19.md)、[实现与检查](TAR_BROWSE_LINKS_FREEZE_1.7.19.md)。下一阶段 [v1.7.20 所选硬链接内容提取](ARCHIVE_ROADMAP_1.7.20.md)仅规划。
