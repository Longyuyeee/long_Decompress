# B-05.3 正式安装版图片全流程审计

审计日期：2026-08-28（Asia/Hong_Kong）

开发分支：`codex/archive-media-roadmap`

公开基线：`v1.1.14`；本步骤只完成 B-05 功能验收，不提前修改版本或公开 Release。

## 1. 目标与真实性边界

B-05.3 验证同一份无 `desktop-e2e` 桥的正式 NSIS 候选经过真实覆盖安装后，可以完成图片输入、可见配置、执行前原图/结果边界、真实编码发布、结果对比、统一历史、完整应用重启和输出重新打开，并在卸载后恢复公开 `v1.1.14`、用户数据与右键菜单。

自动化输入使用正式 WebView 中存在的 `window.__TAURI_IPC__`，按锁定的 Tauri 1.x `Event.emit` 协议发送 `tauri://file-drop`，命中产品已注册的生产拖放监听、`get_file_info`、图片检查和后端执行链。它没有安装测试桥、没有直接改 Pinia/DOM 状态，也没有用浏览器 `File` 或 mock 结果代替磁盘路径。该门禁验证生产拖放事件协议，不声称复现了 Explorer 鼠标轨迹；B-02 已另有真实系统文件选择证据。
