# v1.5.34 ZIP BZip2 创建实施

2026-10-21，接续正式v1.5.33（PR #228，标签6c65ab68b9283650cc28e90c48cadf2d0942f973，正式运行39449850570成功）。

在原ZIP方法选择加入BZip2（真实方法12），旧Deflate/Zstandard和ZIPX固定XZ不变。沿用已有zip 8.6与BZip2依赖，不新增引擎或二进制。有效强度1–9；旧0按1执行且仍使用BZip2，单条和转换显示实际最低值，方法帮助说明兼容性。智能分析按BZip2采样，避免用Deflate体积冒充预测；采样0同样使用合法的最小块。

配置组/模板、预设、草稿、历史和多选保留方法，方法单独批量修改只作用ZIP、无关任务保留继承。单条展开、多选弹窗、50/50与窄窗滚动保持；转换ZIP方法移到目标格式旁，与上版WIM选择位置一致。

本版已接通普通/AES-256/ZipCrypto、数字与标准分卷的底层创建和独立回解；再核对公共命令、浏览/有界预览/检查/所选及整包、密码原包双向转换、缺卷补齐新任务和统一结果。新写的测试夹具先前遗漏卷首归一与事务临时路径约定，已纠正；分析前端mock缺少结果已补，只接续失败检查。最终通过项与程序身份在封板记录接续。

默认ZIP兼容性不变；BZip2不是单独.bz2文件，也不是所有系统内置解压器都支持。分享时接收方需支持对应方法、加密和卷型，不承诺通用压缩率。原有格式/密码矩阵和真实盘满不重跑。

实际桌面发现并修复长路径分卷提交错误，最终六项不同Rust、六项前端、两条公共原生及六条UI已通过；范围、各程序身份及夹具补查记录见[封板](ZIP_BZIP2_FREEZE_1.5.34.md)。下一版[ZIP PPMd](ARCHIVE_ROADMAP_1.5.35.md)仅规划，尚未开发。
