# C-05.2.2 视频长时长与大文件真实矩阵审计

日期：2026-08-29

## 结论

**C-05.2.2 已完成，C-05.2 关闭，C-05 尚未关闭。** 两个独立有效 AVI/MPEG-4 输入已分别覆盖 10 分钟时间轴和至少 100 MiB 的大文件，并各自通过唯一产品压缩管线的探测、规划、容量预检、编码、完整验证和原子发布。产品 ffprobe 对输入和输出再次全帧扫描，机器结果 `differences: []`。

该结果与 C-05.2.1 合并后完成原始 C-05 中的格式、分辨率、三预设、无音频、10 分钟及大文件开发态矩阵；不替代后续取消、跨重启历史、默认应用、安装版、Windows N 和公开更新验收。

## 验收口径

- 原始计划只写“至少一个大文件”，没有可执行阈值；仓库 `tests/README.md` 的大文件层级为 10 MB、100 MB、1 GB。本步选择 `100 MiB`（104,857,600 B）作为稳定下限，避免把普通几 MB 视频冒充大文件。
- 长时长与大文件是两个独立样本，避免只用一个样本同时勾选两个要求而漏掉独立路径。
- 两个样本均为可由产品解码的 AVI/MPEG-4，而不是稀疏文件、尾部填充或伪造元数据；输入也由产品 ffprobe 进行 `-count_frames` 全帧读取。

## 实现与边界

- 固定清单：`tests/fixtures/media/c05-video-long-large-matrix.json`；
- 单命令：`npm run test:video-long-large:real`；
- 本机机器证据：`test-results/c05-video-long-large-matrix/result.json`，大输入、输出和工具均在被忽略的 `test-results` 下，不提交二进制；
- Rust 环境门禁调用私有 `run_video_compression`，没有建立测试专用压缩实现；
- 输入生成继续复用 C-05.2.1 固定 URL、版本和 SHA-256 的 GPL FFmpeg，仅作隔离测试工具，禁止进入产品资源、安装包或生产调用路径；
- 架构门禁固定 600,000 ms、100 MiB、两个独立执行、产品 ffprobe 全帧复核和私有产品管线入口。
