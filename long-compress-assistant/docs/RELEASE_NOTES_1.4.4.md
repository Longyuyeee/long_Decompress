# Long解压 v1.4.4

本次升级聚焦密码分卷兼容与坏包处理：生成的 ZIP 更方便分享，失败原因更明确，目录损坏时能尝试救回完整文件。

## 标准 ZIP 分卷创建

- 压缩中心和归档转换新增“标准 ZIP · .z01/.zip”卷型，可配合 AES-256、ZipCrypto、修改密码、重新分卷与合卷使用。
- 旧版数字切卷 `.zip.001` 保留为默认，新卷型由用户主动选择；历史、草稿、配置组和任务模板都会保留选择。
- 标准卷的 `.zip` 是分享/打开入口，请把全部 `.zNN` 和 `.zip` 放在同一目录。不足一卷时生成普通 ZIP，每卷支持 64 KiB 至小于 4 GiB。
- 修正 ZIP 压缩等级 0 仍压缩的问题，并补齐大文件 ZIP64 创建与整组容量计算。真实超过 4 GiB 的无密码文件已经完成原生创建、读取和独立软件校验。

## 密码与格式兼容

- 补齐 PPMd ZIP/ZIPX 读取，修复加密 ZIPX、ZIP 别名和改名归档的密码解压路径。
- 直接选择 RAR 或数字卷中间成员时先定位首卷；缺卷先明确提示，不把它当成密码问题。修正 RAR 后备引擎输出参数。
- 复核常用 ZIP 方法与 AES/ZipCrypto、RAR4/RAR5 的加密/固实与新旧卷型、7Z 的 Unicode 密码/固实/文件名加密组合。
- 明确区分错密码、缺卷、截断、不支持的方法及无法确定的加密内容异常，不再把所有内容读取失败都指向重复试密码。

## 损坏 ZIP 完整条目救援

- 普通 ZIP 和完整数字卷丢失中央目录时，可尝试依据可信本地头恢复完整条目；目录仍可读的普通标准 ZIP 卷组也可救回好的文件。
- 坏内容不放进新包，显示恢复数量和未恢复原因；部分恢复使用警告提示，目录重建时明确原包总条目数无法确认。
- 原包保留，新包发布前完整校验；取消不会留下半成品，也不覆盖已有目标。

## 使用边界

中文 ZIP 密码仍默认 UTF-8。与部分 Windows 软件交换时可主动选择“Windows 兼容”编码，跨系统分享也可优先考虑 7Z；程序不会自动降级或改变密码编码。ZIPX 支持以实际方法为准，不等于支持所有专有算法。

恢复不支持密码 ZIP、缺卷、未知边界或丢目录的数据描述符猜测恢复；标准磁盘卷丢失中央目录本身暂不承诺重建。无法找回原本不存在的数据，恢复后请核对文件是否齐全。RAR 创建仍需要用户安装 WinRAR；ARJ/Z/UDF 和 RAR 恢复卷不是本次新增能力。
