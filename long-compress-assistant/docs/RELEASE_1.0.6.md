# 胧解压 1.0.6

本版本升级了完整归档引擎，并补齐运行时能力检测、RAR 创建决策流程与第一批扩展格式。

## 主要更新

- 随安装包提供完整 7-Zip 26.02 引擎、DLL 和原始许可文件。
- 根据当前引擎实际报告动态识别可读取及可创建格式。
- 新增 WIM 创建能力。
- 扩展 QCOW/QCOW2、VDI、VMDK、APFS、EXT2/3/4、GPT、MBR、AR、CramFS、PPKG、MSP/MSM 等格式读取。
- 创建 RAR 缺少编码器时，可改用 7Z、通过 winget 安装 WinRAR、打开官方下载页或取消任务。
- 用户已安装 WinRAR 时支持普通及密码 RAR 创建。
- 设置中心新增引擎版本、格式能力数量、RAR 状态与重新检测入口。
- 新增真实 7Z、ZIP、TAR、WIM、密码 7Z 和 AR 样本回归矩阵。

## 验证

- 前端单元测试：82 项通过。
- Rust 归档能力回归：12 项通过。
- 真实归档样本矩阵：6 类场景通过。
- TypeScript、Rust 全目标检查、生产构建及 NSIS 安装包构建通过。

## RAR 说明

RAR 是专有格式。本项目不会分发 RAR 编码器；创建 RAR 需要用户自行安装并遵守 WinRAR/RARLAB 的许可条款。RAR 解压仍由应用的读取引擎支持。
