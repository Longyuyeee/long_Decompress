# Long解压 v1.1.6

本补丁版集中收口压缩、解压和密码处理主流程，使界面状态、后端执行、能力声明和真实落盘结果保持一致，并补齐 Windows 桌面与安装态发布门禁。

## 修复与改进

- 密码候选统一由后端状态机执行：先尝试密码保险箱；只有用户开启字典尝试时，才继续使用导入字典和推荐字典。未加密归档不会进入密码破解流程或记录虚假成功。
- 批量压缩与解压接通有界并发，同一解压输出目录始终串行。新安装和迁移后的默认并发保持为 1，用户可在设置中心明确提高。
- 任务事件使用引擎真实处理字节计算速度与预计剩余时间；不提供字节回调的路线只展示可证明的进度，不伪造吞吐。
- 7Z 固实压缩使用原生单压缩块写入，真实回归覆盖 AES 密码双文件归档、固实元数据和完整解密。
- 分卷创建能力按实际实现收敛为无密码 ZIP 普通文件，7Z 不再误报可创建分卷。
- TAR、GZ、BZ2、XZ、Zstandard、LZMA 等非原生密码格式转为 AES-256 7Z 时，设置面板会显示最终扩展名，提交前再次确认；拒绝后不创建任务或输出。

## 发布与兼容性

- 版本身份统一为 `1.1.6`，覆盖前端包、Tauri 应用、Rust 主程序、Shell Extension 与锁文件。
- 继续发布 Windows x64 NSIS 安装包和带更新签名的应用内更新资产。
- 项目仍没有商业 Windows 代码签名证书，因此发布流程继续跳过 Windows 11 第一层菜单身份 MSIX；经典“显示更多选项”中的 Long解压 子菜单保持可用。
