# Long解压 v1.5.12

本版修复 ALZ 普通 Deflate 压缩流的完整性检查缺口，改善“内容已解出却仍有尾部异常”时的最终原因。

- 既有引擎可能忽略 Deflate 结束标记后仍在声明范围内的额外数据。现在会检查完整压缩输入，不再将这类故障记为完整成功。
- 加密条目只有在全部内容大小和 CRC 都匹配后，才将尾部残留明确报为归档损坏并停止重复试密；未通过完整校验时仍保留不确定类别，不凭密码短头判断。
- 八组原 ALZip 普通/中文密码、单包/原生卷均经独立回解核对；故障检查、无半成品、重新获取原包后新任务、历史最终原因、转换及暂停取消按真实操作验证。

本轮调查未取得 Obfuscated Deflate（方法 3）的真实原厂正面包，仍不支持该方法，并明确提示向提供者索取 ZIP/7Z；没有用改头普通 Deflate 或模拟包替代封板证据。ALZ 仍只读，不创建、不修复损坏或补造缺卷；默认编码不变，Windows N 暂不保证支持。

详见[实施审计](ALZ_STREAM_INTEGRITY_1.5.12.md)和[封板发布记录](ALZ_STREAM_INTEGRITY_FREEZE_1.5.12.md)。
