# Long解压 v1.3.9

本轮围绕日常压缩、解压、重复处理和大量历史记录优化。

## 新增与改善

- 文件冲突显示新旧文件信息，支持覆盖、跳过、保留两份；确认期间目标发生变化会重新询问，文件不能直接覆盖整个同名目录。ZIP 使用来源条目的原始时间，无法可靠获取的时间显示未知。
- 新增 ZIP 快速打包：抽样判断难以继续压缩的文件，直接存入归档以节省时间。默认关闭，用户主动开启；普通/AES ZIP 支持，包体积可能增加。
- 新增智能解压目录设置：默认关闭。开启后按顶层结构决定是否建立同名子目录，保留用户手动选择，并在执行前显示输出位置。
- 归档压缩、图片、视频、PDF 历史支持恢复参数、创建独立草稿及所选项批量纠正。草稿不自动执行，不修改原历史，不恢复密码或删除授权；旧记录缺少配置时明确提示。
- 历史列表改用摘要和按需详情，保留全库搜索；窗口最多加载 500 条并支持双向翻页，不删除数据库里的旧记录。
- 输出位置增加最近目录和书签，方便跨页面复用。
- 原生进度刷新采用 100 ms 预算，保留终态和实际错误；任务展开使用高度动画，小窗口自然上下排列，避免缩放变形和横向溢出。
- 新增 ZIP 并行解压设置，默认关闭。符合条件的普通 Store/Deflate ZIP 最多使用两个工作线程，并共享全局资源预算；其他结构保留顺序路径，写入失败不会偷偷重跑掩盖错误。

## 使用提示与范围

- 三项新策略均由用户主动开启，不改变旧设置的默认行为。
- 并行和快速打包并不保证所有磁盘、文件和压缩率都有收益；详细实测见 [并行基线](https://github.com/Longyuyeee/long_Decompress/blob/v1.3.9/long-compress-assistant/docs/PARALLEL_ZIP_BASELINE.md) 和 [快速打包基线](https://github.com/Longyuyeee/long_Decompress/blob/v1.3.9/long-compress-assistant/docs/FAST_PACK_BASELINE.md)。
- 图片、视频、PDF 仍统一位于左侧“特殊压缩”，压缩中心只处理归档压缩。
- Windows N 暂不保证支持。本版不新增完整多标签文件管理器或更多冷门格式。

正式安装升级、四类工作区及卸载/恢复流程 62 项检查通过。完整过程和验证边界见 [发布审计](https://github.com/Longyuyeee/long_Decompress/blob/master/long-compress-assistant/docs/RELEASE_AUDIT_1.3.9.md)。
