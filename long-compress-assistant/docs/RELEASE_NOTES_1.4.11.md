# Long解压 v1.4.11

> 发布说明草稿：当前尚未封板或发布，好压原生加密论坛分卷仍待补齐实际样本。以下为拟发布范围，最终以实施结果和封板记录为准。

这版让收到的自解压包和特殊 ZIP 分卷更容易处理，也改善输错密码、缺少分卷后的继续操作。单条点击展开、多选弹窗配置保持原来的方式。

## 自解压包直接当作压缩包打开

- ZIP、7Z、RAR 自解压 EXE 可以导入、浏览文件、填写密码、解压、检查和转换格式，无须运行收到的 EXE。
- ZIP 自解压包中的文本可以按原有方式预览；7Z/RAR 文件名加密包输入错误密码后，可以修改密码再读取内容。
- 普通程序与无法确认归档格式的 EXE 会说明原因，不建立无法处理的解压任务。

## 好压分卷按整组处理

- 识别 `.haozip01.zip` 等好压论坛 ZIP 卷名；从任意成员打开时按同组文件读取，乱序或重复导入只建立一个任务。
- 支持已核对的论坛明文 ZIP 卷组浏览、解压及转换；普通 ZIP 与同名论坛卷不会混在一起。
- 修复好压部分 ZipCrypto 标准分卷正确密码被误判的问题；内容校验仍会识别损坏文件。
- 原生加密论坛卷的最终发布口径待真实好压生成物检查完成后补充，不将普通密码标准卷改名作为兼容证据。

## 缺卷、密码错误后更方便接着处理

- 导入后才移走分卷，执行失败也会显示准确的缺卷文件名，便于找回。
- 补回分卷、修改密码后，可以在原任务展开区域创建新任务继续解压，保留独立输出目录和原失败记录。
- 错密码预览显示中文原因；普通提示和执行日志不再铺出内部分类标记或转义路径。
- 长路径与缺卷原因可以换行，小窗口通过正常滚动到达处理控件。

## 使用范围

当前 SFX 真实样本覆盖单个 EXE 的 ZIP、7Z 和 RAR5；不扩大到全部 RAR4 自解压变体、外置数据卷或任意 EXE。好压特殊卷型本版处理 ZIP，不包含 7Z 论坛卷、创建 SFX 或 EXE 模块修复。缺卷救援范围不因本版扩大。

RAR 创建、修复及恢复卷仍需要本机 WinRAR/Rar.exe；Windows N 暂不保证支持。本版不改变原软件图标、既有压缩默认值或 EXE 默认打开方式。
