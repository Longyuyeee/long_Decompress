# v1.5.23 封板记录

2026-10-20，LZMA 数字分卷与查看用户链完成，进入受保护合入与正式发布。

## 交付范围

已有 LZMA-alone 原生编码器接入事务数字切卷，前后端能力表不再误报创建依赖 CLI。任意卷经统一卷组读取进入浏览、有界文本/图片预览、完整流检查与提取；诊断直接使用可取消的原生检查，截断、解码/尾随错误按真实数据问题处理。

新增单文件 LZMA 转换目标，密码 ZIP 中一个顶层文件可转换为 LZMA 数字卷，完整卷组可转换成密码 ZIP，原包保留。缺卷补回后沿原失败弹窗创建新任务，保留旧历史。体积分析改用 LZMA-alone 编码，不再按 XZ 容器抽样。

批量弹窗增加 LZMA，保留各自分卷，关闭不适用的密码、固实、文件名加密及 RAR 恢复设置；目录/多文件组在应用前整体拒绝，避免一半修改。单条展开、多选弹窗、自然继承、左右等宽和窄窗滚动保持。LZMA-alone 无原生密码/CRC；流可解码不代替摘要一致性，数字片不是原生多卷。TAR.LZMA 与 Long AES 组合留给 v1.5.24。

- 六组独立 Python FORMAT_ALONE 原件：中文文本、空文件、PNG、随机数据、大文本及非默认 lc/pb 属性；原件 SHA256/大小在 manifest 保存。手工改大小头未通过独立解码的尝试不作为有效原件。
