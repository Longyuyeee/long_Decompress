# Long解压 v1.5.13

> 此为未发布候选说明：发布前发现误后缀路由回归，正式构建已取消，标签保留不移动。最终交付见 [v1.5.14](RELEASE_NOTES_1.5.14.md)。

本版补齐标准 TAR 的 GNU/PAX 稀疏文件只读兼容，避免文件被遗漏、只提取压紧数据或显示临时占位名称。

- 支持原 GNU 稀疏及 GNU PAX 0.0、0.1、1.0 布局。浏览、文本预览、完整/所选解压、完整性检查和转换使用一致的逻辑名称与完整内容。
- 正确区分逻辑展开大小与包内实际数据，避免合法大稀疏包被倍率规则误拒；磁盘空间和输出上限仍按完整展开大小检查，普通压缩包规则不变。
- 稀疏映射损坏、压缩尾部截断和未知稀疏版本保留具体最终原因，不转入反复试密。选中链接、管道等非普通条目会明确拒绝，不静默漏掉后报全成功；普通文件仍可单独提取。

二十组 GNU tar 1.35 原包经 Linux libarchive 独立完整回解，另用固定 2 GiB 稀疏原包验证实际暂停、恢复、取消和历史再次执行。中文长路径属于既有能力，本版作回归。

Windows 输出为填零还原内容的普通文件，不承诺保留 NTFS 稀疏分配、Linux 权限/属主/扩展属性；不新增稀疏包创建、链接创建或自有 AES 包装的特殊布局承诺。ALZ 方法 3 仍不支持，EGG 加密固实仍未验证，Windows N 暂不保证支持。

详见[实施审计](TAR_SPARSE_1.5.13.md)和[封板发布记录](TAR_SPARSE_FREEZE_1.5.13.md)。
