开发分支：`codex/archive-media-roadmap`

进入基线：`49676ad`（B-03.1 单文件图片编码与发布事务）

## 1. 结论

B-03 后端执行与发布事务已收口。单文件服务现按真实内容处理 JPEG、PNG、WebP 的同格式压缩、格式转换和等比例缩放；输出在发布前重新解码，验证真实格式、编码矩阵、应用方向后的可见尺寸、方向、静态帧数与 Alpha，并按配置逐字节复核 EXIF/ICC。Tauri 命令复用现有容量预检、统一取消注册表、受控阻塞工作线程和 B-00 原子发布事务。

前端“开始处理”仍保持禁用，这是节点边界而不是缺少后端事实：B-04 负责把命令接入统一进度、日志和历史，B-05 再完成安装版执行矩阵。B-03 不提前制造没有进度和历史来源的可用状态。

## 2. 需求对齐与纠偏

| 原始要求 | 实际实现与纠偏 | 结论 |
| --- | --- | --- |
| 魔数与解码器确认输入 | 不信任扩展名，先猜测内容格式，再由锁定解码器完整解码；GIF/动画和非公开格式失败关闭 | 完成 |
| 格式转换与缩放 | 最大宽高按“应用方向后的可见尺寸”计算等比例目标；Orientation 5–8 的 JPEG 不把编码矩阵误当可见矩阵 | 完成 |
| 元数据按配置保持或移除 | 产品既有文案只承诺 EXIF/ICC，因此用 `img-parts 0.4.0` 读取、写回并逐字节复核这两类字段，不扩大承诺到 XMP/任意 ancillary chunk | 完成并纠正范围 |
| 方向与视觉语义 | 转换/缩放时烘焙方向并归一为 Orientation=1；同格式去元数据时保留最小方向信息，避免“移除元数据”导致画面旋转 | 完成 |
| 透明与动画 | 支持 Alpha 的目标必须保持 Alpha 语义；显式转 JPEG 才允许按格式语义移除 Alpha；动画始终拒绝 | 完成 |
| 唯一暂存、重解码后发布 | 目标旁 UUID 暂存由 RAII 守卫清理，全部验证和大小策略通过后才进入共享原子发布 | 完成 |
| 取消、容量、竞态 | 命令进入共享任务取消注册表，编码放入 `spawn_blocking`，开始前复用 compression 容量预检；取消、空间不足、目标存在与竞态均不留下暂存 | 完成 |
| 默认仅在更小时替换 | 默认策略在输出不小时返回明确保留结果，不覆盖源或目标 | 完成 |
| 发布后才可回收源文件 | 当前图片配置没有“删除源文件”选项，服务和命令始终只读源文件；未来 B-04/B-05 若开放该选项，只能消费发布成功事实后调用共享回收站服务 | 安全条件完成，未虚构产品选项 |

实现同时失败关闭两个无效组合：有损 PNG 不接受；非 JPEG 输入不能声明“无损转 JPEG”。单张编码上限固定为 512 MiB，完整解码上限固定为 1 亿像素。

## 3. 依赖与安装体积

新增直接依赖 `img-parts = 0.4.0`，关闭默认功能，仅启用 `std`；它只负责 JPEG/PNG/WebP 容器中的 EXIF/ICC 复制与复核。依赖治理记录固定 crate 大小 `22,386 B`、SHA-256 `19734e3c43b2a850f5889c077056e47c874095f2d87e853c7c41214ae67375f0`、双许可证和 feature 边界。运行时图片依赖总数为四个，`gifski`、`imagequant`、FFmpeg 与 qpdf 仍未进入图片运行时。

最终 NSIS 采用同一公开版本、同一前端和同一 NSIS 3.12 工具链做前后对照：

| 产物 | 提交/范围 | 字节 | SHA-256 |
| --- | --- | ---: | --- |
| 基线安装器 | `f4ea25b`，B-02 收口、未接入图片运行时 | 7,736,450 | `3e183b9c22624f15893c93c9e787fdb9b8ea9e17c7a4935d839c2562ec283e70` |
| 当前安装器 | B-03.1 + B-03.2 工作树 | 8,613,866 | `1e81dc079bde00d659f6fc18c92cddf3c27e33a4388bb7bb6bbee8b44dbcb7d8` |

最终增量为 `877,416 B`（`11.3413%`）。B-01 的 `1,077,127 B` 继续只表示隔离候选压缩载荷，不能替代产品安装器数字。

构建宿主的 Tauri 固定 NSIS 缓存无法启动（`0xC0000135`）。审计没有改产品代码或降低门禁，而是用本机编译的参数透明转发器在相同路径调用工作盘上的 winget 已校验 NSIS 3.12，并补入 Tauri 官方 `nsis_tauri_utils 0.4.1`；基线和当前产物使用完全相同的该工具链。
