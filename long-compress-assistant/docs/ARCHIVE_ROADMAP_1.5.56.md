# v1.5.56 资料对比：所选变更生成新包（已完成功能封板）

2026-10-21，承接 v1.5.54 的精确取回与 v1.5.55 的实际内容核对。2026-10-22 开始实现。

## 用户任务

从两边选择需要的内容，组成下一份交付 ZIP，保存前看清新增、替换、移除和最终路径，原来的两份资料仍保留。

## 推进顺序

1. **带入所选变更。** 在既有资料对比的多选弹窗增加组包入口，选择基础内容与新增/替换来源，保留左右来源、版本和精确路径；目录组合也能生成新 ZIP。复用原 ZIP 编辑的修改清单、目录映射与另存引擎，不新增一套打包工作区。
2. **复核最终结构。** 同名和大小写冲突、文件/目录变化按现有编辑预览逐条说明，可改目标路径、撤销和取消。移除必须明确勾选，仅影响新包；来源变化或密码缺失时保留未提交的选择并提供纠正入口。
3. **另存与继续使用。** 复用原进度、日志、停止与结果入口，失败保留可处理的修改；新包可浏览、所选提取、加入资料库和再次对比，已有文件和原包不覆盖。

## 交付边界

- ZIP 创建/编辑的实际方法、密码和编码能力沿已有引擎声明；读入的完整 ZIP 卷组先沿现有受支持路径取材，不承诺原地回写标准卷或所有 ZIP 方法无损互改。
- 密码仅当前会话，草稿保存引用与处理配置；重启后重新提供。核对结论与待保存修改绑定具体来源版本，不能把过期结论当作可直接提交的依据。
- 保持单条展开、多选弹窗、自然继承、左右等宽与窄窗滚动；主页面不摊开大块配置。
- 定向检查两种文件夹/ZIP 来源组合、明确移除/冲突和撤销、密码/分卷取材、原件保留、实际新包独立回解、失败后继续及新增宽窄界面。只补新增/受影响项，不重复旧矩阵、真实盘满、媒体或个人安装。

本阶段收齐查看差异、核对内容、取回差异与组成新包；不新增目录镜像同步、自动删除原件或任意格式原地修改。之后 v1.5.57～58 整包图片阅读，暂定 v1.5.59 起回归格式、算法、密码、分卷与容错兼容。后续均未开始运行时开发。

## 本版实现选择（编码前记录）

- 在原多选弹窗选择“取回文件”或“生成新 ZIP”。基础可选完整左侧、完整右侧或仅所选；基础最多与补充合计 10000 项，所有冲突在原 ZIP 编辑清单中确认。
- 新组包使用持久的小型空 ZIP 作为编辑起点，草稿中每项保留来源版本与包内路径，不持久化解密文件或密码。保存时临时取材，再调用原 ZIP 编辑另存引擎；发布前再次核对引用来源。
- 复用编辑清单的最终结构、移除、撤销、移动、更名与冲突处理。密码来源在复核弹窗中按来源填写；加密取材默认要求为新包设置 AES-256 密码，用户可明确改为不加密。
- 失败保留引用和修改清单。来源变化后须明确重新读取并确认该来源；已消失的路径仍提示处理，不扩大所选范围。重启恢复原编辑草稿，密码重新填写。
