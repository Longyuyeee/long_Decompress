# v1.6.3 封板记录：ZPAQ 数据块诊断与文件影响定位

## 用户结果与当前进度

本版已封板，可进入正常合并与标签发布。完整日志式目录可读取时，诊断按实际快照只检查被引用的数据块，每块一次；以块及片段内容校验区分通过、受影响、未检查。共享失败块的所有关联文件均标为受影响，不声称每个文件都已证实损坏。只诊断，不产生部分文件结果。

现有归档诊断页提供紧凑摘要，明细进入文件/数据块双页签弹窗，支持筛选、分页、搜索与双向关联范围。诊断依据折叠，报告复制包含范围与状态。浏览器选项内可诊断当前快照，诊断页可返回浏览器选择快照；普通/密码、单包/已确认原生组沿相同入口。原生来源先确认，页面显示实际成员位置。保留原双栏、单条展开与多选弹窗。

## 实现边界

只接受可完整读取的日志式事务目录。流式或混合来源沿原完整性路径，目录不可用时不给条目级结论；中断尾部提供完整旧快照入口，不推断尚未写成的目录。已确认成员缺少、密码/加密头不匹配、设备 I/O 错误与取消不会变成可用文件清单。

块读取限制在目录记录的压缩边界内，解码后检查段摘要及目录片段摘要。单块展开超过 512 MiB、模型声明内存超过 256 MiB，或块解码内存不足时保持未检查；诊断目录最多十万文件/块、二百万片段引用和 16 MiB 文件名总量，超限不返回成功清单。不对未引用快照的块作健康承诺。空文件也按其实际引用检查。

四类受控副本未触发资源上限；前端的未检查与大列表样例为构造数据，不能当作大块真实互通证据。源状态在目录读取及诊断结束核对；报告 revision 为本次目录/状态身份，不是整个归档的内容哈希。

普通提取和密码候选原规则不变，本版不承诺从损坏包取回部分文件。后续 [v1.6.4](ARCHIVE_ROADMAP_1.6.4.md) 先按所选范围接通密码预检，再做显式选择、暂存取回与未取回说明。

## 桌面发现与修正

真实入口检查发现：诊断页立即接收浏览器的快照请求后，初始化恢复历史结果的函数在没有结果可恢复时仍先清空快照；新增来源确认的异步步骤使后续诊断读到默认最新版本。现将清空限定在确实恢复旧结果时执行，保留本次请求的版本。新增组件回归覆盖初始化、再次诊断与返回浏览器的快照/会话密码。四种已完成诊断和六张布局均不受此守卫调整影响，仅接续旧快照及中断尾部两个入口。
