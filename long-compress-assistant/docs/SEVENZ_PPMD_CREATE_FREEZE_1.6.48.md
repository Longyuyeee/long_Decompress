# v1.6.48 · 7Z PPMd 创建

## 已完成

按[本版路线](ARCHIVE_ROADMAP_1.6.48.md)，在原 7Z 方法字段增加 PPMd（PPMdH），适合尝试文本归档。沿单条行内展开、全局配置和多选弹窗使用；默认继续 LZMA2，旧配置缺字段保持原默认。说明收进问号，保留等宽布局、主题、工具和快捷键。

使用锁定 ppmd-rust 的 Ppmd7Encoder，五字节属性为阶数加小端内存字节数，强度 1～9 分别映射 (阶数, MiB)：(2,4)、(3,4)、(4,8)、(5,8)、(6,16)、(7,16)、(8,32)、(10,32)、(12,64)，旧值 0 按 1。内存上限 64 MiB 与原预览预算一致。它和 ZIP PPMd8 属于不同容器方法，不混用属性或结束方式。

普通 flush 只刷新下游，不提前结束范围编码；终止空写才消费编码器并按 7Z 已知长度 finish(false)，完成后续计数/AES 终止与 flush。范围尾部、下游结束或最终刷新失败立即返回，并保持失败状态，不能重试成成功；不依赖忽略错误的析构。支持内容/文件名密码、非固实/固实、完整数字分卷，沿原输出事务、取消、进度、日志和结果入口。没有新增依赖或格式计数。

预设、配置组、便携模板、草稿、历史再次执行和工作流接受并保留目标方法。分析使用真实 7Z PPMd 编码抽样，改方法后旧结果失效。源包读取与目标创建方法分开。
