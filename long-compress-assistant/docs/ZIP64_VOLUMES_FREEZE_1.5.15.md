# v1.5.15 ZIP64 大包封板快照

2026-10-19，本版功能可发版。基线为 v1.5.14 后的主线 05506ff；运行时修正冻结 e861e32，后续仅整理证据、README 和发布文档。此文件固定合入前结果，候选 CI、受保护合入、标签与正式资产的后续身份记在[本版 PR 列表](https://github.com/Longyuyeee/long_Decompress/pulls?q=is%3Apr+head%3Acodex%2Fv1.5.15-zip64-volumes)和[正式 Release](https://github.com/Longyuyeee/long_Decompress/releases/tag/v1.5.15)，不为回填同一收据再次构建无运行时变化的文档版本。

## 用户得到的修复

- 独立选中的空文件夹在压缩及转换后保留；原有非空目录布局和重名规则保持。
- ZIP64 终目录、必要扩展及卷内偏移确定损坏时明确说明原因；真实 I/O、超出能力和取消不混成损坏。
- 丢目录救援读取发现的密码问题不再盖过已确认的 ZIP64 结构损坏。仍需有效密码才能尝试加密条目救援，原包保留，不把可找回局部条目说成原目录完整。

单条行内展开、多选弹窗、自然配置继承、左右等宽与小窗口滚动沿用，无 UI 重构或新增使用门槛。智能目录、ZIP 并行等默认开关不改。

## 本轮结果与程序身份

[检查收据](evidence/zip64-1.5.15/checks.json)、[十组原生结果](evidence/zip64-1.5.15/native-results.json)、[十组独立回解](evidence/zip64-1.5.15/independent-results.json)、[十五条程序记录及页面](evidence/zip64-1.5.15/desktop-results.json)。

实际逐块写入 4,295,098,367 字节，并含其后中文说明、空文件和空目录。普通、AES-256、ZipCrypto 分别验证单包、数字卷和标准卷；额外使用真实非 Seek 标准输出生成的 ZIP64 数据描述符，令描述符跨实际卷边界。十组均完整核对大小/SHA-256，再由独立 7-Zip 26.04 流式回解全部内容。无密码 Store 大包的末条本地头虚拟偏移超过 32 位边界。没有改头小文件、稀疏预分配或只验证目录代替完整内容。

十二项不同 Rust 检查由多个定向执行汇总（五项新增、七项既有），不是一次全项目测试。前端类型检查与 E2E 前端构建通过一次；Shell 版本 DLL 重建、八处版本身份检查通过。ZIP/7Z/TAR 受影响输入收集器、既有密码/跨卷及丢目录救援回归通过，未影响部分沿用历史结果。

四个外部原包实际浏览、完整性和末尾所选，七组产品卷任意成员浏览及所选，共十一条健康入口结果先在早期优化桌面程序完成。诊断修正后仅重做受影响的损坏入口及页面，未重复这些健康流程。最终四条为损坏 IPC、真实损坏诊断页、真实浏览/末尾文本预览、真实 AES 大包改密并转标准卷。转换由正常按钮启动，等待真实历史完成；外部 7-Zip 对新密码结果全量回解核对，并确认空目录保留，未注入完成状态。

## 复现与边界

输入生成、原工具调用、测试专用依赖优化和阶段失败记录见[实施记录](ZIP64_VOLUMES_1.5.15.md)及 scripts/prepare-zip64-1515.mjs、zip64-1515-tools.mjs、zip64-1515-gate.mjs、zip64-1515-test-profile.toml。多 GiB 数据保存在忽略的 test-results/zip64-1515，Git 仅保留生成器、清单、日志和截图。测试专用优化不修改生产 profile，不提供吞吐提升承诺。

ZIP64 是既有能力，不宣传新增格式或全部工具/布局互通；缺卷不能凭目录猜全，救援结果仍只允许完整读出并校验的文件。ALZ 方法 3 未实现、EGG 加密固实未验证和 Windows N 边界保持。

下一版仍为既定第十目标 v1.5.16 过程 I/O 故障接续，未开工。先审计各引擎读写错误如何流入任务、诊断和历史，用隔离测试目录/独立测试盘复现盘满、源卷撤回、卷组变化及目标占用；优先呈现真正原因及已发布/未发布状态，恢复条件后建立新任务，旧失败记录保留。原十目标按调整范围已收口九项，不把 v1.5.13 撤回计作交付，也不把尚未支持的 ALZ/EGG 组合抹去。无需另起重复路线。
