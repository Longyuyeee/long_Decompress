# v1.6.23 · 7Z 大日志直接读开头

查看未加密、非固实的 LZMA/LZMA2 7Z 大日志时，现在可在原双栏直接阅读前 1 MiB，无需先完整提取。

- 沿原文本预览入口显示开头，保留滚动、已读/声明大小与只读状态；明确标注“部分内容 · 未校验整文件”，不会把未读取的尾部当作完整检查成功。
- 处理 UTF-8、带 BOM 的 UTF-8/UTF-16 与原常用编码读取边界，避免因字符被截断而显示乱码；二进制内容仍不作为文本显示。
- 增加紧凑的“提取后打开”，沿原完整提取与默认应用打开流程查看全文，不改变原包。
- 完整数字分卷可从有效成员进入，关闭取消、来源变化、缺卷与迟到结果丢弃沿原流程；不先读取无关大文件。实际输入合计 ≤64 MiB、字典 ≤64 MiB、每次请求候选整体限时 30 秒，声明总大小超过 64 MiB 的独立流也可只读开头。
- 小文本和图片保留完整大小/CRC/编码结束检查。密码大文本、固实大文本和未支持的方法组合给提取指引，继续分阶段扩展。
- 修复 LZMA2 完整读取被文件大小包装提前截断、未检查真实结束标记的问题：即使正文和 CRC 都能读出，尾部结束标记损坏也不再误报完整检查成功。前缀仍明确不校验未读尾部。

保留单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键，格式数量不变。下一阶段已规划 v1.6.24 非固实密码大文本开头，尚未开发。
