# v1.7.40 封板 · 包内复制与右键菜单

2026-11-05：功能检查完成，版本统一提升为 1.7.40；正式合并、签名安装器和四份公开资产由本版 CI / Release 接续，不把候选检查当作已发布安装器。

## 交付范围

[#364](https://github.com/Longyuyeee/long_Decompress/issues/364)：包内所选普通文件、文件夹和空目录完整提取后写入 Windows `CF_HDROP`（Unicode、多路径、复制而非移动）。复制准备显示紧凑进度，可取消；失败不发布半成品。独立本地缓存成功后保留，关闭应用仍可粘贴；后续复制时清理七天过期、未被剪贴板引用的缓存。链接、未知大小及同名根冲突提示先提取处理，密码和完整分卷沿原流程。

普通文件/目录提供 ZIP、7Z、更多配置、加密、分卷；压缩包同时提供浏览/解压与普通打包入口，维护收进子菜单。JPG/JPEG/PNG/WebP 增加图片压缩、WebP 和尺寸预设，带入现有界面确认。快速 ZIP/7Z 按本次选择建立独立任务，不启动其他等待任务，不继承删除原件、密码或分卷开关；完成任务保留。经典分卷后缀不再被仅修复菜单覆盖，卸载同步清理新增注册。

保持原单条展开、多选弹窗和等宽双栏。多选右键标题与复制/提取范围统一；输入框和已选文字保留文字复制。

## 必要检查

- 原生库六项：ZIP 普通/密码/数字卷、7Z 普通/密码、TAR、目录和空目录；坏密码、损坏、缺卷、取消、来源变化、路径/大小/选择矛盾及缓存过期清理。
- 一个真实 Windows 文件剪贴板检查；生产进程退出后由另一个 Windows Forms 消费程序读取 `CF_HDROP`，以该列表复制到独立目录，核对嵌套内容、空目录、未选内容排除与 `Preferred DropEffect=copy`。结束恢复原剪贴板；没有直接控制用户桌面。
- 六项 Shell/COM 测试：实际 `IShellItemArray` 的普通/图片/归档/恢复卷/混合选择、目录伪装扩展、工厂与菜单枚举；真实独立进程接收命令参数，核对中文、空格和多选。
- 经典注册真实临时 HKCU 读回及旧注册识别；一项相关旧注册组；一项启动参数多路径检查。
- 前端核心 63 项通过；相关视图六项最终通过，其中选中文字检查补上真实 DOM 附着后只复查该项。
- 1440×900、1024×720、920×620 三个无头浏览器场景最终通过，六张实看截图确认等宽、菜单边界、紧凑进度、取消/重试与多选。界面 IPC 使用演示数据，不能替代上述原生检查。

宽筛选的旧预览断言和缺失媒体样本在原始 HEAD 同样失败，未记为全量通过；工具中心快捷键旧断言已同步现状。首次冷导航两次超过 30 秒，明确给冷启动 60 秒后最终三场景通过。Playwright 默认清理误删了忽略的历史测试输出，后改为独立输出目录；只补存当前必要记录，已提交证据与用户设计/审计文件保持。
