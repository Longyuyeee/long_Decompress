# Long解压 v1.5.16

本版改善处理中读写失败后的提示与接续，让用户知道要释放空间、关闭占用程序，还是补回原卷。

- **失败原因更准确**：保留底层读写详情，盘满、文件占用、访问受阻不再误导为密码错误。任务、诊断、历史和转换沿用同一原因。
- **处理中卷组变化能及时说明**：解压时后续分卷被撤回或替换，显示来源缺失或变化及实际阶段；不发布本次不完整结果。恢复原卷后，可以从既有纠正入口建立新任务，原失败记录保留。
- **占用失败后更好接续**：目标提交因读写问题失败后清理未发布暂存，避免遗留无法继续提交的旧内容；关闭占用或调整输出后建立新任务。回滚不完整时仍保留明确的恢复目录与原原因。
- **熟悉的界面保持**：单条行内展开、多选弹窗、自然配置继承、左右等宽与窄窗口滚动保持，失败提示给出可执行的下一步。

本轮定向检查、实际 Windows 文件占用、密码 ZIP 处理中撤卷/换卷和恢复后完整内容核对完成。真实盘满的隔离 VHD 补充测试已编写但未执行，不把注入异常当作实际磁盘写满。来源变化采用卷组元数据快照，不承诺识别长度和时间等元数据完全相同的替换。

本版不新增格式。ALZ 方法 3、EGG 加密固实和 Windows N 的现有边界保持。下一阶段按多段压缩流、自有 AES 容器分卷、逐文件校验原因的顺序推进，已写入路线，尚未实施。
