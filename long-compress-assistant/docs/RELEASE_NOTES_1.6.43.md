# v1.6.43 · 固实 Deflate64 大日志先看开头

普通和密码固实 Deflate64 7Z 中的大日志，现在也可以在原双栏浏览器先看前 1 MiB，再决定是否提取全文。

- 接通内容加密、文件名加密、完整数字分卷和从非首卷进入，继续使用手动密码或密码保险箱。
- 流式跳过前置内容，只保留所选开头；前置内容与开头合计最多 64 MiB，超过范围仍可提取后打开。
- 沿用文本编码、字符边界和滚动，明确“部分内容 · 未校验整文件”，保留提取全文入口；达到上限后停止推进后置内容。
- 完整小文本、图片和非固实大文本继续使用原读取路径，取消、来源变化和缺卷处理保持。

部分预览不代表完整文件、共享块或未读尾部已校验。单条展开、多选弹窗、等宽双栏、主题/工具/快捷键保持，范围说明放原问号，格式数与依赖不变。下一阶段规划 7Z Bzip2 完整图文预览。
