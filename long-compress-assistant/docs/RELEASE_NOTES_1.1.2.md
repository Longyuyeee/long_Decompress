# Long解压 v1.1.2

本版本完成产品增强路线第一轮收口，重点提升归档可检查性、批量自动化与执行前安全判断。

## 新增与改进

- 归档中心支持目录浏览、压缩包诊断、恢复可能性说明和非破坏式 ZIP 修复。
- ZIP 与 TAR 内的常见图片可直接预览，并限制解压字节、像素、尺寸与 TAR 扫描预算。
- 压缩配置可以导出为不含固定密码和危险选项的任务模板，也可导入后生成待确认草稿。
- 支持经用户明确授权的监控文件夹；新文件稳定后生成草稿，重启和托盘隐藏期间可继续发现事件。
- 压缩与解压任务新增资源预检，可靠判断空间不足时会在执行前阻止任务。
- 压缩结果在发布前校验；启用删除源文件时，只有校验成功才允许删除。
- 安全解压继续传播 Windows 互联网来源标记，保持事务提交与失败回滚语义。
- 增加固定机器 I/O 基线及 SSD 同卷/跨物理盘矩阵，当前仅用于观测，不自动调整并发。

## 验收

- Rust：227 项通过，1 项固定机器性能基准按设计忽略。
- 前端：191 项单元测试通过；类型检查与生产构建通过。
- 浏览器：32 项通过，13 项按当前环境能力跳过。
- Windows Release Tauri：真实 ZIP 往返、诊断、修复、ZIP/TAR 图片预览、资源预检、任务模板、监控文件夹、托盘与重启恢复全部通过。

## 已知限制

公开安装包不使用 Windows 商业代码签名证书，因此不会分发 Windows 11 新式第一层右键菜单身份包。资源管理器经典右键菜单仍可使用。
