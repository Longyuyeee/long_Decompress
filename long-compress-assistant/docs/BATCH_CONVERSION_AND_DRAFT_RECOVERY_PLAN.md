# v1.4.2 批量转换与待处理任务恢复

2026-10-12 用户批准，按批量转换、草稿恢复的顺序实施。两项已完成实现；版本仍为 1.4.1，等待后续封板发布。

## 用户操作

- 从压缩中心“转换压缩包”一次添加多个文件，或通过现有 Windows 右键菜单带入多选来源。每条点击后在本列表内展开，多个条目可同时展开，不切换或覆盖其他条目的配置。
- 选择条目后点击“修改所选配置”，在弹窗内修改格式、等级、目录、原包密码、新包密码、分卷和文件名加密。默认保持各自设置；取消不应用，重新打开重新选择要修改的字段。统一更换目录保留各条自定义名称。
- 默认配置影响未单独编辑的条目；修改某条后自然保留自己的配置。修改密码/分卷入口默认保持来源的 ZIP/7Z 格式，用户修改默认格式或单条格式后按所设格式执行。
- 自动生成“原名_转换”或“原名_调整”的新包名称，并实时显示最终路径；可单独更改。所选任务保存位置重复时直接在对应条目提示。原包保留；各任务调用已有转换引擎，输入密码与新包密码分别传递。
- 批次逐个执行，失败不阻断其他项目。停止时取消当前项、保留未开始项；运行中收到的新右键来源只进入待处理列表，不加入已经启动的批次。完成后复用单条产物和批量目录/复制入口，失败或取消可展开调整后再次转换。
- 未开始的归档压缩文件/组、解压任务和转换配置自动保存在本地。下次打开只出现紧凑恢复栏，用户决定恢复或丢弃；新添加的工作不会被旧草稿覆盖。恢复不会自动执行，已开始/完成项目继续使用历史记录。
- 草稿不保存密码。使用过密码的条目恢复后显示重新填写/确认入口；缺失来源显示“需要调整”并可重新选择。恢复时保留全局默认与单条配置，已独立编辑的设置不会被全局配置覆盖。

## 实现与范围

- `archiveConversion` 从单表单扩展为草稿列表，执行批次开始时固定范围和配置，复用既有 IPC、任务历史、取消与产物模型。
- `pendingDrafts` 使用版本化本地快照，只记录尚未开始的工作区配置；不保存运行进度、日志或凭据。保留尚未处理的启动恢复内容，同时保存本次新工作；标题栏关闭前立即保存。
- 解压工作区默认设置改为随应用存活，以便跨页面和恢复时保持配置。全局进度入口仅有待处理任务时显示等待状态。
- 嵌套批量弹窗的 Escape/Tab 由最上层弹窗处理，关闭批量配置后仍保留转换列表。
- 本轮不增加格式、不修改转换引擎、不扩展媒体草稿或运行中任务的自动续跑，不替换本机安装器/右键注册。
