# v1.7.13 · 旧 GNU 稀疏文件部分取回

TAR.LZO 后段损坏或缺卷时，落在已校验连续前缀内的完整旧 GNU 稀疏文件也可取回，不再直接在 `S` 条目处停止。

- 支持头内与扩展块映射、多段数据、全零文件、大空洞及 GNU 长名称；映射、实际数据和填充完整后，才把文件列为可取回。
- 区分完整大小与包内数据位置，核对包含空洞的逻辑 SHA；Windows 使用稀疏写入，保留大空洞。保存位置不支持时提示换目录，失败或取消不发布半文件。
- 原列表和折叠结果显示完整大小、包内数据，所选文件、目录时间、后续普通文件和部分历史保持衔接；保留单条展开、多选弹窗和等宽双栏。

仅扩展旧 GNU `S` 布局；叠加 PAX size、未知/不完整布局仍明确停止，不扫描缺口之后。PAX sparse、链接救援及全部元数据恢复未扩展。

见 [本版范围](ARCHIVE_ROADMAP_1.7.13.md)、[实现与检查](TAR_GNU_SPARSE_FREEZE_1.7.13.md)。下一阶段 [v1.7.14 PAX sparse 1.0](ARCHIVE_ROADMAP_1.7.14.md)仅规划。
