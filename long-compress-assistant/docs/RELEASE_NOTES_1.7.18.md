# v1.7.18 · GNU 长链接目标内容取回

TAR.LZO 后段损坏或缺卷时，GNU 格式中使用长目标名称的硬链接也可以取回。原目标无需一并选中，结果保存为独立文件。

- 接通 GNU `K` 长链接目标与 `L` 自身长名称，两种记录可同时出现；普通、空文件及稀疏目标沿用已确认内容、修改时间和空洞。
- 链接元数据完整后只应用于对应条目一次。重复、孤立、冲突或不完整记录停止在已确认前缀，补卷后可重新检查。
- 继续使用原列表的简短来源提示、折叠结果和部分历史，保留单条展开、多选弹窗及等宽双栏。

本版扩展部分取回。未确认或有歧义的目标、链接链条、符号链接及带正文的硬链接仍停止；正常完整解压的链接规则未扩展。

见 [本版范围](ARCHIVE_ROADMAP_1.7.18.md)、[实现与检查](TAR_GNU_LONGLINK_FREEZE_1.7.18.md)。下一阶段 [v1.7.19 完整包硬链接目录与预览](ARCHIVE_ROADMAP_1.7.19.md)仅规划。
