# v1.5.44 · ZIP 内容编辑第一阶段

## 直接补齐 ZIP 内容，另存一份新包

- 在原压缩包浏览器点击「编辑内容」，定位包内目录后添加文件或文件夹；编辑状态下也可以拖入。
- 右键文件可选择「替换此文件并另存」，也可勾选一个文件后使用替换按钮。
- 同名文件由你选择替换、跳过或保留两份；跳过后仍可改主意。文件与目录重名时不会直接互相覆盖，目录保留两份会连同子项使用新位置。
- 修改先进入复核清单，可逐项撤销或放弃全部修改；确认「另存新 ZIP」才写入。切换页面后，当前会话的待保存内容仍保留。

## 原包保留，新包可以继续使用

- 未修改的条目沿原编码复制，保留名称、路径、内容、空目录和条目时间；新增/替换可选 Deflate 或仅存储，默认 Deflate 6。
- 沿原任务面板显示进度、日志与停止；保存失败或停止后保留修改，可调整位置、重新确认来源后再另存。已有目标文件不覆盖，旧失败记录保留。
- 成功后展示紧凑结果，可定位、复制路径、生成校验清单，或直接浏览新包、预览和提取内容。编辑任务在历史与底部任务面板中单独标识，返回时进入原包编辑，不误入普通压缩。

## 第一阶段的支持范围

支持独立、未加密、原条目采用 Store/Deflate 的普通 ZIP。密码包、分卷、自解压、嵌套临时来源、特殊路径或链接以及其他压缩方法继续使用现有浏览/提取功能，本阶段不会静默去密码、改方法或丢弃内容。当前会话可以继续编辑；跨次启动的编辑草稿按后续阶段接入。

原有单条展开、多选弹窗、自然继承和压缩/解压等宽布局保持；编辑复核在宽窗分列，窄窗顺序排列并滚动，长名称/路径可换行。

下一版按既定路线推进 **v1.5.45 删除、重命名与批量目录整理**；密码包和编辑草稿安排在 v1.5.46。五模块分阶段完成后，再回归更多算法、格式与容错兼容主线。
