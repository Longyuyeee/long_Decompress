# v1.5.43 · 一批任务，找结果更方便

## 更容易找到已完成和待处理任务

- 压缩中心、解压中心与转换窗口增加「全部、待处理、进行中、成功结果、失败/取消」分类与数量，暂停和正在取消也归入进行中。
- 成功结果沿用原条目的结果卡、打开位置、复制路径与校验入口；解压成功分类也可批量打开目录、复制结果路径。
- 切换分类会取消原多选，查看其他分类时，新添加任务和重试草稿回到待处理分类；开始后回到全部，进度和结果持续可见。从底部任务栏返回解压纠正时，也会显示原任务。

## 批量修改前，看清改了哪些任务、哪些设置

- 所选任务与完整来源/位置清单在原批量配置弹窗查看，同名文件也能分辨。
- 确认前显示本次指定的格式、强度、目录、分卷、密码处理和编码等摘要；未指定项目保留各自设置。密码内容不出现在摘要中。
- 单条仍点击行内展开，多选仍在弹窗修改，不增加全局/单独配置的必选步骤。

## 结果路径与小窗口显示

- 批量打开目录有失败时，列出具体无法访问的位置，并支持只重试这些目录，避免重复打开已经成功的窗口。
- 分类按钮、修改摘要和长路径随可用空间折行，所选清单可滚动；转换长名称最多显示两行，完整路径仍可在原详情查看。
- 保留左右等宽的配置/执行区域和日志、结果滚动。解压的成功、进行中和失败分类收起本批重复汇总和默认配置，留出更多任务空间；默认配置仍在全部/待处理，添加文件入口保留。

本版收尾常用批处理与结果体验，不增加格式或算法。接下来按已确定路线进入 v1.5.44 ZIP 添加/替换与另存，再分阶段推进编辑工作区、资源库与跨包搜索、自动化、文件夹/归档对比、整包图片阅读；模块阶段完成后回归更多算法、格式和容错兼容主线。
