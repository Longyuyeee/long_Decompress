# v1.6.42 · Deflate64 大日志先看开头

普通和密码非固实 Deflate64 7Z 的大文本，现在可以在原双栏浏览器里先看前 1 MiB，再决定是否提取全文。

- 接通内容加密、文件名加密、完整数字分卷和从非首卷进入，继续使用手动密码或密码保险箱。
- 沿用只读文本窗口、常见编码、字符边界与滚动；明确显示“部分内容 · 未校验整文件”，保留“提取后打开”入口。
- 读取到开头上限即停止，不按大文件大小分配全文；已观察到的损坏、提前结束或声明冲突仍提示处理。
- 完整小文本、图片和固实完整图文保持原完整读取。取消、来源变化和缺卷处理继续生效，明确输入的错误密码不回退。

部分预览不代表整文件或未读尾部完整。固实大文本仍可先提取后打开，下一版单独接通；范围说明放原问号。单条展开、多选弹窗、等宽双栏、主题/工具/快捷键保持，格式数与依赖不变。
