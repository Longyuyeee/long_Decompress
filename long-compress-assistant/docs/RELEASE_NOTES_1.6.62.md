# v1.6.62 · 直接创建 LZOP 单文件

在原压缩中心选择 **LZOP**，即可将一个普通文件生成标准 `.lzo`。单条点击展开后配置，多选文件仍在原弹窗里批量修改，每个文件分别生成自己的结果；全局默认保留，修改某条自然成为该条配置。分析使用实际 LZOP 编码采样，进度、取消、完整校验、结果位置及历史接入原流程。

已有压缩包如果只包含一个顶层普通文件，可以转成 LZOP，包括先用原包密码读取再转换。多文件或文件夹来源会明确提示选择 ZIP、7Z 或 TAR 组合，原包保留，不会悄悄遗漏内容。创建结果可沿原双栏浏览、文本/图片预览、取回或继续转换；宽窄窗口布局、主题和快捷键保持。

LZOP 使用固定 LZO1X 编码模式，界面收起无效的强度、密码选项；本版不创建分卷。标准头和数据块带 CRC32，压缩无收益的块原样存放；新输出由官方 lzop 独立完整回解并核对 SHA256。源名称在格式长度允许时保留；超长 UTF-8 名称超过头部限制时沿用输出文件名，建议保留原扩展名。旧 ANSI 工具的中文文件名还原不作为兼容承诺。
