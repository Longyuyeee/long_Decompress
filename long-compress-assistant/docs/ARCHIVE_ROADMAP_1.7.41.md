# v1.7.41 · Windows 右键菜单维护版

状态：候选，尚未正式发布。优先修复用户确认的经典“显示更多选项 → Long解压”功能缺失；原 XZ 多流/填充计划顺延至 [v1.7.42](ARCHIVE_ROADMAP_1.7.42.md)。

1. 用真实 Windows Shell 同时构建通用与类型关联，复现同名子菜单重复。改用一个分类提供器，按所选普通文件、文件夹、归档、图片和校验清单生成适用操作；保留中文路径、多选和已有任务派发。
2. 压缩包保留四个常用浏览/解压入口，将五项压缩收进“压缩打包”，四项维护收进“更多操作”；图片优先三个图片操作，普通打包保留。校验按类型显示。
3. 注册与读取串行化，完整时跳过重建，修复目标版本不一致和部分注册残留；设置显示实际入口并提供修复按钮，失败不误报成功。
4. 补齐 Windows 11 完整菜单根的包声明和校验命令。原生入口需有效应用身份；公开构建的完整经典菜单继续可用。使用版本独立 DLL，避免旧进程复用上版扩展。
5. 合入 #366 减少动画窗口偏移修复。保持单条展开、多选弹窗和等宽双栏，只检查新增与受影响流程，不重跑已通过格式矩阵。

功能范围、实际 Shell 菜单树、逐项派发和限制见[菜单核对](EXPLORER_MENU_AUDIT_1.7.41.md)，候选说明见 [Release 文档](RELEASE_NOTES_1.7.41.md)。
