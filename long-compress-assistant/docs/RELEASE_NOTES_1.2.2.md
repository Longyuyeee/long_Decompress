# Long解压 v1.2.2

v1.2.2 收口特殊压缩布局与双栏文件浏览器的 Windows 集成体验。

## 特殊压缩

- 图片与视频的批量设置改为 Modal，打开设置不会挤压或拉长主界面；空任务页面保持紧凑。
- 删除由当前 Tab 已经表达的重复工作区标题和格式说明，图片、视频、PDF 页面使用一致的信息层级。
- Tab、工作卡片与操作按钮的反馈和入场动效对齐解压中心与压缩中心，并尊重系统减少动态效果设置。

## 双栏文件浏览器

- 文件夹、普通文件和压缩包的右键菜单统一提供“在 Windows 文件管理器中打开”。文件夹打开准确目录，文件和压缩包在准确目录中被选中。
- Explorer 参数保留 Windows 扩展路径的原始内容，不再因预处理改变合法路径。
- 系统保护目录、junction 等特殊项目无法读取属性时只显示友好提示，不暴露底层错误；随后查看普通项目会清除旧提示并正常显示属性。

## 验证原则

- Windows Tauri/WebView2 门禁从真实双栏右键菜单触发 Explorer，不通过测试桥绕过前端。
- 使用中文、空格、普通文件与真实 junction 夹具核对精确目录、精确文件选择和特殊属性错误转译。
- 设置 Modal 在三档 Chromium 视口及真实 WebView2 中核对打开前后几何与页面滚动高度，避免以静态单元测试代替实际界面。
