# v1.6.4 ZPAQ 已校验文件的部分取回（已封板）

接续 v1.6.3 的受损块与关联文件诊断。先让用户明确选择已经通过内容检查的文件，再接通原队列，最后形成有范围的独立结果。

## 顺序与用户结果

1. 固定来源与实际快照：以诊断范围为起点，重新读取所选目录及来源状态，变化后要求重新诊断。诊断通过不是永久可用凭证，实际提取仍完整校验；受影响与未检查条目不默认混入。
2. 先打通密码预检：当前通用密码候选检查会验证整个当前视图，其他损坏块可能阻断已通过文件。部分取回必须验证所选版本和所选范围，区分内容损坏与密码不匹配，不能为通过预检而跳过文件校验。
3. 在现有文件检查详情提供选择入口；二级弹窗确认快照、文件数量、输出位置与不取回范围，加入原解压队列。保留单条展开、多选弹窗与左右等宽，不在主页面增加大块常驻配置。
4. 用现有私有暂存及发布路径另存完整文件，原件保留。密码只在会话使用；来源、版本、所选路径与部分取回意图贯通草稿、补密码、失败新任务和历史，恢复后不自动开始。
5. 独立结果说明列出实际取回文件，以及受影响、未检查、用户未选的文件及原因。不得把半文件当作成功，也不能把部分结果称为整包完成；原有普通解压保持原规则。
6. 只接续四类已冻结受控副本、所选文件哈希、来源变化和必要宽窄显示。v1.6.3 已通过的诊断与旧格式矩阵不重复执行。
