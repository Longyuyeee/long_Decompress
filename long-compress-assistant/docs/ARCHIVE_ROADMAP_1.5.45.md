# v1.5.45：删除、重命名与批量目录整理

2026-10-21，接续已合入发布的 v1.5.44，沿已批准五模块路线推进 ZIP 编辑工作区第二阶段。

## 用户任务与交互

在原浏览器进入 ZIP 编辑，从整理按钮或右键进入整理弹窗。按目录查看本次编辑后的内容，多选文件/目录，删除、改名或使用前后缀/文本替换及目标目录进行批量整理；先显示原路径、新路径、影响子项和冲突，确认后进入同一待保存清单。添加、替换、删除和改名可以组合使用，逐项撤销或整体放弃，统一另存新 ZIP。

原浏览器继续浏览原包，整理弹窗明确显示待保存的目录结构；未另存前不把新路径当作原包真实条目预览或提取。保存后直接浏览新包，沿原结果/历史继续使用。宽窗等宽分列，窄窗顺排滚动；长路径可换行，整理和修改清单均可搜索，批量规则放弹窗，不摊在主页面。

## 实施范围

- 沿 v1.5.44 的独立未加密 Store/Deflate ZIP 范围，不扩大密码、卷型或方法。
- 编辑状态投影保留条目来源，结构操作按顺序应用，目录连同子项；撤销后重新计算，依赖已撤销来源的操作就近提示并阻止保存。
- 同名、大小写、文件/目录重名、无效路径与移入自身子目录在加入清单前显示；批量改名整体计算，支持大小写改名与互换，禁止隐式覆盖。
- 未改内容仍按原编码复制，重命名沿原内容/时间/备注，原包和已有输出保留，失败/停止保留会话内清单。跨重启编辑草稿仍在 v1.5.46。

## 收尾与发布

检查本版组合编辑、目录子项、冲突/撤销/失败接续、空包、方法/内容保留、新包使用及宽窄显示；不重复无关格式/密码矩阵、盘满或媒体安装检查。通过后同步 README、Release、支持范围、版本身份及交接，正常候选构建、合入并发布。下一版 v1.5.46 接密码 ZIP、跨次编辑草稿及失败继续，后续模块和主线回归顺序不变。
