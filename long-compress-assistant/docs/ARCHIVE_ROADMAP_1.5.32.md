# 下一版：v1.5.32 WIM LZX 压缩创建

2026-10-20，接续 v1.5.31。已开始开发；按下列范围推进到可发版，再更新封板记录。

## 用户要解决的问题

XPRESS 补上快速压缩后，希望更小体积的用户仍只有一种压缩算法。下一版增加非固实 LZX，让用户在仅存储、速度优先的 XPRESS 和体积优先的 LZX 之间选择；不把无效强度滑块重新打开。

## 推进顺序

1. 复用已固定的独立编码器，先用可压缩内容与混合熵数据确认实际 LZX 资源和独立完整回解。核对固定块大小、资源占用、取消/暂停、失败及源数据统计；不更换后缀或以 XPRESS 结果冒充 LZX。
2. 在既有 WIM 方法选择中新增 LZX；单条展开、多选弹窗、自然继承、配置组/模板、预设、草稿及历史重做保留方法，旧任务继续存储、已选 XPRESS 不自动改变。
3. 打通文件/目录创建、密码包转 LZX WIM、数字切卷、任意成员浏览/有界预览/检查、所选与整包提取、LZX WIM 转密码 ZIP、补卷新任务及统一结果。只补本版受影响链，已有旧格式/密码矩阵和真实盘满不重跑。
4. 检查常用/窄窗显示与完成统计，保持50/50和滚动，更新 README、中文 Release、范围与交接后收尾。

不新增 WIM 密码、LZMS/固实编码、原生SWM创建或系统部署，不承诺 Windows 全部权限/部署元数据。ZPAQ 增量/原生追加多部分/损坏事务抢救，以及ALZ方法3/EGG加密固实继续分别研究，有独立正面依据再排版。本轮发布等待期间不启动下一版运行时开发。
