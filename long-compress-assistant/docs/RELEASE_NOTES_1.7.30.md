# v1.7.30 · TAR.LZO 前向链接内层包浏览

TAR.LZO 中“链接在前、内层包内容在后”的压缩包副本，现在可以直接进入浏览，继续在原来的双栏中操作。

- 支持本版确认的普通头、GNU 长名称、局部 PAX，以及完整数字分卷；原内容目标无需同时选中，副本按真实内容确认格式。
- 内层 ZIP 与文件名加密 7Z 沿原密码提示、文本/图片预览及所选文件取回流程；内层密码独立填写，可继续进入第三层。
- 来源变化、取消、坏尾或缺卷有原位提示；失败和会话结束清理私有缓存，原包保留。
- 保持现有导航、返回、选择、等宽双栏及三层/缓存大小上限，没有新增页面或常驻配置区域。

本版不增加格式数量；任意链接链条、循环/符号链接和缺口后扫描继续分期。见[本版范围](ARCHIVE_ROADMAP_1.7.30.md)、[实现与检查](TAR_FORWARD_NESTED_FREEZE_1.7.30.md)。下一阶段 [v1.7.31 ZIP / ZIPX UTC 修改时间读取与恢复](ARCHIVE_ROADMAP_1.7.31.md)仅规划。
