# v1.5.25 结果生成校验清单

2026-10-20，从正式 v1.5.24 接续。功能封板，进入发布；发布状态以本版 PR/Release 为准。见[封板与证据](RESULT_CHECKSUMS_FREEZE_1.5.25.md)。

## 用户目标与实现顺序

1. 完成结果和历史记录可主动选择“生成校验清单”，带入全部实际文件和整组分卷，进入现有校验页面。用户点击开始才读取文件，不因为打开结果就重算。
2. 复用现有计算进度、停止、继续未完成项。列表显示来源路径，区分不同子目录的同名文件；已完成摘要可直接导出。
3. 清单按保存位置生成相对路径，保留目录层级。基准目录外/跨盘来源、无法表达的文件名和未完成摘要给出明确原因，导出失败不截断原清单。
4. 导出后可主动进入现有核对界面，核对刚导出的清单。计算和核对均沿用原流式算法。

保留单条展开、多选弹窗、自然继承、左右等宽和窄窗滚动。本版不增加格式，不自动递归解压结果目录，不重新执行旧格式矩阵和已通过的真实盘满检查。
