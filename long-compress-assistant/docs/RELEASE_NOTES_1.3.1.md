# Long解压 v1.3.1

v1.3.1 是 RAR 密码判定与源文件稳定性的补丁版本。

## RAR 密码判定

- 自动密码候选现在只允许由真实加密条目证明；归档前部存在未加密文件时，不会再把任意候选误报为匹配。
- 密码已由加密头或加密内容证明后，后续 `BadData`、`BadPassword` 等结果会归类为归档损坏、不完整或条目使用不同密码，不再误导用户重复输入同一密码。
- 手动密码在提示验证成功前会测试真实内容；密码保险箱使用次数只在完整载荷解压成功后增加。

## 写入中归档

- 解压开始前拒绝 0 字节归档。
- 密码检测、预检和解压阶段持续比对源文件大小及修改时间；下载或复制仍在继续时会清理暂存并提示等待完成，避免前部校验通过、后部读取失败。

## 验证

- Rust 主库 389 项通过，RAR 错误分类聚焦回归 3/3 通过。
- 固定真实加密 RAR 的错误密码拒绝、正确密码验证及完整解压通过；自动密码来源矩阵 6/6 通过。
- 本机历史共识别 29 条失败记录、18 个去重文件；14 个仍存在的源文件完成无落盘复核。13 个加密文件与当前候选不匹配，修复版均未误报“找到密码”；1 个未加密文件的 168 个条目均可完整读取，其历史失败属于后续输出提交问题。
- 严格 Clippy 通过；详细证据见 [RAR 密码修复审计](RAR_PASSWORD_POST_VALIDATION_FIX_AUDIT_2026-09-05.md)。

## 已知边界

- 历史中已不存在的源文件无法重新验证；过去已经删除的保险箱候选也无法还原。
- Windows N 暂不保证支持；Windows 11 第一层菜单仍受代码签名身份限制。
