# v1.7.7 · 默认打开方式配置修复

状态：本地功能和定向检查完成，进入打包发布。优先处理用户反馈的格式全选、取消无效、跳转到文件夹和实际生效状态不清楚。

## 已完成

- 同一个格式弹窗提供全选、全部取消和确认；已有默认格式也可取消勾选，移除设置页额外的“更改 / 取消默认”按钮。
- 首次勾选从 Windows 实际默认状态生成，不把已注册的候选格式视为已默认。
- 确认后保留待处理格式，区分已默认、待确认、待更换；返回软件或手动刷新后重新读取实际状态。
- 使用 ShellExecuteW 激活设置 URI，按 Windows 版本选择应用专页或默认应用首页，失败时显示原因。
- 支持空选择；已有显式默认在系统更换前保留有效打开命令和系统配置入口，避免取消期间产生失效入口。
- 小窗口只滚动弹窗内容，底部确认按钮保持可见；补充最下面格式和提示可滚达的检查。

Windows 10/11 的默认应用仍需系统界面确认，本版不承诺一次软件内确认即可静默替换或移除全部系统默认。见 [实现与检查](DEFAULT_APP_SETTINGS_FIX_1.7.7.md)与 [发布说明](RELEASE_NOTES_1.7.7.md)。

后续 GNU 长名称和全局 PAX 兼容移至 [v1.7.8](ARCHIVE_ROADMAP_1.7.8.md)，仍仅规划。保留单条展开、多选弹窗、左右等宽及原双栏浏览交互。
