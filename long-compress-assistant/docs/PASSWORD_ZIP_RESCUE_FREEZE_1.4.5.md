- 目录可读的密码 ZIP 完整文件救援，AES/ZipCrypto、ZIPX、混合包及完整数字/标准卷；沿用填写的密码生成 AES-256 / UTF-8 新包，明确部分恢复和未恢复原因。

- 密码纠正后重新诊断、处理中取消、结果定位/复制；重复本地名称不再中止整个救援。单条行内展开、多选弹窗、自然配置继承保留。
