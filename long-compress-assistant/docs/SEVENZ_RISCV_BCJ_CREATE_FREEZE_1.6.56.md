## 原生实现与边界

锁定 sevenz-rust 原本缺少 RISC-V 方法和内核。本版注册标准单字节 `0x0B`，参考 [XZ riscv.c](https://github.com/tukaani-project/xz/blob/master/src/liblzma/simple/riscv.c) 适配 Rust JAL 与 AUIPC 成对转换；作者、来源和完整 0BSD 原文随[内核](../src-tauri/vendor/sevenz-rust/src/bcj/riscv.rs)及[许可](../src-tauri/vendor/sevenz-rust/src/bcj/RISCV-0BSD.txt)保留。标识/两字节对齐参照 [7-Zip 注册](https://github.com/ip7z/7zip/blob/main/CPP/7zip/Compress/BranchRegister.cpp)。

两字节扫描兼容压缩指令混排，JAL 只处理 x1/x5；AUIPC 核对第二指令寄存器与低位，保留错配跳过距离和 x2 特殊格式的假转换，使任意数据也可逆，x0 landing pad 保持。位置、立即数和加减使用 u32 wrapping。处理至少八字节窗口，最多七字节尾部跨 write/flush/固实条目保留，最后不足窗口的 JAL 按标准保持。固定 8 KiB 流式封装只增加 RISC-V 构造及七字节尾部断言；原架构内核未改。结束仅排尾部一次并结束后续编码器，失败保持失败。

输出空属性，读取接受空或四字节小端、两字节对齐的起点；错误长度与奇数起点拒绝。完整图文走原完整共享读取并保留可用 CRC/完整 AES 消费检查。开头只接收严格可选 AES + LZMA2/LZMA + RISC-V 单进单出链，前置内容、所选前缀及最多七字节前看计入原 64 MiB 预算，以 take 限制过滤器读取。取消、来源变化、部分内容/未校验整文件和提取全文下一步保持。
