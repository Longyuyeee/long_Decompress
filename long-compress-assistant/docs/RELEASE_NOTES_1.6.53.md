# v1.6.53 · 可选 7Z ARM32 BCJ 预处理

- 原 7Z 折叠的「高级预处理」加入 ARM32 BCJ，适用于 LZMA2 / LZMA，与无、Delta、x86 BCJ 互斥；默认关闭，不按扩展名自动开启，不增加格式计数。
- 面向 ARM32 小端程序指令。选择 BCJ 时收起 Delta 距离，切回 Delta 保留原值；其他方法保留设置并显示暂未应用，沿用单条展开、多选弹窗和等宽布局。
- 接通内容/文件名密码、固实/非固实、数字分卷、预设/配置组/模板、草稿、历史、工作流和转换；体积分析使用实际选定编码链，不保证所有文件都更小。
- 新输出和独立 7-Zip ARM 归档可直接使用原图文预览、查看大文本开头与提取流程；处理跨文件指令对齐，最多三字节前看计入原预算，保留部分内容提示。
- 修正 ARM32 转换的位置回绕，读取支持空属性或四字节对齐的起始位置；补齐历史配置白名单，避免恢复时丢失 ARM32 选项。

范围和检查见[开发记录](SEVENZ_ARM32_BCJ_CREATE_FREEZE_1.6.53.md)。正式附件由标签流水线自动生成，实际状态在本版 PR 接续。下一阶段 [ARM Thumb BCJ](ARCHIVE_ROADMAP_1.6.54.md)仅规划；更多格式与真实失败包的兼容容错继续保留在主线中。
