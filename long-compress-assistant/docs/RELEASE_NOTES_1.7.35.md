# v1.7.35 · ZIP 恢复结果保留修改时间

救回文件后按日期整理资料，现在更方便：恢复新 ZIP 中的文件和明确目录会保留可确认的来源修改时间，继续解压后也能读回对应日期。

- 接通完整目录和丢目录重建两类来源，保留确认范围内的 UTC 奇数秒及原 DOS 兼容日期。
- 已支持的密码包、完整数字/标准分卷及 BZip2/LZMA 流式取回沿原入口传递时间，原件与部分取回标记保持。
- 缺失、重复或冲突时间沿规则回退，不用当前时间冒充来源日期，也不因时间有效而取回校验失败的内容；界面与交互保持。

UTC 范围继续为 1970–2038 整数秒，DOS 仍为两秒精度；本版不扩展亚秒、其他时间/权限元数据、格式数量或密码未知边界。见[范围](ARCHIVE_ROADMAP_1.7.35.md)、[实现与检查](ZIP_RECOVERY_TIME_FREEZE_1.7.35.md)。下一阶段 [v1.7.36 流式 Zstandard ZIP 部分取回](ARCHIVE_ROADMAP_1.7.36.md)仅规划。
