# v1.6.55 · 可选 7Z ARM64 BCJ 预处理

- 原 7Z 折叠「高级预处理」增加 ARM64 BCJ，适用于 LZMA2 / LZMA；与无、Delta、x86、ARM32、Thumb 互斥，默认关闭，不按扩展名自动启用。
- 原生引擎补齐 ARM64 的 BL / ADRP 指令过滤与读取，采用标准 7Z 方法标识，可与独立 7-Zip 互通；支持空属性或四字节对齐的起点，位置计算按 32 位回绕。
- 密码/隐藏文件名、固实/非固实、数字分卷及非首卷、配置组/预设/模板、草稿、历史、工作流、真实编码链分析与转换接通。
- 新输出和独立 ARM64 归档接入原完整图文、大文本开头和提取入口，必要前看计入原预算，保留部分内容与未校验整文件提示。
- 保留单条展开、多选弹窗、等宽双栏、折叠设置和窄窗口长状态换行；BCJ 收起并保留 Delta 距离，不兼容方法显示暂未应用。没有新增格式计数、依赖或外部运行引擎。

实现来源、边界与检查见[开发记录](SEVENZ_ARM64_BCJ_CREATE_FREEZE_1.6.55.md)。正式附件由标签流水线自动生成，状态在本版 PR 接续。下一阶段 [RISC-V BCJ](ARCHIVE_ROADMAP_1.6.56.md)仅规划；更多格式与真实失败包兼容容错继续保留在主线。
