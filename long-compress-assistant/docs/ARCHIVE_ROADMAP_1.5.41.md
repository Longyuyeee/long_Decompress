# v1.5.41：按用途配置压缩

2026-10-21 已完成功能封板，见[实际记录](PURPOSE_PRESETS_FREEZE_1.5.41.md)。本版开始开发时，接续已发布 v1.5.40 和[近期排期](ARCHIVE_ROADMAP_1.5.40_TO_1.5.43.md)。

## 用户得到什么

在现有配置位置提供四种用途方案：兼容分享（ZIP / Deflate / 6）、体积优先（7Z / 9）、加密分享（7Z / 6 / 密码与文件名加密）、按大小分包（ZIP / Deflate / 6 / 标准分卷）。先显示实际参数与使用条件，用户确认后才应用；空密码不能应用加密方案。名称、目录、原包密码、删除原件等未指定参数保留。压缩与转换共用方案定义。

单条仍在原位置展开配置；多选仍在原弹窗中填入方案，最终确认后才批量生效。全局自然继承，单条编辑自动独立，既有预设、配置组、模板与智能分析继续使用。左右等宽、窄窗可滚动，不改为必经向导或额外任务弹窗。

## 实施与收尾

1. 共用方案与紧凑选择组件，显示格式、强度、加密或卷型，保留手动微调。
2. 接压缩/转换的单条、默认与多选；密码只在填写或明确沿用时使用，多选取消不得改任务。
3. 必要的补丁保留与继承检查，以及实际桌面宽/窄显示和代表性创建/转换结果；复用已通过的格式矩阵，不重跑无关检查。
4. 更新 README、中文 Release、交接和范围说明，受保护合入后发布。后续按 v1.5.42 失败纠正、v1.5.43 批处理与结果体验，再进入五模块分阶段路线。

本版不增加算法，不承诺固定压缩率或所有系统自带解压器都能处理密码/分卷；不自动删除原件，不改变未确认的默认配置。
