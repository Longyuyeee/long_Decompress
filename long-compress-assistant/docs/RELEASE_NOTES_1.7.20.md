# v1.7.20 · TAR.LZO 所选链接内容提取

在双栏浏览器中选中 TAR.LZO 的链接副本，现在可以直接提取到另一栏或指定目录，原始目标文件无需一并选中。

- 接通普通头、局部 PAX 和 GNU 长名称组合，普通、空文件和已支持的稀疏内容均保存为独立文件。同源多个副本按来源顺序处理。
- 沿用原目录结构、同名处理、暂存发布、暂停取消与文件/目录时间；来源变化或选项失效时明确提示。
- 历史再次解压及重启草稿保留所选范围、目录方式和同名策略，避免变成整包解压。
- 原双栏等宽、包内外一致列表、单条展开及多选弹窗保留；来源信息仍收在提示和详情中。

本版完成所选内容提取，不创建系统链接。整包链接解压、完整链接内容检查、转换与嵌套打开继续分期；前向、歧义目标、任意链条及符号链接仍有限制。

见 [本版范围](ARCHIVE_ROADMAP_1.7.20.md)、[实现与检查](TAR_SELECTED_FREEZE_1.7.20.md)。下一阶段 [v1.7.21 整包提取与链接内容检查](ARCHIVE_ROADMAP_1.7.21.md)仅规划。
