# v1.6.22 · 带密码的 7Z 固实相册直接看图

带密码的固实 7Z 相册现在也能在原双栏预览、连续阅读，不必先提取整包。

- 支持 AES + LZMA/LZMA2 固实包内的 PNG、JPEG、GIF、WebP、BMP，接通内容加密、文件名加密和完整数字分卷。
- 沿原手动密码和保险箱打开目录、读取所选图片；手动密码不回退，预览不增加整包密码成功统计，也不先检查无关大文件。
- 使用原阅读器翻页、缩放、适应窗口、跳过坏图、定位和提取当前页。按需读取当前图片，保留有限缓存，另一栏位置保持。
- 所选图片 ≤8 MiB、单边 ≤8192、总像素 ≤1600 万；共享压缩数据/解码总量分别 ≤64 MiB，全部共享内容和 AES 长度/填充检查通过后显示。错误密码、损坏和超限保留明确下一步，不显示部分图片。
- 保留关闭/停止/换页取消、来源变化核对和完整卷组检查；实际输入合计 ≤64 MiB，每次请求的密码候选合计限时 30 秒。共享读取给简短等待，范围说明收在问号中。

单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键保持，格式数量不变。未加密图文、非固实密码图文和加密固实小文本保持原范围；大文本前缀与新方法组合继续分阶段推进。
