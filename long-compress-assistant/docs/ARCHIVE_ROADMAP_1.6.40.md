# v1.6.40 规划 · 普通固实 Deflate64 完整图文

仅规划，尚未开发。接续非固实普通/密码图文预览，先解决普通固实 7Z 中“只想看共享块里某个文件”的需求，AES 固实与大文本继续拆分推进。

1. **所选完整小图文**：唯一普通条目、完整共享映射/顺序/条数/总量与方法链可确认时，文本 ≤1 MiB、图片 ≤8 MiB。共享压缩输入和解码总量分别 ≤64 MiB；流式处理全部共享内容，仅保留所选文件，核对真实结束、扣除预读的精确消费与全部可用逐文件/块/打包 CRC，不用按文件大小截止掩盖短流。
2. **原入口贯通**：完整数字卷/非首卷、原只读文本/常见编码/滚动、图片预览和连续阅读/缩放/跳过坏图/定位/仅提取当前页保持。超限、AES 固实、大文本或其他方法组合提供提取下一步；范围只写原问号，不新增配置区。
3. **只读所需范围**：实际输入/整体时间、跳过前置和处理后续时取消、来源绑定继续有效，不读取无关大块、不为整个共享声明分配全文。
4. **必要收尾**：真实原工具样本由另一版本逐文件独立回解，覆盖所选前/中/后、空项、常见编码/图片与完整数字卷。只补新增共享消费、CRC/终止/范围及受影响宽窄窗口，普通/密码非固实路径补必要连续性。同步 README、Release、能力表与交接，正常 PR/标签发布。

之后分拆 AES 固实 Deflate64 完整图文、非固实大文本开头、固实大文本开头，继续格式/算法、密码/分卷与容错主线。ALZ 方法 3、历史 Bzip2/原工具图片及 EGG 加密固实仍需有效外部原件。保留单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键和问号收纳，不重复已过且未受影响的旧检查。
