# Long解压 v1.5.28

从 Windows 资源管理器直接带入文件和校验清单，少找一遍路径。

- **右键生成清单**：启用软件右键菜单后，选中文件使用“Long解压：生成校验清单…”，进入现有完整性页面。确认后再计算，导出相对路径清单，同名文件保留各自目录。
- **右键核对清单**：SFV、MD5、SHA256 文件增加核对入口。多份清单一起带入后可逐份选择，清单名称优先显示，完整位置另行展示，长路径也容易辨认；主动点击后才读取文件。
- **已有工作继续保留**：新请求排队，计算列表由你选择替换或合并，重复路径去重；计算进行中不会被新选择打断，已有核对结果保留到主动检查另一份清单。
- **失败提示更准确**：文件已移动或无法读取时保留逐项原因，不再出现绿色“成功”通知；已完成摘要仍可导出。

沿现有经典菜单注册，Windows 11 可在“显示更多选项”中使用；没有放宽新式菜单的签名条件。只处理选中文件，不隐式递归目录，不自动全文件重算。保留单条展开、多选弹窗、自然继承、左右等宽和小窗口滚动，继续复用进度、停止与接续。
