## 怎样划分版本

- 近期 [v1.5.40～v1.5.43](ARCHIVE_ROADMAP_1.5.40_TO_1.5.43.md) 保持原安排，之后依次推进五个模块。
- 将五个模块拆成 15 个有用户收益的功能阶段，暂放在 v1.5.44～v1.5.58；v1.5.59 起回归更多算法、格式与容错兼容主线。版本号表示顺序，不代表发布日期或固定工期。
- 每个阶段都交付可以独立使用的完整流程。不能只交一个空页面、后端接口或预览按钮，就当作一版完成；也不要求第一版穷尽整个模块。
- 美观、窄窗可用、进度/结果可见和必要的失败处理随当版功能完成，不统一拖到最后一个“美化/验收版”。阶段完成以本版列出的用户任务为界。
- 15 个阶段不是必须发布 15 次：开发前核对实际工作量，已具备的功能直接复用，小阶段可以合并；某阶段仍过大时可拆分。调整时同步版本表、交接与回归位置，不为凑版本重复开发。
- 模块阶段继续修复已支持流程的严重阻断问题，并沿真实使用路径小步优化性能。新的格式/算法专题按本路线后置，不反复打断已确定的模块顺序。

## 一、压缩包编辑工作区：v1.5.44～v1.5.46

典型场景：替换项目 ZIP 中的说明文件，补入素材，整理旧目录，生成新的交付包。复用现有归档浏览器、压缩写入、转换、配置与统一结果。

### v1.5.44：向 ZIP 添加、替换内容并另存（已完成功能封板）

[实施计划](ARCHIVE_ROADMAP_1.5.44.md) · [封板与范围](ZIP_EDIT_FREEZE_1.5.44.md) · [中文说明](RELEASE_NOTES_1.5.44.md)。首阶段已贯通添加/替换/另存、新包使用与会话内失败接续；密码和跨次编辑草稿仍按 v1.5.46 推进。

用户任务：打开普通 ZIP，补入新文件或替换指定文件，得到能正常使用的新包。

- 从原浏览器选择包内位置并添加文件/目录，支持拖入；同名项明确选择替换、跳过或保留两份，不默认覆盖。
- 显示本次待保存修改，支持撤销、取消与另存；首版就保留原包，不把这些基本操作留到后续版本。
- 首版限定普通、当前可完整读取并写出的 ZIP。显示输出方法与关键选项；超出本版范围的密码/方法就近说明，不静默清密码、改格式或丢内容。
- 保存沿现有进度、停止与结果入口；结果能重新浏览、预览和提取。未改条目的路径、中文名称、内容与空目录按该范围保留，保存失败不伪装成成功结果。

**本版完成边界**：用户可以完成“打开 ZIP → 添加/替换 → 复核修改 → 另存 → 打开新包”。不把删除、重命名、密码包或跨次编辑草稿都塞进这一版。

### v1.5.45：删除、重命名与批量目录整理（已完成功能封板）

[实施计划](ARCHIVE_ROADMAP_1.5.45.md) · [封板与范围](ZIP_ORGANIZE_FREEZE_1.5.45.md) · [中文说明](RELEASE_NOTES_1.5.45.md)。普通 ZIP 添加/替换/删除/改名/移动已能组合另存；密码、跨次草稿仍按 v1.5.46。

用户任务：一次整理包内的多处文件和目录，清楚知道改了什么。

- 接入删除、重命名和目录重命名；多选操作沿原交互提供，批量规则在弹窗中配置，操作结果进入同一待保存列表。
- 提供修改前/后路径与受影响数量，目录操作连同子项展示，修改可逐项撤销或整体放弃。
- 处理新增/替换/删除/重命名之间的相互影响、同名和大小写冲突、文件与目录重名；不能形成的目标路径当场说明，不拖到保存结束才报模糊错误。
- 连同 v1.5.44 的添加/替换统一保存，沿现有结果再次查看；长路径和大量修改可搜索/筛选，不在页面摊开巨大的配置区。

**本版完成边界**：普通 ZIP 的常用增、替、删、改可以组合使用，目录结构与修改清单一致。外部编辑器自动回写和任意格式原地修改不纳入本版。

### v1.5.46：密码 ZIP、编辑草稿与失败继续（已完成功能封板）

[实施计划](ARCHIVE_ROADMAP_1.5.46.md) · [封板与范围](ZIP_PASSWORD_DRAFTS_FREEZE_1.5.46.md) · [中文说明](RELEASE_NOTES_1.5.46.md)。密码编辑、跨次草稿、来源修复与成功收据接续已在独立 Store/Deflate ZIP 范围内完成；下一步进入资源库阶段。

用户任务：编辑已有密码包，或者中断后继续之前的整理，不重新做一遍。

- 接通当前可读写的 ZIP 密码方案与方法组合，复用原包密码/输出密码和保险箱；保留或更改输出加密由用户明确选择。特殊编码或无法保留的参数显示具体限制与可用另存选项。
- 接入编辑草稿：记录源包、待保存修改、外部新增/替换文件的引用及输出配置；恢复时明确显示仍可用和已变化的来源，缺失项可重新定位。
- 保存失败后保留修改，纠正密码、目录或源文件后重试；保存已成功时不自动重复生成第二份结果。停止后保留可继续的编辑状态，不承诺从编码中间字节续写。
- 新包的浏览、再次编辑、提取、转换和历史来源接在既有入口，保持原结果及原包可找。

**模块阶段完成**：在已声明 ZIP 范围内完成内容编辑、密码、草稿恢复与结果接续。7Z/RAR 直接编辑、标准卷回写、所有 ZIP 方法互改及外部应用回写进入之后的格式兼容候选，不阻塞模块阶段收尾。

## 二、归档资源库与跨包搜索：v1.5.47～v1.5.49

典型场景：知道文件在某份下载资料里，却记不起包名。资源库围绕资料来源和包内条目组织，复用现有浏览、预览、提取和本地持久化，不替代任务历史。

### v1.5.47：本地建库、跨包搜索与单项取回（已完成功能封板）

[实施计划](ARCHIVE_ROADMAP_1.5.47.md) · [封板与范围](ARCHIVE_LIBRARY_FREEZE_1.5.47.md) · [中文说明](RELEASE_NOTES_1.5.47.md)。普通 ZIP/TAR 本地建库、跨包查找与原浏览器单项使用完成；密码/分卷/更多格式及持续维护按下一阶段。

用户任务：添加一批资料，搜到包内文件并打开或提取。

- 主动添加归档或选择资料目录扫描候选，先覆盖可读的普通 ZIP/TAR；列出来源、格式和索引状态，手动开始或刷新索引，不默认全盘扫描。
- 建立文件名、包内路径、大小与时间索引，搜索多个已索引归档；支持按来源和文件类型筛选，搜索命中保留所属归档与包内位置。
- 从命中结果返回原浏览器、预览或提取所选条目；无法预览时继续提供已有提取后打开方式，结果沿原入口。
- 建库过程可停止，已完成来源可搜索，未完成或不可读来源明确展示；移除资料库条目不会删除原包。

**本版完成边界**：本地普通 ZIP/TAR 的“添加资料 → 建索引 → 搜文件 → 查看/取回”完整可用。密码包、更多现有格式及自动更新留到下一阶段。

### v1.5.48：索引更新、密码包与分卷来源（已完成功能封板）

[实施计划](ARCHIVE_ROADMAP_1.5.48.md) · [封板与范围](LIBRARY_MAINTENANCE_FREEZE_1.5.48.md) · [中文说明](RELEASE_NOTES_1.5.48.md)。现有格式候选、密码/分卷、来源维护、离线缓存与暂停接续完成；分类和跨包批量取回按下一阶段。

用户任务：资料换位置或更新以后，仍能找到准确内容；密码包与分卷不变成重复资料。

- 扩展到现有实际可列目录的格式，沿原能力说明区分可搜索、可预览和可提取；分卷组只作为一份归档，镜像/快照来源保持各自身份。
- 密码包复用现有凭据解锁，缺卷、不可读或未解锁来源有明确状态；未能索引的内容不以“无搜索结果”冒充已经完整检索。
- 只重建变化的归档索引；可暂停与恢复建库，来源移动、删除、修改时提供重新定位、刷新或移除记录，不静默沿用过期条目执行。
- 已有索引可用于查找离线资料，但缓存状态和当前来源可访问性明确区分；真正预览/提取前读取当前来源并接可用纠正操作。

**本版完成边界**：持续维护本地资料库，能处理已有格式范围内的密码/分卷及来源变化。离线索引不等于已缓存文件内容。

### v1.5.49：资料分类与跨包批量取回

用户任务：整理常用资料，并把分散在多个包里的命中项一次取出。

- 提供标签、收藏、保存的搜索/筛选条件，搜索状态与返回位置可保留，避免反复重新找资料。
- 跨包多选命中项后，在原多选配置方式中确定输出位置、目录结构及同名处理，按各自来源和选择范围进入现有队列；默认只处理用户选择的条目。
- 需要密码、缺卷或暂不可用的来源与可执行部分分开显示，纠正后只接续待处理部分；结果保留所属来源、所选文件与打开位置。
- 编辑产生新包或任务完成后，可主动加入/刷新资料库；不强制把所有历史产物永久纳入库。

**模块阶段完成**：本地资料的查找、更新、分类及跨包批量取回贯通。全文检索、OCR、云盘与全盘常驻扫描不作为本轮前置。

## 三、自动化工作流中心：v1.5.50～v1.5.53

典型场景：每次交付都要筛选资料、解压或转换、按日期命名并压缩到固定目录。复用配置组、任务模板、监控目录和同一任务队列，重点解决步骤串联及继续处理。

### v1.5.50：手动运行的顺序工作流

用户任务：保存一套顺序处理方案，再次选择资料后一次运行。

- 提供常用模板和简单的顺序步骤编辑，选择来源/规则筛选 → 解压、压缩或转换 → 输出命名/保存目录，清楚展示每步的输入和输出。
- 后一步使用前一步实际产物，支持已有配置组/模板复用；可保存、复制和修改方案，不增加第二套压缩或结果引擎。
- 默认手动运行，从流程看到各步骤状态、当前任务及结果；失败定位到具体步骤，停止时不再派发后续步骤，已完成产物保留。

**本版完成边界**：至少常用的“解压后重新打包”和“筛选后按日期归档”方案完整可用。首版就有正确结果和停止行为；细粒度失败恢复与自动触发分开推进。

### v1.5.51：纠正失败、重启恢复与按需重跑

用户任务：改好一个出错步骤后继续，不重做已成功的整条流程。

- 保留每次运行的步骤输入、输出和完成记录；纠正密码、目录或配置后，明确显示哪些步骤可以复用、哪些下游需要重新运行。
- 继续执行之前确认已完成产物仍存在且与本次输入对应，不仅凭“曾成功”就跳过；输入或参数变化时说明受影响范围。
- 连接现有草稿/运行历史，重启后显示未完成流程和继续入口，避免重复触发同一任务；支持从指定步骤重新运行。

**本版完成边界**：手动工作流的失败/停止/重启后续处理可用。恢复的是步骤与任务状态，不承诺任意压缩算法中间字节断点续写。

### v1.5.52：监控目录触发与运行队列

用户任务：把资料放入指定目录后，自动执行自己启用的方案。

- 用户明确启用目录触发，设定来源范围、文件筛选和等待文件稳定的条件；升级不改变旧的“监控后生成待确认草稿”语义。
- 处理复制未完成、重复文件事件、分卷陆续到齐及同一来源已有运行的情况；缺卷或不满足条件时显示等待原因，补齐后继续。
- 显示触发来源、等待/运行/完成记录，可暂停规则或取消待执行项；输出目录不会再次触发同一流程形成循环。
- 运行仍使用应用/托盘已有队列与并发配置，异常沿 v1.5.51 的纠正继续流程。

**本版完成边界**：应用运行或托盘驻留时，目录变化能可靠触发既有工作流。退出应用后的系统级唤醒不在此版范围。

### v1.5.53：定时触发、错过处理与运行管理

用户任务：按约定时间处理固定资料，能看清何时会执行以及上次结果。

- 支持日常需要的指定时间/重复周期，显示下一次运行与最近结果；规则可启停、编辑或立即运行，不强迫用户填写表达式。
- 应用重启恢复规则，错过时段显示未执行并提供现在运行/跳过；不静默补跑所有历史次数。
- 同一流程仍在运行时展示排队/跳过策略，避免定时和目录事件重复派发；从规则进入每次运行、失败步骤及统一结果。
- 界面明确“应用运行或托盘驻留时执行”，不把退出后尚未执行的计划显示成已完成。

**模块阶段完成**：手动方案、失败继续、目录和定时触发构成可日常使用的自动化中心。复杂分支图、任意脚本/插件、系统唤醒和全媒体步骤集成作为后续候选。

## 四、文件夹与压缩包对比：v1.5.54～v1.5.56

典型场景：两份资料很相似，需要知道改了什么，取回差异或生成新的交付包。复用 ZPAQ 对比的展示/选择思路，保留其独立快照语义。

### v1.5.54：看差异并取回所选文件

用户任务：选两份资料，快速定位新增、移除和疑似修改项。

- 覆盖文件夹↔文件夹、普通 ZIP↔ZIP、文件夹↔ZIP；左右来源、相对路径与统计清楚，支持搜索/筛选、分别选取左右条目。
- 先按目录、大小、时间等元数据对比，显示新增、移除、元数据变化、内容候选或尚未核对；同大小/时间不能直接标为内容相同。
- 从 ZIP 提取、从目录复制所选差异到用户指定位置，沿原队列与结果显示；不因跨来源选择就变成整包操作。
- 读取可停止，来源变化或不可读时保留可解释状态；窄窗下仍能辨认左右来源和差异。

**本版完成边界**：可以查找并取回差异候选，清楚知道哪些还没有核对内容。不将目录比较结果冒充逐字节确认。

### v1.5.55：按需核对内容与复杂来源

用户任务：确认同名文件到底是否相同，而非猜测时间和大小。

- 对所选或筛选后的候选执行实际内容核对，展示读取进度、停止与已确认结果；区分内容相同、内容不同、仅元数据变化及无法读取。
- 密码/分卷 ZIP 沿当前可读能力接入，补密码或卷后只继续受影响部分；预览不能读取的条目不等于无法通过已有提取路径核对。
- 结果绑定左右来源的实际版本，来源变化时指出受影响条目并重新核对，不使用过期结论。

**本版完成边界**：可从“疑似变化”推进到有内容依据的差异判断。首版不要求所有其他格式同步获得同等能力。

### v1.5.56：把所选变更组成新包

用户任务：从两边挑选需要的文件，生成下一份交付 ZIP。

- 复用 v1.5.44～v1.5.46 编辑工作区，将所选新增/替换项带入待保存清单，明确来源与目标路径。
- 移除项由用户明确选择后才进入删除清单；冲突、重命名和整目录影响沿原编辑预览处理，可撤销或取消。
- 另存新包后继续浏览、提取、加入资源库或再次对比，源包和原对比结果保留；适用的密码/方法范围沿编辑能力说明。

**模块阶段完成**：在文件夹与受支持 ZIP 范围内完成查看差异、核对内容、取回差异及生成新包。双向同步、自动删除镜像、所有格式原地合并不作为前置。

## 五、整包图片阅读：v1.5.57～v1.5.58

典型场景：打开扫描件或设计素材包，连续翻阅并挑出需要的图片。复用已有图片预览与归档读取能力，范围随实际能力显示，不承诺所有包都能直接预览。

### v1.5.57：缩略图与连续阅读

用户任务：直接浏览一包图片，不反复关闭和打开单张预览。

- 在原归档浏览入口进入缩略图网格和阅读视图，支持路径/自然排序、上一张/下一张、键盘翻页、全屏、缩放与适应窗口。
- 按需加载当前图片及少量相邻图片，展示当前页/总数和加载状态，复用现有读取/缓存预算，不提前整包解压进内存。
- 首版就处理不可读图片和受限条目，显示原因并可跳过或沿已有方式提取后打开；宽窄窗口都能看清图片及操作。

**本版完成边界**：在已支持可预览的普通归档/图片中完成连续翻阅。不是只做一排缩略图，记忆位置和跨包资料使用留在下一阶段。

### v1.5.58：大包阅读、阅读记忆与所选取回

用户任务：资料很多时仍能方便翻阅，回来继续看，并取出选中的素材。

- 阅读位置绑定归档及包内条目，离开/重启后回到原位置；来源变化时刷新并定位仍存在的条目，不沿用失效序号。
- 大量图片使用按需列表、缩略图回收和有限预取，结合实际等待优化；固实包、超大图等范围限制就近说明，不默认扩大读取上限。
- 密码/分卷来源按当前可预览能力接通，受限格式沿提取后阅读的既有方式处理；资源库搜索命中进入同一阅读器，保留返回位置。
- 多选图片沿原弹窗配置提取、压缩或转换，保持来源、排序与选择范围，结果仍在原任务/产物入口查看。

**模块阶段完成**：在实际支持范围内形成“找资料 → 连续阅读 → 记住位置 → 挑选取回”的完整流程。新图片编码器、PDF 页面、OCR 和图片编辑器不作为本轮前置。

## 六、v1.5.59 起回归格式、算法与容错兼容主线

上述五个模块达到各自阶段完成范围后，恢复增加真实可用算法/格式、密码与卷型组合，以及异常恢复和流程兼容的主线。模块功能的无限扩展不成为延后回归的理由；原先 v1.5.49 起回归的安排被本次分阶段路线替代。

| 方向 | 回归后的安排 |
| --- | --- |
| 更多算法和格式 | 重新评估 ALZ 方法 3、EGG 加密固实等，依据真实需求、正向来源及实现可行性选择下一专题，不预先承诺未知算法在 v1.5.59 完成 |
| 密码、卷型及编辑支持 | 补齐已有格式中的实际缺口；分别记录原生密码、自有 AES 包装、数字切片与原生多卷，逐步扩展可读/可写/可编辑范围 |
| 容错与部分取回 | 按真实来源处理截断、缺卷、目录异常、编码、密码及数据错误区分，保留成功内容、未恢复原因与可继续的操作 |
| ZPAQ 等专项 | 原生追加多部分、损坏事务取回等继续独立评估，保留能力缺口，不把数字切片或另存增量更新当成已经完成 |
| 全流程兼容和性能 | 新增支持延伸到创建、浏览、预览、转换、提取、结果，以及本轮编辑/索引/工作流/对比/阅读适用路径；沿真实重复读写和等待改进性能 |

v1.5.59 是恢复主线的暂定起点，具体题目在启动时确定；如果阶段合并或拆分导致版本移动，同步更新起点并说明剩余模块，不能无限添加“完善版”推迟主线。未排期的备份中心、空间整理、云服务等不加入本轮。

## 依赖、交互与推进方式

- 编辑工作区先形成修改/另存与草稿能力，资源库复用浏览与结果，工作流复用配置/队列/历史，对比再复用编辑，阅读最后串起资源库命中与所选取回。每阶段先核对现有代码，只补真实缺口。
- 单条任务仍点击行内展开；多选配置仍在弹窗；全局自然继承、修改后形成单条配置保持。新模块不引入强制的全局/单独选择或每步必经弹窗。
- 现有任务配置/日志与结果保持 50/50 和窄窗滚动；模块按自身任务采用适合的布局，不机械地把所有信息挤在一页。美观与可用性随功能一起完成。
- 各阶段只做与改动相关的必要检查和显示确认，复用已通过且未受影响的依据；不重复旧全格式/密码矩阵、真实盘满或大量无关验收。不另排只为重复检测的版本。
- 阶段收尾记录已交付内容、限制和下一步；尚未开发不能写成已封板。README 以软件特点为主，实际更新放末尾，Release 只写当版真实交付。
