# Long解压 v1.5.5

本版补齐真实外置分卷自解压包的只读处理，并修复 RAR 密码判断和取消后的输出清理问题。

## 新增和修复

- 支持已验证的 RAR4 单 EXE、旧式 EXE/rNN、RAR4/5 新式 part1.exe/partN.rar，以及固定 7-Zip 24.09 GUI 加载器加 .7z.001 外置数据卷。普通、内容密码和文件名密码组合均有真实原包验证。
- 从任意成员统一归组，贯通浏览、所选/整包解压、完整性检查、诊断和转换。多选 EXE 与数据卷只加入同一组任务；文件管理器可双击 RAR 中卷或数字卷进入归档浏览。
- 缺首卷提示原始同名 EXE 的可能性，明确缺中卷/可见缺尾卷与卷头损坏原因；补回原卷后创建新任务，旧失败记录保留。
- 修复加密空文件被当作密码验证成功、RAR4 文件名加密 SFX 在正确密码尝试前被 CLI 模糊文字拒绝，以及完整性检查误读 EXE 资源的问题。
- RAR 块内暂停、恢复、暂停中取消真正生效；修复原生 C++ 异常展开缺失造成的取消后部分输出文件锁，取消不发布结果且保留源卷。
- 密码纠正并成功读取后清除该浏览请求的旧错误提示，不清除其他任务错误；SFX 诊断不再显示不支持的创建恢复卷操作。

## 验证

94 项定向 Rust、214 项前端、十五组原工具原包、24 个桌面场景和 18 张常用/窄窗页面通过。包含真实错密码失败后纠正、缺卷补回、历史重做、转换 ZIP 独立回解，以及确认实际内容已写入后的暂停/恢复/取消。

## 本版边界

只读取归档数据，不执行输入 EXE，不创建/修复 SFX 或处理其恢复卷。RAR4 旧格式样本由原 RAR 6.24 生成，不承诺全部历史自解压模块；独立 7Z 加载器仅本次实测的 24.09 GUI 原始模块。加密 RAR 头隐藏卷数时不从卷名猜最终完整性，需正确密码后的原生完整读取确认。

RAR 进度目前仍有预分配长度估算，准确实际解码字节进度列为下一版优先项；不影响本版已验证的暂停和取消控制。Windows N 暂不保证支持。详见[实施审计](SFX_VOLUMES_1.5.5.md)与[封板记录](SFX_VOLUMES_FREEZE_1.5.5.md)。
