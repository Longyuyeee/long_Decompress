# Long解压 v1.4.3

这一版围绕归档的完整处理流程升级：同一组分卷只处理一次，更多格式可以创建、转换和分卷，修改配置后能继续完成任务。

## 分卷整理更省事

- 选择任意一卷或同时选择多卷，转换列表会合并成一个归档任务，并找到实际首卷。
- 标准 ZIP 的 `.z01/.zip`、RAR 的新旧卷名和数字卷使用一致的归档识别；缺卷会显示需要补齐的文件，保留已经修改的配置。
- 标准 ZIP 多卷支持浏览、图片/文本预览、密码读取及转换，覆盖本轮验证的 ZipCrypto、AES 和 ZIP64 目录；只剩 `.zip` 时也会提示缺失的分卷。
- 历史和待处理草稿保留卷组来源，补齐分卷后可以再次执行。启动中新增的右键任务留在待处理列表。

## RAR 可以带密码分卷、改密和转换

- 普通压缩、批量配置及归档转换支持 RAR 分卷、内容密码和文件名加密，也可重新分卷、合卷或转换到其他目标格式。
- 结果入口展示真实的 `.partN.rar` 文件清单，正确处理取消、失败清理和文件名冲突。
- 内容不足一卷时也能正确校验和发布；两个来源包含同名文件时保留各自内容。
- 修复 RAR 转换带入临时目录完整路径的问题，解压后只保留原包中的目录和文件。
- 修复 Windows 下中文等 Unicode 密码被误判为错误密码的问题，创建、浏览、读取和转换使用一致的密码。
- 创建 RAR 仍需要自行安装 WinRAR/Rar.exe，配置位置会提示编码器状态并提供重新检测；解压 RAR 不需要另装 WinRAR。

## 新增 LZ4 和 Brotli

- 新增单文件 LZ4、Brotli，以及适合目录/多文件的 TAR.LZ4、TAR.BR；支持创建、浏览和解压。
- 转换目标新增 TAR.LZ4、TAR.BR 及已有的 TAR AES 加密包装系列。
- 普通 TAR/TGZ/TBZ/TXZ/TZST 和 GZ/BZ2/XZ/ZST、LZ4/Brotli 支持数字切卷与合并回解。
- 单文件流的默认名称保留原文件后缀，例如 `说明.txt.br` 解压后仍是 `说明.txt`。

LZ4 使用快速压缩模式，Brotli 可以调整压缩强度。普通 TAR 和流格式本身没有密码；使用密码时会先提示并改用 7Z 容器，`.aes` 则属于本应用的加密包装。数字切卷适合本应用完整卷组回解，外部工具的兼容能力不同。

## 保持熟悉的操作

单条点击后仍在原位置展开，多选后通过按钮打开配置弹窗。全局配置作为默认值，修改某条后自然保留该条配置。新增格式沿用原有界面与结果入口。

修复转换保存路径清空重填时拼接旧名称的问题，保留用户修改的默认目标格式；修复归档预览被侧栏遮挡，选择文件时可直接看到新增格式及常见首卷。

兼容引擎更新到 7-Zip 26.04。修正 TAR 压缩流尾部未检查导致截断文件被当成成功的问题，并改善大条目解压的取消响应。
