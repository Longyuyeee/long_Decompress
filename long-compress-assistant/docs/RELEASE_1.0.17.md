# Long解压 1.0.17

本版本继续收口压缩中心的核心交互，并为密码保险箱补齐真实数据持久化、生命周期分析、长期统计与动态图表全景。

## 主要更新

- 压缩任务行统一显示压缩包名称、源文件路径以及压缩状态与进度，信息结构与解压中心保持一致。
- 压缩详情继续采用左侧配置、右侧阶段/进度/速度/当前文件/实时日志布局，选择文件后顶部操作区保持稳定。
- 密码强度由真实密码正文评估并持久化到后端，编辑已有密码不会清空创建时间、使用次数、最后使用时间或使用历史。
- 新增保险箱数据全景，展示安全指数、近 30 天活跃度、累计使用、风险项目、密码强度、分类分布和常用密码排行。
- 新增单条密码生命周期分析，展示创建、更新、最后使用、存放天数、使用次数和密码长度。
- 使用趋势支持 7 天、30 天、90 天和全部历史；全部历史会从最早密码或使用记录开始自适应聚合。
- 新增长期使用画像，包括保险箱使用时长、最早创建日期、历史月均使用次数和历史峰值月份。
- 图表增加折线绘制、渐变面积、节点弹出、环图轨道、分类流光、卡片错峰入场与悬浮光泽，并兼容系统“减少动态效果”设置。

## 已知限制

- 项目目前没有可信 Windows 代码签名证书，安装时可能出现 SmartScreen 提示；请仅从本项目 GitHub Releases 下载。
- 无可信代码签名证书时，公开安装包不会携带 Windows 11 顶层右键菜单身份包；传统“显示更多选项”菜单及一键解压/打包继续可用。
- RAR 解压继续受支持；创建 RAR 仍需要本机安装 WinRAR。
