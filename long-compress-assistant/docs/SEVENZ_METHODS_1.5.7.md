# v1.5.7 7Z 方法兼容

从 v1.5.6 发布后主线 `b9b5292` 接续，按十版路线第二项补齐现有 7Z 读取，不改变默认压缩算法，不新增格式入口。

## 实际缺口与范围

`sevenz-rust 0.6.1` 目前启用 aes256；PPMd 没有方法登记/解码器，Deflate 和 Deflate64 只有名称，Bzip2 解码分支因特性未启用而不可达。LZMA/LZMA2、Copy、AES、Delta、常见 BCJ 与 BCJ2 已有实现，不计新增。Zstd 及其他新过滤器未取得本轮原版生成证据，不承诺支持。

本版在现有原生流式读取中接入 PPMd7、Deflate、Deflate64 并启用 Bzip2，复用已有依赖版本、CRC、固实顺序、数字卷拼接、路径过滤及事务。无需外部进程回退，错密或损坏不重试另一引擎。明确不支持方法/内存限制不应吞为密码不匹配。

## 验收顺序

1. 原版 7-Zip 24.09 生成固定载荷，随附 26.04 独立读回；四方法分别覆盖普通非固实、固实、内容密码、文件名密码数字卷，另回归 LZMA2/BCJ2。保留工具身份、参数、原卷和载荷哈希。
2. 修改前真实红测；修改后整包、过滤、浏览、所选、密码纠正、检查、转换，以及损坏/缺尾卷不发布验证。
3. 桌面使用真实文件和命令，不注入成功状态；常用/窄窗页面实看。生产构建与测试程序分离，不改变个人安装和数据。
4. 审计推送、受保护合入后固定标签；更新 README、中文 Release/更新说明与安装器，回下载核对四资产，再回填发布收据。

原包/范围提交 `600881c` 已推送。修改前相同测试真实失败，列出四方法十六组整包/过滤共 32 个 UnsupportedCompressionMethod；LZMA2、BCJ2 对照通过。补齐原生读取后 18 项 7Z Rust 定向测试通过（含 18 组原包各整包/过滤、错误分类、CRC、缺卷、盘满及取消），前端四文件 150 项通过；正在进行真实桌面与最终生产构建，尚未封板发布。

PPMd 使用现有锁定 [ppmd-rust 1.4.0 Ppmd7Decoder](https://docs.rs/ppmd-rust/1.4.0/ppmd_rust/struct.Ppmd7Decoder.html)，对应 7z 的 PPMdH 范围编码。Deflate/Deflate64、Bzip2 也复用已有锁定依赖，不升级其他依赖或引擎。新增许可原文随包保留。
