# v1.6.57 · LZOP 单文件读取与转换

- 新增普通 `.lzo`（LZOP 容器）读取，支持常见 LZO1X 三种方法、未压缩块、多块和空文件；直接沿双栏文件浏览器查看、预览并取回。
- 接通文本/图片预览、文件完整性检查、解压及转换 ZIP/7Z，完成结果与历史保留原 LZOP 来源。转换后的密码和分卷按目标格式提供。
- 头与数据块按原件携带的 Adler32/CRC32 检查，截断、校验错误及不支持的参数保留明确原因和下一步；修正单文件流提取未遵守所选条目的问题。
- 大文件列表沿用有界读取，无法确认整体大小时显示未知；文本预览沿用前缀和预算，保留完整提取入口。单条展开、多选弹窗、等宽双栏、主题与快捷键保持。

本版只读单成员 LZOP，不支持裸 LZO、创建、原生密码、数字切卷、多部分、附加非零过滤器或多成员。`.tar.lzo` 本期可先取回一个 `.tar` 文件，直接目录浏览安排在 [v1.6.58](ARCHIVE_ROADMAP_1.6.58.md)。未携带数据校验的来源仅能检查结构和解码结果，不能证明内容未改变。

实现与检查见[封板记录](LZOP_READ_CONVERT_FREEZE_1.6.57.md)。正式附件由标签流水线生成，源码/合并和附件状态在本版 PR 接续。
