# Long解压 v1.3.6

修复较早任务历史被静默删除的问题，并提供逐页加载更早记录。

- 保存新任务不再删除第 500 条之外的历史。默认保留至你主动删除或清空，数据会占用本机磁盘；旧版已经删除的记录无法恢复。
- 历史页每次加载 100 条，可继续加载更早记录；相同完成时间使用任务 ID 稳定排序，加载失败保留已加载列表并允许重试。
- 刷新与清空不再被迟到的查询结果覆盖，单条删除后旧请求也不会重新显示该记录。
- 筛选无结果时仍可继续加载。界面明确说明筛选、统计和趋势只覆盖已加载记录，不冒充全库搜索。

验证：前端 406 项、Rust 库 406 项通过（12 项按既有条件忽略），严格 Clippy、类型检查和生产构建通过。真实 Windows ZIP/失败恢复回归及 505 条合成历史经真实 SQLite 保存、重启、页面翻页查找通过；505 条夹具不是 505 次真实解压。

暂未实现全库搜索/聚合、自动保留策略设置或未保存结果跨重启恢复。降级到旧版前应备份历史，旧版保存时可能再次清理 500 条以外记录。Windows N 暂不支持。
