# Long解压 v1.4.1

本版让批量调整任务、找到完成结果和从资源管理器处理压缩包更方便，保留原来的点击行内展开交互。

## 一次调整所选任务

- 压缩中心可勾选文件或压缩组，在列表内修改 ZIP/7Z 格式、压缩等级和输出目录。
- 解压中心可为所选待处理任务统一修改输出目录，以及是否创建同名子文件夹。
- 每项初始为“保持各自设置”，只应用明确指定的参数；其余设置、密码、名称和未选中任务保持原值。
- 全局配置仍提供默认值。仅展开查看不会改变配置；编辑某条或所选任务后自动保留各自配置，不需要选择“全局 / 单独”模式。
- 批量操作栏选中后才出现，随任务列表滚动；窄窗口允许换行，单条详情继续在原任务下方展开。

## 在当前页面找到结果

- 压缩、解压、归档转换、图片、视频、PDF、历史和全局任务面板使用统一结果操作。
- 解压结果可打开实际输出目录；压缩和转换结果可定位文件或首卷，并复制实际结果路径。
- 分卷清单在当前卡片展开。全局完成结果可批量打开目录或复制路径，同一目录只打开一次。
- 旧结果移动或删除时显示可读提示；没有产物的图片跳过任务不显示新结果按钮。

## Windows 压缩包右键入口

- 新增“转换压缩包格式…”和“修改密码 / 调整分卷…”，直接带入所选压缩包进入现有转换表单。
- 原包密码和新包密码分开设置，支持更换或移除密码、重新分卷或合卷；原包保留，用户配置后手动启动。
- 多选原包可在同一表单逐个切换、配置和执行；已有草稿或运行中的转换会保留。

## 使用说明

- 批量配置用于未提交、未开始的任务；压缩批量格式先提供 ZIP/7Z，其他格式继续在单条设置中选择。
- 已启用 7Z 文件名加密的任务改为 ZIP 时，会提示先处理该选项，不会悄悄关闭加密或部分修改其他任务。
- 新右键入口在安装本版后生效，沿用现有 Windows 菜单集成；转换格式范围沿用 v1.4.0，多选入口不会自动批量转换。
- 本版不包含跨重启草稿恢复。安装前请先完成或停止正在进行的任务，再退出旧版。
