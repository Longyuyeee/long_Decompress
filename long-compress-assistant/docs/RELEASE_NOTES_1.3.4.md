# Long解压 v1.3.4

本版修复视频/PDF 跨页面控制，以及视频取消后的暂存残留。

- 视频和 PDF 开始处理后，切换到历史或其他工作区再返回，仍可控制原批次；不会因为页面重建而失去取消按钮。
- 输出路径规划、执行和历史保存期间保持同一批次运行锁，防止重复启动。
- PDF 文件列表、任务关联、已确认配置和输出目录在本次运行中保留；未提交的密码在离开页面时清空，不写入持久配置，不承诺重启恢复草稿。
- 视频在结果验证阶段取消时，等待 ffprobe 退出并释放文件后再清理，修复 Windows 上已显示取消却残留编码暂存文件的问题。

验证：前端 387 项、Rust 库 405 项通过（12 项按既有条件忽略）；真实视频/PDF 页面开始→切历史→返回取消→核对源文件和暂存→重启查历史通过。原生选择器路径响应由测试桥提供，未冒充原生窗口验收；正式包不含测试桥。

Windows N 仍暂不支持。本版不改变编码参数、PDF 优化策略或历史保留上限。

后续优先开发失败后的对应操作，再完善历史保留/检索和未保存结果重启恢复。
