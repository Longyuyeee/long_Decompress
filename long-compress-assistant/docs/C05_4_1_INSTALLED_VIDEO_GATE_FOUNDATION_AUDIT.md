# C-05.4.1 正式安装版视频门禁基础审计

日期：2026-08-29

## 结论

**C-05.4.1 的正式安装版视频工作区门禁实现已完成，正式 NSIS 生命周期证据尚未执行，因此 C-05.4.1 与 C-05 均未关闭。** 新门禁只接受无桌面 E2E 桥的生产二进制，通过生产 Tauri 文件拖放进入实际视频工作区，并用同一 114,842,332 B 真实 AVI 分别验证编码中取消和完整发布。

本节点先提交并推送门禁及运行时纠偏，使后续正式 NSIS 可以从干净、可追溯的提交构建。当前预演使用无测试桥 Release 二进制，不得冒充“已安装候选”或公开发布证据。

## 与最初需求对齐

`config/media-release-gates.json` 要求安装版具备生产桥、真实完成/取消、输出复核、跨重启历史、候选生命周期及上一版本恢复。原仓库只有安装目录 FFmpeg 预检/转码冒烟，没有从安装版可见视频 UI 执行、取消、默认播放和重启历史的门禁。本次补齐：

- `test:installed-video-workspace`：先复现固定长时长/大文件样本，再运行生产桌面门；
- `test-installed-release.ps1 -RunVideoWorkspaceMatrix`：候选覆盖安装后从真实安装路径执行该门，并把机器结果纳入安装生命周期目录；
- 媒体架构门固定无测试桥、真实 FFmpeg 进程、取消无发布、产品 ffprobe、默认应用及完整重启历史约束。

正式门使用与源文件同目录的产品默认输出策略，不调用测试对话框队列；文件通过生产 Tauri `tauri://file-drop` 事件进入。每次运行使用唯一中文文件名，避免复验时把旧历史误算成本次结果。

## 无测试桥生产预演结果

机器结果位于忽略目录 `test-results/installed-video-workspace/result.json`：

- 输入：114,842,332 B，SHA-256 `240682ed61e9b09dcbb461fd1e76f4dccc3184144aa759b676820d8ce02b8d26`；
- 取消：观察到与唯一中文输入匹配的产品 FFmpeg PID；取消后进程退出、最终输出不存在、`.video-encode-*` 为零、源哈希不变；
- 完成：输出 8,410,052 B，SHA-256 `53f6281593c8584d4fbac7cc760208d7a8adbec0a2fa80dd0f460337f4215f45`；
- 产品 ffprobe：MP4/H.264、1280×720、32.000 秒、无虚构音轨；
- 默认应用：可见结果按钮收到“已将视频交给系统默认应用播放”；
- 历史：当前会话一条 `已取消`、一条 `已完成`，原生应用完全退出并使用新 WebView profile 后仍精确保留。
