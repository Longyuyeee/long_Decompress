# v1.7.25 · ZIP 顶层目录与目录时间封板

日期：2026-10-28。

## 实现与用户行为

新增 ZIP 专用保留结构收集入口，顶层文件夹（含非空根）先获得独立目录头。按来源顺序预留不区分大小写的根名称，不同位置的同名根及文件/目录根冲突统一改名整个子树，修正旧流程逐条改名后把目录内容混放的问题；同一规范来源重复加入仅收录一次。单一正常根内路径保持。扁平创建和 TAR / 7Z 沿原收集器，没有修改它们的布局；旧 ZIP 日期检查的样本清单改用实际 ZIP 收集入口，避免把新增目录头误当多余条目。

解压完成整理暂存后，读取实际 ZIP 目录头，按原选择范围和暂存内仍保留的路径收集日期；提交前重查原包/卷组版本。复用现有目录时间清单及冲突等待对象，在最终内容提交、暂存清理后由深到浅恢复，并沿原日志反馈目标文件系统无法保留时间的情况。冲突确认不重解压、不重读目录日期。只选文件、扁平模式或关闭保留时间时不套用父目录时间；缺少实际目录头或重复歧义目录不编造日期。采用原 ZIP 本地 DOS 两秒日历，UTC / 亚秒与权限/所有者不扩展。

普通解压、精确所选、AES / ZipCrypto、数字/标准卷和转换复用原入口。TAR.LZO 已确认链接转换后可保留新包中明确编码的 `docs`、`gallery` 顶层目录日期。UI、单条展开、多选弹窗、左右等宽及结果/历史入口不变，没有新增常驻配置。

## 检查与证据

- 新原生 6 项首轮执行均通过：ZIP 根独立/同名子树一致/规范来源去重及旧布局保持；ZIP / ZIPX、AES / ZipCrypto、数字/标准卷创建与完整验证、最终目录树及日期；所选目录、仅文件、筛选、扁平及时间关闭；待确认冲突沿原暂存与时间清单继续提交、原有及无关文件保持；隐含/歧义目录不伪造时间及取消；TAR.LZO 链接内容转换到校验后提交的密码 ZIP / ZIPX。
- 相关旧收集器 2 项通过，确认既有扁平重名与混合空根规则保持。测试开始前修正暂存类型名称为 `ExtractionStaging`；执行后无新测试失败，不重跑已通过项。
- 6 份实际归档、74 个编码条目的本地头/中央目录日期由独立 Python 解析核对，再用独立 7-Zip 取回比较文件 SHA、显式目录与文件日期。项目原生最终输出另核对精确目录树、全部日期和内容；转换结果与固定 SHA 的原 GNU TAR 逻辑内容/时间比对，四份加密结果拒绝错误密码，原件保持。所选结果的目录时间与仅文件父目录策略另行核对。独立脚本兼容未提供 nanos 的零亚秒源记录，未重跑原生样本。
- 原生检查使用与生产相同的创建、所选解压、暂存整理、事务提交和最终目录恢复函数，未使用桌面 IPC 或控制电脑。Shell DLL、八处版本身份及差异空白通过；UI 源码未改，未重复 UI/前端及无关格式矩阵。正式前端/Windows 构建、安装器与签名更新附件由对应提交 CI/Release 接续。
