# D-03.2 PDF 候选验证与失败矩阵审计

审计日期：2026-08-31

节点状态：**完成（真实低容量卷仍列入后续发布前门禁）**

执行边界：**内部暂存候选验证；不注册产品命令、不原子发布、不创建任务或历史**

## 1. 目标与需求对齐

D-03.2 消费 D-03.1 的所有权暂存候选，在任何发布动作之前执行真实 qpdf `--check`，并比较源文件与候选的页数、加密状态、页面 MediaBox、表单字段身份、注释所在页/类型、书签标题/目标页及附件名称、字节数和 SHA-256。候选变大时默认拒绝；验证期间取消、候选损坏或目标竞争均不得产生最终输出。

本节点仍没有 Tauri 产品命令、输出锁、原子发布、UI 执行入口、任务或历史。“已验证”只是一份绑定当前暂存文件字节的内部报告，不能被写成用户任务完成。

## 2. 真实代码

- `pdf_output_validation.rs` 对暂存路径重新读取普通文件身份和实际字节；若与 D-03.1 守卫记录不同则失败关闭。候选在结构验证前后分别流式计算 SHA-256，摘要或字节数变化返回 `PDF_OUTPUT_CHANGED_DURING_VALIDATION`；内部验证报告携带最终 SHA-256，供下一发布层绑定同一组字节。
- qpdf `--check` 只接受退出码 0；候选警告或错误均不进入可发布状态。
- 详细 JSON 固定读取 `pages/acroform/attachments/outlines/qpdf`，上限 32 MiB；进程可取消、120 秒超时，取消后终止并等待子进程。
- 附件使用独立参数 `--show-attachment=<key>` 读取实际 stdout，单附件上限 64 MiB、合计上限 128 MiB，并计算 SHA-256；不把文档内容写入日志。
- 输出大于输入返回 `PDF_OUTPUT_LARGER_THAN_SOURCE`；最终目标在验证前出现返回 `PDF_OUTPUT_TARGET_APPEARED`，不覆盖用户字节。
- `run-d03-pdf-validation.mjs` 生成结构化 expected/actual 证据；同时调用独立 pypdf 检查器比较页面文字/尺寸、图片数量、表单值、注释内容与位置、书签目标和附件正文，避免只依赖 qpdf 自证。

## 3. 真实样本结果

8 类可执行 PDF 分别运行两种模式，共 16 个真实候选：

| 输入 | 输入 B | 无损整理 B | 图片优化 B | 结构事实 |
| --- | ---: | ---: | ---: | --- |
| `text-vector.pdf` | 1834 | 1186 | 1192 | 1 页，独立事实相同 |
| `scanned-image.pdf` | 34915 | 24466 | 24466 | 1 页，独立事实相同 |
| `mixed-content.pdf` | 35373 | 24675 | 24675 | 1 页，独立事实相同 |
| `transparency.pdf` | 2109 | 1283 | 1291 | 1 页，独立事实相同 |
| `form.pdf` | 8589 | 5084 | 5089 | 2 字段、1 Widget 注释保持 |
| `annotation.pdf` | 1409 | 1057 | 1067 | 1 个 `/Text` 注释保持 |
| `outline.pdf` | 2111 | 1290 | 1301 | 2 页、2 个标题及目标页保持 |
| `attachment.pdf` | 1639 | 1207 | 1215 | 1 个附件名称、字节和 SHA-256 保持 |

输出字节会因 qpdf 文件标识等序列化细节在重复运行间有少量变化，因此自动门禁只要求非零且不大于输入，不把上述观察值固化成压缩率承诺。16 个候选均未生成最终文件，源 SHA-256 均未变化，所有守卫 Drop 后暂存消失。
