## 原生实现与边界

原锁定 sevenz-rust 没有 ARM64 方法与转换核。本版注册标准单字节 0x0A，参考 XZ arm64.c 以 Rust 适配 BL / ADRP 转换，来源作者及 0BSD 原文在[原生实现](../src-tauri/vendor/sevenz-rust/src/bcj/arm64.rs)与[0BSD 原文](../src-tauri/vendor/sevenz-rust/src/bcj/ARM64-0BSD.txt)保留；全程使用 u32 wrapping。固定 8 KiB BCJ 流式适配新增 ARM64 构造，保留 x86/ARM32/Thumb 路径。四字节扫描与指令边界和最多三字节尾部跨 write/flush/固实条目保留，普通 flush 不终止不完整指令。结束仅排出一次尾部并结束后续编码器，失败保持失败。

输出空属性；读取接受空或四字节小端、四字节对齐的起点属性，错误长度及未按四字节对齐的起点拒绝。指令处理与对齐参照 [XZ ARM64 实现](https://github.com/tukaani-project/xz/blob/master/src/liblzma/simple/arm64.c)和[过滤器初始化](https://github.com/tukaani-project/xz/blob/master/src/liblzma/simple/simple_coder.c)，以独立字节原件核对；7Z 标识参照 [7-Zip 注册](https://github.com/ip7z/7zip/blob/main/CPP/7zip/Compress/BranchRegister.cpp)。

完整小图文走原共享完整读取，保留所有可用 CRC 与完整 AES 消费检查。大文本开头仅接受严格的可选 AES + LZMA2/LZMA + ARM64 单进单出链；所选条目前置、开头与最多三字节前看计入原 64 MiB 解码预算，take 限制过滤器读取。取消、来源变化、未校验整文件提示与提取全文下一步保持。
