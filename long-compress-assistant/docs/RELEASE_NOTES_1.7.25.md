# v1.7.25 · ZIP 顶层目录与目录时间

ZIP / ZIPX 保留目录结构时，非空顶层文件夹现在有独立条目和自己的修改时间；解压完成后再恢复目录日期，避免写入子文件把日期改成当前时间。

- 不同位置的同名文件夹各自保留并统一改名整棵子树，同一来源重复加入只收录一次，内容不再混放。
- 正常/所选解压、密码、分卷和转换保持衔接；冲突确认后沿保留的时间清单继续提交，无需重新解压。
- 只选文件、扁平解压或关闭时间保留时，不套用父目录日期；隐含及歧义目录不伪造日期。
- 保留原界面、单条展开、多选弹窗和等宽双栏，扁平创建与 TAR / 7Z 路径规则保持。

ZIP 日期继续采用本地两秒精度与现有年份边界。本版不增加格式数量。见[本版范围](ARCHIVE_ROADMAP_1.7.25.md)、[实现与检查](ZIP_DIRECTORY_TIME_FREEZE_1.7.25.md)。下一阶段 [v1.7.26 TAR 目录结构与同名来源一致性](ARCHIVE_ROADMAP_1.7.26.md)仅规划。
