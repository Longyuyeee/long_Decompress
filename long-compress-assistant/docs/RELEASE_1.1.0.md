# Long解压 1.1.0

本版本收口 Windows 经典右键菜单的实机故障，并完成前端构建与测试工具链的安全主版本迁移。版本号提升到 1.1.0，作为后续真实桌面 E2E、格式证据持续化与性能趋势工作的稳定基线。

## Windows 资源管理器菜单

- 修复 v1.0.23 在部分 Windows 11 实机上只显示 Long解压 父项、没有二级菜单的问题。
- 父项不再退化为打开所选文件，因此点击后不会再触发“没有与之关联的应用”错误。
- 经典级联结构改用空 `SubCommands` 值和父项下的内联 `shell` 子键；四类菜单根继续提供 17 条命令。
- Long解压、一键解压到同名文件夹和一键打包为 ZIP 统一声明 `Position=Top`，保持同组连续排列。
- 安装、公开更新与运行时状态检测会同时校验级联标记、命令数量、程序路径和顶部排序。

## 工具链与安全

- Vite、Vue 插件、Vitest、V8 覆盖率和 vue-tsc 更新到 `8.2.1 / 6.0.8 / 4.1.10 / 4.1.10 / 3.3.9`。
- Node 约束统一为 `^20.19.0 || >=22.12.0`，与 GitHub Actions 的 Node 24 对齐。
- 完整 npm 审计由 7 项开发工具链漏洞降为 0；生产依赖审计保持为 0，没有使用 `npm audit fix --force`。
- Vitest 4 的覆盖率配置已迁移到真实 AST 重映射结果，消除假 `0/0`，并保留防倒退阈值。

## 验证范围

- 版本身份、干净 `npm ci`、类型检查、163 项单元测试和 184 项覆盖率测试。
- 5 项集成测试、17 项性能测试以及 Chromium、Firefox、WebKit 和移动端共 25 项浏览器 E2E。
- Rust Release 全目标测试、Clippy `-D warnings`、Shell Extension 构建与正式 Tauri Release 构建。
- Windows CI 的桌面 E2E 构建和 NSIS 安装包门禁。
- 真实 Shell 动词验证一键打包生成非空 ZIP、一键解压逐字节还原内容；四类菜单根均使用新级联结构。
- 在真实 Windows 11 环境完成 v1.0.23 → v1.1.0 覆盖升级、用户数据保留、右键菜单注册、候选版卸载及 v1.0.23 回装恢复，共 41 项检查全部通过。
- 本地 NSIS 安装包 `Long解压_1.1.0_x64-setup.exe` 已验证产品版本为 1.1.0，SHA-256 为 `F65EC14F33BCFE515ABCB73F91777E3BA1F5CA20B5785BDAEA81E07D0A7F18AF`。

## 签名边界

本版本不配置 Windows Authenticode 或商业代码签名证书，也不分发 Windows 11 新式第一层菜单身份包。右键菜单能力位于“显示更多选项”的经典菜单；Tauri 应用内更新包继续使用独立更新签名保证完整性。
