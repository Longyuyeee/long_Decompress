# v1.5.52 · 目录触发与运行队列

## 把资料放进目录，让方案接着做

- 工作流中心增加“目录与队列”。绑定已保存方案、监控目录和保存位置，明确启用后自动执行；也可先保存为暂停。
- 可按每个文件/整组分卷处理，或按每个顶层项目文件夹分别归档；支持扩展名、子目录范围与 3～300 秒稳定等待。
- 新规则默认只处理创建后新增或变化的内容，勾选后才接收已有资料。复制中的文件继续等待；缺卷显示具体原因，补齐并稳定后入队。
- 同组分卷作为一份来源，重复通知和未变化版本不重复执行。注册过的输出位置持续排除，避免新结果再次触发循环。

## 等待、执行与结果在一处查看

- 集中查看等待稳定、等待分卷、排队、待补密码、运行和完成记录，可按状态筛选；规则点击展开，创建/编辑放在弹窗中。
- 支持暂停整个队列、暂停单条规则、取消待执行项与明确重新加入。暂停不打断已开始的运行，运行中可停止本次处理。
- 一次执行一套工作流，手动工作流运行或确认弹窗打开时自动等待；切换页面或托盘驻留仍可处理，执行与并发控制沿用现有任务链。
- 排队项保留加入时的方案和保存位置，之后编辑方案不会暗改已排队内容。来源变化会重新等待，开始前再核对当前来源与卷组。
- 失败/停止保留原运行和已有产物，不反复自动重试。可进入原流程纠正继续，队列随后指向最新接续结果，并保留原触发运行入口。

## 重开应用后，保持清楚的状态

- 规则、等待项、队列暂停选择和运行关联保留。正常退出先停止派发并保存；已经开始的中断执行供用户查看和手动接续，不自动重复启动。
- 需要输出密码时先等待本次会话密码，来源密码和 ZIP/ALZ/EGG 编码可分别提供，并复用原保险箱。密码不写规则、队列或执行快照，重开后重新填写。
- 删除规则取消未开始的项目，保留正在运行的任务、旧记录和文件。原监控功能仍只生成待确认草稿。
- 单条展开、多选弹窗、自然继承和压缩/解压左右等宽保持。新增区域宽窗分区、窄窗顺排，长路径换行、列表及弹窗可滚动。

本版在应用运行或托盘驻留时工作，不提供退出后的系统唤醒或定时任务。目录触发复用已有格式、密码和分卷能力，未新增算法；分卷完整性沿当前检测器判断，稳定观察依据路径、大小、修改时间及 Windows 写入占用，不宣称仅凭元数据核对内容相同。
