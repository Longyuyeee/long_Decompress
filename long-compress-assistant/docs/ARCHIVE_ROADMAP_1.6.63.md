# v1.6.63 候选 · Windows 打开与双栏浏览体验

根据用户 2026-10-26 的确认，优先处理 Issue #315 和本轮浏览/历史界面问题。代码身份仍为 v1.6.62，本文件是下一版本候选范围，不表示已经发布。

1. 设置中选择默认打开格式并跳转 Windows 确认，显示实际关联状态。打开行为默认询问，提供当前目录、同名目录、自选目录、双栏浏览四项；可保存默认行为，解压完成可显示结果或打开文件夹。
2. 打通 Windows 裸文件参数、专用打开参数及已有实例入口；明确右键动作直接执行；处理运行中排队、已完成包再次打开、分卷去重、目录选择取消和实际结果路径。
3. Windows 经典/原生菜单增加自选目录，把转换、密码分卷、完整检查与救援收进更多操作，去掉重复快速解压入口。
4. 普通目录与包内共用导航和列表；保留两栏、路径、行高、列头、单击/Ctrl/多选模式、文本图片预览、目录返回及另一栏状态。密码、搜索、编码、编辑等收进选项，不把解压目标再铺一块。取回所选文件夹时保留范围内空目录。
5. 历史页再次执行与结果入口同排，更多结果操作使用浮层菜单。

实现与功能/UI 记录见 [本轮交接](WINDOWS_OPEN_AND_BROWSER_UI.md)。TAR.LZO 目录创建与转换顺延，原计划完整保留在 [后续格式主线](ARCHIVE_TAR_LZO_NEXT.md)。
