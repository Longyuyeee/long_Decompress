# v1.5.23 LZMA 数字分卷与查看流程

2026-10-20，接续 v1.5.22 与既定 v1.5.23～25 路线。

## 范围与开发状态

- 已有原生 LZMA-alone 创建沿用；本版接通数字切卷、首中尾成员进入、浏览/有界文本和图片预览、检查、提取、转换及补卷新任务。
- 前后端能力表修正旧的 7-Zip 创建依赖说明，沿已有事务切卷，不新增卷格式。LZMA 没有原生密码，本版保留既有 7Z 密码替代；Long AES 和 TAR.LZMA 按下一版规划处理。
- 统一流解码入口采用 LZMA-alone 解码器，截断/未识别尾随数据不算完整；不是 ZIP/7Z 中的 LZMA 方法，也不是 XZ 容器。摘要体积分析同步使用真实 LZMA-alone 编码。
- 转换增加单文件 LZMA 目标并保留数字分卷设置；多文件和目录提前提示选择 TAR 组合，旧有单条展开、多选弹窗、自然继承、等宽和窄窗滚动保持。

独立原件由 Python 标准库 FORMAT_ALONE 生成，含中文文本、空文件、PNG、随机二进制、大文本和非默认属性。手工改未知大小头的尝试未通过独立解码，未纳入有效原件。接续定向回归和真实桌面证据，不重跑旧格式及盘满矩阵。
