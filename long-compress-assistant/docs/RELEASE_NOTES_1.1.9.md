# Long解压 v1.1.9

v1.1.9 集中收口 v1.1.7 之后确认的 Windows 持久化、密码保险箱、历史任务和窄窗口资源预检问题。v1.1.8 仅作为内部修复候选，没有正式发布；本次以新的补丁版本交付全部修正。

## 主要修复

- 移除未签名主程序的用户级开机自启动入口与 `Run` 注册表读写；安装与更新会清理历史启动值，同时保留密码保险箱、任务历史和其他用户数据。
- 解压服务改为读取密码保险箱实际使用的文件库，按收藏、使用频率和最近使用优先尝试；读取失败不再误报“密码本为空”。
- 真实加密归档命中保险箱密码后，原子更新调用次数、最近使用时间和本地自然日趋势；复制密码使用相同记录路径。
- 历史任务详情使用完全不透明的表面，紧凑窗口中的状态、完成时间和箭头保持单行且不互相挤压。
- 左侧栏增加由原生应用版本驱动的版本角标。
- 密码保险箱统计改为解压场景语义：整库展示真实调用、归档线索和长期活跃；单条展示独立使用档案，不再使用传统账户密码强度、风险、轮换、到期或正文长度指标。
- 压缩和解压共享的目标存储预检卡改为最多两列、极窄单列，目标位置、存储介质、剩余可用和预计占用不再被挤成竖排文字。

## 发布门禁

- 前端单测、类型检查与生产构建；Rust 全目标测试与 Clippy；Shell Extension COM 测试；Chromium 浏览器 E2E。
- 真实 Windows 桌面门禁覆盖加密 7Z 保险箱命中与当天趋势、历史任务真实 ZIP 回环和重启恢复、资源预检真实 ZIP 压缩/解压与布局断言。
- GitHub Release 必须同时提供 NSIS 安装包、更新压缩包、更新签名和可解析的 `latest.json`。

## Windows 集成说明

项目仍没有商业 Windows Authenticode 代码签名证书，因此公开安装包不会分发 Windows 11 新式第一层菜单身份包。“显示更多选项”中的 Long解压 经典菜单、一键解压、一键打包和浏览压缩包继续可用。应用内更新包使用独立更新签名校验完整性。
