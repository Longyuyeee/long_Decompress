# v1.6.36 · Deflate 非固实大文本开头预览

## 完成范围

按[本版路线](ARCHIVE_ROADMAP_1.6.36.md)接通普通 Deflate 与有序 AES → Deflate 非固实 7Z 大文本，最多读取前 1 MiB。新增独立 read_deflate_entry_prefix，确认唯一普通非固实条目、声明大小与 coder/流/绑定映射，固定 32 KiB 输入/输出块并限制返回缓冲。大型声明不会转为全文分配或整包读取目标。发现原始流提前结束、已观察到的 Deflate StreamEnd 短于声明、损坏或无进展则报错；到达开头上限后即返回，未读尾部、完整压缩消费、CRC 和载荷 AES 消费不作完整成功声明。

密码载荷复用显式 PreviewAes::new_prefix，检查 AES 顺序/参数与声明密文对齐，完整目录头和其他已创建的完整 AES 流仍保留独立消费回执。内容/文件名加密、原手动密码/保险箱、完整数字卷/非首卷接通；手动错误不回退，不记整包密码成功。实际输入 ≤64 MiB、参数、候选整体时间、读取中取消与来源绑定沿用。文件声明或压缩声明可大于实际读取预算，但实际读取仍受限。

沿原双栏只读文本窗口、编码/滚动，显示“部分内容 · 未校验整文件”和“提取后打开”。UTF-8/BOM、UTF-16LE/BE、GBK 的字符边界沿用已存在的裁切逻辑。完整小文本、图片、固实完整图文和其他 codec 的完整/部分读取方法保持；仅删除已被替代的旧非固实大文本不支持断言。固实大文本与 Deflate64 继续给提取下一步。保留单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键，仅扩展原问号说明；无新增依赖、许可或格式计数变化。

## 必要检查与证据

原版 7-Zip 26.02 生成普通、AES 内容、AES 文件名和完整数字卷四组非固实 Deflate 原件，官方 26.04 独立逐文件回解 SHA-256，确认方法和 Solid -。数据含精确方括号/相邻路径、完整小文本、精确 1 MiB/刚超出、五种字符截断边界、二进制；另有独立回解的固实/Copy 范围样本、普通/加密单日志与 65 MiB 大文本。受控压缩尾部/开头损坏由独立工具确认完整性失败，见 tests/fixtures/archives/sevenz-deflate-text-prefix-1636/manifest.json。取材时初始普通尾部变动落在忽略的 Deflate 填充位，独立工具正确接受；将变动移至压缩数据内倒数 32 字节后确认完整性失败，保留有效原件，修正后才启动后端检查。初始/完成取材日志随证据保留。

两项新部分适配单元通过：普通/部分 AES 的三字节短读精确返回开头，未读尾部、错误 CRC 仍明确未检查，32 KiB 实际读取不随巨大声明增长；已知短于声明、读取中取消和其他完整 AES 回执不能被豁免。五组后端通过：四组原件与每个数字卷成员、五种编码边界/精确大小；保险箱和手动错误不回退/计数保持；损坏尾部仅部分显示、完整读仍失败、完整小文本与错误 CRC、未开放范围/二进制；取消/来源/缺卷和 65 MiB 文本；映射/方法/AES 参数/大小与读取中取消，部分结果不冒充 CRC 成功。完整小文本仅补同一入口连续性，不重复旧方法、固实/图片矩阵、安装或真实盘满。

类型/Vite、八处版本身份和新 Shell DLL 通过。四组实际 Tauri 桌面通过：原文本窗口明确部分/滚动和提取全文入口；普通、内容加密、非首加密卷与五种字符边界、手动密码/65 MiB 文本；损坏尾部与完整性错误/未开放范围/二进制和完整小文本；取消/来源变化与新请求。1100×650 与 760×520 两张截图已实看，文本可读可滚动，部分范围和提取全文入口可见，无横向溢出，底层双栏等宽。候选 SHA-256 `9d20825e3cb38700dfaf102ff03cc7e741b4463ea94a81ca91cd1dd4f431cc23`，见[证据](evidence/sevenz-deflate-text-prefix-1.6.36/checks.json)。本地 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false；正式配置不改，入口 node scripts/test-tauri-desktop.mjs --sevenz-deflate-text-prefix-1636-only。

首轮桌面已通过窗口显示及原件/编码两组，未开放范围组因取材参数保留 -ms=off、实际为非固实包而未满足预期。仅移除该固实样本中的关闭固实开关，独立回解并确认 Solid + / Blocks 1；产品代码/候选 SHA 未变，保留先前两组结果与截图，仅继续剩余两组，最终四组通过。初始/修正与续跑记录均保留。
