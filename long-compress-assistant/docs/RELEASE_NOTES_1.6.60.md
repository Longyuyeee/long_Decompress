# v1.6.60 · LZOP 多成员资料直接浏览

同一个 `.lzo` 中的多个文件，现在可以在原双栏里分别查看、搜索和取回，不再要求用户先用其他工具拆开，也不会把几个文件拼成一个结果。

- 接通成员文本/图片和大文本开头预览、选择性取回、完整检查、整包提取与 ZIP/7Z 转换，保留结果和来源历史。
- 完整数字分卷仍可从任意一卷打开；成员重名使用稳定的区分名称，缺名称或无法确认编码时提供稳定成员文件名，避免覆盖合并内容。
- 完整提取时，后续成员校验失败会保留具体成员名，沿原暂存流程失败退出，不发布前面已经解出的半成品；修正原件后可以重试。
- 保留单条点击展开、多选弹窗配置、自然继承、左右等宽、主题和快捷键。设置中的 LZOP 名称不再限定“单文件”，没有增加格式计数。

支持已确认的独立完整成员序列，包括官方多文件包使用的 multipart 提示标记。它不等于原生块分段/跨文件多卷协议。TAR.LZO 保留原单流目录逻辑；带目录成员本版按文件名取回，未知旧名称编码不猜测。LZOP 创建、原生密码和缺卷内容救援仍不提供。成员列表读取结构与声明大小，前缀/所选预览不代替整包检查；没有数据校验的来源不能证明内容未变。序列没有总成员数字段，完整成员整段丢失不能仅靠剩余文件判断；不虚构完整性承诺。

封板验证和发布身份见[记录](LZOP_MEMBERS_READ_FREEZE_1.6.60.md)。下一阶段 [v1.6.61 成员路径与名称兼容](ARCHIVE_ROADMAP_1.6.61.md)仅规划。
