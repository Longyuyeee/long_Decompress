# v1.6.24 · 非固实密码大文本开头

## 功能与边界

按[路线](ARCHIVE_ROADMAP_1.6.24.md)接通 AES + LZMA/LZMA2 非固实大文本前 1 MiB，准确唯一普通文件、单独流与方法顺序确认后才读取。内容/文件名加密、完整数字卷任一有效成员沿原入口；手动密码不回退，留空沿原保险箱尝试，候选整体 30 秒、实际元数据/载荷输入合计 ≤64 MiB、字典/头范围 ≤64 MiB 保持。声明总大小不作为前缀分配量，65 MiB 原版独立流也可只读开头，不读无关大块。

明确部分读取的 AES 构造仅供所选独立前缀使用：CBC 仍处理短卷读取、对齐、密码参数/KDF 的取消和限时；检查声明压缩明文与密文对齐长度，若读到结尾仍检查填充/额外字节。提前停止不注册完整消费回执，不冒称已核对未读尾部、完整填充/结束、整文件 CRC 或整包密码。元数据与完整文本/图片继续注册并强制完整 AES 消费，完整 LZMA2 结束检查保持；不全局关闭条件，不记完整密码成功统计。只保留前缀，编码边界和二进制判断沿原实现。固实大文本和其他组合仍给提取指引。

原弹层明确“部分内容 · 未校验整文件”、已读/声明大小、滚动与“提取后打开”，复用原完整提取/默认应用流程。关闭取消、迟到丢弃与来源前后绑定保持；不改变单条展开、多选弹窗、50/50 双栏、侧栏/工具/主题/快捷键，格式数不变。

## 必要检查

四组原版 7-Zip 26.02 AES 非固实样本（LZMA、LZMA2、文件名加密、完整数字卷），经官方 26.04 独立回解逐文件 SHA-256 核对；侧例覆盖原版固实/Copy/65 MiB 声明总量，以及明确标注的密文开头/尾部和无关 65 MiB 块受控损坏。见 tests/fixtures/archives/sevenz-password-text-prefix-1624/manifest.json。首次准备脚本发现侧例重复 -p 与重跑数字卷不允许更新，修正参数/重入后保留并独立核对原件，不冒称软件缺陷。

四项新后端、五项前端（含受影响原弹层约定）、两项 AES 单元检查通过。AES 单元初次使用被原范围拒绝的 cycles-power 63，改用范围内 power 0 的自有明文/密文后仅续跑这两项；生产限制未放宽。首次编译命令尚未注册新模块而选中零项，不计通过；注册后四项执行通过。检查覆盖准确前缀/各数字卷成员、五种编码边界、保险箱错误候选后成功/手动不回退/不记成功、未读尾部部分与完整校验失败的区分、完整小文本 CRC、二进制/方法/错误密码、取消/来源/缺卷、无关大块跳过、完整 AES 回执仍强制及短读取/取消。

四组实际 Tauri 桌面检查通过：原保险箱打开文件名加密大日志；原窗口部分标记/滚动/全文入口及宽窄等宽双栏；两方法/非首卷和编码边界/65 MiB 声明量；未读损坏尾部与完整检查、错误密码/二进制/不支持提示；取消/来源/新请求及无关大块跳过。1100×650 和 760×520 CSS 窗口截图均已实看，无横向溢出，关闭与全文操作可见。候选 SHA-256 `50710e3681c1558d0b50b103032add9c00b763dfb2335f91600d51fe5a000c40`。见[证据](evidence/sevenz-password-text-prefix-1.6.24/checks.json)。前端类型/Vite 构建、八处身份及新 Shell DLL 通过；桌面候选 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置不改。不重复旧算法/密码/卷矩阵、安装或真实盘满。
