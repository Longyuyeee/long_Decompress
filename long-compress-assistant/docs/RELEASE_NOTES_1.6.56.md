# v1.6.56 · 可选 7Z RISC-V BCJ 预处理

- 原 7Z 折叠「高级预处理」增加 RISC-V BCJ，适用于 LZMA2 / LZMA，默认关闭；与无、Delta 及其他架构 BCJ 互斥，不按文件名自动启用。
- 原生引擎补齐 JAL、AUIPC 成对指令的转换与读取，使用标准 7Z 方法标识；处理两字节扫描、跨块尾部和 32 位位置回绕，可与独立 7-Zip 互通。
- 密码/隐藏文件名、固实/非固实、数字分卷及非首卷、配置组/预设/模板、草稿、历史、工作流、实际抽样分析与转换沿原流程接通。
- 完整图文、大文本开头和提取沿用原入口，必要前看计入原预算，保留部分内容与未校验整文件提示。
- 保留单条展开、多选弹窗、左右等宽布局和窄窗口换行。选择 BCJ 时收起并保留 Delta 距离；其他方法保留设置并显示暂未应用。没有新增格式计数或外部运行引擎，不保证所有文件压缩后更小。

实现和本版检查见[开发记录](SEVENZ_RISCV_BCJ_CREATE_FREEZE_1.6.56.md)。正式附件由标签流水线生成，状态在本版 PR 接续。下一阶段 [v1.6.57 LZOP 单文件读取与转换](ARCHIVE_ROADMAP_1.6.57.md)仅规划，回到格式扩展与真实失败包兼容主线。
