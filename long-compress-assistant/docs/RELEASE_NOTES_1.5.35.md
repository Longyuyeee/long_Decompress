# Long解压 v1.5.35

ZIP 新增 PPMd，为文本与资料归档提供更多选择，继续使用熟悉的密码、分卷和转换流程。

- **在原方法选项选择 PPMd**：默认仍为兼容 ZIP（Deflate）；Zstandard、BZip2 和 ZIPX 固定 XZ 保持原有行为，不会自动切换方法。
- **内存开销看得见**：选择 PPMd 后显示当前等级的字典占用，6级约32MiB、9级约256MiB；这是字典预算，运行时总内存还包括其他开销，多任务会叠加。有效等级1–9，旧配置中的0按1执行。
- **密码与分卷贯通**：支持普通包、AES-256、ZipCrypto，以及单包、数字卷和标准 ZIP 卷。任意成员可继续浏览、预览、检查及提取，缺卷补齐后可建立新任务。
- **转换和工作接续**：密码原包可转换为 PPMd ZIP，PPMd 密码数字卷也可转为新密码归档；配置组/模板、预设、草稿、历史与多选保留所选方法。
- **原交互保持**：单条行内展开、多选弹窗、自然继承、左右等宽及窄窗滚动不变。PPMd 按小批次处理数据，及时响应暂停、取消与进度；体积分析使用实际 PPMd 编码，不套用 Deflate 的预测。

PPMd 的效果取决于文件内容，不能保证更小或更快。接收方需要支持 ZIP PPMd（方法98）及相应加密、密码编码与卷型，部分系统内置解压器不支持；分享给未知环境时可沿用默认兼容 ZIP。PPMd ZIP 不是独立 PPMd 文件。
