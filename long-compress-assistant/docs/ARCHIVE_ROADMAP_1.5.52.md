# v1.5.52：目录触发与运行队列

2026-10-21，接续工作流手动执行及纠正接续。先写范围，再实施，完成后按正常候选、合入与 Release 发布。

## 用户交付

在工作流中心增加目录与队列页签，规则绑定已保存方案、监控目录、保存位置、文件/顶层文件夹范围、扩展名和稳定等待时间。用户明确启用；新规则默认只接新增/变化，勾选后才处理已有内容。规则点击展开，创建/编辑和本次凭据用弹窗，保留原步骤单条展开、多选弹窗、自然继承与压缩/解压 50/50 和滚动。

来源变化后等待稳定；分卷按原检测器归组，缺卷列明等待，补齐后接续。重复事件及同版本不重复派发，同来源运行时不并发触发。输出目录从监控范围排除，跨规则也不把输出变成循环输入。候选超过当前范围或目录不可用时明确原因，不将部分扫描冒充完整。

队列集中显示来源、规则、等待/排队/运行/完成原因，支持暂停整个队列、暂停规则、取消待执行项；运行仍沿既有顺序工作流及任务队列，不另造引擎。规则编辑不暗改已排队的方案快照；删除规则保留运行与产物。失败/停止只处理一次，不自动反复重试，从对应运行纠正继续。需要输出密码时等待本次凭据，来源密码可在本次提供，密码仅内存；重启重新提供，不写入规则或队列。

应用/托盘运行时监听；启动恢复明确启用的规则和未完成排队项，已开始但未结束的运行先关联原记录、标明中断，不静默重新派发。退出前停派发并保存，关闭失败保持应用；旧监控生成待确认草稿的行为不变。不做退出后的系统唤醒或定时触发。

## 实施

扩展独立工作流触发表，兼容旧方案/运行摘要。原文件通知作为变化信号，稳定观察、去重和队列持久化由本模块处理；运行前再次检查来源、分卷和启用状态。待执行使用确定的运行标识与队列关联，避免保存与执行间隙重复派发；取消/暂停在真正派发前生效。

界面有清晰统计、状态筛选、长路径换行和限高列表；宽窗分区、窄窗顺排，操作始终可达。检查只覆盖新增规则/去重/稳定/分卷/防循环/持久化、排队派发与退出，以及相关宽窄显示。不重复旧格式矩阵、真实盘满、媒体或个人安装检查。
