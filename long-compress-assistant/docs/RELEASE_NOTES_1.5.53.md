# v1.5.53 · 定时工作流与错过处理

把常用资料处理安排到合适的时间，并看清每次是否真正执行。

## 定时更直观

- 工作流中心新增定时规则：单次、每天、每周指定星期，直接选日期和本地时间，无需填写表达式。
- 规则显示下一次时间和最近状态，可暂停、编辑、立即运行，展开后查看固定来源、保存位置和最近运行结果。
- 定时规则与目录规则分栏切换，处理队列始终在旁；宽窗等宽、窄窗顺排，编辑与密码继续使用弹窗。

## 错过也有交代

- 应用退出、休眠或长时间挂起后，错过的时段显示“未执行”，可选择现在补跑或跳过，多次错过合并处理，不自动追赶所有历史次数。
- 同一方案忙碌时可排队等候或跳过；相同方案和来源已进入目录或定时队列时不重复派发。全局暂停仍控制新任务启动。
- 排队项保留触发时的方案、来源与保存位置；派发前重新检查来源和整组分卷，变化、缺失或仍在写入时说明原因，可处理后重新加入。

## 沿用熟悉的处理流程

- 每次运行使用独立结果目录，规则和队列可进入对应运行、失败纠正及实际结果；本次密码只在当前会话使用，重启后重新填写。
- 保留单条点击展开、多选弹窗、自然继承、压缩/解压左右等宽与滚动方式。
- **执行条件**：应用运行或托盘驻留；不提供关闭后的系统唤醒或后台服务。采用电脑本地时间，变更时区后可编辑或重新启用规则以重新计算。

工作流模块四阶段已完成声明范围。后续 v1.5.54～56 按路线推进文件夹与压缩包对比，再做整包图片阅读，之后回归算法、格式与容错兼容主线。本版不扩大格式和密码算法范围。
