# v1.6.50 规划 · ZIP 明确仅存储与低收益建议

仅规划、尚未开发。接续 7Z Copy，将常见 ZIP 的快速打包从隐藏的强度 0 变为原方法字段里的明确「仅存储（Store）」选择，保留既有配置语义和交互。

1. 扩展原 ZIP 方法与各配置路径，在单条/全局/多选弹窗中明确选择 Store，收起不适用的强度并保留原值。默认 Deflate；旧 Deflate + 等级 0 仍为 Store，旧 Bzip2/PPMd/LZMA/Zstandard 的 0 继续各自原映射，ZIPX 继续 XZ，不强行重解释历史设置。
2. 接通 AES/ZipCrypto 密码、数字与标准分卷、转换，以及配置组/预设/模板、草稿、历史和工作流；按真正 Stored 方法输出与计算大小，错误、取消、冲突仍走原结果/事务流程。源包算法与新包方法保持独立。
3. 原分析按真实 ZIP Store 抽样，不因文件后缀虚构收益；依据足够的实际样本提供可选的仅存储建议，明确采用后只修改当前任务的方法，保留密码、卷型、分卷和强度，不自动执行或新增常驻说明区域。
4. 用独立工具核对实际方法与逐文件内容，重点覆盖空项/CRC 0、密码、数字/标准卷和跨方法转换；只补新增/受影响检查与必要默认连续性，实际宽窄显示确认后同步 README/Release/交接。

后续继续增加格式/算法和真实失败样本的容错兼容；ALZ/EGG 缺原件的项保持明确待办，不以新增方法冒充新增格式支持。
