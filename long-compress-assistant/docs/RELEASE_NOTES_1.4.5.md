# Long解压 v1.4.5

这版围绕“有密码的坏包还能救回文件、更多归档能直接处理”升级，沿用原有单条展开和多选弹窗操作。

## 密码 ZIP 完整文件救援

- 密码 ZIP 部分文件损坏、目录仍可读取时，填写密码后可尝试恢复完整文件，支持 AES、ZipCrypto、ZIPX，以及完整数字卷和标准 ZIP 分卷。
- 跳过损坏文件，显示恢复数量和未恢复原因；部分恢复以警告呈现，便于核对内容是否齐全。
- 新包沿用填写的密码，统一使用 AES-256 和 UTF-8 编码。恢复前后都明确提示密码状态，不会默认导出明文。
- 填错密码后可纠正并重新检查；支持处理中取消。结果新增“定位新包”和“复制路径”，方便继续使用救回的文件。

## 新增 ARJ、Unix `.Z`、UDF 读取

- 可以导入、浏览、解压，或转换为 ZIP/7Z 等已有创建格式。ARJ 常用存储和方法 1～4、非空 UDF 镜像及 `.Z` 单文件样本已走通。
- 双栏文件浏览器的打开选择器、双击浏览和右键“解压到另一栏”沿用共用格式列表；Windows 经典与原生右键的扩展名同步。
- UDF 目录正确显示为文件夹；`.Z` 没有提供展开大小时显示“大小未知”，不为填列表先解压整个文件。

## 使用范围

密码救援先覆盖目录可读的 ZIP，需要正确密码及完整卷组；加密内容已经损坏的条目无法恢复。密码包丢目录重建、缺卷恢复、标准磁盘卷丢目录重建和 RAR `.rev` 留在后续。

新包使用 AES-256 / UTF-8；它的加密方式可能不同于原包的 ZipCrypto 或 Windows 密码编码，与旧软件交换时可使用既有归档转换功能调整。ARJ、`.Z`、UDF 本版为读取能力，不新增这些格式的创建、密码或原生分卷。`.Z` 解出其单个文件；内层若为 TAR，可继续用已有 TAR 功能处理。

实际检查与完整范围见 [本版记录](https://github.com/Longyuyeee/long_Decompress/blob/v1.4.5/long-compress-assistant/docs/PASSWORD_ZIP_RESCUE_AND_FORMATS_1.4.5.md)。安装器、签名更新包与更新清单由正式发布流程生成，下载以本 Release 实际附件为准。
