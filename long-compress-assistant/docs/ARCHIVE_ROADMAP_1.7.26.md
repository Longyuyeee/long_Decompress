# v1.7.26 · TAR 目录结构与同名来源一致性

状态：已完成并封板，正式 Windows 产物由本版 CI/Release 接续。

1. TAR 保留结构时，为非空、空顶层文件夹写入自身条目；不同位置的同名来源按根统一改名整个子树，同一规范来源重复加入只输出一次。与 ZIP 共用根名称分配器，扁平创建和 7Z 原布局保持。
2. 覆盖 TAR、TAR.GZ、TAR.BZ2、TAR.XZ、TAR.ZST、TAR.LZMA、TAR.LZ、TAR.LZ4、TAR.BR、TAR.LZO；完整数字 TAR / TAR.LZO 分卷与已确认 TAR.LZO 内容转换接通原流程。
3. 复用已有 TAR 预检扫描记录实际目录日期，在最终提交及暂存清理后由深到浅恢复；冲突确认保留同一时间清单，不重解压或重读日期。隐含/歧义目录、只选文件、不保留路径或关闭时间保留时不编造父目录日期。
4. 修复 TAR 仅选中文件并扁平解压时，路径过早变平导致暂存筛选漏文件的问题；原包路径用于选择/筛选，最终整理时再扁平。
5. 新原生 6 项、相关旧 2 项及 14 份实际归档/178 个条目独立核对通过。保留原 UI、所选与结果入口，未重复未受影响矩阵，见[封板记录](TAR_DIRECTORY_LAYOUT_FREEZE_1.7.26.md)。

完成标准已满足：TAR 根目录和内部文件不混放，包内明确编码的目录日期在最终输出恢复。没有新增权限/所有者或链接语义，没有把 TAR 包装称为原生密码加密。

下一阶段 [v1.7.27 7Z 目录结构与同名来源一致性](ARCHIVE_ROADMAP_1.7.27.md)仅规划；随后继续格式/算法、密码/分卷与容错兼容主线。ZIP UTC / 亚秒扩展、重复读取成本及既有 ALZ / EGG 外部生产者原件、原生密码/块分段等缺口仍另行安排。
