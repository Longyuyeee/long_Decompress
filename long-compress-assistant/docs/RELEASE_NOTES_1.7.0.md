# v1.7.0 · 打开更顺手，双栏更统一

本版集中改善从 Windows 打开压缩包、在双栏中找文件、执行任务及查看历史结果的完整体验。保留单条展开、多选弹窗、自然继承配置与左右等宽布局。

## 从 Windows 双击开始

- 在 **设置 → 行为 → 默认打开压缩包** 选择格式，再到 Windows 默认应用设置确认 Long解压。界面显示实际默认状态；保存“打开后”的行为不会擅自更改系统默认应用。
- 默认询问四种动作：解压到当前文件夹、解压到同名文件夹、选择解压文件夹、进入双栏查看。可以记住选择，也可回到设置调整；自选目录每次询问目标，取消不创建任务。
- 首次使用给出一次轻量设置提醒。提醒状态按用户独立保存，关闭即计入，更新版本与恢复应用偏好不重复提醒；已经设为默认的用户不弹提醒。删除用户数据后视为首次使用。
- 支持程序尚未运行或已经运行时打开文件。处理中收到新任务会排队，已完成的压缩包可以再次执行；离开解压中心后任务继续运行。
- 单包使用自选目录本身，多包分别建立同名目录。完成后可查看结果或打开实际输出文件夹；多个输出位置集中查看。

## 压缩包作为特殊文件夹

- 普通目录与包内共用导航、地址栏、面包屑、列表列头、行高、选择方式和底栏，保持双栏结构与另一栏状态。
- 包内根目录点上一级可回到磁盘目录，恢复选择和滚动；前进可恢复包内位置。
- 保留 TXT 等常用文本与图片预览。搜索、密码、编码、包详情、内容编辑和图片阅读收进选项区，不再占据多行固定空间。
- 在一栏选择包内文件或文件夹，取回到另一栏；保留所选范围内的空目录，不夹带未选目录。

## 常用操作在手边

- Windows 右键增加“选择解压文件夹”，常用解压与浏览在前；校验、救援、转换和重新配置收进“更多操作”，去掉重复入口。明确的右键动作直接执行，不受双击询问设置干扰。
- 历史任务中再次执行与打开结果位置同排；三点按钮弹出浮层菜单，不再展开一整块操作区，支持键盘与窗口边缘避让。
- 修复跨页返回出现空白、缓存包内列表影响磁盘滚动恢复等衔接问题。
