# v1.5.42 失败纠正功能封板

[本版计划](ARCHIVE_ROADMAP_1.5.42.md) · [中文 Release](RELEASE_NOTES_1.5.42.md) · [实际记录](evidence/failure-recovery-1.5.42/)。这是合入前快照，候选 CI、正常合入、标签及正式资产的准确收据在本版 PR 接续。

压缩与转换在原详情显示已有分类、实际阶段、原始原因和下一步。明确分类不再被实时“未分类/最后观测阶段”遮住，观测阶段不被说成已确认的出错位置；不确定原因仍保持不确定。压缩与转换的已存在输出在预检即给出明确分类，历史保存与筛选保持该阶段。

转换失败/取消后的调整创建新条目，保留原条、旧任务和来源关联；原包/新包密码分别确认，方法、强度、分卷、卷型和输出位置带入，重名时建议新名称。任务栏重试改为准备配置：解压返回原条展开纠正，压缩带入已有草稿流程，转换进入新的待处理项。失败/取消旧任务不会被直接执行或改写；所有新任务仍需确认启动。已有新条目可返回，不重复添加。普通密码输入能够解除对应的草稿提醒。

159 项不同前端检查通过；最终整理只补新增提示场景，不重跑前面通过项。四项不同 Rust 覆盖密码需求布尔字段、压缩/转换预检冲突保留原文件、历史分类与筛选。修正了 DOM 集合写法与新增错误类型的引用；一条旧工具栏测试的按钮数量按已有 ZPAQ 入口纠正，没有因此修改产品功能。Shell 版本资源、八处版本身份、前端类型与构建通过。

三条实际桌面流程首次运行均通过：重名转换→分别确认密码→关联新任务；缺卷→任务栏返回原条→补齐后新任务；重名压缩→带入原设置→新草稿。两份已有目标逐字节保留，三份生成/提取内容独立回解并核对 SHA-256，三条原失败记录前后相同。五处界面各查 1100×700、760×520，横向/内容溢出为 0，宽窗左右等宽；六张代表图已查看。单条展开、多选弹窗、自然继承和原滚动结构保持。

查看截图后只整理短通知、两类密码占位提示和已解决的校验提示，补两项前端检查，未再跑已通过的桌面流程。桌面程序 SHA、当时源码及这四个最终文件的补丁哈希分开保留；正式候选由 CI 编译最终源码。没有修改新格式或算法，不重跑旧矩阵、真实盘满和无关媒体/安装流程；个人安装和右键配置未改。
