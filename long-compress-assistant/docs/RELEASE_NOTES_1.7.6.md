# v1.7.6 · 修复更新重复下载与进度超出总大小

优先处理“已下载 33.12 MB / 总大小 23.14 MB”等更新进度异常。

- 检查更新只保留最新的一份原生更新信息，不再累积等待安装的事件；多次检查后点击一次安装也只启动一份下载。
- 原生层限制同一时间只有一个检查或安装操作，并核对待安装版本。下载失败后重新检查、重新开始，旧计数不带入下一次。
- 已下载量按实际数据块计数。总大小缺失或被服务器低估时，显示实际接收量和不确定进度，不显示超过总大小的分数，也不以强行截成 100% 来掩盖问题。
- 清理后的旧监听回调不再修改当前进度；安装中重复点击不会改变当前任务状态。

沿用现有更新弹窗、下载后签名核对和安装流程。本版专注更新故障，没有扩大归档格式或改变原有压缩、解压和双栏交互。

修复在新版本运行后生效，旧版本当前的下载窗口仍由旧代码控制。需要避开旧下载流程时，可以从本 Release 下载安装器直接覆盖安装。

见 [实现与检查](UPDATER_DOWNLOAD_FIX_1.7.6.md)。原 GNU 长名称与全局 PAX 元数据计划顺延到 [v1.7.7](ARCHIVE_ROADMAP_1.7.7.md)，尚未开发。
