# Long解压 v1.1.16

v1.1.16 首次正式交付本地视频压缩。视频工作区复用现有任务、日志、取消、历史、容量预检和原子发布链，所有探测、编码和验证均在本机完成，不上传媒体文件。

## 主要更新

- 支持 MP4/H.264、MOV、AVI、WMV、WebM 等常见视频输入，公开输出固定为 MP4/H.264/AAC；H.265/HEVC 已作为输入验证，不是本版本的输出格式。
- 提供“清晰、均衡、小体积”三档与最大分辨率设置，保持宽高比和旋转方向；执行前展示真实 ffprobe 事实、估算输出区间以及字幕、多音轨等流变化。
- FFmpeg 以冻结的 LGPL 最小化软件编码运行时随包分发，启动前校验精确大小、SHA-256、版本、编码器和过滤器；缺失或替换时拒绝任务。
- 编码参数使用参数数组，进度来自机器通道；Windows Job Object 管理进程树，取消或应用退出会终止编码并清理暂存。
- 发布前重新验证 MP4 容器、H.264/AAC 流、尺寸、旋转、时长与完整音视频帧；验证失败、源或目标竞态、磁盘不足和取消均不发布半成品。
- 视频任务写入统一 `compression/video` 历史，保存后端确认的输入/输出字节、节省比例、时长、尺寸和流事实；完成与取消记录可跨完整应用重启恢复。
- 结果可交由 Windows 默认应用播放，视频源文件默认保持不变。

## 实际验证

- 5 种输入格式、480p/720p/1080p/4K、三档预设、无音频、旋转、VFR、字幕、多音轨均经过真实产品管线。
- 600 秒输入与 114,842,332 B 大输入完成独立验证；输出容器、编码、时长、尺寸、流和完整帧事实差异为零。
- 109.52 MiB 编码中途取消后产品 FFmpeg 退出，无最终输出或暂存，源 SHA-256 不变；完成和取消历史跨原生应用完整重启保持一致。
- 版本号提升前的功能冻结 NSIS 候选生命周期 50/50、安装态视频工作区 20/20 已通过，包括覆盖安装、运行时字节对账、真实转码、默认应用、卸载、用户数据保持和公开 `v1.1.15` 恢复；`1.1.16` 精确版本候选仍须由干净 CI 重建并复验。

## 支持边界

- `v1.1.16` 支持范围限定为带 Windows Media Foundation 的非 N Windows x64 版本。
- Windows N 尚未取得 Media Feature Pack 安装前后的真实同机证据，因此暂不支持；不得把普通 Windows、人工移除 DLL 或单元注入解释为兼容证明。
- 首版只承诺软件编码，不包含 Intel QSV、NVIDIA NVENC、AMD AMF 或其他硬件编码路径。
- 多音轨会按明确策略收敛为单音轨，字幕不写入首版输出；存在流变化时必须由用户确认后才执行。
- 项目没有商业 Windows Authenticode 证书，公开构建不分发 Windows 11 第一层菜单 identity package；经典“显示更多选项”菜单保持完整。
- updater ZIP、签名和 `latest.json` 只由配置发布密钥的 GitHub Actions 生成；正式发布后仍须完成公开资产回下载和 `v1.1.15 → v1.1.16` 应用内更新审计。

完整证据见 `C01` 至 `C05` 视频节点审计、[正式安装生命周期审计](C05_4_1_INSTALLED_VIDEO_LIFECYCLE_AUDIT.md)与 [Windows N 支持范围变更审计](C05_4_2_WINDOWS_N_SCOPE_CHANGE_AUDIT.md)。
