# v1.5.61 ZIP Zstandard 跨流程兼容（已完成功能封板）

2026-10-22。接续 v1.5.60，按有限方法打通格式、密码、卷型和容错流程。本版已完成方法 93 的编辑、实际对比、完整卷取材与精确取回，进入发布。完整帧检查保持，字典/窗口/截断原因接通。

## 用户目标与范围

已有 ZIP Zstandard 创建、浏览、预览、提取和转换路线；下一版让方法 93 的 ZIP 进入原编辑与资料对比工作区，能核对真实内容、取回所选资料和另存整理后的新 ZIP。独立 .zst 与 ZIP 方法 93 分别说明，不当作同一种归档。

1. 核实方法 93 的实际帧、完整结束、大小/CRC、字典及资源边界，先接独立普通 ZIP 编辑与内容对比。不能只放开方法白名单；外部字典或未支持参数给出明确原因。
2. 沿现有 AES/ZipCrypto、明确密码编码、完整数字/标准卷和任意成员归组，接精确取回及组包引用。选有限真实组合，原生分卷编辑仍单独保留边界。
3. 保留条目真实能沿原压缩数据复制时才称保留原字节；密码条目按同方法重编码，新增/替换和组包方法明确。沿原冲突复核、来源变化、失败纠正、草稿/历史与统一结果接续。
4. 截断、损坏、错误密码/编码、缺卷及未知方法分别处理；未读完整内容不作相同结论或发布新包，原件与已有结果保留。

本地当前 ZIP 解析器只把方法 93 映射为 Zstandard；旧编号 20 不能未经真实来源和解码确认就一并宣称支持。若有可行正向依据再细化，不以改方法字段作为支持证明。

只检查新增及受影响路径、独立回解和必要宽窄显示，复用既有创建与其他格式依据，不重跑旧全格式、盘满、媒体或个人安装。单条展开、多选弹窗、自然继承、压缩/解压 50/50 和窄窗滚动保持。

之后按同样粒度接 ZIP PPMd，再根据真实正向来源继续 ALZ 方法 3、EGG 加密固实、ZPAQ 原生多部分/损坏事务等未完成主线；不无限添加大模块完善版。
