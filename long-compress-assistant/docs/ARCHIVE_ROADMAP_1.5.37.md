# 下一版：v1.5.37 ZPAQ 快照对比与变化提取

2026-10-21，接续v1.5.36增量更新。本文件仅规划，尚未启动运行时开发；继续沿格式、密码、分卷与完整处理流程推进。

## 用户要解决的问题

备份更新后，用户想直接知道两版之间增加、修改和移除了什么，并一次取出需要的变化，而不是反复切换目录查找。复用现有文件浏览器与快照选择，先把版本比较做清楚，再接提取、历史与结果。

## 推进顺序

1. **先确认比较依据。** 对普通/原生密码、多事务和数字卷验证同一归档内两个版本的身份。优先研究日志的片段引用与真实内容标识；仅有大小/时间差异时必须标为元数据或变化候选，不能声称已证明内容不同或相同。同大小同时间但内容变化需要独立样本；缺卷、来源变化及损坏不能悄悄回到最新版本。精确比较若需读取数据，显示真实进度并支持停止，不在打开目录时隐式全量解码。
2. **在原浏览器增加版本对比。** 选择较早/较新版本，显示新增、变化、移除与未变数量和逐项原因；支持搜索和筛选，明确移除项属于旧版。保留原目录浏览、预览与所选快照，窄窗口能滚动，不重做整体UI。
3. **接通变化提取。** 用户选择变化后，新增/修改从新快照读取，移除项若要找回则从旧快照读取；确认来源版本与保存位置，先创建待处理任务，保留路径和冲突策略。不同版本不可混用一个错误的快照身份；分别提取并在统一结果入口展示。
4. **工作接续与收尾。** 原生密码/数字卷、补齐缺卷、草稿/历史重做保留各自版本。只补新增比较与变化提取链，复用已通过的增量创建和旧格式依据；保持单条展开、多选弹窗、自然继承、50/50及窄窗显示。更新README、中文Release、范围与发布收据。

## 继续保留的方向

ZIP LZMA写入需单独确定真实编码器与互通（当前zip库该写入分支不支持），不能只添加方法选项。WIM固实/ESD、SWM创建与部署、ALZ方法3、EGG加密固实，以及ZPAQ原生追加多部分/损坏事务抢救继续分别研究。删除同步、直接覆盖原备份、定时备份与跨归档任意版本合并不计入本版承诺。
