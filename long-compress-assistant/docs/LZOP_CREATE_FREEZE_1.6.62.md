# v1.6.62 · LZOP 单文件创建封板

已完成功能封板。用户在原压缩中心选择 LZOP 可生成标准 `.lzo`，每条任务限一个普通文件，多选文件仍各自创建。单条点击展开、多选弹窗、自然继承、左右等宽、主题与快捷键保持；真实采样分析、完整校验、进度/取消、统一结果和历史接通，隐藏无效的等级/密码/ZIP 编码/RAR 恢复控件。手动输入新输出目录会自动建立。

固定 MIT lzokay 2.0.1 编码，不升级依赖或附带外部编码程序；256 KiB 分块，字典与缓冲有界，压缩无收益时原样存储，头及压缩/展开数据 CRC32 和标准结束标记。方法 3/等级 9 描述固定兼容流，不提供可调等级，不声称逐字节等同官方编码器。源名称用 UTF-8 根相对路径保存；头部名称字段超过 255 字节时不截断，取回按输出文件名，默认输出保留原扩展名。老 ANSI 工具的中文名称不作为承诺。

密码原包的单顶层文件可转入；目录/多文件明确改选 ZIP、7Z 或 TAR 组合，保留来源且不遗漏文件。输出事务、验证、取消和失败清理沿原路线；新输出可沿双栏图文预览、取回或继续处理。LZOP 不含原生密码与创建分卷；多成员和完整数字卷读取保持，TAR.LZO 本期仍只读。

初轮七项相关 Rust 通过，修正桌面发现的新目录问题后只补一项受影响 IO/取消专项；七个唯一前端用例及最终类型/Vite、Shell/身份通过。七类新输出由官方 lzop 完整回解并核对 SHA256，来源包括空文件、中文/长名、可压缩与不可压缩数据、文本/图片；最终实际 GUI 产物亦由官方验证和完整回解。四组实际桌面业务全部通过，含原交互和分析、创建与结果/历史、密码来源/范围拒绝与改选格式、活动取消后继续创建；转换结果由独立 7-Zip 完整取回。
