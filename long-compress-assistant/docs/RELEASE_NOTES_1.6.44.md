# v1.6.44 · 7Z Bzip2 图文直接看

使用 Bzip2 方法的 7Z，现在也能在原双栏浏览器直接查看完整小文本和图片，不必先把整个压缩包解开。

- 同版支持普通包、密码包、非固实和固实包，接通内容/文件名加密、完整数字分卷及从非首卷进入。
- 继续使用手动密码或密码保险箱，保留文本编码与滚动、图片预览、连续阅读、翻页缩放、跳过坏图、定位和仅提取当前页。
- 完整文本最多 1 MiB、图片最多 8 MiB；固实共享压缩与解码各最多 64 MiB。完整读取并核对结束、大小和可用 CRC 后显示，只保留所选文件。
- 大文本、超限内容和其他方法组合提示先提取后打开；取消、来源变化、缺卷及明确手动密码错误继续沿原流程处理。

单条展开、多选弹窗、等宽双栏、主题/工具/快捷键保持，说明放原问号，格式数与依赖不变。下一版规划 Bzip2 大文本开头预览，把普通/密码、非固实/固实一起接通。
