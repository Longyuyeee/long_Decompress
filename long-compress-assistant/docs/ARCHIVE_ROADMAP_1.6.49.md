# v1.6.49 已完成功能封板 · 7Z 仅归档与不可压缩文件建议

已完成，见[记录](SEVENZ_COPY_CREATE_FREEZE_1.6.49.md)；[下一版](ARCHIVE_ROADMAP_1.6.50.md)仅规划。面向已经压缩过的图片、视频和资料，提供不重复压缩的快速 7Z 打包，并让现有体积分析给出明确、可选的建议。低收益建议以至少 4 KiB 实际样本压缩收益不足 2% 为条件，不仅凭文件扩展名判断；采用建议只改变当前条目的 7Z 方法，保留强度、密码、固实和分卷。继续格式/算法、密码/分卷与流程容错主线。

1. 原 7Z 方法中加入「仅归档（Copy）」，走真实 Copy coder 和计数/AES 结束；不把用户的强度 0 暗改为 Copy，默认仍为 LZMA2。仅归档不适用的强度配置合理收纳并说明，保留单条展开、多选弹窗和等宽布局。
2. 接通普通/内容密码/文件名密码、固实/非固实、完整数字分卷、取消与重名冲突；原配置组/预设/模板、草稿、历史和工作流保持方法。没有压缩空间收益也应正确显示大小、进度、结果和实际字节计数。
3. 原体积分析按实际 Copy 抽样；所选压缩方法对样本收益很低时，在分析结果中给出轻量的仅归档建议，由用户决定，不自动改动配置或在列表常驻大说明区。明确预计体积与最终结果的区别。
4. 以独立工具回解新输出，再接图文预览、提取和跨方法转换；重点检查空文件/目录、已压缩与不可压缩内容、密码数字卷及中途取消。只做新增/受影响检查和必要默认连续性，宽窄实看后同步 README/Release/交接。

后续根据真实失败样本继续容错兼容；ALZ/EGG 缺少有效原件的事项保持待办。一个版本只完成上述可交付闭环，不把未完成格式写成支持。
