2026-10-22，基于 v1.5.55。见[实施](ARCHIVE_ROADMAP_1.5.56.md)、[中文说明](RELEASE_NOTES_1.5.56.md)及 `evidence/comparison-package-1.5.56/`。

## 交付

- 原对比多选弹窗增加“生成新 ZIP”，完整左侧/右侧作基础并带入另一侧所选，或仅两侧所选。基础含父目录，补充只带精确文件/空目录及必要父目录。
- 复用原 ZIP 编辑清单、冲突选择、最终结构预览、删除/改名/移动、撤销、另存引擎、进度/日志/停止与结果。新结果可浏览并继续原提取、资料库或对比流程。宽窗等宽，窄窗纵向滚动；主页面只有紧凑编辑条。
- 草稿保存具体来源版本、包内路径、目标与配置；不保存密码或解密文件。持久的空 ZIP 只作为原编辑引擎的起点，实际取材在单次保存临时目录，失败/停止/完成均清理。完成页以用户资料说明，隐藏内部编辑起点与空白编辑入口。
- 来源变化、缺失或读取失败保留清单；按来源重新定位或重读确认，仍只接受原选路径，不自动加入新增文件。读取前后及发布前确认版本；已有输出保留。
- Store/Deflate ZIP 的普通、AES/ZipCrypto、完整数字/标准卷取材沿原读取能力。新包全量按所选 Deflate/Store 写出，可 AES-256/ZipCrypto 或明确无密码；含密码来源默认 AES-256，需填写新密码。来源与新包密码分开、保险箱和编码复用原控件，重启重新填写。
