# v1.6.58 规划 · TAR.LZO 目录读取与转换

已完成功能封板，见[记录](TAR_LZO_READ_CONVERT_FREEZE_1.6.58.md)。下一阶段 [v1.6.59 完整数字切卷读取](ARCHIVE_ROADMAP_1.6.59.md)仅规划。在 v1.6.57 单文件 LZOP 基础上，让 Linux 多文件备份可以直接像目录一样浏览和取回；继续回到格式扩展、真实失败包兼容的主线。

1. 用官方 lzop 包装独立 TAR 原件，明确 `.tar.lzo` 的组合识别与命名；测试真实多目录、中文、空文件、空目录以及必要 TAR 扩展，不把任意 `.lzo` 当成 TAR。
2. 接通双栏目录浏览、搜索/筛选、文本/图片预览、所选条目提取、完整检查及 ZIP/7Z 转换。保留来源、历史、失败纠正和结果入口；目录条目与整体大小只显示可确认的状态。
3. 提取、预览与检查都复用本版 LZOP 头/块校验、流式读取、取消和暂存流程；截断或坏块不能伪装为健康备份，也不把未完成产物当成成功结果。按实际原件确定 TAR.LZO 支持等级。
4. 维持单条展开、多选弹窗、自然继承、左右等宽、主题及快捷键。必要说明用问号提示，减少占用文件列表空间；只核对新增和受影响路径，复用通过的检查。

数字切卷留待下一期单独评估完整卷组和非首卷、缺卷提示；LZOP 创建、原生密码、多成员、多部分与救援不在本期。ALZ/EGG 缺有效外部原件的条目仍保留，拿到原件后按用户影响排序，不用合成数据替代真实兼容证明。
