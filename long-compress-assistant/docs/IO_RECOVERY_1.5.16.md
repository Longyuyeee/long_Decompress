## 本版目标

- 处理中盘满、访问受阻、目标占用和源卷变化保留真正原因，不误入密码流程。
- 已有事务式输出、失败重建与历史是基础能力；只修具体缺口，不重新计算新增。

## 开工审计与顺序

现有来源快照只覆盖归一后的一个入口文件，处理中其他分卷被替换或撤回不能从该快照识别。部分 7Z 读写错误转成字符串，公共盘满归一丢失原始细节；任务/历史还没有处理中 I/O 的明确分类及恢复指引。上述是待复现线索，不提前宣称已修复。

1. 固定定向复现，补真实卷组快照及 typed I/O 传播。
2. 接通错误到任务、历史、转换和用户恢复指引；保留发布阶段与回滚状态的优先级。
3. 对改动执行定向回归；本机做真实目标占用、处理中源卷撤回/替换、恢复来源后新任务及常用/窄窗实看。
4. 实际盘满限定独立小测试盘：本机未提升权限，不触碰个人盘符；用隔离 Windows CI 虚拟盘验证真实 OS 写满，不能用注入异常冒充真实盘满。
5. 收口版本身份、README、中文 Release 与证据；必需候选构建通过后合入并正式发布。

当前为开工状态，尚未封板或发布。ALZ 方法 3 未实现、EGG 加密固实未验证等边界保持。十目标完成后再按真实格式/方法、密码分卷和失败接续继续规划，不能把未完成组合抹掉。
