# Long解压 v1.5.40 · 原生 SWM 创建

本版把原生 SWM 从读取扩展到创建，让需要交换 WIM 分包内容的用户可以直接生成和处理整组文件。

- **真正的原生分包**：在压缩和转换入口选择「SWM（原生分包）」，可用仅存储、XPRESS 或 LZX，生成 name.swm、name2.swm 等资源分包，与 WIM/ESD 数字切片区分清楚。
- **整组结果与后续取回**：结果列出全部成员；可从任意成员浏览、预览、检查、提取。缺卷显示具体名称，补齐后创建待确认的新任务，原失败记录保留。
- **转换与配置接续**：密码 ZIP 可转 SWM，SWM 也可转密码 ZIP；方法与卷大小沿原配置、草稿、历史和多选保存，保留单条展开、多选弹窗及左右等宽布局。

另外修正了编辑卷大小时的默认值回填，以及分包完成后源数据总量未保留的问题，结果页能正确显示实际读取量与压缩比例。

目标卷大小并非每个文件的严格上限：单个文件资源不能跨 SWM 成员拆分，部分成员可能超过该大小。请整组保留所有分包。SWM 不含原生密码，本版不提供 LZMS/固实 SWM 或 Windows 系统部署保证；WIM/ESD 数字切片继续保留原有方式。
