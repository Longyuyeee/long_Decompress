# Long解压 v1.4.0

本版完善现有归档的密码、分卷与转换流程，并收紧日常操作界面。不新增归档格式。

## 密码与分卷

- ZIP、7Z 支持目录和多文件的数字分卷创建与读取；可使用密码，保留空目录和原始内容。
- 7Z 支持固实压缩和文件名加密，配置组、模板与历史草稿保留选项；再次执行需要重新填写密码。
- ZIP 默认 AES-256，新增用户主动选择的 ZipCrypto 传统兼容方式（保护较弱）。密码默认 UTF-8，与 Windows 7-Zip 共享中文等非 ASCII 密码包时，可显式选择 Windows 本地编码；不会自动降级加密。
- 缺卷、截断、可确定的结构损坏及系统错误显示具体最终原因；无法区分错误密码与加密数据损坏时明确说明，不武断归因。
- 修复中文 ZipCrypto 编码探测偶然通过短密码头、最终却校验失败的问题；未加密条目避免重复读取，必要完整性检查保留。

## 归档转换

- 压缩中心新增“转换压缩包”，目标支持 ZIP、7Z、TAR、TGZ、TBZ、TXZ、TZST、WIM。
- 原包密码和新包密码分开设置，可更换或移除密码，ZIP/7Z 可重新分卷或合卷；转换解包后的内容，不是把原压缩包再包一层。
- 原包保持不变，新包校验通过后发布；读取和写入阶段支持取消并清理暂存。
- 历史与全局任务面板支持再次转换，恢复独立草稿，不自动执行或恢复密码；修复取消状态倒退和重试走错流程。

## 界面与日常操作

- 解压、压缩设置保留行内展开和动效，默认窗口布局更紧凑；长压缩包名称与后缀不再重叠。
- “常用目录”内区分收藏目录和最近使用，目录与格式菜单统一外观。
- 解释文字收进可点击问号，高级选项直接显示；历史统计改为弹窗，不铺满主页面。
- 移除快速打包，旧配置也不会重新启用；预计体积分析保留。智能目录和受限 ZIP 并行仍由用户主动开启、默认关闭。
- 修复失败历史原因被通用提示覆盖、完成状态与进度不一致、纠正输入后旧错误通知残留等问题。

## 使用范围

- 本版创建的是 `.zip.001` / `.7z.001` 数字卷，不承诺创建 PKZIP `.z01/.zip` 分卷。
- 转换暂不开放 RAR、单文件流及 AES 包装目标；RAR 创建仍依赖用户提供的外部工具和现有授权条件。
- ZIP 各编码、加密和分卷组合的覆盖不同，不将 ZIPX 后缀视为全部编码兼容证明。Zstd ZIP 不承诺全部加密组合。
- 图片、视频、PDF 仍位于“特殊压缩”；Windows N 暂不保证支持。

安装时请先完成或停止正在进行的任务，再退出旧版。封板检查与性能实测见 [开发交接](https://github.com/Longyuyeee/long_Decompress/blob/master/long-compress-assistant/docs/DEVELOPMENT_HANDOFF.md)。
