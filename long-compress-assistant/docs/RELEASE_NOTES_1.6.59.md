# v1.6.59 · LZOP / TAR.LZO 数字分卷直接打开

收到 `.lzo.001` 或 `.tar.lzo.001` 的完整数字分卷，集齐并放在同一目录后，可以从任意一卷打开。普通 LZOP 保持单文件，TAR.LZO 直接沿原双栏浏览目录；图文预览、按需取回、完整检查、ZIP/7Z 转换和结果/历史使用原入口。

- 跨卷的文件头、数据块、校验和结束标记连续读取，无需用户先手动合并。
- 缺首卷、缺中间卷保留具体文件名；尾部不完整提示补齐原始卷后重试，不猜测总卷数。补齐后可重新处理，失败不发布半成品。
- 保持单条点击展开、多选弹窗配置、自然继承、左右等宽、主题和快捷键，无新增占用文件列表的区域。

本版是一个 LZOP 成员的字节切片读取，不含原生多部分、多成员、创建、原生密码或缺卷内容救援。预览不代替整包检查，没有数据校验的来源不能证明内容未改变。
