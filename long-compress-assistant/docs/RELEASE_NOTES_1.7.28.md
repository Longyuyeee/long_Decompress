# v1.7.28 · TAR.LZO 前向链接内容取回

“链接在前、目标文件在后”的完整 TAR.LZO 包，现在可以正常浏览、预览和解压，不再因为目标顺序而无法取回。

- 支持普通头、GNU 长名称、局部 PAX，以及本版核对的普通、空文件和稀疏内容；完整数字分卷沿原入口处理。
- 整包或只选链接文件均可取回，原目标无需同时选中。每份副本保存为独立文件，并保留自身编码日期。
- 接通目录、筛选、平铺、冲突确认、取消及结果入口；完整检查与诊断使用同一确认规则。
- 缺卷或损坏包保留原部分抢救边界；缺失、歧义、链条和循环目标不显示为零字节成功。
- 保持原界面、单条展开、多选弹窗及等宽双栏。前向链接的转换和嵌套打开暂请先提取后操作，后续分期接通。

本版不增加格式数量。见[本版范围](ARCHIVE_ROADMAP_1.7.28.md)、[实现与检查](TAR_FORWARD_LINKS_FREEZE_1.7.28.md)。下一阶段 [v1.7.29 前向链接内容转换](ARCHIVE_ROADMAP_1.7.29.md)仅规划。
