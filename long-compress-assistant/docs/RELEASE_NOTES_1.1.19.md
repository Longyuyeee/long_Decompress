# Long解压 v1.1.19

v1.1.19 将原“压缩包浏览”升级为真正的双栏文件浏览器。打开页面即可浏览电脑文件，不再要求先拖入压缩包。

## 新功能

- 左右两栏可独立进入磁盘和文件夹，支持前进、后退、上一级、刷新、常用位置和多选。
- 一键或右键把所选项目复制、移动、压缩到另一栏；压缩包可直接解压到另一栏。
- 新增重命名、新建文件夹、系统回收站删除和递归属性。
- 双击压缩包进入原有安全归档工作区；也可点击“打开压缩包”，完成后返回双栏浏览。

## 数据安全

- 默认永不覆盖同名目标，整批冲突在写入前统一阻断。
- 文件复制使用目标侧暂存、逐文件 BLAKE3 校验和目录结构复核，验证后才发布。
- 跨卷移动先复制并校验，再删除源；符号链接、重解析点、自身子目录和磁盘根操作会被拒绝。
- 删除进入 Windows 系统回收站；压缩和解压继续使用既有任务、历史和安全事务。

## 验证

- 273/273 单元测试、Rust 真实文件系统 3/3、生产构建和发布身份门禁通过。
