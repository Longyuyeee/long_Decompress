# v1.6.54 规划 · 7Z ARM Thumb BCJ 预处理

仅规划、尚未开发。接续 ARM32，下一步提供可选 ARM Thumb BCJ + LZMA2/LZMA，默认关闭，不按文件名自动启用；ARM64 和复合过滤链继续另行评估，不把过滤器计为新增压缩格式。

1. 沿原折叠高级预处理增加 ARM Thumb，与无、Delta、x86、ARM32 互斥。Delta 距离切回保留，不适用的方法保持暂未应用；原单条展开、多选弹窗、等宽双栏和主题/快捷键保持。
2. 核实现有 Thumb 转换核，补两字节对齐、四字节分支指令跨块、位置回绕、未完成尾部和明确结束；复用流式适配，但仅补受影响架构的连续性检查。
3. 接通密码/隐藏文件名、固实/非固实、完整数字卷和非首卷、配置组/预设/模板、草稿、历史、工作流、真实分析及跨过滤器转换；源包过滤链独立于目标，前端和后端白名单同步。
4. 用独立编解码字节原件、新输出的独立 7-Zip 完整回解，以及外部工具生成的归档核对完整图文、开头和提取。明确必要前看字节并计入预算；不把合成指令样本当成真实应用的压缩率证据。只补新增或受影响检查，实际宽窄确认后收尾发布。

更多格式/算法及真实失败包的兼容容错继续推进；ALZ/EGG 缺有效外部原件的事项保持待办，ARM64 与其他架构过滤器分期，不以新菜单代替实际处理能力。
