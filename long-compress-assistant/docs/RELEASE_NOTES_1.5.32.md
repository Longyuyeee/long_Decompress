# Long解压 v1.5.32

WIM 新增 LZX 体积优先，让打包与转换多一个实用选择。

- **三种 WIM 方法**：仅存储与去重、XPRESS 快速压缩、LZX 体积优先。沿用现有方法下拉框，旧任务和 XPRESS 配置不变，无需调节无效的强度滑块；实际压缩效果随文件内容变化。
- **设置能够接续**：单条展开、多选弹窗、配置组/模板、预设、草稿和历史再次执行保留 LZX。修正同时批量修改 WIM 与 ZIP 方法时，无关任务被转成单独配置的问题。
- **创建与转换贯通**：文件、目录、密码原包可生成 LZX WIM 数字分卷；任意成员继续浏览、预览、检查、所选/完整提取，并可转成新密码 ZIP。补齐缺卷后新建待处理任务，统一结果入口保持。
- **过程与显示保持一致**：暂停/继续、取消、完成源数据和结果统计沿用原流程；保留单条点击展开、多选弹窗、自然继承、左右等宽与窄窗滚动。

本版提供非固实、单镜像内容归档。WIM 没有原生密码，数字切片需集齐；不提供原生 SWM 创建、系统部署或完整 Windows 权限元数据备份。
