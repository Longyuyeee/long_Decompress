# v1.7.40 · 包内文件复制与资源管理器右键整理

状态：功能完成并封板（2026-11-05），正式产物由 CI / Release 接续。本次优先处理 [#364](https://github.com/Longyuyeee/long_Decompress/issues/364) 及用户提出的右键分类需求。v1.7.39 的 XZ 多流/填充兼容尚未开发，顺延，不能作为已完成能力宣传。

## 用户操作

- 双栏浏览器内选中文件或目录，右键“复制”或 Ctrl+C，准备完成后可在 Windows 任意文件夹粘贴；保留文件名、目录内容和空目录。多选、中文空格、密码、分卷、失败后重试沿现有读取流程。
- 复制过程中显示进度并允许取消；全部成功后更新文件剪贴板，失败或取消保留先前剪贴板。临时文件独立于浏览预览缓存，关闭软件后仍能粘贴，后续操作清理过期缓存。
- 普通文件/目录：ZIP、7Z、更多配置、加密/分卷；压缩包：浏览、常用解压、同样的压缩入口及维护；支持的图片：图片压缩/转换优先，仍保留普通打包入口。混合多选不执行不适用操作。
- 校验文件、验证清单沿工具中心入口。Windows 经典菜单与原生菜单的分类一致，维护类操作收进子菜单。
