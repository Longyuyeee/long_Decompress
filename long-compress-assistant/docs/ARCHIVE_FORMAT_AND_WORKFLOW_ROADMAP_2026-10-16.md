## v1.4.10 实施步骤

1. **复现用户阻塞。** 混合 ZIP 中只选公开文件、只选某一密码文件、选择文件夹/筛选文件名，以及全包解压分别检查。当前整包密码判断早于选中范围，静态风险不能直接算桌面复现。
2. **按本次所选内容处理。** ZIP 密码判断、凭据验证、容量估算与实际读取遵守相同选择范围；全包任务仍验证全部应处理的内容。未选文件不阻止任务，也不能借此把未验证文件标成密码正确或全部已恢复。目录、中文路径、数字卷/标准卷与取消保持一致。
3. **补特定兼容证据。** 加密 Zstandard 和真实 ZIP64 密码/卷型使用实际载荷，核对外部工具与应用的输出。不将已有小文件伪 ZIP64 头当作大文件证据，不承诺全部 ZIPX 专有算法。
4. **定向审计并推送。** 每个完成步骤记录问题、修复、实际测试与剩余边界；相关回归通过后提交、推送，再继续下一步。暂不修改用户已安装程序与个人历史。
5. **桌面用户链与发布。** 用户实际入口、选择条目、补密码/失败原因、结果文件均确认；UI 改动查看真实常用/窄窗口页面。全部本版范围完成后确定冻结提交，统一 1.4.10、更新两份 README 与中文 Release，完成仓库必需检查，合入并创建正式标签及安装包。

v1.4.10 已完成普通安装器检查、合入与正式发布。实际证据见 [实施审计](ARCHIVE_COMPATIBILITY_1.4.10.md)，冻结与发布身份见 [封板记录](ARCHIVE_COMPATIBILITY_FREEZE_1.4.10.md)及 [PR #164](https://github.com/Longyuyeee/long_Decompress/pull/164)。下一版为 v1.4.11；开发中能力不计入当前正式版，不提前宣称 SFX/LZIP 已发布。

## 持续保留的产品要求

- 按用户真实顺序测试，不注入完成状态，不放松业务断言换取通过；外部样本读取和外部工具回解分别说明来源。
- 单条行内展开、多选弹窗及自然独立配置不改变；说明文字保持问号帮助，不重新铺满页面。
- 智能目录及 ZIP 并行解压保持默认关闭、用户主动开启，不恢复已取消的快速打包功能。
- 最终失败说明区分损坏、缺卷、密码、方法不支持和实际 I/O；证据不足时如实说明原因未确定。
- 每轮围绕受影响的用户链检查，复用未受影响的现有证据，不追加无关完整矩阵。Windows N 实机门禁已取消，暂不保证支持。
- v1.4.9 曾有一次初始桌面启动超时，根因未明，作为独立稳定性待办保留；不宣称已经修复。
