v1.4.10 已正式发布，合并及标签提交 `b1587d6`，见 [正式 Release](https://github.com/Longyuyeee/long_Decompress/releases/tag/v1.4.10)。现在接续 [v1.4.11 实施审计](SFX_AND_VOLUME_COMPATIBILITY_1.4.11.md)，不重复开发或发布 1.4.10。下文 v1.4.10 的基线与实施步骤保留为路线批准时的记录。

2026-10-16 用户批准将审计建议写入文档，从 v1.4.10 按顺序开发，每一步完成审计和推送，封板后更新 README、Release 并发布安装包。基线为已正式发布的 **v1.4.9 / `083082e`**。本轮从 v1.4.10 开始，不把后续所有版本同时列为本版封板条件。

产品重点保持为：增加真正可用的归档格式，完善密码与分卷组合，改进实际解压/压缩及失败后的继续处理。识别后缀、只读提取、创建、原生密码、原生多卷、应用加密包装与通用切片分别记录；不能以新增名称代替完整支持。

## 已有能力不重复开发

ZIP/7Z 密码及分卷、标准 ZIP 多卷创建、RAR 密码分卷与恢复卷、格式转换/改密/重新分卷、失败纠正及补卷、批量检查修复切页/重启接续均已交付。LZ4、Brotli 及 TAR 组合也已实现。准确范围见 [格式支持分级](FORMAT_SUPPORT_LEVELS.md)及 [v1.4.9 审计](ARCHIVE_CONTINUITY_1.4.9.md)。

ZIP/ZIPX 已有 Store、Deflate、Deflate64、BZip2、LZMA、XZ、PPMd 七种方法与三种加密状态的真实读取证据；不能重复列为未开发。加密 Zstandard、更多真实 ZIP64 密码/卷型组合、RAR4 恢复、ZIP 缺卷及未知边界仍须分别核对。

## 分版本顺序

| 版本 | 主要目标 | 收口边界 |
| --- | --- | --- |
| v1.4.10 | 现有 ZIP/ZIPX 与密码流程补强 | 复现并修正选择性解压受未选条目密码阻挡的问题；补加密 Zstandard、ZIP64 密码与卷型的定向证据，遇到真实差异则修正；不支持的方法明确说明，不引导无效密码重试。 |
| v1.4.11 | 自解压包及特殊卷型 | ZIP/7Z/RAR SFX 作为归档浏览、解压、转换，不执行程序；评估并接入好压等特殊 ZIP 卷名。任意卷进入统一组，缺卷指出所缺文件。 |
| v1.4.12 | LZIP 与 TAR.LZIP | 接入 `.lz`、`.tar.lz`、`.tlz` 的识别、读取、转换，再补创建；当前内置引擎无 LZIP 处理器，需要编解码实现，首版不承诺原生密码与多卷。 |
| v1.4.13 | 损坏包部分抢救 | 先处理目录可读、条目范围可靠的缺卷 ZIP，保留完整且内容校验通过的文件，显示未恢复项；RAR4 恢复另取实际样本，不承诺补造丢失数据。 |
| v1.4.14 | 压缩输出方法增强 | ZIP 可选 Zstandard，ZIPX 先接明确的一种方法（候选 XZ）；原有兼容 ZIP 默认值不变，密码与数字/标准多卷分别确认。 |
| v1.4.15 | 大包及海量文件流程优化 | 实测后减少重复扫描、密码校验和暂存读写；优先可可靠复用的 ZIP 路径，改进取消与 RAR 进度扫描。用真实时间、空间记录收益，不预设提升百分比。 |
| v1.5.0 候选 | ZPAQ 接入 | 先接浏览、密码解压和转换，再接创建；增量归档及历史版本恢复单独确定范围。新引擎可行性确认后才冻结该大版本。 |

ALZ/EGG 为第二批候选，须独立处理算法、密码、固实和卷型；没有解码实现前不开放名称。后续版本在启动时核对届时的实际代码、工具能力和样本，再细化实施范围，必要时向用户询问影响使用方式的选择。

## v1.4.10 实施步骤

1. **复现用户阻塞。** 混合 ZIP 中只选公开文件、只选某一密码文件、选择文件夹/筛选文件名，以及全包解压分别检查。当前整包密码判断早于选中范围，静态风险不能直接算桌面复现。
2. **按本次所选内容处理。** ZIP 密码判断、凭据验证、容量估算与实际读取遵守相同选择范围；全包任务仍验证全部应处理的内容。未选文件不阻止任务，也不能借此把未验证文件标成密码正确或全部已恢复。目录、中文路径、数字卷/标准卷与取消保持一致。
3. **补特定兼容证据。** 加密 Zstandard 和真实 ZIP64 密码/卷型使用实际载荷，核对外部工具与应用的输出。不将已有小文件伪 ZIP64 头当作大文件证据，不承诺全部 ZIPX 专有算法。
4. **定向审计并推送。** 每个完成步骤记录问题、修复、实际测试与剩余边界；相关回归通过后提交、推送，再继续下一步。暂不修改用户已安装程序与个人历史。
5. **桌面用户链与发布。** 用户实际入口、选择条目、补密码/失败原因、结果文件均确认；UI 改动查看真实常用/窄窗口页面。全部本版范围完成后确定冻结提交，统一 1.4.10、更新两份 README 与中文 Release，完成仓库必需检查，合入并创建正式标签及安装包。

v1.4.10 已完成普通安装器检查、合入与正式发布。实际证据见 [实施审计](ARCHIVE_COMPATIBILITY_1.4.10.md)，冻结与发布身份见 [封板记录](ARCHIVE_COMPATIBILITY_FREEZE_1.4.10.md)及 [PR #164](https://github.com/Longyuyeee/long_Decompress/pull/164)。下一版为 v1.4.11；开发中能力不计入当前正式版，不提前宣称 SFX/LZIP 已发布。

## 持续保留的产品要求

- 按用户真实顺序测试，不注入完成状态，不放松业务断言换取通过；外部样本读取和外部工具回解分别说明来源。
- 单条行内展开、多选弹窗及自然独立配置不改变；说明文字保持问号帮助，不重新铺满页面。
- 智能目录及 ZIP 并行解压保持默认关闭、用户主动开启，不恢复已取消的快速打包功能。
- 最终失败说明区分损坏、缺卷、密码、方法不支持和实际 I/O；证据不足时如实说明原因未确定。
- 每轮围绕受影响的用户链检查，复用未受影响的现有证据，不追加无关完整矩阵。Windows N 实机门禁已取消，暂不保证支持。
- v1.4.9 曾有一次初始桌面启动超时，根因未明，作为独立稳定性待办保留；不宣称已经修复。
