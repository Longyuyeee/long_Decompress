# v1.7.24 · ZIP / ZIPX 修改时间保留

状态：已完成并封板，正式 Windows 产物由本版 CI/Release 接续。

1. 普通文件、空文件和已写入的目录条目使用各自源修改时间，不再复用默认日期。文件时间从已打开的源句柄元数据取得，目录时间从原路径元数据取得；读取失败返回原错误，不伪造日期。
2. 复用 ZIP 库的本地 DOS 日期字段，精度为两秒，秒数向下取整。1980–2107 年之外采用最早/最晚边界日期，任务日志汇总提示，原件不变；未增加 UTC / 亚秒扩展字段。
3. 六种现有 ZIP 方法和 ZIPX XZ、AES / ZipCrypto、数字 / 标准分卷及原转换创建器共用日期规则。既有并行能力属于 ZIP 解压，本期核对顺序及实际工作线程还原日期，没有新增“并行压缩”能力。
4. 新原生 5 项、相关日期回归 2 项通过。13 份实际归档、71 个编码条目的本地/中央日期头由独立脚本核对，独立 7-Zip 读回内容与日期；转换、重名、空根、边界日期和原件不变接通。见[封板记录](ZIP_SOURCE_TIME_FREEZE_1.7.24.md)。

完成标准已满足：原生 ZIP / ZIPX 创建或转换后保留可表达的源本地修改日期，结果与历史及原 UI 交互保持。

下一阶段 [v1.7.25 ZIP 顶层目录与目录时间](ARCHIVE_ROADMAP_1.7.25.md)仅规划。非空顶层目录的显式条目、解压后的目录时间恢复、UTC / 亚秒精度与重复扫描成本不混入本版；后续继续沿格式、算法、密码、分卷和容错主线推进，既有 ALZ / EGG 等缺口保留。
