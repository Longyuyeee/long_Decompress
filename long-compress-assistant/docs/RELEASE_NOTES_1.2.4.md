# Long解压 v1.2.4

本版本收紧特殊压缩的信息层级，并修复无原生装饰窗口的拖动、缩放和侧栏任务区布局。

## 改进

- 图片、视频和 PDF 批量设置改为紧凑弹窗；PDF 输出目录不再平铺占用主工作区。
- 压缩中心全局设置改为紧凑两列布局；配置组管理限制为 736×576 的实测上限，标题固定、内容独立滚动，去除原生箭头式滚动条。
- 视频任务默认折叠，只展示尺寸、时长、质量和预计大小；真实媒体事实与执行前变化在展开后提供。
- 删除特殊压缩中由当前 Tab、配置或执行结果已经表达的重复说明。
- 顶端标题栏去除重复产品名，同时恢复空白区域拖动；增加四边和四角共 8 个窗口缩放热区。
- 左侧栏删除“本地处理 · 隐私优先”，将原位置作为稳定任务监控槽，避免任务出现时导航闪烁和挤压。
- 图片、视频和 PDF 长列表统一使用低对比度细滚动条，并继续支持真实纵向滚动。

## 验证

- Windows Release Tauri 壳层、图片、视频和 PDF 四组真实门禁通过。
- 压缩中心全局设置实测 736×399.5，配置组管理 736×576；关闭动作、浅色/深色标题对比度和主题化滚动容器均通过真实 Tauri 门禁。
- 视频覆盖 10 分钟和 114,842,332 B 样本、取消、发布、重启和默认播放器；PDF 覆盖 13 个真实样本。
- 正式无测试桥 NSIS 与 `v1.2.3 → v1.2.4 → 卸载 → v1.2.3` 真实安装生命周期 50/50 通过。
- 详细预期—实际对照见 [v1.2.4 实现审计](SPECIAL_COMPRESSION_SHELL_AUDIT_1.2.4.md)。

## 已知边界

- Windows N 仍不在已验证支持范围内。
- Windows 11 第一层资源管理器菜单继续受应用代码签名身份限制。
