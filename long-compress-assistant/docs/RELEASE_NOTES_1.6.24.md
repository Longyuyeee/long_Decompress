# v1.6.24 · 密码 7Z 大日志直接读开头

带密码的非固实 7Z 大日志，现在也能在原双栏里直接阅读前 1 MiB，无需先提取全文。

- 支持 AES + LZMA / LZMA2，内容加密、文件名加密与完整数字分卷沿原入口使用。
- 沿用手动密码和密码保险箱。手动填写的密码优先，错误时直接提示；留空可尝试保险箱，不把部分读取记为整包密码成功。
- 复用原文本窗口，保留滚动、编码识别、已读/声明大小和“提取后打开”；明确标注“部分内容 · 未校验整文件”，不会把未读尾部、整文件 CRC 或完整加密结束当作已验证。
- 字符截断边界、关闭取消、来源变化和缺卷处理贯通，不预先读取无关大文件。实际输入、字典和解码头各沿原 64 MiB 范围，候选整体限时 30 秒。
- 完整小文本、图片和文件头仍走完整消费与校验路径；固实大文本和其他方法组合继续给出提取指引。

保持单条展开、多选弹窗、左右等宽、原主题与工具中心；格式数量不变。下一阶段规划未加密固实大文本开头，尚未开发。
