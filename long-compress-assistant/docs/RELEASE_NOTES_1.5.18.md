# Long解压 v1.5.18

本版让 Long 自有加密包也能分卷搬运，并接通浏览、解压和转换的日常流程。

- **九种 AES 格式支持数字分卷**：TAR.AES、TAR.GZ/BZ2/XZ/ZST.AES，以及 GZ/BZ2/XZ/ZST.AES 可在原配置区设置每卷大小；转换沿原目标列表提供五种 TAR.AES，可重新拆卷或合并。
- **任选一卷进入**：全部分卷放在同一目录，从首卷、中间卷或末卷打开，使用完整容器读取。补齐来源后通过原失败纠正弹窗建立新任务，保留旧失败记录。
- **加密内容直接查看**：填写密码后可浏览目录、预览支持的文本和图片、只提取需要的文件；完成整组认证后才读取内层内容。支持 AES 分卷与密码 ZIP 的转换。
- **失败原因更明确**：V2 缺尾按声明总长度提示补齐来源，前段已通过后的后续认证失败提示内容异常；首块失败仍如实说明可能是密码或数据问题，不强行区分无法确认的原因。
- **目录与界面保持顺手**：修复 TAR.AES 多源目录创建，保留空目录并沿用普通 TAR 的布局与所选提取；单条行内展开、多选弹窗、自然继承、左右等宽和窄窗滚动保持。

这是 Long 自有 AES 容器的数字切卷，接收方请使用 Long解压；不是通用 TAR 原生密码/分卷标准。V1 保留有限只读兼容，V1 缺尾无法可靠区别于密码或内容异常。文本/图片预览沿用现有限制；读取加密内容前需要完整认证和临时空间。加密格式、参数与默认设置未改变。
