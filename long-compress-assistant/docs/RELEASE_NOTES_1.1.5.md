# Long解压 v1.1.5

本补丁版集中修复压缩与解压详情在窗口缩窄后的布局退化，并统一详情滚动体验；项目主页同步采用完整的 Windows 真实运行截图。

## 修复与改进

- 解压中心和压缩中心的展开详情固定保持“左侧配置、右侧状态与实时日志”，不再因窗口宽度缩小而变成上下结构。
- 双栏使用可压缩的 `minmax(0, …)` 网格，内部文本与控件按可用宽度换行，详情卡片与页面不会产生横向滚动。
- 压缩配置、压缩执行和解压执行区域统一采用强调色细滚动条，隐藏 Windows 原生上下箭头，并保持透明轨道。
- 响应式自动验收覆盖 1440、1024、760 和 390 四档宽度，同时检查左右位置关系和水平溢出。
- README 使用五张完整的 Windows 实际运行截图，展示解压中心、压缩中心、压缩包浏览、密码保险箱和密码生命周期分析。
- 仓库根目录的历史发布记录、旧工具、样例与开发材料统一归入 `archive/legacy-root`，保留追溯能力。

## 发布与兼容性

- 版本身份统一为 `1.1.5`，覆盖前端包、Tauri 应用、Rust 主程序、Shell Extension 与锁文件。
- 继续发布 Windows x64 NSIS 安装包和签名的应用内更新资产。
- 本项目仍没有商业 Windows 代码签名证书，因此发布流程继续跳过 Windows 11 第一层菜单身份 MSIX；经典 Long解压 子菜单保持可用。

## 验收

- 前端类型检查、单元测试、响应式浏览器 E2E 与生产构建通过。
- Rust 主程序测试与 Clippy `-D warnings` 通过。
- Windows Shell Extension 构建、测试与 Clippy `-D warnings` 通过。
- 发布身份脚本确认所有版本来源和版本化 Shell Extension DLL 一致。
- npm 官方源生产依赖安全审计为 0 个已知漏洞。
