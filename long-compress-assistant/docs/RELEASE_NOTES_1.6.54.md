# v1.6.54 · 可选 7Z ARM Thumb BCJ 预处理

- 原 7Z 折叠「高级预处理」增加 ARM Thumb BCJ，适用于 LZMA2 / LZMA，与无、Delta、x86、ARM32 互斥；默认关闭，不按扩展名自动启用，不增加格式计数。
- BCJ 收起并保留 Delta 距离，其他方法保留设置并显示暂未应用；继续使用单条展开、多选弹窗和等宽双栏。
- 窄窗口下较长的预处理状态自动换行，避免把“高级预处理”标题挤成竖排。
- 密码/隐藏文件名、固实/非固实、数字分卷和非首卷、配置组/预设/模板、草稿、历史、工作流、实际链分析和转换接通。
- 新输出及独立 7-Zip Thumb 归档接入原完整图文、大文本开头与提取入口；跨文件指令和最多三字节前看计入原预算，保留部分内容提示。
- 修正 Thumb 转换的位置回绕，读取支持空属性或两字节对齐起始位置；普通 flush 保留不完整指令，不重置位置。

范围与检查见[开发记录](SEVENZ_ARM_THUMB_BCJ_CREATE_FREEZE_1.6.54.md)。正式附件由标签流水线自动生成，实际状态在本版 PR 接续。下一阶段 [ARM64 BCJ](ARCHIVE_ROADMAP_1.6.55.md)仅规划；其他格式、算法与真实失败包的兼容容错继续保留在主线。
