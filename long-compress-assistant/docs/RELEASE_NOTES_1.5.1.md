# Long解压 v1.5.1

本版补齐 ZPAQ 创建闭环，可以把文件或文件夹打包为新的 ZPAQ，并使用原生密码分享。

## 新增与改进

- 压缩中心新增 ZPAQ 日志式创建，支持中文名称、目录、空文件和空目录。密码直接使用 ZPAQ 原生加密，不转换为 7Z；查看目录和提取内容均需密码。
- ZPAQ 参数可保存为配置组并重新应用。历史任务保留格式、压缩强度等设置，重新执行时先生成待确认草稿，密码重新填写，不改写原记录。
- 转换界面新增 ZPAQ 输出，支持已有密码包转换和 ZPAQ 重新加密；保留原包，仍先暂存、校验再发布。
- 修复随附 ZPAQ 引擎的 Windows 读写错误传播。读取、短写、定位、关闭或刷盘失败都会结束任务并保留具体原因，检查报告不再把明确 I/O 故障归为密码或损坏待定。失败和取消不发布半成品。
- ZPAQ 任务暂停会实际暂停引擎进程，恢复后继续；暂停中仍可取消，不再只挡住后续结果提交。
- 修复“保存为配置组”弹窗在小窗口下超高的问题，使用内部滚动；配置预览改用主题配色。长归档名与 `.zpaq` 后缀保持分开显示，分卷等未实现选项不会误启用。

## 使用边界

新建的是日志式归档，不会在已有 ZPAQ 上追加更新。压缩强度 1～9 映射为上游 1～5 级，使用两个线程和 16 MiB 块。既有流式、日志式当前文件读取继续保留。

本版不提供固定大小 ZPAQ 分卷、原生增量多部分、自动备份或历史恢复。原生多部分按更新追加新段，不等同于普通分卷。ZPAQ 原生加密不提供独立认证，文件内容校验不能保证发现所有头部变化。

产品输出已用作者原版 ZPAQ 7.15 独立回解，并核对已知文件内容；真实桌面覆盖创建、配置复用、历史再执行、密码转换和取消。具体测试与发布身份见[实施审计](ZPAQ_CREATE_1.5.1.md)和[封板记录](ZPAQ_CREATE_FREEZE_1.5.1.md)。
