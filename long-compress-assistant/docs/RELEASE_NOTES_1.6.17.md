# v1.6.17 · 7Z 小文本原位预览

收到 7Z 包时，可以直接在原双栏浏览器阅读说明、配置和小日志，不必先解压，也不用切换到另一个浏览中心。

- **原位置阅读**：支持 LZMA / LZMA2 非固实文本，完整文件不超过 1 MiB；双击、预览按钮、右键和 Ctrl+Enter 沿现有入口，保留滚动、关闭和另一栏的位置。
- **密码与分卷接通**：支持所选内容的密码、文件名加密及完整数字卷；留空尝试保险箱，手动填写时只使用该密码，不先验证无关文件，也不引入不适用的 ZIP 密码代码页。
- **显示结果可信**：准确匹配所选路径，完整大小、CRC 与解码结束通过才显示“完整显示”。关闭取消，来源变化提示刷新；固实共享内容、超限、同路径重名或损坏会给出提取或核对来源的下一步。

每次候选的元数据与数据实际读取合计最多 64 MiB，候选流程整体限时 30 秒；大包内的无关文件不因为整包体积大而被强制读取。预览不产生临时整包，不记作整包密码验证成功。

本版不开放 7Z 图片、全部固实预览或大文本前缀，格式数量不变。保留单条展开、多选弹窗、左右等宽、原主题和工具收纳。详见[本版记录](https://github.com/Longyuyeee/long_Decompress/blob/master/long-compress-assistant/docs/SEVENZ_TEXT_PREVIEW_FREEZE_1.6.17.md)。
