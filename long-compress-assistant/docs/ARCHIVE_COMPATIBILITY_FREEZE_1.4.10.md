# v1.4.10 功能封板与发布接续

日期：2026-10-16（Asia/Shanghai）。基线正式 v1.4.9 / `083082e`，分支 `codex/archive-compatibility-1-4-10`。**功能冻结提交 `d62795e06d4c3f6e48f4990d3180b95eea4ec887`**。后续只完成本分支普通安装包检查、合入及正式发布，不追加功能。

## 冻结范围

- ZIP 密码判断、自动及手动凭据验证、容量与实际读取遵守同一所选范围；混合包的未选加密条目、不同密码和未知方法不阻挡本次提取。全包密码验证仍要求完整有效。
- 浏览目录不先尝试整包密码；预览、打开文件及嵌套包的凭据查找只针对所选条目。普通/加密 ZIP 及数字/标准卷使用同一原生选项路径。
- 接通 ZIP 原生旧方法，固定只读样本覆盖 Shrink、Reduce factor 4、Implode；不新增 ZIPX 压缩方法或承诺全部旧密码变体。
- 浏览页“返回双栏文件浏览器”进入正常标题操作区，修正窄窗口滚动遮住搜索的问题。
- 版本及版本化 Shell DLL 统一为 1.4.10，两份 README、中文 Release 和后续路线已更新，原软件图标保留。

## 检查与证据

- 后端 **69 个不同用例**、前端相关 **20 项**通过；普通前端构建、测试 Release 编译与版本/Shell 身份检查通过。不累计重跑。
- 最终实际 Windows 用户链：独立创建的两种混合密码 ZIP，浏览/预览/选择提取、错密码失败后改正、保险箱匹配及数字卷提取完成，原失败记录和原包保留。
- Zstandard AES/ZipCrypto × 单包/数字卷/标准卷 **6 组**经独立 7-Zip 验证并应用回解；真实 **4,294,979,641 字节**文件的 AES/ZipCrypto ZIP64 数字分卷两组独立创建、全量校验、应用完整解压及 SHA-256/尾随条目对照通过。
- 旧方法真实固定样本 **3 组**，Reduce 与上游公布的原始字节比对，不能写为不支持它的 7-Zip 校验通过。原有七种 ZIP 方法的密码及数字卷读取也重新通过。
- 常用与最小窗口真实页面已查看，结果与 **11 张截图**随仓库保存。测试程序 SHA-256 `7b178baac409d0f185a9bb6da7d02a94cd84f8ce5d49bf9fb129ce6a8c982fef`，它不是普通发布安装包。

完整用户操作、失败与修正、工具边界和重现命令见 [实施审计](ARCHIVE_COMPATIBILITY_1.4.10.md)，最终结果见 [证据 JSON](evidence/zip-selection-1.4.10/final/zip-selection-1410-results.json)。未修改用户已安装软件或个人任务。

## 发布顺序

用户已明确批准封板后更新 README、Release 并发布。接续本分支 PR 必需的 **Windows package**；成功后按对应最新提交合入 `master`，从合并提交创建 `v1.4.10`，由正式 Release 工作流生成安装器、签名更新包和更新清单，中文正文使用 [本版说明](RELEASE_NOTES_1.4.10.md)。

准确 PR/合入提交、构建链接及附件结果记录在 PR 正文和 [正式 Release](https://github.com/Longyuyeee/long_Decompress/releases/tag/v1.4.10)，不为结果回写重复打包。触发工作流不等于安装包已经发布。
