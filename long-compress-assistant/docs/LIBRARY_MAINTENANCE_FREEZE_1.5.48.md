# v1.5.48 资料库维护、密码与分卷来源封板

[实施计划](ARCHIVE_ROADMAP_1.5.48.md) · [中文 Release](RELEASE_NOTES_1.5.48.md) · [记录](evidence/library-maintenance-1.5.48/)。候选、正常合入、标签与正式附件收据在本版 PR 接续。

## 已交付

添加和指定目录扫描沿当前浏览器实际可列目录的后缀，扩展 7Z、RAR、压缩 TAR、压缩流及镜像等既有能力，不新增解码算法。同组分卷从任意成员加入只保留一份来源；兼容此前 ZIP 尾卷的来源身份，整组检查成员名称、大小和修改时间，明确缺失成员，不把不同来源合并覆盖。

来源点击展开，密码/编码在弹窗填写或取用保险箱，密码仅当前会话。密码 ZIP 实际验证内容，加密目录 7Z 等沿既有密码能力；密码不可用、缺卷、不可读分别说明。搜索命中带会话凭据进入原浏览器，预览或单项取回沿原入口；正常退出重启后重新填写密码，可继续取用保险箱，保留此前编码选项。弹窗读取中可停止。

来源可手动检查，区分可用、变化、离线、缺卷及不可读。已完成缓存仍能搜索并明确上次索引及当前状态，操作前检查实时来源；移动后重新定位保留身份和缓存，必须明确刷新后使用。只重建变化的来源，未变化索引跳过；事务失败/停止保留先前完整缓存。未知大小显示“大小未统计”。

建库和来源检查可暂停/继续；当前来源完成后暂停下一派发，继续只处理剩余项，停止取消当前读取并保留完成记录。重启后手动接续未完成来源。schema 13 → 14 保留旧来源与条目。单条展开、多选弹窗、自然继承、压缩/解压左右等宽与滚动保持；资源库宽窄分区、长路径换行、来源行保留完整高度。

## 范围与检查

手动维护元数据，不缓存文件内容，不提供全文/OCR/云盘或全盘常驻扫描。变化判断是大小、修改时间及分卷成员信息，不宣称内容哈希身份；已索引不等于全包内容完整性验证。镜像与快照先按既有默认目录建库，不宣称遍历全部镜像/快照。后缀候选沿既有浏览能力，不将任意改名文件或所有自解压包当作本版全部支持。原扫描和索引数量上限保留。

56 项不同前端（11 原资源库、11 新维护、34 受影响浏览器）、19 项不同 Rust（13 资源库、6 迁移）通过；既有真实个人库快照按 opt-in 忽略。类型/Vite、Shell 与八处版本身份、原生构建通过。五条实际桌面流程涵盖旧库升级、密码/保险箱/编码/单项取回、离线缓存/定位/变化、缺卷恢复后跳过、十万项暂停继续和同资料目录正常关闭重启再解锁。单项取回为正确的一个 26 字节文件，原 ZIP/7Z 哈希保持。16 条宽窄布局无横向溢出，八张代表图实看。

最终 E2E SHA-256 `22fea6f2ba9f7d3fdf27021b6e1fdc14cb983ab516eed059de00e4b1efa80d6b`。前四条流程保留此前身份，最终只补编码字段来源属性、两项前端和未完成第五条；自动脚本等待禁用按钮修正如实记录。不重复旧矩阵、真实盘满或无关安装；本地构建不冒充正式附件。
