# 目标存储预检布局审计（2026-08-21）

## 问题与用途

截图中的“位置 / 介质 / 可用 / 预计”属于任务启动前的目标存储预检，用于说明输出盘位置、磁盘类型、剩余空间和预计占用，并在容量不足时阻止任务。功能应保留，但原布局依据整个窗口宽度切成四列，没有考虑详情左栏的实际宽度，导致中文逐字换行。

## 修复范围

- 共享组件改名为“目标存储预检”，字段明确为“目标位置 / 存储介质 / 剩余可用 / 预计占用”。
- 默认最多两列，极窄组件自动降为一列；标题和值均保持单行并在必要时省略，完整介质信息保留在提示中。
- 解压中心的任务详情和压缩中心的执行详情均引用同一个组件，因此使用同一布局规则，不保留平行样式分支。

## 验收标准

1. 卡片及所在详情面板不存在横向滚动。
2. 指标区域最多两列，不再出现四列窄格和逐字竖排。
3. 四个字段的标题和值保持单行，容量信息仍完整可辨。
4. 真实容量不足时仍显示阻止状态，功能逻辑与安全保护不受视觉调整影响。
