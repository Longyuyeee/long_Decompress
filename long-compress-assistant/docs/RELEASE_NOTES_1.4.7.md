# Long解压 v1.4.7

这版围绕 RAR 受损和缺卷后的继续处理升级，并提供可选的恢复保护；保持单条点击展开、多选弹窗配置的操作方式。

## RAR 修复与恢复卷补卷

- 失败任务可以直接进入检查与修复。发现同组 `.rev` 后，尝试利用恢复卷重建缺失或损坏的 RAR 数据卷；没有恢复卷时，可尝试利用包内恢复记录修复或重建结构。
- 所有处理在独立副本中完成。通过内容校验的结果保存到新的 `.repaired` 文件夹，原包和已有结果保持不变。
- 多卷修复会把替换卷和完好卷副本组成完整卷组；结果显示保存的数据卷数量，可直接加入解压队列，保留密码及本次输出设置。
- 加密 RAR 密码预检未通过内容校验时，提示密码或内容异常，避免把损坏一概判断为密码错误。
- RAR 修复保留原加密方式与密码；缺少恢复数据、密码不正确或仍有损坏时，说明原因并允许继续调整。结构重建的结果会明确提示部分恢复。

## 压缩时可选恢复保护

- 选择 RAR 后，可展开高级选项中的“恢复保护”，添加 3%、5% 或 10% 的恢复记录；默认关闭。
- 单条配置、多选弹窗、归档转换、配置组、便携模板、待处理草稿和历史再次执行保持该设置。
- 恢复记录增加一些体积，用于包受损时尝试修复；`.rev` 恢复卷创建留在后续，本版可以使用已有的恢复卷。

## Windows 右键快捷入口

- 经典与原生右键菜单新增“检查与尝试修复”。RAR 分卷和 `.rev` 可从资源管理器直接进入检查页面，自动查找同目录卷组。
- 多选多个文件时，可在检查页切换查看；选择保存位置后才开始修复，修复结果先加入待处理队列。
- 恢复保护折叠显示，沿用现有双栏、滚动和窄窗口布局。

## 使用范围

RAR 修复需要本机可用的 WinRAR/Rar.exe，普通 RAR 解压沿用已有能力。当前需要至少一个仍保留的同组数据卷。本轮新增恢复以 RAR5 实际样本为依据，修复结果取决于来源损坏程度及可用恢复数据，不保证所有归档都能恢复。带加密文件名的恢复卷补卷受本机 RAR 控制台密码编码约束，无法表示的字符会给出明确说明。

标准 ZIP 分卷丢目录、未知数据描述符变体及创建 `.rev` 不属于本次新增范围。安装器与自动更新附件以正式 Release 页面实际内容为准。
