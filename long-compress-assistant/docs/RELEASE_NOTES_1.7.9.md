# v1.7.9 · 全局 PAX 归档读取与取回兼容

含全局 PAX 元数据的 TAR / TAR.LZO，现在可沿原入口浏览和解压；TAR.LZO 后续损坏或缺卷时，已确认的完整文件也能按正确名称和大小部分取回。

- 全局属性持续继承，局部属性只覆盖下一条，支持空值删除与后续更新；元数据不会显示成文件。
- 统一浏览、预览、所选解压、验证和转换的读取规则，修正 PAX 大小与普通文件头不一致、控制记录夹在文件之前时的内容边界问题。
- 完整浏览和解压正确处理 PAX 修改时间，包括小数和负时间；转换为密码 ZIP 后，文件路径与内容保持。
- 部分取回继续使用原筛选弹窗、独立结果位置和“已部分取回”历史；截断、缺中卷或更换来源时保留原有明确停止和重新检查行为。
- 保留单条展开、多选弹窗、左右等宽双栏及原主题；没有增加常驻配置区。

本版支持普通文件和目录的常见全局属性。未知全局属性、换行属性值及不确定的布局明确停止；链接、稀疏文件、GNU 长名称与局部 PAX 叠加的部分取回仍未扩展，不扫描缺口之后。

见 [本版范围](ARCHIVE_ROADMAP_1.7.9.md)、[实现与检查](TAR_GLOBAL_PAX_FREEZE_1.7.9.md)。下一阶段 [v1.7.10 混合名称记录取回](ARCHIVE_ROADMAP_1.7.10.md)仅规划。
