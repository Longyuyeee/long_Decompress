# v1.7.29 · TAR.LZO 前向链接内容转换

状态：已完成功能开发并封板。接续 v1.7.28 已完成的完整前向引用识别、浏览、预览和正常/所选提取。

1. 复用既有完整条目计划，把已确认前向目标内容送入原归档转换入口，用户无需先手动解压再压缩。普通、空文件与已证实的稀疏逻辑内容均作为独立文件输入，不创建系统链接。
2. 先覆盖既有 ZIP / ZIPX、7Z、TAR / TAR.GZ 创建器的代表流程；按目标自身能力衔接密码、分卷和已发布的目录/时间规则，不承诺每种目标能保留源 TAR 的全部元数据。创建方法未变化时不重跑整套算法矩阵。
3. 沿现有新包验证、来源版本重查、取消、同名确认、结果与历史/失败重试流程。保留当前明确提示，只有实际接通并核对的操作才移除“先提取后压缩”限制。

完成标准：声明范围内的完整前向链接包能够沿原转换入口得到可浏览、可取回的新包，内容与自身可表达日期正确，原包保持；失败和取消不把临时结果当成功。

前向链接的嵌套物化、任意链条、循环/符号链接、缺口后扫描和其他未证实目标仍另行安排。保留现有 UI、单条展开、多选弹窗、等宽双栏与包内外结构；继续格式/算法、密码/分卷和容错主线，既有 ALZ / EGG 外部原件、原生密码/块分段等缺口保持未完成。

实际范围与检查见[封板记录](TAR_FORWARD_CONVERT_FREEZE_1.7.29.md)。下一阶段 [v1.7.30 前向链接嵌套浏览](ARCHIVE_ROADMAP_1.7.30.md)仅规划。
