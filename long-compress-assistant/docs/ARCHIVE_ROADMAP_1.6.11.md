# v1.6.11 候选 · ALZ 大文本前缀预览

仅规划，尚未开发。接续 ALZ 小文本和图片阅读，让用户直接查看较大日志、说明与配置的开头，继续复用原双栏和文本预览弹层。

1. **先明确“部分内容”**。仅为显式文本预览提供有界前缀读取，默认最多显示 1 MiB，沿现有编码识别与完整字符边界处理；界面明确显示已读范围和未展示内容，不冒充整文件大小/CRC/终止校验成功。
2. **只处理所选条目**。对 Store/Deflate/Bzip2 分别处理到前缀为止的读取、输入扫描和时间预算；避免为一份日志先解码无关内容。完整提取、检查和转换仍必须校验完整文件，不复用“部分可读”作为成功依据。
3. **接原密码、卷组与失败流程**。手动密码、保险箱、显式编码和完整原生卷沿旧入口处理；关闭/换包/换编码可取消，来源变化提示刷新。密码尝试不得先完整验证超大条目；不能满足预算时给提取指引。
4. **按可用增量收口**。只补前缀、字符截断、超限、取消/来源变化和必要宽窄显示，沿用已过图片、旧算法、安装与真实盘满依据；完成后同步 README、Release、能力说明和版本身份。

并行保留来源条件，不空发取材版本：新增原 ALZip 图片密码/原生卷原件、历史原工具 Bzip2 大包、方法 3 与 EGG 加密固实。v1.6.10 官方安装器已取得但本地旧解包工具不支持其版本，未安装或执行安装器，不重复同一失败提取；后续有可用工具或有效原件再补。继续既定格式/算法、密码/分卷和容错主线，五个大模块的原交互与收纳方式保持。
