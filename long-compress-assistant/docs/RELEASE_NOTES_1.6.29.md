# v1.6.29 · 固实 PPMd 7Z 直接查看图文

未加密的小型固实 PPMd 7Z，现在也能在原双栏直接阅读小文本、预览图片和连续看图。

- 支持完整文本 ≤1 MiB、PNG/JPEG/BMP/GIF/WebP ≤8 MiB；完整数字分卷可从有效的非首卷进入，准确读取首个或后续所选文件。
- 完整检查所选文件所在的共享块，包括前后文件、大小、可用 CRC、完整压缩覆盖和 PPMd 实际结束。所选正文已读出而后续内容或结束数据损坏时，仍明确报错。
- 沿原文本编码识别、滚动和“完整显示”，沿原图片阅读器翻页、缩放、跳过坏图、定位和准确提取当前页。
- 共享块压缩/解码各限 64 MiB，仅保留所选文件；实际输入、字典、时间、取消和来源范围保持，不整包临时解压、不扫描无关数据块。
- 密码固实或大文本 PPMd 暂时仍给出提取下一步。普通/密码非固实 PPMd 和既有 LZMA/LZMA2 路径保持。

单条展开、多选弹窗、左右等宽、主题/工具/快捷键保持，帮助收在原问号，格式数量不变。下一阶段仅规划密码固实 PPMd 图文预览。
