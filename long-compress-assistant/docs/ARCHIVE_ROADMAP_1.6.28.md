# v1.6.28 已完成功能封板 · 密码 PPMd 非固实图文预览

已完成，见[封板记录](SEVENZ_PASSWORD_PPMD_PREVIEW_FREEZE_1.6.28.md)；下一版[PPMd 小型固实图文](ARCHIVE_ROADMAP_1.6.29.md)仅规划。接续 v1.6.27，让已有原生解压能力的密码 PPMd 包，也能沿原双栏阅读完整小文本和图片。

1. **先完整小文本**：原版 AES → PPMd7 非固实，准确唯一普通文件 ≤1 MiB。按实际方法顺序确认单进出/单打包流、AES 明文与密文对齐长度，接通 PPMd 声明大小、range coder 结束、压缩完整覆盖与可用 CRC。不能用部分读取路径绕过完整 AES 消费/填充条件。
2. **再图片和原阅读器**：≤8 MiB 的既有受支持图片，保持尺寸/像素范围；按需当前页、翻页、缩放、坏图跳过、定位和精确提取，不整包临时解压。
3. **贯通实际密码与分卷**：手动密码不回退，留空沿原保险箱有界尝试；内容/文件名加密、完整数字分卷有效成员、实际元数据/载荷输入合计 ≤64 MiB、PPMd 阶数/字典及 AES KDF 参数范围、候选整体 30 秒、取消和来源绑定保持。不先验证无关大文件，不记整包密码成功。
4. **独立收尾**：原工具生成、另一版本逐文件回解；覆盖两种密码布局、非首卷/缺卷、错误密码、填充/结束/CRC 失败及原界面宽窄显示。只做该版受影响的必要检查，同步 README、Release、能力口径与交接。
