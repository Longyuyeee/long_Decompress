# B-00.1 统一任务与历史模型审计

审计日期：2026-08-27

## 开发目标

在不新增媒体页面、不引入媒体引擎、不复制任务队列的前提下，为现有压缩任务和历史增加向后兼容的 `workloadKind` 与版本化实测指标。

## 模型边界

- 顶层任务类型仍只有 `compression | decompression`。
- `workloadKind` 只允许 `archive | image | video | pdf`；旧记录缺省解释为 `archive`。
- 指标 V1 记录输入字节、输出字节、节省比例与可选媒体元数据。
- 节省比例由 Rust 按字节值重算，不信任前端传入值。
- 归档任务拒绝媒体元数据；未知指标版本和未知字段被拒绝。
- 只有确定的最终输出字节才会自动进入历史，估算值不会冒充实测。

## 迁移策略

SQLite schema 从 V6 升级到 V7，只向 `task_operation_history` 增加可空的 `workload_kind` 和 `metrics` 列。迁移不回填、不重写旧行；API 读取旧 `NULL` 时才解释为 `archive`。迁移可重复执行。

## 需求对齐结论

B-00.1 已收口。没有新建媒体 Tab、没有媒体引擎、没有第二套队列或历史数据源，也没有将估算数据写成实测。该步骤不构成版本发布节点。
