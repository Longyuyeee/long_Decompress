# Long解压 v1.5.42 · 失败后调整并继续

压缩或转换没有完成时，在当前条目看清原因、调整配置，再确认启动新的任务。

- **原因就在任务旁**：压缩和转换详情显示已知原因与下一步，原始错误可展开。重名拦截会明确提示换名称或保存位置；缺卷、编码、不支持方法和原因未确定的情况分别说明。
- **转换重试保留加密需求**：分别确认原包密码与新包密码，避免清空密码后把原定的加密新包改成不加密。明确选择“新包不加密”仍然可用。
- **带入原设置继续处理**：失败压缩可带入原方法、强度、分卷和保存位置创建草稿；转换创建关联的新条目，重名时建议新名称。已有待处理项会直接返回，不反复添加。
- **任务栏重试先回到配置**：解压返回原条展开纠正，压缩和转换进入待确认草稿；失败或取消的旧任务保留，不再直接重跑旧任务。

保留单条展开、多选弹窗、自然继承和左右等宽布局。新条目创建后仍由用户确认启动，原失败记录、原文件和已有结果保留；查看指引不会额外运行完整性检查。

本版沿用既有格式与算法，没有增加格式矩阵或盘满检查。下一步按路线推进 v1.5.43 批处理与结果体验，再进入五模块分阶段开发。
