# v1.7.4 · LZOP 损坏后，先取回完整的文件

普通 LZOP 后续成员损坏、被截断或缺少数字卷时，现在可以沿失败任务的 **检查并尝试救援** 入口，选择此前已完整结束并通过校验的文件，直接保存到独立的“部分取回”文件夹。

## 本版更新

- 新增完整成员前缀检查，核对文件头、数据块、结束标记和内容校验；首个损坏、无内容校验或缺卷位置之后不继续猜文件。
- 取回范围放在二级弹窗中，支持筛选、勾选、空文件和成员路径；停止原因默认收起，说明放进问号，保留原有单条展开、多选弹窗与等宽布局。
- 原包与已有结果保留；取回前核对来源，发生变化时要求重新检查。取消清理本次暂存，完成后统一展示独立结果目录。
- 历史明确标为 **LZOP 部分取回 / 已部分取回**，保留数量与停止原因，可重新检查原包。正常解压和全量转换仍要求来源完整。
- 保持“不支持的方法”和“损坏”分别显示，修正完整 LZOP 目录统计；部分诊断明确显示已确认范围。

## 使用边界

只支持普通 `.lzo` 及 `.lzo.001` 等数字切片的连续前缀。缺少中卷时，只读取从首卷到第一个间断之前的内容；后面的卷不拼接。没有可确认完好的完整成员时，不生成恢复结果。

这是部分取回，不能保证原包所有文件都已找到。LZOP 没有总成员数或总卷数，无法证明完整成员和其后内容是否整体丢失。本版不增加 TAR.LZO 内部条目救援、原生密码或原生块分段。
