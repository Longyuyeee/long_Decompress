# Windows 打开与双栏浏览体验

用户于 2026-10-26 确认：先处理本轮完整体验，再回归 TAR.LZO 目录创建等格式主线。本轮按用户确认提升为 v1.7.0，正式状态以 GitHub 标签和附件为准。

## 范围与顺序

1. 默认打开：设置中显示真实 Windows 文件关联状态，提供格式选择与系统设置入口；默认询问，提供当前文件夹、同名文件夹、自选解压文件夹、双栏浏览四个动作；可记住选择并在设置恢复。明确右键命令和软件内双击不受询问设置干扰。
2. 执行衔接：既有窗口与冷启动使用同一入口；分卷去重、再次打开已完成任务、运行期间的新任务排队、取消目录选择及密码/失败处理接入原解压中心；完成后使用实际结果路径。
3. Explorer 右键：四个明确打开/解压动作，移除重复的一键解压入口；压缩、转换、密码分卷、校验、救援按用途收纳，Windows 10/11 名称与行为一致。
4. 双栏统一：压缩包作为特殊文件夹，复用目录导航、地址栏、面包屑、列表列头/行高、选择与底栏；上一级可退出包，返回目录保留位置；搜索、密码、编码、详情与编辑能力按需收纳；图片和常用文本预览保留。
5. 历史任务：结果位置、再次执行、更多操作同排；更多操作为浮层，不改变卡片布局。此项已有本地修改，一并集成。

## 设计原则

常用操作就近放，次要功能进菜单，复杂配置进二级界面。主区域留给文件列表和任务内容，不重复展示目标目录、导航与介绍。保留单条展开、多选弹窗、左右等宽、已有主题和快捷键。

## 完成情况

上述五部分均已实现于 `codex/windows-opening-browser-ui`，本轮收尾版本为 v1.7.0。

- 默认打开与原生参数分流接通。Windows 文件关联使用用户级候选注册与真实默认处理器查询，不写 UserChoice；设置页可选择候选格式并前往系统确认。取消默认也通过系统入口完成，卸载清理仅移除本软件拥有的候选信息。
- 默认询问显示四个动作；自选目录取消不创建任务、不更改默认偏好。保存自选目录动作后，每次直接打开目录选择，取消不反复重弹。单包使用所选目录本身，多包在所选目录下分别建立同名目录。
- 直接动作进入原任务流程，沿用密码、缺卷与冲突处理。已完成来源可再次打开，活动任务避免重复添加，新任务等当前批次结束后运行。离开解压中心不会销毁正在运行的页面状态；完成后使用后端返回的实际目录，批量跨目录结果集中展示。
- 经典菜单使用真实嵌套子菜单，原生菜单使用独立枚举器；四个常用打开/解压动作在前，转换/密码分卷/校验修复在“更多操作”。旧快速解压 COM 身份保留兼容，但隐藏重复入口。补齐 ALZ、EGG、ZPAQ 与常见首卷入口。
- 普通目录与包内共用 `FilePaneNavigation`、`FilePaneList`。导航位置、表头、行高、单击选择/Ctrl 多选、复选模式及底栏一致；本地 TXT、包内图文预览均保留。返回目录恢复原选择与滚动，前进恢复缓存的包内位置；搜索、编码、密码、编辑、图片阅读等留在选项面板。所选文件夹的空目录只在所选范围内保留。
- 历史操作同排；更多结果菜单支持外部点击/Escape 关闭、焦点恢复和窗口边缘避让，不改变任务行高度。

- 默认关联与打开行为分开说明，未设为默认时明确提示先到 Windows 确认；不因保存动作而更改系统默认。
