# Long解压 v1.1.14

v1.1.14 完成压缩包浏览工作区 2.0。重点不是增加一个静态文件列表，而是把目录导航、对象化操作、安全预览、默认应用打开、嵌套归档和选择性解压收敛为可验证的正式安装版工作流。

## 主要更新

- 压缩包浏览中心支持文件夹树、面包屑、后退/前进/上一级/刷新、拖入打开、搜索、类型筛选、聚焦与多选分离以及键盘导航。
- 文件和文件夹右键菜单按对象提供打开目录、解压到当前或指定位置、复制名称/归档内路径、详情、内部预览、默认应用打开和进入嵌套归档。
- 默认应用打开先将单个条目提取到隔离会话缓存；CMD 等可执行或脚本内容默认取消，必须再次确认才会交给 Windows。
- ZIP/TAR 系列支持有界图片与文本预览。图片验证魔数、8 MiB 体积、8192 单边和 1600 万像素；文本只读前 1 MiB并识别常用中西文编码。二进制、伪装、截断和超限内容均拒绝渲染。
- 支持最多三层只读嵌套归档，逐层隔离密码、限制临时提取预算、校验父子内容哈希并阻断循环；返回时恢复外层目录、筛选、焦点、多选和导航历史。
- 归档读取具有真实取消请求与 30 秒用户等待上限；浏览、嵌套与预览格式策略由后端实际能力统一提供。
- 修复内部预览弹窗无法通过 Esc 关闭，避免预览遮罩阻断后续键盘或右键操作。

## 实际验证

- 正式 NSIS 覆盖安装后核对安装 EXE 与候选构建字节一致，确认生产版不含桌面测试桥。
- 真实 ZIP、加密 7Z、固定加密 RAR、TAR/TAR.GZ、中文八层路径、TXT/PNG/PDF/MP4/CMD 混合内容和 ZIP→加密 7Z→ZIP 三层嵌套均通过。
- 固定加密 RAR 使用正确密码解出两个文件，`foo.txt` SHA-256 为 `325d7b459b439684cad8825cbf2e488de15518103de09c56a42d6b1875081ee7`。
- 1280×800、150% 缩放下页面无横向溢出；18 万条目 TAR 在正式安装版中 78 ms 返回取消状态。
- 候选卸载后恢复 `v1.1.13`、原菜单目标及用户数据逐文件指纹。

## 边界

- 无商业代码签名证书的公开构建不包含 Windows 11 第一层菜单 identity package；完整功能位于经典“显示更多选项”菜单。
- 7Z 固实块和当前 RAR 读取无法证明严格有界，因此不开放内部图片/文本预览；元数据浏览、选择性解压和确认后的默认应用打开不受影响。
- 归档内增删改不在本版本范围。未来若实现编辑，必须重建新归档、完整验证并原子替换，不能原地修改。
- 图片、视频和 PDF 专项压缩继续作为后续独立节点，不与本版本混合发布。
