# v1.6.16 EGG 非固实大文本前缀封板记录

## 用户交付与范围

Store / Deflate / Bzip2 / LZMA 非固实大文本沿原双栏和文本弹层，最多显示前 1 MiB，明确“部分内容 · 未校验整文件”。双击、眼睛、右键、Ctrl+Enter、滚动和关闭保持；UTF-8、UTF-16 和已有兼容编码在字符边界显示。范围说明在问号内，超限给提取下一步，没有新增浏览中心或常驻配置。单条展开、多选弹窗、左右等宽、工具中心和主题保持。

helper 0.8.0 的独立 prefix 模块沿原 preview-text 操作自动识别非固实大文本，用有类型的主动停止标记区分前缀完成和读取/解码失败。只保留所选前缀，无临时提取目录；完整位于前缀内的数据块仍检查大小、CRC、终止条件，包括刚好到达 1 MiB 的块。最后只读部分的块与未访问尾部不作完整结论；早于目标前缀已结束或已有完整块损坏则拒绝显示。未改动算法解码器和完整 verify/extract 路径。

每次候选的实际所选压缩载荷读取最多 64 MiB，认证和解码共用同一计数，seek 不重置；候选整体 30 秒。带认证尾的 AES/LEA 仍需先认证完整所选压缩载荷，再按余下预算读取前缀，无法有界完成就拒绝；不承诺密码包只读取压缩文件开头。大 Store 可只读必要前缀，不因完整压缩大小大于 64 MiB 提前拒绝。读取范围不是整个进程总内存承诺。

复用手动密码、保险箱、显式代码页、完整原生卷、关闭取消与读取前后来源核对。候选不先整包验证、不写完整密码成功/使用计数，不运行暴力尝试；预算到达不循环尝试密码。小文本、图片和固实小图文保持完整条件，固实大文本/加密固实/创建/修复未开放，格式数量不变。

## 来源与增量检查

[生成器](../scripts/prepare-egg-prefix-1616.py)构造自有日志、四种方法、中文 CP936 ZipCrypto/AES、完整原生三成员、跨块与字符边界。像素/旧格式生成器不执行，只复用现有自有密码辅助函数；新增全部为受控，不是原工具新互通。LEA 前缀未新增正向原件，旧 LEA 完整小文本/密码组合沿用，不扩大所有历史组合口径。[清单](../tests/fixtures/archives/egg-prefix-1616/manifest.json)保留身份。
