# v1.7.1 · TAR.LZO 创建与转换记录

已完成功能封板，接续正式合并与发布。版本身份为 1.7.1，分支 `codex/tar-lzo-create-171`。

## 用户可以完成的操作

在原压缩中心直接选择 TAR.LZO，添加目录或多文件，沿单条展开、多选弹窗配置。原全局默认保持，选中修改自然形成各条配置。固定模式收起无效的强度和密码控件，切换目标清掉不适用的加密、固实、分卷及 RAR 恢复设置。

分析实际使用 LZO1X 编码采样。创建接入原进度、取消、完整校验、输出事务、结果位置及历史；来源归档密码只用于读取，目录、多文件与空目录完整转换。新产物继续在原双栏中浏览、预览、取回和转换。

## 实现与互通

复用有界 TAR 流桥与现有 LZOP 256 KiB 块编码器，编码时不另存完整 TAR。中文路径添加显式 UTF-8 PAX 记录，底层使用唯一 ASCII 备用名，避免 Windows TAR 按 ANSI 代码页解释原始 GNU 路径字节。其他 TAR 格式默认路径策略不变。

三种全新产物（目录、多来源、只有空目录）均由官方 lzop 完整测试和回解，再由 Windows bsdtar 按默认参数取出，逐文件哈希与空目录核对一致。长中文路径、空文件、图片及不可压缩数据均包含在新产物中。工具与新产物身份保存在 [独立回解记录](evidence/tar-lzo-create-1.7.1/official.json)。

## 保留边界

本版不创建 LZOP 多成员、密码或分卷。普通 `.lzo` 的单文件创建不变，完整数字卷读取保留；TAR.LZO 与 LZOP 的名称、目录语义分开显示。ALZ/EGG 有效外部原件缺口不因本版完成而关闭。
