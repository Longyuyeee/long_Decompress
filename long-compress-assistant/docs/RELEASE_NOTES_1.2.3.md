# Long解压 v1.2.3

v1.2.3 重点修复特殊压缩的设置、滚动、视频质量语义、任务反馈和 Windows 子进程体验，并彻底移除窗口最外层残留边框。

## 特殊压缩交互

- 图片批量设置改用主题化下拉菜单，不再显示浏览器原生下拉样式；单项图片设置采用紧凑对齐布局。
- 视频压缩新增独立的 1–100 质量控制，默认保持原分辨率；1080p、720p、480p 改为用户主动选择的分辨率上限，不再把“均衡”等质量概念等同于降分辨率。
- 图片、视频和 PDF 的任务列表按内容高度排布，超出工作区后在中间任务区域纵向滚动，不再压扁卡片或裁掉单项设置。
- PDF 空态继续保持精简，不再展示已经由执行边界保证的重复安全说明。
- 图片、视频和 PDF 任务统一出现在左侧全局任务栏，并明确标注“图片压缩”“视频压缩”或“PDF 优化”。

## 稳定性与窗口体验

- FFmpeg、FFprobe 和 qpdf 等生产子进程统一通过 Windows 隐藏窗口封装启动，导入视频、切换单项配置和处理 PDF 时不再反复弹出控制台窗口。
- 视频探测结果按真实路径、字节数和修改时间缓存；打开单项配置不会清空已探测的分辨率、时长、帧率、音轨和字幕事实，连续调整设置采用短时合并后再规划。
- 无装饰窗口的 WebView 内容现在直接贴合窗口边界，删除 1 px 透明缓冲、圆角外框和焦点边框，避免最外圈出现白色边线。

## 验证

- 真实 Windows Tauri/WebView2 分别完成图片、视频和 PDF 工作区门禁，覆盖实际输出、取消、历史、重启、默认应用、任务栏分类及 1100×720/760×560 滚动布局。
- 视频真实矩阵覆盖 10 分钟输入和约 114.8 MB 的 1080p 输入；取消后进程退出、暂存和最终文件清理，源文件哈希保持不变。
- 最终候选由 computer-use 实际打开检查窗口边缘、三个 Tab、图片下拉弹层、视频质量/分辨率设置和 PDF 空态。
