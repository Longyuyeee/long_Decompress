# Long解压 v1.5.37

ZPAQ新增快照对比与变化提取，让两次备份之间的变化更容易找到、确认和取回。

- **在原浏览器对比两版**：点击“对比快照”，选择较早/较新版本，查看新增、变化、内容候选、元数据、移除与未变数量。支持搜索、筛选和分页，长列表每页200条。
- **候选按需精确核对**：先比较目录与内容片段引用，引用变化只标为候选；需要确认时，临时提取所选候选并计算SHA256，显示实际阶段/字节，支持停止和清理。同大小、同时间的内容变化不会仅凭元数据漏掉。
- **按正确版本提取所选内容**：新版的新增/变化与旧版移除项可分别选择，创建独立的待处理任务和版本输出子目录，保留文件路径。目录不会隐式带出未选子文件，空目录可保留；创建后由用户在解压中心开始。
- **密码、分卷与工作接续**：普通/原生密码和完整数字卷组可继续对比；草稿、补卷重试和历史重做保留快照、所选范围与目录标识，密码重新填写。来源变化会提示重新对比，不改成最新版本或整包提取。
- **沿用现有界面**：单条展开、多选弹窗、自然继承、左右等宽和窄窗滚动保持，提取结果继续使用原统一入口。

本版比较同一完整日志式ZPAQ的两个版本，不修改原包或执行删除同步。目录对比不是整包内容校验；精确核对会依次使用临时空间处理所选候选，不保证固定速度。流式包、跨归档比较、原生追加多部分和损坏事务救援另行研究。
