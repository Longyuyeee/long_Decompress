# v1.6.28 · 密码 PPMd 7Z 直接查看图文

带密码的非固实 PPMd 7Z，现在也能在原双栏直接阅读小文本、预览图片和连续看图。

- 支持 AES 内容加密和文件名加密，完整文本 ≤1 MiB、PNG/JPEG/BMP/GIF/WebP ≤8 MiB；完整数字分卷可从有效的非首卷进入。
- 沿用手动密码和密码保险箱。手动密码错误时直接提示；留空可尝试保险箱，只读取目录和所选内容，不先验证无关大文件，不把预览记作整包密码成功。
- 沿原图片阅读器翻页、缩放、跳过坏图、定位及准确提取当前页；文本编码识别、滚动和“完整显示”保持。
- 同时确认 AES 明文/密文长度、零填充与完整消费，以及 PPMd 声明大小、实际结束、完整压缩覆盖和 CRC。错误密码或损坏内容不显示成完整图文。
- 保留实际输入、字典、时间、取消和来源范围。缺卷、来源变化、超限或不支持时给处理下一步；固实和大文本 PPMd 暂时仍需先提取。

保留单条展开、多选弹窗、左右等宽、主题/工具/快捷键，格式数量不变。下一阶段仅规划未加密小型固实 PPMd 图文预览。
