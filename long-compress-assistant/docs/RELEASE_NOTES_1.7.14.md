# v1.7.14 · PAX 1.0 稀疏文件部分取回

TAR.LZO 后段损坏或缺卷时，已校验连续前缀内的完整 GNU PAX sparse 1.0 文件也可以取回。

- 识别专用元数据中的真实名称，避免出现 `GNUSparseFile` 占位目录；支持长名称、跨块稀疏图、多段数据、全零文件和大空洞。
- 分清映射、填充与包内数据，确认完整后才列入可取回清单；取回保留空洞和原修改时间，后续普通文件正常衔接。
- 沿用原选择列表、折叠结果和部分历史，继续区分完整大小与包内数据；单条展开、多选弹窗和等宽双栏保持原交互。

本次扩展局部 PAX sparse 1.0；0.0/0.1 部分取回、链接与缺口后扫描未扩展。未知或冲突布局明确停止，目标目录须支持稀疏文件。

见 [本版范围](ARCHIVE_ROADMAP_1.7.14.md)、[实现与检查](TAR_PAX10_FREEZE_1.7.14.md)。下一阶段 [v1.7.15 PAX sparse 0.1](ARCHIVE_ROADMAP_1.7.15.md)仅规划。
