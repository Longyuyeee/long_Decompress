# v1.6.35 · Deflate 固实图文预览

## 完成范围

按[本版路线](ARCHIVE_ROADMAP_1.6.35.md)接通普通 Deflate 与有序 AES → Deflate 固实 7Z，完整文本 ≤1 MiB、受支持图片 ≤8 MiB，完整共享压缩/解码各 ≤64 MiB。新增独立 read_solid_deflate_entry：确认唯一所选普通条目、完整共享映射/顺序/条数/大小与 coder 形状/绑定，固定 32 KiB 输入/输出块依次分发各文件 CRC，仅追加所选正文。跨文件边界和零长流保持顺序，其他内容解码后丢弃，不保留共享整块。必须明确 raw Deflate StreamEnd、精确压缩明文消费与输出总大小，再完成原始/解密 EOF、AES 密文/明文长度与零填充回执，检查全部可用文件、块及打包 CRC 后返回。先前或后续依赖失败均不能显示所选正文为完整成功。

内容/文件名加密、原手动密码/保险箱、完整数字卷与非首卷贯通；手动错误不回退，预览不记整包密码成功。元数据与载荷实际输入、AES 参数/整体时间、块内取消和来源绑定沿用原限制；完整目录头的 AES 消费条件独立保留。原非固实 Deflate、LZMA/LZMA2/PPMd 和默认提取路径不改，仅删除已被本版替代的旧固实不支持断言，不重跑已过旧矩阵。

原双栏预览、编码/滚动、整包阅读、翻页/缩放、跳过坏图、定位与仅提取当前页沿用；只更新原问号说明，保持单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键。大文本和 Deflate64 继续给提取下一步，无新增格式计数、依赖或许可变化。

## 本版必要检查

原版 7-Zip 26.02 生成普通、AES 内容、AES 文件名和完整数字卷四组固实 Deflate 原件，官方 26.04 独立逐文件回解 SHA-256，并确认 Solid +、Blocks 1 和方法列表。包含前置/后续文本、精确方括号路径、相邻路径、空项、UTF-8/UTF-16/GBK、二进制、精确 1 MiB/刚超出、五种图片与正确 CRC 的坏栅格。共享解码精确 64 MiB/刚超出和 AES 固实图片精确 8 MiB/刚超出也独立回解；受控密文损坏由独立工具确认失败。原件、参数和哈希见 tests/fixtures/archives/sevenz-solid-deflate-preview-1635/manifest.json，重复调用生成脚本仅核对并保留原件。

两项新共享单元通过：普通/完整 AES 的三字节短读，首个、空、跨块中间和末尾所选内容精确，正文完整但未终止、额外压缩明文或 AES 非零填充不能成功；前后/空文件 CRC、块/打包 CRC、条数/总量/映射和共享范围异常不能成功。六组后端通过：四组原件与每个数字卷成员、编码/首尾条目；五种图片及非首加密卷；保险箱与手动错误不回退且计数保持；依赖 CRC/共享映射/方法与读取中取消；共享/图片精确边界、二进制/大文本和损坏；取消/来源/缺卷/新请求。

类型/Vite、八处身份与新 Shell DLL 通过。五组实际 Tauri 桌面通过：保险箱加密固实文本完整/滚动；原图片像素；阅读器翻页/缩放/跳坏图/定位/仅当前页提取；普通/内容加密/非首加密卷的文本及两种图片命令和错误入口；取消/来源/缺卷和新请求。1100×650 文本、760×520 图片和阅读器三张截图已实看，内容/关闭与操作可见，无横向溢出，底层双栏等宽。候选 SHA-256 `d99f8cf7e05105bb723d64beb960de3b29cd70ac3083aba580bf0a086296f85a`，见[证据](evidence/sevenz-solid-deflate-preview-1.6.35/checks.json)。本地桌面构建 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置未改。入口 node scripts/test-tauri-desktop.mjs --sevenz-solid-deflate-preview-1635-only。

首轮后端 5 项通过、1 项失败：工具默认将边界样本拆成两个独立块，因而并非预期的超大共享块。仅为这两个边界原件显式设置 -ms=128m，重新由独立版本回解并确认 Solid + / Blocks 1；产品代码未改，只重跑失败的边界组，1 项通过，其余已通过组未重复。初始/修正/重跑日志一并保留。
