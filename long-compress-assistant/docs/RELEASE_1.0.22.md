# Long解压 1.0.22

本版本是发布治理与验收基础设施维护版，交付 v1.0.21 发布后形成的公开更新生命周期加固、文档与追溯更新。

## 公开更新验收加固

- 记录升级前应用 PID，必须确认旧进程退出后，才接受不同 PID 的新版重启进程。
- 等待新版 Tauri 启动阶段完成资源管理器菜单迁移，再进入进程收口和数据一致性检查。
- 只终止与当前安装路径完全匹配的应用进程，避免影响其他 Long 系列程序或同名进程。
- 在应用退出后校验两套用户数据目录，避免 SQLite 文件占用造成假失败。
- 保持传统菜单四类根、17 条命令、旧 `SubCommands` 清理和命令目标的严格验证。

## 发布内容

- 八个版本源统一为 1.0.22，并生成唯一的 `long_compress_shell_extension_1_0_22.dll`。
- README、开发审计、路线图和 Release 追溯同步到 v1.0.22。
- 正式发布继续生成 NSIS 安装器、updater ZIP、更新校验签名和 `latest.json`。

## 签名边界

本版本不配置 Windows Authenticode 或商业代码签名证书，也不分发 Windows 11 顶层菜单身份包。
资源管理器快捷操作继续位于“显示更多选项”的传统菜单中。Tauri updater 的签名是应用内更新包的完整性与来源校验，
与 Windows 商业代码签名不是同一机制，因此继续保留。
