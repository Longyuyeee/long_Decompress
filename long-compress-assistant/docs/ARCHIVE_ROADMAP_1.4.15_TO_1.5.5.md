# 十二版本开发路线：v1.4.15 至 v1.5.5

批准日期：2026-10-17。用户要求将规划写入开发文档并继续开发。

当前：v1.4.15 功能、实际用户链和资源观察已封板，候选统一 1.4.15，接续普通安装包与发布决定，见[封板记录](ARCHIVE_PERFORMANCE_FREEZE_1.4.15.md)。v1.4.16 及后续尚未开始；不在旧候选发布顺序未明确时擅自跨版本开工。

## 基线与顺序

正式版为 v1.4.13；v1.4.14 功能、真实页面及候选安装包已完成，PR #168 尚未合并、未正式发布。新开发从 `458b14b` 接续，使用独立分支 `codex/v1.4.15-archive-performance`，不修改旧候选的功能范围。

主线是增加真正可用的格式、密码及分卷互通、失败原因与恢复接续。已交付的 ZIP/7Z 密码分卷、格式转换/改密/重新分卷、普通 SFX 读取、LZIP、RAR5 恢复和标准 ZIP 缺卷部分救援不重复列为新功能。

以下是顺序里程碑，不是并行开工或一次发版的总门槛。新引擎先核实可分发实现、真实样本和能力，再冻结范围；遇到实质使用方式选择时询问用户。若某项实际已被支持，只补必要修正和证据；同一实现完成相邻阶段时可合并，不为凑版本制造改动。

## 第一阶段：现有格式与流程补强

| 版本 | 目标 | 实施及封板边界 |
| --- | --- | --- |
| v1.4.15 | 大包及海量文件性能 | 实测 ZIP 重复扫描、密码校验、暂存 I/O、取消响应及 RAR 进度扫描；优先减少有证据的重复工作。TAR 组合格式的完整暂存成本单独测量。记录耗时、内存、临时空间，不预设提速比例，不取消完整性校验。 |
| v1.4.16 | 旧工具中文密码兼容 | 在 UTF-8 与本机 Windows 编码之外，只补有真实包支持的旧编码（如繁体/日文）；浏览、解压、检查、转换和重试使用一致选择。默认不变，不盲目遍历所有编码，不把无法表示的字符替换后宣称密码正确。 |
| v1.4.17 | 特殊分卷兼容 | 核实并补齐好压 AES ZIP、7Z 特殊卷型；覆盖任意成员导入、正确归组、内容/文件名密码、缺卷与补回继续。使用原工具真实生成的卷，不靠改名模拟，不扩大现有好压 ZipCrypto ZIP 证据。 |
| v1.4.18 | ZIPX 标准多卷 | 取得真实 `.zxNN/…/.zipx` 样本，补读取、创建及密码/转换/重新分卷。先明确压缩方法和密码组合，独立互通通过才开放；已有 ZIPX 数字卷不重复算新增。 |
| v1.4.19 | RAR4 旧格式恢复链 | 核实旧 RAR、旧卷型、恢复记录及可用恢复卷的实际能力，明确 Rar.exe 条件；修复到副本，保留原件，无可恢复数据时如实说明。RAR5 现有能力保持。 |
| v1.4.20 | ZIP 部分抢救扩展 | 扩展边界与卷偏移可靠的特殊卷组及损坏布局；逐文件标明已恢复、缺失、校验失败和未知。仅输出完整且校验通过的内容，不猜末卷目录、未知卷长度或加密条目边界。 |

| 版本 | 目标 | 实施及封板边界 |
| --- | --- | --- |
| v1.5.0 | ZPAQ 浏览、密码解压与转换 | 接入真实引擎，完成目录、所选提取、原生密码读取和转换；分别确认流式/日志式归档，明确当前文件视图，不能混入重复历史文件。自动备份、增量更新和历史恢复交互另定，不默认扩张。 |
| v1.5.1 | ZPAQ 创建闭环 | 普通和原生密码创建、配置保存、历史再执行和转换输出，使用官方工具独立回解。原生多部分归档按规格单列，不把通用切片称为原生固定体积分卷；创建范围取决于引擎验证。 |
| v1.5.2 | ALZ 只读 | 识别、浏览、解压、检查、转换，覆盖实际算法、ZipCrypto 与卷型。首版不承诺 ALZ 创建；没有解码实现不只开放后缀。 |

| v1.5.5 | 外置卷 SFX 与旧自解压 | 补真实 EXE 首卷加外置数据卷、旧 RAR4 SFX 的归组、密码、缺卷和转换；仍只读归档，不执行输入 EXE，不承诺任意自解压程序。 |

## 每版共同要求

1. 开发前对照实际代码和[格式分级](FORMAT_SUPPORT_LEVELS.md)，区分已实现、仅有引擎能力、缺证据和真实不支持。以“格式 × 方法 × 密码 × 卷型 × 损坏状态”定义范围。
2. 失败原因由实际证据决定。确认损坏、缺卷或方法不支持时，不继续无效试密码；证据不足则说明未确定，不把所有失败都判成密码错误。
3. 使用真实入口与源文件，按导入、配置、密码纠正、补卷、重试和结果检查的顺序测试。新增创建要经独立工具回解及文件内容核对，不注入成功、不放宽断言。
4. UI 改动必须查看真实常用及窄窗口页面。单条行内展开、多选弹窗、自然继承、左右等宽和窄窗口滚动保持，解释置于就近问号，不重铺小字。
5. 智能目录、ZIP 并行解压仍默认关闭，用户主动开启；不恢复快速打包。Windows N 实机门禁继续取消，不扩大支持承诺。
6. 每个实施步骤审计、提交、推送；只跑受影响的检查，复用未受影响证据。每版自身范围完成后才封板、统一版本、更新两份 README/中文 Release、完成必需构建并发布安装包，不提前写成已发布。
7. 性能实测说明机器、输入、实现提交、重复次数、缓存及验证范围；没有可比数据不承诺百分比。保留 CRC/内容校验、准确分类、取消和输出清理。
