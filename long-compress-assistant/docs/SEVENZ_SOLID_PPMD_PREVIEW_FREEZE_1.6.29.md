# v1.6.29 · PPMd 小型固实图文预览

## 完成范围

按[路线](ARCHIVE_ROADMAP_1.6.29.md)接通原版未加密小型固实 PPMd7/PPMdH 7Z：所选完整文本 ≤1 MiB，受支持图片 ≤8 MiB，尺寸 ≤8192、像素 ≤1600 万保持。新增独立 read_solid_ppmd_entry，确认普通条目、共享流数量/顺序/逐项与总大小、单 PPMd 编码器/打包流、所选范围；共享压缩/解码分别 ≤64 MiB。分段走过整个共享块，逐项检查可用 CRC，只保留所选正文，最后核对 PPMd 声明总量后的 range coder 结束、压缩完整覆盖及可用块/打包流 CRC。每个依赖必须由自身或块 CRC 覆盖，所选 CRC 正确不足以放行后续损坏。

PPMd 阶数 2～64、字典 2048 字节～64 MiB，实际元数据/载荷合计 ≤64 MiB、候选整体 30 秒、块内取消及来源前后绑定保持。不整包临时解压，不保留前后无关文件，不扫描其他大数据块。复用 v1.6.27 的大小定义 finish_7z API，不解多余符号，默认模型/编码器/解码器和 ZIP registry PPMd 不改。原非固实 PPMd/AES、共享/非共享 LZMA/LZMA2 完整与部分路径不改，不新增依赖、外部运行引擎或格式数量。

原文本/图片弹层、编码识别/滚动/完整标记与图片阅读器的按需翻页、缩放、坏图跳过、定位及准确提取当前页贯通；完整数字分卷可从有效非首卷进入。帮助仅扩展原问号，保持单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键。密码固实 PPMd 和大文本前缀仍给提取下一步；不能确认范围、共享映射或完整结束时不显示完整正文。

## 必要检查与来源

原版 7-Zip 26.02 生成阶数 6/8 MiB、阶数 12/16 MiB 和完整数字卷三组未加密固实包，官方 26.04 独立逐文件回解 SHA-256；列表均确认 Solid +、Blocks 1。包含首个/后续文本、带方括号/相邻路径、空目录/空项、UTF-8/UTF-16/GBK、精确 1 MiB 与超限文本、五种图片、假图片和前后依赖。独立原件还包括精确 64 MiB/65 MiB 共享解码总量、精确 8 MiB/超限/超尺寸图片及密码固实。bad-flush 为受控尾部修改：独立工具测试与回解报错，但所有文件的独立回解 SHA 与原件一致，新路径仍按结束失败拒绝图文。65 MiB 无关 COPY 块先独立检查后受控损坏，所选共享图文继续准确读取。见 tests/fixtures/archives/sevenz-solid-ppmd-preview-1629/manifest.json。

六项后端通过：三组/每个卷成员的完整文本与首个/后续、相邻和编码边界；五种受支持图片及非首卷；前后文件/块/打包流 CRC、映射/顺序/大小、方法参数与读取中取消、有效块 CRC 单独覆盖所有文件和拒绝仅所选 CRC；正文可读而结束损坏仍拒绝文本/图片、跳过无关大块；共享/图片精确边界与超限、二进制、密码固实/大文本下一步；关闭取消、来源/缺卷与新请求。首次编译在测试开始前因工具会话中断，保留 backend-interrupted.log；恢复后六项一次通过，没有重跑已通过用例。由于入口分派有变化，仅补一项密码非固实连续性；不重复已过的旧 AES/KDF、PPMd 独立单元、算法/密码/分卷、安装和真实盘满矩阵。删除被本版替代的旧“普通固实 PPMd 不支持”负例。样本脚本保留已提交原件，在新检出缺少忽略的大块补充样本时仅重建该补充，不重做原件。

前端仅扩展原问号文字，类型/Vite 构建通过，没有重复未变交互的组件用例。五组实际 Tauri 桌面通过：准确完整共享正文/滚动；PNG 实际像素；原阅读器翻页/缩放/坏图跳过/定位/当前页准确提取；首个文件、阶数 12/非首卷与两个图片命令、结束失败/密码固实/大文本指引；取消/来源/缺卷/新内容与大块跳过。1100×650 正文、760×520 图片和阅读器三张截图已实看，关闭/正文/工具可见，无横向溢出，底层双栏等宽。候选 SHA-256 `0d3ebef861a69c2709b5b2c5d05692cb4380ddbd2112b6af146c7b0838e3d712`，见[证据](evidence/sevenz-solid-ppmd-preview-1.6.29/checks.json)。桌面使用 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置不改；入口 node scripts/test-tauri-desktop.mjs --sevenz-solid-ppmd-preview-1629-only。八处身份与新 Shell DLL 同步。
