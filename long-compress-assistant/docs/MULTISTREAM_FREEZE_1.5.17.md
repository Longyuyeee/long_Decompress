# v1.5.17 多段压缩流封板快照

2026-10-19，从正式 v1.5.16 的 41e4eb7 接续，运行时冻结 bb80afd。此文件记录合入前范围，后续候选安装器、受保护合入、固定标签和正式四附件收据在[本版 PR](https://github.com/Longyuyeee/long_Decompress/pulls?q=is%3Apr+head%3Acodex%2Fv1.5.17-multistream)及[正式 Release](https://github.com/Longyuyeee/long_Decompress/releases/tag/v1.5.17)接续，避免仅回填发布收据又触发整包构建。

## 用户可见改进

- GZIP、BZIP2、XZ 连续压缩流完整读取，跨段 TAR 的末尾内容不再遗漏；Zstandard 保持已有多帧能力。普通文件、TAR 包装流及已有 AES 单包内层检查采用同一路径。
- 后段截断、校验和尾部失败明确提示，不发布本次不完整结果；真实嵌套 OS 读写原因保留。多个完整 TAR 直接拼接明确报不支持，避免只得到第一包却报全成功。
- 普通流支持原生浏览及既有文本/图片查看器。从数字分卷首、中、尾成员进入，都先归一到完整卷组再预览；卷组压缩大小按整组统计。
- 单条展开、多选弹窗、自然配置继承、左右等宽及窄窗滚动保持。失败后补回来源，经原纠正弹窗建立新任务，由用户启动；旧失败历史保留。

## 已完成证据

[实施与复现](MULTISTREAM_1.5.17.md)、[检查计数](evidence/multistream-1.5.17/checks.json)、[独立回解](evidence/multistream-1.5.17/independent.json)、[实际程序结果](evidence/multistream-1.5.17/desktop-results.json)及[界面复用来源](evidence/multistream-1.5.17/completed-ui-reuse.json)。

八组独立工具原件：CPython gzip/bz2/lzma、系统 libzstd 与 GNU tar 1.35；独立 7-Zip 26.04 全内容回解哈希匹配。正面包不是改头小包；截断、破坏尾部及多个完整 TAR 拼接作为明确的派生反例。原件生成器、参数、工具版本和哈希随仓库保存。

52 项不同 Rust（14 新增、38 相关既有）、16 项 FileIntegrityView 前端、类型检查、前端打包及 Shell 版本 DLL 构建通过。相关 TAR 原因曾被笼统覆盖，仅修正并重跑该项；未受影响检查复用。普通生产安装器由必需 Windows package 提供，不将 E2E 程序冒称正式安装器。

25 条实际原生程序记录：八原件完整浏览/检查/提取并核对全部文件与空目录；八后段损坏不发布或遗留未发布暂存；八数字卷中间成员入口提取所选内容；另有单包和末卷图片预览记录。真实 UI 五条流程：普通文本、数字卷 TAR 末尾文本、缺卷补回后纠正/新任务/完整输出及旧历史保留、密码 ZIP 转换并独立回解所有文件和空目录、后段损坏诊断。没有注入进度或完成状态。

常用 1100×700、窄窗 760×520 共十张实际页面逐张实看，文字、按钮与纵向滚动可用。八张早期页面捕获时横向溢出断言通过，但原始几何值未落盘；最终诊断两张的几何记录保存，溢出为 0。截图像素受设备缩放影响，名称表示外窗设置，不冒称精确内视口尺寸。

## 范围与接续

浏览最多扫描 8 MiB，超过显示大小未知；文本保留 1 MiB、扫描预算 64 MiB，图片最多 8 MiB。预览是有界读取，不等同完整性验证。多个完整 TAR 直接拼接、未知布局或失败时的部分救援不在本版承诺范围。

既有普通流/TAR 数字分卷不是新格式；本版不开放 AES 容器分卷。下一步按[现有路线](ARCHIVE_ROADMAP_1.5.17_TO_1.5.19.md)做 v1.5.18 自有 AES 容器分卷，再 v1.5.19 逐文件校验原因/待补列表，均尚未实施，不重复规划。ALZ 方法 3、EGG 加密固实、真实 VHD 盘满补测和 Windows N 原边界保持；VHD 补测未执行不计通过。个人安装、设置与历史未修改。
