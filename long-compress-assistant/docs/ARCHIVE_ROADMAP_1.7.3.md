# v1.7.3 规划 · LZOP / TAR.LZO 数字分卷创建

状态：仅规划，尚未开发。接续 v1.7.2 的多成员创建，继续格式、算法、分卷与真实失败包兼容主线。

## 范围与顺序

1. 复用现有输出暂存与数字切卷流程，先接单文件和多成员 LZOP，再接 TAR.LZO 目录创建。切片是完整标准流的字节分段，不宣称是 LZOP 原生块分段或原生多卷格式。
2. 在原单条展开、多选弹窗和转换设置中开放有效的分卷大小，保留自然继承和结果整组入口，不新增工作区；密码选项继续关闭。
3. 新产物从任意完整卷打开，接通原双栏目录、图文预览、所选取回、全量检查、整组转换和历史；外部工具先合并切片，再逐文件核对内容与目录。
4. 覆盖不足一卷、正好整卷时不产生空尾卷、缺中间卷和缺尾卷提示、成员/数据块跨卷、运行中取消与后续重试。失败和取消不发布半组，保留原来源；只运行新链和受影响检查后封板。

序列和数字切片没有总成员数或总卷数字段，不保证识别“完整成员及其后内容一起被删掉”的情况。目录及空目录继续使用 TAR.LZO；不新增原生密码、LZOP 块分段或缺卷救援。真实用户失败包可按影响优先修复；ALZ / EGG 外部原件缺口继续保留记录，不以本阶段完成代替。
