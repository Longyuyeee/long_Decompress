# v1.5.39 固实 WIM / ESD 实施

2026-10-21，接续正式 v1.5.38（PR #233，标签74a007ca0d1201c60905407a63704743a98ebfc9）。按既定路线完成固实内容归档接入。

## 实现与用户流程

复用已随包锁定的 wimlib 1.14.5 独立编码器，不新增上游二进制或运行依赖。WIM 方法增加 `solid`；固实使用 LZMS、64 MiB 固实块、128 KiB 元数据块、单线程，ESD 目标无论旧方法值是什么均强制真实固实。文件头版本0xe00与固实资源引用有独立依据，不能只改后缀。原 Store、XPRESS、非固实 LZX/LZMS 不变。

WIM 在原方法处选固实，ESD 显示固定方法，不让用户选择无效等级或原生密码。就近说明单线程约640 MiB预算、更耗时间、选单文件也可能读取同块其他数据；此预算来自随包对应源码的 wimcapture 手册，不保证固定效果或性能。压缩前不套用旧 Store 体积估算，原实际阶段/字节进度、暂停停止和暂存发布复用。

普通包与数字分卷沿原读取、浏览、文本/图片预览、检查、所选/整包提取、补卷新任务及统一结果。多镜像维持编号目录和现有 `[1].xml` 内容视图；密码原包转新 ESD，ESD 数字卷转密码 ZIP。原包和目标密码相互独立，WIM/ESD 不支持原生加密，带密码多选转为无密码格式前明确报出未修改。

方法串接前后端、配置组、模板、预设、草稿和历史；继承的 ESD 只在有效值层固定固实，打开不脱离全局。单条展开、多选弹窗、左右等宽和窄窗滚动保持。

## 依据与范围

独立 wimlib capture/append 与 7-Zip 完整回解中文、同名层级、空文件/目录和默认系统排除名称；双镜像的编号与 XML 也按实际内容核对。实现检查和实际桌面记录见[封板](WIM_SOLID_FREEZE_1.5.39.md)与[证据](evidence/wim-solid-1.5.39/)。

不含原生 SWM 创建、Windows 部署、系统启动或完整权限元数据备份保证；数字卷仍需整组，不冒充 SWM。预览沿现有时间和内存边界，超限按提示提取后打开，不全局放宽限制。[下一版原生 SWM 创建](ARCHIVE_ROADMAP_1.5.40.md)仅规划，尚未开发。
