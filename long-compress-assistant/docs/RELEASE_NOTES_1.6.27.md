# v1.6.27 · PPMd 7Z 直接查看图文

未加密、非固实的 PPMd 7Z，现在也能在原双栏直接阅读小文本、预览图片，无需先提取整个压缩包。

- 支持完整文本 ≤1 MiB，沿用原编码识别、滚动和“完整显示”；准确区分相邻文件名与带方括号路径。
- 支持 ≤8 MiB 的 PNG/JPEG/BMP/GIF/WebP，沿原图片阅读器翻页、缩放、跳过坏图、定位和提取当前页。完整数字分卷可从有效的非首卷进入。
- 核对声明大小、完整压缩覆盖、CRC 和 PPMd 实际结束状态。正文可读而编码尾部损坏时明确报错，避免误显示为完整。
- 保留实际输入、方法内存与时间范围，关闭取消、来源变化和缺卷沿原流程提示；不扫描无关大文件，不新增整包临时解压。
- 密码、固实或大文本 PPMd 暂时给出“先提取后打开”，下一阶段单独规划密码 PPMd 图文支持。

单条展开、多选弹窗、左右等宽、主题和快捷键保持，帮助收在原问号。格式数量不变，原 ZIP PPMd 与既有 LZMA/LZMA2 预览路径保持。
