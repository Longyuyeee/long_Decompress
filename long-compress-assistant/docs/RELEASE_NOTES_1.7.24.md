# v1.7.24 · ZIP / ZIPX 修改时间保留

压缩或转换为 ZIP / ZIPX 时，普通文件、空文件和已写入的目录条目现在使用源修改时间，不再统一落到默认日期，便于按时间查找和比对。

- 现有 ZIP 方法与 ZIPX XZ 共用日期规则，密码、数字/标准分卷和原转换入口保持衔接。
- 沿 ZIP 标准的本地日期记录，精度为两秒；1980–2107 年之外使用边界日期，并在任务日志提示，原文件不变。
- 不增加设置项，保留单条展开、多选弹窗、等宽双栏及结果和历史入口。

本版不增加格式数量，不承诺 UTC / 亚秒扩展时间或此前未编码的顶层目录时间。见[本版范围](ARCHIVE_ROADMAP_1.7.24.md)、[实现与检查](ZIP_SOURCE_TIME_FREEZE_1.7.24.md)。下一阶段 [v1.7.25 ZIP 顶层目录与目录时间](ARCHIVE_ROADMAP_1.7.25.md)仅规划。
