# v1.5.35 ZIP PPMd 创建实施

2026-10-21，接续已正式发布v1.5.34（PR #229，标签5fe6846bf732e6817e2036e8ad84a2ccee1a8c91）。本版按既定顺序完成，未启动下一版运行时。

ZIP方法增加PPMd（方法98），沿用已启用的zip 8.6/ppmd-rust，不新增引擎或产品依赖。默认仍Deflate，Zstandard/BZip2、ZIPX固定XZ不变。PPMd1–9级对应真实阶数与字典参数，旧0按1；6级字典32MiB、9级256MiB。逐条与转换根据当前等级就近显示预算，字典不等于总内存，不承诺压缩率或速度。

抽样使用同一个ZIP PPMd写入器，含方法参数和收尾，最多2MiB内容；逐64KiB检查取消，避免套用Deflate。实际创建PPMd也限制为最多64KiB复制批次，沿现有暂停/取消点和字节进度；其他方法的复制策略保持。模板导入/导出、配置组/预设、草稿、历史重做和批量修改均保留PPMd，方法限定修改ZIP，无关任务继续自然继承。

普通、AES-256、ZipCrypto与单包/数字/标准卷接通。任意卷浏览/有界预览/完整检查/所选与整包提取、密码原包双向转换、补卷新待处理与统一结果均有实际证据。单条展开、多选弹窗、50/50及窄窗滚动保持，方法仍在原位置，转换时与目标格式并排。

六项Rust、六项前端、三条公共原生和六条实际UI完成；包含9级真实混合内容的暂停恢复和资源记录。外部7-Zip中文AES密码编码差异由独立认证/解密+pyppmd回解核对，只调整测试解码器，未改产品和密码夹具。旧格式/密码矩阵与真实盘满未重跑，具体记录见[证据](evidence/zip-ppmd-1.5.35/)。

v1.5.34正式流水线在附件上传后立即读取CDN曾返回BlobNotFound，发布随后由真实下载和身份核对完成。本版为该读取增加有限退避重试，附件上传、版本和签名规则不变，避免重复打包。

README、[中文Release](RELEASE_NOTES_1.5.35.md)与[封板记录](ZIP_PPMD_FREEZE_1.5.35.md)同步，最后候选、受保护合入/标签及正式四附件收据写本版PR，不额外回填触发打包。[v1.5.36 ZPAQ增量更新](ARCHIVE_ROADMAP_1.5.36.md)只规划，尚未开发。
