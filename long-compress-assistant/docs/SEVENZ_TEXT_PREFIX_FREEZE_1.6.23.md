# v1.6.23 · 7Z 非固实大文本开头

## 本版范围

按[路线](ARCHIVE_ROADMAP_1.6.23.md)接通未加密 LZMA/LZMA2 非固实大文本前 1 MiB，保留原双栏文本弹层。独立前缀接口准确映射唯一普通文件、单 coder/单打包流与声明大小，实际输入合计 ≤64 MiB、字典/头范围与每次请求候选整体 30 秒保持。声明总解码大小不作为前缀分配大小，65 MiB 原版独立流可只读开头；每 32 KiB 输出检查取消，只留显示字节，无临时整包，不读无关块。

vendor 新增 read_single_entry_prefix 与仅允许裸 LZMA/LZMA2 的 add_prefix_decoder；前者不会读取剩余尾部或校验完整 CRC/编码结束，后者保留预览范围字典/方法/形状检查，不把独立流的声明总解码量当作内存分配。原 add_decoder 提取共用构造函数；实际桌面随后发现旧完整流程的 LZMA2 结束标记可被大小/CRC 包装遮住，新增 Lzma2EndReader 在最后输出返回完整回调前检查真实结束，仅作用于裸 LZMA2 / AES+LZMA2 完整栈。前缀独立入口不受此完整条件影响，AES 完整消费要求未改。小文本/图片仍走完整入口，密码/固实大文本和未知组合给提取下一步。

字符边界沿原 UTF-8/BOM、UTF-16 代理对与常用编码启发式处理，截断不强求完整末尾；完整 7Z 文本仍保留末尾检查。原预览窗口明确“部分内容 · 未校验整文件”、已读/声明大小、只读，并增加紧凑“提取后打开”复用原完整提取/默认应用命令。关闭可取消，来源前后绑定、缺卷和迟到丢弃保持；不记整包密码成功或使用次数。单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键与格式数量保持。

## 来源与验证

三组原版 7-Zip 26.02 非固实 LZMA、LZMA2 和数字卷，经官方 26.04 独立回解逐文件 SHA-256 核对。另有原版 65 MiB 总大小、固实、密码、Copy 方法及完整单日志边界样本。受控尾部/开头损坏和 65 MiB 无关 COPY 块损坏明确标注，不冒称原工具自然损坏来源，见 `tests/fixtures/archives/sevenz-text-prefix-1623/manifest.json`。尾部损坏允许显式部分预览，完整入口必须仍报错；开始损坏、短输出和二进制不显示。

首次五项新 Rust 中四项通过，一项因固实负例保留 -ms=off 被原工具生成多个独立块而未通过；只修正这份原件、独立确认 Solid +/Blocks 1，再仅续跑该一项通过，已过结果保留。五项前端通过（原四项后补“提取后打开”一项，不重复原四项）；最终前端因增加该操作重新构建，旧产物未当作最终桌面候选。首次桌面前两组前缀/编码与宽窄显示通过，第三组实际完整性命令暴露旧 LZMA2 尾部结束误报。只新增完整路径回归（损坏末尾拒绝、正常非固实和原加密固实完整检查/图片兼容），修复后重新生成候选；原前缀代码和前端未改，前两组及截图结果保留身份，仅接续剩余完整路径/来源两组。四组实际桌面完成（原前两组保留候选身份，后两组在完整结束修复后的最终候选接续）：原双栏明确部分/可滚动/全文入口、LZMA/非首卷与五种编码边界和 65 MiB 声明总量、未读损坏尾部与完整校验区分/不支持及二进制提示、取消/来源/新请求和无关 65 MiB 损坏块跳过。1100×650/760×520 CSS 窗口两张截图已实看，原双栏等宽、无横向溢出，关闭和全文入口可见。候选 SHA-256 `563a6e9a2772e06b47048f22914e4476b0758f5b50e19b2591aa0edd773d3b3f`，见[证据](evidence/sevenz-text-prefix-1.6.23/checks.json)。初次 Rust 日志中大体积 panic 内容在证据副本明确省略，四项通过与失败原因保留。
