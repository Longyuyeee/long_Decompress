# v1.7.25 规划 · ZIP 顶层目录与目录时间

状态：仅规划，尚未开始。接续 v1.7.24 的 ZIP / ZIPX 源日期写入，补齐用户选择文件夹时的目录身份与还原时间。

1. 审计 ZIP 当前的隐含父目录和显式目录路径。保留目录结构时，让非空顶层目录拥有明确条目和自己的修改时间；空根、同名目录、重复来源与扁平方式分别保持明确规则，不能因为增加目录头改变文件去向。
2. 解压完成后按由深到浅还原实际编码的目录时间，避免写入子文件后把文件夹日期变成当前时间；核对正常解压、所选目录与原转换流程。隐含父目录没有源时间时不伪造保留。
3. 先完成 ZIP / ZIPX 的普通、必要密码/分卷和边界组合。若需调整共享收集器，保持 TAR、7Z 原有路径规则，其顶层目录增强另行安排；只运行受影响检查。

完成标准：用户选择含文件的文件夹创建或转换 ZIP / ZIPX 后，目录名与文件位置保持原规则，已编码目录的可表达日期在解压后恢复。

当前 ZIP 本地日期精度为两秒，1980–2107 以外使用边界日期并提示；UTC / 亚秒扩展时间另行评估，不在本期暗示支持。之后继续推进格式、算法、密码、分卷与容错兼容；ALZ / EGG 外部原件、原生密码/块分段及其他既有缺口保留。
