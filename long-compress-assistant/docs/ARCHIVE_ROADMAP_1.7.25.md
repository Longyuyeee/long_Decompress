# v1.7.25 · ZIP 顶层目录与目录时间

状态：已完成并封板，正式 Windows 产物由本版 CI/Release 接续。

1. ZIP / ZIPX 保留目录结构时，非空和空顶层目录均有显式条目与自身日期。不同位置的同名来源各自保留根目录并一致改名整个子树，避免旧流程把两份目录混放；同一规范来源重复加入只收录一次。文件/目录名称及大小写冲突也按根统一处理。
2. 扁平创建沿原命名与重复选择规则，TAR / 7Z 仍用原收集器，未改它们的路径布局。
3. 解压只收集实际编码、属于本次选择且在暂存中仍保留的目录日期。最终内容提交并完成暂存清理后，由深到浅恢复；冲突待确认保留时间清单，确认后继续提交，不重解压。只选文件、不保留路径或关闭时间保留时不套用父目录日期；隐含或歧义目录不伪造日期。
4. 原正常/所选解压、密码、数字/标准卷与转换衔接；读取目录元数据可取消，提交前重查原包/卷组版本。新增原生 6 项、相关旧 2 项及 6 份归档/74 个条目的独立核对通过，见[封板记录](ZIP_DIRECTORY_TIME_FREEZE_1.7.25.md)。

完成标准已满足：普通来源文件夹的名称和内部位置保持；原先会混放的同名来源以各自根目录明确区分，已编码目录的 ZIP 可表达日期在提交后恢复。UI、结果与历史入口保持。

下一阶段 [v1.7.26 TAR 目录结构与同名来源一致性](ARCHIVE_ROADMAP_1.7.26.md)仅规划。ZIP 本地日期仍为两秒、1980–2107 边界；UTC / 亚秒扩展不在本版。7Z 顶层目录、重复扫描成本及后续格式/算法、密码/分卷和容错兼容继续分期；既有 ALZ / EGG 等缺口保留。
