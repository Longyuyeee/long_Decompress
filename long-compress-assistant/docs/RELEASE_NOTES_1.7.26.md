# v1.7.26 · TAR 目录结构与目录时间

打包多个同名文件夹时，TAR 现在为每份来源保留独立根目录，并统一调整整个子目录的名称，避免内容混放；同一来源重复加入只收录一次。

- 非空、空顶层文件夹均写入明确目录条目，解压完成后恢复包内记录的目录日期，避免日期被写入子文件的操作覆盖。
- 接通 TAR 及 Gzip、Bzip2、XZ、Zstandard、LZMA、Lzip、LZ4、Brotli、LZO 包装的创建与解压流程，覆盖完整数字 TAR / TAR.LZO 分卷和 TAR.LZO 内容转换。
- 冲突确认沿原暂存结果与目录时间清单继续，无需重新解压。只选文件、扁平或关闭时间保留时，不套用父目录日期。
- 修复 TAR 选中文件后扁平解压可能漏文件的问题。
- 保留原界面、单条展开、多选弹窗、等宽双栏与结果入口；ZIP、7Z 和扁平创建的原有规则保持。

本版不增加格式数量。见[本版范围](ARCHIVE_ROADMAP_1.7.26.md)、[实现与检查](TAR_DIRECTORY_LAYOUT_FREEZE_1.7.26.md)。下一阶段 [v1.7.27 7Z 目录一致性](ARCHIVE_ROADMAP_1.7.27.md)仅规划。
