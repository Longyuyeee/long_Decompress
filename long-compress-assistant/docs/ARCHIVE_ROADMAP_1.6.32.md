# v1.6.32 规划 · PPMd 固实大日志预览

仅规划，尚未开发。接续非固实大日志，让固实 PPMd 包里的日志也能先读开头，减少整包提取。

1. **先普通固实文本**：确认共享条目、顺序和逐项/总大小，只跳过所选条目前置内容并读取其前 1 MiB；前置与所选开头合计 ≤64 MiB，只保留所选开头。不校验未读共享尾部，不用完整 CRC/结束描述部分结果。
2. **再密码与分卷**：沿有序 AES → PPMd、原手动密码/保险箱、内容/文件名加密和完整数字卷；部分载荷使用显式 AES 前缀路径，完整目录头仍需完整消费，手动错误不回退，不记整包密码成功。
3. **保留界面与边界**：原文本窗口、编码截断、滚动、“部分内容 / 未校验整文件”和提取入口保持。实际元数据/载荷合计 ≤64 MiB，PPMd 阶数/字典、候选整体 30 秒、取消和来源绑定保持；超出前置范围、未知方法或映射不能确认时给提取下一步，原完整小图文不改。
4. **独立收尾**：原工具与另一版本回解核对，覆盖首个/后续所选、前置范围、密码/非首卷/缺卷、编码/二进制、取消/来源和原窗口宽窄显示。只做受影响检查，同步 README、Release 和交接。

保留单条展开、多选弹窗、左右等宽、工具中心和问号收纳。未知过滤器、跨页密码计算及其他算法另拆；ALZ 方法 3、历史 Bzip2/原工具图片和 EGG 加密固实仍需有效来源，继续回归格式与容错兼容主线。
