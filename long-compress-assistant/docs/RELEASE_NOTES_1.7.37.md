# v1.7.37 · 多帧 Zstandard ZIP 丢目录部分取回

一个文件使用多个 Zstandard 帧压缩、又丢失 ZIP 目录时，现在可沿原救援入口，取回已经完整确认的成员并另存新包。

- 按累计尺寸和 CRC 确认整个成员，支持普通多帧、空帧组合、普通/ZIP64 及有/无签名描述符，避免把半个文件当作恢复成功。
- 接通完整数字切片、目录和混合方法，保留已确认修改时间；无签名 CRC 恰好类似帧头时也能正确识别。
- 后帧损坏、截断、矛盾或未知边界停止，原件与部分取回标记保持。新包验证、结果/历史和重试沿原流程，界面及交互保持。

未知尺寸恢复每个成员最多 4096 普通帧，窗口上限 256 MiB；可跳过帧、外部字典、历史 method 20 和密码未知边界仍未扩展，不增加格式数量。见[范围](ARCHIVE_ROADMAP_1.7.37.md)、[实现与检查](ZIP_ZSTD_MULTIFRAME_FREEZE_1.7.37.md)。下一阶段 [v1.7.38 ZIPX（XZ）流式取回](ARCHIVE_ROADMAP_1.7.38.md)仅规划。
