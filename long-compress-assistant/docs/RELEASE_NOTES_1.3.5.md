# Long解压 v1.3.5

失败之后，不只知道原因，也知道下一步如何处理。

- 损坏或不完整：引导重新取得完整文件，不误导反复试密码。
- 缺少分卷：按已保存详情核对，补齐后通过现有草稿重新检测，不猜测缺卷名称。
- 权限受阻：证据明确时区分来源读取与输出提交；仅有最后观测阶段时不下结论。
- 输出冲突、来源变化等问题提供对应核对步骤；未知原因保留原始详情并引导导出诊断。
- 保留回滚不完整的专项指引，页面与诊断报告一致。重新执行仍需用户确认，新任务不改写旧失败记录。

验证：前端 400 项通过；真实 Windows 损坏/完整 ZIP 队列、同名文件保留两者、可见失败指引、缺失中间分卷阻断、新草稿手动执行和重启历史一致通过。选择器路径响应由测试桥提供；权限分类为组件测试，不冒充实际 ACL 验证。

本版不改变解压引擎、历史保留上限或媒体处理策略。Windows N 暂不支持。
