# v1.4.6 功能封板记录

日期：2026-10-15（香港时间）。**功能冻结提交：`88972264923982d1f05df8bc11663dd05b425c7b`**，分支 `codex/task-details-scroll` / [PR #160](https://github.com/Longyuyeee/long_Decompress/pull/160)。本轮功能实现与定向检查完成，版本身份统一为 1.4.6；只接续仓库安装包构建及后续正式发布，不追加 RAR 或新格式。

## 冻结范围

- 失败条目在原位置展开纠正，缺卷显示名称并可打开目录，换来源、改密码与重新入队保留配置。多项仍使用弹窗。
- 损坏任务直接进入救援，恢复新包可沿用原设置或本次修改的输出目录、子目录和密码加入解压队列，原失败记录保留。
- 本地条目边界明确的 AES/ZipCrypto ZIP 丢目录救援，覆盖单包和完整数字卷；仅恢复完整文件，另存加密新包并显示部分恢复。
- 压缩/解压等宽详情、紧凑摘要、可滚动日志和小窗口任务行修正一并纳入。单条展开、多选弹窗、自然配置继承保持。

## 已完成检查

- 相关前端 4 文件 63 项、类型检查及最终普通前端生产构建通过。
- Rust 诊断/恢复 28 项通过；新增丢目录密码包、数字卷、ZIP64 元数据和已知/未知边界相邻的恢复检查。
- 实际 Windows Release WebView2：外部 7-Zip AES/ZipCrypto × 单包/数字卷共 4 个恢复组合，错密码拒绝、独立回解及原件哈希一致。
- 两条实际用户链通过：损坏失败 → 行内纠正 → 救援 → 保留改后的目录 → 再次解压；缺卷失败 → 显示缺卷 → 补齐 → 新任务 → 再次解压。
- 常用/窄窗口实际截图已查看。此前 20 个详情布局场景及既有安装、媒体、格式证据复用，不重新扩大矩阵。
- npm、Tauri、Rust 主程序、右键组件及版本化 DLL 同步为 1.4.6，版本身份检查通过；两份 README 与 [中文发布说明](RELEASE_NOTES_1.4.6.md)已准备。

## 安装包与发布接续

最终普通 Windows 生产安装器由仓库要求的 `Windows package` CI 构建，不将带测试桥的桌面程序作为正式安装包。最新结果及下载产物以 [PR #160 的检查](https://github.com/Longyuyeee/long_Decompress/pull/160/checks)为准，只有安装包构建成功后才满足正式发版条件。

当前用户要求推进到可发版，尚未要求本次直接合并或推送正式标签；本轮不创建 Release。后续正式发布时使用冻结范围与中文说明，按既有流程合入并创建 `v1.4.6` 标签，不重跑已完成的无关检查。

本地尺寸未知的数据描述符、缺卷、标准磁盘 ZIP 卷丢目录、未知边界和 RAR `.rev` 不在本轮新增能力内；部分恢复不代表原包全部文件已找回。
