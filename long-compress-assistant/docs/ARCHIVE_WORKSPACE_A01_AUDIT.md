# 压缩包浏览中心 2.0：A-01 交互状态模型审计

审计日期：2026-08-26

开发基线：`v1.1.13` / `codex/archive-media-roadmap`

结论：A-01 代码与聚焦真实桌面门禁通过；大节点 A 尚未完成，不提升版本、不制作正式安装包。

## 1. 本步目标与实现对齐

| 目标 | 实际实现 | 结论 |
| --- | --- | --- |
| 聚焦与多选分离 | 单击行只设置焦点；复选框、Ctrl/Meta 和 Shift 负责多选；目录不进入文件选择集合 | 通过 |
| 文件夹式目录导航 | 右侧列表显示直属文件夹，双击或 Enter 进入；左侧目录树仍可直接定位 | 通过 |
| 导航历史 | 增加面包屑、后退、前进、上一级和刷新；重新打开归档时清空历史 | 通过 |
| 键盘行为 | Backspace 上一级、Alt+Left 后退、Alt+Right 前进；输入框获得焦点时不拦截 | 通过 |
| 搜索与目录状态 | 非搜索状态只显示当前目录直属条目；搜索时匹配归档内完整路径；清空搜索后恢复当前目录 | 通过 |
| 响应式边界 | 页面和工作区禁止横向滚动，目录树、文件列表和面包屑各自有界 | 通过自动化；安装版 150% 系统缩放仍归入 A-06 总验收 |

本步没有实现右键菜单、默认应用打开、会话缓存、文本查看器或嵌套归档。这些分别属于 A-02 至 A-05，不能提前把大节点 A 标记为可发布。

## 2. 预期—实际—修正记录

### 2.1 桌面测试桥首次未注入

- 预期：Release Tauri 启动后桌面测试桥可用。
- 实际：窗口和标题可见，但测试桥等待 30 秒超时。
- 原因：Rust 使用了 `desktop-e2e` feature，但前端曾以普通生产环境构建，测试桥已被 Vite 条件编译移除。
- 修正：以 `VITE_DESKTOP_E2E=1` 重建前端，再以 `custom-protocol,desktop-e2e` 重建 Rust Release 二进制。
- 复验：桥接就绪，进入真实归档门禁。

### 2.2 目录切换后 Alt+Left 无响应

- 预期：双击进入目录后 Alt+Left 返回根目录。
- 实际：真实 WebView2 中双击后的原文件行已卸载，焦点回到页面外，绑定在页面根节点的键盘监听收不到事件。
- 修正：桌面运行时增加窗口级键盘监听；页面内事件先 `preventDefault`，窗口监听检测已处理事件，避免执行两次。
- 复验：真实桌面日志依次确认“双击进入 -> Alt+Left 返回 -> 前进 -> 上一级”。

### 2.3 旧桌面脚本仍按三项顶部配置查找输出目录

- 预期：输出目录由现有底部操作栏选择。
- 实际：旧门禁仍断言顶部存在三个字段，和当前两字段布局不一致。
- 修正：门禁明确断言顶部只有“当前压缩包、密码”，并通过底部 `output-target` 完成真实输出目录选择。
- 复验：三个格式均使用可见底部入口选择独立输出目录。

### 2.4 旧预览测试跳过了目录层级

- 预期：`art/preview.png` 在根目录可直接定位。
- 实际：A-01 正确把它展示为根目录 `art` 文件夹内的文件，旧测试直接找文件失败。
- 修正：浏览器回归先双击 `art`，核对面包屑，再打开图片预览。
- 复验：Chromium 四档宽度纵向滚动门禁通过。
