# v1.6.20 · 7Z 固实相册直接看图

固实 7Z 里的图片现在可以直接在原双栏查看，并进入现有图片阅读器，无需先把整包解压到临时目录。

- 支持未加密 LZMA/LZMA2 固实包内的 PNG、JPEG、GIF、WebP、BMP；完整数字分卷可从任意有效成员进入。
- 沿用双击、预览按钮、右键和 Ctrl+Enter，在原弹层中看图；原阅读器保留翻页、缩放、适应、坏图跳过、定位与准确提取当前页，另一栏位置保持。
- 按需读取当前页，保留原有限缓存，不在后台预读下一张。共享内容读取时显示简短等待，停止/换页/关闭能取消，过期结果丢弃。
- 检查整个共享块的大小、CRC、压缩覆盖与编码结束后，才显示所选图片；只保留这一张，不读无关数据块。
- 所选图片 ≤8 MiB、单边 ≤8192、总像素 ≤1600 万，共享压缩数据与解码总量分别 ≤64 MiB；元数据和载荷实际输入合计仍 ≤64 MiB，候选整体 30 秒。来源变化、缺卷、损坏和超限保留明确下一步。

本版不开放加密固实图片；非固实密码图文与既有完整小文本支持保持。单条展开、多选弹窗、左右等宽、主题和工具中心不变，格式数量不变。下一阶段已规划 v1.6.21 加密固实小文本，尚未开发。
