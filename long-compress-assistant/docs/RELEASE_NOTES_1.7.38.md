# v1.7.38 · 流式 ZIPX（XZ）丢目录部分取回

使用 XZ 压缩的 ZIPX 丢失目录、本地尺寸又未知时，现在可沿原救援入口，取回已经完整确认的成员并另存普通 ZIP。

- 确认单 XZ 流完整结束、块校验、索引/尾部、实际尺寸和 ZIP CRC，再匹配普通/ZIP64 及有/无签名描述符。
- 接通空文件、目录、混合方法和完整数字切片，沿已有规则保留可确认修改时间。
- 损坏、截断、矛盾或未知边界停止；原件、部分取回标记及结果/历史和重试流程保持，界面与交互保持。

此恢复路径解码内存上限 256 MiB；多流、填充、特殊滤镜/字典组合和密码未知边界未扩展，不增加格式数量。来源零字节 XZ 的外部工具差异及日期范围见[实现与检查](ZIP_XZ_RESCUE_FREEZE_1.7.38.md)、[范围](ARCHIVE_ROADMAP_1.7.38.md)。下一阶段 [v1.7.39 多流与合法填充兼容](ARCHIVE_ROADMAP_1.7.39.md)仅规划。
