# v1.7.23 · TAR.LZO 嵌套压缩包链接浏览

TAR.LZO 中已确认目标的压缩包副本，现在可以直接双击或通过右键继续浏览，原目标无需选中。

- 进入和返回都沿用同一栏的导航、面包屑与列表，返回恢复原目录、选择和滚动位置，另一栏保持。
- 支持本期确认范围的普通头、PAX、GNU 长名称和完整外层数字卷；内层密码独立填写，保持原三层和大小限制。
- 打开状态与取消收在原底栏；来源变化或内容无法识别时明确提示，失败清理本次缓存。
- 长路径和窗口缩放时露出当前面包屑，保留单条展开、多选弹窗及等宽布局。

本版不增加格式数量，不创建系统链接；其他链接的外部打开、前向/任意链条与符号链接继续分期。见[本版范围](ARCHIVE_ROADMAP_1.7.23.md)、[实现与检查](TAR_NESTED_LINKS_FREEZE_1.7.23.md)。下一阶段 [v1.7.24 ZIP / ZIPX 修改时间保留](ARCHIVE_ROADMAP_1.7.24.md)仅规划。
