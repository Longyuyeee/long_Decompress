# Long解压 v1.5.17

本版改善多段压缩流的完整读取，让最后一段内容也能正常浏览、提取和转换。

- **多段内容不再遗漏**：补齐 GZIP、BZIP2、XZ 连续压缩流读取，覆盖普通文件和跨段 TAR；XZ 的流间填充正常处理，已有 Zstandard 多帧读取保持。
- **后段损坏不报完成**：后续段截断、校验或尾部异常会明确提示并停止发布本次不完整结果；已有 AES 单包也会验证完整内层流。多个完整 TAR 直接拼接会明确说明当前不支持，避免只得到前一包却误以为全部成功。
- **普通压缩文件更方便查看**：原生浏览显示完整的小文件大小，文本和图片沿用现有内部查看器。较大文件显示“大小未知”，预览超出读取范围时引导先解压后打开，避免打开列表就完整读取大包。
- **原有流程保持顺手**：沿用数字分卷任意成员入口、所选内容、失败纠正新任务和密码 ZIP 转换，单条行内展开、多选弹窗、自然配置继承、左右等宽及窄窗滚动保持。

README 继续先介绍软件特点和使用方式，版本记录放在末尾。预览使用既有大小限制；有界预览不代表整包完整性验证。已有 TAR/普通流数字分卷不是本版新增格式，自有 AES 容器分卷继续留在下一版。
