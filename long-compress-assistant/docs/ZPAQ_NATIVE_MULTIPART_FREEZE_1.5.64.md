# v1.5.64 ZPAQ 原生多部分封板记录

2026-10-22。范围按[单版路线](ARCHIVE_ROADMAP_1.5.64.md)，功能与本版受影响流程已收口，可进入正常 PR 合入与发布。

## 本版实现

- `zpaq_multipart` 只提出编号候选，原始同名序列不自动成为来源组；浏览中心、显式解压导入、转换和历史重新定位沿共用确认弹窗。可确认整组或明确单文件。日期数字后缀超过卷编号范围的独立备份保留原读取方式。
- 确认后本机 `zpaq-sources/<id>/<原成员名>.zpaq` 是小型不可变来源引用，含成员路径、长度与修改时间，不含归档内容/密码。它不是可交给其他工具的归档；外部分享仍使用原成员。保留在应用数据目录，任务/草稿/历史只需引用它，不增加另一套任务配置模型。
- 引用接入共用 SplitArchiveDetector 与虚拟成员读取器，来源身份覆盖每个成员；ZPAQ 原适配器沿同一密码流读取完整有序组，快照无效不回退最新，选取不扩大整包。新增文件不自动加入已确认来源，原组变化需重选确认后建立新任务。
- 成员明细可折叠；解压默认同目录仍指向原成员目录。原增量更新不接收原生组来源，原生组取回不回收来源；本版保留整组原件、旧失败与已有输出。

- 四项 Rust：普通/密码真实整组各三快照全量提取与摘要、旧文图预览、所选历史文件；缺成员/补齐、来源变化/新文件不自动加入、次序异常、错误密码/快照不回退；明确单文件和更新边界。首次仅测试代码 `u64/u32` 类型不符，修正后四项通过。
- 日期命名兼容项单独通过；不重跑上述四项。缺号查找使用集合避免大编号组反复遍历。
- 六项不同前端：不影响其他后缀、确认前不提交、缺成员禁止整组/允许单文件、非首成员单文件选择、变化原因与保留弹窗；转换默认原成员目录和不可变来源接续。
- 最终类型/Vite、八处 v1.5.64 身份与 Shell DLL 已通过。最终桌面构建已通过。六条真实桌面流程完成，22 条 1100×700 / 760×520 布局无横向溢出，左右等宽保持，八张代表图已实际查看。最终程序 SHA-256 `c0d1a52acd60992e2b78e8f2f10d37b8204c66a6999c12ee5a634302bfec5567`；成功项按原程序身份保留，详情在[证据](evidence/zpaq-native-1.5.64/desktop-progress.json)。

真实桌面首轮的布局采集误把 `display: contents` 的图片容器当作有尺寸面板，已改采实际图片，保留已完成文本/确认布局。随后发现并修正两处产品断点：密码头没有公开 magic，快照校验需在 ZPAQ 后缀解析之后；浏览中心原先只给快照、未给精确范围身份，现对确认来源使用已有 ZPAQ catalog guard 与 selectedEntries 接续原历史/重试模型。只恢复受影响流程，原读取/确认/预览成功依据按其程序身份保留。

桌面闭环包括：从非首成员确认普通组并看旧版文图；密码组只取回旧版一个已删除文件；历史草稿正常退出重启，来源不变且密码不保存；真实缺第二部分失败，补回后从历史新建任务，仅取原选文件并保留旧失败/已有输出；密码旧快照转换独立 ZIP，经 7-Zip 回解逐文件摘要一致；普通/密码组从解压中心导入、同组成员去重及两项多选弹窗。全部六个原成员摘要未变。

脚本接续记录：图片采样容器、历史输出目录须存在、恢复后补密码和格式选择需精确匹配 ZIP（避免命中 TAR.LZIP）已按实际交互修正。批次失败面板检查尝试未记为通过，缺成员新任务闭环采用成功的历史入口；没有重复已完成的确认/预览/重启组合。原失败日志与最终收据分别保留。

## 边界与接续

目前候选识别名称末尾数字前缀，同组从 1 连续排序，可读等宽编号或不补零编号。复杂含数字固定前缀的自定义模板不承诺自动识别；现存成员不能证明未知尾部是否丢失，确认时应核对数量及预期快照。确认后缺任何已记录成员明确拒绝；补回相同版本重试，变更过的成员需重新确认。

不支持原地追加、原生多部分创建/更新、远端索引模式或损坏事务救援。下一版[原生多部分另存增量更新](ARCHIVE_ROADMAP_1.5.65.md)仅规划未开发；ALZ 方法 3、EGG 加密固实继续保留。旧全格式/密码/分卷矩阵、盘满、个人安装不重复。

候选/合入/标签及正式附件收据在本版 PR 接续；相同检查树不另起回填构建。
