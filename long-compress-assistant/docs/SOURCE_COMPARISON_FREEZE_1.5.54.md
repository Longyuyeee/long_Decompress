# v1.5.54 资料对比与所选取回封板记录

基于 v1.5.53，2026-10-21。完成对比模块首阶段，范围以本页和[中文说明](RELEASE_NOTES_1.5.54.md)为准。

## 已交付

- 新增资料对比工作区。文件夹↔文件夹、普通 ZIP↔ZIP、文件夹↔ZIP，按相对路径对齐，左右身份明确；类型/大小/时间变化、单侧条目、内容待核对与空目录可见。元数据相同始终是候选，不宣称内容相同。
- 搜索、分类计数、50 条分页、左右独立与跨页选择。单条就地展开；多选取回弹窗集中配置独立输出、左右分目录/合并、结构/平铺、同名改名/跳过。
- 目录所选复制与 ZIP 所选提取复用原解压任务队列、暂停停止、暂存提交、统一结果与历史；原件与已有结果保留，不退化成整包取回。最终收据返回实际提交字节，跳过不算新产出。
- 每次入队/执行/提交前复查来源元数据版本及精确路径，来源变化或消失先处理；旧失败保留，可用侧先入队，未入队选择保留。此版本依据并非完整内容证明。
- 待处理草稿保存来源、版本、所选路径、结构和冲突方式，正常重启后手动恢复/启动；历史再次取回只重做相同范围。不同来源版本的草稿不合并，临时多余字段不持久化。schema 保持 18。
- 原单条展开、多选弹窗、自然继承、压缩/解压左右 50/50 与滚动保持；新页面与弹窗宽窗等宽、窄窗顺排，不横向挤压。

## 范围

目录和独立未加密 Store/Deflate ZIP。密码/分卷/其他方法回原浏览器，重复/歧义、链接或无法完整读取来源明确失败，不静默截断。每侧最多五万条，选择最多两千条且路径 JSON 最多六万字符。非空目录通过文件选择，空目录可选。输出需在两侧目录之外且互不包含；原文件不删除、不自动覆盖。新模块的限制不收窄原浏览/压缩/解压能力。
