# v1.5.45 ZIP 目录整理与批量修改封板

[计划](ARCHIVE_ROADMAP_1.5.45.md) · [中文 Release](RELEASE_NOTES_1.5.45.md) · [记录](evidence/zip-organize-1.5.45/)。候选、正常合入、标签与正式资产收据在本版 PR 接续。

## 已交付

原编辑入口新增整理弹窗，按目录查看编辑后结构，支持路径搜索、分页、多选文件/目录、删除、重命名和移动；多选名称规则支持前后缀、字面文字替换、公共目标目录，文件扩展名保留。目录连同子项，重叠选择只处理独立根位置，先看修改前后路径及数量；同名、文件/目录冲突、无效路径或移入自身子目录在加入清单前说明，不覆盖其他条目。大小写改名可用。

结构操作与添加/替换按顺序进入同一会话清单，操作可逐项撤销或整体放弃，清单按类型和前后路径搜索。内部按来源身份重算后续修改，依赖已撤销新增内容的操作明确提示，不能误用同名的另一条目。原浏览器右键接整理与删除，原目录改名后添加/替换跟随到当前位置；已删除位置先提示选择新位置。

整理弹窗展示待保存结构，原浏览器继续读原包；保存前不拿新路径访问原包。统一另存沿原进度、日志、停止、失败纠正、结果与历史；失败/停止保留清单，已有目标、原包与旧失败记录保留。新包能浏览、预览和提取。删除最后子项后所保留的空目录可写出，也可删除全部位置另存为空 ZIP。

未改与仅改名内容按原编码复制，核对保留内容与新路径；原有效 ZIP 时间、方法和备注保留。新增/替换仍选 Store/Deflate。原单条展开、多选弹窗、自然继承、压缩/解压 50/50 与滚动保持；整理/复核宽窗等宽，窄窗顺排，长路径换行、条目分页、子项限量并可搜索定位。

## 范围与依据

仍限定独立未加密、原条目采用 Store/Deflate 的普通 ZIP，不扩大密码、卷型、自解压、嵌套临时来源及其他方法编辑。跨应用启动编辑草稿未在本版宣称，仍按 v1.5.46。没有接入任意外部应用回写或任意格式原地编辑。

56 项不同前端通过（16 项工作区、11 项原编辑、29 项受影响浏览器）；最后只补两项原位置接续，不重复已通过组。11 项相关 Rust 通过（5 项新结构、6 项原编辑/历史），覆盖组合编辑、名称互换、隐式目录变空、空 ZIP、无效映射、原件与停止清理。类型/Vite、Shell、八处版本身份与原生桌面构建通过。

三条桌面实际流程一次通过：组合整理并独立回解，冲突/失败后纠正并浏览预览提取，以及清空后另存与浏览空 ZIP。来源 SHA-256、已有输出与旧失败保留，新增/替换/保留内容正确。七处宽窄共 14 条布局记录无横向溢出，八图实际查看；所有桌面使用同一二进制身份。未跑无关旧格式/密码矩阵、盘满或媒体/个人安装流程。本地 E2E 程序不冒充正式包，候选及正式附件由流水线生成。
