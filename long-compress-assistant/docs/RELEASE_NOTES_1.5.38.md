# Long解压 v1.5.38

ZIP 增加 LZMA 创建方法，在熟悉的压缩与转换入口尝试更多归档方式，并保持密码、分卷和后续取回流程。

- **原位置选择 LZMA**：默认仍使用兼容 ZIP；LZMA 强度为 1～9，旧配置的 0 按 1 执行。随等级显示字典大小，6 级 8 MiB、9 级 64 MiB；编码总内存更多，接收方需支持 ZIP LZMA。
- **密码与分卷接通**：普通、AES-256、ZipCrypto，单包、数字卷与标准 `.z01/.zip` 可继续使用；原有中文密码编码选择保持。
- **从创建到取回**：按实际方法抽样分析体积，沿真实字节进度与暂停/停止；新包浏览、文本/图片预览、检查、所选/整包解压、补卷后新任务，以及密码原包双向转换使用现有流程和统一结果。
- **工作接续与界面保持**：配置组、模板、预设、草稿、历史和多选配置保留 LZMA；单条展开、多选弹窗、自然继承、左右等宽与窄窗滚动保持。

LZMA 是可选方法，不保证固定压缩率或速度；部分系统内置解压器不支持，分享前请确认接收方工具。现有 Deflate、Zstandard、BZip2、PPMd 及 ZIPX（XZ）继续保留。
