# Long解压 v1.4.13

Windows x64 正式版：[下载安装包](https://github.com/Longyuyeee/long_Decompress/releases/download/v1.4.13/Long-Decompress_1.4.13_x64-setup.exe)，也可在设置中心检查更新。

收到一组 ZIP 分卷却缺少其中一卷时，可以先尝试救出其他卷中的完整文件。恢复后查看文件和未恢复原因，再把新包加入解压队列继续处理。

## 缺卷时，也有机会先取出完整文件

- 支持目录仍完整可读的标准 `.z01/…/.zip` 分卷，先处理缺首卷或中间卷的情况。
- 从现有连续分卷中读取完整条目，跨越缺失卷、被截断或内容校验失败的文件会跳过；缺失卷后的完整文件仍可救回。
- 普通 ZIP、AES 和 ZipCrypto 密码包沿用已有密码读取方式；密码包恢复为使用原密码的 AES-256 / UTF-8 新包。
- 诊断区分“缺卷但可尝试救援”“需要密码”及暂不能救援的情况，明确指出缺少的文件。

## 结果更容易看清，继续处理更顺手

- 已恢复文件与未恢复原因分别按需展开，长清单在区域内滚动。
- 单项和批量结果统一展示部分恢复状态，保留定位结果、复制路径和加入解压队列。
- 从失败任务进入救援后，继续保留原输出目录、子文件夹设置与恢复时使用的密码。
- 单条行内展开、多选弹窗配置及既有详情布局保持。

本版不补造缺失数据。终卷或目录所在卷缺失、目录不完整，以及无法确定缺失范围的数字切卷和好压论坛卷，仍需补齐原始分卷；不扩大 RAR4 恢复或任意损坏包恢复的承诺。
