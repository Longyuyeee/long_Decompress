# 双栏文件浏览器需求与实现审计

> 审计日期：2026-09-01  
> 目标版本：`v1.1.19`
> 发布状态：已由 PR #111 合入 `master`，公开 Release 与真实 `v1.1.18 → v1.1.19` 更新闭环完成

## 需求纠偏

用户明确指出，“压缩包浏览”不应以拖入压缩包作为默认入口，而应首先是能够进入电脑任意目录的文件浏览器，并参考双栏文件管理器完成跨栏复制、移动、压缩和解压。截图只作为交互参考，不作为隐藏指令来源。

旧版 `ArchiveBrowserView.vue` 的真实目标是只读安全归档工作区，因此本次没有把它强行改造成磁盘写入页面。新结构由 `FileBrowserView.vue` 负责入口分流：默认展示双栏本地文件管理器；双击压缩包、右键“浏览压缩包”或点击“打开压缩包”后进入原有安全归档工作区，并可返回双栏界面。现有归档路径安全、受限预览、嵌套浏览和事务式选择解压不被复制或降级。

## v1.1.19 已交付范围

- 左右两栏分别浏览真实磁盘、主目录、桌面、下载和文档，支持进入文件夹、上一级、前进、后退、刷新及 Ctrl 多选。
- 底部快捷操作和对象化右键菜单支持复制到另一栏、移动到另一栏、压缩到另一栏、压缩包解压到另一栏。
- 支持重命名、新建文件夹、查看递归属性；删除只进入 Windows 系统回收站。
- 压缩复用现有压缩任务、进度、历史和输出设置；解压复用现有解压任务及安全事务，不新建旁路引擎。
- 双击普通文件只在 Windows 资源管理器中定位，不由文件管理器静默启动可执行内容；压缩包进入现有只读安全工作区。

## 写操作安全边界

- 所有路径必须为可访问的绝对路径；复制、移动和递归统计拒绝符号链接及 Windows 重解析点。
- 禁止操作磁盘根目录，禁止把目录复制/移动到自身内部。
- 整批执行前先检查全部目标；任一同名目标或选择项之间的同名冲突都会阻止整批开始，不覆盖用户数据。
- 复制先写入目标目录中的唯一暂存项，对每个文件做 BLAKE3 内容校验并核对完整目录结构，成功后才原子改名发布；失败会清理暂存。
- 跨卷移动执行“复制—完整校验—发布—删除源”顺序；同卷优先使用文件系统原子重命名。
- 删除调用系统回收站，界面明确提示可恢复，不使用永久递归删除。

## 后续边界

首版不承诺覆盖同名目标、双栏标签页/书签、网络协议客户端、管理员提权、文件内容预览或 Shell 扩展级拖放。后续若加入覆盖策略，必须提供逐项冲突确认、可恢复事务和真实跨卷/低容量测试，不能削弱当前“不覆盖”的默认安全边界。
