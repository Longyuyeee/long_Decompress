# v1.7.28 规划 · TAR.LZO 前向硬链接兼容提取

现有 TAR.LZO 只接受目标在链接之前、已唯一确认的内容引用；目标在后方时仍会明确拒绝。下一阶段解决这类完整包无法取回的问题，范围收在完整独立 TAR.LZO 与完整数字卷。

1. 先补实际外部生产者原件并固定身份，核对普通头、局部 PAX、GNU 长名称的前向引用。完整扫描后才确认目标：目标必须是唯一普通内容文件，空文件一并覆盖；稀疏目标只在原逻辑读取器和实际证据可复用时宣告支持。
2. 接入正常与精确所选提取，原目标无需同时选中；副本保存为独立文件，保留各自编码时间。浏览与文本/图片预览复用同一身份规则，避免列表显示可读、实际却取到另一条内容。继续沿原暂存、来源版本、取消、同名和最终结果流程。
3. 缺失、重复歧义、循环或任意链接链条、目录目标与符号链接不推断为成功；不完整包和缺卷不冒称完整兼容。转换与嵌套物化的后续接通单独安排，不把未覆盖操作提前标为完成。

完成标准：声明范围内的完整前向引用可在原入口正确取回，内容、路径和时间与外部原件相符，失败原因可理解。只补受影响检查，保留单条展开、多选弹窗、左右等宽与双栏包内外结构。

本阶段不增加格式数量，也不重写已完成目录流程。之后继续扩展算法/格式、密码/分卷与容错；ZIP UTC / 亚秒、重复读取成本及 ALZ / EGG 外部原件、原生密码/块分段等既有缺口继续保留。
