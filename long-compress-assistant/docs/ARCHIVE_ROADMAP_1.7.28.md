# v1.7.28 · TAR.LZO 前向硬链接兼容提取

状态：已完成并封板，正式 Windows 产物由本版 CI/Release 接续。ZIP / TAR / 7Z 的本段目录一致性工作完成，回归归档兼容主线。

完整独立 TAR.LZO 和完整数字卷现在支持“链接在前、目标内容在后”的直接引用。普通头、GNU 长名称和局部 PAX 均有真实 GNU tar 原件；普通、空文件以及已核对的旧 GNU / PAX 1.0 稀疏目标沿同一逻辑内容流程取回。

1. 完整扫描与外层校验完成后，统一确认直接目标的唯一原包身份；浏览、预览、正常/所选提取和完整检查沿相同规则，未确认目标不再作为零字节文件展示。
2. 原目标无需同时选中，取回的是独立文件，保留链接自身编码日期；目录、筛选、平铺、冲突确认、来源变化与取消接通既有暂存和结果入口。
3. 前向预览先完整确认再读取目标，与重放共用原 64 MiB 累计扫描预算；普通/后向预览原短路径保持。正常提取复用物理顺序读取及已选内容副本，不按链接逐份解码原包。
4. 专用部分抢救保持原前缀规则，缺卷或坏尾部不把前向内容当成完整成功。缺失/歧义、链条/循环、目录或非普通目标继续明确拒绝。
5. 新增原生 6 项、相关旧 4 项及独立核对通过：3 组原件、44 个编码条目；9 份输出共 101 个所选/完整条目、83 个文件内容与自身日期一致。见[封板记录](TAR_FORWARD_LINKS_FREEZE_1.7.28.md)。

完成标准已满足：声明范围内的完整前向引用可沿原入口正确取回，内容、路径和时间与原件相符，失败原因及“先提取后使用”的后续操作提示明确。原 UI、单条展开、多选弹窗、左右等宽与双栏结构保持。

下一阶段 [v1.7.29 前向链接内容转换](ARCHIVE_ROADMAP_1.7.29.md)仅规划，嵌套物化随后分期。本版不增加格式数或原生密码能力；算法/格式、密码/分卷和容错继续推进，ZIP UTC / 亚秒、重复读取成本及 ALZ / EGG 等既有缺口仍保留。
