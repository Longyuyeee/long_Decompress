# v1.5.48 · 资料库维护、密码包与分卷来源

## 更多资料，接到同一个资源库

- 添加与扫描扩展到当前引擎可浏览的归档类型，包含 7Z、RAR、压缩 TAR、已支持的压缩流和镜像等；具体可列目录、预览和提取能力沿原引擎。
- 支持从任意分卷成员加入，同一组只保留一份来源；同时兼容此前以 ZIP 尾卷记录的来源身份，避免重复入库。
- 密码资料可在原展开项的弹窗中填写密码、选择原有编码或从保险箱取用。密码 ZIP 和加密目录 7Z 等接入后，可从搜索结果继续查看或取回所选文件。
- 密码只在当前应用会话使用，索引不保存密码；重新打开应用后再次填写或选保险箱。ALZ/EGG 沿原有编码默认值与说明。

## 资料变了、移走了，仍然知道该怎么处理

- 新增来源状态检查，区分可用、已变化、离线、缺卷和不可读，并显示具体原因。分卷检查覆盖整组成员的大小和修改时间。
- 已完成的索引可供离线查找，命中明确标记“上次索引”和来源状态；查看或取回前再次检查当前来源，变化或缺失时先处理，不静默沿用旧索引执行。
- 支持重新定位原包或任意分卷成员，保留资料库身份与上次索引，刷新确认后再使用；已在资料库的另一份来源不会被合并覆盖。
- 手动更新资料库时，未变化来源沿用已有索引，只重建有变化的部分；索引事务失败或停止仍保留此前已完成的缓存。
- 对无法在列目录时统计大小的压缩流，明确显示“大小未统计”。

## 批次可以暂停，再从剩下的资料继续

- 建库和来源检查增加暂停/继续。当前来源处理完成后暂停，继续时只派发剩余来源；停止会结束当前读取并保留已完成索引。
- 重启后保留已完成来源，未完成部分可手动继续。旧版本资料库和索引会随应用升级保留。
- 密码弹窗在读取期间提供停止按钮，长路径、原因和来源列表保持完整高度、换行与滚动；宽窄窗口沿原样式。

本版不增加新解码算法或文件内容缓存。元数据索引不代表全部内容已验证，预览/提取范围及密码限制沿原引擎；分卷需补齐后使用。来源变化判断基于大小/修改时间，不承诺内容哈希身份。镜像与快照先按原浏览器默认目录建立索引，未宣称已遍历每个历史快照或镜像。原单条展开、多选弹窗、自然继承和压缩/解压左右等宽布局保持。
