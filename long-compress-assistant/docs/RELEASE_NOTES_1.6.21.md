# v1.6.21 · 带密码的 7Z 固实说明直接阅读

带密码的固实 7Z 中，说明、日志与配置文件现在也可以直接在原双栏阅读，无需先提取整包。

- 支持 AES + LZMA/LZMA2 固实包内的完整小文本，接通内容加密、文件名加密与完整数字分卷；有效成员可沿原入口打开。
- 填写的密码优先使用，留空沿原保险箱读取目录和所选文本。打开目录只读取文件名信息，预览不先检查无关大文件，也不增加完整解压的密码成功统计。
- 显示前完整检查所选共享内容的大小、CRC、AES 长度/填充与编码结束；密码错误或来源损坏时不显示部分内容，保留明确的核对与提取指引。
- 关闭可停止密码计算与共享读取，来源变化、缺卷和超限分别提示。固实条目正确显示共享读取等待，说明仍收在问号内。
- 所选文本 ≤1 MiB，共享压缩数据与解码总量分别 ≤64 MiB；实际输入合计 ≤64 MiB，每次目录/预览请求的密码候选合计限时 30 秒。预览支持已确认范围内的 AES 参数；超限或未知组合请先提取。

保留单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键。非固实密码图文和未加密固实图片保持原支持范围；本版不开放加密固实图片或大文本前缀，格式数量不变。下一阶段已规划 v1.6.22 加密固实图片与原阅读器，尚未开发。
