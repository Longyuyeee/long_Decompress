# v1.7.21 · TAR.LZO 整包链接内容提取

TAR.LZO 中已确认目标的硬链接副本，现在可以随正常任务整包解压为独立文件，不必先进入浏览器逐项选择。

- 接通普通头、局部 PAX 与 GNU 长名称组合，保留普通、空文件和已支持的稀疏内容，以及每份文件和目录的修改时间。
- 完整性检查使用相同的目标确认逻辑；修正旧回退路径可能跳过链接目标却报告通过的问题。未确认目标、坏尾和缺卷不会当成完整成功。
- 继续沿用原同名处理、目录结构、暂停取消、结果和历史入口；单条展开、多选弹窗与等宽双栏保持。

本版不创建系统链接。链接内容需要完整、可确认的原包及外层内容校验；前向/歧义目标、任意链接链条和符号链接仍有限制。转换与嵌套打开继续分期。

见 [本版范围](ARCHIVE_ROADMAP_1.7.21.md)、[实现与检查](TAR_FULL_LINKS_FREEZE_1.7.21.md)。下一阶段 [v1.7.22 TAR.LZO 链接内容转换](ARCHIVE_ROADMAP_1.7.22.md)仅规划。
