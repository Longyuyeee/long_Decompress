# v1.5.51：纠正失败、重启接续与按需重跑

2026-10-21，接续 v1.5.50 手动工作流。原单条展开、多选弹窗、自然继承、压缩/解压 50/50 与滚动保持。

## 用户交付

从运行记录“纠正并继续”或指定步骤重跑，在弹窗核对来源、输出位置、来源/产物读取密码及需要重做的步骤。步骤配置仍点击展开，复用原压缩参数和配置组；修改只影响这次接续，不覆盖原方案或旧运行。默认从首个未完成步骤开始，成功运行也能指定步骤重新处理。

记录不含密码的执行方案与各步实际输入/输出内容指纹。确认后按需读取并核对可复用前缀，仅匹配的完整成功步骤沿用原产物；来源选择或上游参数变动会将重跑范围提前。内容变了、产物缺失或缺少接续依据时指出具体步骤，提供从该步/更早重跑，不能凭旧成功状态跳过。核对显示实际读取进度，可取消；同一运行不重复派发。已有密码产物在本次重新提供读取密码，后续新密码仍按步骤配置。

每次接续建立独立运行目录和新记录，关联原运行，前缀标明复用及原位置，后续使用真实产物。旧记录、部分成功和已有文件保留；原任务进度/日志/历史/停止/结果操作复用。已完成整步才可复用，本版不在同一失败步骤内部逐来源恢复，也不续写压缩算法中间字节。

正常退出/重启可从未完成记录手动接续，不自动运行；来源缺失时可重新选择，已保存方案删除也不影响本版运行快照。v1.5.50 旧摘要没有执行快照和内容依据，继续保留查看，可明确带入当前保存方案做新运行，不伪造恢复记录。

## 实施与边界

扩展原 JSON 运行记录，旧表/旧摘要保持可读，不为可选字段重建库。内容指纹使用现有 BLAKE3，覆盖目录结构、实际文件和分卷成员；读取前后大小/时间变化会使本次依据不可用。核对仅在用户继续时执行一次，读取过程可停止；超出记录/核对范围时说明该步无法复用，不阻断原引擎已支持的正常处理。密码仅会话，不写快照或记录。

补齐实际分卷产物作为下一步压缩/筛选输入的整组传递，避免只处理首卷。检查限于新增快照/指纹、受影响顺序执行、恢复/重跑、失败停止、旧记录兼容和宽窄显示，不重复旧格式矩阵、真实盘满或无关安装。

本版收尾同步 README、中文 Release、封板、交接和八处身份，正常合入发布。下一步 v1.5.52 目录触发和运行队列，随后定时、对比、整包图片阅读，再回归算法/格式/容错兼容；不提前混入自动触发或任意脚本。
