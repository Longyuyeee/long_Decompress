# v1.7.34 · 流式 LZMA ZIP 丢目录部分取回

未加密 LZMA ZIP 中央目录损坏或丢失、文件尺寸只写在数据流末尾时，现在可通过原诊断与恢复入口取回能明确确认的完整文件。

- 支持明确声明并实际带有结束标记的 LZMA 流，接通 ZIP32 / ZIP64、带或不带可选签名的描述符、空文件与明确目录，以及完整数字切片的非首卷入口。
- 按实际结束位置核对尺寸和 CRC，扣除解码器预读的后续字节；遇到属性损坏、标记缺失、截断或矛盾数据停止，只另存此前确认的完整文件，原件保留。
- 结果仍为“部分取回”，原总清单未知；没有完整文件时沿原提示禁用恢复，现有结果、历史、失败重试和界面交互保持。

本版不增加格式数量或密码流未知边界支持，也不跨缺卷缺口扫描。见[范围](ARCHIVE_ROADMAP_1.7.34.md)、[实现与检查](ZIP_LZMA_RESCUE_FREEZE_1.7.34.md)。下一阶段 [v1.7.35 ZIP 部分取回结果保留修改时间](ARCHIVE_ROADMAP_1.7.35.md)仅规划。
