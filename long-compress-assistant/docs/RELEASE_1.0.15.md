# Long解压 1.0.15

本版本集中修复压缩与解压最核心的任务可靠性问题，补齐压缩中心的完整任务生命周期，并使用真实 Windows Tauri 桌面流程验证常用格式。

## 主要更新

- 同一规范化输出路径由前端预检和后端原子占用共同保护，避免重复点击或并发入口同时写入一个压缩包。
- 压缩与解压任务在查询、启动、统计、展示和清理的每一层隔离，文件不会再跨中心串台。
- 压缩中心改为任务式交互：点击任务展开详情，左侧配置选项，右侧显示状态、进度和实时日志，并支持取消及清理已完成任务。
- 7Z 压缩与解压按真实处理字节报告进度，读写过程中可及时响应取消。
- 7Z 加密判断改为读取归档元数据，移除此前没有阶段反馈的完整归档预检。
- 提交后的压缩草稿立即转换为任务，配合输出占用机制阻止重复启动。
- 取消中的任务保持“正在取消”状态，直到后端清理注册表和临时输出完成。
- LZMA 使用内置流式编码器，修复随包 7-Zip 对 `-tlzma` 返回“不支持”的压缩失败。

## 验证项目

- 前端 24 个测试文件、136 项单元与组件测试通过，TypeScript 类型检查和生产构建通过。
- Rust 压缩服务 17 项测试、取消与输出保护 4 项测试、19 项格式往返和归档冒烟矩阵通过。
- Clippy 以 `-D warnings` 通过。
- 真实 Windows Tauri E2E 验证 24 MiB 随机数据 7Z 压缩解压逐字节一致，并观察到压缩与解压中间进度。
- 真实 96 MiB 7Z 任务取消后没有留下最终归档。
- 应用命令矩阵验证 ZIP、7Z、TAR、TAR.GZ、TAR.BZ2、TAR.XZ、GZ、BZ2、XZ、ZST、TAR.ZST、LZMA、加密 ZIP 和加密 7Z。
- 托盘、第二实例恢复、退出确认和更新安装阻断继续通过桌面回归。

## 已知限制

- 项目目前没有可信 Windows 代码签名证书，安装时可能出现 SmartScreen 提示；请仅从本项目 GitHub Releases 下载。
- 无可信证书时公开安装包不会携带 Windows 11 顶层右键菜单身份包；传统“显示更多选项”菜单及一键解压/打包仍可使用。
- RAR 解压继续受支持，但本次没有可合法随仓库分发的 RAR 编码器或固定样本，因此未纳入新增的真实创建—解压矩阵。
- CAB、ISO、WIM、DMG、VHD/VHDX、MSI 等外部容器仍需通过固定样本继续扩大兼容矩阵。
