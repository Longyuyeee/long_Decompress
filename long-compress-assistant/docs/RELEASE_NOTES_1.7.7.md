# v1.7.7 · 默认打开方式更容易设置与取消

- 格式选择增加“全选 / 全部取消”，21 种压缩格式可一次选齐；已默认的格式也可以取消勾选。
- 设置和取消统一在同一个弹窗确认，移除设置页单独的“更改 / 取消默认”按钮。
- 修正前往 Windows 设置时可能打开文件夹的问题；较新 Windows 11 进入 Long解压的默认应用页，旧系统进入默认应用首页。
- 按系统实际状态显示“已默认、待确认、待更换”。系统只确认一部分时，弹窗保留选择与剩余数量；返回软件会自动刷新，也可以手动刷新。
- 小窗口支持弹窗内容滚动，底部按钮保持可见。沿用现有主题和双击打开后的操作偏好。

Windows 10/11 更换已有默认应用仍需在系统界面确认：勾选的格式选择 Long解压，取消的格式改选其他应用。软件不会把候选注册显示成“已设置成功”。
