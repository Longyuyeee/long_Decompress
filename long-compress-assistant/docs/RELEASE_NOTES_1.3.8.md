# Long解压 v1.3.8

恢复熟悉的行内操作，修正 v1.3.7 中不必要的配置限制。

- 解压中心点击任务行后，在该行下方展开配置和日志，直接在页面编辑，不再弹出任务详情窗口；可同时展开多条任务。
- 解压全局选项恢复到页面底部。解压与压缩中心均移除强制“全局 / 单独”模式切换，展开任务即可编辑。
- 新任务默认跟随全局设置；修改某条任务后自动保留该条配置，之后修改全局不会覆盖它。仅展开查看不会改变配置关系。
- 修正压缩单条配置引用全局对象的问题，编辑一条不会影响全局或其他任务；明确选择同目录后，不再被后续全局输出目录替换。
- 保留全库历史搜索、再次解压设置恢复、输出预览、失败纠正和成功结果入口。
