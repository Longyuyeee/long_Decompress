# Long解压 v1.5.22

大文件校验不再只能等待：看清正在读取哪个文件，随时停止，再继续尚未完成的项目。

- **真实读取进度**：计算 CRC32/MD5/SHA256 摘要和核对 SFV/MD5/SHA256 清单时，显示当前文件、已读字节、总字节和已处理项数。
- **停止后接着做**：停止会中断当前读取，已完成结果保留在当前工作区。点击“继续未完成项”只处理未完成的文件，中断的文件从头读取，不重复读取已经完成的项目。
- **结果不会混淆**：中断文件单独标记，不会显示为匹配或导出部分摘要；清单修改后旧结果作废，旧行号不会直接套到新清单。读取期间文件发生变化也会提示重新检查。
- **界面保持熟悉**：紧凑进度卡配合原来的逐项展开、等宽摘要和问题筛选；计算时锁定算法与文件选择，恢复操作保持清晰。压缩/解压中心原有单条展开、多选弹窗和布局保持。

已完成项是上次读取时的观察，文件之后有改动时请主动复查。继续功能限当前工作区，不保存哈希的内部中间状态，也不会在后台自动重新检查全部文件。基础哈希和格式能力沿用既有范围。
