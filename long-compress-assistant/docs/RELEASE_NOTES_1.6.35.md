# v1.6.35 · Deflate 固实图文直接预览

固实 Deflate 7Z 中的文本和图片，现在也可以在原双栏文件浏览器内直接查看。

- 普通包、内容加密、文件名加密和完整数字分卷贯通，可从非首卷进入，继续使用手动密码或密码保险箱。
- 完整文本 ≤1 MiB 保持编码识别、滚动和只读显示；受支持图片 ≤8 MiB 接回预览、整包阅读、翻页/缩放、跳过坏图、定位及仅提取当前页。
- 共享压缩数据和解码总量分别 ≤64 MiB，完整检查共享内容后只保留所选文件，避免为看一个文件保留整块内容。
- 保留密码错误、损坏、缺卷、取消和来源变化的处理入口。超出预览范围时可继续提取，不把未读完的共享块显示为完整成功。

单条展开、多选弹窗、等宽双栏、主题、工具与快捷键保持。大文本开头预览及 Deflate64 后续分阶段接续；本版没有增加格式计数或依赖。
