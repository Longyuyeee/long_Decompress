# v1.6.51 规划 · 7Z Delta 预处理

仅规划、尚未开发。接续 ZIP Store，回到算法扩展：为原始音频、采样数据等相邻字节相关的内容提供可选的 Delta 预处理，再由原 7Z LZMA2/LZMA 压缩。不是新格式，不保证任何文件都缩小，默认关闭；BCJ 等其他过滤器另行分期。

1. 在原 7Z 设置中收纳高级预处理：无（默认）/Delta，距离 1～256，仅在适用的 LZMA2/LZMA 下执行。字段与说明紧凑，距离只在选 Delta 后显示；其他方法不误执行过滤器，切换时保持清楚的状态。单条展开、多选弹窗、左右等宽保持。
2. 基于当前有 Delta 解码器、尚无创建编码器的事实，补流式 Delta 编码及正确链顺序/距离属性；明确结束后续压缩与 AES 并返回终止错误，检查空流、跨缓冲区/文件边界和 CRC。接通内容/文件名密码、固实/非固实、完整数字卷、取消/冲突与原结果入口。
3. 配置组/预设/模板、草稿、历史、工作流及转换携带目标预处理，源包过滤链与目标设置独立。体积分析按真实 Delta + 压缩方法抽样，不凭文件后缀宣称收益，未取得全链路结果前不扩大能力口径。
4. 独立工具完整回解新输出，再打通图文预览、大文本开头、提取和跨方法转换。用有代表性的相关数据及普通文本/图片确认内容一致；只补新增和受影响检查及默认关闭的连续性，实际宽窄界面确认后更新 README/Release 到可发版。

后续评估 BCJ 等过滤器和更多格式/算法，继续真实失败包的容错兼容。ALZ/EGG 缺原件项仍明确等待，不用新增算法充当兼容性完成证据。
