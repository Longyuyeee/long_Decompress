# Long解压 v1.5.20

LZIP 大文件也能拆成方便传输的分卷，并从任意一卷接续浏览、解压和转换。

- **LZIP / TAR.LZIP 数字分卷**：在原来的单条配置中设置卷大小；LZIP 用于单个文件，TAR.LZIP 用于目录或多个文件，兼容 `.tlz` 别名。结果入口显示实际生成的卷组。
- **从首卷、中卷或尾卷继续处理**：集齐所有卷后，可以浏览、预览、检查、选择提取或整包解压。普通 LZIP 文本和图片也接入内部有界预览，连续多成员不会漏掉后面的内容。
- **转换时重新拆卷或合并**：密码 ZIP 可转换成无密码 TAR.LZIP 数字卷，也可把 TAR.LZIP 卷组转换为带密码 ZIP。新包设置随目标格式提供，来源文件保留。
- **配置与失败处理更顺手**：多选改成 TAR.LZIP 时保留各自的分卷设置，关闭不支持的加密。缺卷补齐后，沿原纠正弹窗创建新任务，旧失败历史保留。单条展开、多选弹窗、左右等宽和窄窗滚动保持。

普通 LZIP 没有密码加密。数字卷是完整压缩流的字节切片，与 LZIP 原生成员不同；解压需把全部卷放在同一目录。分享给其他软件时，请先按顺序合并成完整文件，不承诺其他工具直接识别任意一卷。预览受既有读取预算限制，不等同整包完整性检查。
