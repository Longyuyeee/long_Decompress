# Long解压 v1.5.0

本版新增 ZPAQ 只读支持，重点是打开真实归档、取出当前文件，以及在失败后看懂原因并继续处理。

## 新增与改进

- 支持 ZPAQ 流式和日志式归档的浏览、完整解压、所选文件提取及完整性检查。日志式归档显示当前文件，不混入历史修订或已删除内容。
- 支持原生密码读取，包含中文和空格密码；密码通过标准输入传给随附引擎，不写入命令行。文件头无法解密时，明确保留“密码不匹配或文件损坏”的可能性。
- ZPAQ 可以作为归档转换输入，转换成现有可创建格式；仍先暂存、校验再发布，保留原包。
- 目录扫描遇到坏块或未完成事务时，不再沿用工具的宽松跳过结果冒充完整成功。内容校验失败不发布半成品。
- 浏览页用“当前文件”及就近问号说明边界；修改时间采用可读的 UTC 时间。设置页明确 ZPAQ 密码能力仅为读取。
- 重试时输出目录不存在或无法访问，会明确指出目录和处理办法，不再只显示无法定位的原始 IO 错误。

## 使用边界

本版不提供 ZPAQ 创建、原生多部分归档、增量备份或历史恢复。ZPAQ 原生密码没有独立认证标签，部分头部信息也不受文件内容校验保护，因此不能保证发现任意字节变化；检查使用格式实际提供的结构和内容校验。

已用官方 ZPAQ 7.15 生成流式/日志式、普通/中文密码原包，覆盖更新、删除和已知载荷；转换输出用独立 7-Zip 回解核对。准确测试、页面与发布状态见[实施审计](ZPAQ_READ_1.5.0.md)和[封板记录](ZPAQ_READ_FREEZE_1.5.0.md)。

已有 ZIP/ZIPX、7Z、RAR 及媒体能力保持；智能目录和 ZIP 并行仍默认关闭，不恢复快速打包。下一版按既定路线推进 v1.5.1 ZPAQ 创建闭环，原生多部分与普通切片分别核实，不混称原生固定体积分卷。
