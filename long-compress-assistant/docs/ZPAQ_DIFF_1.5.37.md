# v1.5.37 ZPAQ 快照对比与变化提取实施

2026-10-21，接续已正式发布v1.5.36（PR #231，标签2924c08d7574a2abbbb515d41bdaf1af3dcfb6c8，正式运行39475820062成功）。按既定路线推进，下一版仅规划ZIP LZMA创建，不启动运行时。

## 用户流程

在原ZPAQ历史选择旁点击“对比快照”，选择较早/较新版本，查看新增、变化、内容候选、元数据、移除和未变。目录比较不解码所有文件；同大小同时间但引用不同的内容仍列为候选。搜索、按类型筛选、每页200条与本页选择支持长列表，默认只选第一页变化。

新版和旧版独立勾选：新增/变化默认新版，移除默认旧版；可同时取同一路径的两版。非空目录不能单独勾选，避免隐式带出未选文件；空目录可选。点击创建后，按版本生成最多两个待处理任务和独立版本输出子目录，保留路径、现有冲突处理与统一结果入口，不自动执行。

普通/原生密码及数字卷任意成员接原有读取。草稿保存快照、目录标识和选择范围，不保存密码；缺卷补齐后新任务保留同一范围，旧失败记录不变。历史重做只为本版有标识的变化任务恢复局部范围，原有无标识历史仍沿整包策略。来源改变时要求重新对比，不改成最新版本或扩大成整包。

## 比较依据与执行

随附适配器可选-long-refs目录模式，对按顺序排列的片段SHA1与长度计算引用摘要，不改变默认读取/创建、编码或密码实现。引用相同提供目录依据，不声称已逐字节核对整个归档；不同引用可能受分片表示影响，仅标候选。文件大小或文件/目录类型变化有单独原因，时间记录变化也单列。

用户明确核对所选候选后，两版依次在临时目录提取，并逐64KiB计算真实SHA256，完成/停止后清理。相同内容归为未变或仅元数据，不同内容标已核对变化。阶段区分目录读取、旧/新临时提取和哈希；哈希字节实际计量，不虚构解码百分比。支持停止和取消先于注册的请求；晚到响应不覆盖当前结果。同一来源/版本的已核对结果可在同次工作中保留，重新比较或来源改变则重新建立依据。

目录标识绑定快照目录及实际卷成员长度/写入时间。创建待处理前核对，实际提取的规划与执行入口再核对；执行前资源检查失败也先保存选择与标识，避免失败历史丢范围。副本或历史变化后需重新对比；这不是对未读取载荷的完整校验承诺。原包字节始终不改。

## 检查与修正

六项不同Rust覆盖普通/密码/数字卷、真实SHA256和独立原件内容、同大小同时间内容变化/纯时间变化、真实哈希阶段停止、错误身份/来源改变/缺卷、历史清洗及所选空目录。八项新增前端覆盖分组、范围拷贝、已核对结果接续、取消晚到响应、200条分页、关闭中止创建、草稿无密码/不同范围不误合并和未创建版本目录的重试。

实际桌面发现通用暂存清理会移除选中的空目录。仅为本版带目录标识的选择保留明确目录，并允许仅选空目录；未选空残留仍清理，其他格式/旧策略不变。前面的目录比较、实际核对、草稿恢复与补卷文件哈希步骤保留原程序身份，只补受影响的空目录提取/发布和后续历史链。检查器最初把任务详情当成行标题子节点，改为等待真实兄弟详情；不把选择器修正计为产品功能。

实际原生/UI链、程序身份、布局与已实看截图见[封板](ZPAQ_DIFF_FREEZE_1.5.37.md)和[证据](evidence/zpaq-diff-1.5.37/)。保持单条展开、多选弹窗、自然继承、中心50/50及窄窗滚动，没有重做整体UI。旧格式/密码矩阵和真实盘满不重跑，个人安装/菜单不改。

## 范围与发布

只比较同一完整日志式ZPAQ的两个版本，不提供跨归档比较、流式历史、删除同步、原地覆盖、原生追加多部分或损坏事务抢救。精确核对需要所选文件的临时空间，两版顺序处理；不承诺固定速度、零读写或所有载荷已验证。
