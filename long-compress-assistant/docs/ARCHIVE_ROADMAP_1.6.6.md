# v1.6.6 窗口位置与大小记忆（已封板）

优先处理 [#248](https://github.com/Longyuyeee/long_Decompress/issues/248)：高分辨率屏幕上，每次重启都要重新调整窗口。本版自动恢复用户上次的正常位置、尺寸和最大化状态，不新增开关或说明区。

1. 在本地应用数据目录独立保存窗口状态，与任务/密码配置分离；移动、缩放后合并写入，关闭和退出前保存。缺失或损坏记录沿用默认窗口。
2. 最大化时保留还原尺寸；最小化和隐藏到托盘不保存成小窗口，也不让下次普通启动隐藏。沿用托盘、第二实例唤醒、开机隐藏启动与任务退出确认。
3. 按显示器、缩放比例和工作区恢复；原屏断开、分辨率降低或窗口越界时调整到当前可见工作区，标题栏可操作。
4. 只做窗口状态计算与真实桌面重启、最大化还原、托盘及必要宽窄布局检查，不重复格式矩阵。保持单条展开、多选弹窗和左右等宽。

完成后同步 README、中文 Release 和版本身份，按正常 PR/标签流水线发布。原定 [ALZ Bzip2 大包有界读取](ALZ_BZIP2_BOUNDED_READ_PLAN.md) 移为后续候选，来源与实现均未完成；方法 3 / EGG 加密固实的现有限制保持，不把单项支持扩大为全组合。

完成状态：自动记忆与恢复已实现；两项 Rust、七项桌面流程和三张实看布局通过，详见 [封板记录](WINDOW_MEMORY_FREEZE_1.6.6.md)。后续路线见 [v1.6.7 候选](ARCHIVE_ROADMAP_1.6.7.md)。
