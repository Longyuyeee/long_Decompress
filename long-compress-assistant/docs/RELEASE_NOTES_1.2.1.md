# Long解压 v1.2.1

v1.2.1 修复应用内更新完成后的 Explorer 经典菜单竞态。

## 修复

- `v1.1.19 → v1.2.0` 的首次公开更新实测中，应用本体、版本、安装路径和自动重启均成功；但旧 updater 的尾部清理可能发生在新进程首次菜单修复之后，导致目录与目录空白处入口在本次退出后缺失，直到下一次启动才恢复。
- 新进程现在会在启动后 2 秒和 6 秒复核原本已启用的 Explorer 菜单，覆盖 updater 尾部清理窗口，不要求用户手动重启第二次。
- 复核仍遵循原设置：只有检测到既有经典或原生菜单时才刷新，不会替用户擅自启用右键菜单。

## 验证原则

- 公开更新门禁在首次看到 4 个菜单根、17 条命令和 4 条快捷动作后继续观察 8 秒，再停止应用并重新核对，防止把瞬时完整误报为稳定完成。
- 首轮失败证据和修复后证据都保留在发布审计中。
