# v1.5.49 资料分类与跨包批量取回封板

[实施计划](ARCHIVE_ROADMAP_1.5.49.md) · [中文 Release](RELEASE_NOTES_1.5.49.md) · [记录](evidence/library-retrieval-1.5.49/)。候选、正常合入、标签与正式附件收据在本版 PR 接续。

## 已交付

来源标签/收藏在原展开项的弹窗中整理，跨包搜索可组合来源、类型、标签与收藏。常用搜索命名保存、更新或删除；来源已移出时具体说明，不静默扩大搜索。查找条件、页码、来源展开、筛选和外层浏览位置保留，重启亦可接续。分类与搜索独立 SQLite 表，不修改原包。

结果跨页勾选，当前页全选和清空，配置集中在批量弹窗。按来源复核路径，设置输出、包内结构或平铺、按来源子目录或合并、同名改名或跳过。来源独立目录附短身份，避免同名资料混在一起。原解压中心待处理任务保留确切所选项、来源身份与索引版本，核对后开始，复用原队列、进度、日志、停止、结果和失败纠正。

检查当前来源和索引范围，可用部分先加入，密码/缺卷/离线/变化部分保留选择、显示原因和处理入口；纠正后只派发剩余项，同一待处理范围不重复加入。执行前再次核对来源、版本与选择，来源变更后重新搜索选择，不变成整包解压。草稿、历史重做、失败新任务及开始前取消的历史都保留范围和输出方式，密码不持久化。原浏览器与归档结果可主动加入/刷新资料库，再手动建库。

原单条展开、多选弹窗、自然继承、压缩/解压左右 50/50 与滚动保持。新增来源/结果控件紧凑排列，宽窗等宽批量复核、窄窗顺排，长路径换行；结果列表和弹窗来源列表设置高度上限，避免长结果把操作和分页推远。

## 范围与检查

复用 v1.5.48 既有格式/密码/分卷与默认镜像/快照范围；不新增算法、全文/OCR/内容缓存/全盘常驻扫描。收藏针对来源，每份最多 12 个标签、每个 30 字；常用搜索最多 100 份；每批最多 2000 文件，单来源路径序列过长时需分批。尚未入队勾选仅当前会话；查找条件和已入队待处理草稿可跨次恢复。任务历史范围保护要求保留的来源记录和相同索引版本仍存在，否则从资源库重新选择。

140 项不同前端、五项新增 Rust（分类/搜索/选择三项、迁移一项、历史一项）通过，类型/Vite、Shell/八处身份和原生构建通过。四条实际桌面流程、16 条宽窄布局、八图实看；旧测试库升级、跨页五项/四来源、首批仅三文件、密码/离线剩余项、原目标保留、同名策略、正常退出同目录恢复准确范围与最终取回字节均通过。四个原包 SHA-256 保持。

最终 E2E SHA-256 `6dc34d0b574b1078987ccce312b8c84c3877d93b5eefe93ffa17bcd415e9dc53`。前三条保留先前程序，最终只补滚动及开始前取消历史范围，并接续第四条和最终布局；脚本截图/关闭步骤与 WebView 就绪超时后接续如实记录。不重复旧矩阵、真实盘满、媒体或个人安装；本地程序不冒充正式安装包。
