# v1.6.39 · 密码 Deflate64 完整图文预览

## 完成范围

按[本版路线](ARCHIVE_ROADMAP_1.6.39.md)扩展独立完整 read_deflate64_entry，支持唯一非固实普通条目中的有序 AES → Deflate64。内容/文件名加密、完整数字卷/非首卷接通原手动密码/保险箱；完整文本 ≤1 MiB、图片 ≤8 MiB，保持编码/滚动、图片预览与连续阅读、翻页/缩放/坏图跳过/定位/仅提取当前页。明确手动错误不回退，不凭预览记录整包密码成功。固实、大文本和其他方法组合仍提供提取下一步；只扩展原问号说明，单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键保持。

检查映射与 coder/参数/流/绑定/打包形状、AES 明文/密文声明与对齐；复用完整 PreviewAes 和消费回执，固定 32 KiB 输入/输出块。Deflate64 使用无声明大小截止的 inflater，真实终止并排空输出，精确核对扣除 Huffman 整字节预读后的输入、实际消费和输出；随后完成 AES EOF、零填充/密文消费，检查全部可用文件/块/打包 CRC，不能用可读正文替代完整结果，其他完整 AES 回执也不可豁免。实际输入 ≤64 MiB、整体限时、取消/来源绑定沿原流程，不读无关大块或按巨大声明分配全文。

本地 Deflate64 0.1.12 的终止位置查询、默认解码、ZIP 的 registry 依赖与其他 codec 保持，未新增依赖/许可，格式计数不变。仅删除旧普通 Deflate64 阶段已被本版替代的密码不支持断言，保留固实和大文本下一步。
