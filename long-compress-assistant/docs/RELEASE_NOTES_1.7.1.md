# v1.7.1 · 文件夹也能直接打包成 TAR.LZO

在原压缩中心选择 **TAR.LZO**，文件夹和多文件即可生成保留层级的 `.tar.lzo`。空文件、空目录和中文长路径一起保留；单条仍点击展开，多选仍在弹窗集中配置，修改选中任务不会改变全局默认。

## 本版更新

- 新增 TAR.LZO 创建与归档转换，接通实际编码采样、进度、取消、完成校验、统一结果和历史。
- TAR 内容直接流入有界 LZO1X 编码器，不先落地完整临时 TAR；沿用原有输出暂存、失败清理和发布流程。
- 中文路径使用显式 UTF-8 PAX 信息，兼顾长文件名和 Windows TAR 工具的名称还原；其他 TAR 格式保留原写入方式。
- 密码 ZIP 等原包可以先用来源密码读取，再完整转换为 TAR.LZO；新包可沿原双栏浏览、预览文本与图片、按需取回或转回 ZIP / 7Z，原包保留。
- 固定编码模式不展示无效的压缩强度、新包密码等控件；切换目标会清理不适用的密码、固实和分卷配置。
- 修正批量压缩成功提示末尾多余的 `s`，以及磁盘文件修改时间显示为 `[object Object]` 的问题。

## 使用边界

TAR.LZO 是标准 TAR 外层使用 LZOP 压缩，适合目录和多个文件；普通 LZOP 仍只创建一个普通文件。本版不提供 LZOP 多成员创建、原生密码或创建分卷，已有完整数字卷的读取能力保持。

保留 v1.7.0 的四项默认打开动作、一次性设置提醒、包内外统一双栏、历史浮层菜单、左右等宽、主题与快捷键。README 末尾继续只保留最近五个版本。
