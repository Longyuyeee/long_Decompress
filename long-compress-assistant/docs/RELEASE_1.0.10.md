# Long解压 1.0.10

本版本完成软件品牌升级，产品名称由“胧解压·方便助手”统一调整为“Long解压”，并启用全新的 L 形拉链图标系统。

## 主要更新

- 统一主窗口、网页标题、系统托盘、安装器、开始菜单、右键菜单、Shell 扩展和 GitHub Release 的产品名称。
- 新图标以清晰的字母 L 为主体，将竖向笔画与拉链结合，直接表达文件解压能力。
- 重新生成 Windows PNG/ICO/Appx、macOS ICNS、网页 favicon 和应用内侧栏图标。
- 保留 `com.longcompress.assistant` 应用标识符、现有配置路径和更新公钥，避免品牌调整破坏用户数据与更新链路。
- 延续 1.0.9 的一键解压到同名文件夹、一键打包为 ZIP、单实例任务分发和传统右键菜单能力。

## Windows 11 右键菜单说明

项目没有生产 Windows 代码签名证书，因此 1.0.10 正式安装包不会携带 Windows 11 新式菜单 MSIX 身份包。“显示更多选项”中的传统右键菜单和全部快捷命令保持可用。

## 验证项目

- 前端类型检查、单元测试和生产构建。
- Rust 主程序全套 release 测试与 Shell 扩展测试。
- 版本化 Shell 扩展 DLL、NSIS 安装包与应用内更新产物构建。
- 图标母版透明通道、32×32 小尺寸和 Windows ICO 资源检查。
