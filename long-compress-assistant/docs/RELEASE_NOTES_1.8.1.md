# Long解压 v1.8.1

从双栏发起压缩、批量调整参数，再到打开结果，本版缩短了这三段日常操作。

## 双栏发起，做完回到原处

- 在任一栏选中文件并点击「压缩到另一栏」，压缩中心会使用另一栏的目录。运行中也可以点「返回发起位置」，恢复两栏目录、滚动位置和原选择，任务继续执行。
- 完成后可点「在双栏定位结果」，在目标栏选中实际生成的压缩包或首卷。同名导致产物改名时，也能定位到最终文件。「打开结果位置」可在 Windows 资源管理器中定位。

## 批量配置先看用途和改动

- 多选待处理任务后点「修改所选配置」。选「兼容分享」或「体积优先」即可预填方案。「加密分享」与「按大小分包」会显示对应的密码或大小输入。
- 常用区保留格式与输出目录，算法、压缩等级和密码编码等收进「高级设置」。底部先预览本次改动，再点「应用到 N 项」。切换用途会替换本次预填参数，未指定的设置沿用各任务原值。

## 更多操作收进结果菜单

- 压缩和解压结果沿用历史任务的「⋯」菜单。复制路径、加入资料库和生成校验清单等适用于当前结果的操作从按钮旁打开。
- 菜单浮出时任务行保持原位。窗口下方空间不足时向上展开，按 Esc 或点击外部即可关闭。

首次下载可选择 Windows x64 的 `setup.exe`，已安装用户可在设置中心检查更新。[图文操作指南](https://github.com/Longyuyeee/long_Decompress/blob/v1.8.1/README.md#quick-start)
