# v1.7.40 · 包内文件复制与右键菜单升级

在压缩包里选中文件或文件夹，右键“复制”或按 Ctrl+C，准备完成后即可在 Windows 文件夹中粘贴。本版响应 [#364](https://github.com/Longyuyeee/long_Decompress/issues/364)，并按文件类型补齐资源管理器快捷操作。

- **包内复制**：多选、文件夹、空目录接入原完整提取流程，显示紧凑进度并可取消；成功后提供文件剪贴板，关闭软件后仍能粘贴。失败不发布不完整文件；原件保持不变。
- **普通文件与文件夹**：ZIP / 7Z 快速打包、添加到压缩包、加密压缩和分卷压缩。所选内容合成独立任务，快速打包只启动本次任务，保留其他等待任务及原配置。
- **压缩包**：浏览、解压到此处、同名目录、自选目录，以及普通打包入口；测试、修复、转换和调整密码/分卷收在更多操作。经典菜单补齐 `.r00–r99`、`.z01–z99`、`.001–999` 分卷入口。
- **JPG / JPEG / PNG / WebP**：优先提供图片压缩、转换 WebP 和缩小尺寸；带入现有图片界面，确认后再开始，不自动改动图片。
- **交互细节**：多选菜单显示实际项目数，复制与解压使用相同选择范围；保留等宽双栏、单条展开和多选配置弹窗。输入框或选中文字的 Ctrl+C 继续复制文字。

复制依赖来源可完整提取、密码正确和卷组完整；链接、大小未知或同名冲突会提示先提取处理。缓存只在本机保存，过期七天且未被当前文件剪贴板引用的缓存，在后续复制时清理。图文预览与默认应用打开保持原流程。

本版不增加归档格式或算法数量。原 v1.7.39 的 XZ 多流/填充计划尚未实现，按本次优先级调整到 [v1.7.41](ARCHIVE_ROADMAP_1.7.41.md)。详见[开发范围](ARCHIVE_ROADMAP_1.7.40.md)和[封板记录](EXPLORER_CLIPBOARD_FREEZE_1.7.40.md)。
