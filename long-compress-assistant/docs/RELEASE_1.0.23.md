# Long解压 1.0.23

本版本集中修复 Windows 资源管理器经典右键菜单的高频操作可达性，并统一系统菜单与解压中心的格式范围。

## 右键菜单

- 保留 v1.0.21 起使用的 `ExtendedSubCommandsKey` 二级菜单，继续提供四类菜单根和 17 条内联命令。
- 在“显示更多选项”外层增加“一键解压到同名文件夹”。该入口只为公开支持的压缩包格式注册。
- 为文件、文件夹和目录空白处增加“一键打包为 ZIP”，多选请求继续由单实例动作队列合并。
- 注册状态会逐项校验二级菜单和独立快捷项的命令目标；覆盖升级与卸载会清理旧键值。

## 格式范围

- DOCX、XLSX、PPTX、ODT、ODS、EPUB 不再被资源管理器菜单识别为待解压归档。
- 移除尚未完成公开真实样本验证的 ARJ、CHM、UDF、PPKG 菜单声明。
- 补齐 QCOW/QCOW2、VDI、VMDK、APFS、EXT2/3/4、HFS/HFSX、UEFI、IHex 等已验证只读格式。

## 验证

- 前端：27 个测试文件、163 项测试通过，类型检查与生产构建通过。
- Rust：Release 全目标测试、集成矩阵和 Clippy `-D warnings` 通过。
- 资源管理器：注册表往返、二级菜单、独立快捷项、Shell DLL 和 NSIS 卸载覆盖测试通过。
- 八处版本身份统一为 1.0.23，资源目录只保留 `long_compress_shell_extension_1_0_23.dll`。
- 本机从已安装 v1.0.19 覆盖到候选 v1.0.23，再卸载并恢复 v1.0.19；安装位置、两套用户数据、菜单迁移、快捷项、唯一 Shell DLL 和卸载清理共 41/41 项通过。
- 安装验收等待条件改为二级菜单和独立快捷项全部迁移完成，避免相同安装路径上的旧注册值造成过早断言。

## 签名边界

本版本不配置 Windows Authenticode 或商业代码签名证书，也不分发 Windows 11 第一层菜单身份包。快捷操作位于“显示更多选项”的经典菜单中；Tauri updater 的完整性签名继续保留。
