# v1.5.55 资料内容核对与密码分卷 ZIP 封板

基于 v1.5.54，2026-10-21。完成对比模块第二阶段，范围见[实施计划](ARCHIVE_ROADMAP_1.5.55.md)和[中文说明](RELEASE_NOTES_1.5.55.md)。

## 已交付

- 对双方都有的所选或当前筛选文件核对实际内容：大小不同时直接判定不同，同大小逐侧完整读取 SHA-256。分为内容相同、不同、仅时间变化、未核对/未完成；不以时间或 CRC 替代内容依据。
- 真实读取字节、当前路径与侧别、处理数量和停止。保留完整完成的项目，继续只处理剩余/读取失败项，单条可以重新核对。来源版本变化撤销旧结论并要求重新读取。
- 复用 ZipInputReader、完整卷组和现有密码编码，Store/Deflate ZIP 接通 AES/ZipCrypto、数字及标准卷；任意成员归到同组。公开条目不借用未选密码条目的要求，缺卷不冒充完整清单，补齐后重新读取保留仍有效的选择。
- 来源密码用弹窗及原保险箱，编码使用原控件；取回密码只进本次任务，不存草稿或历史。原队列、精确范围、改名/跳过、结果、正常关闭重启草稿与历史同范围再次处理贯通。恢复任务在原行内展开区补密码，保留编码，不自动开始。
- 内容变化与待核对计数和对应筛选统一。原单条展开、多选弹窗、自然继承、压缩/解压 50/50 与滚动保持，新控件宽窄均可用。数据库 schema 保持 18。

## 明确范围

本模块为文件夹与 Store/Deflate ZIP 的上述普通/密码/完整卷组合，不扩展压缩算法；其他方法、格式、Long AES 外层容器和缺卷救援继续原浏览器。每侧五万条，核对或取回单批两千条且路径 JSON 六万字节以内；只对双方文件作内容结论，目录按子项查看。不提供目录同步、自动删除、原包覆盖或持久化跨重启的内容核对缓存。

来源版本仍按结构/元数据和整组卷身份确认；内容相同结论则来自本次双方完整读取。正在外部修改的资料请重新读取；不将一次核对说成永久不变的文件保证。

## 针对性依据

30 项不同前端通过，覆盖新内容状态/停止/来源变化、密码运行参数、选择/范围、草稿、历史、恢复行内入口和统计筛选；17 项不同 Rust 通过（8 新、9 受影响共享路径）。类型/Vite、菜单扩展、八处身份与原生构建通过。前端最初草稿测试调用了不存在的 inspect，改用现有 restore 后只接续该项；新历史用例和后续统计/恢复项分别定向执行，不重复已通过无关项。

真实桌面五个组合流程完成：三种来源组合与真实内容/时间差异、过期结论撤销；密码数字卷从非首成员进入、错密码与补填后再核对、所选实际取回；标准密码卷缺卷纠正和选择保留；点击真实停止按钮后保留已完成项目并只继续剩余大文件；正常退出重启后密码不恢复、编码/范围保留、行内重填和历史同范围再次取回。产物逐项与原内容独立比对，来源归档字节保持。

最初四流程程序 SHA-256 `8aa7d6d09fcf99920544793fae30cb54d66310ded035eba7beb75c154bc80b7a`。恢复流程发现缺少行内密码入口，已补齐并定向检查；最终程序 `d0652814c505d884a2a6b6dcdc9f2bf3242ef3d7d264aa821ebca2f1680623fd` 接续恢复/历史和一组统计、筛选、进度样式，前四流程保留原程序身份。共 26 条宽窄布局、10 张代表图已实看。最终仅复用现有错误格式化去除内部标记，经最终 TypeScript/Vite，不为提示文字再编译原生。详见[摘要](evidence/source-content-1.5.55/checks.json)和[桌面记录](evidence/source-content-1.5.55/desktop-progress.json)。
