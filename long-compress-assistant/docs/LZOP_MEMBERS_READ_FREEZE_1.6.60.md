# v1.6.60 · LZOP 多成员资料读取

已完成功能封板。正式源码/合并/标签与附件身份在本版 PR 接续。

## 用户得到什么

同一个 `.lzo` 中的多个文件沿原双栏分别列出，支持搜索、图文/前缀预览、所选取回、完整检查、全部提取和 ZIP/7Z 转换，保留来源及历史。完整数字切卷从任意一卷打开。保持单条展开、多选弹窗、自然继承、左右等宽、主题与快捷键，没有新增主页面或铺开的配置区。设置里的 LZOP 名称与后台能力表不再标记“仅单文件”，创建格式数与创建权限不变。

## 实现和边界

官方 `lzop -o` 多文件原件实际带有 `F_MULTIPART` 提示；本版接通已确认的独立完整成员序列，而非根据该标志全部拒绝。原生 `0xffffffff` 块分段标记仍明确不支持。普通单成员保留来源文件名和旧行为；TAR.LZO 只使用原有单流目录路线，多个独立成员不猜测为一条 TAR 数据流。没有新增依赖、外部运行程序、LZOP 创建、原生密码或缺卷内容救援。

共享头/块布局解析，目录索引按结构跳过压缩载荷，仅保留成员元数据，大小来自合法块头声明；不为浏览列表展开所有内容。成员总数限制 100000，数据块沿用 64 MiB 上限。预览/提取只解码所选成员，完整检查则逐成员解码并检查全部可用校验；原暂存/冲突/取消与最终发布事务保持。

本版按官方 `-N` 式只恢复文件名，忽略头内目录和权限。有效 UTF-8 名称默认识别，显式 Latin-1 标记优先；其他非 UTF-8 且无法确认编码的名称不猜旧代码页，使用稳定 `member-编号.bin`。重名/大小写、缺名称、过长名、保留名和非法路径字符采用确定的显示/输出名；预览、提取和转换一致，不覆盖合并成员。目录与旧 Windows/DOS 名称兼容留待下一版。

成员列表读取结构不代表内容已校验，所选/前缀预览不代替整包检查；无数据校验的来源不能保证内容未变。缺首/中数字卷沿原组提示，已观察到的短头/坏块/不完整结束和尾部杂数据拒绝成功，完整取回失败不发布前面成员的半成品。序列本身没有总成员数：一个完整成员整段丢失且剩余成员均完整时，无法仅从剩余文件断言丢失，不能虚构总数或承诺检测；源组/已知清单与任务期间变化仍按原来源事务判断。

## 证据与范围

三份官方 Windows lzop 1.03 / LZO 2.04 多文件 `-o` 原件覆盖三种 LZO1X 方法（`-3` → 方法 1、`-1` → 方法 2、`-9` → 方法 3），CRC32 + 压缩/展开校验；每份均以官方 `-t -N`（退出 0）检查、`-d -N -p`（退出 0）逐文件独立回解并核对 SHA256，包含真实压缩多块、随机 stored 数据、中文内容、图片和空文件。参数、SHA256 及可复现脚本见[原件](../tests/fixtures/archives/lzop-members-1660/manifest.json)。拼接 stdin 成员、头内重名/异常名称、CRC/截断与数字切片仅是派生测试，不冒充外部官方原件。

首轮 7 项新增及受影响 Rust 已通过：官方成员全量/所选取回与 SHA、图文/1 MiB 开头和诊断，重名/缺名称/异常名称，非首数字卷/缺卷/尾部与补齐，后续成员 CRC、杂数据、取消和拒绝误判 TAR；受影响普通单成员、短读取/校验/边界、数字卷预览及 TAR.LZO 失败回归通过。能力表单一标记和未使用导出在候选编译前收尾，未改变上述读取行为，不重跑通过项。生产类型/Vite、桌面前端资产、版本身份与 Shell 已通过。随后审读发现显式 Latin-1 标记应优先于有效 UTF-8 字节猜测，已修正并新增 1 项专项检查通过；其余 7 项结果复用，未重跑。

首轮桌面 4 组业务通过：非首卷的成员列表、文本/图片、只取所选文件，完整检查/提取/大文本开头/ZIP 与 7Z 转换和来源历史，以及后续成员坏 CRC 不发布半成品、保留已有文件并修正重试；转换由独立 7-Zip 逐文件回解，含 7Z 密码/隐藏名称/数字卷。首轮 4 张宽窄图已实看。名称优先级修正后的最后候选只补 1 组名称专项：同字节的显式 Latin-1/UTF-8 名称分别显示、预览和取回，完整检查通过，新增 2 张宽窄图实看通过。其余业务与图片复用首轮通过结果，两个候选的 SHA 分别记录于 desktop.json / desktop-name.json，不冒充同一二进制。6 张图双栏等宽、无横向溢出，弹窗在窗口内。见[证据](evidence/lzop-members-read-1.6.60/README.md)。只检查本版新增和受影响路径，未重跑旧格式矩阵、安装或盘满。桌面候选采用 custom-protocol,desktop-e2e 及 opt-level=1/LTO=false；正式签名附件使用既有生产参数，不能以本地候选代替正式附件。
