# v1.5.4 复杂 EGG 读取

从已发布 v1.5.3 的发布后主线 `4304d43` 接续。按批准路线补 AZO、固实、AES-128/256、LEA-128/256 的只读闭环，不新增 EGG 创建、全局/文件名加密或损坏修复。每种方法、密码及原生卷组合按真实原包分别确认，未验证组合不外推。

## 代码与范围审计

开工基线的隔离 helper 已接统一浏览、密码、所选/整包提取、检查、转换和重试，当时复杂方法明确拒绝。保留的上游 `extract.rs` 未编译，不能直接启用：固实路径聚合全部压缩输入，AES/LEA 构造器固定 UTF-8 密码，短验证器不是完整密码证据。

新增 AZO 候选为 [libazo 0.1.1](https://github.com/alkegi/libazo)，已取得发布源码与 MIT 许可。其入口会读入整段压缩数据，结束标记后未检查剩余输入；接入前改为逐 AZO 块有界读取，核对结束、长度、CRC 与读写错误。算法参考[上游格式说明](https://github.com/alkegi/docs/blob/master/egg.md)及[原厂组合说明](https://en.bandisoft.com/bandizip/help/how-to-open-alz-and-egg-files/)。

## 实施顺序

1. 固定来源和真实原包/独立载荷，修正解码边界、密码字节及固实输入/输出划分；保持原生卷双向链接和事务发布。
2. 接复杂读取和所选范围：固实选中文件仍需解码其共享流，依赖块需要的密码和失败原因必须显示，不能因条目自身无数据块而漏判。
3. 真实桌面验证错密码纠正、中文编码、所选提取、缺卷补回、检查/转换和实际暂停取消；有变化的常用/窄窗页面必须查看。
4. 完成定向审计后封板、统一版本、受保护合入、正式发布及四资产回下载核对，再回填两份 README、收据和交接。未完成验证前不写成已发布。

十二版路线当前交付十版，本版与 v1.5.5 外置卷 SFX 尚待完成，不追加重复规划。

## 实施审计

隔离 helper 0.2.0 接入 AZO、AES/LEA 和固实依赖流。`libazo` 0.1.1 固定上游 `49b325c738cb0535d74ab2ea455f8dd696a78ad1`，MIT 许可随包；逐 AZO 块读取，不再收集整段输入，块压缩/展开各最多 256 MiB，严格终止/尾随及读写错误。上游两项旧回归暴露错误类别不一致，修正真实截断为损坏，原断言保持，并补精确终止/输出故障检查。

固实输入在原数据块间流式读取并保持所属文件的解密状态；输出分别按文件跨度和块 CRC 划分，所选提取只创建选中文件，仍检查共享流。依赖块的密码需求会传给早期无块条目，不能因其自身无加密头而绕过验证。固实单条压缩体积标记未知，避免误把零或所有共享数据算到最后一个文件。原版固实目录条目也可能持有数据块，读取不会漏掉。

AES/LEA 使用显式无损密码字节，2 字节验证器匹配后仍检查认证尾部（存在时）及完整内容大小/CRC。真实旧布局没有认证尾部时不伪称已认证；错误密码、损坏和无法确认保持区分。无 EGG 创建、全局/文件名加密、修复或缺卷部分救援承诺。

十二组原始复杂包先由独立 Bandizip 固定全部文件名、字节数和 SHA256；另有六组原 ALZipCon 生成的中文 AES-128/256、原生五卷与固实 Deflate/LZMA，独立回解后再与产品对比，空目录和嵌套中文载荷均保留。原工具拒绝 `-s -m0` 和 `-s -m4`，不作为成功样本；没有将普通包改名为复杂组合。原名 `enc_lea_bzip2.egg` 的实际头部是 AES-256，按实际方法而非文件名记账。固定原包和独立证据见 `tests/fixtures/archives/egg-154`。

实际使用审计补齐解压中心批量来源编码逻辑：旧界面包含 ALZ/EGG，处理分支却只有 ZIP/ZIPX；两项定向回归先复现未应用 CP936，再修正白名单，保留其他配置和 RAR 不变。桌面验证使用真正文件选择/队列/重试；旧测试桥强制任务为 7Z，不用于证明 EGG 缺卷重试。完整组选择后移走一卷、启动失败、补回原卷和新任务才是本次缺卷接续场景。

实现步骤完成 119 项不同 Rust 检查：主程序 EGG/历史 16、诊断 32、ALZ 8、卷组 9、ZIP 密码 14，helper 5、上游解析/LEA 11、AZO 24。十一文件 212 项前端及类型/构建通过。版本身份统一至 v1.5.4；普通生产初构建通过，最后补批量逻辑后仍需最终生产构建和完整桌面重跑，不将中途截图当封板结果。新的 512 MiB 原版固实 Deflate 控制包用于真实暂停/取消，原字节和生成器记录在忽略的控制目录；不注入延迟或成功。
