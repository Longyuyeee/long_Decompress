# v1.6.34 · 密码 Deflate 图文直接预览

带密码的非固实 Deflate 7Z，现在也能沿原双栏文件浏览器查看文本、图片，再决定是否提取。

- 接通 AES 内容加密、文件名加密和完整数字分卷，可从非首卷进入，继续使用手动密码或密码保险箱。
- 完整小文本 ≤1 MiB 保持编码识别、滚动和只读显示；受支持图片 ≤8 MiB 接回原预览、整包阅读、翻页/缩放、跳过坏图、定位及仅提取当前页。
- 完整显示前同时确认 AES 消费/填充、Deflate 流结束、精确大小与压缩消费和可用 CRC，损坏内容不会作为完整成功显示。
- 手动密码错误不会回退到其他密码，预览不记为整包密码成功；保留取消、缺卷、来源变化和提取下一步，不扫描无关大文件。

保留单条展开、多选弹窗、等宽双栏、主题、工具及快捷键。固实、大日志与 Deflate64 可先沿原入口提取，后续分阶段接续；无新增依赖或格式计数变化。
