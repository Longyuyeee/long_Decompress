# v1.6.59 · LZOP / TAR.LZO 完整数字切卷读取

已完成功能封板。正式源码/合并/标签与附件状态在本版 PR 接续。

## 用户得到什么

集齐 `.lzo.001` / `.tar.lzo.001` 数字分卷并放在同一目录，从任意一卷打开、预览和取回。普通 LZOP 保持单文件，TAR.LZO 保持目录；沿原双栏、所选文件/目录入口、完整检查、ZIP/7Z 转换及结果/历史，保留单条展开、多选弹窗、自然继承、左右等宽、主题与快捷键。没有新页面或摊开的配置区域。

## 读取与失败行为

复用完整卷组解析与只保留一个打开卷句柄的读取器，跨卷解析 LZOP 文件头、数据块和结束标记，不先合并一份完整临时压缩包。所选非首卷解析为同一组，来源引用沿现有任务和历史流程保留；普通单成员校验、TAR 的完整尾部检查、取消及暂存发布保持。

缺首卷或中间卷给出确切缺失名称；重复数字编号拒绝歧义组。编号连续仅表示现有组无间隔，成功仍依赖 LZOP 结束标记及可用校验。尾卷缺失/截断明确提示可能缺后续卷或卷损坏，总卷数无法确认，补齐原始分卷后重试；不虚构缺失总数，也不将半成品作为成功结果。

只有一个完整 `.001` 成员文件也可作为合法字节切片组。数字切片不等于 LZOP 原生 multipart 或多成员；原生多部分、多成员、裸 LZO、附加过滤器、创建、原生密码和缺卷内容救援仍不支持。无数据校验的原件无法保证内容未变，前缀预览不代替完整检查。创建能力的 supports_split 保持 false，读取数字切片不增加可创建格式数。
