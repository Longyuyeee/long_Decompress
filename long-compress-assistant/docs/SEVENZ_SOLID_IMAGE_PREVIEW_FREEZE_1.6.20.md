# v1.6.20 · 7Z 小型固实图片与原阅读器

## 本版范围

按[路线](ARCHIVE_ROADMAP_1.6.20.md)将未加密 LZMA/LZMA2 固实包的准确所选完整 PNG/JPEG/GIF/WebP/BMP 接入原双栏图片弹层和原阅读器，完整数字卷从有效任意成员进入。图片 ≤8 MiB、单边 ≤8192、总像素 ≤1600 万；共享压缩数据和解码总量分别 ≤64 MiB，元数据与载荷实际输入合计沿原 64 MiB 包装器，seek 不重置、候选整体 30 秒。

复用 v1.6.19 的 `BlockDecoder::read_solid_entry`，本版没有修改 vendor 或通用提取/创建。完整共享块内全部文件大小/CRC、块 CRC、可用压缩 CRC、压缩覆盖和编码结束通过后，再交给原图片识别；仅保留所选图片，共享输出逐 32 KiB 检查取消/截止，不解开临时整包、不读取无关大块。取消、换源、缺卷、损坏和超限保留明确下一步。加密共享流在解码前给提取指引，不冒称密码失败，不触发所选以外的验证；原非固实密码图文和完整小文本范围保持。

沿原双击、眼睛、右键/Ctrl+Enter 和图片弹层；阅读器按需当前页，保留三张/16 MiB/2400 万像素缓存，关闭下一页后台预读。停止/翻页/关闭取消、缩放/适应、坏图跳过、定位与当前页准确提取保持，来源读取前后绑定。7Z 固实共享读取显示简短等待，帮助仍收在问号里，另一栏位置保持；EGG 原有共享状态判断与预读策略保持。单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键和格式数量不变。

## 来源与接续检查

四项新 Rust 和四项新前端已通过。首次后端三项通过；超限负例最初受 7-Zip mx=1 默认固实块限制，被拆成无关大块和小图片块，预览允许是正确的。仅修样本为 `-ms=128m` 并核对官方 `Blocks = 1`、独立回解，再只补跑这一项，已过结果保留。完整新后端覆盖方法/五类图/任意卷入口、精确图片字节、边界/损坏/加密指引、取消/进度、来源前后变化与缺卷。共享等待与停止、关闭迟到结果、只按需当前页和原弹层帮助四项前端通过。

五组实际桌面、三张宽窄实看全部通过，已封板：准确 PNG 像素、翻页/缩放/坏图跳过/定位、当前页精确提取、LZMA/非首数字卷、共享范围/坏结束/取消/来源处理通过；1100×650 和 760×520 无横向溢出、双栏等宽。候选 SHA-256 为 `d5c0d6789f058d54ef3e169fa56cb4ec1d540a8c5c79afd51a3cd66fa3e095d5`，见[证据](evidence/sevenz-solid-image-preview-1.6.20/checks.json)。保留原 EGG 共享判断后重新生成前端与最终候选，已过业务结果不重跑；仅执行本版相关路径，不重复旧矩阵、安装或真实盘满。
