# v1.6.3 · 找出 ZPAQ 备份中受影响的文件

ZPAQ 备份目录还能打开、内容校验却失败时，现在可以看清检查到了哪些文件。

- **区分结果**：按所选快照检查数据块与片段内容，把文件分为检查通过、受影响和未检查；共享块失败会列出关联文件，不能据此断定每个文件都已损坏。
- **按需看详情**：归档诊断页只保留紧凑摘要。详情弹窗支持文件/数据块切换、搜索、筛选、分页和关联范围定位，长清单不铺满主页面。
- **保持所选版本**：浏览器当前栏可进入文件影响诊断，也可以从诊断页返回选择旧快照。检查旧快照通过，不代表整个备份或其他版本完整。
- **报告与来源接通**：覆盖普通包、密码包、单包和已确认原生多部分；可以取消，复制报告包含实际快照及各项状态。选择原生部分会先确认来源组，页面显示原始文件位置；重启后的批量记录要求重新检查，不保存密码或巨大的文件明细。

本版只诊断定位，不执行部分文件抢救。目录损坏、缺卷或密码不匹配时不推断可用条目；尾部写入中断时继续提供 v1.6.2 的完整旧快照取回入口。超过本次解码范围的内容保持未检查。原包保留，单条展开、多选弹窗与双栏交互保持。

依据为明确标注的受控数据字节损坏副本：四种组合共二十次官方逐文件读取对照，并检查旧快照范围，不冒充自然损坏原件。详见 [封板记录](https://github.com/Longyuyeee/long_Decompress/blob/v1.6.3/long-compress-assistant/docs/ZPAQ_BLOCK_DIAGNOSIS_FREEZE_1.6.3.md)。下一步为 [v1.6.4 已校验文件的部分取回](https://github.com/Longyuyeee/long_Decompress/blob/v1.6.3/long-compress-assistant/docs/ARCHIVE_ROADMAP_1.6.4.md)。
