# v1.5.27 功能封板

2026-10-20，接续正式 v1.5.26。WIM 数字分卷按范围完成，进入候选、普通受保护合入与正式发布。本文件为合入前快照，最后候选及正式资产身份在本版 PR/Release 接续。

## 交付与边界

WIM 指定大小数字切卷、任意成员浏览、按编号查看多镜像、有界文本/图片预览、完整检查、所选/整包、密码 ZIP 双向转换、补卷新任务和整组结果校验清单接通。随包 7-Zip WIM.SPLIT 直接跨成员读取，不先拼接完整临时包。修复目录空 Size 导致前置资源统计失败。

实际新建 WIM 只存储和去重，明确 -mx0；单条、多选与转换停用无效强度。读取 Copy、XPRESS、LZX、LZMS 原件不等于新增对应编码。WIM 无原生密码，带密码任务批量切换会整体提示并保留原配置；源 ZIP 密码独立于新目标。数字切片不是原生 SWM，不承诺部署/原镜像元数据恢复。多镜像转换保留内容目录，新建一个内容归档；不提供缺卷部分救援。

单条展开、多选弹窗、自然继承、左右等宽及窄窗滚动保持。预览不落临时文件，限制输出、256 MiB 子进程内存和30秒等待，超限提示先解压；不宣称随机访问解码的全部输入字节严格受文本预算限制。

## 定向依据

- 九项不同 Rust：四类独立原件极小/不等长切片的首中末成员浏览/检查、精确镜像2文件和镜像1目录所选提取、缺卷/截断、密码/取消/超限原因、公共格式/资源统计，以及四方法文本与 PNG。首轮八项通过，仅修复并补过空 Size 资源统计项。
- 八项不同前端：能力、继承分卷/打开不隐式编辑、原多选弹窗、各条卷大小/不适用参数、密码批量原子保留、转换源密码、WIM 仅存储强度和过期强度不提交。仅增强受影响组件并新增两项，不重复计数。
- 六条真实公共原生：Copy、XPRESS、LZX双镜像、LZMS固实原件中卷完整提取；请求旧level0/6的产品数字卷创建、中卷提取、独立wimlib完整apply与源SHA256/空目录一致。level6最终明确为Copy，不把原错误检查当成新编码能力。
- 六条实际 UI：三卷创建及结果带入摘要/独立值；双条多选和带密码原配置保留；中卷双镜像文本/图片与仅取镜像2一个文件；真实撤卷失败/补齐新待执行任务/旧失败保留；WIM末卷到密码ZIP；后者到普通WIM数字卷。两次转换经独立解码逐文件核对。

独立 wimlib 1.14.5 官方包摘要、工具和原件身份固定于 fixtures manifest。多镜像根 [1].xml 由独立工具抽出原资源取得摘要。新建WIM没有可选整包integrity table，verify的跳过提示本身不算通过，仍解出全部内容核对SHA256。
