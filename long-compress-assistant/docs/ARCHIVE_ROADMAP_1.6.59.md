# v1.6.59 规划 · LZOP / TAR.LZO 完整数字切卷读取

已完成功能封板，见[记录](LZOP_NUMERIC_READ_FREEZE_1.6.59.md)。下一阶段 [v1.6.60 多成员资料读取](ARCHIVE_ROADMAP_1.6.60.md)仅规划。在普通 LZOP 与 TAR.LZO 只读流程上，让收到完整数字切卷的用户从任意一卷直接打开、定位与取回；继续优先打通实际文件处理流程。

1. 先做整组字节切片的识别/归组和完整读取，覆盖文件头、块及结束标记跨卷，支持普通 `.lzo.001` 与 `.tar.lzo.001`。数字切片不等于 LZOP 原生多部分或多成员，保持明确区分。
2. 贯通双栏目录/单文件浏览、图文/前缀预览、完整检查、选择性取回、ZIP/7Z 转换及结果/历史，非首卷保留用户来源与整组身份。
3. 缺中间卷、非连续编号、截断和不完整尾卷保留具体原因及补齐后重试。编号连续不能证明完整，尾卷缺失只按结束标记、已知卷清单等实际证据判断，不猜测不存在的总卷数或给出假成功。
4. 同时核对普通单文件/完整 TAR 目录的尾部检查、取消和暂存发布。保持单条展开、多选弹窗、自然继承、左右等宽、主题和快捷键，复用已经通过的原件和界面证据，只检查新增与受影响路径。

本期仍不创建 LZOP、不提供原生密码、多成员/原生多部分或缺卷内容救援。完成这一步后继续按真实失败包影响推进格式/算法与容错兼容；ALZ/EGG 有效外部原件缺口继续保留，不把切片原件或合成数据当成原生卷/外部真实应用兼容证明。
