# v1.5.62 ZIP PPMd 跨流程兼容封板记录

2026-10-22。实施见[路线](ARCHIVE_ROADMAP_1.5.62.md)，用户说明见[Release](RELEASE_NOTES_1.5.62.md)。

## 实际范围（功能已封板，进入发布）

- ZIP 方法 98 纳入独立普通/AES/ZipCrypto ZIP 编辑与资料对比。普通保留条目复制原压缩数据，密码条目按 PPMd 重编码；新增/替换和所选组包明确 Deflate/Store。原件、已有输出及原失败保留，沿原元数据能力，不冒称全部无损。
- 文件夹↔ZIP、ZIP↔ZIP 的实际内容核对、所选精确取回、补充取材、完整数字/标准卷、明确密码编码与原草稿/历史接续共用原流程，不做原生分卷回写。
- 修正 PPMd 解码器将物理提前断流当作正常结束的问题：ZIP 专用输入适配把提前 EOF 作为错误，按实际目录大小读并检查真实结束标记、尾部压缩数据和原 CRC/加密包装；空读取不初始化解码器。未知恢复码（含 Freeze）及异常阶数在分配前拒绝，支持原 Restart/CutOff 和 1～256 MiB 头参数范围。分配失败说明所需内存。未改 PPMd 写入器、未新增依赖或资源限额，未改 7z PPMd。
- 原单条展开、多选弹窗、自然继承、压缩/解压左右等宽、窄窗滚动及 schema 18 保持。前端只更新支持提示，不为静态文案添加重复单测。

九项新增 Rust 全部通过：普通保留条目字节/方法/备注/时间/权限及添加；AES/ZipCrypto、明确 CP936、保留/去密码/换密码和空文件；错误/缺密码及已有输出保留；真实内容核对；数字卷取材精确范围、来源变化/缺卷与编辑边界；CRC/大小/截断拒绝；独立 7-Zip 的真实 Restart/CutOff 原包、参数/原字节另存及独立回解；晚期截断、未知恢复码/异常阶数、尾部多余数据和伪造匹配 CRC 的前缀大小拒绝；流式空读取和完整结束。

类型/Vite、八处版本身份/Shell DLL 通过。原生 `custom-protocol,desktop-e2e` 构建通过，桌面程序 SHA-256：`c2f462fc797208698e0377dcbf94064d600fd65b4dc4ff3deab7aea4e043a037`。四条真实桌面组合、18 条宽窄布局及 6 张代表图实看完成，见[原始记录](evidence/zip-ppmd-compatibility-1.5.62/desktop-progress.json)和[检查收据](evidence/zip-ppmd-compatibility-1.5.62/checks.json)。这是本次检查程序身份，不当作正式安装包身份。

1. 独立 7-Zip 生成真实 PPMd 普通 ZIP，单条右键改名/移动和添加，沿原清单另存；独立回解内容正确，原条目保留 PPMd，新增内容为明确选择的 Deflate。
2. AES PPMd 错密码失败不产输出，纠正原密码并设新 AES 密码后另存成功，保留原失败；独立回解内容和 PPMd 方法正确。
3. AES 数字卷从非首成员读取，缺密码核对未完成、补密码后内容相同；弹窗只取所选文件，正常退出/重启恢复范围且密码为空，补密码取回及历史再取回均仅产所选文件。
4. ZipCrypto 标准卷从非首成员进入 ZIP↔ZIP 内容核对，缺卷拒绝，补齐后所选引用组包；明确去密码并按 Deflate 写出独立 ZIP，7-Zip 回解只含所选内容，全部原包/卷组 SHA-256 保持。

九项 Rust 与四条桌面组合首轮全部通过，没有为本版修正样本、重跑已完成组合或调整产品交互。复用 v1.5.35 既有创建/转换和资源依据，不重跑旧全格式/密码/算法/媒体矩阵、真实盘满或个人安装。
