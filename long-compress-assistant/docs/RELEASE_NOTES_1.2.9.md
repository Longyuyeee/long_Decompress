# Long解压 v1.2.9

v1.2.9 是 v1.2.8 之后的维护收口版本，不改变已审计的归档业务语义。

## 本次收口

- 完整复验解压显示与真实启动顺序、并发上限、同目标安全串行及全局/单独配置来源。
- 重新验证单项与全部暂停、恢复、停止：原生读写、密码尝试、完整性校验、最终发布和 Windows 外部归档进程继续受统一控制器约束。
- 重新验证停止后的暂存清理和队列接续，以及并发压缩、真实字节遥测、加密 7Z 往返和密码格式回退。
- 清理已经被后续版本取代的陈旧开发入口，并统一 README、发布审计和跨电脑交接状态。

## 保持不变的边界

- 原生 RAR 在条目边界安全暂停；外部 RAR/7-Zip 进程可由 Windows 即时挂起。
- 图片、视频和 PDF 仍使用各自的取消协议，不显示不具备后端能力的可恢复暂停。
- Windows N 暂不支持；Windows 11 第一层菜单仍需要生产代码签名身份。
