## 2. 审计发现与纠偏

- 原 `test:e2e:desktop:video-workspace` 仍按 C-02 口径查找已经删除的 `.execute-disabled`，只证明规划且无法执行，和 C-03.3.2 已开放真实执行的代码事实偏离。现已升级为 C-05.1 真实执行门禁。
- 视频输出目录和流变化确认最初没有复用项目现有的 `VITE_DESKTOP_E2E` 对话框/确认队列，导致隔离 Release 门禁只能打开原生对话框而无法继续。现只在 E2E 构建中消费既有桥接；普通生产构建仍调用原生 Tauri 对话框。
- completed 任务保留最后一个 `Publishing` 阶段，卡片会同时显示“已完成”和陈旧阶段。发布事实写入后现清空瞬时阶段，让状态回落到终态标签。
- 压缩中心视频标签仍显示 `C-02`。现纠正为当前阶段 `C-05`，避免 UI 与开发文档继续漂移。
- 短生命周期全局成功提示不是稳定验收依据。门禁改用卡片终态、磁盘输出、产品 ffprobe、数据库历史和结构化 JSON 交叉证明结果。

## 3. 真实结果

- 输入一：冻结 MP4/H.264，VFR、90° 旋转、AAC 和字幕，时长 1.200 秒；输出 23,060 B，MP4/H.264/AAC，360×640。
- 输入二：产品 FFmpeg 从冻结容器复制生成的 30.536 秒双音轨/字幕样本；输入 975,868 B，输出 700,693 B，MP4/H.264/AAC，360×640，历史节省率约 28.20%。
- 本地可再生成证据：`test-results/desktop-e2e/video-workspace-execution-result.json` 与 `video-workspace-published-results.png`，不提交仓库。
