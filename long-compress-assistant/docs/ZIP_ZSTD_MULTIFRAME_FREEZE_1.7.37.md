# v1.7.37 · 多帧 Zstandard ZIP 丢目录部分取回封板

日期：2026-10-30。

## 用户行为与实现

未加密 method 93、未知本地压缩尺寸的 ZIP 丢目录后，原恢复入口现在可把一个成员中的多个普通 Zstandard 帧作为一个完整文件取回。每帧真实结束时，先用累计消费量、展开量和 CRC 在准确位置匹配描述符；不吻合时，仅在同一位置为下一普通帧才继续，不扫描正文标记找后续成员。无签名描述符的 CRC 恰好等于 Zstandard magic 时，仍优先确认描述符。

解码器按帧只重置会话，保留 256 MiB 窗口上限；未知边界恢复每个成员最多 4096 普通帧，累计展开上限和取消沿原规则。确认描述符结束后直接传回恢复读入器，避免再匹配一次同一描述符。非零本地展开声明与累计值仍需一致。后帧坏损、截断、缺失、CRC/尺寸矛盾或未知边界时，整个当前成员不输出，前面的完整成员仍可另存。

空帧前后组合、普通/ZIP64 有无签名描述符、完整数字切片、明确目录和后续混合方法接通。帧头和描述符被切片拆开时可读，缺中间卷不跨缺口扫描。新包整体验证、确认日期传递、结果/部分历史及修正原件后重试保持，原总清单仍未知。UI、单条展开、多选弹窗及等宽双栏保持，不增加格式数量。

可跳过帧、外部字典、历史 method 20 及密码未知边界仍未扩展；4096 帧限制专指这条未知尺寸恢复路径，不改变正常完整目录的既有读取能力。

## 本次来源与检查

- 固定真实 libarchive 帧与独立 CPython BZip2 尾记录；普通/ZIP64、签名组合均明确标为结构控制，压缩帧 SHA 对应原件。另由 bsdtar 实际编码 CRC 等于帧头 magic 的四字节原件，派生无签名控制。
- 5 项新增原生专项首轮全部通过：普通多帧/空帧/无签名歧义；实际数字切片与缺中间卷；26 个后帧/描述符损坏停止；首成员失败及修正重试；4096 帧边界、累计展开上限和取消。共享原 v1.7.36 的结果/最终目录检查辅助，没有复制整套恢复辅助或新增页面。
- 独立 Python/7-Zip 核对 33 份恢复新包、115 个条目的内容、大小、路径、本地/中央 UT 和 DOS 日期；33 份本软件最终解压目录与 38 次外部读回一致。2 个不发布场景、原件 SHA 和暂存清理通过。
- 最后代码审阅补齐帧间真实读取错误的原始原因传递，只补查受影响的完整成员和损坏停止两组，更新后的产物再次独立核对通过。
- 相关旧单帧 Zstandard（含 BZip2 混合）与 Deflate 两组通过。当前 Shell DLL 和版本身份通过，文档、最近五版清单与差异检查通过；前端没有修改，未重跑已通过界面或无关矩阵，未控制桌面。正式安装器和更新附件由本版 PR / Release 接续。
