# Long解压 v1.1.4

本版本重新整理压缩包浏览中心，让目录与文件成为页面主工作区，并补齐拖入打开和资源管理器直达浏览能力。

## 修复与改进

- 压缩包路径、密码和统计改为紧凑区域，释放主要纵向空间给目录树与文件列表。
- 左侧目录从完整路径平铺改为可折叠的文件夹层级，支持嵌套目录与空目录，不再重复展示难以辨认的完整路径。
- 空状态和已打开状态均支持 Windows 原生文件拖放，并保留标准 Web 拖放兜底；拖入新压缩包可以直接切换浏览对象。
- 输出目录移入底部操作栏，搜索、类型筛选、精确多选、图片受限预览和选择性解压继续复用现有安全链路。
- 资源管理器经典菜单和 Windows 11 原生 Long解压 子菜单均提供“浏览压缩包内容”，使用独立动作直达浏览中心；既有 Shell Command GUID 保持不变。

## 验收

- 前端：193 项单元测试通过，TypeScript 类型检查和生产构建通过。
- Windows Shell Extension：5 项 COM 单元测试通过；Rust 右键命令参数测试通过。
- 发布身份：应用、Tauri、Shell Extension 与两份锁文件统一为 `1.1.4`。
- 依赖安全：npm 官方源生产依赖审计为 0 个已知漏洞。

## 已知限制

公开安装包没有商业 Windows 代码签名证书，因此继续跳过 Windows 11 第一层菜单身份包；Long解压 经典子菜单仍可用。可见 Release 桌面拖放与安装态右键需要在未占用 WebView2 自动化会话的环境完成最终复验。
