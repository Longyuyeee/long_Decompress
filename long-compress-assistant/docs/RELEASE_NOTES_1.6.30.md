# v1.6.30 · 密码固实 PPMd 7Z 直接查看图文

带密码的小型固实 PPMd 7Z，现在也能在原双栏直接阅读小文本、预览图片和连续看图。

- 接通 AES 内容加密、文件名加密和完整数字分卷，兼容首个或后续所选文件；沿原手动密码和密码保险箱入口，手动输入错误时明确提示。
- 支持完整文本 ≤1 MiB、PNG/JPEG/BMP/GIF/WebP ≤8 MiB。原编码识别、滚动、“完整显示”和图片阅读器翻页、缩放、坏图跳过、定位、准确提取当前页贯通。
- 完整检查 AES 明文/密文与填充、所选共享块的前后内容、大小、可用 CRC 和 PPMd 实际结束；不能把读出所选文件当作完整读取成功。
- 共享块压缩/解码各限 64 MiB，只保留所选文件；原输入、字典、时间、取消和来源范围保持，不整包临时解压、不扫描无关大块。

保持单条展开、多选弹窗、左右等宽、主题/工具/快捷键，帮助沿原问号。PPMd 大文本仍给“提取后打开”下一步；下一阶段仅规划非固实大文本开头预览。无新增依赖或格式计数变化。
