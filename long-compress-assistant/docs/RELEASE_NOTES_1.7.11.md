# v1.7.11 · 取回文件保留原修改时间

从损坏或缺卷的 TAR.LZO 取回完整文件后，可继续按原修改时间整理资料，避免所有文件都变成取回当天。

- 普通文件头、GNU 时间及局部/全局 PAX 的时间继承、覆盖、删除、小数与负数接通；小数以整数秒和纳秒处理。
- 文件内容确认后再保存时间，并回读确认。目标位置的范围或精度不足、时间缺失或无法写入时单独提示，已取回内容继续保留。
- 原结果详情默认折叠，展开查看每个文件的原时间和提示；历史详情保存时间保留数量。旧记录可读，保留单条展开、多选弹窗和左右等宽双栏。

本版仅恢复普通文件修改时间，目录时间、权限、所有者及其他完整元数据未扩展。GNU tar 1.35 对负数小数时间的解释与 Python/Go 不同，本版沿用现有正常读取的负数语义，详见实现记录。

见 [本版范围](ARCHIVE_ROADMAP_1.7.11.md)、[实现与检查](TAR_RECOVERY_TIME_FREEZE_1.7.11.md)。下一阶段 [v1.7.12 目录修改时间](ARCHIVE_ROADMAP_1.7.12.md)仅规划。
