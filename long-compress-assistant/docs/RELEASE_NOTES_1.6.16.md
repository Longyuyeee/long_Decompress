# v1.6.16 · EGG 大文本前缀预览

查看 EGG 包内的大日志、说明和配置时，现在可以直接阅读开头，无需先把整份文本解码或提取出来。

- **原位置看开头**：非固实 Store / Deflate / Bzip2 / LZMA 文本最多显示前 1 MiB，保留原双栏、双击/眼睛/右键/Ctrl+Enter、滚动和关闭操作。
- **部分内容说清楚**：显示“部分内容 · 未校验整文件”，保留 UTF-8、UTF-16 和已有兼容编码的完整字符边界。读到的完整数据块仍要检查，范围前的损坏拒绝显示；未读尾部的 CRC/终止状态不会伪装为完整成功。
- **密码与分卷接续**：沿手动密码、保险箱、显式代码页和完整原生卷入口；候选只尝试所选内容，不记为整文件密码验证成功。关闭/换项取消、来源变化刷新，超限给提取指引。

每次候选的实际压缩载荷读取（含认证重读）最多 64 MiB，候选整体限时 30 秒。有认证尾的密码条目仍需认证压缩载荷，读取也计入预算；大存储条目无需因整条超过 64 MiB 而提前拒绝。新增方法/密码/卷组为自有受控组合，不扩大原工具所有历史互通口径。

小文本、图片和固实小图文继续完整校验，完整提取、检查与转换的成功条件保持。保留单条展开、多选弹窗、左右等宽和工具收纳；不新增固实大文本前缀、加密固实、EGG 创建或修复。详见[本版范围与记录](https://github.com/Longyuyeee/long_Decompress/blob/master/long-compress-assistant/docs/EGG_TEXT_PREFIX_FREEZE_1.6.16.md)。
