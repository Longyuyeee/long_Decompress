# Long解压 v1.5.4

本版补齐更多 EGG 只读组合，让密码包、固实包与原生分卷能沿用现有浏览、解压和失败接续流程。

## 新增和修复

- 新增已验证的 AZO（含 x86 过滤）、AES-128/256、LEA-128/256，以及固实 Deflate/LZMA 读取；支持浏览、所选/整包提取、完整性检查与转换输入，保留已有基础方法、传统密码及原生卷。
- 固实所选提取只输出选中文件，同时读取并核对依赖的共享流。早期条目没有自己的数据块时，仍正确显示其依赖的密码需求，不误报压缩体积。
- 原版中文 ALZip 的 AES 密码可明确选择 CP936，文件名按自身标记读取。错误密码纠正、缺卷补回后新任务、历史重做保留编码，但不保存密码，旧失败记录继续保留。
- 修复解压中心批量设置 ALZ/EGG 来源密码编码时，界面已选择但任务实际未应用的问题；不覆盖无关配置。
- 未知方法、缺卷和损坏保留具体最终原因，不一概引导尝试密码；AES/LEA 短验证器匹配后仍需完整内容大小/CRC，存在认证尾部时同时核对。
- 调整 EGG 只读提示及问号说明，常用与窄窗口页面已经实际查看。

## 验证

119 项定向 Rust、212 项前端、35 组真实原包、45 个真实桌面场景与 24 张页面通过。包含中文 AES 中卷所选提取、固实所选、转换后独立回解，以及实际解码开始后的暂停、恢复与暂停中取消；取消不发布结果且保留源包。

## 本版边界

EGG 仍只读，不创建 EGG，不提供全局/文件名加密、损坏修复或缺卷部分救援。算法、密码、代码页和卷型按真实验证组合开放，不宣传全部 EGG 兼容；加密固实、LEA 中文密码等未经验证组合不作承诺。旧布局可能没有认证尾部，CRC 不认证文件来源。

最多 1000 原生卷、250000 条目、16 MiB 单元数据字段、512 GiB 声明展开总量；AZO 单个内部块压缩/展开各 256 MiB，LZMA 单个压缩块及固实 LZMA 整段压缩输入各 256 MiB。固实混合方法和只有加密空文件的密码验证仍明确拒绝。原生卷需保持原名并补齐。Windows N 暂不保证支持。
