# v1.7.5 · TAR.LZO 损坏后，取回已经完整的资料

TAR.LZO 尾部截断、数据块损坏或缺少数字分卷时，可以从失败任务的 **检查并尝试救援** 入口，选择已经确认完整的文件和目录，保存到独立的“部分取回”文件夹。

## 本版更新

- 核对外层 LZOP 数据块校验与内部 TAR 的文件头、内容和填充边界。尚未完整到达的文件不列入清单，首个间断之后不拼接后面的卷。
- 支持普通文件、空文件、目录和 UTF-8 PAX 路径。目录勾选会带上其中已确认的条目，空目录也可单独取回。
- 复用原来的紧凑救援弹窗，支持筛选与勾选，停止原因默认收起，范围说明放进问号；保留单条展开、多选弹窗、左右等宽和原双栏浏览。
- 结果独立保存，取消清理本次暂存；来源变化需重新检查。历史明确显示 **TAR.LZO 部分取回 / 已部分取回**，分别保存文件与目录数量，并可重新检查原包。
- 完整 GNU/PAX 归档仍沿原来的完整读取流程检查，不因部分抢救暂不支持某些扩展而误判完整包损坏。

## 使用边界

支持 `.tar.lzo` 和 `.tar.lzo.001` 等数字切片的连续前缀。无外层内容校验时不宣称文件完好；抢救遇到稀疏、硬链接、符号链接、GNU 长名称或未知 PAX 元数据时停止并说明原因。本版未增加这些条目的部分抢救，完整包的既有读取能力保留。

部分取回不等于完整解压成功，也不会补造缺失数据或覆盖原件。正常解压、浏览与全量转换仍要求完整来源。
