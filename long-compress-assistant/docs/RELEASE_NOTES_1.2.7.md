# Long解压 v1.2.7

本版本收口解压任务布局、全局省略文本提示、核心工作区垂直密度和双栏文件浏览器窄窗口行为。

## 解压任务布局

- 加宽任务名称区域，省略名称悬停后显示完整内容。
- 状态、阶段、进度和操作使用稳定网格，完成状态保持居中，不再被无意义空白挤偏。
- 多文件使用中文数字自然排序，避免 `2`、`10` 等编号按纯字符串顺序混排。
- 存储预检恢复目标位置、介质、剩余空间、预计占用、文件系统与预留空间，同时保持紧凑。
- 760×520 低高度窗口继续显示侧栏版本徽标，预检卡不会被底部操作栏遮挡。

## 完整文本与工作区密度

- 所有真实发生省略的单行文字可在鼠标悬停或键盘聚焦时查看全文。
- 已有业务标题不会被统一机制覆盖；动态文字更新后，下一次悬停会同步刷新完整内容。
- 解压中心、压缩中心、特殊压缩的标题字号、上下留白和底部操作区向文件浏览器的紧凑布局对齐，为中间任务区释放更多空间。

## 双栏文件浏览器

- 920、760、390 px 三档宽度始终保持左右两个文件浏览区，不再切换成上下排列。
- 窄窗口按优先级收缩修改时间、大小、按钮文字和工具间距，根容器不产生横向溢出。
- 文件名、大小、修改时间和窄窗口图标按钮均保留完整提示。

## 验证

- 前端单元测试、Chromium E2E、生产构建通过。
- 真实 Windows Tauri 在 920×620、760×520 下逐图验证解压/压缩详情与双栏文件浏览器。
- 真实文件浏览器门禁继续覆盖右键菜单、精确目录/文件定位、复制、移动与特殊目录属性友好提示。

Windows N 仍不在当前支持范围内；Windows 11 第一层资源管理器菜单仍受生产代码签名身份限制。
