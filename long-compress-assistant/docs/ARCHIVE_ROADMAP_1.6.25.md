# v1.6.25 候选 · 7Z 固实大文本开头

仅规划，尚未开发。接续 v1.6.24 非固实密码大文本，先处理未加密 LZMA/LZMA2 固实包中准确所选的大日志，继续算法、密码、分卷和容错兼容主线。

1. **先准确定位共享内容**：确认共享块中的唯一普通文件、顺序和大小映射。流式跳过其前置依赖，只保留所选前 1 MiB，避免把前一个文件的字节显示为所选正文；前置输出与显示开头合计不超过 64 MiB，元数据/载荷实际输入合计仍不超过 64 MiB、字典/头范围与候选整体 30 秒保持。
2. **独立部分读取**：原完整共享读取仍须检查全部大小/CRC/真实编码结束。部分路径不宣称已校验前置或未读尾部、整文件 CRC 或整包完整性；二进制、过早结束、映射不明、超范围与未知组合给出下一步。
3. **沿用现有操作**：复用原双栏文本弹层、部分标记、滚动与“提取后打开”，完整数字分卷、来源前后绑定、关闭取消和迟到丢弃接通；不创建临时整包、不增加主页面介绍区。
4. **独立完成后发版**：原工具生成、另一版本独立回解的固实样本，覆盖首个/中间文件、相邻易混名称、前置范围、坏尾与短输出、编码边界/取消/缺卷/来源及宽窄窗口的必要检查；保留已通过且未改动的旧证据，同步 README/Release/交接。

加密固实大文本随后单独规划，复用 v1.6.24 的明确部分 AES 路径，不能关闭元数据或完整内容的完整消费要求。新的方法/过滤器组合另拆；ALZ 方法 3、历史 Bzip2/原工具图片和 EGG 加密固实继续等待有效来源。保留单条展开、多选弹窗和 50/50 双栏。
