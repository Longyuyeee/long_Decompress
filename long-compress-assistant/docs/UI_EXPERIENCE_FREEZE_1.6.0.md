# v1.6.0 界面体验升级封板记录

2026-10-22。用户明确要求将本轮界面改进合并并正式发布为 v1.6.0；本版不扩展新的归档算法。

## 交付范围

整合 PR #261 的全部页面信息层级整理、三大资料模块收纳、持续双栏归档浏览、本地常用文本预览、四种特色主题、动态格式统计、更新下载进度与关闭到托盘修正。前面各阶段的范围和依据分别见[全页面整理](PAGE_UI_REVIEW_2026-10-22.md)、[双栏浏览](DUAL_PANE_ARCHIVE_BROWSER_2026-10-22.md)、[模块整理](UI_WORKSPACES_POLISH_2026-10-22.md)、[设置与托盘](SETTINGS_UPDATE_TRAY_2026-10-22.md)。

最终补齐三个导航快捷键：资料对比 `Ctrl+Shift+D`、归档资源库 `Ctrl+Shift+L`、工作流中心 `Ctrl+Shift+W`。全部 11 个入口共用显示和按键定义，保留窄窗名称与悬停提示；编辑输入、已处理事件、IME 和额外 Alt 组合不触发跳转。设置中的密码格式长清单也默认收起，展开正文使用主题文字色，避免深色主题出现暗棕正文。

单条点击展开、多选弹窗、左右等宽与原处理流程保持。原 v1.5.65 未开发计划顺延为 [v1.6.1](ARCHIVE_ROADMAP_1.6.1.md)，继续 ZPAQ 原生多部分另存增量更新及后续格式、密码、分卷、容错主线。
