# Long解压 v1.5.30

从 ZPAQ 历史中找回旧版文件。

- **按快照浏览**：日志式 ZPAQ 有多次更新时，可按编号和时间选择；默认仍显示最新内容。切换后目录、统计和文件选择同步更新，刷新保留当前快照。
- **看清旧版再取回**：文本/图片预览、打开文件、内容检查、诊断及所选/完整解压都读取所选快照，可取回后来修改或删除的文件。
- **密码与分卷接通**：支持原生密码和现有数字分卷，从任意成员进入；缺卷补齐后创建新待执行任务，保留原失败记录与所选快照。
- **转换与接续更顺手**：从浏览器直接转换当前快照，也可在转换中读取历史。多选改配置、草稿恢复和历史再次解压保留各自快照，恢复不自动执行，密码仍需重新填写。

保留单条点击展开、多选弹窗、自然继承、左右等宽与小窗口滚动。原压缩包不变；新归档只包含所选快照内容，不复制所有历史。此版不提供增量备份创建、原生追加多部分或损坏事务抢救；普通流式 ZPAQ 没有历史选择，数字分卷仍需集齐。来源变化或快照不存在时明确提示重新选择，不自动改读最新内容。
