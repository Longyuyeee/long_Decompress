# Long解压 v1.5.24

目录和多个文件也能使用 LZMA 归档，需要密码时可直接选择对应的 Long AES 组合。

- **TAR.LZMA 多文件归档**：压缩中心与转换入口增加 TAR.LZMA，保留目录结构和空目录，支持数字分卷。沿用已有 TAR 流式管线，无需先生成完整的未压缩 TAR 副本。
- **两种加密组合**：新增单文件 LZMA.AES 和多文件 TAR.LZMA.AES，沿用 Long AES V2。密码、数字分卷、认证后浏览、文本/图片预览、完整性检查及所选/整包提取贯通。
- **转换和失败接续**：新组合可与密码 ZIP 转换；缺卷补齐后沿原入口创建新任务，保留原包与旧失败历史。认证或压缩流尾部失败不会发布半成品。
- **原有入口更完整**：单条配置和多选弹窗增加新格式，批量修改保留各条密码与分卷设置。单文件格式不适用目录时先提示，避免一半修改；结果仍从原入口定位。

保留单条展开、多选弹窗、自然配置继承、左右等宽和窄窗滚动。普通 TAR.LZMA 无原生密码；LZMA.AES / TAR.LZMA.AES 是 Long 自有加密包装，接收方需使用 Long解压 v1.5.24 或更新版本。数字分卷需集齐全部成员；向其他软件分享普通 TAR.LZMA 时，可按序合并后打开。原有单文件 LZMA 及其 7Z 密码替代行为保持。
