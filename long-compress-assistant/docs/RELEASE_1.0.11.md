# Long解压 1.0.11

本版本集中优化系统托盘、解压格式过滤、任务进度显示和压缩包命名体验，并降低批量导入及任务统计的额外开销。

## 主要更新

- 托盘悬停显示“Long解压”；右键菜单可直接打开主窗口、解压中心或压缩中心，并保留显示/隐藏与安全退出能力。
- 解压中心不再接收 DOCX、XLSX、PPTX、ODT、ODS、EPUB 等文档容器。文件选择、拖放和右键任务汇合后均会执行统一归档后缀校验。
- 左下角全局进度摘要仅保留“X 个进行中”，解决其与蓝色完成数统计重叠的问题；详细完成数仍可在展开的任务监控面板中查看。
- 压缩设置新增“使用同名压缩包”，可按单个来源、文件组或全局规则自动生成归档名称。
- 多文件元数据改为每批最多 16 个并行读取；全局任务状态、完成数、总进度和当前任务改为单次遍历汇总。

## Windows 11 右键菜单说明

项目没有生产 Windows 代码签名证书，因此 1.0.11 正式安装包仍会跳过 Windows 11 新式菜单 MSIX 身份包。“显示更多选项”中的传统右键菜单及一键解压、一键打包等快捷命令继续可用。

## 验证项目

- 前端类型检查、95 项单元测试与生产构建全部通过。
- Rust 主程序、真实归档矩阵及集成测试全部通过。
- Tauri/Rust 编译检查与版本化 Shell 扩展构建通过。
- 发布构建在无 Windows 代码签名证书时会明确跳过新式菜单身份包，不会打入测试证书。
