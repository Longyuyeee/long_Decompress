# v1.5.5 外置卷 SFX 与旧自解压

从 v1.5.4 发布后主线 `479dcab` 接续，完成十二版路线最后一版。目标是原工具真实生成的 EXE 首卷加外置数据卷，以及旧 RAR4 SFX 的只读归组、密码、浏览、所选/整包提取、检查、转换和缺卷补回。输入 EXE 始终作为数据读取，不执行；不创建 SFX，不承诺任意自解压程序。

## 开工审计

`sfx_archive.rs` 检查 MZ 内真实归档头；RAR 头部与 CRC、7Z 相对偏移及普通单 EXE 在 v1.4.11 已接通。当前 RAR 卷组正则仅接受 `.rar/.rNN`，EXE 首卷不在组内；7Z SFX 相对读取仅打开单个文件。不能通过更改后缀或直接取消拒绝逻辑补齐。RAR 诊断的 SFX 分支目前只记录一个文件，需同步检查真实外置卷，保持缺卷原因先于密码。参考 [RARLAB 原厂格式说明](https://www.rarlab.com/technote.htm)。

## 实施与封板顺序

1. 原版 RAR 6.24/7.23 与 7-Zip 生成真实普通/内容密码/文件名密码 SFX，固定原名、原始字节及独立载荷，确认实际外置卷命名。旧 RAR4 单 EXE 与已发布能力分别记账。
2. 统一任意成员归组、相对读取、缺首/中/末卷及头部损坏原因；错误密码、混卷和损坏不一概归为密码错误。未知组合保持明确边界。
3. 按真实用户顺序验证浏览、所选提取、密码纠正、缺卷补回新任务、历史和转换；实际暂停/取消与输出清理必须有效。UI 如有修改，查看常用/窄窗页面。
4. 定向审计、提交推送，满足条件后固定封板提交，受保护合入、统一版本、发布四资产及中文说明，回下载核对并回填 README/交接。全部十二版交付后再按格式、密码/分卷互通和流程容错规划后续版本。

## 实施审计

十五组原包经独立 7-Zip 固定文件名、字节数和 SHA256：RAR4 单 EXE、RAR4 旧式 `.exe/.r00…`、RAR4/5 新式 `.part1.exe/.part2.rar…`，各含普通、内容密码、文件名密码；7-Zip 24.09 的独立 GUI 模块与 `.7z.001…` 三类组合。RAR4 是原 RAR 6.24 生成的旧格式，不冒称全部古早模块兼容。7Z 独立模块只接受实测原始模块哈希，数据卷不包含 EXE，可独立打开；任意 EXE 不凭同名伴随文件识别为启动模块。来源、许可与固定原字节见 `tests/fixtures/archives/sfx-155`。

共享卷组现在包含真实 RAR EXE 首卷，任意成员回到同一来源，浏览/密码/解压/诊断/检查共用；可见卷头核对 CRC、原生卷标记及 RAR5 卷内序号。明确的缺中卷、可见缺尾卷和卷头损坏先于密码。加密卷头隐藏最终卷数时不猜，解锁后的完整原生读取继续验证；缺首卷提示同名原始 EXE 的可能性，不让用户改名其他分卷。自解压诊断不开放修复。

两项真实使用问题由原包回归复现后修正：加密空文件不能证明 RAR 密码，候选需验证非空加密内容；RAR4 文件名加密 SFX 的 CLI 文本可能同时含 Headers Error 和 Wrong password，密码需求改由原生 RAR 元数据判断，不在预检阶段拒绝正确密码。完整性检查也走原生 RAR/7Z，避免把 EXE 的 PE 资源当作归档内容校验成功。

256 MiB 真实 RAR5 SFX 控制包用于块内暂停/恢复/取消。UnRAR 会预分配文件长度，测试观察与独立原载荷一致的已写内容，不能以逻辑长度冒充处理进度；原载荷须在启动提取前读取，避免测试准备 I/O 抢占真实暂停窗口。首轮取消后共享锁残留，短暂重试未解决，撤回该假设修改。固定 `unrar_sys 0.5.8` 原发布源码和 MSVC `/EHsc` 后，同一原生控制场景通过：内容先实际写入 62390272 字节，暂停不增长，恢复增长，暂停中取消，源卷保留且无发布/暂存结果。新增原生取消后立即删除输出的单元回归通过。源码 commit、许可及修改说明随仓库保留，解码算法不变；这只是控制场景重验，尚不替代最终完整桌面门禁。

真实桌面双击 `.r02` 又复现了入口遗漏：文件管理器只判断归档后缀，未包括共享分卷候选，因而没有打开归档页面。R02/001 两项回归先失败后修正，同时接右键“解压到另一栏”；仍由后端核实组内文件，不把候选当作完整归档。缺首卷的 EXE 备选提示在实际页面验证中继续核对。

当前定向 Rust 94 项不同测试通过（另 7 项需要专用外部条件的旧测试为 ignored，不计成功），九文件 196 项前端及类型/构建通过。版本统一至 v1.5.5；完整桌面与普通生产构建进行中，不提前记封板。个人安装、设置和历史未改；商业原工具只生成测试原包，不随应用分发。
