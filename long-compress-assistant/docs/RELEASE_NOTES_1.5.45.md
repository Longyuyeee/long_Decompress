# v1.5.45 · ZIP 目录整理与批量修改

## 在另存前，把内容整理好

- 原浏览器的 ZIP 编辑新增「整理内容」弹窗，按目录查看本次编辑后的结构，搜索路径、多选文件和目录。
- 支持删除、文件或目录重命名；目录操作连同子项。单个条目填写新包内路径即可移动，批量可设置名称前后缀、文字替换及目标目录，文件扩展名保留。
- 修改前后路径和受影响子项即时预览；同名、文件/目录重名、无效路径和移入自身子目录会就近提示。大小写改名可用，不默认覆盖。
- 原包右键可重命名、批量整理或从新 ZIP 删除；目录改名后，再从原位置添加或替换会对应到当前编辑位置。

## 同一清单，统一另存

- 添加、替换、删除、改名与移动按顺序进入同一待保存清单，可搜索、按类型筛选、逐项撤销或放弃全部修改。
- 整理弹窗展示待保存结构，原浏览器继续展示原包；未保存的新路径不会冒充原包内容进行预览或提取。
- 未修改及仅改名内容沿原编码复制，保留内容、方法、有效条目时间与备注；空目录可保留，也支持清空全部内容后另存为空 ZIP。
- 继续沿原进度、日志、停止、失败纠正与结果入口。失败或停止保留会话内修改，改名另存保留已有文件和旧失败；新包可继续浏览、预览和提取。

宽窗整理/复核左右等宽，窄窗顺排滚动，长路径可换行；大量条目分页，子项预览限量显示并可搜索定位。原有单条展开、多选弹窗、自然继承和压缩/解压等宽布局保持。

本阶段仍支持独立、未加密、原条目采用 Store/Deflate 的普通 ZIP；密码、分卷和其他方法继续沿原浏览/提取。下一版按既定路线推进 **v1.5.46 密码 ZIP、编辑草稿与失败继续**，随后逐步完成其余模块，再回归更多算法、格式及容错兼容主线。
