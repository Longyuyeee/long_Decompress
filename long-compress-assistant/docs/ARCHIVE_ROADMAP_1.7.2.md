# v1.7.2 规划 · LZOP 多成员创建

状态：仅规划，尚未开发。接续 TAR.LZO 目录创建，回到格式、算法及真实失败包兼容主线。

## 范围与顺序

1. 先确认官方 lzop 对新建多成员的逐文件回解与名称还原；验证普通文件、空文件、重名和中文名称，记录工具编码与名称长度边界。
2. 在原压缩中心允许将多个普通文件组成一个 LZOP 成员序列，沿用单条展开、多选弹窗、自然继承和统一结果，不新增工作区。
3. 接通已有多成员浏览、图文预览、按需取回、完整检查、转换与历史。写入取消和成员失败时不发布前半段结果。
4. 仅运行新创建链和受影响检查，证明所有成员和名称均可取回后封板，更新 README 与 Release。

原生 LZOP 不能表达独立空目录；文件夹和需要完整目录语义的内容继续使用 TAR.LZO。不能无声丢掉空目录或为无法明确命名的成员承诺完整还原。数字切卷创建、原生密码、块分段和缺卷内容救援继续分期；收到真实失败包时可按用户影响优先修复。
