# v1.6.2 · 中断备份，明确取回完整旧快照

ZPAQ 备份最后一次写入被中断时，可以从仍完整的旧快照取回资料。

- **看清状态**：双栏浏览器当前栏显示尾部更新中断、完整旧快照数量；另一栏保留。只有校验通过的未完成事务头才能开启此入口。
- **明确取回**：点击“取回完整快照”，在弹窗选择版本和输出目录，查看范围，加入解压中心待处理队列。原包保留，输出到独立子目录。
- **流程接通**：普通包、密码包、单包与已确认原生多部分组共用原任务、进度、日志、草稿与失败重试。草稿不保存密码，不会恢复后自动运行。
- **结果有边界**：任务与记录保留实际快照；执行日志标明中断事务的新增、修改和删除未取回，具体条目范围无法确定。不会把旧快照称为最新完整备份。

缺少已确认成员、密码不匹配、目录损坏或无法确认事务边界时，继续报告原问题。不会猜测未知尾卷、自动拼包、原地修复或把未校验的部分文件当作成功结果。正常备份的原有更新、单条展开、多选弹窗与左右等宽交互保留。

本版依据官方 ZPAQ 7.15 实际写入后终止进程的四类原件，独立回解前三个快照；人为裁切仅用于失败边界检查。实施范围和验证记录见 [封板记录](ZPAQ_TAIL_RECOVERY_FREEZE_1.6.2.md)，后续见 [v1.6.3 路线](ARCHIVE_ROADMAP_1.6.3.md)。
