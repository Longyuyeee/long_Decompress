# Long解压 v1.4.8

这版继续完善分卷、密码与损坏归档的处理，让多包检查、修复和重新解压可以连贯完成。单条点击展开、多选弹窗配置的操作方式保持。

## 更多 ZIP 分卷可以尝试救援

- 完整标准 `.z01 / .z02 / .zip` 卷组在中央目录丢失或损坏时，可以尝试从仍完整的文件条目重建新包，支持边界明确的普通与 AES/ZipCrypto 密码条目。
- 扩展普通流式 Deflate ZIP：通过压缩流结束位置和数据描述符核对完整文件，覆盖普通和 ZIP64 描述符。
- 恢复结果明确标注部分恢复，显示已恢复文件和未恢复说明；密码包沿用填写的密码，结果可继续加入解压队列。

## RAR 可以创建 .rev 恢复卷

- RAR 高级设置新增恢复卷数量。实际产生多个分包时，可附带创建 1～10 个 `.rev`；默认不生成，已有恢复记录比例选项继续保留。
- 单条、多选弹窗、转换、配置组、便携模板、草稿和历史再次执行保留恢复卷配置。
- 已有完整 RAR 分包可从检查页面进入“创建恢复卷”，选择数量和保存位置，不需要重新压缩；资源管理器右键“检查与尝试修复”也可以进入该页面。
- 恢复卷进入产物清单；为已有分包创建时显示保存文件，可直接定位。每个恢复卷的大小接近一个数据卷，请与原分包整组保留。
- 修正 RAR 完成后源文件体积仍显示为 0、压缩比仍为“计算中”的问题；成功后界面与历史记录保留源文件总量，结果体积包含恢复卷。

## 多个压缩包一起检查和修复

- 选择多个文件或从资源管理器右键多选进入时，自动整理为压缩包组，同组的多个分卷只检查一次。
- 汇总正常、缺卷、需要核对密码和可尝试修复的状态；单条点击展开查看原因和填写密码，多选通过弹窗修改共用密码及保存/解压目录。
- 只修复所选中可处理的归档，每组结果保存到独立目录。一项失败可继续处理，停止后可重新检查剩余项。
- 已恢复结果可统一加入待处理队列，保持修复时使用的密码和各自的解压目录，核对后开始解压。

## 使用范围

ZIP 丢目录救援要求分卷齐全且文件边界可确定。密码条目的未知边界、无法确认的数据描述符、缺卷和不支持的压缩方法不能凭空恢复；“部分恢复”不代表原包全部内容均已找回。

RAR 创建和恢复卷生成需要本机 WinRAR/Rar.exe。本轮新增恢复卷以 RAR5 为实测范围。为已有加密文件名分包补充生成恢复卷时，密码传递沿用控制台 OEM 编码限制；无法表示的字符会给出说明。原包与已有结果不会被覆盖。
