# v1.5.43：批处理与结果体验

2026-10-21，接续已合入并发布说明的 v1.5.42。按近期路线收尾常用操作，下一阶段进入已批准的 v1.5.44 编辑工作区。

## 本版要完成的事

1. 压缩、解压和转换复用一组轻量状态筛选：全部、待处理、进行中、成功结果、失败/取消。计数按当前工作区，查看不会改任务、自动重试或清除结果；筛选后空列表给出返回入口。切换筛选取消原多选，避免看不见的条目仍参与修改/启动；新建重试草稿和任务栏定位应回到可见范围。
2. 原多选弹窗内显示所选任务清单和本次修改摘要。摘要与实际提交共用同一份参数，密码只显示是否统一/关闭，不显示内容；未指定项目保留各自配置。压缩、解压和转换一致。
3. 成功筛选直接使用原任务结果卡与批量打开/复制。批量目录有不可访问项时列出对应路径，便于找回；长路径自动换行，窄窗按钮折行，不新增结果中心。
4. 保留单条展开、多选弹窗、自然继承、左右 50/50、原日志/结果滚动。所有既有配置、预设、校验和失败处理入口保留。

## 实施与收尾

本版改前端交互，不扩格式算法，不改底层执行/发布和历史数据。只测受影响的状态分类、筛选/选择、配置摘要与提交、目录反馈，做一次实际桌面批处理及宽窄显示；已通过且未受影响的格式/密码矩阵、盘满等不重复。

完成功能后更新 README、中文 Release、八处版本身份和交接，候选 Windows 构建通过后正常合入、标签发布；正式附件由既有流水线生成。后续五模块细分见 [v1.5.44～v1.5.59](ARCHIVE_ROADMAP_1.5.44_TO_1.5.59.md)，本版不提前开发。
