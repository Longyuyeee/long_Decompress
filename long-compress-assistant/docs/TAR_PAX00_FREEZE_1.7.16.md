# v1.7.16 · PAX sparse 0.0 部分取回封板记录

日期：2026-10-28。

## 已完成

TAR.LZO 恢复读取支持局部 PAX sparse 0.0：使用 GNU.sparse.size / numblocks 和按原顺序保存的重复 offset/numbytes 属性对，不做字典覆盖。声明段数与实际配对数量、偏移/长度顺序、严格十进制值、范围和存储总量逐项确认；缺少或额外配对、乱序、重复普通属性及混合 0.1/1.0 属性明确停止。全局 sparse 和未知类型保持停止规则。

0.0 使用普通头/PAX 路径，不要求后续布局的 sparse.name；中文长路径与普通头内名称均接通。头内物理大小表示实际数据量，PAX plain size 与之冲突则停止。元数据、零填充、真实头、数据及条目末填充完整并位于外层已校验连续前缀时，才提交可取回条目。

复用已有有界 Layout、包含空洞的逻辑 SHA、Windows 稀疏写入、文件/目录时间、来源重查和取消清理。每文件 65,536 段、总映射、512 GiB 逻辑量及 1 MiB 局部 PAX 元数据边界保留；内部图计入 revision。原件保留，输出另存，恢复历史仍明确为部分取回，不跨缺口扫描。

界面仅补充原问号帮助的支持范围。原筛选、目录联选、完整/包内大小、折叠结果和部分历史保持；单条展开、多选弹窗、等宽双栏与主题未改动。正常完整读取器、普通 PAX 解析规则及稀疏写入/时间实现未改动。

格式依据：[GNU tar PAX 0.0/0.1 说明](https://www.gnu.org/s/tar/manual/html_node/PAX-0.html)。
