# v1.5.50 手动顺序工作流封板

[实施计划](ARCHIVE_ROADMAP_1.5.50.md) · [中文 Release](RELEASE_NOTES_1.5.50.md) · [记录与界面](evidence/workflow-1.5.50/)。候选、正常合入、标签与正式附件收据在本版 PR 接续。

## 用户交付

新增工作流入口，两类模板及空方案，筛选/解压/压缩/转换最多 8 步，步骤点击原位展开，支持名称、顺序、移除、保存/复制/修改/删除。压缩和转换复用原配置面板与配置组，归档名有来源、日期、时间和序号占位符；不另造编码器。运行弹窗集中选择来源、保存位置、来源密码/编码和每步输出密码，接原保险箱。

每次建立独立运行目录，各步产物分开；后一步仅接已成功步骤的实际目录或归档首个成员，原分卷分组与实际成员结果沿用。单份解压目录再次打包时读取其内容，避免把人工步骤目录包装进交付包。生成密码包的本次凭据接后续转换/解压，不把旧来源密码用于已解压内容。扫描外部目录时排除嵌入的输出目录，明确读取内部上一步产物时仍可接续。

失败定位当前步骤，其他来源或后续步骤不继续；已成功部分保留，不将部分来源成功冒充整步成功。停止取消当前任务或筛选，不再派发下一项；保存记录后、真正派发前再次检查停止。原进度/日志、任务历史和统一产物操作复用。独立 SQLite 方案/摘要表升级到 schema 16，旧资料库与历史保留；密码和删除来源选项不保存。重启保留定义和最近 100 次运行摘要，遗留运行标为中断，不自动执行。

原单条展开、多选弹窗、自然继承、压缩/解压 50/50 和滚动保持。工作流宽窗分区、窄窗顺排，来源/结果长路径换行，列表和日志有滚动上限，页面与弹窗能滚动，开始按钮保持可见。

## 范围与依据

19 项不同前端（工作流 13、受影响导航 6）、4 项不同 Rust（方案清理、持久化/15→16 升级、实际筛选/输出排除、空目录处理）通过；筛选范围改变后只补该项。类型/Vite、Shell、八处版本身份及 Windows 原生构建通过。

六条真实桌面流程、八条宽窄布局通过，八图实看。两类模板独立完整回解、目录结构和内容一致；密码 ZIP 压缩→转换→解压接续，错误来源密码不派发后一步，保险箱纠正后新运行成功；256 MiB 来源停止不派发下一步。正常关闭、同目录重启保留方案和各步结果、不新增运行，五个原件 SHA-256 保持。具体身份见记录，最终 E2E SHA-256 `17e5739348713f1df7943459e5d007bfb1bb3c74d209a34dfd34bf4ff33b5df4`。

首轮测试 worker 启动超时后改单 worker；桌面脚本修正复制后需展开新步骤的定位，实测修正未加密码的 7Z 错带文件名加密。前四条布局保留修正前程序身份，未重复已经通过的界面检查，六条完整流程在最终程序通过。只运行新增/受影响检查，不重跑旧格式/密码矩阵、盘满、媒体或个人安装；本地程序不冒充正式安装包。

首阶段手动线性、100 份方案、最近 100 次运行，主动选 1000 处来源，筛选扫描 10 万位置/保留 5 万文件；包内筛选先解压，单文件流在工作流压缩选项中禁用。RAR 等外部编码器仍按原能力和凭据限制处理。本版没有自动触发、任意脚本、自动删除、失败步骤继续或中间字节续写；运行摘要只供查看，不冒充可恢复执行。
