# v1.7.31 · ZIP / ZIPX UTC 修改时间读取与恢复

压缩包已经记录 UTC 修改时间时，浏览与实际解压现在会优先使用该时间，保留可确认的奇数秒，减少跨时区读取带来的时间偏差。

- 顺序/并行解压、所选文件、平铺、目录日期、“仅解压较新文件”和冲突提示使用统一规则；转换到目标格式时按目标自身能力保留日期。
- 密码解压回退与资料对比同步读取同一时间，界面和现有交互保持。
- 缺失、重复或无法确认的 UT 时间沿用原本地日期；边界完整但值无效的可选时间字段不再阻止正常内容解压。
- 支持本版确认的中央目录 Info-ZIP UT（0x5455）修改时间，明确范围为 1970 至 2038；高位歧义值及仅本地头记录沿原 DOS 回退，完整字段容器截断仍报错。

本版先完成读取与恢复，ZIP 创建器继续使用原日期写入方式，不增加格式数量或改变算法。见[范围](ARCHIVE_ROADMAP_1.7.31.md)、[实现与检查](ZIP_UTC_READ_FREEZE_1.7.31.md)。下一阶段 [v1.7.32 UTC 修改时间写入](ARCHIVE_ROADMAP_1.7.32.md)仅规划。
