## 5. 尚未完成与风险

恢复验证首先发现 Windows CRLF 门禁误报以及图片桌面门禁不必要依赖完整 FFmpeg 媒体夹具；两项已完成纠偏并通过真实图片基线，证据见 [B02_VALIDATION_INFRASTRUCTURE_AUDIT.md](B02_VALIDATION_INFRASTRUCTURE_AUDIT.md)。

1. 当前桌面门禁通过测试桥注入真实文件，仍需补一次用户可见的原生选择/拖放操作，验证文件路径、拒绝提示和焦点行为没有被测试桥绕过；这是 B-02 当前唯一明确阻断项。
3. 原图预览授权目前只允许 JPEG、PNG、WebP，且要求魔数与扩展名一致。这是有意的安全边界；若以后支持无扩展名图片或 TIFF，必须先更新依赖与样本审计，不能放宽成任意本地文件资产访问。
4. B-02 不执行编码，因此没有实际输出大小、压缩率、结果图或历史任务；这些只能由 B-03/B-04 的真实事实来源提供。
5. 本阶段不应提交 `target`、`dist`、测试截图或本地安装包等生成物。

## 7. 需求与偏移审计

本阶段仍以归档压缩/解压稳定性为基线，没有修改现有归档执行路径；图片草稿复用现有压缩 store，并以独立集合避免污染归档草稿。暂停审计发现并纠正了“新建图片 store 绕过 B-00 统一任务边界”的实现偏移，也补强了对应静态门禁。恢复验证继续纠正了 Windows 资产 CSP 和方向尺寸语义两处实际偏差，没有把视频/PDF 计划节点伪装成完成，也没有提前引入未经发布审计的编码器。当前只剩原生文件进入路径证据未闭环；完成前不能直接进入 B-03 或升版。
