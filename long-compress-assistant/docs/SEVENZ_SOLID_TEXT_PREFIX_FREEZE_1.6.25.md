# v1.6.25 · 未加密固实大文本开头

## 完成范围

按[路线](ARCHIVE_ROADMAP_1.6.25.md)接通未加密 LZMA/LZMA2 固实包中准确所选大文本前 1 MiB。按有数据流的文件顺序、共享数量和总大小确认映射，目录/空项不占错误偏移；前置输出与显示开头合计 ≤64 MiB，流式丢弃前置内容，只保留所选 1 MiB。实际元数据/载荷输入合计 ≤64 MiB、字典/解码头范围与候选整体 30 秒保持。共享总量超过 64 MiB 不再阻止范围内靠前大文本的部分阅读，超前置范围则给提取下一步。

vendor 增加独立 read_solid_entry_prefix，仅裸 LZMA/LZMA2、单打包流与普通文件，借用已有限字典的前缀构造，声明总大小不作为分配量。不克隆整份元数据/共享内容，每 32 KiB 前置跳过及输出检查取消，过早结束/映射/方法/范围错误不交付成功。部分路径不核对前置 CRC、未读尾部、整文件 CRC 或完整编码结束；原 read_solid_entry 仍检查完整共享大小、前后所有文件/块/可用打包 CRC、压缩覆盖和真实结束。完整小文本/图片保持原范围；非固实密码前缀保持，加密固实大文本继续提示提取，未关闭 AES 元数据或完整内容消费要求。

原双栏文本弹层明确“部分内容 · 未校验整文件”、已读/声明大小、滚动与“提取后打开”，说明放原问号。原完整数字卷、编码边界、来源前后绑定、关闭取消和迟到丢弃接通，不增加主页面介绍和临时整包。单条展开、多选弹窗、50/50 双栏、工具/主题/快捷键及格式数量保持。

五项新后端、三项前端一次执行通过：原件两方法/各卷入口、首个/中间与相邻文件、五种编码、准确范围边界、共享大总量、错误映射/短输出/前置取消、部分尾部与完整共享 CRC/结束检查、二进制/来源/缺卷和新请求。前端确认共享条目原弹层、准确所选/来源与全文命令、原问号说明及加密共享下一步。移除 v1.6.23 已被新功能替代的“未加密固实大文本不支持”负例，不重跑其余旧矩阵。顺带修正 v1.6.24 桌面报告/运行器的版本文字字段（误为 1.6.23），候选哈希与检查内容未改，不重跑前版。

四组实际 Tauri 桌面通过：原固实条目在双栏内预览且可滚动、准确部分/全文入口、首个/后续与非首卷/五种编码、65 MiB 共享总量前部可读而后置超范围拒绝、损坏尾部部分可读但完整检查失败、二进制/加密固实下一步、取消/来源/缺卷和新请求。1100×650 与 760×520 CSS 截图均已实看，预览正文、关闭、部分提示和全文按钮可见，无横向溢出，底层双栏仍等宽。候选 SHA-256 `cfcfe1aa0bccbbf9d5236e8f2c929e221a633e05a738d35a8a6aad428bc28802`，见[证据](evidence/sevenz-solid-text-prefix-1.6.25/checks.json)。前端类型/Vite 构建、八处版本身份与 Shell DLL 通过。桌面候选 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置不变；入口 node scripts/test-tauri-desktop.mjs --sevenz-solid-text-prefix-1625-only。
