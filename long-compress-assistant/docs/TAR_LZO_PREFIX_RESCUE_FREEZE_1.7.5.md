# v1.7.5 · TAR.LZO 完整条目部分取回记录

状态：功能封板完成，接续正式合并与发布。版本 1.7.5，分支 `codex/tar-lzo-prefix-rescue-175`，日期 2026-10-27。

## 实现

复用普通 LZOP 的连续来源、revision、取消和暂存发布流程，增加 TAR.LZO 专用顺序扫描。外层读取器先完整解码并核对数据块内容校验，才把字节交给 TAR；内部文件头校验、声明数据和填充均完整到达才加入清单。不要求整个外层成员已经结束，因此尾部坏块之前已确认的文件仍可独立取回。TAR 位置指当前内部条目头起点，不是压缩来源的精确坏字节。

首期支持普通文件、目录、空文件和 UTF-8 局部 PAX 路径/大小及常见不改变数据布局的元数据。PAX 记录长度和覆盖状态明确处理；未知属性、重复/叠加状态、稀疏、链接、GNU 长名称、坏头、坏数据或不完整填充处停止，不搜索下一头。无外层内容校验不列为已确认。根目录项不伪造成文件，名称和重名沿原规则分配，目录映射与文件别名一致。

数字分卷只读取 .001 开始连续非空的前缀，任意一卷可进入；缺中卷之后不拼接，缺首卷明确停止。取回前重新检查 revision，再顺序重读所选内容并核对 SHA，全部所选完成后一次移入独立结果目录。来源和已有结果保留，失败或取消清理本次暂存；目录可单独建立。

沿失败任务原救援入口进入二级弹窗，打开弹窗复用诊断结果。范围说明放问号，停止原因默认收起；图标区分文件/目录，目录勾选连同其下已确认条目，空目录可单独选择。结果及 `archive-recovery` 历史分别记录文件/目录数量，显示“TAR.LZO 部分取回 / 已部分取回”，保留原失败任务关联，可重新检查原包。单条展开、多选弹窗、左右等宽和原双栏导航保留。

部分抢救读取器范围比正常完整读取小。完整 GNU/PAX 包遇到此范围限制时沿已有完整解析和内容检查流程确认，避免把本可正常读取的完整包降为损坏。正常浏览、提取和转换的完整来源要求没有降低。
