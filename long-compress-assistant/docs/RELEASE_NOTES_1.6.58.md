# v1.6.58 · TAR.LZO 目录读取与转换

- `.tar.lzo` 现在直接在原双栏中显示目录和文件，支持搜索、文本/图片预览、文件或目录选择性取回；无需先手动解成 TAR 再打开。
- 接通完整检查、整包提取及 ZIP/7Z 转换，保留中文长路径、普通文件、空文件/目录与已验证的 GNU/PAX 稀疏内容；结果和历史保留 TAR.LZO 来源。
- 同时核对 LZOP 外层的头/块/结束标记和 TAR 内层结构，截断、坏头、无效尾部不会当成完整成功结果；修正 TAR 坏头被误归普通读写错误的提示，失败修正后可沿原入口重试。
- 复用单条展开、多选弹窗、等宽双栏与原预览界面，设置页只读支持列表同步。只有明确 `.tar.lzo` 组合且实际为 LZOP 时才展开目录；普通 `.lzo` 保持单文件读取。

只支持单成员只读，无新增创建、原生密码、数字切卷、多部分、多成员或非零过滤器能力。无数据校验的 LZOP 来源不能保证内容未改变；预览保持原有读取预算，不代替整包检查。完整数字切卷安排在 [v1.6.59](ARCHIVE_ROADMAP_1.6.59.md)。

实现与本版结果见[封板记录](TAR_LZO_READ_CONVERT_FREEZE_1.6.58.md)，正式附件由标签流水线生成，源码/合并/附件状态在本版 PR 接续。
