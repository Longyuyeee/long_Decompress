# Long解压 v1.6.1

这次让原生多部分 ZPAQ 备份可以继续添加资料，并另存为完整的新组。

## 新增与改进

- **另存原生多部分组**：在压缩中心的“ZPAQ 备份更新”中选择任一原部分，确认完整来源组后添加文件或文件夹；自动沿用原生事务结构。
- **原件与历史保留**：复制所有原部分，再为新增或变化内容写入真实的新事务部分。新组可独立交给官方 ZPAQ 读取，不依赖原目录。
- **普通包与密码包贯通**：密码组沿用原密码与密钥流，不必解密重建。未选旧内容保留；同名路径更新，无变化时另存副本且不增加空事务。
- **任务继续处理**：草稿恢复保留来源、添加路径、强度和保存位置，密码需重新填写；失败后调整并创建新任务，保留原失败记录。
- **清晰的进度与结果**：区分复制、更新、检查和发布阶段，完成后列明全部原生部分、快照变化与实际大小。单条仍在原位置展开，多选仍通过弹窗修改。
- **深目录与恢复显示修正**：修复 Windows 较深保存目录下暂存来源记录写入失败；草稿恢复后立即识别原生整组配置，保留缺失来源提示。

## 使用提示

例如保存名称为 `新备份.zpaq`，实际输出为 `新备份.part1.zpaq`、`新备份.part2.zpaq` 等。分享时请带上全部部分；这些是原生事务部分，无需设置数字切卷大小。

本版只更新已确认完整的日志式原组，不做原地追加、删除同步、改密、流式归档更新或损坏事务修复。保存位置需要容纳完整原组副本和本次新增数据。相似编号文件仍需明确确认，缺成员、来源变化或新组重名时会提示处理。

v1.6.0 的双栏结构、主题、快捷键、更新进度和托盘行为保持。下一阶段按路线推进中断尾部诊断与完整快照取回。
