# 密码保险箱全景与历史任务中心开发审计（2026-08-20）

> 历史设计说明：本文记录 2026-08-20 的初始方案。传统账户密码的强度、轮换、到期与风险统计已被后续审计否决并替换；当前实现与验收口径以 [DEVELOPMENT_AUDIT_2026-08-21_ARCHIVE_PASSWORD_ANALYTICS.md](DEVELOPMENT_AUDIT_2026-08-21_ARCHIVE_PASSWORD_ANALYTICS.md) 为准。

## 本阶段目标

1. 将密码保险箱统计从基础概览升级为可解释、可行动的数据全景。
2. 在左侧导航的“文件完整性”与“设置中心”之间增加“历史任务”。
3. 历史任务必须来自真实压缩/解压任务结果，清理当前队列或重启软件后仍可查看。
4. 不持久化压缩密码、解压密码、尝试中的密码或其他敏感字段。

## 现状审计

### 密码保险箱

现有条目已经提供 `created_at`、`updated_at`、`last_used`、`expires_at`、`use_count`、`usage_history`、`strength`、`category` 等真实字段；现有全景弹窗已具备强度分布、使用趋势、分类和生命周期基础视图。可以在不制造模拟数据的前提下继续增加：

- 健康度与风险分层：弱密码、长期未更新、即将到期、从未使用。
- 活跃热力与时间分布：基于逐日 `usage_history`，旧数据仅以 `last_used` 做一次兼容回退。
- 更新年龄分布：30 天内、31–90 天、91–180 天、180 天以上。
- 真实排行：最常使用、最近使用、长期未维护。
- 可行动洞察：只展示由现有条目触发的建议，不展示伪造预测。

### 任务历史

- `src/stores/task.ts` 当前只保存内存任务；“清除已结束”或应用退出后数据消失。
- 数据库已有 `compression_history`，但当前高频压缩/解压流程没有写入它；其外键依赖旧任务队列表，也无法覆盖现有前端直连命令的完整生命周期。
- 当前任务模型已有统一所需字段：类型、状态、起止时间、来源、目标、格式、处理字节、总字节、错误和实时日志。

因此本阶段新增独立的统一任务历史表和命令，并在任务进入 `completed`、`failed`、`cancelled` 时写入。相同任务 ID 使用更新写入，避免重复记录。

## 交互与视觉方案

### 密码保险箱数据全景

- 顶部：安全指数、活跃度、累计使用、待关注四项核心指标。
- 中部：长期画像、密码强度环图、使用趋势折线与范围切换。
- 深度区：风险矩阵、更新年龄分布、35 天活跃热力、分类分布。
- 洞察区：真实风险建议卡、常用密码排行、最近活跃/长期未维护列表。
- 单条密码入口继续保留生命周期视图，并与全局统计共享统一视觉语言。

### 历史任务中心

- 顶部总览：总任务、成功率、累计处理量、平均耗时。
- 趋势区：最近一段时间任务量与成功/失败分布。
- 工具区：关键词、任务类型、状态、时间范围筛选。
- 主列表：按完成时间倒序，清晰显示任务名称、类型、状态、目标、格式、处理量和耗时。
- 详情面板：来源文件、输出位置、起止时间、处理量、错误与执行日志。
- 空状态、加载状态、错误状态均提供明确反馈；窄窗口不产生横向滚动。

## 数据与隐私约束

- 历史记录不包含 `password`、`currentPassword`、`compressionOptions.password`。
- 日志写入前过滤疑似密码内容并限制条数/长度，防止数据库无限增长。
- 默认最多保留 500 条历史；用户可删除单条或清空全部历史。
- 任务队列清理与历史清理是两个独立动作，避免误删可追溯记录。

## 真实验收口径

| 场景 | 修改前实际结果 | 本阶段预期结果 |
| --- | --- | --- |
| 完成真实 ZIP 压缩 | 只在当前压缩中心存在，清除后消失 | 历史中心出现成功记录，包含真实目标、耗时和字节数 |
| 完成真实 ZIP 解压 | 只在当前解压中心存在，重启后消失 | 历史中心出现解压记录，应用重启后仍存在 |
| 任务失败或取消 | 只能从当前任务日志查看 | 历史中心保留状态、错误摘要与脱敏日志 |
| 查看保险箱全景 | 仅有基础趋势和分布 | 新增风险、年龄、热力、洞察和排行，数值与测试条目逐项可核对 |
| 缩小应用窗口 | 新页面尚不存在 | 导航可滚动，历史页和统计弹窗仅纵向滚动、无横向溢出 |

## 验收结果

- 修改前：真实压缩/解压任务只存在于 Pinia 内存；清除已结束任务或重启软件后无法查询。
- 修改后：真实 ZIP 压缩和解压各生成一条统一历史；重新启动独立 Release Tauri 会话后，两条任务 ID、状态和路径保持一致。
- 隐私审计：持久化 DTO 不包含任何密码字段；Rust 写入端再次过滤包含“password/密码”的日志并限制来源数、日志数和文本长度。
- 视觉审计：历史中心在默认窗口与产品允许的 760×520 最小窗口均无横向溢出，侧栏在高度不足时改为纵向滚动。
- 自动验证：`npm.cmd run test:unit`（203/203）、`npm.cmd run build`、`cargo check --bin long-compress-assistant`、`cargo test task_history --lib`、`npm.cmd run test:e2e:desktop:history`。
