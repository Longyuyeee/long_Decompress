# v1.6.21 候选 · 7Z 加密固实小文本

仅规划，尚未开发。接续 v1.6.20 的未加密固实图文，回到密码、分卷与容错主线，先让常见带密码的固实 7Z 说明和日志可以在原双栏直接阅读。

1. **先确认原件与共享加密范围**：从原版工具产生的 AES + LZMA/LZMA2 固实包起步，区分内容加密和文件名加密。完整文本 ≤1 MiB，共享压缩/解码量分别 ≤64 MiB；确认 AES 尾部填充、全部共享文件/块 CRC 和实际编码结束，不把可读前缀当作密码成功。未知组合或不能确定的依赖继续给提取指引。
2. **接通原密码操作**：手动密码优先且不回退，留空只对所选共享内容尝试保险箱，不先验证无关大文件，不记整包密码成功或增加密码使用次数。不套 ZIP 密码代码页。加密参数与密钥派生工作量在读取前确认范围，密码候选合计保持 30 秒目标并能取消；错误区分取消/超限/来源变化与密码或损坏的不确定性。
3. **接文件名加密和完整数字卷**：沿原入口读取所选准确路径，从有效成员归一化到完整卷组，来源前后绑定，缺失/混卷/换源需重新确认；关闭丢弃迟到结果。保留单条展开、多选弹窗、50/50 双栏，帮助收在问号中。
4. **按小文本独立交付**：用有效原件独立回解、所选文本哈希、错误密码/损坏和取消/来源以及宽窄 UI 做必要检查，更新 README、Release 和能力边界。加密固实图片、大文本前缀与新方法组合另拆，不重跑已过的旧矩阵、安装或真实盘满。

ALZ 方法 3、历史 Bzip2/原工具图片和 EGG 加密固实继续保留有效来源条件；不空发取材版本，不因某个加密组合通过就宣称全 7Z 加密固实支持。
