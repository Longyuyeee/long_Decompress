# Long解压 v1.5.9

本版改善加密 RAR 分卷失败后的最终原因，让“已找到密码，却仍解压失败”有具体可操作的解释。

- 缺卷时保留原生引擎实际请求的卷名和补回目录，覆盖已验证的 RAR4/5 加密头普通卷与 SFX；不根据文件名猜隐藏尾卷数量。
- 前段加密头或内容已用当前密码读通过，后续 CRC/数据失败时明确显示“RAR 后续数据异常”，提示核对同组原卷、传输完整性或后续条目密码，不再一概引导反复试同一个密码。
- 浏览、密码预检、完整性检查、只读诊断、提取、转换与最终历史保留一致原因；补回原卷或换回原组后创建新任务，旧失败记录继续保留。
- 96 项 Rust、152 项前端、39 个真实桌面记录场景通过，14 张常用/窄窗页面已查看；原始卷组、实际产物和转换 ZIP 按完整哈希核对，大文件暂停/恢复/取消回归通过。

前段密码通过不代表整包完整，也不能证明后续条目使用相同密码。目录可列出不等于全部内容可解压。本版不新增 RAR 创建或损坏修复，不执行输入 EXE；默认设置不变，Windows N 暂不保证支持。

详见[实施审计](RAR_FINAL_CAUSES_1.5.9.md)与[封板发布记录](RAR_FINAL_CAUSES_FREEZE_1.5.9.md)。
