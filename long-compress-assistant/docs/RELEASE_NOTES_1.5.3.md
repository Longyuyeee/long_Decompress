# Long解压 v1.5.3

本版新增 EGG 基础只读，重点补齐真实解压、密码、原生分卷和失败后的接续。

## 新增和改进

- 支持已验证的 EGG Store、Deflate、Bzip2、LZMA、传统 ZipCrypto，以及 UTF-8 文件名和原生 `.volN.egg` 卷组；可从任意成员导入，同一组不重复建任务。
- 贯通目录浏览、所选/整包提取、完整性检查和转换输入。转换为新 ZIP 后保留原包，载荷经独立工具回解核对。
- EGG 密码默认 UTF-8；来自旧版中文 ALZip 的密码可明确选 CP936。该选项只影响密码字节，文件名仍按原始格式标记读取。重试和历史重做保留编码，需重新填写密码。
- 缺首/中/末卷、混卷、结构损坏和未支持特性先说明原因，不把所有失败都当作密码问题。补回原卷后创建新任务，原失败记录保留。
- 不支持的特性在任务/历史中保留具体分类和处理指引；完整内容大小及 CRC 通过后才确认密码。解释放在问号内，常用/窄窗口页面已实际查看。

## 验证

76 项定向 Rust、140 项前端、十七组真实原包、26 个真实桌面场景和 26 张页面确认通过。包含真实子进程暂停、恢复和暂停中取消；取消不发布结果，且保留源包。

## 本版边界

EGG 为只读，不创建 EGG，不提供损坏修复或缺卷部分救援。AZO、固实、AES/LEA、全局/文件名加密仍留在后续版本；遇到这些组合会明确说明，不宣传完整 EGG 支持。原生卷需保持原名并补齐；算法、密码和编码互通以已验证组合为准。

最多 1000 原生卷、250000 条目、16 MiB 单元数据字段、512 GiB 声明展开总量；单个 LZMA 压缩输入上限 256 MiB。只有加密空文件时无法以实际内容完整确认密码，明确拒绝。CRC 不认证文件来源。Windows N 暂不保证支持。
