# Long解压 v1.1.7

本补丁版增强任务可追溯性、密码保险箱统计与原生压缩遥测，并以真实 Windows Release 桌面回环验证 ZIP 和 TAR 系列的进度、归档与解压结果。

## 新增与改进

- 左侧新增“历史任务”中心，持久保存压缩与解压的终态、来源、目标、格式、耗时、真实处理量、错误摘要和脱敏日志；支持趋势、筛选、详情、单条删除与清空。
- 密码保险箱数据全景新增 35 天活跃热力、密码更新年龄、可行动风险洞察、常用和最近活跃排行；所有统计继续只读取本机条目，不上传密码。
- 普通 ZIP 与 AES ZIP 在源文件读取过程中累计真实输入字节，并使用后端统一计算的速度与 ETA。
- TAR、TAR.GZ、TAR.BZ2、TAR.XZ、TAR.ZST 共用有界计数读取器，按真实源文件字节报告进度；目录和空载荷不会生成伪造吞吐。
- 速率计时从压缩任务开始建立，快速任务也能保留真实平均吞吐。

## 修复

- 修复 TAR 大文件读取中取消被 `Interrupted` 自动重试、无法及时退出的问题；取消现会回译为明确的任务取消并清理未发布输出。
- 保持 TAR 长路径、文件大小与元数据写入语义，并增加真实回环测试。
- 修复历史任务数据库已迁移到 schema v6 后，旧迁移回归仍硬编码期待 v5 的发布门禁失败；测试同时确认历史表实际创建。

## 真实验收

- 前端 35 个测试文件、203 项测试、类型检查和生产构建通过。
- Rust 库测试 240 项通过，1 项固定机性能基准按设计忽略；Clippy 以 warnings 视为错误通过。
- 64 MiB 普通/AES ZIP 门禁验证中间与最终真实字节、可见速度/ETA、错误密码拒绝、独立 7-Zip 完整性和解出文件 SHA-256。
- 64 MiB TAR 系列门禁逐一覆盖 TAR、TAR.GZ、TAR.BZ2、TAR.XZ、TAR.ZST；每种格式均验证中间字节、最终精确总量、速度/ETA、独立 7-Zip 测试、应用实际解压和 SHA-256 内容一致性。
- 历史任务桌面门禁以真实 ZIP 压缩与解压验证终态持久化、应用重启恢复和 760×520 最小窗口无横向溢出。

## 发布与兼容性

- 版本身份统一为 `1.1.7`，覆盖前端包、Tauri 应用、Rust 主程序、Shell Extension 与锁文件。
- 继续发布 Windows x64 NSIS 安装包和带更新签名的应用内更新资产。
- 项目仍没有商业 Windows 代码签名证书，因此继续跳过 Windows 11 第一层菜单身份 MSIX；经典“显示更多选项”中的 Long解压 子菜单保持可用。
