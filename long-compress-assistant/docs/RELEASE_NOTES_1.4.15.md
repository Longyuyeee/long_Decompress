# v1.4.15 · 归档流程性能与响应改善

发布草案：候选已封板，尚未正式发布。安装器与最终发布身份以[封板记录](ARCHIVE_PERFORMANCE_FREEZE_1.4.15.md)及本版 PR 为准。

- **ZIP 少做重复工作。** 解压只对本次选择的加密文件做密码预检，混合密码和实际内容校验保持，不再重复初始化所选明文文件的解码器。
- **TAR.LZ4 / TAR.BR 流式打包。** 不再先写一份完整 TAR 临时文件；减少这一步暂存空间和重复读写，保持压缩后完整校验、取消及错误返回。
- **RAR 预检查响应改善。** 扫描条目前后支持暂停与取消，同步扫描不再占用异步工作线程；仍保留真实文件统计和错误原因。
- **矮窗口能看全归档内容。** 调整归档浏览页滚动与列表高度，避免标题、密码和筛选栏把文件列表挤到不足一行。

本候选同时继承尚未单独发布的 v1.4.14 能力：ZIP 可选 Zstandard、ZIPX（XZ）创建，接通密码、数字分卷、转换，以及配置组/模板/预设/草稿/历史的方法保存。ZIP Zstandard 支持标准分卷；ZIPX 标准分卷暂不开放，接收方需支持对应压缩方法。

效果取决于内容和设备，不承诺整条解压固定百分比提速或内存下降。RAR 的单次 SDK/系统 I/O 调用不保证立即中断；TAR.LZIP 和格式兼容范围没有扩大。Windows N 暂不保证支持。
