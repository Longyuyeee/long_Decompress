# v1.6.36 · Deflate 大日志先看开头

非固实 Deflate 7Z 中的大文本，现在无需全部提取，就能在原双栏窗口先查看前 1 MiB。

- 普通包、内容加密、文件名加密和完整数字分卷贯通，可从非首卷进入，继续使用手动密码或密码保险箱。
- 沿用文本预览、滚动和常见编码识别，处理开头末尾截断的中文或 UTF-16 字符，不显示乱码替代符。
- 明确显示“部分内容 · 未校验整文件”，保留“提取后打开”入口，方便继续查看全文。
- 按实际读取控制开销，不因文件很大就分配全文缓冲；保留取消、缺卷、来源变化和错误密码的处理。

完整小文本、图片和小型固实图文继续沿用已有完整读取流程。固实大日志和 Deflate64 后续分阶段接续；单条展开、多选弹窗、等宽双栏、主题与工具入口保持，格式计数和依赖不变。
