# v1.6.51 · 7Z Delta 预处理

## 已完成

按[本版路线](ARCHIVE_ROADMAP_1.6.51.md)，在原 7Z 方法字段内收纳「高级预处理」，默认关闭。支持 LZMA2 / LZMA + Delta，距离 1～256；展开并选择 Delta 后才显示距离，清空可重新输入，单条空值按默认 1，多选空值保持各自原值。摘要可查看已启用的距离；切到 Bzip2/Deflate/PPMd/Copy 等不适用方法时保留设置、明确暂未应用，实际不会执行。Delta 是针对相关字节内容的可选尝试，不保证任何文件都缩小，不增加格式数或改变默认算法。

单条仍行内展开，编辑后自动独立，多选仍在原弹窗；左右等宽、主题/工具/快捷键保持。单条/全局、多选、转换、配置组/预设/便携模板、待处理草稿、历史和工作流携带方法、预处理和距离；模板复核可查看 Delta 状态。源包过滤链和目标配置独立，方法/距离变化使原分析失效。实际按 Delta + 所选方法抽样，不凭后缀宣称收益，也不会自动启用。

新增流式 Delta 编码器，以固定 8 KiB 缓冲区处理，字节历史跨写入和固实条目连续，属性写距离减一。链为编码 Delta → LZMA2/LZMA → 可选 AES；结束信号明确传递，写入/有效 flush/终止失败保持失败。首次真实创建发现 Delta 在通知下游结束后又 flush，LZMA2 拒绝已结束状态；现删除重复 flush，终止交由原下游编码器完成，不依赖 fallible Drop。旧 Delta 解码器对属性 255 先用 u8 加一导致溢出成 0，现先扩宽再加，正确读取距离 256。

接通内容/文件名密码、非固实/固实、完整数字分卷、取消/输出冲突与原进度和结果。图文完整读取沿原全部可用 CRC、尺寸和 AES 完成检查；大文本开头仅接纳严格的可选 AES → LZMA2/LZMA → Delta 线性解码链，验证单字节属性，不放宽其他过滤组合。固实前置与开头合计仍 ≤64 MiB，文本只保留前 1 MiB 并明确未校验整文件；图片和完整文本保持原预算。
