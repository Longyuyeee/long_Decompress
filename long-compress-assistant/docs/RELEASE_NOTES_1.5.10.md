# Long解压 v1.5.10

本版补强大 EGG 的 LZMA 读取：超过原先 256 MiB 压缩输入限制的包，不再因整块缓冲而直接拒绝。

- 压缩输入改为 64 KiB 缓冲、连续解密和流式解码，取消整块读入及第二份完整复制；普通、固实和传统密码原生四卷均用原 ALZip 大包验证。
- 固实包只取最后一个文件时仍核对共享流，未选文件不输出；正确密码、缺卷补回、完整检查与转换继续沿用同一读取链。
- 保留完整消耗、声明长度和 CRC 检查，读写故障保留原始 I/O 类型，损坏或未完成结果不会当作成功。
- 三组约 304 MiB 压缩输入、320 MiB 载荷的原包经 Bandizip 独立回解核对；本轮进程工作集峰值采样约 21 MiB，指定临时目录未使用压缩输入暂存。

仍是只读 EGG，不提供创建、全局/文件名加密或损坏修复，不外推所有密码与固实组合。LZMA 字典上限仍为 256 MiB，其余元数据、条目数量和声明展开总量边界保持；默认设置不变，Windows N 暂不保证支持。

详见[实施审计](EGG_LARGE_LZMA_1.5.10.md)与[封板发布记录](EGG_LARGE_LZMA_FREEZE_1.5.10.md)。
