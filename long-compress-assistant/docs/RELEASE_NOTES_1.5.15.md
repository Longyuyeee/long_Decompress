# Long解压 v1.5.15

发布草案：本版正在收口，正式发布状态以 GitHub Release 为准。

- 补强真实超过 4 GiB 文件的 ZIP64 流程，分别核对无密码、AES-256、传统密码，以及单包、数字卷、标准卷和流式数据描述符。浏览、所选文件、完整内容和转换使用同一套原生读取能力。
- 修复单独选中的空文件夹在压缩或转换后消失的问题。保留原有非空目录结构和文件重名处理，空目录也会跟随结果保存。
- ZIP64 终目录、扩展字段和卷内偏移确定损坏时，明确说明结构异常，避免让用户继续无效试密；实际文件读写错误仍保留原始类别。
- 保持单条行内展开、多选弹窗、左右等宽和窄窗口滚动。开发 README 将逐版本记录移到末尾，先介绍功能与使用方式。

ZIP64 是既有能力，本版不把它宣传为新格式，不代表全部工具、全部 ZIP64 布局都已覆盖。默认压缩方法不变；ALZ 方法 3、EGG 加密固实和 Windows N 的现有支持边界保持。

实施、实际范围和证据见 [本版记录](ZIP64_VOLUMES_1.5.15.md)。
