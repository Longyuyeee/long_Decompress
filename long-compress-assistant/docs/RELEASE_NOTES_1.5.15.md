# Long解压 v1.5.15

本版改善超大 ZIP 和密码分卷流程，保留熟悉的单条展开、多选弹窗和任务布局。

- **空文件夹不再丢失**：修复独立选中的空文件夹在压缩或转换后消失的问题，原有非空目录结构与重名处理保持。
- **损坏原因更清楚**：ZIP64 终目录、必要扩展和卷内偏移确定损坏时明确提示，不再引导无效试密；真实读写错误保留原类别。
- **救援提示更准确**：丢目录后的密码问题作为救援条件显示，不覆盖已确认的 ZIP64 结构损坏。只有有效密码才能尝试加密条目救援，原压缩包保留。
- **大文件流程贯通核对**：使用实际写入的超过 4 GiB 文件，覆盖普通/AES-256/传统密码、单包/数字卷/标准卷和真实流式描述符跨卷；完整内容独立回解、末尾所选/预览、改密码转换及空目录保留通过。

README 继续先介绍功能与使用方式，逐版本记录放在末尾。单条行内展开、多选弹窗、左右等宽和窄窗口滚动保持。

ZIP64 是已有能力，本版不表示新增格式或全部工具、全部布局都已覆盖。默认压缩方法不变；ALZ 方法 3、EGG 加密固实和 Windows N 的现有支持边界保持。
