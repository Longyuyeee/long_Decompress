# Long解压 v1.5.11

本版补齐原中文 ALZip 密码组合的真实兼容验证，改善密码编码不匹配后的接续提示。

- 固定验证 ZipCrypto、AES-128/256、LEA-128/256 的中文密码，覆盖 Deflate/LZMA、普通单包和原生分卷；文件名与密码编码分开处理。
- 正确中文密码未通过默认编码时，最终原因和重试页明确提醒核对 EGG 密码编码；用户可主动选择 CP936 创建新任务，默认 UTF-8 不变，不自动猜编码。
- 中卷浏览、只取末条、完整检查、缺卷补回、不可表示密码、转换和历史再次解压按真实内容核对；旧失败记录保留，历史保留编码但不保存密码。

二十组原厂包中十八组经独立 Bandizip 回解；两组 LEA/LZMA 原生卷由原 ALZip 回解核对已知载荷，本机 Bandizip 7.38 Beta 对它们报 CRC，不承诺该工具互通。当前原厂工具拒绝加密固实创建，本版不承诺加密固实，不将模拟包当原包。EGG 仍只读，不创建、不提供文件名/全局加密或损坏修复；Windows N 暂不保证支持。

详见[实施审计](EGG_PASSWORD_COMBINATIONS_1.5.11.md)和[封板发布记录](EGG_PASSWORD_COMBINATIONS_FREEZE_1.5.11.md)。
