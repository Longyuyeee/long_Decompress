# v1.6.15 · EGG 固实图片与连续阅读

小型 EGG 固实包中的图片，现在也能在原双栏直接查看，并沿用原阅读器连续翻页，无需先提取相册。

- **原位置看图**：双击、眼睛按钮、右键与 Ctrl+Enter 使用原单图弹层，继续阅读时保留翻页、缩放、坏图跳过、定位与当前页提取。
- **按需读取共享内容**：支持未加密 Deflate / LZMA 固实流，所选图片不超过 8 MiB，共享压缩载荷与解码总量分别不超过 64 MiB。仅保留当前所选图片，完整共享依赖的大小、CRC 和终止条件通过后显示，不落地整包。
- **阅读等待更明确**：显示共享内容读取状态，固实图片不自动预读下一张；保留有限缓存，缓存复用前核对来源。关闭/换页取消，来源变化刷新；后段损坏、缺卷、超限与加密固实给出提取或补卷指引。

沿现有 PNG/JPEG/GIF/WebP/BMP、单边 8192 和 1600 万像素范围，单次读取限时 30 秒。加密固实在保险箱候选前拒绝；原非固实图文、密码及固实小文本保持。新增图片、两种共享流和原生卷为明确标注的自有受控组合，不外推原工具全部历史互通。

保留单条展开、多选弹窗、50/50 双栏、工具中心和原主题。README 与后续大文本路线已同步；本版不增加格式数量，不开放 EGG 创建、修复或加密固实。详见[本版范围与记录](https://github.com/Longyuyeee/long_Decompress/blob/master/long-compress-assistant/docs/EGG_SOLID_IMAGE_PREVIEW_FREEZE_1.6.15.md)。
