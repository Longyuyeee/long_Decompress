# Long解压 v1.1.18

v1.1.18 调整压缩功能的信息架构：归档文件压缩留在“压缩中心”，图片、视频和 PDF 统一进入左侧新的“特殊压缩”页面。所有处理仍在本机完成。

## 主要更新

- 左侧新增一个“特殊压缩”入口，页面内提供图片压缩、视频压缩和 PDF 压缩三种选择。
- 压缩中心不再展示媒体/PDF模式，只处理 ZIP、7Z、RAR、TAR 等归档文件压缩。
- 保留已有图片、视频、PDF 的设置、真实执行、取消、结果预览/重开和历史能力。
- 归档与特殊压缩继续共用 `compression` 顶层任务、全局进度、SQLite 历史、容量预检、暂存验证和原子发布，不复制媒体旁路系统。
- 桌面测试改为按稳定导航标识进入页面，并等待懒加载路由的新页面根节点，避免把动画过渡中的旧 DOM 当成验收结果。

## 实际验证

- Node.js 24 下类型检查、47/47 单元测试文件、270/270 用例、生产构建和 17 文件媒体架构契约通过。
- 图片真实桌面门禁完成 JPG/PNG/WebP 3/3 编码、发布、历史、预览和选择器，并验证归档草稿与图片队列跨页面保持且互不串入。
- PDF 真实桌面门禁完成取消、批量失败隔离、签名/加密阻断、默认阅读器和完整重启历史。
- 视频门禁完成 10 分钟/114,842,332 B 前置矩阵、真实取消、两项软件编码、默认播放器和完整重启历史。
- 正式安装候选、资产回下载与 `v1.1.17 → v1.1.18` 公开应用内更新结果以发布审计为准。

## 支持边界

- 本版本只调整入口结构，不改变图片、视频、PDF 已公开的格式与安全边界。
- 视频仍只承诺带 Media Foundation 的非 N Windows x64；Windows N 暂不支持，硬件编码不在当前范围。
- 项目没有商业 Windows Authenticode 证书，公开构建不分发 Windows 11 第一层菜单 identity package；经典“显示更多选项”菜单继续提供。
- updater ZIP、签名和 `latest.json` 只由配置发布密钥的 GitHub Actions 生成。

完整证据见 [特殊压缩导航纠偏审计](SPECIAL_COMPRESSION_NAVIGATION_AUDIT.md)与 [v1.1.18 发布审计](RELEASE_AUDIT_1.1.18.md)。
