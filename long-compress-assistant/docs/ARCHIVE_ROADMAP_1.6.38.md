# v1.6.38 规划 · Deflate64 普通完整图文预览

仅规划，尚未开发。完成 Deflate 普通/密码、完整/开头与固实接续后，继续扩展 7Z 算法覆盖。本阶段限定普通非固实 Deflate64 的完整小图文，不将密码、共享块和大文本合成一个过大的版本。

1. **完整小文本**：接通有明确映射的唯一普通非固实 Deflate64 条目，完整文本 ≤1 MiB。确认方法/参数、声明大小、压缩范围，明确观察解码结束与精确消费，检查全部可用文件/块/打包 CRC；仅可解出正文不能称完整成功，不能用按文件长度截止的包装器掩盖缺失终止。
2. **图片和完整数字卷**：受支持图片 ≤8 MiB 接回原预览、连续阅读、翻页/缩放/跳过坏图、定位与仅提取当前页；完整数字分卷/非首卷沿原入口。保留实际输入、整体时间、取消和来源绑定，不读取无关大块或为大声明分配全文。
3. **保留用户下一步**：普通完整小图文先交付，密码包、固实、大文本及其他方法组合保持清晰的提取入口；沿原问号说明范围，不增加页面配置区。既有 Deflate、LZMA/LZMA2、PPMd 及完整/部分条件保持独立。
4. **一次收尾**：原版工具原件由另一版本独立回解，确认完整字节、编码/图像与数字卷、终止/损坏/精确范围和原宽窄窗口。只补新增方法和受影响检查，完成后同步 README、Release、能力表、证据和交接并发布。

之后再拆密码 Deflate64、固实完整图文与大文本开头阶段，继续格式/算法、密码/分卷与容错主线。ALZ 方法 3、历史 Bzip2/原工具图片及 EGG 加密固实仍需有效外部原件，不为空取材单独发版。保留单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键和问号收纳。
