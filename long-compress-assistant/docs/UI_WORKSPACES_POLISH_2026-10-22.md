# 三个资料模块的界面整理

本轮根据用户实际截图处理导航缺字与信息堆叠，范围为资料对比、工作流中心、归档资源库，以及它们共用的导航。应用版本暂沿用 v1.5.64，v1.5.65 的 ZPAQ 更新功能仍处于规划阶段。

## 界面层级

| 模块 | 主区域 | 收纳位置 |
| --- | --- | --- |
| 归档资源库 | 跨包搜索、文件结果、选择与取回 | 资料管理使用独立页签；索引维护、搜索筛选可展开；批量取回仍在弹窗配置 |
| 工作流中心 | 当前方案的步骤，或本次运行与结果 | 模板、保存方案放进选择弹窗；自动化使用独立页签；队列、定时规则和目录规则分别查看 |
| 资料对比 | 差异概况、搜索筛选、逐条结果 | 来源读取完成后收起；实际内容核对与支持范围按需展开；多选处理保留弹窗 |

统一使用现有主题的卡片、输入框、强调色与圆角，三个页面共用紧凑标题和页签样式，去掉占据顶部的英文大标题与重复说明。根据主内容区实际宽度调整布局，长路径换行，小窗口采用单列。步骤和条目仍然点击展开。

## 导航缺字原因

原矮窗口规则隐藏 `.sidebar-copy > div:last-child`，用来隐藏快捷键。但新增三个模块没有快捷键，标题成为最后一个子元素，因而被一起隐藏。现按 `.sidebar-shortcut` 精确隐藏快捷键。窄窗口也保留图标下方的名称，导航区域可滚动，底部项目可以到达。

## 功能接续

- 搜索与资料管理之间切换保留查询和跨包选择；查看异常来源时自动转到资料管理并展开相应来源。搜索命中的正常密码弹窗留在搜索页，便于从浏览器返回原查询和位置。
- 添加归档或确认扫描候选后进入资料管理，方便继续建立索引；不会自动开始建库。
- 资料管理页签随原视图偏好恢复，不保存密码。
- 工作流方案、复制、排序、步骤配置、运行密码、运行记录、纠正继续、目录及定时触发均沿用原处理函数。
- 对比内容核对进行时展开工具区，核对结束后保留可读结果；来源、逐项详情与多选处理均保留原行为。
- 压缩、解压中心及原左右等宽结构没有改动，后端算法与数据结构没有调整。
