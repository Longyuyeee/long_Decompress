# v1.5.61 ZIP Zstandard 跨流程兼容封板记录

2026-10-22。实施见[路线](ARCHIVE_ROADMAP_1.5.61.md)，用户说明见[Release](RELEASE_NOTES_1.5.61.md)。

## 实际范围（功能已封板，进入发布）

- ZIP 方法 93 纳入独立普通/AES/ZipCrypto ZIP 的编辑与资料对比。普通保留条目直接复制原压缩数据，密码条目按 Zstandard 重新编码；新增/替换与组包明确选择 Deflate/Store。原件、已有输出及原失败记录保留，沿原元数据能力，不冒称全部无损。
- 文件夹↔ZIP、ZIP↔ZIP 的实际内容 SHA-256、所选精确取回、补充取材、完整数字/标准卷、明确密码编码与原草稿/历史接续共用已有流程。分卷取材后另存独立 ZIP，不做原生分卷回写。
- 原 Zstandard 解码器已检查完整帧、串联帧、损坏和截断，继续保留原窗口边界与 CRC/AES 校验。只补外部字典/窗口/未完整结束的原因与处理提示，保留原错误种类和细节；空读取不消耗输入。不新增解码器、依赖或内存限制，不扩展旧编号 20 与独立 .zst，不提供外部字典导入或损坏修复。
- 原单条展开、多选弹窗、自然继承、压缩/解压左右等宽、窄窗滚动与 schema 18 保持。前端只更新支持提示，不为静态文案新增重复单测。

## 新增与受影响检查

类型/Vite、八处版本身份及 Shell DLL 已通过。首次原生编译因本地构建盘空间耗尽而未运行测试，按 Cargo 包/开发配置清理可再生成缓存后接续，源文件与开发记录保留。八项新增 Rust 全部通过：普通条目原压缩字节/方法/备注/时间/权限和新增内容；AES/ZipCrypto、明确 CP936、保留/去密码/换密码及空文件；错误/缺密码和已有输出保留；实际内容核对；数字卷取材的精确范围、来源变化/缺卷与编辑边界；CRC/大小/截断拒绝；独立真实原始块帧和串联帧的原字节另存及 7-Zip 回解；尾部不完整帧/垃圾、外部字典、超窗口和旧编号 20 的拒绝。

原生 `custom-protocol,desktop-e2e` 构建通过，桌面程序 SHA-256：`8d526069350f6b72595a16446653c02582119a8c50049ed71825193781dff4ae`。四条真实桌面组合、18 条宽窄布局及 6 张代表图实看完成，见[记录](evidence/zip-zstd-compatibility-1.5.61/desktop-progress.json)与[检查收据](evidence/zip-zstd-compatibility-1.5.61/checks.json)。上述为原生检查程序身份，不当作正式安装包身份。

1. 独立构造真实 Zstandard 原始块帧的普通 ZIP，单条右键改名/移动和添加，原清单另存；独立 7-Zip 回解，原方法保留，新增内容为 Deflate。
2. 沿既有创建器生成的 AES Zstandard ZIP，错密码失败不生成输出，纠正并设新 AES 密码后另存成功，保留原失败；独立 7-Zip 回解，方法仍为 Zstandard。
3. AES 数字卷从非首成员读取，缺密码核对未完成、补密码后实际内容相同；弹窗只取所选文件，正常退出/重启后恢复范围且密码为空，补密码取回及历史再取回均仅产所选文件。
4. ZipCrypto 标准卷非首成员进入 ZIP↔ZIP 实际对比；缺卷拒绝，补齐后所选引用组包，明确去密码并按 Deflate 生成独立 ZIP。7-Zip 独立回解只含所选内容，全部原包与卷组 SHA-256 保持。

首次桌面样本判断把外部工具输出的 `zstd` 错按大写匹配，修正脚本大小写判断后继续；当时尚未完成任何桌面组合。产品不受影响，全部四条与截图对应同一程序；不重复已完成组合。

既有 v1.4.14 Zstandard 创建、密码/卷型和转换依据复用，不重跑旧全格式/密码/算法/媒体矩阵、真实盘满或个人安装。只补本版新增与受影响路径、独立回解和必要宽窄显示。
