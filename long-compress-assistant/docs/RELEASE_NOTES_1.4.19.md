# Long解压 v1.4.19

本版聚焦旧 RAR4 的检查、恢复和继续解压，修复原包仍保持不变。

## 改进

- 支持将旧式 `名称1.rev` 与真正的 RAR4 `.rar/.r00` 数据卷关联，也保留现代 `.partN.rar/.partN.rev` 卷型；名称有歧义时明确提示整理卷组，不混入其他压缩包。
- 校验 RAR4 恢复卷内容及卷数，识别缺失末卷和恢复卷不足；无效或过短的恢复卷会说明原因并排除，不再拖累其他有效恢复卷。
- 修复 RAR4 加密文件名补卷时多次密码提示导致的退出，覆盖无密码、内容密码和文件名密码的恢复记录修复及补首/中/末卷。修复后的 RAR 保留原密码和加密方式。
- 为完整 RAR4 分包创建恢复卷，复用现有检查页面入口。修复结果可沿用原任务的输出设置重新入队，原失败记录保留，便于核对。

## 使用条件

普通 RAR 解压不需要安装 WinRAR；修复和创建恢复卷需要本机 Rar.exe，本版已用 7.23 实测。修复在副本中执行，完整内容校验通过才另存到新的 `.repaired` 目录；恢复数据不足、密码不对或校验失败不会保存一个冒充成功的结果。

实测范围为 RAR4 单包、旧式 `.rar/.r00` 和现代 `.partN.rar`，分别覆盖三类密码状态。至少需要一个保留的数据卷；只剩 REV、RAR 3.0 老恢复卷和未实测的扩展字母卷号不作完整恢复承诺。本版不新增 RAR4 创建选项，不随软件分发旧编码器，不要求用户安装旧版 WinRAR。

原有 ZIP/ZIPX、7Z、RAR5 和媒体功能保持；智能目录和 ZIP 并行仍默认关闭，不恢复快速打包。

验证与边界见 [实施审计](RAR4_RECOVERY_1.4.19.md)和[封板记录](RAR4_RECOVERY_FREEZE_1.4.19.md)。下一版按既定路线推进 v1.4.20 ZIP 部分抢救扩展。
