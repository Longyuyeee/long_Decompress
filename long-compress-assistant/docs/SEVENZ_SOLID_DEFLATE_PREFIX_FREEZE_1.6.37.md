# v1.6.37 · Deflate 固实大文本开头预览

## 完成范围

按[本版路线](ARCHIVE_ROADMAP_1.6.37.md)接通普通 Deflate 与有序 AES → Deflate 固实 7Z 的大文本开头，最多 1 MiB。新增独立 read_solid_deflate_entry_prefix，确认唯一所选普通条目、完整共享映射/顺序/条数/总量与 coder/流/绑定形状，检查前置内容与所选开头合计 ≤64 MiB。固定 32 KiB 输入/输出，前置内容随解码丢弃，跨过所选边界后只保留开头，不分配共享整块；总块声明可大于 64 MiB，仍须满足所选前置+开头与实际输入限制。发现已知提前结束、开头前损坏或无进展时报错。

AES 载荷复用显式 PreviewAes::new_prefix，声明对齐/方法顺序与参数保持；完整目录头及其他已创建的完整 AES 流仍须完成独立消费。普通/内容加密/文件名加密、原手动密码/保险箱、完整数字卷与非首卷贯通，手动错误不回退，不记整包密码成功。实际输入 ≤64 MiB、整体时间、读取中取消和来源绑定保持。部分结果不检查全部前置依赖 CRC、所选完整 CRC、未读尾部或整包密码，不称完整成功。

沿原双栏只读文本窗口、编码/滚动，明确“部分内容 · 未校验整文件”和“提取后打开”；只扩展原问号说明。完整 Deflate 小图文、非固实开头和其他 codec/default 方法保持独立，仅删除被替代的旧固实大文本不支持断言。保持单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键，无新增依赖、许可或格式计数变化。

## 本版必要检查

原版 7-Zip 26.02 生成普通、AES 内容、AES 文件名和完整数字卷四组固实 Deflate 原件，官方 26.04 独立逐文件回解 SHA-256，确认 Deflate、Solid +、Blocks 1。数据含首个/前置/所选/相邻/后续内容、空项、完整小文本、精确 1 MiB/刚超出、UTF-8/BOM/UTF-16LE/BE/GBK 五种边界与二进制。另有两份明确单块的 AES 原件：前置 63 MiB 与所选开头合计精确 64 MiB，及前置刚多 1 字节；两份总共享量均超过 64 MiB，独立完整回解后确认早期/边界可达与超限下一步。受控普通/加密尾部及开头损坏由独立工具确认完整性失败，变动在有效压缩数据内；原件、参数/哈希见 tests/fixtures/archives/sevenz-solid-deflate-prefix-1637/manifest.json，生成脚本保留已生成原件。

三项新增共享部分单元通过：普通/部分 AES 三字节短读、首个/后续/空前置与跨边界精确内容，仅保留所选字节，未读尾部和错误 CRC 不冒充完整成功，巨大声明仍只读有限块；精确前置预算/少 1 字节、映射/总量/条数/反向项/方法/压缩映射与已观察到的提前结束；跳过过程取消以及其他完整 AES 消费回执不可豁免。六组后端通过：四组原件与每个数字卷成员、首个/后续与编码/精确大小；保险箱/手动错误与统计，固实单文件压缩量不误算；映射/总量/AES 对齐/已知短输出与跳过过程取消；真实精确 64 MiB 与刚超出边界、较大共享总量的早期开头；受控尾部仅部分显示而完整共享读取仍失败、错误 CRC 不成为完整成功、二进制/坏开头与完整小文本；取消/来源/缺卷和新请求。因分发入口扩展，仅补一项非固实 Deflate 连续性，不重复旧方法、图片/完整矩阵、安装或真实盘满。

类型/Vite、八处版本身份与新 Shell DLL 通过。四组实际 Tauri 桌面通过：原文本窗口部分范围/滚动与提取全文入口；首个、普通、非首加密卷、五种编码边界及较大共享块的早期内容；损坏尾部与完整性错误、二进制/错误密码、真实精确 64 MiB/刚超限与完整小文本；取消/来源/缺卷和新请求。1100×650、760×520 两张截图已实看，正文/滚动、部分提示及提取全文入口可见，无横向溢出，底层双栏等宽。候选 SHA-256 `4c31a1e57c260ed76abeb378653a54c4f08d3e608c7000f8622a9753efa3786a`，见[证据](evidence/sevenz-solid-deflate-prefix-1.6.37/checks.json)。本地 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置未改；入口 node scripts/test-tauri-desktop.mjs --sevenz-solid-deflate-prefix-1637-only。
