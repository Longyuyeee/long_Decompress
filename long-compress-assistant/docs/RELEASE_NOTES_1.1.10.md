# Long解压 v1.1.10

v1.1.10 收口分卷归档导入与压缩/解压详情布局。重点是接受用户真实的拖入顺序，并确保长路径、长日志和资源预检在最小桌面窗口中仍然可用。

## 主要修复

- 支持直接拖入 `.zip.001`、数字分卷、`.z01/.zip` 等分卷成员，并自动归一到同组起始卷。
- 同时拖入同组多个分卷时只创建一个解压任务；缺少首卷、卷号断档或混合分卷组时给出可执行的诊断信息。
- 解压和压缩详情固定为有界左右双栏，左侧配置与右侧执行区等高，各自只进行纵向滚动。
- 超长当前文件路径限制为三行；实时日志独立滚动并强制换行，不再横向撑大任务详情。
- 解压资源预检卡不再被 Flex 收缩；压缩资源预检移入左侧配置区，避免挤占执行日志。

## 验证

- 前端 209 项单元/组件测试、类型检查和生产构建通过。
- Chromium 页面级门禁使用长路径、18 条长日志和完整资源预检数据，覆盖 760×520、920×620、1024×720 与 1440×900。
- 分卷归档解析与任务去重已纳入自动化回归；发布工作流继续执行 Rust、Shell Extension、浏览器 E2E、桌面构建和 NSIS 安装包门禁。

## Windows 集成边界

项目没有商业 Windows Authenticode 代码签名证书，因此公开安装包继续不分发 Windows 11 第一层菜单身份包。“显示更多选项”中的经典 Long解压 菜单保持支持；应用内更新包继续使用项目独立更新签名验证完整性。
