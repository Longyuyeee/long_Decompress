# Long解压 v1.5.31

WIM 现在可以真正压缩，而不只是存储文件。

- **新增 XPRESS 创建**：选择 WIM 后，可在“WIM 压缩方法”中切换“仅存储 · 去重”和“XPRESS · 快速压缩”。XPRESS 使用固定算法，无需调整强度；旧任务继续沿用存储方式。
- **批量与接续一致**：单条展开、多选弹窗、配置组/模板、预设、草稿和历史再次执行保留各自方法；只修改指定项目，其他格式、密码与分卷设置保持各自原值。
- **创建与转换接通**：文件、目录和密码压缩包均可生成 XPRESS WIM 数字分卷；从任意成员浏览、预览、检查、按需提取，也能转换为新的密码 ZIP。缺卷补齐后创建新任务，结果入口沿用原布局。
- **完成结果看得清**：修正 XPRESS 完成后源数据为0、压缩比停在“计算中”的问题，分卷阶段保留源数据总量；取消或失败不会发布未完成的新包。

保留单条点击展开、多选弹窗、自然继承、左右等宽和窄窗口滚动。WIM 不提供原生密码，数字分卷需集齐；本版是单镜像内容归档，不提供原生 SWM 创建、系统部署或完整 Windows 权限元数据备份。LZX 仍为下一版计划。
