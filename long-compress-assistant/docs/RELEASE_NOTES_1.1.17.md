# Long解压 v1.1.17

v1.1.17 首次正式交付本地 PDF 安全优化。PDF 工作区复用现有任务、日志、取消、历史、容量预检和原子发布链，分析、转换与验证均在本机完成，不上传文档。

## 主要更新

- 提供“无损整理”和“兼容图片优化”两种模式；兼容模式会显式标记可能有损，且两种模式都不承诺输出一定更小。
- 执行前读取真实页数、文件大小、加密、签名、表单和附件事实；签名文档默认只分析，加密文档在无法安全保持加密时拒绝生成降级副本。
- 固定 qpdf 12.4.0 五文件运行时及 Apache-2.0/NOTICE，启动与执行时校验精确身份、版本、加密后端、JSON v2 和图片优化能力。
- 密码只经标准输入传递，不进入命令行、日志或历史；每次执行前重新分析源文件和冻结配置，拒绝源变化与危险组合。
- 输出使用隔离暂存、结构/页数复核、容量预检、目标竞态检查和同目录原子发布；取消、失败或磁盘不足不会覆盖源文件或留下半成品。
- PDF 任务写入统一 `compression/pdf` 历史，记录后端确认的输入/输出字节、页数和处理模式；完成、失败和取消可跨完整应用重启恢复。
- 结果可交由 Windows 默认 PDF 阅读器打开，源文件默认保持不变。

## 实际验证

- 11 类可执行 PDF 分别通过两种模式，另有签名/加密稳定阻断，共 24 项产品矩阵差异为零。
- 覆盖文本、扫描、图文混合、中文字体、透明图片、表单、附件、300 页和 6000×4000 图片；Poppler 可见抽查无裁切、乱码或透明变化。
- 中途取消无输出且源哈希不变；三项批量中首项失败不阻断后续两项，输出可重开，四条终态历史跨完整重启保持一致。
- 精确 `1.1.17` 正式 NSIS 以生产 Tauri IPC 完成安装生命周期 54/54、PDF 工作区 23/23，并成功卸载及恢复公开 `v1.1.16`；正式四资产回下载和公开应用内更新 24/24 亦已通过。

## 支持边界

- PDF 优化不会编辑页面内容、填写表单、移除签名或破解密码；签名和加密边界以保守拒绝为准。
- 兼容图片优化可能改变图片编码，因此只在用户明确选择后执行；任何模式都可能因结构整理而变大，默认拒绝较大结果，用户可显式保留。
- 项目没有商业 Windows Authenticode 证书，公开构建不分发 Windows 11 第一层菜单 identity package；完整经典“显示更多选项”菜单继续提供。
- updater ZIP、签名和 `latest.json` 只由配置发布密钥的 GitHub Actions 生成；本版本公开资产回下载和 `v1.1.16 → v1.1.17` 应用内更新审计已完成。
