# Long解压 v1.4.6

这版让失败任务更容易继续处理，并扩展密码 ZIP 的完整文件救援，保留单条展开、多选弹窗的操作方式。

## 失败后直接处理

- 点击失败任务即可在展开区里调整来源、输出目录、密码和子目录设置，检查后加入待处理队列。原失败记录保留，成功任务不用重做。
- 缺卷时显示已知缺失文件，提供打开分卷目录的入口；补齐后重新检查，沿用原配置创建新任务。
- 损坏任务可直接进入“检查并尝试救援”。救回的新包能直接加入解压队列，保留原配置或本次修改的输出目录与子目录选项。
- 多项纠正继续使用弹窗；救援和重试均先加入队列，由用户核对后开始执行。

## 密码 ZIP 丢目录也能尝试救援

- 对中央目录丢失、但本地条目头能确定文件边界的 AES/ZipCrypto ZIP，可填写正确密码后尝试救回完整文件，支持单文件与完整数字分卷。
- 损坏文件会跳过，新包沿用填写的密码并使用 AES-256 / UTF-8；显示已找到、已恢复及未恢复说明。
- 目录重建结果明确标为部分恢复，原包总文件数可能无法确认，原压缩包保持不变。

## 详情显示与日志阅读

- 修复压缩、解压中心右侧无法滚动、实时日志被挤出视野的问题。
- 左右详情各占一半，配置按可用宽度排列，执行摘要更紧凑，日志保留阅读空间。
- 小窗口按空间换行或改为上下布局，修复放大文字时解压阶段与百分比重叠；保持原有单条展开交互。

## 使用范围

密码救援需要正确密码和完整来源。文件内容已经损坏时无法保证找回；本地尺寸未知的数据描述符、无法确定的边界、缺卷、标准磁盘 ZIP 分卷丢目录以及 RAR `.rev` 恢复不在本次新增范围内。目录可读的普通标准 ZIP 分卷救援沿用已有能力。

本文件作为发布正文准备；是否已可下载安装，以正式 Release 的实际附件为准。
