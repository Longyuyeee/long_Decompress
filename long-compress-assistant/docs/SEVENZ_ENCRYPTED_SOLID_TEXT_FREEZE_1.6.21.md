# v1.6.21 · 7Z 加密固实小文本

## 本版范围

按[路线](ARCHIVE_ROADMAP_1.6.21.md)接通原版 AES + LZMA/LZMA2 固实完整小文本、内容/文件名加密与完整数字卷。所选 ≤1 MiB，共享压缩/解码量分别 ≤64 MiB；实际元数据与载荷输入合计 ≤64 MiB，seek 不重置。每次目录/预览请求的密码候选合计 30 秒，手动不回退，留空只对文件头和所选共享内容尝试保险箱，不先验证无关大文件、不记整包密码成功或使用次数，不使用 ZIP 密码代码页。

元数据入口先登记取消并绑定来源，再沿同一有界读取尝试原密码；读取目录只读文件名数据，不把数据解压成功当作打开目录的条件，保留原已接入的有界内存文件头编码。固实条目压缩体积不单独计算，正确返回共享标记，原弹层/阅读器的等待提示随之生效。原双栏、单条展开、多选弹窗、50/50 布局、主题/工具/快捷键保持。

vendor 新增同步 thread-local RAII 预览范围，仅在元数据/预览期间生效，不跨 await，错误/异常后恢复原范围。解码头/字典 ≤64 MiB，AES cycles power ≤20、UTF-16LE 密码 ≤4096 字节；每 4096 轮密钥计算与共享输出块检查取消/截止。预览专用 AES-CBC 用精确对齐的短读兼容输入、声明明文长度、零填充和完整密文结束；所有创建的 AES 流须完整消费，编码头检查真实结束和块 CRC。所选共享块仍逐文件/块/可用压缩 CRC、大小和真实结束完整通过后才显示，只留所选字节，无临时整包。普通非预览解压/创建默认保持。原未加密图文和非固实密码图文沿同入口；加密固实图片和大文本不混入。

## 来源与验证

四组原版 7-Zip 26.02：内容加密 LZMA、LZMA2、文件名加密与文件名加密数字卷；官方 26.04 独立回解并逐文件 SHA-256 核对。包含中文/空格/方括号相邻名称、共享前后文件、空目录/空文件。另有受控密文损坏、原版 65 MiB 单共享块超限、65 MiB 无关 COPY 块损坏而所选共享块有效的范围样本，见 `tests/fixtures/archives/sevenz-encrypted-solid-text-1621/manifest.json`。Bzip2 受控编码头由自有原件的头信息编码，官方独立测试通过，明确不冒称新原工具来源；用于防止有界目录入口误拦原已接入的文件头编码。

五项新应用 Rust、五项预览 AES 核心与四项新前端已通过：原方法/任意卷入口/完整字节，密码/保险箱与手动不回退，无关损坏不读，损坏/超限/来源/取消；核心涵盖短读、填充、截断/多余密文、完整消费、范围恢复、密钥计算取消/超时与大小边界。vendor 测试驱动先补 AES feature 与只读切片类型后，五项实际执行通过；没有重跑旧核心矩阵。应用五项、界面四项均通过。随后保留原文件头编码兼容并重新生成最终候选，仅在最终桌面检查新增 Bzip2 文件头接续。

五组最终候选实际桌面全部通过：加密目录/原保险箱/完整文本与宽窄显示，原 LZMA/LZMA2、非首数字卷和受控 Bzip2 文件头，手动错误/损坏/超限，无关 65 MiB 损坏块跳过，来源变化/取消/新请求接续。1100×650 与 760×520 CSS 窗口两张截图已实际查看，文本可读、可滚动、关闭和完整内容提示可见，无横向溢出，原两栏等宽。候选 SHA-256 `21d270b395d24e9ccdbd4d129c28255f94bccdc70203060221e6d4b05c5c3bd7`，见[证据](evidence/sevenz-encrypted-solid-text-1.6.21/checks.json)。只做本版相关路径与必要兼容，不重复旧矩阵、安装或真实盘满。
