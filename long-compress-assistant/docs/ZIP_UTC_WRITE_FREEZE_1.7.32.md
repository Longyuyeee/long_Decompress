# v1.7.32 · ZIP / ZIPX UTC 修改时间写入封板

日期：2026-10-29。

## 实现和用户行为

原生 ZIP / ZIPX 共享创建入口现在对每个文件及明确目录读取自身修改时间，写入 Info-ZIP UT（0x5455）修改字段。本地头与中央目录各有且仅有一份 flags=1、长度为 5 的 UTC 整数秒；每条记录从基础选项独立生成，不累积前一条的扩展字段。保留原本地 DOS 日期、两秒精度与 1980–2107 年边界策略，密码校验使用的 DOS 字段不变。

确认写入范围为 Unix 秒 0..2147483647，即 1970-01-01 00:00:00 至 2038-01-19 03:14:07 UTC。保存可确认的奇数秒，亚秒向下截取为整数秒，原文件和目录的亚秒不修改。超出范围不猜测高位值的有符号含义，沿原 DOS 日期并在任务日志提示；处于范围内但早于 DOS 年份的条目保留 UTC，仅旧工具使用的兼容日期按边界写入，日志明确区分。

既有方法、ZIP / ZIPX、AES / ZipCrypto、标准/数字分卷与转换均复用该入口；ZIPX 空文件的 Store 回退仍保留时间与密码选项。转换先按来源恢复暂存时间，创建目标再写入 UTC；内容验证通过后发布，沿原结果与历史入口。界面、单条展开、多选弹窗和等宽双栏均未改变；格式数量、算法和密码能力没有增加。
