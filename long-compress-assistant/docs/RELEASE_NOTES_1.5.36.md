# Long解压 v1.5.36

已有 ZPAQ 备份可以继续添加和更新内容，并保留原备份与全部历史快照。

- **更新入口清楚**：压缩中心点击“更新 ZPAQ”，添加原包或任意数字卷，再选择本次文件/文件夹。界面直接显示“来源 → 归档内位置”，同路径更新，未选旧内容保留。
- **真正按内容比较**：同大小、同时间的内容改动也能识别。只追加新增或变化的数据；内容和时间都未变化时另存同内容副本，明确提示未新增快照。
- **密码与分卷接续**：支持普通和原生密码日志包，以及完整数字卷组。新包沿用原密码，可另存单包或重新分卷；原件不变。
- **进度与工作接续**：显示复制、比较更新、完整检查和切卷阶段，支持暂停、继续与停止。草稿、历史重做和失败纠正保留来源、路径映射与配置，密码重新填写。
- **结果继续使用**：新包可打开位置、查看产物、选择新旧快照、预览、检查、提取或继续转换。保留单条展开、多选弹窗、自然继承与现有等宽/窄窗布局。

本版采用“复制原包后另存更新包”，需要完整副本及新增数据的空间；重新分卷还需要切卷空间，不承诺固定节省量或速度。更新基于最新快照，不执行删除同步或同时改密；流式包、原生追加多部分和损坏事务不属于本版更新范围。
