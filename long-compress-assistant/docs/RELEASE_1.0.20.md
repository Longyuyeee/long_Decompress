# Long解压 1.0.20

本版本完成归档引擎职责拆分与 Windows 已安装环境验收，重点提升压缩、解压失败路径的可诊断性和输出安全。

## 归档引擎与可靠性

- ZIP、7Z、TAR/TAR.GZ/TAR.BZ2/TAR.XZ/TAR.ZST、单文件流和应用自有 AES 压缩写入迁入独立原生模块。
- 归档格式识别、压缩能力、别名归一化、参数校验与执行路由统一由单一规则维护。
- 7Z 解压补齐 CRC/密码错误分类、时间戳恢复、筛选、取消、损坏跳过、磁盘写满与暂存回滚回归。
- 压缩公共出口使用唯一临时输出；失败、目标竞争或磁盘写满不会覆盖既有文件，并会清理未发布输出。
- 桌面 E2E 使用独立应用身份、IPC、数据目录和 WebView2 用户目录，旧进程残留不再阻塞后续验收。

## 压缩中心

- 修复已完成的同源 ZIP 任务静默阻止后续 7Z 请求的问题。
- 对同一来源切换格式时，新任务会原位替换终态行；等待中或进行中的重复任务会显示明确提示。
- 单文件与磁吸分组之间统一去重，避免同一来源同时出现在多个待压缩任务中。

## Windows 右键菜单与签名

当前没有可信 Windows 商业代码签名证书，因此正式安装包继续跳过 Windows 11 新式顶层菜单身份包，并使用
“显示更多选项”中的传统右键菜单。新式菜单实现会保留到未来取得可信证书后启用。
