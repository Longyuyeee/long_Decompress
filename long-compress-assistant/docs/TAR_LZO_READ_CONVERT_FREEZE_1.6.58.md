# v1.6.58 · TAR.LZO 目录读取与转换

已完成功能封板。源码、合并、标签与正式附件身份在本版 PR 接续。

## 用户流程

`.tar.lzo` 直接沿原双栏浏览目录、搜索与图文/前缀预览，可按文件或目录取回、完整检查、整包提取及转成 ZIP/7Z。结果/历史沿原入口保留 TAR.LZO 来源，不再要求用户先手工取回 TAR。普通 `.lzo` 继续按单文件处理；只有实际 LZOP 容器且为明确组合后缀时才解读为 TAR，已知的其他文件头不会被后缀覆盖。

原单条展开、自然继承、多选弹窗、等宽双栏、主题和快捷键保持，无新页面或铺开的说明区。设置页只读支持列表和组合扩展导入同步；现有 `.lzo` 原生浏览/嵌套能力复用，没有伪造新的可创建格式或算法计数。

## 实现与边界

- 复用原生 LZOP framing、固定 lzokay 2.0.1 和现有 TAR/PAX/GNU sparse 逻辑，不新增依赖或外部运行引擎。TAR.LZO 只读识别与创建路由分开，压缩验证会拒绝该目标，不能默默写成其他格式。
- 目录提取复用所选条目/文件过滤、暂存事务、取消、同名冲突和结果发布。完整检查同时读取 TAR 逻辑内容与 LZOP 尾部，外层结束标记或校验损坏、内层坏头/截断/额外非零尾部不计健康归档。
- 空文件/目录、中文长路径、GNU 旧稀疏与 PAX 0.0/0.1/1.0 内容按原逻辑读取；这是内容归档，不承诺 Linux 权限/所有者、设备文件、链接或部署元数据还原。
- 文本保留前 1 MiB、扫描预算 64 MiB，图片沿用 8 MiB 上限；LZOP 为块校验可能先完整解码当前块，单块上限 64 MiB。预览不代替整包检查；没有数据校验的 LZOP 来源不能证明内容未变。
- 本版不创建 LZOP、不提供原生密码、数字切卷、原生多部分、多成员、非零过滤器或缺卷救援。完整数字切卷在 [v1.6.59](ARCHIVE_ROADMAP_1.6.59.md) 单独规划，ALZ/EGG 有效外部原件缺口仍保留。

## 原件与检查

[九份有效 TAR.LZO 原件](../tests/fixtures/archives/tar-lzo-read-1658/manifest.json)：Windows bsdtar 3.8.9 生成多目录/中文长路径/图文/空文件和空目录，复用有来源记录的 GNU tar 1.35 旧 GNU / PAX 0.0、0.1、1.0 及普通 PAX 原件，由官方 Windows lzop **1.03 / LZO 2.04** 包装。目录包的三种方法均包含真实压缩块；各件经官方 `-t`、完整回解和独立 TAR 逐文件 SHA256 核对，工具不随应用分发。四份有效 LZOP 包裹的无效 TAR 是派生拒绝样本，明确单列，不能算作健康外部原件。

独立 Windows libarchive 最初未明确 GNU 传统名称字符集，回解报错；指定 `hdrcharset=UTF-8` 后核对通过。生成脚本显式记录完整工具回解步骤，供重新生成原件；本轮未运行旧格式全矩阵。

补充发现并修正 TAR 库将坏头/短块报告为普通 IO 的分类问题：只匹配库实际产生的三种结构错误，保留原始细节，不改变权限/设备/空间原因；TAR.LZO 诊断和实际提取都保留明确损坏标记。只续跑该失败项、新的错误映射和受影响普通 LZOP，不重跑已通过三组。

前端两项、生产类型/Vite、桌面前端资产、版本身份与 Shell 通过。本版后端六项通过（复用初次三项通过，修正分类后只续跑失败项、新映射及受影响普通 LZOP 三项）。最终桌面四组业务、五张 1100×650 / 760×520 CSS 宽窄图及右键菜单已实看，双栏等宽，无横向溢出，预览/菜单在窗口内；图文预览、原目录右键取回、完整检查、ZIP/7Z 独立逐文件回解、tar.lzo 历史格式及失败修正后重试完成，7Z 目标含密码/隐藏名称与数字卷。脚本初始检索/目录复选框尝试失败后按原有路径搜索和右键入口接续，保留日志并复用通过截图/文本，未重建候选或重跑已通过业务。不重复安装、盘满或旧格式全矩阵，见[证据](evidence/tar-lzo-read-convert-1.6.58/README.md)。
