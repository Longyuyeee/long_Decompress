# v1.5.56 · 把所选资料组成新 ZIP

比较完两份资料后，可以直接组成下一份交付包，原文件夹和原压缩包继续保留。

## 从对比进入组包

- 在“处理所选”弹窗切换“生成新 ZIP”。选择完整左侧加右侧所选、完整右侧加左侧所选，或仅合并两侧所选。
- 文件夹、Store/Deflate ZIP、密码 ZIP 和完整数字/标准分卷都沿现有对比读取能力取材；勾选范围和具体来源版本随清单保留。
- 进入原 ZIP 编辑清单复核，同名文件明确选择替换、跳过或保留两份。查看最终目录，可改名、移动和明确移除；保存前可撤销。

## 另存、恢复与继续处理

- 新包沿原编辑另存引擎生成，可选 Deflate 或 Store，设置 AES-256、ZipCrypto 或明确不加密。来源含密码内容时默认提示设置新包密码；来源密码只用于读取。
- 草稿只保存引用和配置，不保存密码或解密文件。正常重启恢复后补密码；保存时临时取材，完成、失败或停止后清理临时内容。
- 来源变化或缺失时保留清单，可重新定位、重新读取并确认原选路径；不会自动加入新出现的文件。已有输出保留，换名后可继续另存。
- 沿用进度、日志、停止和结果入口，成功后可浏览新包，再沿原流程提取、加入资料库或再次对比。

## 熟悉的界面与范围

单条仍点击展开，多选仍在弹窗配置；宽窗等宽，窄窗纵向滚动。组包来源集中展示，完整路径可展开查看，原任务布局保持。

每次组包最多 10,000 项（含父目录），补充所选每侧最多 2,000 项并限制路径长度。输出为独立新 ZIP，全部组包内容按选定方法重新写入；请保存到来源文件夹之外。不覆盖原包、不做目录镜像同步，不承诺任意格式原地合并、分卷回写或无损保留全部原条目元数据。
