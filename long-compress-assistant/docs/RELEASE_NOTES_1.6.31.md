# v1.6.31 · PPMd 非固实大日志直接读开头

普通或带密码的非固实 PPMd 7Z，现在也能直接查看大日志前 1 MiB，再决定是否提取。

- 沿原双栏文本预览、编码识别和滚动，明确显示“部分内容 / 未校验整文件”，保留提取后打开入口。
- 接通 AES 内容/文件名加密、完整数字分卷、原手动密码和保险箱；手动密码错误时不会回退到其他密码。
- UTF-8、BOM、UTF-16 和 GBK 在开头截断处保持完整字符；精确 1 MiB 小文本仍走完整读取，超过时才显示部分内容。
- 不扫描无关大文件，不读取整份日志；保留输入、字典、时间、取消和来源范围。开头预览不能代替整文件校验，预览也不记为整包密码成功。

保持单条展开、多选弹窗、左右等宽、主题/工具/快捷键。固实 PPMd 大日志仍可先提取后打开，下一阶段已单独规划；既有完整小文本、图片和连续阅读保持，无新增依赖或格式计数变化。
