# Long解压 v1.1.9 发布收口审计

审计日期：2026-08-21

## 结论

本轮用户反馈已具备补丁版本收口条件。能够由当前无商业代码签名产品形态交付的问题均已修复并进入自动化或真实 Windows 桌面门禁；Windows 11 第一层右键菜单继续作为明确的外部签名限制，不伪装成已交付能力。

## 真实验证边界

- 已完成：真实 ZIP 压缩/解压与 SHA-256 闭环、真实加密 7Z 保险箱命中及趋势、历史任务重启恢复、资源预检布局与容量阻断、归档主流程、格式矩阵、经典右键安装态结构。
- 自动化继续要求：前端单测/类型/生产构建、Rust 全目标测试与 Clippy、Shell Extension COM 测试、浏览器 E2E、Windows Release 桌面及安装器门禁。
- 发布继续要求：版本身份完全一致，正式 Release 同时具备 NSIS 安装包、更新压缩包、更新签名和有效 `latest.json`。

## 非阻塞后续研究

- 在取得可信商业代码签名证书后重新启用并实机验证 Windows 11 第一层菜单身份包。
- 继续积累真实 HDD、网络盘与跨盘性能样本；证据不足前不改变默认并发。
- HFSX 非空真实载荷保持独立格式证据项，不把缺失样本写成已验证支持。
