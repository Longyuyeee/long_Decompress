# Long解压 1.0.18

本版本完成全格式真实载荷矩阵收口，并修复 Windows 11 无签名公开版右键菜单和覆盖安装残留问题。

## 主要更新

- 严格全格式桌面 E2E 覆盖 25 种可创建格式，以及虚拟磁盘、FAT16/NTFS、APFS、SquashFS、
  MSI/MSM/MSP、UEFI、RAR、LHA、RPM、DMG/HFS 等真实载荷。
- Windows 11 只有在签名身份包成功部署时才启用顶层原生菜单；无证书公开版可靠降级到
  “显示更多选项”中的传统菜单。
- 覆盖安装先注销旧身份包并删除历史 Shell DLL/MSIX，安装目录只保留当前版本扩展。
- 新增 `test:installed-release`，在备份和自动恢复保护下验证真实覆盖安装、数据保持、
  右键注册、卸载清理和上一正式版恢复。
- 新增统一版本身份门禁，检查 8 个版本来源、版本化 Shell DLL 和 Git 标签。

## 已安装环境验收

在 Windows 11 22H2 x64 上以公开 v1.0.17 安装为基线完成 41 项检查：

- 覆盖安装到 v1.0.18，保留自定义安装目录。
- 主程序、卸载器和 Shell DLL 版本一致，且安装目录不存在旧 DLL。
- 密码保险箱与应用设置目录在覆盖安装、卸载和恢复后逐目录 SHA-256 指纹一致。
- 无签名候选版注册传统菜单，不留下不可用的 Windows 11 原生入口。
- 静默卸载清理主程序、卸载器、产品注册表和安装器声明的全部右键菜单键。
- 验收结束后恢复公开 v1.0.17、原菜单模式和用户数据；没有残留测试进程或临时备份。

严格桌面 E2E 也已在隔离测试构建中通过，覆盖所有可创建格式、密码归档、虚拟磁盘、
FAT16/NTFS/APFS/SquashFS、MSI/MSM/MSP、UEFI、固定上游只读样本，以及取消、退出、
更新阻断、托盘和第二实例恢复。测试完成后已重新生成不含 E2E 桥的生产安装包。

## 发布与应用内更新

公开 v1.0.17 固定读取 GitHub 的最新正式 Release，因此不能在不影响现有用户的前提下
发现草稿或预发布候选版。v1.0.18 正式资产生成后，必须立即从保留的 v1.0.17 环境执行
真实应用内更新，并将结果回填发布验收记录。

发布后真实验证确认：版本发现、签名校验、下载、解包、原目录覆盖安装和用户数据保持均成功，
但被动安装完成后应用没有自动重启。该项未标记为通过，验收记录见
[Issue #24](https://github.com/Longyuyeee/long_Decompress/issues/24)，补丁修复见
[Issue #25](https://github.com/Longyuyeee/long_Decompress/issues/25) 与 v1.0.19。

## 已知限制

- 当前没有可信 Windows 代码签名证书，安装器可能触发 SmartScreen；Windows 11 顶层菜单
  暂不随公开版交付。
- HFSX 尚缺可再分发的非空真实载荷样本，因此不宣称完整支持。
- 创建 RAR 仍依赖本机安装 WinRAR；RAR 解压由随包引擎支持。
