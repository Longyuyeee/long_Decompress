# Long解压 v1.5.19

导入校验清单后，可以直接看清哪一卷缺失、哪一个文件内容不符，以及什么原因导致无法读取。

- **逐文件查看结果**：SFV、MD5、SHA256 清单分别显示匹配、缺失、内容不符、无法读取；有误的清单行也会保留提示。点击单条行内展开完整路径、原因及左右等宽的预期/实际摘要。
- **复制待补文件列表**：集中复制缺失和内容不符的文件名，便于补回或重新下载。占用、权限等读取问题单独说明，避免把它们当作需要重新下载的文件。
- **按需复查**：可复查问题项、所选项或单独一项，其他文件保留注明的上次结果；需要时再主动全部检查。清单内容发生变化会作废旧结果，未检查的项目不会算作匹配。
- **接续原来的处理流程**：从归档或分卷条目进入现有诊断，返回时保留校验列表。补齐来源后进入解压中心，通过原失败纠正弹窗建立新任务，确认后再开始，旧失败记录保留。
- **显示清晰、操作保持熟悉**：紧凑列表、状态筛选、长路径换行、单条展开和窄窗纵向滚动；解压/压缩中心的多选弹窗与左右等宽布局保持。

摘要匹配表示文件与所提供的清单一致，不等同于归档所有内容已通过检查，也不判断清单来源可信性。导入支持 UTF-8（含 BOM）清单；未复查项目显示上次观察结果，文件变化后请主动复查。本版不新增归档格式或修改密码、分卷默认选项。
