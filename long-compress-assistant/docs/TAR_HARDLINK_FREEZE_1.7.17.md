# v1.7.17 · 已确认硬链接内容取回封板记录

日期：2026-10-28。

## 已完成

TAR.LZO 部分取回支持指向前面已确认内容文件的零正文硬链接。目标按归档原始路径匹配，区分大小写，独立于 Windows 输出名称修复；重复/歧义名称保持不确定状态，目录、未确认目标、自引用及链接链条停止。局部 PAX linkpath 覆盖普通头目标名，全局 linkpath、非硬链接附带目标、稀疏/链接元数据混用及带正文/冲突大小保持停止规则。

条目继承已确认目标的数据位置、逻辑大小、SHA 和可选稀疏图，自己的头及局部元数据完整后才提交。目标 ID、原始目标与物理位置绑定来源 revision。长普通头/PAX 自身名称、目录选择、时间提示和连续前缀边界沿原流程，不扫描缺口或从输出目录寻找目标。

实际复制阶段按来源位置排序并顺序解码；同一来源的第一个所选输出从原包写出，其他所选条目从本次新建且已校验的文件读取。目标无需被选中，不添加缓存文件，不为每个链接重新解码原包，也不同时为整组选项持有输出句柄。稀疏副本按已确认范围提供实际数据，复用原稀疏写入和逻辑 SHA，保留空洞。每个结果是独立新文件，取消/失败仍清理暂存，目录时间在所有内容完成后处理。

列表只加简短链接内容来源，完整目标位于原折叠结果；原逻辑大小、文件数、部分历史、单条展开、多选弹窗与等宽双栏保留。旧记录的新字段可选，没有新增页面或常驻配置区。正常完整读取/解压的链接处理未扩展。

格式依据：[GNU tar 文件头说明](https://www.gnu.org/software/tar/manual/tar.html#Standard)、[POSIX pax](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/pax.html)。GNU 原件确认零正文硬链接和局部 linkpath；本版只承诺已验证的子集。

## 原件与检查

`tests/fixtures/archives/tar-hardlink-1717/` 是项目自编文件和真实 Linux 硬链接的 GNU tar 1.35 PAX 生产者原件，由官方固定 SHA lzop 完整回解核对。14 个条目含 5 个硬链接，覆盖普通、空、长名称和稀疏目标。源目录与 GNU 完整提取目录的内容、名称及 inode 关系一致；Python 独立读取目标内容，不冒称它能通过 GNU 稀疏占位名称完成链接查找。异常边界另行构造，不作为额外生产者兼容依据。

- 新原生 7 项最终通过：完整原件清单/目标绑定；坏尾、CRC 与缺结束标记的整组选取和仅选链接；未确认/目录/链条/外部/歧义目标及冲突记录；目标数据与填充、链接元数据/头边界；Windows 名称相同且逻辑内容不变时的目标身份重查；独立文件修改与暂存副本读取期间取消；缺中卷与补卷重查。
- 首轮 6 项通过；坏校验样本最初改到了尾部填充块，文件内容仍完整，测试预期有误。改为在 GNU TAR 内容外显式构造 CRC 错误块，只续跑该失败项。实际坏尾/缺结束标记仍使用生产者 LZOP 原件，CRC 构造的来源单独写入 native.json。
- 相关旧原生 3 项通过：PAX 0.0 的实际稀疏输出/子集，目录时间与选择范围，未知元数据停止及复制取消。其余未受影响矩阵复用。
- 前端 4 项通过：新链接大小/来源和仅选链接历史，旧稀疏大小及折叠结果兼容。新增测试文件后的类型检查通过；Vite、Shell DLL 与 8 个版本来源身份通过。
- 独立 Python 核对 4 份实际输出、39 个文件的逻辑 SHA、精确树、明确时间、稀疏属性/分配量；所有文件 st_nlink 为 1。独立修改一份副本不改变另一副本或目标；原件 SHA 未变。仅选链接加空目录的结果为 5 个文件、1 个明确目录，25,565,830 逻辑字节，未输出原目标或缓存文件。
- 后台真实 Vue/CSS 回放原生报告和结果，3 组通过：来源提示和筛选，宽窄折叠结果，所选子集及原部分历史。1100×700、760×520 无横向溢出，底部按钮可见，长来源可滚动查看；六张截图逐张检查。IPC 明确为回放，没有接管桌面。
