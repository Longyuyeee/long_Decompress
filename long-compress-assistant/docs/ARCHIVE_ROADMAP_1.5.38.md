# 下一版：v1.5.38 ZIP LZMA 创建与流程接续

2026-10-21，接续v1.5.37。本文件只规划，尚未开发运行时；回到更多归档方法、密码与分卷的既定方向。

## 用户要解决的问题

在常用ZIP入口选择更多压缩方法，仍能使用熟悉的密码、数字/标准分卷和转换流程；接收方兼容范围清楚，失败时知道原因。默认兼容ZIP不变。

## 推进顺序

1. **先做真实写入与互通探测。** 当前src-tauri/vendor/zip/src/write.rs的CompressionMethod::Lzma分支明确返回“LZMA isn't supported for compression”；仅启用lzma feature只提供读取，不能当作创建已完成。核对读取分支需要的封装、属性与结束语义，研究现有lzma-rust2编码API的适配，先生成最小普通ZIP并由独立实现完整回解。普通文件、空文件/目录、中文路径与同名层级均需真实依据，再开放方法选项。若编码依据尚未成立，明确记录研究进度，不发布失效选项或借用ZIPX XZ冒充。
2. **接创建和资源展示。** 在原ZIP方法选择中增加LZMA，保持旧Deflate/Zstandard/BZip2/PPMd与ZIPX固定XZ；按真实编码器确定等级、字典预算和采样，不承诺固定压缩率或速度。沿小批次进度、暂停停止与原暂存提交机制。
3. **接密码、分卷和转换。** 普通、AES-256、ZipCrypto，单包、数字卷和标准ZIP卷分别核对新方法。密码原包输入/新方法输出及反向内容转换，任意卷浏览、预览、检查、所选/整包提取、缺卷补齐后新任务和统一结果接通；不把密码编码差异误报成损坏。
4. **配置接续与收尾。** 配置组/模板、预设、草稿、历史重做和多选保存方法，保持自然继承、单条展开、多选弹窗、50/50及窄窗滚动。仅补新增写入方法受影响链，旧格式/密码矩阵和真实盘满不重跑；更新README、中文Release、范围与发布收据。

## 继续保留

WIM固实/ESD、SWM创建与部署、ALZ方法3、EGG加密固实、ZPAQ原生追加多部分和损坏事务抢救继续分别研究。ZPAQ跨归档比较、删除同步、原地覆盖和定时备份不计入本版范围。已有快照对比与变化提取按v1.5.37范围保持，不提前扩展。
