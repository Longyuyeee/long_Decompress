# Long解压 v1.1.11 发布审计

审计日期：2026-08-21

## 结论

v1.1.10 的大型分卷加密误判路径已被移除。当前实现能够区分加密探测、密码尝试和真实解压三个阶段，并以真实样本证明普通分卷不会进入耗时字典流程。完成全部发布门禁和安装资产核验后可发布 v1.1.11。

## 需求对齐

| 范围 | 实际结果 | 判定 |
| --- | --- | --- |
| 未加密分卷误判 | 仅依据结构化元数据或明确密码错误判定加密 | 已完成 |
| 探测超时 | 明确失败，不回退为加密 | 已完成 |
| 解压过程不可感知 | 两位小数进度、当前文件、产出量、预计总量和速度 | 已完成 |
| 密码流程不可感知 | 展示来源、序号、结果和耗时，不记录明文 | 已完成 |
| 解压后删除源文件 | 完整成功后移动到 Windows 系统回收站，分卷整组处理 | 已完成 |
| 压缩体积反馈 | 展示真实输出大小、压缩比和空间变化 | 已完成 |
| 用户真实五卷样本 | 未进入密码流程并产生真实解压进度 | 已完成 |

## 发布门禁

- npm、Tauri、主程序、Shell 扩展、Cargo 锁文件和版本化 DLL 必须统一为 `1.1.11`。
- 前端单元测试、类型检查、生产构建、Rust 测试、真实五卷分卷回归和 Release 安装包构建已通过。
- GitHub Release 必须包含 NSIS 安装包、updater ZIP、签名文件和可解析的 `latest.json`。
- 无商业代码签名时继续禁止将 Windows 11 第一层菜单身份包纳入公开安装资产。
