# v1.7.36 · 流式 Zstandard ZIP 丢目录部分取回

使用 Zstandard 压缩的 ZIP 丢失目录后，现在可以沿原救援入口，取回连续前缀中能够完整确认的文件，并另存新 ZIP。

- 新增未加密 method 93、未知本地尺寸的单帧恢复：确认实际帧结束、消费量、展开量和 CRC 后匹配描述符。
- 接通空文件、明确目录、普通/ZIP64 描述符、混合方法及完整数字切片，保留已确认修改时间。
- 坏帧、矛盾尺寸、缺卷或未知边界处停止；结果继续标为部分取回，原总清单未知。沿用新包校验、结果/历史和重试入口，现有界面及交互保持。

本版不增加格式数量，不扩展外部字典、多帧、可跳过帧、历史 method 20 或密码流未知边界的恢复。见[范围](ARCHIVE_ROADMAP_1.7.36.md)、[实现与检查](ZIP_ZSTD_RESCUE_FREEZE_1.7.36.md)。下一阶段 [v1.7.37 多帧 Zstandard ZIP 部分取回](ARCHIVE_ROADMAP_1.7.37.md)仅规划。
