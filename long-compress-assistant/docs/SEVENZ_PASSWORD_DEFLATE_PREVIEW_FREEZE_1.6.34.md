# v1.6.34 · 密码非固实 Deflate 图文预览

## 完成范围

按[路线](ARCHIVE_ROADMAP_1.6.34.md)接通有序 AES → Deflate 非固实 7Z 的完整文本 ≤1 MiB 和受支持图片 ≤8 MiB。扩展已有 read_deflate_entry 的单/双 coder 形状、绑定顺序、唯一普通条目/大小和映射检查，复用完整 PreviewAes::new 的消费回执；固定 32 KiB 块按声明压缩明文读取，仍需观察 raw Deflate StreamEnd、精确压缩明文消费/输出大小，随后完成原始/解密 EOF 的 AES 长度/零填充/密文消费，再检查可用文件、块及打包 CRC。Deflate 正文和结束不能豁免 AES 或完整目录头等其他已登记流的消费条件。

内容/文件名加密、原手动密码/保险箱和完整数字卷贯通。手动错误不回退，预览不记整包密码成功；元数据/载荷实际输入合计 ≤64 MiB，单块密文/明文也分别 ≤64 MiB，AES 参数、候选整体 30 秒、块内取消和来源前后绑定保持，不扫描无关大块。普通 Deflate 沿相同完整读取路径，原 LZMA/LZMA2/PPMd 与默认提取不变。

文本编码/滚动、图片预览、连续阅读的翻页/缩放/跳过坏图/定位/仅当前页提取沿原界面，仅扩展原问号说明。单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键保持。固实、大日志和 Deflate64/其他组合仍给提取下一步，无新增依赖、许可或格式计数变化。

类型/Vite、八处身份和新 Shell DLL 通过。五组实际 Tauri 桌面通过：保险箱文件名加密文本的完整/滚动；原小窗口图片像素；原阅读器翻页/缩放/跳坏图/定位/仅当前页提取；内容加密/非首卷文本及两种图片命令、损坏/错误手动密码与未开放范围；取消/来源/缺卷/新请求与跳过无关大块。1100×650 文本、760×520 图片与阅读器三张截图已实看，正文/图像、关闭和操作可见，无横向溢出，底层双栏等宽。候选 SHA-256 `74360d28f8ae9354800ca1357d2f76ed3391c7849118a941b6ca692c9e46064e`，见[证据](evidence/sevenz-password-deflate-preview-1.6.34/checks.json)。桌面 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置不改；入口 node scripts/test-tauri-desktop.mjs --sevenz-password-deflate-preview-1634-only。
