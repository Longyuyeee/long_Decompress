# v1.5.46 密码 ZIP 与编辑草稿封板

[实施计划](ARCHIVE_ROADMAP_1.5.46.md) · [中文 Release](RELEASE_NOTES_1.5.46.md) · [记录](evidence/zip-password-drafts-1.5.46/)。候选、正常合入、标签与正式附件收据在本版 PR 接续。

## 已交付

独立 Store/Deflate ZIP 的 AES-128/192/256、ZipCrypto 与未加密条目可在原工作区添加、替换、删除、改名、批量移动并另存。浏览器原包密码/编码带入，复用现有保险箱；原包和新包密码分开设置。支持保留原方案及公开条目、设置新 AES-256/ZipCrypto，或明确无密码；只改密码也能保存。混合原方案新增条目采用 AES-256，替换采用原条目方案。输出编码明确可选、默认 UTF-8，保留模式不承诺保持旧密码字节编码。

加密内容重新写入，保留内容、原压缩方法、有效时间、备注和空目录，体积可变。保存前读取核对完整原包与外部引用，保存后核对实际内容 CRC；AES AE2 无头部 CRC 时也按真实内容处理。原包、已有目标和旧失败保留，临时写入/停止清理沿既有路径；新包继续浏览、预览、提取、转换与再次编辑，并带入本次新包凭据。

编辑清单、来源引用、操作顺序、输出配置自动写入本地专用文件，不保存密码。全局紧凑草稿入口接多份编辑；恢复先列出缺失/变化来源，可重新定位或明确接受当前原包/外部文件。目录定位只映射原引用，不加入后来出现文件。恢复不自动执行，不覆盖本次编辑；失败/停止保留清单，正常关闭和托盘退出等待草稿写入。已完成任务的残留草稿查询原历史收据、返回原结果；失败来源链接原历史，新任务另存而不改旧记录。

原单条展开、多选弹窗、自然继承、压缩/解压 50/50 与滚动保持。密码、来源修复沿原复核弹窗，宽窗等宽，窄窗顺排；长路径换行、问题清单限量并可滚动，底部操作保持可访问。

## 范围与依据

仅独立 Store/Deflate ZIP；同包须一份用户凭据能够完整读取。分卷、自解压、特殊路径/链接、嵌套临时来源及其他方法编辑后置，仍保留原浏览/提取。空 ZIP 没有可加密文件，须明确选择无密码。草稿只保存引用，不缓存原包或外部内容；停止保留编辑方案，不从编码中间字节续写。

70 项不同前端（14 新增、11 原编辑、16 原整理、29 受影响浏览器）、18 项相关 Rust（6 新密码/引用、1 草稿持久化、11 原编辑/历史）通过。类型/Vite、Shell 与八处版本身份、原生桌面构建通过。四条实际桌面流程、三份独立完整回解结果与原包/已有目标保留通过；实际正常关闭与同资料目录重启、成功收据防重放有记录。八处宽窄共 16 条布局无横向溢出，八图实看。夹具/自动化修正及接续见记录，所有桌面流程采用同一最终程序身份。

只补新增/受影响项，未重复无关旧格式/密码矩阵、真实盘满或媒体/个人安装。此处本地 E2E 程序不冒充正式包，候选和正式附件由流水线生成。
