# v1.8.1 双栏往返与任务配置

本版改善三段日常操作。原定的 [ZIPX（XZ）多流与合法填充](ARCHIVE_ROADMAP_1.8.2.md) 顺延至 v1.8.2。

## 在双栏发起压缩，回到原位置或定位产物

从左栏或右栏发起「压缩到另一栏」时，记住该次任务的两个目录、滚动位置和文件选择。沿现有快速打包流程进入压缩中心，仍使用另一栏的目录。任务控制区提供「返回发起位置」。返回后正在运行的任务继续执行。

成功结果同时提供「在双栏定位结果」和「打开结果位置」。前者回到双栏并在目标栏选中实际生成的文件或首卷，后者仍在 Windows 中定位。结果移动或目录不可用时提示具体原因，并尽量还原可读取的一栏。一次任务的返回位置仅保留在当前会话，随任务清理。

## 多选配置先展示用途和输出目录

点「兼容分享」或「体积优先」便把方案参数填入当前弹窗。加密和分卷方案先填写所需参数，再预览修改。切换方案会重新计算这次要应用的参数，避免上个方案预填的密码或分卷混入。底部「应用到 N 项」是唯一提交动作，取消即丢弃预览。

常用区显示压缩格式和输出目录。把压缩等级、算法、密码编码及恢复选项集中到默认折叠的高级设置。选择具体格式时只显示适用项，保留各自格式时按选中任务显示可用项。已有密码或分卷能力发生变化时，在原修改摘要里说明。

## 复用历史任务的结果菜单

完成结果优先显示打开位置。历史任务继续将再次压缩放在打开位置旁边。复制路径、资料库与校验清单用按钮旁的「⋯」浮层，空间不足时向上展开，按 Esc 或点击外部关闭。打开菜单时保持任务行高度，单条详情仍可展开，批量配置继续用弹窗。

## 验收

- 两个方向分别发起压缩，核对源目录、选择、目标目录和真实产物。覆盖运行中返回、重名产物路径、路径失效和普通任务。
- 核对用途直接填入、参数提交前后、取消、切换加密或分卷方案后的配置，以及高级设置按格式显示。
- 在宽窗和窄窗检查菜单锚点、键盘关闭、任务行位置和弹窗主要操作的可见性。版本身份同步后检查生产构建。

相关前端用例 171 项和 Chromium 界面端到端用例 5 项通过。双栏用例通过模拟 Tauri 返回验证两种发起方向、运行中返回、原选择与滚动位置，以及重名后的产物定位。760 像素窗口核对弹窗底部按钮和结果浮层。前端生产构建、Windows 右键扩展构建和 v1.8.1 版本身份检查通过。
