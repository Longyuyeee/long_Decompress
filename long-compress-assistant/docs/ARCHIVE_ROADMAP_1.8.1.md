# v1.8.1 规划 · ZIPX（XZ）多流与合法填充兼容

接续 v1.8.0，承接原 v1.7.39 / v1.7.42 尚未开发的范围。仅规划，尚未开始实现。

当前 v1.7.38 的未知边界恢复支持单 XZ 流；正常 ZIPX 读取器也会拒绝流后的填充或后续流。本期先补正常读取，再接恢复，不增加格式数量。

前期两份派生控制已由独立 7-Zip 无警告读回，见[可行性记录](evidence/zip-xz-rescue-1.7.38/next-xz-probe.json)。本软件兼容仍待实现，这些控制不代表全部 ZIPX 算法。

1. 接通正常 ZIPX 浏览、校验和提取中的普通 XZ 多流及合法零填充，继续验证精确展开量、各流块校验/索引/尾部、ZIP CRC 和压缩范围，拒绝任意垃圾或不完整后流。
2. 接通丢目录、未知尺寸恢复：按真实流结束及累计消费量、展开量、CRC 确认描述符；合法零填充按四字节对齐连续确认，限制流数、填充量和内存，不扫描正文标记。
3. 覆盖两个非空流、空流组合、填充前后、普通/ZIP64、有无签名、完整数字切片和来源日期；后流损坏不输出半个文件，只另存此前完整成员，原清单仍未知。
4. 沿原暂存、新包验证、结果/历史、失败重试和取消入口，保留单条展开、多选弹窗及等宽双栏。只检查新增及受影响流程。

完成标准：声明范围内正常读取与恢复均可独立读回准确内容及日期，坏后流和非零垃圾仍被拒绝，原件不变。特殊滤镜/字典、密码未知边界、Zstandard 可跳过帧和外部字典、历史 method 20、跨缺口扫描、恢复记录、ALZ/EGG 及更宽日期继续分期。
