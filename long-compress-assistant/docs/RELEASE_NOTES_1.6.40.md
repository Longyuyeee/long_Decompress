# v1.6.40 · 固实 Deflate64 图文直接看

普通固实 Deflate64 7Z 中的小文本和图片，现在也能在原双栏浏览器里直接预览，无需先把整个共享块提取出来。

- 完整文本最多 1 MiB、图片最多 8 MiB，支持完整数字分卷和从非首卷进入。
- 流式处理所选文件前后的共享内容，只保留所选文件；共享压缩数据与解码总量分别最多 64 MiB。
- 继续使用原文本窗口、编码识别/滚动、图片预览、连续阅读、翻页/缩放、跳过坏图、定位和仅提取当前页。
- 检查共享块真正结束、精确压缩消费及全部可用文件/块 CRC，损坏的前后内容不会被当作完整预览成功；取消、来源变化和缺卷处理保持。

密码固实包、大文件和超限共享块继续提供提取后打开的下一步；非固实普通/密码预览保持。单条展开、多选弹窗、等宽双栏、主题/工具/快捷键不变，说明收进原问号。下一阶段接通密码固实 Deflate64 完整图文。
