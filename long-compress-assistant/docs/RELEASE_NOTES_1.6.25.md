# v1.6.25 · 固实 7Z 大日志直接读开头

未加密的固实 7Z 大日志，现在也能在原双栏里直接阅读前 1 MiB，无需先提取整个共享块。

- 支持 LZMA / LZMA2，准确定位首个或后续所选文件，流式跳过必要的前置内容，只保留所选日志开头。
- 复用原文本预览窗口，保留滚动、编码识别、已读/声明大小和“提取后打开”；明确标注“部分内容 · 未校验整文件”，不会把前置内容或未读尾部当作已校验。
- 前置内容与显示开头合计限 64 MiB；实际输入、字典/解码头范围及候选整体 30 秒保持。共享总大小超过 64 MiB 时，仍可部分阅读范围内靠前的大文本；超出前置范围时提示先提取。
- 完整数字分卷、编码边界、关闭取消、来源变化、缺卷和迟到结果丢弃沿原流程。过早结束、二进制及方法不支持时保留下一步指引。
- 完整小文本和图片仍检查共享内容的完整大小、CRC 和编码结束；非固实密码大文本保持原支持，加密固实大文本随后单独推进。

保持单条展开、多选弹窗、左右等宽和现有主题/工具/快捷键，格式数量不变。下一阶段已规划加密固实大文本开头，尚未开发。
