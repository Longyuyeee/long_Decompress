## 当前状态

功能基线为主线 `6f9e85b`（PR #150）：批量转换、待处理草稿恢复及收口修正已合入。公开版本仍为 1.4.1。当前仅准备了 [设置页静态示意图](../design/settings-style/README.md)，正式产品源码尚未修改；设计和审计记录随本轮提交同步，未升版或发布新安装包。

示意图基于当前设置组件渲染，通过仅在设计脚本中注入 CSS 调整样式。标题栏、侧栏、品牌、现有主题色与全部配置选项沿用实际组件；没有可点击原型。图片中的原生状态使用模拟数据，不能作为本机菜单、引擎或发布状态的证明。

## 仅调整设置页

- 标题大小、页面间距、卡片圆角、细描边及阴影参考现有文件完整性等页面，保持当前软件风格。
- 分组标题与说明集中放在卡片顶部，配置名称和操作区对齐，减少原左侧大面积留白。
- 外观设置保留六种主题、十三种强调色、中英文和界面缩放；整理选择器和选中效果。
- 无障碍设置去掉重复的内层卡片，用轻分隔线组织字体、对比度、色觉、动画和焦点选项；说明文字更易读。
- 性能、行为、更新和格式说明沿用同一套标题、间距和控件外观，减少双列布局空白；小窗口继续纵向滚动。

不新增搜索、分类导航、保存步骤、确认流程或设置模式；保持当前设置的实时生效、范围、默认值和原生调用。其他页面、共享侧栏、主题系统、任务与结果操作不纳入此次修改。

## 接续顺序

1. 用户先查看静态图并反馈，只调整设置页设计方向。
2. 按选定示意样式实现 `SettingsView.vue` 与其无障碍设置组件的外观；所有已有选项与交互保留。
3. 查看设置页常用/窄窗口和深浅主题；只检查受到修改影响的控件，不重复安装或归档格式全矩阵。
4. 设置样式收口后接续 v1.4.2 发布工程，更新版本、README 与 Release 说明。旧的逐页重构计划不作为发布前置。
