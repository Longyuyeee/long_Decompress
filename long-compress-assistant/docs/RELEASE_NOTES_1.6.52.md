# v1.6.52 · 可选 7Z x86 BCJ 预处理

- 在原 7Z 折叠的「高级预处理」中加入 x86 BCJ，与无、Delta 互斥，适用于 LZMA2 / LZMA；默认关闭，不按文件扩展名自动开启，也不保证所有程序都更小。
- BCJ 面向可执行代码中的相对跳转指令。选择 BCJ 时收起 Delta 距离，切回 Delta 保留原值；不适用的方法保留设置并显示暂未应用。无需距离输入时选择框占满整行，保留单条展开、多选弹窗和等宽布局。
- 接通内容/文件名密码、固实/非固实、数字分卷、配置组/预设/模板、草稿、历史、工作流和转换，体积分析使用实际 BCJ 编码链。
- 完整图文、大文本开头与提取可读取新输出及独立工具的 x86 BCJ 原件；大文本只读必要前置与开头，额外前看字节计入原预算，保留部分内容提示。修正 x86 转换的位置回绕，并正确读取空属性或四字节起始位置。

验证和本版范围见[开发记录](SEVENZ_X86_BCJ_CREATE_FREEZE_1.6.52.md)。正式附件由标签流水线自动生成，实际状态在本版 PR 接续。
