# v1.6.4 · 从受损 ZPAQ 中取回已校验文件

诊断找到仍可完整读取的文件后，现在可以直接选择取回，减少在损坏备份里来回尝试。

- **选择清楚**：在文件影响详情里勾选已检查通过的文件，再在二级弹窗确认快照、位置和未取回范围；支持选中本页或全部已通过内容，较大清单可分批处理。
- **沿用原队列**：普通/密码、单包/已确认原生多部分沿同一入口。密码按所选快照和文件验证，其他坏块不会阻断正确凭据；执行时重新核对诊断身份并完整校验所选文件。
- **结果有范围**：每次另存独立目录，保留相对路径和原包，并生成独立说明，分清已取回、受影响、未检查和未选择。任务、批量结果、全局结果与历史可按需查看说明，不把部分结果称为整包修复。
- **继续处理方便**：草稿、重启补密码、失败新任务和历史重做保留精确文件范围与快照；密码不保存，恢复后不会自动开始。

仅支持完整日志目录可读取、已诊断且所选文件检查通过的 ZPAQ。来源或检查结果变化时需要重新诊断；不提供未知密码恢复、不完整目录推断或未检查文件的强行取回。单条展开、多选弹窗与原双栏交互保留。

四种受控损坏来源复用 v1.6.3 冻结副本；取回文件与原始 SHA-256 对照，不把受控注入当作自然损坏样本。详见 [封板范围](https://github.com/Longyuyeee/long_Decompress/blob/v1.6.4/long-compress-assistant/docs/ZPAQ_RETRIEVAL_FREEZE_1.6.4.md)。后续按 [v1.6.5 路线](https://github.com/Longyuyeee/long_Decompress/blob/v1.6.4/long-compress-assistant/docs/ARCHIVE_ROADMAP_1.6.5.md) 回到 ALZ 方法 3 与格式兼容主线。
