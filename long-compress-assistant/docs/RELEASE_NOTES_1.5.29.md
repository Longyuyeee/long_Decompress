# Long解压 v1.5.29

直接打开原生 SWM 分卷，按需取出镜像里的文件。

- **任意一卷进入**：支持同目录的 `install.swm`、`install2.swm` 等原生 WIM 分卷，自动回到首卷读取整组资源，无需先拼接完整临时镜像。读取 Copy、XPRESS、LZX 非固实分卷。
- **浏览后再提取**：多镜像按编号目录展示，支持文本/图片预览、完整检查，以及所选文件或整组内容提取；中文路径、空文件与空目录保留。
- **缺卷原因看得清**：缺少首卷、中间卷或尾卷时显示实际文件名，混入其他镜像、卷号改错或文件截断分别提示。补齐后沿原有重试弹窗创建新待执行任务，保留旧失败记录。
- **内容转换接通**：可将 SWM 内容转换为密码 ZIP 或其他已有目标格式，继续使用统一结果入口；原生 SWM 也出现在文件选择器及资源管理器归档菜单名单中。
- **开发态菜单隔离**：桌面测试程序停用系统右键菜单的启动刷新及注册/移除操作，避免测试路径影响已安装程序的菜单。

请保留原始分卷名称并放在同一目录。不新增 SWM 创建、WIM 原生密码、缺卷部分救援或系统部署；内容提取与转换不等于恢复完整 Windows 部署元数据。现有 `.wim.001` 数字切卷与原生 SWM 分别识别。保留单条展开、多选弹窗、自然继承、左右等宽与小窗口滚动。
