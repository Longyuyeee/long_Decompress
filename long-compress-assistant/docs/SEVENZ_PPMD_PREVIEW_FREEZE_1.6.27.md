# v1.6.27 · PPMd 非固实完整图文预览

## 完成范围

按[路线](ARCHIVE_ROADMAP_1.6.27.md)接通原版未加密、非固实 PPMd7/PPMdH 7Z 的准确唯一普通文件：完整文本 ≤1 MiB，既有受支持图片 ≤8 MiB，尺寸 ≤8192、像素 ≤1600 万保持。单编码器/单打包流/单子流、所选映射、文件与块大小、完整压缩覆盖及可用文件/块/打包流 CRC 均需通过。PPMd 阶数 2～64、字典 2048 字节～64 MiB 在分配前确认；实际元数据/载荷合计 ≤64 MiB、候选整体 30 秒、检查点取消与来源绑定保持。不整包临时解压、不扫描无关大文件，不改变格式数量。

7z 的 PPMd 通常按声明大小结束，没有 EOS。新增独立 read_ppmd_entry：按精确大小分段读取后检查 range coder Code == 0，再核对压缩消费和 CRC；不继续解一个多余符号，也不以物理 EOF 或正文可读代替完整结束。依据[官方 7-Zip 解码器](https://github.com/ip7z/7zip/blob/main/CPP/7zip/Compress/PpmdDecoder.cpp)的大小定义 FinishStream 语义。sevenz-rust 仅依赖本地 ppmd-rust 1.4.0 的加法 finish_7z 接口；原 Read、模型/编码器、ZIP 原 registry 依赖和既有 LZMA/LZMA2 完整/部分与 AES 路径保持。原始文件 SHA、许可、补丁及测试输入来源已记入 vendor 目录和资源 SOURCE.md。

复用原双栏文本/图片弹层、问号帮助及图片阅读器，完整数字卷有效成员、当前页翻阅/缩放/坏图跳过/定位/准确提取贯通。单条展开、多选弹窗、左右等宽、主题/快捷键和工具收纳保持。密码、固实或大文本 PPMd 明确给提取下一步，不冒称已支持；下一版仅规划密码非固实 PPMd。

## 必要检查

原版 7-Zip 26.02 生成阶数 6/8 MiB、阶数 12/16 MiB 及完整数字分卷三组非固实样本，官方 26.04 独立逐文件回解 SHA-256。包含准确带方括号与相邻名称、空项、UTF-8/UTF-16/GBK、精确 1 MiB/超限文本、五种图片与假图片。独立负例含固实/密码、精确 8 MiB/超限及超尺寸图片。bad-flush 为受控尾部修改：独立工具测试和回解均失败，但吐出的正文 SHA 与原件相同；新路径仍按结束失败拒绝显示完整。65 MiB 无关 COPY 块独立测试后再受控损坏，所选 PPMd 图文仍准确可读。来源、参数与各项 hash 见 tests/fixtures/archives/sevenz-ppmd-preview-1627/manifest.json。

两项 PPMd 结束单元、六项后端通过；覆盖原阶数/每个卷成员、五种图片、完整输出边界、CRC/大小/映射/方法参数/额外压缩字节/缺少 CRC、读取中取消、结束损坏、密码/固实下一步、二进制、来源/缺卷/新请求和无关大块跳过。最初 vendor 单元编译因 registry 未带上游 include_str 测试输入而未执行，补入明确来源的 Apache 许可文本仅作 roundtrip 输入后两项通过；无应用行为修补或隐藏失败。前端未新增交互逻辑，只扩展原问号口径，类型/Vite 构建通过，没有重复旧组件用例和未受影响的算法/密码/分卷、安装及真实盘满矩阵。

五组实际 Tauri 桌面通过：准确完整正文/滚动；PNG 实际像素；原阅读器翻页/缩放/坏图跳过/定位和只提取当前页；阶数 12/非首卷及两个图片命令、损坏结束/超限/密码/固实指引；取消/来源/缺卷/新内容与大块跳过。首次脚本在提取已按原交互关闭阅读器后继续找下一页而超时，改为重新进入后操作，仅接续未通过的组；未改软件交互。1100×650 正文、760×520 图片和阅读器三张截图已实看，弹层/关闭可见，无横向溢出，底层双栏等宽。候选 SHA-256 `5b0707bd1887ad0b9f29312c07a9c710a6408a0be8e3aca28c20792730658d05`，见[证据](evidence/sevenz-ppmd-preview-1.6.27/checks.json)。桌面使用 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置不改；入口 node scripts/test-tauri-desktop.mjs --sevenz-ppmd-preview-1627-only。八处版本身份和新 Shell DLL 同步。
