# v1.5.26 功能封板

2026-10-20，接续正式 v1.5.25。ZPAQ 数字分卷按范围完成，进入候选、普通受保护合入与正式发布。本文件是合入前快照，最后构建和四资产身份在本版 PR/Release 接续。

## 交付与边界

普通和原生密码 ZPAQ 支持指定大小数字切卷，任意成员归组、浏览、完整检查、所选/整包、密码 ZIP 双向转换、补卷新任务和整组结果生成清单接通。读取直接跨成员，不先合成完整临时包；极小盐跨卷、不等长成员和超过 1000 卷有定向依据。

日志式当前文件增加有界文本/图片预览，大小未知、读取/共享块/内存超限时提示先解压。选中内容可经独立临时目录解码后清理，说明统一为“只读 · 不改原包”。数字切片不是原生追加多部分；没有新增密码算法、增量更新、历史恢复、损坏修复或缺卷部分救援。

单条展开、多选弹窗、自然继承、等宽和窄窗滚动保持。能力加载时不再清掉继承分卷，多选名单补入 ZPAQ，各条密码/卷大小保留；取消读取按钮不再被固定图标宽度挤成竖排。

## 定向检查和实际程序

- 七项不同 Rust：四类独立原件的切片、超过 1000 卷的密码流、错密/缺卷/截断原因、公共试密/诊断逻辑格式、文本/未知大小预览、创建与 PNG 精确内容/请求能力、外层 I/O 允许原生密码分卷。六项首轮通过，最后一项在桌面发现旧拦截后单独新增通过，没有重跑原六项。
- 六项不同前端：格式能力、继承设置与打开不隐式编辑、原多选弹窗 ZPAQ、转换保留各条密码/卷大小、压缩多选保留密码/分卷并清除不适用项。最初异步能力和名单遗漏失败分别修正，只补受影响项。
- 四条真实公共原生链：独立普通/密码日志原件从第二成员提取，以及产品普通/密码数字卷创建、中卷提取与原版工具完整回解；独立文件 SHA256、空文件和空目录一致。
- 六条实际 UI 链：行内密码分卷创建及结果带入三卷/独立摘要；双条多选弹窗；中卷密码浏览与文本/图片预览；真实撤卷失败、补回后新待执行任务与旧记录不变；密码 ZPAQ 卷到新密码 ZIP；后者再转另一密码 ZPAQ 分卷。转换由独立解码器完整回读。
