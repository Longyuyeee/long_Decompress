# v1.7.26 · TAR 目录结构与目录时间封板

日期：2026-10-28。

## 实现与用户行为

把已发布的 ZIP 根名称分配器提取为共用保留结构入口，TAR 主写入器与直接 TAR 编码流统一使用。显式写入所选非空/空根目录；不同位置的同名根预留独立名称并一致映射整个子树，同一规范来源去重。ZIP 行为保持，扁平创建和 7Z 沿原收集器。

在既有 TAR 预检中收集实际目录头的日期（含现有逻辑读取器识别的局部 PAX 日期），完整扫描、流尾与来源版本确认仍沿原路径。仅保留本次选择范围内、暂存整理后仍存在的目录；最终内容提交并清理暂存后由深到浅恢复。复用现有冲突等待对象中的目录时间清单，继续提交无需重解压或重读源包。只选文件、扁平、关闭时间，以及隐含或大小写重复歧义目录均不编造父目录日期。

普通 TAR.LZO 解压预检接入上述元数据收集；单独限定在解压路由，保持其已有浏览、完整检查、文件名编码与已确认链接路径。已确认 TAR.LZO 链接转换使用原暂存/验证/发布入口。修复 TAR 仅选中文件并扁平解压时原路径过早变平、随后被暂存选择过滤掉的问题，现保持原包身份到最终整理。

覆盖 TAR、TAR.GZ、TAR.BZ2、TAR.XZ、TAR.ZST、TAR.LZMA、TAR.LZ、TAR.LZ4、TAR.BR、TAR.LZO；完整数字 TAR / TAR.LZO 分卷与到 TAR / TAR.GZ 的转换有本版实际证据。不新增格式数量、权限/所有者、链接语义或 TAR 原生密码能力。UI、单条展开、多选弹窗、等宽双栏、结果与历史入口保持。

## 检查与证据

- 新原生 6 项通过：根名称及旧布局保持；10 种 TAR 写入与数字分卷的完整验证/最终目录树和日期；所选目录、文件、筛选、扁平、时间关闭；冲突等待后不重读原件；PAX 亚秒、隐含/歧义目录、取消与损坏流尾；已确认 TAR.LZO 链接转换到 TAR / TAR.GZ。解压路由限定调整后，只重跑受影响的包装/分卷专项通过，其余通过项保留。
- 相关旧 2 项通过：已知签名不被 TAR 后缀覆盖、TAR 结构损坏与存储错误区分。
- 14 份实际归档、178 个编码条目独立核对：Python TAR 逻辑读取器，标准库 Gzip/Bzip2/XZ/LZMA、外部 7-Zip Zstandard、缓存的 LZ4/Brotli、GNU lzip 1.24.1 与官方 LZOP 1.03 解码。逐条比较精确目录树、文件 SHA 与编码日期，再独立核对项目原生最终输出的目录/文件日期和内容；完整数字卷先拼回，转换另与固定 SHA 的 GNU TAR 原件逻辑条目比较，原件保持。五种选择/时间策略另核对。
- 原生专项调用生产创建、预检、所选解压、暂存整理、事务提交及提交后日期恢复函数，没有使用桌面 IPC 或控制电脑。Shell DLL、八处版本身份与差异空白通过；未改 UI，未重跑前端、无关格式与旧版矩阵。正式 Windows/前端构建、安装器和签名更新附件由本版 CI/Release 接续。
