# Long解压 v1.5.25

打包完成后，整组分卷可以直接生成校验清单，分享前后少做几次文件选择。

- **从结果开始**：完成任务、历史、转换结果和任务监控增加“生成校验清单”。带入全部实际产物，不只选择首卷；打开入口后由你点击开始计算。
- **同名文件也能分清**：清单保留相对于保存目录的子目录路径。不同文件夹里的同名文件不会合成一个文件名；计算列表可展开查看完整路径与摘要。
- **中断后继续**：沿用真实进度、停止和继续未完成项。导出只使用完整成功的摘要，显示已写入和未写入数量；导出不重新读取已完成文件。
- **保存后直接核对**：点击“核对这份清单”进入原核对页面。保存位置不包含全部来源时，会提示改选共同上级目录；失败不会截断已有清单。旧历史缺卷时直接显示需要补齐的卷名。

保留单条展开、多选弹窗、自然配置继承、左右等宽与小窗口滚动。分享时请保留清单与文件的相对目录结构；跨磁盘来源可先集中到同一磁盘，或分开生成清单。解压结果目录不自动递归计算，本版没有新增归档格式或密码算法。
