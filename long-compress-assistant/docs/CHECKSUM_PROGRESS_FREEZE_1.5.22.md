# v1.5.22 封板记录

2026-10-20，功能完成，进入受保护合入与正式发布。

## 交付

计算摘要与校验清单使用 64 KiB 真实分块读取回调，显示当前文件、真实字节及已处理项数；约 80 ms 节流进度，逐项发送结果，避免每项重复传整份长清单。请求按窗口和操作 ID 隔离，监听先于命令启动，结束清理监听；停止及离开工作区可取消活动读取。

停止保留完成观察，当前文件标为 interrupted、不产生部分摘要，其余未读取项保持 not_checked/pending。继续只检查未完成项，当前中断文件从头读取。选择性复查先清除本次所选行旧观察，避免中断时旧匹配回流；清单摘要变化时不套用旧行号读取新清单，全部旧观察作废。读取中长度/修改时间变化会提示重查。

进度卡采用既有色彩和紧凑布局，单条展开、摘要两栏等宽、窄窗滚动保持；压缩/解压中心的多选弹窗、自然继承及等宽布局不变。计算中算法/文件锁定，切换算法重置旧结果；停止结果仅留当前工作区，不保存哈希中间态，不自动后台重算。
