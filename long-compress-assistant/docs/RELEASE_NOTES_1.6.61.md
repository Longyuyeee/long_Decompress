# v1.6.61 · LZOP 目录还原与旧名称编码

带目录的 LZOP 资料现在可以直接在原双栏里进入文件夹、搜索、预览和取回。保留目录提取及 ZIP/7Z 转换沿用同一份成员路径，不再把各目录里的同名文件混在一起。

- 支持官方 `lzop -P` 保存的成员路径，沿用文本、图片预览和文件夹按需取回；根目录文件仍按各自标记读取。
- 原压缩包选项中增加 LZOP 成员名称编码：UTF-8、当前 Windows 代码页、CP932/936/950、DOS CP437/850。已明确标记的 UTF-8/Latin-1 优先，未标明具体代码页时不猜中文；无法确认名称时仍可用固定成员名取回。
- 名称选择贯通浏览、预览、取回、转换与历史。扁平提取稳定区分同名文件；文件/目录相交、大小写和异常名称也保留独立结果。合法长文件名不再任意截短。
- 完整数字切卷保留任意卷入口。后续坏成员仍不发布前面的半成品，修正来源后可重试。保持单条展开、多选弹窗、自然继承、左右等宽、主题和快捷键。

本版为只读兼容增强，没有增加格式数。LZOP 不记录独立空目录，也没有总成员数字段，无法仅凭剩余成员发现整段完整成员丢失。结构列表和所选预览不代替整包检查；创建、原生密码、原生块分段及缺卷内容救援仍不提供。TAR.LZO 继续原单流目录规则。目录与 CP936 中文名称使用官方原件核对；其他代码页边界使用派生样本，不泛化为外部工具原件兼容证明。
