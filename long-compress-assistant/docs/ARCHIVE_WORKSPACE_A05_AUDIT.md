# 压缩包浏览中心 A-05：嵌套归档审计

日期：2026-08-26

版本基线：`1.1.13`（本工作项不单独升版）

目标：把归档内的归档安全地打开为只读子工作区，并保证层级、缓存、密码和返回状态都有可验证边界。

## 需求对齐

| 需求 | 实现 | 验收结果 |
| --- | --- | --- |
| ZIP→7Z→ZIP 三层进入 | 嵌套条目先经既有 A-03 会话缓存精确提取，再由浏览服务读取；顶部显示可点击归档链 | 真实 Release WebView2 已完成三层进入 |
| 最大深度 3 | 前端第三层禁用“进入压缩包”；后端根据已登记父缓存自行推导深度，拒绝客户端伪造与第四层 | Rust 单测与真实菜单均通过 |
| 共享预算 | 嵌套条目继续使用 A-03 的单文件 64 MiB、会话 256 MiB/64 项缓存，不建立第二套无界缓存 | 后端路径复核通过 |
| 返回保持外层状态 | 每层保存目录、搜索、筛选、焦点、多选、导航栈和展开目录；返回时恢复快照 | 前端单测与真实 2/2 选择恢复通过 |
| 密码按当前层隔离 | 进入子层后清空父层手工密码，只允许当前子归档自行匹配保险箱或手工重试 | 加密 7Z 先错密码、后正确密码；进入内层 ZIP 后密码再次为空 |
| 防止循环/重复内容 | 后端计算父子 SHA-256，并维护由服务端登记的祖先哈希链；重复祖先内容会拒绝 | Rust 单测通过 |
| 损坏/伪装归档稳定失败 | 缓存前校验普通文件、大小与归档魔数；读取失败停留在专用子层错误页，可重试或返回 | 损坏 ZIP 真实桌面路径通过 |
| 取消/返回不污染外层 | 每次读取使用序列号；返回外层后，迟到的子层结果会被丢弃 | 延迟 Promise 单测通过，外层状态保持完整 |

## 安全与生命周期审计

- 条目路径先经过统一规范化，拒绝路径穿越、绝对路径、设备路径和 ADS；提取结果必须恰好是一个大小匹配的普通文件。
- 嵌套文件不发布到用户输出目录，也不调用默认应用；它只存在于进程级会话缓存，应用退出后由缓存生命周期清理。
- 深度不是信任前端传值：后端只接受已登记父缓存形成的下一层关系，并自行验证声明深度。
- 哈希以 64 KiB 流式读取，避免为了循环检测把完整归档载入内存。
- 密码不写入归档链、缓存名、日志、历史或命令行。错误密码只留下读取失败分类，不回显密码明文。
- 返回外层属于可立即完成的 UI 取消：底层不可中断的元数据读取可能自然结束，但其迟到结果无权再修改当前工作区。

## 真实测试：预期、首次实际与修正

| 场景 | 预期 | 首次实际 | 修正后实际 |

| 正确内层密码 | 打开加密 7Z，且密码不传给下一层 ZIP | 通过 | 通过 |
| 三层与第四层 | 第三层可浏览，第四层入口禁用并解释原因 | 通过 | 通过 |
