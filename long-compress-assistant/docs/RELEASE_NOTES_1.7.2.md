# v1.7.2 · 多个文件，直接打包成 LZOP

在压缩中心把多个普通文件合成一条任务，选择 **LZOP**，即可生成包含独立文件成员的 `.lzo`。中文名、空文件和图片都可以保留，同名文件自动编号，不会相互覆盖。

## 本版更新

- 新增 LZOP 多成员创建，接入原进度、取消、完成校验、结果位置和历史；后续成员失败或取消时不发布前半包。
- 修正新建成员名称中的 `./`，补齐多成员标记，让官方工具能够按文件逐一取回；UTF-8 成员名称最多 255 字节，多文件中的超长名称会明确提示改用 TAR.LZO。
- 多文件任务可以使用原单条展开配置，多选仍在弹窗修改；修改选中任务不改变全局默认，固定模式继续收起无效的强度、密码与分卷控件。
- 密码 ZIP 等原包可用来源密码读取，再将多个顶层普通文件完整转为 LZOP；支持原双栏图文预览、所选取回和转回 ZIP / 7Z。
- 含目录的创建或转换会提示使用 TAR.LZO，保留文件夹和空目录；采样按成员独立编码，避免误算跨文件的压缩收益。

## 使用边界

普通 LZOP 不表达独立空目录，目录资料请选择 TAR.LZO。本版不增加原生密码、创建分卷或缺卷救援；已有完整数字卷读取保留。普通单文件的超长名称仍沿用输出文件名取回，不截断文件名。

成员名按标准 UTF-8 保存。官方 Linux lzop 已逐文件核对名称及内容；老版 Windows lzop 1.03 使用本地 ANSI 文件接口，中文名可能显示异常，建议用 Long解压读取或选择 TAR.LZO。
