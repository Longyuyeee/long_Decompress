- `native.json`：10 种 TAR 写入与两个完整数字卷案例，来源清单、实际输入/卷组、最终输出和目录时间。
- `conversion.json`：固定 GNU TAR.LZO 原件转 TAR / TAR.GZ，经验证和发布后再取回。

- `checks.json`：本次原生、相关回归、版本与 Shell 构建的执行结果摘要。

路径为本次机器的实际样本位置；自动生成文件位于忽略的 `test-results/tar-directory-layout-1726/`，独立脚本通过这些本地清单读回。样本由本版原生专项生成，外部 GNU 原件继续使用已有固定夹具，没有控制桌面或重跑旧格式矩阵。正式 PR、CI、合入、标签与 Release 附件身份在发布流程接续，不为回填运行号再次打包。
