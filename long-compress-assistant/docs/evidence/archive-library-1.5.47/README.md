# v1.5.47 归档资源库第一阶段记录

[封板](../../ARCHIVE_LIBRARY_FREEZE_1.5.47.md) · [检查摘要](checks.json) · [实际桌面记录](desktop.json)。候选、正常合入、标签和正式附件身份在本版 PR 接续。

51 项不同前端、12 项相关 Rust 通过；已有真实个人数据库快照用例按其显式 opt-in 保持忽略，未访问个人数据库。类型/Vite、Shell/八处身份及原生构建通过。七个实际桌面阶段包含：候选确认和手动建库、密码/损坏独立原因及跨包搜索、原文本预览且只选中命中项、单项 TAR 取回与原包哈希、缺失/变化阻断和手动刷新、3 万条目索引停止/手动继续、正常关闭同资料目录重启，以及类型/来源筛选、分页和只移除索引。

桌面中的首次自动预览暴露能力信息尚未加载的时序，已等初始能力再决定预览，补对应回归；通过的扫描/建库/搜索保留。之后自动化仍带着“只搜此包”筛选却期待全库数量，修正为清除筛选后继续，未重复已通过的取回或停止。窄窗实看发现来源行默认 flex 收缩而裁掉展开内容，已保留条目完整高度、由列表滚动；最终仅补受影响宽/窄列表与搜索显示。初始公共壳断言/隔离 mock 也按新增第九入口与既有草稿组件修正，非生产功能故障。

`desktop.json` 每项保留所属二进制 SHA-256，前两次身份只留已通过且未受后续改动影响的记录；最终身份只增加显示检查，不宣称所有行为在最终程序重跑。20 条布局记录来自 10 个宽窄场景，最终来源滚动与搜索覆盖旧来源显示：行内容不再压缩裁切，超高时列表可滚动，宽窗容得下时不强求滚动。其他布局无横向溢出。以下六张代表图已实看，前四张为最终程序；预览和候选沿未受 CSS 修正影响的已通过记录。未重跑旧矩阵、真实盘满或无关安装。
