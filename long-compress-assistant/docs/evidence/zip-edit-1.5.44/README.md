- `checks.json`：40 项不同前端、6 项不同 Rust、构建和版本身份、来源及产物 SHA-256。
- `desktop.json`：三条实际桌面流程、六处宽窄显示共 12 条布局记录；每条保留实际使用的二进制身份。初次添加/替换/冲突/拖入/另存通过后不重跑，最终程序接续新包浏览/预览/所选提取及失败纠正。横向溢出为零，宽窗待保存两列等宽，窄窗顺序排列并滚动。
- 六张代表图均实际查看。冲突复核来自首轮程序；失败页、文本预览和最终紧凑结果来自最终程序。原始 `save-result` 是调整前的空左列结果页，已被 `corrected-result` 替代，不作为最终界面展示。

原 ZIP 的 SHA-256 前后相同；独立 7z 回解确认未改、替换、保留两份、跳过、中文、空目录及拖入内容；界面提取结果与对应来源一致。已有目标未改，旧失败仍保留，任务栏返回后待保存修改可继续。初次脚本未关闭复核弹窗、第二次预览截图锚点超出当前弹窗范围，仅修正脚本并接续，实际已通过的流程不重复。
