# B-05.2.1 图片百图真实批处理审计

审计日期：2026-08-28（Asia/Hong_Kong）

开发分支：`codex/archive-media-roadmap`

公开基线：`v1.1.14`；B-05 整体尚未完成，本节点不升版、不更新公开 Release。

## 1. 目标与边界

B-05.2.1 只收口“100 张混合图片通过真实 Windows Release Tauri/WebView2 批处理”的可重复门禁。测试从冻结媒体夹具复制出 100 个不同的实际磁盘文件，经可见图片工作区按钮进入生产目标规划、逐图编码、验证、原子发布、结果预览和统一历史写入，不调用模拟编码器，也不把前端估算当作结果。

固定分布为 JPEG 34、PNG 33、WebP 33；其中保留小图、大图、透明、EXIF Orientation 和元数据样本。超大像素资源上限、中文长路径、冲突、磁盘不足和取消拆到 B-05.2.2；正式安装版完整交互拆到 B-05.3。当前产品没有“删除源文件”选项，因此本节点只用执行前后 SHA-256 证明源文件未改变，不冒充回收源文件功能。
