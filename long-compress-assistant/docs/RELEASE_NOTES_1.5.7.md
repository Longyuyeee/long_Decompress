# Long解压 v1.5.7

本版补齐 7Z 压缩方法读取，改善损坏包和密码处理的最终原因。

- 新增 PPMdH、Deflate、Deflate64 的 7Z 原生读取，并启用 Bzip2；贯通普通/固实、内容密码、文件名密码和数字分卷。
- 浏览、仅提取所选文件、完整性检查、整包解压及转换继续使用一致流程。原版 7-Zip 制作的 18 组原包逐一核对，转换产物由独立引擎回解。
- 未加密包损坏或截断时显示明确最终原因；方法不支持、内存限制和输出操作系统错误不误作密码不匹配。密码包无法区分错密与损坏时保留准确提示，不盲目更换引擎重试。
- 61 项 Rust、150 项前端、类型检查和 25 个真实桌面场景通过；8 张常用/窄窗页面已查看。中卷导入、纠正密码后新任务、保留旧失败与页面转换完成。

默认压缩算法及设置不变。已有 LZMA/LZMA2、BCJ2 为回归能力，不重复算新增；不承诺本轮未验证的 7Z Zstd 或新过滤器。Windows N 暂不保证支持。

详见[实施审计](SEVENZ_METHODS_1.5.7.md)与[封板发布记录](SEVENZ_METHODS_FREEZE_1.5.7.md)。
