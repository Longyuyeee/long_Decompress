# v1.6.18 · 7Z 图片预览与连续阅读

收到 7Z 相册或带截图的资料时，可以直接在原双栏浏览器看图，再进入原阅读器连续浏览，不必先把整包解压出来。

- **原位置看图**：接通非固实 LZMA / LZMA2 的 PNG、JPEG、GIF、WebP、BMP，完整大小、CRC 与解码结束通过后显示。单图不超过 8 MiB，单边不超过 8192、总像素不超过 1600 万；超出范围可先提取后查看。
- **连续阅读沿原操作**：支持翻页、缩放、适应窗口、跳过坏图、定位和准确提取当前页，另一栏的位置保留。7Z 按需加载当前页，复用原有限缓存，避免后台预读占用密码读取；关闭、换页或停止会取消对应请求。
- **密码和分卷接通**：支持手动密码、保险箱、文件名加密及完整数字卷，准确读取所选图片，不先验证无关文件。元数据与载荷每候选实际读取合计最多 64 MiB，候选整体限时 30 秒，来源变化会提示刷新。

保留单条展开、多选弹窗、左右等宽、原主题和工具收纳；已有 7Z 小文本仍保持 1 MiB 完整预览。本版不开放多文件共享固实预览或大文本前缀，格式数量不变。详见[本版记录](https://github.com/Longyuyeee/long_Decompress/blob/master/long-compress-assistant/docs/SEVENZ_IMAGE_PREVIEW_FREEZE_1.6.18.md)。
