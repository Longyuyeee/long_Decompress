# Long解压 v1.2.6

本版本完成解压运行态界面、跨卷根目录事务和无边框窗口交互的集中收口。

## 解压任务界面

- 低高度窗口下保持 8 个侧栏入口完整可见，任务监控不再挤压导航。
- 左下任务摘要固定为单行信息；折叠任务补充阶段、当前文件、速度和连续进度。
- 展开详情使用有界双栏和独立滚动区，长路径、状态、指标及日志不再结构性换行。
- 存储预检收敛为关键状态、可用空间和预计占用，删除重复的大段说明。
- 速度只在稳定非终态样本后展示，终态清空速度与 ETA；进度数字使用显示层缓动。
- 密码候选仍逐项真实验证，持久日志改为边界和周期采样且不记录密码明文。

## 跨卷事务

- 修复目标为 Windows 卷根目录时，暂存目录错误回退到工作盘并在最终发布触发 `os error 17` 的问题。
- 暂存现在始终位于所选目标卷；成功、失败和取消继续遵守原子发布与清理边界。

## 窗口交互

- 标题栏拖动和八方向缩放统一交给 Windows 原生非客户区循环处理。
- 不再由前端持续计算窗口位置、尺寸、DPI 或鼠标释放状态。
- 窗口按钮保持独立，不会误触发标题栏拖动。

## 验证

- 真实 Windows Tauri 壳门禁验证标题栏移动、八方向缩放、释放后稳定及紧凑弹窗。
- 920×620 与 760×520 的解压/压缩详情均通过无横向溢出审计。
- 隔离 Windows 逻辑卷根通过真实产品 IPC 解压、逐字节校验、源包保留和事务暂存清理。

Windows N 仍不在当前支持范围内；Windows 11 第一层资源管理器菜单仍受代码签名身份限制。
