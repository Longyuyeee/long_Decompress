# v1.7.7 默认打开方式修复与检查

日期：2026-10-27。

## 用户问题与实现

原弹窗缺少全选，已默认格式的复选框被禁用，空选择不能提交；设置页另放一个更改/取消入口。初始选择还混用了注册候选与实际默认状态，准备注册后立刻关闭弹窗，用户无法判断哪些格式已生效。

现在只保留一个设置入口，弹窗中完成全选、全部取消、单项勾选和确认。初始选择来自 AssocQueryStringW 返回的实际默认应用，候选注册不作为成功依据。确认后读取实际状态，尚有差异时保留弹窗与用户选择；从系统返回或点击刷新时更新已默认、待确认和待更换。所有取消也能提交，系统启动失败会保留选择与错误，并支持重试。

原实现将 ms-settings URI 作为 explorer.exe 参数传入，并把进程创建成功当作跳转成功。现改用 ShellExecuteW 激活 URI 并检查返回码；Windows 11 支持应用专页的版本使用 registeredAppUser 参数，其余版本进入默认应用首页，专页激活失败会尝试首页。调用期间正确管理 COM 初始化计数。

已存在显式 Windows UserChoice 的默认格式，在用户到系统更换之前保留候选和有效打开命令，确保还可在系统页找到并更换。未选的其他候选从本软件注册中移除；不改写其他应用注册、UserChoice 或旧默认值。启动时只刷新原先已注册候选，不重新增加未选格式。

## 系统边界与后续

微软要求 Windows 10/11 的默认应用更改通过系统界面由用户确认，普通软件不能通过受支持 API 静默替换全部系统默认。本版简化软件内管理和系统入口，仍准确提示所需的系统确认。依据：[默认应用平台](https://learn.microsoft.com/en-us/windows/apps/develop/windows-integration/default-apps-platform)、[默认应用设置链接及版本条件](https://learn.microsoft.com/en-us/windows/uwp/launch-resume/launch-default-apps-settings)。

按用户要求，后续不直接接管桌面、不自动操作系统设置，复用后台测试与隔离注册表结果。本版保留“系统目标页未目视确认”的限制，不以模拟状态补作真实系统验收。未重跑归档格式矩阵、旧安装器或已通过更新下载回归。

GNU 长名称和全局 PAX 元数据兼容移至 [v1.7.8](ARCHIVE_ROADMAP_1.7.8.md)，仍仅规划。
