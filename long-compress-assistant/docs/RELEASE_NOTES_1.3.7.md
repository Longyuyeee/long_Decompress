# Long解压 v1.3.7

这次更新围绕解压前后最常用的操作，让批量处理、找回旧任务和取用结果更方便。

- **批量失败更好处理：** 汇总本批成功、失败和待处理数量；选择失败项，更换来源、输出目录或密码后创建新任务，成功项无需重做。
- **历史更容易找：** 关键词搜索全部已保存历史，支持类型、状态、时间和失败类别筛选，不必逐页翻找。统计与趋势仍按当前加载结果展示。
- **再次解压少填设置：** 完整归档的新历史可恢复输出目录和“同名子目录”选择；旧记录缺少配置时明确提示，密码由用户重新提供。
- **开始前看清去向：** 在详情中预览预计输出目录，提示目录已有内容和任务共用目录，可直接修改。目录提示不等同于逐文件冲突检测。
- **完成后直接取用：** 从任务、历史和本批成功结果打开输出目录或复制路径；目录失效时就地说明。清空队列后仍能查看最近批次，重启后从历史查找。
- **界面更清楚：** 主列表保持紧凑，设置和详细信息进入二级窗口；结果名称、路径和按钮分层，长路径自动换行，适配小窗口及深浅主题。

本版聚焦归档解压；压缩/媒体的完整配置恢复、逐项冲突增强、书签和标签页留待后续版本。Windows N 暂不支持，Windows 11 第一层右键菜单仍受代码签名身份限制。
