# v1.6.8 · 大 ALZ Bzip2 按块读取

较大的旧 ALZ Bzip2 文件现在按块读取，不再仅因单条压缩数据超过 256 MiB 而无法检查、提取或转换；处理过程中也不再先将整条压缩数据收集到内存。

- **更稳定的大文件处理**：读取窗口随当前压缩块复用，逐块交付输出，密码状态和跨块位对齐连续保留。
- **沿用现有操作**：双栏浏览、整包/所选提取、转换、暂停、继续和取消沿原入口使用，不增加配置步骤。
- **完整性结果仍准确**：结束标记、异常尾随、实际短读、输出错误、大小和 CRC 校验继续生效，不把未完成结果标为成功。

保持工具中心、单条展开、多选弹窗和左右等宽布局。本版不增加格式数量；ALZ 方法 3、EGG 加密固实和 ALZ 创建/修复仍不支持。

验证范围：使用实际压缩数据 282,956,568 字节的受控多块归档和独立完整回解；密码/原生卷回归同样为明确标注的受控数据。历史原工具生成的大 Bzip2 原件仍待取得，不据此承诺所有历史构建及密码/卷组合。详见[范围与记录](ALZ_BOUNDED_FREEZE_1.6.8.md)。
