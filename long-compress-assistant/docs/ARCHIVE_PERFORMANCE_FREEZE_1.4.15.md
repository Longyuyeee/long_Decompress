## 保留边界

ZIP 局部预检收益不等于整条应用百分比提速；当前整应用资源数据不是前后 A/B。TAR 独立读取时 Windows bsdtar 需要显式 UTF-8，未承诺所有读取器默认中文互通。500 ms 空间与 100 ms 目标进程采样会漏过短峰，工作集求和重复共享页，逻辑 I/O 不是物理磁盘流量。新编码、特殊卷和新格式按后续路线处理。Windows N 暂不保证支持，智能目录/ZIP 并行仍默认关闭。
