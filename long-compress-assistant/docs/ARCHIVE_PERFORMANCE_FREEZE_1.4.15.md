# v1.4.15 封板与发布接续

2026-10-17：功能、实际用户流程和本版资源观察已封板；候选版本统一为 1.4.15。尚未合入或正式发布，公开版仍为 v1.4.13。v1.4.14 PR #168 尚未合入，已请求用户选择先单独发布旧候选还是与本版一次发布；候选构建不等于正式发布。

## 冻结范围

- ZIP 任务内复用所选加密索引，省去重复明文预检；保留全部所选密码条目、混合密码、编码碰撞兼容与完整内容校验。

- RAR 预检查移至阻塞线程，原生操作前后支持暂停/取消；保留全量统计、溢出、容量与准确错误，不宣称 SDK 单次调用内部即时可中断。
- 矮窗口归档浏览页保留可用列表高度，单条配置、多选弹窗及既有界面结构不重做。
- 继承 v1.4.14 的 ZIP Zstandard / ZIPX（XZ）创建和方法设置链；本版不扩展 ZIPX 标准卷或新格式。

## 发布接续

1. 本版 PR 的最终候选只接续必需 **Windows package** 普通 NSIS 构建；成功后达到可发版，不重开无关媒体/旧密码矩阵。
2. 用户明确发布顺序后，再处理旧 PR 与本版合入，从最终合入提交创建正式标签。发布资产必须对应实际标签，不把候选截图哈希套到安装器上。
3. 正式标签后接续既有 Release workflow，核对安装器、签名更新 ZIP、签名与 latest.json，采用中文 Release 正文；两份 README 保留图标，仅在实际发布后把候选改为正式下载。

## 保留边界

ZIP 局部预检收益不等于整条应用百分比提速；当前整应用资源数据不是前后 A/B。TAR 独立读取时 Windows bsdtar 需要显式 UTF-8，未承诺所有读取器默认中文互通。500 ms 空间与 100 ms 目标进程采样会漏过短峰，工作集求和重复共享页，逻辑 I/O 不是物理磁盘流量。新编码、特殊卷和新格式按后续路线处理。Windows N 暂不保证支持，智能目录/ZIP 并行仍默认关闭。
