# v1.5.51 · 工作流纠正、接续与指定步骤重跑

## 改好出错步骤，接着做

- 运行记录增加“纠正并继续”和“从本步重跑”。默认从首个未完成步骤开始，也能指定重新处理的位置。
- 在弹窗修改本次来源、保存位置、密码及步骤参数，配置仍点击展开，继续复用原压缩面板和配置组。明确列出前面哪些步骤待核对复用、哪些下游将重新执行。
- 更换原始来源或调整上游参数，重跑范围自动提前；只改步骤显示名称不会触发重做。修改用于本次接续，原方案和旧运行记录保留。

## 已成功的部分，有依据地复用

- 新运行保存不含密码的执行快照和各步输入、产物内容依据。开始接续时按实际内容核对，不只依赖“曾成功”、文件大小或修改时间。
- 来源变化、产物缺失或分卷不齐时指出具体步骤，先保留原记录，不创建后续任务；可从建议步骤重做，或补齐文件后再次接续。
- 核对显示实际读取进度，可以停止；停止核对不启动新任务。正常执行中无法记录完整接续依据时，保留已生成结果并说明该步需要重做。
- 每次接续使用新的运行目录和记录，已复用步骤显示原产物位置，并可返回原运行。后续仍使用真实产物，整组分卷交给筛选或再次压缩时不会只带入首卷。

## 重开应用后，也能继续

- 正常关闭前保存运行记录；重开后，未完成运行保留步骤、输入和产物，可手动接续，不自动重新执行。
- 执行快照独立于当前保存方案，原方案修改或删除后仍可按该次配置接续。
- 读取已有密码产物时重新填写本次密码或从保险箱选择；与后续新包密码分别设置，密码不写入快照、运行或历史。
- v1.5.50 旧摘要继续可查看；没有恢复依据时可明确带入当前保存方案做一次新运行，不将旧摘要冒充可接续执行。
- 原单条展开、多选弹窗、自然继承、压缩/解压左右等宽与滚动保持，新增复核和配置在宽窄窗口均可滚动操作。

复用以完整成功步骤为单位。同一步中部分来源成功的结果继续保留，但重做该步时会重新处理它的来源；不续写压缩算法中间字节，也不新增格式或算法。内容依据覆盖实际文件、目录结构和分卷成员，超出接续记录范围或读取期间发生变化时说明原因并要求从相应步骤重做。
