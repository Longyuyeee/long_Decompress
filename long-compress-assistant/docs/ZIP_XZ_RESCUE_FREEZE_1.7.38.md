# v1.7.38 · 流式 ZIPX（XZ）丢目录部分取回封板

日期：2026-10-30。

## 实现与范围

原本地条目恢复读入器接通未加密、未知本地压缩尺寸的 method 95 单 XZ 流。使用已有 xz2/liblzma 单流解码器，实际到达 StreamEnd 后确认消费量、展开量及 ZIP CRC，再在准确位置匹配普通或 ZIP64、有或无签名的描述符。块校验、索引和尾部由解码器完整验证，不忽略不支持的校验类型，不扫描正文标记。

解码内存上限 256 MiB，沿原累计展开上限、取消和 I/O 原因传递；坏内容、截断、矛盾或未知边界停止，当前成员不输出，只另存前面完整确认成员。空 XZ 流、明确目录、BZip2 混合尾部、实际完整数字切片和已确认日期接通；缺中间卷不跨缺口扫描。暂存、新包整体验证、结果/部分历史和修正原件后重试沿原流程，原总清单保持未知。

多 XZ 流、流填充、特殊滤镜/字典组合与密码未知边界未扩展；未增加格式数量。UI、单条展开、多选弹窗及等宽双栏保持。
