# v1.6.20 候选 · 7Z 小型固实图片与原阅读器

仅规划，尚未开发。接续 v1.6.19 的完整共享块读取，把常见固实相册带回原双栏预览和现有图片阅读器，继续格式/算法、密码/分卷与容错主线。

1. **先完整单图**：未加密 LZMA/LZMA2 固实原件，所选 PNG/JPEG/GIF/WebP/BMP ≤8 MiB、单边 ≤8192、总像素 ≤1600 万；共享压缩数据和解码总量分别 ≤64 MiB。所有共享依赖大小、CRC、压缩覆盖和编码结束检查通过后，才进入图片识别；只保留所选图片，不展开临时整包。
2. **接原连续阅读**：保留双击、眼睛、右键和 Ctrl+Enter，按需当前页、原有限缓存、翻页/关闭/停止取消、坏图跳过、缩放/适应、定位和准确提取当前页；固实包不后台预读下一页，另一栏的位置保持。
3. **完整卷与来源接续**：原版工具产生的完整数字卷从有效任意成员进入，读取前后核对卷组来源；共享解码逐块检查取消/30 秒目标，损坏、缺卷、超限和不支持有清楚下一步。加密共享流单独规划，不因为非固实密码可用就默认开放。
4. **独立可交付**：原件独立回解与实际像素、所选路径、损坏/超限和宽窄 UI 做本版必要检查，更新能力范围、README、Release 与交接；不重复旧矩阵、安装或真实盘满。

不把全量相册展开、未知组合、固实大文本前缀和加密固实混入本版。ALZ 方法 3、历史 Bzip2/原工具图片与 EGG 加密固实继续按有效来源独立接续，不空发取材版本。
