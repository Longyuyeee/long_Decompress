# Long解压 v1.4.2 · 待发布

本版让多个压缩包一次处理，也能在重新打开软件后找回尚未开始的工作。功能已收口，当前公开版本仍为 v1.4.1；新安装包尚未发布。

## 一次转换多个压缩包

- 从软件一次选择多个压缩包，或从 Windows 右键菜单带入多选文件，统一转换格式、修改密码、调整分卷或合卷。
- 点击某条，在该条下方直接展开编辑；多选后点击“修改所选配置”，在弹窗中调整参数。默认保持各自设置，只修改指定字段，统一更换目录时保留自定义名称。
- 全局配置提供默认值，编辑某条后自然保留该条设置，无需选择全局或单独模式。新包名称与完整保存位置实时显示，原压缩包保留。
- 批次逐个处理，一个失败继续执行其余项；停止后保留尚未开始的工作。每项结果可定位文件、打开目录或复制路径，失败项可调整后再次转换。

## 重新打开后接着整理任务

- 未开始的归档压缩文件与分组、解压任务、转换任务自动保存为草稿。下次打开显示紧凑的恢复入口，可恢复或丢弃；恢复后由用户手动开始。
- 已编辑的单条设置和全局默认一并恢复，新添加的任务不会被旧草稿覆盖。来源文件移动或删除时，在对应条目提示并提供重新选择入口。
- 草稿不保存密码。原包密码与新包密码分别提示重新填写，填写其中一项不会清除另一项需求；无需密码或不加密也可在对应字段明确选择。

## 日常操作更顺手

- 压缩中心、解压中心的多选配置统一使用按钮打开弹窗，任务列表保持紧凑；单条详情继续行内展开。
- 关闭批量配置弹窗后保留转换列表，取消不会应用修改，再次打开从“保持各自设置”开始。
- 从历史再次转换保留正在编辑的草稿，为新任务生成独立输出名称；反复打开同一草稿不会重置配置。

草稿恢复首期覆盖归档任务；已开始或完成的任务继续通过历史查看，图片、视频与 PDF 草稿暂不包含在本版。
