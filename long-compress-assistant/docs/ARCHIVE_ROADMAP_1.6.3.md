# v1.6.3 ZPAQ 受损数据块诊断与受影响条目定位（已封板）

接续 v1.6.2 的完整旧快照取回。进一步的部分抢救拆成小步：本版先回答“哪份快照的哪些文件可能受影响”，下一步才将完整校验的可用条目接入抢救结果。

## 用户目标与顺序

1. 对目录与事务完整、数据块校验失败的日志式 ZPAQ，建立明确标注的受控损坏副本，与独立官方工具读取结果对照。普通/密码、单包/已确认原生多部分分别记录；不能把注入损坏称为自然损坏原件。
2. 利用已读取的片段引用定位共享受损块涉及的条目；区分未检查、检查通过、检查失败和目录不可用。只有实际逐项校验通过才能称为可用，不能从目录可读推断内容完整。
3. 在现有诊断二级界面呈现受影响范围、已选快照和简洁计数，长清单收纳筛选；主浏览列表保持空间，保留双栏、单条展开与多选弹窗。
4. 诊断可取消，沿用会话密码；生成不含密码的结果说明。缺卷或目录本身不完整时停止条目级推断，继续提供 v1.6.2 已确认的完整旧快照入口。
5. 只覆盖新增受损块、共享引用和必要宽窄显示检查，不重跑旧格式/安装/盘满矩阵。
