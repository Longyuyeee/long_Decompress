# v1.7.16 规划 · TAR.LZO PAX sparse 0.0 部分取回

状态：仅规划，尚未开发。接续旧 GNU、PAX 1.0 和 0.1 的部分取回，补齐旧式重复属性映射的恢复流程。

1. 先取得 GNU tar `--sparse-version=0.0` 生产者原件，独立核对源文件、GNU/其他读取器的名称、逻辑大小和 SHA，覆盖长名称、全零、多段及大空洞。与边界构造样本分开记录。
2. 顺序确认局部 PAX 的 `GNU.sparse.offset` / `GNU.sparse.numbytes` 重复属性对，严格核对声明段数、顺序、范围、逻辑大小和实际存储量，不套用普通 PAX 的“最后一个值生效”。与 0.1 逗号图、1.0 条目内文本图分别识别，混合或不完整布局停止。
3. 复用有界映射、逻辑 SHA、稀疏输出、来源重查、取消清理及时间恢复。只列入外层连续已校验前缀中的完整条目，补卷后重新检查，不扫描缺口之后。
4. 保持原筛选、目录联选、结果和部分历史，保留单条展开、多选弹窗与等宽双栏。只检查新布局受影响的元数据/数据/填充、缺卷、实际输出及宽窄显示，不重跑未受影响的矩阵，不接管桌面。

链接救援、缺口后扫描及完整权限/所有者恢复继续分期。ALZ/EGG 加密分卷外部原件缺口及 LZOP 原生密码/块分段继续独立研究，不将缺少依据的组合列为已支持。
