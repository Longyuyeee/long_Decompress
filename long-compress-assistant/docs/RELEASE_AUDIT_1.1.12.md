# Long解压 v1.1.12 发布审计

审计日期：2026-08-22

## 结论

v1.1.12 将开机自动启动恢复为严格的显式选择能力：默认不注册，应用生命周期不写入，只有设置页开关可以改变用户级启动项。真实 Windows 桌面、前端、Rust、安装器和 CI 门禁已覆盖关键生命周期；除必须在启用 Defender 的外部环境完成的发布后扫描外，候选具备发布条件。

## 需求对齐

| 范围 | 实际结果 | 判定 |
| --- | --- | --- |
| 恢复开机自启 | 设置中心恢复可访问开关 | 已完成 |
| 仅用户选择时注册 | 加载与检查只读，只有点击路径调用写命令 | 已完成 |
| 避免重复持久化 | 精确值存在时幂等，启动与更新不反复写入 | 已完成 |
| 静默登录启动 | `--autostart` 隐藏窗口并驻留托盘 | 已完成 |
| 已运行实例 | 登录触发的第二实例不唤醒现有窗口 | 已完成 |
| 更新与卸载 | 更新保留当前显式选择，卸载清理全部相关值 | 已完成 |
| 错误处理 | 写入失败回读真实状态，不保存虚假成功 | 已完成 |
| Defender 风险 | 不创建白名单；启用 Defender 的干净机扫描仍为发布后验证项 | 如实保留 |

## 候选验证

- 前端 36 个测试文件、214 项单元/组件测试通过，TypeScript 类型检查和 Vite 生产构建通过。
- Rust release 主库 254 项通过、3 项按设计忽略；主程序启动参数测试通过，Clippy 严格检查零警告。
- 真实 Windows Release Tauri/WebView2 聚焦门禁通过，实际点击设置页开关并验证注册、精确命令、幂等、关闭清理和隐藏启动。
- 测试结束后 `HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run` 中没有遗留 `Long解压` 测试值。
- NSIS 候选构建成功，安装器模板测试确认覆盖更新保留当前值、卸载清理当前及历史品牌值。
- 主程序 FileVersion/ProductVersion 均为 `1.1.12`；7-Zip 对 NSIS 内 14 个载荷文件的完整性检查通过。
- 最终本地候选安装包大小为 7,658,414 字节，SHA-256 为 `F5473FFE0306F11EC0BA9287A5EFE540945731ABF3D438B3A7239EF001604F20`。

## 发布门禁

- npm、Tauri、主程序、Shell Extension、两个 Cargo 锁文件和版本化 DLL 必须统一为 `1.1.12`。
- GitHub Release 必须包含 NSIS 安装包、updater ZIP、签名文件和可解析的 `latest.json`。
- 无商业代码签名时继续禁止把 Windows 11 第一层菜单身份包纳入公开安装资产。
- 当前开发机的 Microsoft Defender 处于禁用状态；不得将本机无法执行的扫描描述为通过，需在启用 Defender 的 Windows 10/11 环境补验。
