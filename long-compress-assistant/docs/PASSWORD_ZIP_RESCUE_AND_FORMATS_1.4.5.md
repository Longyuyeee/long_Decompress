日期：2026-10-14（香港时间）。基线 `master / 18c4a65`，分支 `codex/password-zip-rescue-formats`。目标为本轮功能可封板；正式公开版本仍是 v1.4.4，不自动创建发布标签。

## 当前实现

### 密码 ZIP 完整文件救援

- 中央目录可读时接受用户提供的密码，复用实际解压的 UTF-8/Windows 密码读取及完整卷组层；覆盖 AES、ZipCrypto、混合明文/加密 ZIP、ZIPX、普通包、数字卷和标准 ZIP 磁盘卷。
- 只将完整读取并通过内容校验的文件写入新包。坏文件、错误密码条目和不支持的方法显示未恢复原因。混合包的明文文件不作为密码正确的证据，必须有完整加密文件通过校验才能发布。
- 新包统一使用 AES-256 和填写的密码（UTF-8），原包保留。页面提前说明新包密码，结果再次显示加密状态；不默认生成明文，不新增强制模式选择。
- 沿用完整性页的密码输入、选择位置、取消和部分恢复结果。修改密码后清除旧诊断，重新检查；修复期间锁定来源、密码和工具切换。新增定位新包、复制路径按钮。
- 保持原来的无密码 ZIP 目录重建与完整条目救援。密码包目录已丢失、缺卷、未知边界恢复和标准卷丢目录重建仍不包含在本轮。

### ARJ、Unix `.Z`、UDF 读取

- 扩展统一导入/选择器、归档转换来源名称、嵌套格式识别及经典/原生 Windows 右键扩展名；双栏浏览器的图标、双击浏览、右键“解压到另一栏”和文件选择器共用同一格式列表，不会把只读格式加入创建目标。
- ARJ 存储及方法 1～4 使用固定上游样本；Unix `.Z` 和 UDF 使用固定非空上游样本，已知载荷独立于应用生成。
- UDF 目录的 `Folder = +` 正确识别为文件夹。Unix compress 本身不保存展开大小，浏览立即展示一个文件及“大小未知”，避免为填列表先解压整个流；诊断页也明确未知大小。
- `.Z` 作为单文件压缩流处理，例如 `t.txt.Z` 回解为 `t.txt`；`.tar.Z` 的这一层输出是 TAR，可继续使用已有 TAR 浏览/解压。没有新增 TAR.Z 创建器或宣称自动解开所有嵌套层。
- ARJ 的密码/原生分卷创建、所有 UDF 变体不作为已完成能力。引擎保持现有随包 7-Zip 26.04。
