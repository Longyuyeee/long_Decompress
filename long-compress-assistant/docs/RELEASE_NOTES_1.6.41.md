# v1.6.41 · 密码固实 Deflate64 图文直接看

密码固实 Deflate64 7Z 中的小文本和图片，现在也能在原双栏浏览器里直接预览，继续使用手动密码或密码保险箱。

- 接通内容加密、文件名加密、完整数字分卷和从非首卷进入。
- 完整文本最多 1 MiB、图片最多 8 MiB；共享压缩数据与解码总量分别最多 64 MiB。流式处理前后内容，仅保留所选文件。
- 沿用原文本窗口、常见编码/滚动、图片预览、连续阅读、翻页/缩放、跳过坏图、定位和仅提取当前页。
- 保留真实结束、共享 CRC 和完整加密消费/填充检查；明确输入的错误密码不回退，不凭预览记录整包密码成功。取消、来源变化和缺卷处理继续生效。

大文本、超限共享块及其他未支持组合仍可提取后打开，范围说明放原问号。单条展开、多选弹窗、等宽双栏、主题/工具/快捷键保持，格式数及依赖不变。下一阶段先做非固实 Deflate64 大文本开头预览。
