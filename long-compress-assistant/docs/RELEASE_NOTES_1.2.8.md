# Long解压 v1.2.8

本版本收口归档队列顺序、并发配置、全局/单独配置来源，以及真正可恢复的运行中暂停与停止控制。

## 队列与配置

- 解压列表与执行队列共用中文数字自然排序，界面第一项就是实际优先启动项。
- 设置中的并行任务数继续作为上限生效；不同输出资源可并行，同一最终目录为避免提交冲突仍安全串行。
- 压缩与解压任务都可明确选择“跟随全局”或“单独配置”；切回全局会清除覆盖，默认格式、等级和同名目录策略可在设置中心持久保存。

## 暂停、恢复与停止

- 解压中心、压缩中心和左下任务监控增加单项与全部暂停/恢复；暂停和停止不再混用。
- 原生 ZIP、7Z、TAR/AES、密码保险箱/词表尝试与发布校验在安全检查点等待；Windows 外部 7-Zip、WinRAR 和分卷进程会被系统级挂起并从同一任务恢复。
- 停止会唤醒已暂停任务、清理暂存和未发布输出、释放队列槽位；单项停止后后续任务接续，全局停止同时通知全部运行与等待任务。
- 图片、视频和 PDF 仍使用各自现有的取消协议；界面不会把归档暂停按钮错误显示为特殊压缩的可恢复暂停。

## 验证

- 真实 Windows 子进程在暂停观察窗内输出字节不增长，恢复后继续增长。
- 真实 Tauri/WebView2 中逐项点击单项暂停、恢复、全部暂停和停止，状态、后台写入和清理结果一致。
- 归档全流程继续通过并发压缩、普通/AES ZIP 遥测、同目标串行、加密固实 7Z 往返和密码格式回退。

Windows N 仍不在当前支持范围内；Windows 11 第一层资源管理器菜单仍受生产代码签名身份限制。原生 RAR 库只能在条目边界安全暂停；外部 RAR 引擎可即时挂起。
