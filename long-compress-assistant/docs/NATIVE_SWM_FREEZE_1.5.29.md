# v1.5.29 功能封板

2026-10-20，接续已正式发布的 v1.5.28（PR #223，标签 d3b4a0e72876fd292536e2d3b6702de19288c833，正式运行39408431109，四附件与中文说明已核对）。本文件为合入前快照；最后候选、受保护合入及正式四附件身份在本版 PR/Release 接续。

## 交付与范围

原生 `install.swm/install2.swm/...` 任意成员归组、浏览多镜像、有界文本/图片预览、完整检查、所选与整包提取、内容转换、缺卷补齐新任务及原结果入口接通。直接交给随包 WIM 引擎跨资源读取，不拼接完整临时镜像。校对卷号、总卷数、GUID、压缩方式及资源范围，缺尾卷也明确报实际文件名；混组、错号、截断与内容损坏保留原因。

独立正面范围为非固实 Copy/XPRESS/LZX，SWM 只读，选择器和归档菜单名单已接入；不新增 SWM 创建、WIM 密码、缺卷部分抢救或系统部署。多镜像转换保留所见编号目录，目标 WIM 是内容归档；不是完整 Windows 元数据恢复。普通/数字 WIM 的既有 LZMS 读取不变。请保留原始名称、同目录集齐分卷，任意改名不靠猜测读取。

单条展开、多选弹窗、自然继承、左右等宽及窄窗滚动保持。测试态启动自动刷新及注册/移除 API 与个人系统菜单隔离，正式程序原启用逻辑保留。v1.5.28 桌面启动菜单变化的旧表述已更正，见[实施记录](NATIVE_SWM_1.5.29.md)，不宣称过去有未保存的完整回滚基线。

## 本版定向记录

- 六项不同 Rust：三类真实原生 SWM 首/中/末卷浏览、完整检查/诊断、预览、指定资源与整组提取；缺首/中/尾卷恢复；混 GUID/错号/截断/坏内容；大小写与前缀含数字/错误改名边界。830 项旧检查过滤未执行，未计为新通过。
- 一项前端：SWM 首/后续成员可导入但没有创建选项；同文件24项旧检查跳过。类型与前端构建、Shell构建和八处版本身份通过。
- 四条公共原生链：测试程序注册/移除 API 均被拒绝，以及 Copy 六卷、XPRESS 三卷、LZX 双镜像六卷从中卷完整提取；文件摘要和空目录与独立 wimlib 原件一致。
- 五条实际 UI：中卷多镜像文本/图片与只取镜像2文件；撤掉真实尾卷失败、补齐新待执行任务与旧失败保留；末卷转新密码ZIP；末卷转普通WIM；一次导入九个成员归为两任务、单条展开与多选弹窗配置且不隐式启动。转换产物全部独立回解核对摘要及空目录。

原件由固定工具 wimlib1.14.5 capture/split/verify/apply，资源表确认XPRESS/LZX分别18/36个大资源确有压缩。manifest固定全部工具/成员身份；运行时没有分发wimlib。实际桌面程序源 c0db9dd8ad75e344523b2c73daf32c4d9c0494d3，SHA256 fd8f03fb9439bbbedc2a3bac5e51cfb21ea6468dd9b047b4c4fa59a361361478。其后只有测试脚本与文档接续；不把早期错误脚本或环境失败计作产品通过。

桌面最初因本机WebView2升级而驱动不匹配，在缓存更新匹配驱动后接续；脚本曾修正测试总和类型与结果定位器，未修改产品来迁就检查。实际运行按检查点跳过已完成链，没有注入成功、预览或进度。1100×700和760×520共18张截图，已实看代表性的预览、所选提取、补卷、转换、行内与批量页面；横向溢出为0，宽窗两列等宽，窄窗保留滚动。Long个人菜单前后2365键/4992值指纹一致，个人设置/历史沿隔离数据目录，未安装个人程序。

证据见[evidence/native-swm-1.5.29/](evidence/native-swm-1.5.29/)。旧格式/密码/哈希全矩阵与已通过真实盘满不重跑。普通生产前端由必需候选构建，桌面测试桥不混作正式发行物。
