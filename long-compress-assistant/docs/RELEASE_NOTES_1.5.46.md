# v1.5.46 · 密码 ZIP 编辑与草稿恢复

## 密码包也能在原工作区整理

- 支持独立 Store/Deflate ZIP 中的 AES-128/192/256 与 ZipCrypto 内容，继续使用添加、替换、删除、改名和批量移动。
- 原包密码和密码编码从浏览器带入，也可从现有密码保险箱选择。原包与新包的密码设置分开显示。
- 可保留原加密与密码、更换为 AES-256/ZipCrypto，或明确另存为无密码 ZIP；只调整密码、不改内容也能另存。
- 保留模式下，原条目沿各自加密方案及公开状态；新增条目沿统一原方案，混合方案的新条目使用 AES-256，替换沿被替换条目的方案。新包密码编码可明确选择，默认 UTF-8。
- 密码内容重新写入，保留内容、压缩方法、有效时间、备注和空目录；体积可能变化。新包可直接继续浏览、预览、提取或转换，并带入本次新包密码。

## 未完成的编辑，关掉以后还能继续

- 修改清单、原包与外部文件引用、输出位置和配置自动保存为本地编辑草稿；上方紧凑入口可找回多份编辑。
- 恢复先核对来源。原包或外部文件缺失、变化时，会列出具体位置，可重新定位或读取当前来源并确认，原修改顺序与包内目标保留。
- 重新定位文件夹只接续清单里的引用，不自动加入后来出现的新文件。
- 草稿不保存密码，恢复后重新填写或从保险箱选择；不会自动启动另存。已完成的保存会返回原结果，不重复执行残留草稿。
- 失败或停止继续保留修改；纠正后另存仍保留原失败、原包和已有目标。正常关闭或托盘退出前会先写入编辑草稿。

原有单条展开、多选弹窗、自然继承及压缩/解压左右等宽布局保持；新增密码、恢复和来源处理沿现有弹窗风格，宽窗等宽、窄窗顺排滚动。

编辑仍限独立 Store/Deflate ZIP；分卷、自解压、嵌套临时来源、特殊路径/链接及其他方法继续使用原浏览/提取。同包需一份用户凭据能够读全；空 ZIP 没有可加密文件，需要明确选择不加密。

ZIP 编辑工作区的三个阶段在本版收尾。下一版按既定路线进入 **v1.5.47 本地归档资源库、跨包搜索与单项取回**，逐步完成后续模块，再回归更多算法、格式与容错兼容主线。
