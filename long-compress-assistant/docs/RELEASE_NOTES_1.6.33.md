# v1.6.33 · 7Z Deflate 图文原位预览

普通非固实 Deflate 7Z，现在可以直接在双栏文件浏览器中查看文本和图片，减少先提取再确认内容的步骤。

- 完整小文本 ≤1 MiB 沿原文本窗口、编码识别和滚动显示；UTF-8、UTF-16、GBK 及空文件保持原使用方式。
- PNG、JPEG、GIF、WebP、BMP 图片 ≤8 MiB 接通原预览和整包阅读器，支持翻页、缩放、跳过坏图、定位及仅提取当前页。
- 完整数字分卷可从任一成员进入，保留缺卷提示、取消与来源变化处理；只读取所选内容，不扫描无关大文件。
- 完整显示前确认 Deflate 流结束、长度、压缩数据消费和可用 CRC。损坏内容不会作为完整预览显示。

保留单条展开、多选弹窗、等宽双栏、主题、工具与快捷键。本版范围为普通非固实 Deflate；密码、固实、大文本和 Deflate64 可沿原入口先提取后打开，后续分阶段接通。无新增依赖或格式计数变化。
