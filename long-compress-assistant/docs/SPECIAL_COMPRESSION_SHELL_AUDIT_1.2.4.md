## 需求与实际结果

| 用户要求 | 修改后的实际结果 | 验证方式 |
| --- | --- | --- |
| 删除特殊压缩中重复、冗长的说明 | 图片、视频、PDF 主界面不再展示已由 Tab 或配置表达的泛化说明 | 组件断言与真实 Tauri 页面观察 |
| 视频未展开时只保留精华信息 | 默认折叠；摘要仅保留尺寸、时长、质量与估算范围，输入事实、流信息和执行前变化在展开后出现 | 单元测试先断言不可见，再展开断言可见；真实视频门禁截图 |
| 三类批量设置不要占满应用 | 图片、视频统一为 `lg` 弹窗；PDF 输出目录和冲突策略归入独立紧凑弹窗 | 1440×900 实测：图片 736×574、视频 736×528、PDF 512×241 |
| PDF 主界面与另外两类对齐 | 主区只保留锁定数、批量设置、开始按钮和文件列表，不再平铺输出目录 | 真实 Tauri 壳门禁与 PDF 门禁 |
| 恢复无原生装饰窗口的拖动与缩放 | 空白标题栏显式调用原生拖动；窗口四边和四角提供 8 个应用内缩放热区，最小尺寸 760×520 | 单元测试验证拖动和东南角尺寸变化；真实壳门禁验证 8 个热区 |
| 去掉重复的顶端产品名 | 顶端仅保留窗口操作按钮，品牌只在左上侧栏出现 | DOM 断言与真实截图 |
| 任务监控出现时侧栏不得闪烁挤压 | 删除“本地处理 · 隐私优先”，原位置改为固定最小高度的任务槽，导航区域可独立收缩 | 真实视频发布截图观察 |
| 滚动条应与整体风格一致 | 特殊压缩列表复用 5 px 低对比度滚动条，仅悬停时使用强调色 | 真实图片、视频、PDF 工作区观察 |
| 压缩中心全局设置过大、配置组滚动条老旧 | 全局设置使用 736 px 紧凑两列布局；配置组限制为 736×576，标题固定、内容独立滚动，隐藏原生滚动箭头 | 浅色与深色真实 Tauri 截图、尺寸和样式断言 |

## 真实验证记录

- Windows Release Tauri 壳门禁通过：`decorations=false`、`resizable=true`、3 个窗口按钮、无重复标题、无隐私文案、8 个缩放热区且真实东南缩放增量为 40×30；归档全局设置、配置组和 3 个特殊压缩弹窗均紧凑，PDF 设置未泄漏到主界面、无冗余 PDF 提示、纵横溢出均为 0；预期与实际差异为 0。
- 压缩中心实测全局设置为 736×399.5、配置组为 736×576；配置组关闭动作成功，标题在浅色主题为 `rgba(15, 23, 42, 1)`、深色主题为 `rgba(248, 250, 252, 1)`，均与内容文字一致；深色背景为 `rgba(25, 29, 40, 1)`。
- 真实视频门禁通过：包含 10 分钟和 114,842,332 B 视频矩阵、折叠摘要、展开详情、取消清理、2 个输出发布、全局任务分类、完整重启与默认播放器。
- 真实图片门禁通过：JPEG、PNG、WebP 的真实编码、结果、历史、任务监控与拒绝边界均通过。
- 真实 PDF 门禁通过：13 个 PDF 样本、取消、批量执行、重启恢复、默认阅读器与任务监控均通过。
- 前端完整单元测试为 49 文件、283/283 通过；版本身份、媒体架构、类型检查与生产前端构建通过。主 Rust Release 核心库 384/384 通过（10 项显式忽略），其余集成矩阵通过；主库和 Shell 扩展严格 Clippy 零告警，Shell 扩展 5/5 通过。
- 最终正式无测试桥 NSIS 已重新生成；真实 `v1.2.3 → v1.2.4 → 卸载 → v1.2.3` 安装生命周期 50/50 通过，覆盖版本/DLL 身份、17 项经典菜单、两套用户数据保持和原安装恢复。证据位于被忽略的 `test-results/installed-release-validation/20260902-165836/result.json`。
- Playwright 首轮 55 项中 39 通过、15 条件跳过，Firefox 最后一项完成后浏览器清理超时；Firefox 项目隔离复跑为 6 通过、5 条件跳过、0 失败。清理超时不记作全量一次通过。
