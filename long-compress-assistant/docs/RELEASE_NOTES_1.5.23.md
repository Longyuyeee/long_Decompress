# Long解压 v1.5.23

LZMA 单文件也能拆成数字分卷，收到完整卷组后，从任意一卷查看、预览和提取。

- **LZMA 数字分卷创建**：压缩中心开放 `.lzma.001`、`.002` 等分卷，复用已有原生编码器；批量弹窗保留分卷设置，界面说明如何分享给其他软件。
- **查看和提取接通**：首卷、中卷、尾卷统一进入浏览、文本/图片预览、检查和提取；大文件浏览沿用读取预算，不必先完整解压才能看文件入口。
- **转换与结果贯通**：新增单文件 LZMA 转换目标，可将密码 ZIP 中的一个顶层普通文件转成 LZMA 分卷，也可将完整 LZMA 卷组转为密码 ZIP。来源保留，结果从原入口定位。
- **问题原因更清楚**：截断、解码失败和未识别尾随内容不会当作完整；缺卷恢复后沿原入口创建新任务，保留旧失败历史。体积分析按实际 LZMA-alone 编码抽样，能力表不再把原生创建标为依赖 7-Zip。

单条展开、多选弹窗、自然配置继承、左右等宽及窄窗滚动保持。LZMA-alone 是单文件压缩流，本身不提供密码或 CRC；流检查不代替独立摘要核对。密码需求保留既有 7Z 替代；TAR.LZMA 与对应 Long AES 组合按下一版规划推进。数字切卷需集齐全部成员，其他软件不能打开卷组时可按序合并成完整 `.lzma` 文件。
