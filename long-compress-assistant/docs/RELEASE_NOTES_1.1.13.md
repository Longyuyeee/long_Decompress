# Long解压 v1.1.13

v1.1.13 是解压主流程可信度修复版本，重点解决密码尝试、真实进度、RAR 正确密码、事务暂存、文件冲突、容量预检与历史审计之间的不一致。

## 主要更新

- 密码保险箱、导入词表和内置字典尝试期间，解压百分比保持 0；真实引擎开始写出内容后才按实际产出字节更新。
- 移除 RAR 密码验证的固定短超时，避免大文件首项 CRC 校验仍在进行时把正确密码判错；密码不匹配、归档损坏和验证器异常分别处理。
- `.long-extract-*` 事务目录创建后立即设置隐藏属性，完成或回滚后通知 Explorer 刷新，减少已删除暂存目录残留在视图中的错觉。
- 冲突弹窗支持逐文件覆盖、跳过和重命名；确认时直接提交已完成的同一份暂存，不再取消并从头解压。
- Windows 存储预检增加原生 Win32 卷查询，不存在的输出子目录也会回溯到最近已存在父目录。
- 新任务历史保存后端实际识别格式；长密码候选日志保留阶段、警告、终态和均匀样本，不被最后 200 条尝试淹没。

## 实际验证

- 固定 libarchive 官方加密 RAR：错误密码无明文输出，正确密码成功解压，两个文件 SHA-256 与固定预期一致。
- 真实 Windows Tauri/WebView2：资源预检、归档闭环、历史重启持久化、保险箱当天命中和加密 RAR 五组聚焦门禁通过。
- 前端 37 个测试文件、218 项通过；Rust 全目标 373 项通过、7 项按设计忽略；Clippy 零警告。

## 边界

- RAR 解压和密码解压使用随程序提供的能力；创建 RAR 仍需要用户选择安装 WinRAR/Rar.exe，或改用原生支持的 7Z。
- 公开无商业 Authenticode 签名的构建不分发 Windows 11 第一层菜单身份包，经典“显示更多选项”菜单保持支持。
- 当前开发机无法完成有效的 Microsoft Defender 扫描，因此不把该项描述为已通过。
