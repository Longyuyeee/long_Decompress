# Long解压 v1.4.9

这版让批量检查修复更方便接着处理，并改善 RAR 密码兼容和大文件检查的取消体验。单条展开、多选弹窗的操作方式保持。

## 检查修复不用切页就重来

- 切到历史或其他页面再回来，本批压缩包、检查结果和各自配置继续保留，正在处理的批次不会因切页被清空。
- 关闭后重新打开软件，在文件完整性页面选择“恢复工作区”，继续处理上次的检查修复记录；也可以丢弃记录。不会自动执行检查、修复或解压。
- 恢复文件和再次解压的目录设置、已恢复结果位置继续保留。密码不写入草稿，加密恢复结果会提示单独重新填写密码。
- 上次的检查报告明确标记仅供参考，需重新检查当前文件后才能据此修复；结果已移动、删除或缺卷时，就近显示原因，可重新检查修复原包。
- 恢复结果可以继续统一入队，避免重复添加；“清空本批记录”只清理工作区记录，不删除原包或恢复文件。

## RAR 兼容与响应

- 修正修复/恢复卷命令通过管道读取密码时的 ANSI/OEM 编码不一致，减少部分 Windows 环境中正确密码被误读的情况。
- RAR 大文件完整性检查可在文件数据处理期间响应取消，不必等待整个大文件检查结束；主动停止不会被标为损坏或密码错误。

## 使用范围

RAR 创建、修复及恢复卷生成仍需要本机 WinRAR/Rar.exe。工具输入字符集无法表示的密码仍会明确提示，不承诺任意 Unicode 密码的管道传递或未经验证的 RAR4 恢复特性。

本版不增加新格式，也不扩大 ZIP 任意缺卷、未知文件边界的救援承诺。“部分恢复”不代表原包全部内容都已找回，原包保持不变。
