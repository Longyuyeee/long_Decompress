# v1.6.39 · 密码 Deflate64 图文直接看

Deflate64 非固实 7Z 的小文本和图片，现在在密码包中也能直接预览，继续沿用原双栏浏览器和阅读窗口。

- 支持内容加密、文件名加密，以及完整数字分卷；可从非首卷进入。
- 继续使用手动密码或密码保险箱，明确输入的错误密码不会被其他候选悄悄替代。
- 完整文本最多 1 MiB、图片最多 8 MiB，原编码识别/滚动、连续阅读、翻页/缩放、跳过坏图、定位和仅提取当前页贯通。
- 完整检查压缩流结束、实际消费、加密填充与可用 CRC；取消、来源变化和缺卷处理保留，不凭预览记录整包密码成功。

固实包、大文件或其他未支持组合仍可提取后打开。保留单条展开、多选弹窗、等宽双栏、主题/工具/快捷键；范围说明放原问号，格式数及依赖不变。下一阶段先接通普通固实 Deflate64 的完整小图文。
