# Long解压 v1.4.20

本版聚焦 ZIP 缺卷和损坏后的部分抢救，让你看清哪些文件救回了、哪些没有，以及为什么。

## 改进

- 扩展好压论坛 ZIP 的部分抢救：当首卷或中卷缺失、终卷目录仍完整可读时，可以把其余卷中完整且校验通过的文件另存为新包。不需要改名原始 `.haozipNN.zip`，从现有任意成员都能进入。
- 单项和批量结果按“已恢复、涉及缺卷、校验失败、无法确认”分组，默认收起，点击查看文件与原因。未恢复文件数量与未知目录尾部分开说明，不把说明条数当文件数。
- 损坏文件不写进抢救结果；本地文件头可读取但目录已丢失时，明确提醒原包总文件清单未知，不把未知内容说成已全部恢复。
- 恢复副本可沿用原任务的密码和输出设置继续解压；原失败记录和原卷保留。补齐缺失原卷后仍可完整解压原包。

## 使用边界

好压原卷实测为 6.5.3.11255 的 ZipCrypto 论坛 ZIP；不据此外推暂无真实原卷的 AES 论坛 ZIP。缺终卷、目录涉及缺卷、未知卷长度或加密条目边界仍不能猜测恢复。普通解压仍要求完整卷组；抢救是尽量救回可验证文件，不保证修好整个压缩包。

已有标准 ZIP/ZIPX、7Z、RAR4/RAR5 及媒体能力保持；智能目录和 ZIP 并行仍默认关闭，不恢复快速打包。

验证及准确发布状态见 [实施审计](ZIP_PARTIAL_RESCUE_1.4.20.md)和[封板记录](ZIP_PARTIAL_RESCUE_FREEZE_1.4.20.md)。下一版按既定路线进入 v1.5.0 ZPAQ 浏览、原生密码读取与转换。
