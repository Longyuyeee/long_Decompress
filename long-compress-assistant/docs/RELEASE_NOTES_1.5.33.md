# Long解压 v1.5.33

WIM 新增 LZMS 非固实创建，为希望进一步尝试压缩体积的用户提供一个选择。

- **沿原方法选择加入 LZMS**：保留仅存储、XPRESS 和 LZX，旧任务默认与已有选择不变。固定小块与单线程，避免使用大块固实设置；强度滑块继续停用。
- **设置跟随任务**：单条展开、多选弹窗、配置组/模板、预设、草稿和历史再次执行保留 LZMS，混合任务仍使用各自方法，不自动执行恢复的草稿。
- **创建与转换接通**：文件、目录和密码原包可生成 LZMS WIM 数字卷；从任意成员继续浏览、预览、检查、所选/完整提取，也能转换为新密码 ZIP。补卷后新建任务，结果入口沿原流程。
- **选择更顺手，过程保持**：转换时 WIM 方法与目标格式并排，减少寻找与滚动；左右等宽、窄窗滚动、暂停/继续、取消、源数据与完成统计保持一致。

LZMS 通常更耗时，旧工具兼容性少于传统 WIM 方法；实际效果随内容变化，不保证总比 LZX 更小。本版提供非固实、单镜像内容归档，不是固实 ESD 或系统部署功能。WIM 没有原生密码，数字卷需集齐；不提供原生 SWM 创建或完整 Windows 权限元数据备份。
