# v1.6.5 · ALZ Bzip2 检查更可靠

修复 ALZ Bzip2 内容已经解出、但压缩流缺少结束标记或尾部夹入额外数据时仍被当作完整成功的问题。

- **检查、解压和转换保持一致**：必须确认真实结束标记及声明压缩范围；完整字节的尾随数据拒绝，正常的不足一字节对齐保留。失败不会发布半成品。
- **失败原因更清楚**：完整内容的大小和 CRC 均匹配后，明确提示原包不完整或损坏，并引导重新获取完整来源；不再把这种确定异常当作反复试密码的理由。只有短密码头匹配或内容未匹配时仍保留不确定原因。
- **沿原流程继续处理**：保留所选文件提取、单条展开、多选弹窗、左右等宽、失败后新建任务和历史原因。没有新增常驻说明区或改变操作方式。

本版不增加格式数量。ALZ Bzip2 的单条 256 MiB 压缩输入上限保持，方法 3 与 EGG 加密固实仍待真实来源，不宣称已经实现。

原件来自此前固定的 CC0 ALZip 样本；尾随、缺结束标记、密码及卷组的故障输入明确标为受控派生，不作为原工具组合互通证据。详见 [本版范围与记录](https://github.com/Longyuyeee/long_Decompress/blob/v1.6.5/long-compress-assistant/docs/ALZ_BZIP2_INTEGRITY_FREEZE_1.6.5.md)。
