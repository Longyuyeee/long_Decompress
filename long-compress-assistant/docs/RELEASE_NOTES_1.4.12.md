# Long解压 v1.4.12

> 候选版说明：本版功能与实际界面已收口，普通安装包以最终 PR 的 Windows package 结果为准，尚未正式发布。当前正式下载仍为 [v1.4.11](https://github.com/Longyuyeee/long_Decompress/releases/tag/v1.4.11)，见 [实施记录](LZIP_AND_TAR_LZIP_1.4.12.md)及 [封板记录](LZIP_AND_TAR_LZIP_FREEZE_1.4.12.md)。

收到 `.lz`、`.tar.lz` 或 `.tlz` 文件后，可以从熟悉的入口浏览、解压、检查和转换；创建新包也可以选择 LZIP 或 TAR.LZIP。单条点击展开、多选弹窗配置保持原来的方式。

## 更多格式，沿用原来的操作

- LZIP 用于压缩单个文件；目录或多个文件可选择 TAR.LZIP，保留中文路径、空文件和空目录。
- `.tar.lz` 和 `.tlz` 按同一种 TAR.LZIP 处理，支持浏览目录、文本预览与所选内容解压。
- 支持读取连续多成员 LZIP，按原有文件名还原到同一个文件。
- 新格式使用内置编解码器，无须另外安装 LZIP 程序。

## 创建、转换与批量配置

- 压缩中心可直接选择 LZIP / TAR.LZIP，沿用压缩强度、保存目录和结果位置。
- TAR.LZIP 可与已有归档格式互相转换；有密码的原包可以填写密码后转换成普通 TAR.LZIP，原包保持。
- 多选压缩任务可在原有弹窗中统一改为 TAR.LZIP；批量转换也可统一调整新包格式。
- LZIP / TAR.LZIP 不提供密码或分卷创建，界面显示实际可用的选项。清理不适用的旧设置时，输出仍保持用户选择的格式。
- 仅打开有效的行内配置不会将任务变成独立配置，保留原来的全局设置继承方式。

## 损坏文件说明

读取到压缩流结束后核对内容及长度；损坏、截断或校验失败会结束本次任务，避免把残缺结果显示为成功。失败时沿用现有原因提示、原件保留和结果入口。

浏览失败的中文原因会保留在当前页面，重新读取时清除；LZIP 校验失败与文件不完整分别说明，便于判断是否需要重新获取文件。

本版范围为 LZIP v1 的单/多成员和 TAR.LZIP，不新增原生密码、原生分卷、LZIP 损坏数据修复或其他下一版格式。现有单条展开、多选弹窗、等宽详情和小窗口滚动方式保持。
