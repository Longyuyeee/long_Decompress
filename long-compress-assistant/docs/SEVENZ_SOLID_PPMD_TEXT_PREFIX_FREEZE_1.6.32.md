# v1.6.32 · 固实 PPMd 大日志开头预览

## 完成范围

按[路线](ARCHIVE_ROADMAP_1.6.32.md)接通普通和 AES 密码固实 PPMd7/PPMdH 7Z 的大文本前 1 MiB。只扩展既有 read_solid_entry_prefix 的 PPMd 允许范围，沿 archive 顺序确认所选唯一普通文件、共享映射/条数/大小、单打包流和单 PPMd 或有序 AES → PPMd；前置内容与所选开头合计 ≤64 MiB，按块丢弃前置，仅保留所选开头。沿已有显式 PPMd 前缀构造的阶数 2～64、字典 2048 字节～64 MiB 限制，不额外解符号，不用未读共享尾部的 CRC/结束描述部分结果。

原手动密码/保险箱、内容/文件名加密和完整数字卷接通，手动错误不回退，预览不记整包密码成功。部分载荷沿 PreviewAes::new_prefix，完整目录头等已创建的完整 AES 流仍必须完成消费；实际元数据/载荷合计 ≤64 MiB、候选整体 30 秒、取消和来源前后绑定保持。声明共享总量大于 64 MiB 时，可达的早期开头仍可读，超出前置范围给提取下一步，声明总量不作为缓冲分配量。

文本沿原编码/截断、滚动、“部分内容 / 未校验整文件”及提取入口；精确 1 MiB 仍完整读取。普通/密码完整小文本和图片的 PPMd finish/CRC/压缩消费保持独立路径，LZMA/LZMA2 路径不变。仅更新原问号说明，单条展开、多选弹窗、50/50 双栏、主题、工具和快捷键保持，无新增依赖、许可或格式计数变化。

## 本版必要检查

原版 7-Zip 26.02 生成普通、AES 内容加密、文件名加密（阶数 12/16 MiB）及完整数字卷四组固实 PPMd 原件，包内官方 26.04 独立逐文件回解 SHA-256，列表确认 Solid + / Blocks 1 / PPMd。包含首个/后续所选、方括号相邻路径、空项、精确 1 MiB/刚超出、五种编码和二进制。另有原版 65 MiB 共享大日志与不可达后续文本，独立回解；普通/密码未读尾部受控损坏，经独立工具确认完整性失败，并另有开头损坏。原件/哈希与生成命令见 tests/fixtures/archives/sevenz-solid-ppmd-text-prefix-1632/manifest.json，脚本重跑保留已提交原件。

两项新增接通单元通过：短读只保留共享所选前缀，不假称未读 CRC/PPMd 结束；部分结果不豁免已创建完整 AES 消费回执，参数/映射、共享范围和跳过期间取消保持。六组后端通过：四组/每个卷成员、首个/后续/精确边界与五种编码；保险箱、手动错误和计数；映射/AES 对齐/短输出与跳过取消；65 MiB 总量与精确前置边界；普通/密码未读损坏尾部和完整 CRC/小文本区分、二进制/开头损坏；取消/来源/缺卷和新请求。因为通用共享前缀路径扩展，只补一项旧 LZMA2 连续性，不重复旧矩阵、完整 AES/PPMd 单元、安装或真实盘满。

类型/Vite、八处身份与新 Shell DLL 通过。四组实际 Tauri 桌面通过：文件名加密日志、原滚动/提取入口；普通/内容加密/非首卷、五种编码和大总量；损坏尾部部分读取而完整校验失败、二进制/错误密码、小文本与不可达提示；取消/来源/缺卷与新请求。1100×650、760×520 两张截图已实看，正文、关闭、提示与提取入口可见，无横向溢出，底层双栏等宽。候选 SHA-256 `405bd5083e59db98f89fe2682274fc5e6d28ae11d998489adcc9c98a152df04c`，见[证据](evidence/sevenz-solid-ppmd-text-prefix-1.6.32/checks.json)。桌面 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置不改；入口 node scripts/test-tauri-desktop.mjs --sevenz-solid-ppmd-text-prefix-1632-only。
