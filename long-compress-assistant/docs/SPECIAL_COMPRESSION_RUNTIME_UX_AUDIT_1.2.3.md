## 额外发现与修正

1. 图片列表看似存在 `overflow-y:auto` 仍不能滚动，根因是卡片参与 Flex 收缩；已在真实失败后增加 `flex: 0 0 auto`。
2. 视频/PDF 使用 Grid，需显式 `grid-auto-rows:max-content`，否则卡片内容同样被网格压缩；两者一并修正。
3. 旧桌面门禁仍从已迁移前的位置选择视频输出目录，并直接点击不可交互的隐藏复选框；已改为真实设置弹窗和可见标签路径。
4. 全局任务面板展开后会遮挡结果区；门禁核对类型后主动收起，产品交互本身保持可控。

## 接续点

本轮功能目标已关闭。发布后下一次开发应从最新 `master` 和公开 `v1.2.3` 拉取，不从本地 Release 二进制或旧 `v1.2.2` 分支接续。若继续改媒体策略，应保持“质量与分辨率独立”“真实探测事实不回退”“真实输出/取消/历史/默认应用”四条门禁。
