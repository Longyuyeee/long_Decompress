# Long解压 v1.5.39

增加固实 WIM 与 ESD 创建，让大量相似文件有新的归档选择，继续使用现有的分卷、转换、浏览和结果入口。

- **原位置选择固实归档**：WIM 方法增加“LZMS · 固实归档”；ESD 作为独立目标格式，固定使用真实 LZMS 固实，旧 WIM 默认存储及 XPRESS、非固实 LZX/LZMS 保留。
- **分卷和取回接通**：普通包与数字卷可浏览、预览、检查、提取和补卷后重试；多镜像按编号保留内容视图，统一结果显示整组产物。
- **原包与新包分别配置**：密码 ZIP 可以转换为固实 WIM/ESD，ESD 内容也可转为密码 ZIP。WIM/ESD 没有原生密码，数字切片需集齐整组，和原生 SWM 不同。
- **工作接续与布局保持**：方法跟随配置组、模板、草稿、历史和多选配置；保持单条展开、多选弹窗、自然继承、左右等宽及窄窗滚动。

固实模式把多个文件一起压缩，编码更耗时和内存，当前单线程预算约 640 MiB；只取单个文件也可能读取同块内容。效果随资料变化，接收方需要支持固实 WIM/ESD。创建是单镜像内容归档，不保证系统部署或完整 Windows 权限元数据。
