# Long解压 v1.5.6

本版改善 RAR 解压的真实进度、暂停后的速度和耗时，并修复同目录统计及停止任务的显示问题。

## 修复与改进

- RAR 进度改用 UnRAR 实际解码块的字节数，不再把预分配文件长度当作已经解压；不增加第二次全包读取。
- 首次解码及时显示，暂停时刷新最后已解码累计。速度、剩余时间与本次新任务的历史耗时扣除暂停区间，恢复后不再被长时间暂停拉低。
- 解压到已有目录或压缩包同目录时，只统计本次实际发布的文件，不把原压缩卷、旧文件、跳过项和覆盖备份算入产出。
- 修复在解压中心点击停止后，底层正常取消却被页面改写成失败的问题；暂停中的停止仍清理暂存，不发布半成品并保留原卷。
- 防止迟到的速度/剩余时间和暂停响应改写已暂停或已结束的任务。

## 支持范围

沿用 v1.5.5 的 RAR4/5、已验证密码、原生卷和 SFX 只读能力，不新增 RAR 编码器或扩大 SFX 模块承诺。解码字节不等于写入、CRC 或事务提交成功；完成状态仍由实际提交结果决定，损坏不能因字节读满而报成功。

历史旧记录不追改；新任务历史保留真实开始/结束时间，耗时扣除暂停。智能目录与 ZIP 并行保持默认关闭，Windows N 暂不保证支持。详见[实施审计](RAR_PROGRESS_1.5.6.md)和[封板记录](RAR_PROGRESS_FREEZE_1.5.6.md)。
