## 2. 本节点新增负向矩阵

- 产品 FFmpeg 非零退出：稳定 `ProcessFailed`，无最终输出、无 `.video-encode-*`。
- 编码后输出被清零：稳定 `VIDEO_OUTPUT_EMPTY`，drop 后无暂存。
- 验证后源文件追加字节：稳定 `VIDEO_PUBLISH_SOURCE_CHANGED`，无最终输出、无暂存。
- 既有 C-04.1/C-04.2 继续覆盖截断、暂存大小变化、取消、Mark-of-the-Web 和目标竞态。
