# v1.6.26 · 加密固实大文本开头

## 完成范围

按[路线](ARCHIVE_ROADMAP_1.6.26.md)接通 AES + LZMA/LZMA2 固实包中准确所选大文本前 1 MiB。沿 v1.6.25 的共享数量/大小/顺序映射与前置跳过，增加已确认的 AES → LZMA/LZMA2 方法顺序、单打包流/单进出形状及 AES 明文/密文对齐长度检查。前置输出与显示开头合计 ≤64 MiB、元数据/载荷实际输入合计 ≤64 MiB、字典/解码头范围与候选整体 30 秒保持；只留所选前缀，不创建临时整包，不读无关块。共享总量超过 64 MiB 时，靠前且在前置范围内的大文本仍可部分阅读。

read_solid_entry_prefix 复用 v1.6.24 的明确部分 PreviewAes::new_prefix，CBC 的对齐/短读取、KDF 参数范围和取消/截止保持。部分载荷不注册完整消费回执，不声称验证前置或未读尾部、完整 AES 填充/消费、整文件 CRC 或整包密码。若实际读到 AES 末端，原填充/额外字节检查仍执行；元数据和完整小文本/图片继续注册并强制完整消费，原共享大小/CRC/压缩覆盖/真实编码结束不改，不全局关闭条件。普通与非固实密码前缀保持原路径。

原手动密码不回退，留空沿原保险箱对所选依赖有界尝试；内容/文件名加密与完整数字卷有效成员贯通，不记完整密码成功或使用次数。部分数据和密码/损坏不能确定时保留原下一步；短输出、二进制、未知组合、映射或前置范围超限不冒称有效正文。原弹层明确“部分内容 · 未校验整文件”、已读/声明大小、滚动与“提取后打开”，帮助收在原问号。来源前后绑定、关闭取消和迟到丢弃保持；不改变单条展开、多选弹窗、等宽双栏、工具/主题/快捷键和格式数量。

## 必要检查与来源

四组原版 7-Zip 26.02 AES 固实样本：LZMA、LZMA2、文件名加密、文件名加密数字卷。官方 26.04 独立回解逐文件 SHA-256 核对，列表确认 Solid + / Blocks 1。覆盖首个/后续大文本、相邻名称、空目录/空项、五种编码边界和二进制。共享总量超过 64 MiB 的原版 AES 样本同样独立回解；密文开头/尾部损坏明确为受控修改，映射/大小/AES 长度/CRC 变更为内存负例，不冒充自然损坏原件。见 tests/fixtures/archives/sevenz-encrypted-solid-text-prefix-1626/manifest.json。

六项后端、三项前端通过：原件两方法、文件名加密和每个卷成员、首个/后续与相邻文件、五种编码边界、保险箱错误候选后成功/手动不回退/不记整包成功、映射/AES 对齐/短输出/前置取消、范围准确边界/大共享总量、部分尾部与完整共享 CRC/结束失败、二进制/取消/来源/缺卷和新请求。完整小文本保留完整条件；原 AES 流实现与完整消费作用域未改，不重复已过且未受影响的旧 AES 单元、算法/密码/卷矩阵、安装和真实盘满。移除已被本版取代的“加密固实大文本不支持”旧负例。

四组实际 Tauri 桌面通过：保险箱打开文件名加密的准确所选大日志，在原双栏内显示部分且可滚动；两方法/首个/非首卷、五种编码及 65 MiB 共享前部可读；损坏尾部部分可读而完整检查失败、错误手动密码、二进制/前置超限下一步；取消/来源/缺卷与新请求。1100×650 和 760×520 CSS 截图已实看，正文/部分提示/关闭/全文按钮可见，无横向溢出，底层双栏等宽。候选 SHA-256 `92a92e6aa2b0c60438cde8e4a7ca9fb252d1cec85423fd85dcd7cfe91acad796`，见[证据](evidence/sevenz-encrypted-solid-text-prefix-1.6.26/checks.json)。前端类型/Vite 构建、八处版本身份和 Shell DLL 通过。桌面候选 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置不改；入口 node scripts/test-tauri-desktop.mjs --sevenz-encrypted-solid-text-prefix-1626-only。
