# v1.6.49 · 7Z 仅归档与低收益建议

## 已完成

按[本版路线](ARCHIVE_ROADMAP_1.6.49.md)，在原 7Z 方法字段加入「仅归档（Copy）」，直接打包数据，不重复编码，适合已压缩的图片、视频和资料。默认继续 LZMA2，旧强度 0 不会被改成 Copy；原单条行内展开/编辑后自动独立、多选弹窗、等宽两列、主题/工具/快捷键保持。单条、全局与转换中选 Copy 后收起不适用的强度，切回时保留原值；多选明确指定 7Z Copy 时收起强度并不提交该字段，混合格式仍保留各自处理。

Copy coder 原样转发字节，终止空写明确结束后续计数/AES 并刷新；终止错误直接返回且保持失败状态，不依赖 fallible Drop。接通内容/文件名密码、固实/非固实、完整数字卷、取消、冲突、进度、日志和结果入口。预设/配置组/便携模板、草稿、历史和工作流保留方法，源包读取与目标方法分开。没有新增依赖或格式计数。

体积分析按真实 Copy 编码抽样，预计数据比例至少 1，既有扩展名经验权重不再制造 Copy 的压缩收益，耗时估算也不受保留的强度影响。原压缩方法实际内容样本至少 4 KiB，且压缩收益不足 2% 时，在原分析结果中给出仅归档建议；不只看文件后缀，不自动改设置。用户点击才只改当前任务的方法，保留强度、密码、固实、分卷与全局默认；旧结果随方法变化失效。说明收进问号，主页面不增加常驻大区块；Copy 不再展示建议切换到另一种格式的泛用推荐。

## 一并修复的空项与 CRC 边界

首次独立回解 Copy 普通包发现空文件的 CRC 为 0，使 PackInfo 进入部分校验值分支：原代码写了定义位图却漏写被标记的非零校验值，独立工具报 Headers Error。现补写对应校验值。另修复单子流固实包对合法 CRC 0 的处理：子流继承已定义的文件夹 CRC，不再因值为 0 而重复写入。非零 CRC 的原路径保持；元数据格式正确后，Copy 空流、仅空项固实和 CRC 0 非空内容均可读取。
