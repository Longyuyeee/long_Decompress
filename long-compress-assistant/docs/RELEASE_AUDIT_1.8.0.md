# v1.8.0 封板核对

本版将 v1.7.41 候选阶段的菜单和界面维护统一收尾为 v1.8.0。相关实现来自 PR #368；正式发布由合并后的 `v1.8.0` 标签和 Release 工作流生成安装器、签名更新包及更新清单。

## 经典右键目录

面向 Windows 文件资源管理器“显示更多选项 → Long解压”。单一分类提供器同时覆盖通用与类型关联，避免同名小菜单和完整菜单并存；按可执行叶子计数，不将分组标题算作功能。

| 所选内容 | 分类与命令数 |
| --- | --- |
| 普通文件 | 五项压缩、生成校验清单，共 6 项 |
| 文件夹 | ZIP、7Z、自定义、加密、分卷压缩，共 5 项 |
| 压缩包 | 浏览、三种解压；压缩打包 5 项；更多操作 4 项；生成清单，共 14 项 |
| JPG/JPEG/PNG/WebP | 图片压缩、WebP、缩小尺寸；压缩打包 5 项；生成清单，共 9 项 |
| SFV/MD5/SHA256 清单 | 核对清单；压缩打包 5 项；生成清单，共 7 项 |

真实 Shell 检查调用 `SHCreateDefaultContextMenu`、版本独立扩展 DLL 和独立原生参数接收器，覆盖唯一根、分组、全部 41 次叶子派发、标签与 CLI 对应、中文及空格路径和旧目标拒绝。注册树、COM 工厂和预定义键映射限制在测试进程及自有临时树中，不控制桌面、不修改真实关联。

## 最近修改复核

- 长路径网格和文字列可收缩，四种打开方式保留；弹窗尺寸有视口上限，中间滚动，关闭和底部选择固定。v1.8.0 紧凑窗口重新打开询问弹窗及默认格式弹窗，验证路径、图标、四个选项、取消目录选择和底部操作。
- 删除解压重复运行汇总，压缩和解压批量结果集中在“成功结果”；失败处理和结果目录失效提示保留。
- 历史页移除多选勾选、所选项状态及批量重做组件，单条详情、再次执行、结果菜单、筛选及统计保留。
- 减少动画偏移修复纳入本版，检查全局选择器作用范围，沿用已通过的开启、关闭及保存恢复记录。

已有检查按范围复用：菜单相关 49 项前端、6 项 COM/19 个参数接收；弹窗 15 项行为与五组尺寸/DPR/缩放；列表 4 项视图及两个页面场景；历史 18 项视图及 920/760 窗口场景；#366 的 23 项相关单元及四个场景。记录见[菜单审计](EXPLORER_MENU_AUDIT_1.7.41.md)、[弹窗修复](DIALOG_RESPONSIVE_FIX_1.7.41.md)、[减少动画修复](REDUCED_MOTION_FIX_366.md)和开发交接。没有重复执行格式与媒体矩阵。

本次菜单核对验证 Shell 派发与输入参数，压缩/图片/修复引擎沿用已有检查；Windows 11 第一层原生签名部署和完整安装/升级矩阵未重跑。公开包完整经典菜单的入口已在 README 和 Release 说明写明。

八处版本身份统一为 1.8.0，随包扩展为 `long_compress_shell_extension_1_8_0.dll`。README 仍以功能介绍为主，末尾仅保留最近五个正式版本。原 XZ 兼容规划改为 [v1.8.1](ARCHIVE_ROADMAP_1.8.1.md)，尚未开发。
