# Long解压 v1.4.10

这版集中改善 ZIP 按需解压：只取所选内容，不再被包里其他文件的密码挡住；补强旧 ZIP 方法和密码分卷的兼容，保持已有压缩默认值。

## 只解压需要的内容

- 混合 ZIP 中只选公开文件，无需填写其他加密文件的密码。
- 同一个 ZIP 内的文件使用不同密码时，可以只选其中一部分，用相应密码提取；密码保险箱也按本次选择范围匹配。全包解压仍要求能读取所有应处理的内容。
- 条目选择、文件筛选、容量估算和实际读取保持一致；中文目录、文件夹选择、数字卷及标准 ZIP 多卷使用相同的选择逻辑。
- ZIP 浏览目录不先尝试整包密码；预览、打开单个文件及进入嵌套包的密码查找只针对所选条目。
- 不支持的所选压缩方法明确说明，不作为损坏或错密码处理。输入错误密码后可以改正继续，原失败记录仍保留。

## 格式与分卷兼容

- 补上原生 ZIP 的 Shrink、Reduce、Implode 旧方法读取，固定样本覆盖 Shrink、Reduce factor 4 和 Implode；不宣称支持全部旧工具密码变体。
- 补充 Zstandard ZIP 的 AES-256 / ZipCrypto 密码读取与单包、数字卷、标准 `.z01/…/.zip` 卷组回解证据。
- 补充真实超过 4 GiB 文件的 AES-256 / ZipCrypto ZIP64 数字分卷读取，检查大文件内容以及大文件之后的条目。

## 页面细节

“返回双栏文件浏览器”并入压缩包浏览页标题操作区，修正小窗口滚动时遮住搜索区域的问题；窄窗口仍可滚动到解压按钮。

## 使用边界

本版没有新增 ZIPX 创建方法，也不代表支持所有 ZIPX 专有算法或全部 ZIP64 密码/卷型组合。缺卷和未知边界的救援范围不变。RAR 创建、修复和恢复卷仍需要本机 WinRAR/Rar.exe；Windows N 暂不保证支持。

安装器及签名自动更新附件以本 Release 实际内容为准。后续从 v1.4.11 的自解压包读取及特殊卷型继续，完整路线见仓库文档。
