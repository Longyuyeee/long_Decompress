# v1.6.9 · ALZ 包内文本预览

查看 ALZ 里的说明、日志和配置文件时，现在可以直接在原双栏浏览器中预览，无需先提取到磁盘。

- **沿原入口查看**：双击、预览按钮、右键和 Ctrl+Enter 打开现有只读弹层，另一栏的位置与选择保留。
- **接通密码与分卷**：支持现有密码保险箱、手动密码、显式编码和完整原生卷组；只读取所选文本，不先解码无关大文件。
- **清楚的结果与接续**：完整小文本校验后显示；过大文件提示先提取。关闭预览取消读取，来源变化提示刷新，旧请求不会覆盖新预览。

本版支持 ALZ Store/Deflate/Bzip2 的常用文本，单条完整内容不超过 1 MiB，压缩输入不超过 64 MiB。保留单条展开、多选弹窗和左右等宽布局，不增加常驻配置区。

ALZ 图片和大文本前缀尚未开放，分别继续分阶段推进；本版不增加格式数量、ALZ 创建/修复、方法 3 或 EGG 加密固实支持。实际密码/原生卷依据来自原 ALZip Deflate，Bzip2 使用既有原小包，不外推全部历史组合。详见[本版范围与记录](https://github.com/Longyuyeee/long_Decompress/blob/master/long-compress-assistant/docs/ALZ_TEXT_PREVIEW_FREEZE_1.6.9.md)。
