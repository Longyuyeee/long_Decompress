# v1.5.44～v1.5.49：五个功能模块与格式兼容主线回归

2026-10-21，基于已正式发布的 v1.5.39。用户已选定压缩包编辑工作区、归档资源库与跨包搜索、自动化工作流中心、文件夹与压缩包对比、整包图片阅读五个方向，要求先按版本完成，再回到更多算法、更多格式和容错兼容主线。

本文为已批准的开发顺序与范围，所有新增版本均处于规划状态，尚未开始运行时开发；版本号表示推进顺序，不承诺发布日期。本次只更新并推送文档，不修改应用版本、不发布安装包。

## 总体顺序

1. 按[既定 v1.5.40～v1.5.43 排期](ARCHIVE_ROADMAP_1.5.40_TO_1.5.43.md)完成原生 SWM、用途配置、失败纠正与批处理结果体验。
2. v1.5.44～v1.5.48 按下表完成五个模块，复用现有浏览、任务、配置、密码保险箱、草稿和结果能力。
3. v1.5.49 起恢复更多格式/算法与容错兼容主线。当前格式阶段收尾是阶段切换，不是长期停止格式扩展。

模块开发期间，已支持功能的严重阻断问题发现后优先修复；性能沿实际使用路径持续改进。新的格式与算法专题留在回归阶段，不反复插队替换已选定模块。

## v1.5.44：压缩包编辑工作区

典型场景：收到项目 ZIP 后，替换说明文档、补入图片、去掉旧文件，直接得到新的交付包。

- 在现有归档浏览器提供添加/拖入、替换、删除与重命名操作，清楚展示包内目标位置；目录调整连同子项一起展示影响。
- 修改先进入待保存列表，可撤销、放弃或统一保存；默认另存新包，原件和既有结果保留。保存期间沿原进度、暂停/停止和结果机制，失败后仍可查看本次修改内容与继续处理。
- 首版优先 ZIP。普通/密码、压缩方法、文件名和密码编码按真实可读写能力接通；不能保留的参数在保存前就近说明，并提供适用的另存/转换选择，不静默换格式、清密码或丢内容。
- 编辑后的文件路径、内容和目录结构可在新包中重新浏览、预览与提取。7Z/RAR 等更多格式的直接编辑作为后续兼容扩展，不阻塞首版 ZIP 完整流程。

复用现有归档浏览、压缩写入、转换及结果组件。首版重点是包内内容编辑与另存；外部应用修改后自动回写、跨格式原地更新等进一步能力后续按真实需求评估。

## v1.5.45：归档资源库与跨包搜索

典型场景：用户知道某份说明或图片在下载过的资料里，但记不起具体压缩包名称。

- 用户主动添加归档或指定资料目录，建立本地目录索引；分卷组按一份归档展示，列出来源位置、格式、文件数量、状态和更新时间。
- 首版索引文件名、包内路径、大小和时间，提供标签、收藏、筛选和跨包搜索；命中结果同时显示所属归档，支持返回原位置、预览与提取。
- 复用当前实际可列目录的格式；密码包沿现有凭据机制解锁，缺卷、不可读或暂未建立索引的项目显示原因。多镜像/快照的来源与路径保持明确，不把不同来源的同名条目合并。
- 仅更新实际变化的归档，可暂停或重新建立索引；原包移动、移除或发生变化后显示实际状态，提供重新定位或刷新。

资源库围绕归档和包内文件组织，不替代现有任务历史。全文检索、OCR、云盘索引和全盘常驻扫描不纳入首版；先把本地文件名/路径检索、预览和取回贯通。

## v1.5.46：自动化工作流中心

典型场景：项目资料经过固定筛选后，按日期命名、压缩加密并保存到交付目录；用户保存一次方案后可以再次运行。

- 复用已有配置组、任务模板、监控目录与任务队列，提供顺序步骤编辑和常用模板，展示输入、步骤、输出以及每次运行的实际状态。
- 首版步骤聚焦已有的选源/规则筛选、解压、压缩/转换、输出命名与保存目录。每步输出可作为下一步输入，仍可从原任务与结果入口访问产物。
- 默认手动一键运行。用户明确启用后，可按指定时间或目录中稳定的新文件触发执行；旧的“监控后仅生成待确认草稿”继续保留原语义，不在升级后自动变为执行规则。
- 首版定时/监控执行以应用运行或托盘驻留为条件；重启后恢复规则，错过的运行时段显示状态并提供立即运行/跳过。退出后系统级唤醒另行评估，不伪称已经后台执行。
- 失败时定位到具体步骤，保留已完成结果，纠正输入、密码或目录后继续需要处理的部分；避免恢复时重新生成已成功产物。运行日志与历史复用现有结构。

不另建第二套任务或结果中心。首版不做通用可视化编程、任意脚本插件或复杂分支图；媒体处理步骤按已有接口逐步接入，不把所有图片/视频/PDF 工具同时串联作为首版前置。

## v1.5.47：文件夹与压缩包对比

典型场景：两份项目交付包名称相近，用户需要找出新增、改动、移除的文件，并取回自己需要的差异。

- 从现有文件/归档浏览器选择左右来源，首版覆盖文件夹↔文件夹、ZIP↔ZIP、文件夹↔ZIP；提供新增、内容候选、元数据变化、移除、相同及无法确认等清楚状态。
- 复用 ZPAQ 快照对比已有的展示与选择思路，保留其原有入口和快照语义。普通跨包/目录对比单独绑定来源，不把它冒充同一归档的历史。
- 可先按路径和元数据定位候选，再按用户选择核对实际内容；同大小、同时间不能直接认定内容相同，不以目录可列出代替内容可读。
- 搜索和筛选后，可分别从左右来源提取所选差异，沿原任务队列执行；希望生成新包时，在 v1.5.44 已支持的编辑范围内带入所选变更，明确目标、冲突与保存结果。
- 来源在对比期间变化、缺卷或凭据失效时保留已知信息并提示重新读取；不会自动扩大提取范围或变成整包操作。

首版不做自动删除同步、双向实时镜像或所有格式的直接合并写回。先完成准确对比、差异取回与 ZIP 编辑另存的完整用户流程，后续格式扩展回到主线评估。

## v1.5.48：整包图片阅读

典型场景：用户收到一包扫描件或设计素材，希望快速翻阅、挑选需要的图片，不反复打开和关闭单张预览。

- 沿现有归档图片预览扩展缩略图网格和阅读视图，支持包内路径/自然排序、上一张/下一张、键盘操作、全屏、缩放与适应窗口。
- 缩略图与原图按需读取，复用现有缓存及读取预算，保持界面可响应；大图、固实包或受限来源沿实际能力说明，不自动放宽全局限制。
- 阅读位置绑定到归档及包内条目，返回时回到原位置；来源变化时刷新条目，不继续引用失效索引。资源库搜索命中可以进入同一阅读视图。
- 多选图片后复用已有所选提取、压缩或转换入口，清楚保留来源与选择范围；密码、数字/原生分卷在已支持读取范围内沿用原机制。

首版以当前支持预览的图片与归档为范围。PDF 页面阅读、OCR、图片编辑器和新图片编解码器属于另外的候选，不作为本版完成条件。

## v1.5.49 起：恢复算法、格式与容错兼容主线

五个模块达到上述可用范围后，下一阶段重新以增加实际可用的算法/格式、补齐密码和分卷组合、改善异常情况下的取回与继续处理为主线。不能把某模块未承诺的全文搜索、所有格式编辑或复杂自动化当作无限延期回归的理由。

| 方向 | 回归后的推进方式 |
| --- | --- |
| 更多算法和格式 | ALZ 方法3、EGG 加密固实等重新进入候选；先确认正向来源和可实现能力，再决定具体版本，不以新增后缀替代真实支持 |
| 密码、卷型及互通 | 继续补已支持格式中的实际缺口，区分原生密码、自有加密包装、数字切片和原生多卷，兼顾现有编辑、搜索、对比与阅读流程 |
| 容错与部分取回 | 根据真实来源处理截断、目录异常、缺卷、编码及密码与数据错误区分；只取回有可靠依据的内容，保留未恢复原因与原失败记录 |
| ZPAQ 等专项 | 原生追加多部分、损坏事务等保留独立研究，按实际可行性纳入后续功能版，不直接承诺某个未知算法在 v1.5.49 完成 |
| 全流程和性能 | 接创建、读取、浏览、预览、转换、提取、结果与失败接续；沿真实等待和重复读写小步优化，不预设收益比例 |

v1.5.49 是恢复主线的首个版本位置，其具体格式/算法或兼容专题在启动时从研究池和真实问题中确定；用户收益、可复现来源、实现可行性和对当前流程的覆盖作为选题依据。相近的小增强合并在一个功能版，严重阻断问题不等待专题版本。

## 一直保留的产品与推进原则

- 用户视角优先：每版围绕一个能完成的实际任务，界面清楚、方便、美观；已有功能直接复用，避免重复建设。
- 单条任务点击行内展开，多选在原弹窗配置，自然继承，编辑后自动形成单条配置；现有左右等宽与窄窗滚动保持。图片阅读采用适合阅览的响应式布局，不挤压已有任务日志与结果。
- 索引、编辑、工作流、对比和阅读均接现有任务、草稿、历史及统一结果，不增加强制的全局/单独选择或每步必经弹窗。
- 各版开发前核对当前代码和已有能力，必要的定向检查与受影响的显示确认随改动完成；已通过且未受影响的检查复用，不重复旧全格式/密码矩阵、真实盘满或大量无关验收。
- README 继续以软件特点为主、版本变化放在末尾；完成后的中文 Release 写实际能力与用户收益，规划不当作已交付功能。
- 本次仅把用户选定的五个模块排入路线；备份中心、空间整理、PDF 页面管理、云服务等其他竞品建议仍为候选，未加入本轮版本。
