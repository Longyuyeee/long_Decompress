# Long解压 v1.2.0

v1.2.0 聚焦特殊压缩与双栏文件浏览器的空间利用和高频操作。底层压缩、解压与文件事务安全边界保持不变。

## 特殊压缩

- 新增 `Ctrl+Shift+S` 全局快捷键，并在左侧导航中明确展示。
- 图片、视频、PDF 三个模式 Tab 移到标题右侧，不再单独占用一整行。
- 图片和视频批量设置默认折叠；图片、视频与 PDF 空任务状态均限制在主工作卡片内，无需向下滚动。
- 添加任务后仍保留原批量设置、任务队列、取消、历史、容量预检、验证和原子发布能力。

## 双栏文件浏览器

- 每栏新增显式进入/退出多选模式；支持 `Ctrl+A` 全选、`Esc` 退出和 `F5` 刷新。
- 路径按盘符、UNC 或目录层级拆分，可直接点击任一级跳转。
- 左栏跨栏图标指向右侧，右栏指向左侧；菜单同时写明实际目标方向。
- 目录右键可在另一栏打开；空白区右键可同步当前目录、交换两栏、刷新、新建文件夹、全选或切换多选模式。

## 安全与验证

- 文件操作继续默认拒绝覆盖、拒绝重解析点和危险根目录操作；复制经过目标暂存与 BLAKE3 校验，跨卷移动先校验目标再删除源。
- 完整单元测试 276/276、Chromium 10/10、生产构建与隔离 Release Tauri + WebView2 均通过。
- 真实桌面 IPC 复制、移动和属性核验实际得到 2 个文件、2 个目录、9 字节，与预期完全一致；图片、视频、PDF 三种空态滚动差异均为 0。
