# Long解压 v1.5.34

常用 ZIP 新增 BZip2 方法，继续使用熟悉的压缩、密码和分卷流程。

- **原方法选择增加 BZip2**：默认仍为兼容 ZIP（Deflate），已有 Zstandard 和 ZIPX（XZ）不变。BZip2 有效强度为1–9，旧配置中的0按1执行；显示、体积分析和实际创建保持一致。
- **密码与卷型接通**：支持普通、AES-256、ZipCrypto，以及单包、数字卷和 .z01/…/.zip 标准卷。从任意成员继续浏览、预览、检查、所选/完整提取；补齐缺卷后可创建新任务。
- **转换与配置能够接续**：密码原包可以转为 BZip2 ZIP，也可把 BZip2 密码数字卷转成新密码归档。配置组/模板、预设、草稿和历史保留方法，多选修改只作用于适用的 ZIP 任务。
- **长路径分卷修正**：修复较长路径下，编码已完成却在提交数字分卷时提示“找不到路径”的问题。
- **选择更顺手**：转换时 ZIP 方法与目标格式并排，减少寻找与滚动；保留单条展开、多选弹窗、自然继承、左右等宽与窄窗滚动。

BZip2 ZIP 不是单独的 .bz2 文件，也不是所有系统内置解压器都支持。分享时请确认接收方支持对应方法、加密与卷型；压缩效果随文件内容变化，默认兼容 ZIP 不会自动切换。
