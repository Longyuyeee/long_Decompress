# Long解压 v1.1.15

v1.1.15 完成图片压缩首个正式版本，并同步收口密码数据保护、任务历史边界和媒体发布基础设施。图片能力复用既有任务、日志、取消、历史、容量预检与原子发布链，没有建立旁路任务系统。

## 主要更新

- 压缩中心新增图片工作区，支持 JPEG、PNG、WebP 输入、单项/批量设置、保持或转换格式、质量、缩放、元数据策略、重名策略、执行前原图预览和执行后结果对比。
- 图片执行使用真实生产编解码器：JPEG/WebP 走受限 `libcaesium` 能力，PNG 走无损 `oxipng`；输出发布前重新解码并核对格式、尺寸、方向、Alpha 与元数据。
- 每张图片进入统一 `compression/image` 任务、阶段日志、取消注册表和 SQLite 历史；完成、失败、取消及“不更小则保留”均以真实终态记录，不制造估算结果。
- 发布事务覆盖唯一暂存、容量预检、目标竞争、自动重命名、取消、写满和清理；源文件默认保持不变。
- Windows 密码保险箱以当前用户 DPAPI 保护随机安装密钥，密码正文使用 AES-256-GCM 保存；旧数据可迁移，活动接口、搜索、统计与历史已收敛为归档密码语义。
- 媒体依赖、许可、固定样本哈希、真实指标、任务模型和发布门禁成为可重复执行的仓库检查。

## 实际验证

- JPEG、PNG、WebP 共 9 个冻结样本全部通过真实编码、重新解码和逐项质量/元数据验收；PNG 像素完全一致，有损样本达到冻结 PSNR 下限，透明 WebP 的可见像素和 Alpha 分别核对。
- 100 张混合图片在 Windows Release 桌面链中完成 100/100，产生 100 个唯一输出和 100 条统一历史，格式分布 34/33/33，源 SHA-256 变化为 0。
- 96 MP 图片可真实处理，100.01 MP 图片按上限拒绝；中文长路径、skip/rename/replace-if-smaller、编码期目标竞态、容量不足和编码后取消均有真实文件终态证据。
- 无测试桥正式 NSIS 覆盖安装后，3 个真实 JPEG/PNG/WebP 完成“输入—可见配置—原图预览—编码发布—前后对比—历史—完整重启—输出重开”17/17 门禁；安装、卸载和公开 v1.1.14 恢复生命周期 50/50。
- 前端、Rust、Clippy、媒体架构/依赖/发布门禁及生产安装包完整性均纳入发布候选回归。

## 边界

- 本版本交付图片压缩；视频软件编码和 PDF 安全优化仍是后续独立节点。
- 当前图片配置不提供删除源文件选项；不得把归档任务已有的回收站能力解释为图片源文件删除。
- 自动化安装态拖入使用生产 Tauri 文件投递协议和真实磁盘路径，不包含测试桥；它验证生产事件/监听/后端完整链，但不声称复现 Explorer 鼠标轨迹。原生系统文件选择器已有独立真实证据。
- 无商业 Windows 代码签名证书的构建不包含 Windows 11 第一层菜单 identity package；经典“显示更多选项”菜单保持完整。
- updater ZIP、签名和 `latest.json` 只由配置发布密钥的 GitHub Actions 生成；正式发布后必须再执行公开资产回下载与 `v1.1.14 → v1.1.15` 应用内更新审计。
