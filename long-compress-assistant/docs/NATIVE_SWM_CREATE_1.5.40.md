# v1.5.40 原生 SWM 创建：实施与范围

本版按[既定计划](ARCHIVE_ROADMAP_1.5.40.md)完成功能封板；合入、标签与正式包状态见本版 PR/Release，不把本地构建当作已发布安装包。

## 用户可用范围

- 在原压缩和转换入口选择独立的 SWM 原生分包目标，使用仅存储、XPRESS 或 LZX 非固实内容编码。
- 指定目标卷大小，生成 name.swm、name2.swm 等资源容器；卷头具有同组标识、卷号和总数，区别于 WIM/ESD 数字切片。
- 先编码内容再分资源卷，进度/暂停/停止沿现有任务控制；整组发布、冲突、结果清单与失败暂存清理接既有机制。
- 复用已支持的原生 SWM 任意成员读取、浏览、预览、完整检查、所选/整包提取与补卷后新任务；密码 ZIP 可转换为 SWM，SWM 可转密码 ZIP。
- 复用方法字段，沿配置组、预设、模板、草稿、历史和多选配置保存；单条行内展开、多选弹窗、自然继承、50/50 和窄窗滚动保持。

## 范围边界

[官方 wimsplit 说明](https://wimlib.net/man1/wimsplit.html)指出单个文件资源不能拆在多个卷中，部分成员可能超过目标大小。UI 就近说明此语义；SWM 没有原生密码，本版不支持 LZMS/固实 SWM，不保证 Windows 部署、启动镜像或完整权限元数据。转换得到的是新的内容归档，不是原镜像部署元数据的重建。

## 本轮必要检查与接续

五项不同 Rust 定向检查通过：三种方法的真实卷头/同组标识/独立完整回解、浏览/预览/检查与所选/整包提取、缺首/中/尾卷及补齐、发布冲突和取消清理、无效请求拒绝，以及分包阶段输入字节与新目录输出。仅接续失败或受影响项。

前端配置、转换、历史、编辑卷大小及配置组相关 98 项通过；普通生产前端、版本 Shell 资源与版本身份 1.5.40 通过。桌面已完成创建、密码 ZIP→SWM、任意 SWM 成员→密码 ZIP、补卷新任务、多选配置/草稿恢复与源数据统计；16 个宽窄布局无横向溢出，7 张代表图已实看，原单条展开、多选弹窗、50/50 和滚动保持。

修复了仅存储编码不能带压缩块大小、卷大小清空时被有效值回填，以及分包阶段切换未保存源数据总量三处问题。完成后实际读取量、产物大小与比例正确显示；多选适用说明明确包括 SWM。过程、逐条结果及桌面构建身份见[证据](evidence/swm-create-1.5.40/)。

不重跑旧格式/密码矩阵、真实盘满或无关媒体门禁。下一版本为既定 v1.5.41 用途配置，五模块与之后主线回归仍按[分阶段路线](ARCHIVE_ROADMAP_1.5.44_TO_1.5.59.md)。
