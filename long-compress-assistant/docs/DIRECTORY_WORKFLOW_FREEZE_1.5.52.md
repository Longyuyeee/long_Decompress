# v1.5.52 目录触发与运行队列封板

[实施计划](ARCHIVE_ROADMAP_1.5.52.md) · [中文 Release](RELEASE_NOTES_1.5.52.md) · [记录与界面](evidence/directory-workflow-1.5.52/)。候选、正常合入、标签与正式附件收据在本版 PR 接续。

## 用户交付

工作流中心新增“目录与队列”，规则绑定已保存方案、监控目录、保存位置、文件/整组分卷或顶层项目文件夹、扩展名/子目录与 3～300 秒稳定等待。明确启用才自动处理，默认只接新增/变化，勾选才处理已有资料。规则点击展开，编辑与本次凭据在弹窗中；原单条展开、多选弹窗、自然继承、压缩/解压 50/50 与滚动保持。

文件通知仅作为变化信号，元数据稳定后才排队；Windows 文件仍有写入占用时继续等待，分卷沿原检测器归组、缺卷就地说明，补齐后重新等待稳定。重复事件/相同版本去重，取消后未变化的来源不自动入队。注册过的输出目录持续排除，修改/删除规则后旧输出仍不成为循环输入。来源变化先重新等待，实际派发前再次核对整组来源和保存位置。

队列显示状态、规则、来源、等待原因和结果，支持全队列暂停、规则暂停、取消待执行与明确重新加入。暂停不终止当前运行；当前处理可停止。排队项保留加入时的方案与输出快照，之后编辑不会暗改；删除规则取消尚未开始项目，原运行和文件保留。一次执行一套工作流，手动工作流/确认弹窗期间等待，后台或托盘继续沿原任务队列与引擎执行，不另造压缩器。后台运行不抢走正在查看的历史记录，内存中的最近运行有上限。

输出需密码时等待本次会话凭据，来源密码/编码与输出密码分开，保险箱复用；密码不写规则、队列或执行快照。失败/停止只处理一次，从原运行纠正继续后队列关联最新接续，原触发仍可打开。规则、未开始队列、暂停选择和运行关联持久化；退出前停派发并等待保存，重启不重复已开始的执行。原监控生成待确认草稿的行为保持。

## 范围与后续

最多 20 条目录规则，每条完整扫描访问最多 2 万位置/1000 份来源，最多 200 份等待项与最近 500 条结束记录。超过范围或读取异常说明原因，已就绪来源仍在实际派发前独立核对；容量/通知降级提示不将所有已就绪项锁住。文件通知配合周期观察，稳定依据路径、大小、修改时间与 Windows 写入占用，并非内容相同证明。分卷终卷/完整性沿现有检测器，不扩大既有格式能力。
