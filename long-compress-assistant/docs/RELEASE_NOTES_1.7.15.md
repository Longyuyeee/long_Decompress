# v1.7.15 · PAX 0.1 稀疏文件部分取回

TAR.LZO 后段损坏或缺卷时，已校验连续前缀内的完整 GNU PAX sparse 0.1 文件也可以取回。

- 支持元数据中的逗号稀疏图、长名称、多段数据、全零文件和大空洞，使用真实名称展示与保存。
- 核对映射段数、范围、逻辑大小和包内数据量，元数据、数据与填充完整后才列入可取回清单；冲突或不完整布局明确停止。
- 取回保留空洞与原修改时间，沿用原选择列表、折叠结果和部分历史；单条展开、多选弹窗、等宽双栏保持原交互。

本版扩展局部 PAX sparse 0.1，旧 GNU 和 PAX 1.0 保留。0.0 部分取回、链接和缺口后扫描未扩展，目标目录须支持稀疏文件。

见 [本版范围](ARCHIVE_ROADMAP_1.7.15.md)、[实现与检查](TAR_PAX01_FREEZE_1.7.15.md)。下一阶段 [v1.7.16 PAX sparse 0.0](ARCHIVE_ROADMAP_1.7.16.md)仅规划。
