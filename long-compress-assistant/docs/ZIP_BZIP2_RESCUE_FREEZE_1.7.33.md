# v1.7.33 · 流式 BZip2 ZIP 丢目录部分取回封板

日期：2026-10-29。

## 实现和用户行为

原 ZIP 本地条目恢复读入器新增未加密 BZip2（method 12）的未知尺寸流边界识别。使用解码器实际消费量、展开量、明确结束标记和内容 CRC，与紧随其后的普通/ZIP64 数据描述符逐一比对；可选签名有无均可，不扫描正文中的 ZIP 签名猜测下一条。非零本地展开尺寸还需与实际内容吻合。解码使用固定输入/输出缓冲，能排出已消费输入后暂存的输出，保持原取消与展开上限。

普通文件、空文件、明确 BZip2 目录及后续混合方法可接续；Deflate 流目录也沿同类结束边界判断，Store 空目录仍保留原零内容规则。完整单包和完整数字切片共用，数字切片可从非首卷进入。损坏流、矛盾描述符、截断或未知方法处停止，只保留此前可确认条目；缺中卷不跨缺口拼接。

原诊断入口显示“目录信息已丢失”和已找到的文件数，原总清单仍未知。只确认到目录、没有完整文件时，说明尚未找到可取回文件，并禁用恢复操作，避免进入必然失败的步骤。完整读取及校验的文件先沿原暂存、新 ZIP、整包验证与提交流程发布到独立结果；结果继续标记部分取回，原结果/历史、失败重试及取回后加入解压队列保持。没有新增页面、常驻参数或格式数量；单条展开、多选弹窗和等宽双栏保持。

本版不新增密码流未知边界支持。加密标记控制用于确认沿原密码保护规则停止，未冒称真实密码 BZip2 原件的新增救援能力。正常完整 ZIP 读取和既有已知尺寸流程保持。
