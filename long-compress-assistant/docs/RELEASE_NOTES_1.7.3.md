# v1.7.3 · LZOP 与 TAR.LZO 可以分卷保存了

压缩中心和格式转换现在都能为 **LZOP / TAR.LZO** 设置每卷大小。多个普通文件可打成 LZOP 分卷，文件夹和空目录可用 TAR.LZO 分卷，结果入口会列出整组文件。

## 本版更新

- 原单条展开配置直接设置分卷大小；多选弹窗可统一大小、关闭分卷或保持各自设置，不改变全局默认。
- 密码 ZIP 等来源可用原包密码转换成数字分卷；生成后的任意一卷均可打开，接通双栏浏览、文本/图片预览、所选取回和后续转换。
- 分卷复用暂存、完整校验和整组发布；不足一卷和正好整卷不多出空尾卷，失败或取消清理本次暂存，不留下半组结果。
- 结果和历史保留整组位置，缺卷时明确失败，补齐后可以重试。原单条展开、多选弹窗、左右等宽和主题样式保持一致，额外说明收进问号提示。

## 使用方式

生成的是 `.lzo.001 / .002 / …` 或 `.tar.lzo.001 / .002 / …` **数字字节切片**，需集齐整组。本软件可从任意卷识别整组；其他软件请先按编号合并成完整流，再打开。它不是 LZOP 原生多卷或块分段格式。

LZOP / TAR.LZO 仍不提供原生密码。普通 LZOP 不表达空目录，目录资料请选择 TAR.LZO。格式本身没有总成员/总卷数，不能保证发现完整成员及后续内容同时被删除的情况；缺卷内容救援另行分期。老 Windows lzop 的中文名称限制沿用原说明。
