# Long解压 v1.4.18

本版补齐 ZIPX 标准多卷，继续围绕格式、密码和分卷的实际使用流程改进。

- 支持 `.zx01、.zx02…/.zipx` 标准卷，从任意成员识别完整卷组、浏览、解压、检查和转换；与同名 ZIP、数字卷正确区分。
- ZIPX（XZ）可创建无密码、AES-256 或 ZipCrypto 标准多卷，并支持改密、重新分卷和合卷。原有数字卷默认方式不变，选择可保存在配置组和历史中。
- 缺卷、终卷截断先给出具体最终原因，不反复要求试密码；补齐原卷后可创建新任务继续，原失败记录保留。
- 修正文件浏览器中卷入口和输出目录名称，卷型控件使用简洁标题及卷名示例，常用与窄窗口均已实际查看。

## 兼容说明

标准 ZIPX 的方法和卷名需要接收方软件支持。本版产品输出已用 WinRAR 7.23 原名完整回解；本机 Bandizip 7.38 Beta 对产品输出存在内容解码异常，7-Zip 26.04 不能直接识别该标准卷名，不承诺所有软件互通。通用分享仍可选择兼容 ZIP。

新增创建方法限 XZ，空文件使用 Store，仍执行完整校验；不扩张到全部 ZIPX 专有方法或未经验证的 >4 GiB 密码组合。Windows N 继续暂不保证支持。

实施、独立样本和实际页面见[本版审计](STANDARD_ZIPX_1.4.18.md)，发布身份见[封板记录](STANDARD_ZIPX_FREEZE_1.4.18.md)。
