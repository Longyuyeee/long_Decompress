# 1.3.7 发布记录

发布范围见 [更新说明](RELEASE_NOTES_1.3.7.md)，分步实现与已有证据见 [开发交接](DEVELOPMENT_HANDOFF.md)。

## 复用的验证

- 功能开发阶段已分别验证批次失败纠正、全库历史查询、解压配置快照、输出预览和结果取用。数据库迁移及关闭重开用例已覆盖 schema 9/10；真实 Windows ZIP 失败纠正与历史关联已检查。
- 最后一轮前端定向测试 35 项通过，生产构建通过；760×520 浏览器完成批次结果打开、目录失效提示与关闭流程，深浅主题截图已复核。浏览器目录及资源管理器调用为响应夹具，不冒充真实系统打开验证。
- 本次发布不重复执行已通过的全量引擎、媒体和安装生命周期矩阵。版本身份、正式构建及发布附件由发布步骤确认。

## 发布状态

候选版本为 1.3.7。正式安装包通过仓库现有 Release 工作流构建，包含 NSIS 安装器、签名更新包和 `latest.json`。公开状态以 [v1.3.7 Release](https://github.com/Longyuyeee/long_Decompress/releases/tag/v1.3.7) 为准；本段准备时尚未生成公开附件。

本版历史数据库升级到 schema 10，增加原任务关联及可选解压配置；保留旧记录缺失字段的兼容读取。统计不是全库聚合，批次结果仅保留当前会话最近一批，跨重启通过历史取用。Windows N 及第一层右键菜单限制未改变。
