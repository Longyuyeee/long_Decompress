# ALZ Bzip2 大包有界读取（原始规划，v1.6.8 接续）

v1.6.8 已实现有界块读取；历史原工具大包未取得，本版调整为真实压缩数据的受控越界回归与独立完整回解，未外推原工具互通。准确范围见[本版路线](ARCHIVE_ROADMAP_1.6.8.md)与[封板记录](ALZ_BOUNDED_FREEZE_1.6.8.md)。以下保留原计划，不作为当前完成情况。

接续 v1.6.5 的结束与尾随修复。目标是用户收到较大旧 ALZ 时不必因实现的整条缓冲限制而换工具；先取材，再决定可发布增量，不将参数放宽当作完成。

1. 核对实际能创建 ALZ 变体 Bzip2 的历史构建，取得压缩数据超过现有 256 MiB 单条限制的真实原包。固定工具身份、参数、自有原始载荷及独立读取结果；密码、原生卷须按真实取得组合分别记录。不能只改头声明大尺寸。
2. 调整当前整条 Vec 收集及重包探测，使压缩输入按有界窗口/真实块读取；跨块密码状态、位对齐、终止和尾随检查沿 v1.6.5，保留资源预算和读写错误，不借临时全包副本掩盖内存。
3. 接原浏览、整包/所选提取、检查/诊断、转换、实际暂停/取消和失败新任务。所选末条依赖、缺卷/中途来源变化或损坏不能标为完整成功；进度按实际可获取数据展示，不虚构百分比。
4. 只检查越过旧边界的真实样本、受影响失败路径与必要宽窄显示，沿用旧格式矩阵。保持单条展开、多选弹窗和左右等宽，不新增铺开的说明区。

本版目前仅规划，没有大包原件或流式实现。若真实工具来源不足，明确记录缺口并把可复现的既有流程缺陷提到前面，避免连续版本只做同一轮取材。只有可用且证据足够的功能增量才确定发布范围和版本身份。
