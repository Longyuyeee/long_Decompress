# Long解压 v1.3.2

v1.3.2 修复损坏 RAR 被错误引导到密码尝试，以及失败历史缺少最终原因的问题。

## 损坏 RAR 识别

- 只有完整成功的归档列表才能用条目元数据证明归档加密。截断或损坏 RAR 即使前部暴露加密条目，也会直接报告“RAR 文件损坏或不完整”。
- 归档明确返回“需要密码”或“密码错误”时，仍按原顺序尝试保险箱、导入词表和内置字典，正常加密归档流程不变。
- 本机同批 12 个近期损坏 RAR 已逐项复验：12/12 直接报告损坏，0 个进入密码尝试。

## 最终失败原因

- 任务进入失败状态前先保存错误摘要，再追加最后一条“最终失败原因”错误日志，之后才写入历史。
- 外层获得更准确的错误时会更新同一历史记录，避免较早的笼统异常覆盖最终结论。
- 后端解压返回与历史持久化层均增加兜底，压缩、解压、图片、视频和 PDF 等任务不会再保存空白失败原因。
- 已经缺少错误摘要的旧历史无法还原当时丢失的信息；重试或新任务会按新逻辑完整记录。
