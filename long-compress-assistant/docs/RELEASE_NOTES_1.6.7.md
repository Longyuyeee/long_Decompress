# v1.6.7 · 工具中心，常用辅助功能集中使用

资料对比、工作流中心、归档资源库和文件完整性现在收纳到一个「工具中心」。像特殊压缩一样，在顶部切换分类，侧边栏更简洁，主要操作区域继续留给文件、结果和任务。

- **一个入口，四类工具**：侧边栏保留一致的图标、名称和快捷键格式，`Ctrl+Shift+T` 打开工具中心。四类工具在紧凑页签中切换，帮助按需显示，原操作和二级页签保留。
- **切换时保留手头工作**：已打开分类的输入、选择、展开详情和结果保留，进行中的读取/检查继续；隐藏分类的弹窗与帮助浮层不会挡住当前页面。离开工具中心仍按原页面规则清理操作。
- **原入口继续可用**：资料对比 `Ctrl+Shift+D`、工作流 `Ctrl+Shift+W`、资源库 `Ctrl+Shift+L`、完整性 `Ctrl+I` 继续直达对应分类。历史、结果和资源管理器校验入口均沿原路径接入。
- **更合适的小窗口布局**：不重复显示大标题和介绍区，四个分类保留名称，侧边八个入口统一调整间距；深浅主题沿用现有配色。

保留单条点击展开、多选弹窗、左右等宽以及各工具原有功能。本版不新增格式或算法；后续回到 ALZ Bzip2 大包兼容的真实来源与有界读取。
