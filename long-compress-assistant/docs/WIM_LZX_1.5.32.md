# v1.5.32 WIM LZX 创建实施

2026-10-20，接续正式 v1.5.31（PR #226、标签26e28a74c1c9c5d10e8511b43a17f6072b51dd4c，正式运行39433990042成功）。

在既有 WIM 方法中新增 LZX 体积优先，沿用已锁定、未修改的 wimlib1.14.5 独立编码器和完整对应源码/通知。不新增运行库，不改变旧存储默认值或既有 XPRESS 配置。LZX 使用非固实32KiB块、2线程，继承真实百分比、源数据合计、暂停/继续、取消及事务发布；不使用原存储体积预测。

单条展开、多选弹窗、配置组/模板、预设、草稿、历史再次执行和转换保留方法。混合修改 WIM 与 ZIP 方法时，无关任务保留全局继承；名称、原包密码、分卷等保持各自设置。原有50/50与窄窗滚动不变。

本版定向核对真实LZX资源、完整独立回解、暂停/继续及取消、文件目录创建、数字卷、任意成员浏览/有界预览/检查、所选与完整提取、密码 ZIP 双向转换、补卷新任务与结果。通过项与程序身份在封板记录接续；不重跑旧格式矩阵和真实盘满。

WIM 无原生密码；数字切片需集齐，并非原生SWM。单镜像内容归档不提供LZMS/固实创建、系统部署或完整Windows权限元数据备份。算法效果随内容变化，不保证每个包都比XPRESS更小。

七项新增Rust、六项新增前端、一条公共原生和六条实际UI已通过；具体产物、程序身份、一次脚本断言修正及显示记录见[封板](WIM_LZX_FREEZE_1.5.32.md)。下一版仅规划[LZMS非固实创建](ARCHIVE_ROADMAP_1.5.33.md)，尚未开发。
