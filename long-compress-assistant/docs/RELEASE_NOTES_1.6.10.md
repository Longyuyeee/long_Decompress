# v1.6.10 · ALZ 图片预览与连续阅读

ALZ 中的图片现在可以在原双栏直接查看，并接着进入现有图片阅读器，无需先解压整包。

- **原位预览**：双击或使用预览按钮，沿原只读弹层查看图片，另一栏的位置与选择保留。
- **接着阅读和取回**：沿用目录/整包阅读、翻页、缩放、跳过无法显示的图片、在列表定位及提取当前页，不增加新的浏览中心。
- **密码与分卷接续**：复用手动密码、保险箱、显式编码和完整原生卷组；关闭可取消，来源变化提示刷新，只解码需要的图片。

支持现有 PNG、JPEG、GIF、WebP、BMP 入口，ALZ 条目经完整大小、CRC 和压缩流终止检查后交付显示。图片不超过 8 MiB，单边不超过 8192、总像素不超过 1600 万，单条压缩输入不超过 64 MiB；超限可先提取后查看。保留原有单条展开、多选弹窗、左右等宽布局和工具收纳。

本轮图片及密码/原生卷使用明确标注的受控回归，未新增原 ALZip 图片互通原件，不外推全部历史构建与组合。文本仍保持原 1 MiB 完整文件范围；大文本前缀继续下一阶段。本版不增加格式数量、ALZ 创建/修复、方法 3 或 EGG 加密固实支持。详见[本版范围与记录](https://github.com/Longyuyeee/long_Decompress/blob/master/long-compress-assistant/docs/ALZ_IMAGE_PREVIEW_FREEZE_1.6.10.md)。
