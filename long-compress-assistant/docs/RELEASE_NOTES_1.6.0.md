# Long解压 v1.6.0

这次升级集中改善界面和操作体验：主要区域留给文件、任务与结果，常用操作更容易找到，保留单条展开、多选弹窗和左右等宽的使用方式。

- **双栏始终保留**：在当前栏打开压缩包，另一栏的位置与选择保留；两栏可分别浏览归档，所选内容直接提取到另一栏。本地 TXT、日志、Markdown、JSON、CSV、配置及常见代码文件新增只读预览，图片与包内预览继续可用。
- **页面更清爽**：归档资源库、工作流、资料对比及其他页面统一工具区和信息层级。次要配置收进页签、展开区或弹窗，介绍放入圆形问号，鼠标悬停或键盘聚焦即可阅读。
- **入口样式一致，快捷键可用**：资料对比 `Ctrl+Shift+D`、归档资源库 `Ctrl+Shift+L`、工作流中心 `Ctrl+Shift+W`。所有导航共用快捷键定义；窄窗口保留名称，悬停可查看完整提示，输入文字时不会触发页面跳转。
- **四种特色主题**：极地冰川、雨林秘境、星云紫境、曜石鎏金，分别提供背景、面板、渐变或细纹及推荐强调色。原有主题保留，色板可以直接预览，强调色仍可调整，外观配置支持恢复。
- **设置与更新反馈完整**：设置分为六类；格式数量按本机当前能力统计，与可展开明细一致。更新显示真实下载大小、总大小、百分比和安装阶段；服务器不提供总大小时显示等待进度。
- **关闭到托盘生效**：修复勾选后点击标题栏 X 仍直接关闭的问题。勾选时隐藏到托盘；取消勾选时保留原有任务确认和草稿保存退出流程。

本版沿用既有格式、密码、分卷及容错能力，没有把尚未开发的算法规划记为已完成。RAR 创建仍需本机安装编码器，格式统计会随本机能力变化。此前 v1.5.65 的 ZPAQ 原生多部分另存增量更新计划顺延为 v1.6.1。
