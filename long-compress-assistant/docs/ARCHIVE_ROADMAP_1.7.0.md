# v1.7.0 · Windows 打开与双栏浏览体验

按用户 2026-10-26 确认，本轮由原 v1.6.63 候选提升为 v1.7.0，集中交付已实现的打开方式、双栏与历史操作改进。

## 已完成

1. Windows 设置中确认默认应用，显示真实关联状态；区分系统关联与软件打开行为。
2. 四项打开动作及保存偏好、单包/多包自选目录、目录取消、冷/热启动和运行中排队。
3. 一次性按用户保存设置提醒；升级及恢复偏好不重置，已有默认关联不打扰。
4. 经典/原生右键按用途分组，常用操作在前，次要操作进入更多；升级保留原有关联候选。
5. 普通目录与压缩包共用双栏导航、列表、选择和底栏，保留图文预览、返回位置与另一栏状态。
6. 历史常用操作同排，更多操作使用浮层；所选空目录取回与离页运行衔接修正。
7. README 大幅精简与重排，末尾只保留最近五个版本。

实现、检查和限制见 [本轮记录](WINDOWS_OPEN_AND_BROWSER_UI.md)，用户说明见 [Release 说明](RELEASE_NOTES_1.7.0.md)。合并、标签与附件状态以 GitHub 发布页为准。
