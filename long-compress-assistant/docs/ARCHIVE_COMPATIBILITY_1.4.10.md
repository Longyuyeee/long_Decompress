# v1.4.10 ZIP 兼容与选择性解压实施审计

## 范围与基线

2026-10-16，接续正式 v1.4.9 / `083082e`，分支 `codex/archive-compatibility-1-4-10`。用户批准从 [后续路线](ARCHIVE_FORMAT_AND_WORKFLOW_ROADMAP_2026-10-16.md)按顺序开发并在本版封板后发布。

本版聚焦选择性解压的密码/容量/读取一致性，以及加密 Zstandard、真实 ZIP64 密码与卷型的特定兼容缺口。SFX、LZIP、任意缺卷救援和新压缩方法创建留后续版本。

## 初始审计

- `CompressionService::extract` 在实际读取前按整个归档判断是否需要密码，手动及自动凭据验证也未带本次条目范围。
- 原生 ZIP 读取的密码预检查遍历全部条目；实际复制阶段另有文件筛选。仅选公开文件仍可能被未选加密条目挡住，需要实际复现。
- 转换当前完整落地临时内容后重新压缩，已有空间检查；读写优化属于 v1.4.15，不在本版扩展。
- 前端公开格式入口没有 LZIP/ZPAQ；内置 7-Zip 26.04 也无这两种处理器。不能只增加后缀。
