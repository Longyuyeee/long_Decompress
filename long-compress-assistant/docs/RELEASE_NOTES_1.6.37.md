# v1.6.37 · 固实 Deflate 大日志先看开头

固实 Deflate 7Z 中的后续大文本，现在也可以在原双栏窗口直接先看前 1 MiB，无需先提取全文。

- 普通包、内容加密、文件名加密和完整数字分卷贯通，可从非首卷进入，继续使用手动密码或密码保险箱。
- 流式跳过所选文件前面的内容，只保留所选开头；前置内容与开头合计 ≤64 MiB，避免为预览一个文件保留整个共享块。
- 沿用只读文本预览、滚动和常见编码识别，明确显示“部分内容 · 未校验整文件”，保留“提取后打开”入口。
- 保留超限、缺卷、取消、来源变化和密码错误的处理；不能把未读尾部或前置依赖称为完整校验成功。

完整小图文与非固实大文本继续沿用原有读取流程。单条展开、多选弹窗、等宽双栏、主题和工具入口保持，格式计数及依赖不变。下一阶段分步扩展 Deflate64 预览。
