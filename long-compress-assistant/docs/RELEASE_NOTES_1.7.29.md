# v1.7.29 · TAR.LZO 前向链接内容转换

“链接在前、目标文件在后”的完整 TAR.LZO 包，现在可直接转换为新压缩包，省去先解压再压缩的步骤。

- 普通、空文件和已支持的稀疏逻辑内容按独立文件转换，支持普通头、GNU 长名称、局部 PAX 及完整数字分卷来源。
- 接通 ZIP / ZIPX、7Z、TAR / TAR.GZ 代表流程，沿目标格式能力使用密码、分卷、目录结构及修改时间。
- 新包经验证及原包状态重查后再发布；结果、历史及失败重试继续沿原入口。原包保留，失败和取消清理私有暂存。
- 保持原界面、单条展开、多选弹窗及等宽双栏。前向链接形式的内层包仍需先提取后打开，将在下一阶段处理。

本版不增加格式数量；稀疏内容按逻辑文件转换，不承诺目标格式保持源 TAR 全部元数据或空洞布局。见[本版范围](ARCHIVE_ROADMAP_1.7.29.md)、[实现与检查](TAR_FORWARD_CONVERT_FREEZE_1.7.29.md)。下一阶段 [v1.7.30 前向链接嵌套浏览](ARCHIVE_ROADMAP_1.7.30.md)仅规划。
