# Long解压 v1.5.8

本版补齐更多原厂自解压模块，收到不同年代的 7-Zip 外置分卷时可以继续使用一致的浏览与解压流程。

- 新增 7-Zip 19.00、23.01、26.04 GUI 独立加载器识别，保留 24.09；支持已验证的普通、内容密码、文件名密码和原始数字卷组合。
- 30 组原包贯通浏览、整包与所选提取、完整性检查和只读诊断；10 组密码包转换 ZIP 并独立回解。补充 WinRAR 6.24 GUI/控制台、x86/x64 模块及内嵌 7Z 回归。
- 全部成员导入归为一个任务；缺卷保留明确最终原因，补回原卷并填写密码后以新任务重试，保留原失败记录。输入 EXE 只作为数据读取，不执行。
- 67 项 Rust、150 项前端、33 个真实桌面场景通过，10 张常用/窄窗页面已查看；原文件和结果内容按完整哈希核对。

仅扩展经过原件确认的模块，不承诺全部历史/修改版模块。加密 RAR 卷头隐藏尾卷数量时仍需完整解码确认，相关最终原因继续在后续版本细化。不创建或修复 SFX，默认设置不变，Windows N 暂不保证支持。

详见[实施审计](SFX_MODULES_1.5.8.md)与[封板发布记录](SFX_MODULES_FREEZE_1.5.8.md)。
