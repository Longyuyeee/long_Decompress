# v1.5.53 定时工作流封板记录

基于 v1.5.52，2026-10-21。当前已实现单次、每天、每周固定资料定时和共用队列；三个真实桌面组合流程已完成。

## 交付范围

- 本地日期/时间与星期选择、下一次时间、最近状态、规则点击展开、编辑弹窗、暂停/启用/立即运行和最近五条运行入口。
- schema 17→18 新增定时规则表，沿用目录触发队列、运行快照、当前会话密码、原任务引擎和纠正接续关系，不新增第二套执行引擎。
- 应用运行或托盘驻留时执行；启动时过期的下一次、休眠/挂起超过 90 秒的到期请求汇总为“错过·未执行”，选择现在补跑或跳过。不自动补跑历史次数，重复计划从当前时间计算下一次。
- 同方案仍在运行时排队或跳过；同一方案和重叠来源的目录/定时请求双向去重。每规则最多一条尚未开始请求，不叠加历史欠账。队列上限 200，规则最多 30 条，来源最多 32 份；完整分卷自动展开。
- 排队使用触发时的方案/保存位置，派发前按元数据、结构、整组卷和 Windows 写入占用复查来源，变化或缺失留下未执行原因，可重新加入获取当前资料。此处为可执行性检查，不冒充逐字节内容一致证明。
- 暂停定时阻止未来触发并暂停普通等待项；主动立即运行或补跑可以在规则暂停时入队，但仍遵守全局暂停与原工作流忙碌状态。删除规则取消未开始项，保留原运行和文件。
- 密码只在内存，退出后重新提供；原失败/停止记录可沿原入口纠正，队列关联最新子运行。退出前复用 v1.5.52 停派发、保存和重启逻辑。
- 原单条展开、多选弹窗、自然继承、压缩/解压左右等宽保持。自动化规则区切换目录/定时，旁边队列；窄窗顺排，卡片与弹窗可纵向滚动。

## 边界与后续

不包含退出后唤醒、系统定时任务、任意 Cron、复杂分支和脚本。采用电脑本地时间；夏令时不存在的时刻跳过，重复时刻取第一次；修改系统时区后编辑/重新启用规则重新计算时间。未解决的错过请求只保留一份，后续时段合并等待决定。

固定文件夹来源与结果目录不可互相包含；固定输入可以明确选择其他规则已产出的结果，避免目录观察的输出排除误用于用户主动选择的资料；目录观察输出持续排除定时注册的结果目录，防止回流。删除/更改规则不改已排队的旧快照，旧请求可取消后重新加入。
