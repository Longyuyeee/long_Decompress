# v1.5.54 · 资料对比与所选取回

把两份资料放在一起看，找到差异，再只取回需要的内容。

## 看清两边有什么不同

- 新增“资料对比”工作区：文件夹与文件夹、ZIP 与 ZIP、文件夹与 ZIP 可以自由组合。
- 按相对路径对齐，区分仅左侧、仅右侧、类型变化、大小变化、时间变化；支持搜索、状态筛选和分页，左右分别勾选，跨页保留选择。
- 同大小、同时间明确显示“内容未核对”，避免把相似的文件误认成内容相同。单条仍点击展开查看说明，宽窗左右等宽，窄窗依次展示。

## 只取回勾选的资料

- 多选后在弹窗统一设置保存位置、保留目录结构或平铺、左右分开或合并，以及同名自动改名或跳过。
- 文件夹复制和 ZIP 所选提取进入原解压中心队列，查看进度、日志、停止和实际结果；原件保留，不扩成整包操作。
- 来源变化时说明原因，重新读取后再选择；暂不可用部分保留选择，可用部分先加入队列。
- 待处理任务可随草稿恢复，历史再次取回仍保留所选范围与处理方式；恢复或加入队列不会自动开始。
- 完成卡片显示实际提交的字节，同名跳过不计作新增产出。

## 当前范围

本版对比支持文件夹及独立、未加密的 Store/Deflate ZIP；密码包、分卷及其他格式可继续使用原文件浏览器。每侧最多 50,000 项，单批最多选择 2,000 项；非空目录请选择其中的文件，空目录可直接取回。取回位置选择两侧来源之外的独立目录。

本阶段比较类型、大小和时间，实际内容核对按 v1.5.55 接续，再做所选变更生成新包和整包图片阅读，之后回归算法、格式、密码、分卷与容错兼容主线。原单条展开、多选弹窗、自然继承、压缩/解压左右等宽与滚动保持。
