# Long解压 v1.5.14

本版统一交付 TAR 稀疏兼容和真实格式路由修正。v1.5.13 在发布前追加审计发现问题后取消，未公开发布，原标签保留不移动。

- 补齐旧 GNU 及 GNU PAX 0.0、0.1、1.0 稀疏 TAR 的真实名称与完整内容，避免遗漏文件或只读到压紧数据。浏览、文本预览、完整/所选解压、检查、诊断和转换保持一致。
- 已知 ZIP/7Z/RAR 不再因误写 TAR 后缀被当作 TAR；真实裸 TAR 也优先按内容识别。浏览和预览的同类后缀优先问题一并修正。
- 区分稀疏空洞和实际数据，修正合法大包被倍率规则误拒；磁盘空间与输出上限仍按完整逻辑大小检查，普通包规则不变。
- 映射损坏、压缩尾部截断和未知版本保留具体最终原因，不反复试密。选中的链接、管道等非普通条目明确拒绝，普通文件可单独提取。

二十组 GNU tar 原包经 Linux libarchive 独立回解，另验证误后缀真实 ZIP/TAR、固定 2 GiB 稀疏原包的实际暂停恢复取消和历史再次执行。

Windows 输出普通填零文件，不承诺 NTFS 稀疏分配、Linux 权限/属主/扩展属性、链接或稀疏包创建；不扩张自有 AES 特殊布局。TAR 细粒度实时字节百分比仍非本版交付。ALZ 方法 3 仍不支持，EGG 加密固实未验证，Windows N 暂不保证支持。

详见[实施审计](TAR_ROUTING_1.5.14.md)和[封板发布记录](TAR_ROUTING_FREEZE_1.5.14.md)。
