# v1.5.57 归档图片连续阅读封板

2026-10-22，基于 v1.5.56。见[实施](ARCHIVE_ROADMAP_1.5.57.md)、[中文说明](RELEASE_NOTES_1.5.57.md)及 `evidence/image-reader-1.5.57/`。

## 已交付

- 保留原图片/文本单张预览；浏览器摘要增加阅读入口，原图片预览可进入同一阅读器。按当前目录或整包、自然路径/数字顺序连续翻阅，页数/跳页、键盘、相邻缩略导航、适应窗口/原始大小与 25%～400% 缩放齐全。
- 图片舞台独立滚动，工具/缩略导航/返回和提取入口保持可见。关闭回原列表保留选择，也可定位当前图片，或沿原流程提取准确的一张。
- 复用既有有界解码路线，增加实际字节/扫描事件、请求取消、过时结果隔离；WIM/ZPAQ 进程与 AES 认证沿原引擎取消能力接通。定位阶段与图片读取阶段区分，不在未获得字节时伪造进度。
- 浏览结果附带整组来源版本；新读取前后与缓存命中都确认来源，变化/缺卷停止复用，提供返回刷新。密码、编码、快照沿原上下文，仅会话；未支持、坏图、重复路径、浏览器解码失败及超过预算有可继续的出口。
- 缓存最多 3 张、合计 16 MiB 原始图片字节和 2400 万像素，只预读下一张；缩略导航最多 7 项。对象 URL 在淘汰/关闭释放，切换取消无关工作，不持久化图片或密码。

## 明确边界与接续

沿现有有界预览格式与密码/完整卷/快照能力，不增加图片或归档解码器。PNG/JPEG/GIF/WebP/BMP，每图最多 8 MiB、单边 8192、1600 万像素，TAR 最多扫描 64 MiB；不支持的来源继续原提取后打开。来源版本根据路径/文件元数据与完整卷组确认，不宣称一次读取后内容永不变化。

当前缩略导航为相邻窗口，不是全包缩略库；没有跨重启阅读记忆。阅读记录、长列表与资料库往返/多选素材取回留 [v1.5.58](ARCHIVE_ROADMAP_1.5.58.md)，仍未开始运行时开发。之后按既定 v1.5.59 起回归格式/算法/密码/卷型与容错主线。

schema 18、原单条展开、多选弹窗、自然继承及压缩/解压 50/50 保持；不重复旧矩阵、真实盘满、媒体压缩或个人安装。v1.5.56 正式构建 39638441478 已成功、四附件齐全。
