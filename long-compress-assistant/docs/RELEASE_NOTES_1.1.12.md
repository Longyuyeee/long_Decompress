# Long解压 v1.1.12

v1.1.12 恢复 Windows 开机自动启动能力，并把它限制为用户在设置页明确选择后才注册的可撤销功能。本版本不恢复 v1.1.7 曾出现的启动时重复持久化行为。

## 主要更新

- 设置中心重新提供“开机自动启动”开关；打开应用、加载设置和检查状态只读，不会注册、迁移或修复启动项。
- 用户开启后写入当前用户 Windows `Run` 值，命令固定为带引号的当前程序绝对路径和 `--autostart` 参数；精确值已存在时保持幂等。
- 登录启动隐藏主窗口并静默驻留托盘；若应用已经运行，自启触发的第二实例不会抢占焦点或弹出窗口。
- 用户关闭时删除当前及历史品牌启动值；覆盖更新保留已经明确开启的当前值，卸载时清理全部相关值。
- 注册失败会回读实际系统状态并回滚界面，不把失败保存成成功；重置普通设置不会绕过专用开关修改 Windows 持久化状态。

## 安全边界

- 不创建系统服务、计划任务、驱动、启动脚本或 Defender 排除项，不要求管理员权限。
- 不建议用户关闭 Defender，也不提供自动添加白名单的路线。
- 未签名程序无法保证永不触发安全软件启发式告警；发布前仍需在启用 Defender 的干净 Windows 环境验证正式安装包。
- 当前开发机的 Defender 服务、实时保护和行为监控被禁用，因此本地结果不能标记为 Defender 扫描通过。完整说明见 [AUTOSTART_SECURITY_AUDIT.md](AUTOSTART_SECURITY_AUDIT.md)。

## 验证

- 前端单元测试覆盖加载只读、点击才写、成功后保存和失败回滚。
- Rust 测试覆盖安全命令生成、启动参数、平台能力声明和安装/卸载生命周期。
- 真实 Windows Release Tauri/WebView2 门禁点击实际设置开关，验证注册表精确值、重复启用、关闭清理和独立登录启动隐藏窗口。
- 托管 Windows CI 构建隔离测试二进制并校验桌面脚本；真实 GUI 聚焦门禁在交互式 Windows 环境通过，正式 NSIS 候选可以成功构建。

## Windows 集成边界

项目仍没有商业 Windows Authenticode 代码签名证书，因此公开安装包不包含 Windows 11 第一层菜单身份包；经典“显示更多选项”菜单继续支持。自动更新资产继续使用项目独立更新密钥签名验证完整性。
