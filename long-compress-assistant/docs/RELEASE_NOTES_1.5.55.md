# v1.5.55 · 资料内容核对与密码分卷 ZIP

两份资料看起来相似，现在可以进一步确认文件内容是否真的相同。

## 从差异候选到内容结论

- 资料对比新增“核对所选未完成项”和“核对当前筛选”，也能展开单条重新核对。
- 同大小文件逐侧读取完整内容，以 SHA-256 判断相同或不同；内容相同但记录时间不同会单独显示。大小不同直接说明内容不同，不用再完整读取。
- 显示已读取字节、当前文件和处理数量。停止保留已完成结论，继续时只处理未完成或读取失败的项目。
- 内容相同、不同、仅时间变化、待核对和未完成均可筛选。来源变化会撤销旧内容结论，提示重新读取；读取失败不会当作内容相同。

## 密码与分卷直接接续

- Store/Deflate ZIP 对比接入 AES/ZipCrypto 密码、完整数字分卷和标准 ZIP 分卷，可从任意成员选择同一组资料。
- 在来源密码弹窗填写本次密码，或从原保险箱选择；沿用 ZIP 密码编码选项。补密码后继续未完成项，缺卷先说明并在补齐后重新读取，所选仍有效的路径继续保留。
- 密码与分卷所选取回沿原队列、实际结果、草稿恢复和历史重试接通。密码仅保留在会话，重启或从历史再处理时重新填写，原选择与编码继续保留。

## 保持熟悉的界面

单条仍点击展开，多选仍在弹窗集中配置；宽窗左右等宽，窄窗纵向展示并可滚动。原件保留，既有结果按改名或跳过处理。

本模块范围为文件夹与 Store/Deflate ZIP，每侧最多 50,000 条，单批核对或取回最多 2,000 项并限制路径总长度。密码不隐藏包内名称；不完整或无法唯一读取的来源先处理，其他方法、格式及缺卷救援可继续使用原浏览器。未新增压缩算法，也不提供目录双向同步或自动删除。
