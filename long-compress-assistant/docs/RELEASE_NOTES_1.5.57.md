# v1.5.57 · 整包图片连续阅读

打开扫描件、漫画或设计素材包后，可以在同一个阅读窗口连续翻图，保留原单张预览和文件操作。

## 看图不必反复开关预览

- 文件浏览器增加“阅读图片”，原图片预览也可进入连续阅读。支持当前目录或整包范围，按包内路径自然数字排序。
- 当前页/总数、跳页、上一张/下一张、相邻缩略导航；方向键、PageUp/PageDown、Home/End 翻页，Esc 返回。
- 适应窗口、原始大小和 25%～400% 缩放，大图在舞台内独立滚动；宽窄窗口均保留工具和图片区域。
- 返回原列表继续操作，所选文件保持；也能定位当前图片，或沿原流程只提取这一张。

## 等待、异常和来源变化

- 显示读取阶段、实际读取字节与 TAR 定位扫描；原引擎尚未返回字节时显示等待，不冒充百分比。可以停止本次读取，再重试或翻到下一张。
- 未支持、坏图片或超出范围有明确原因，可重试、跳过或提取后查看。浏览器无法解码时不会留下空白成功状态。
- 阅读绑定本次整组来源版本；缓存命中也先确认来源，变化后停止复用旧图，返回刷新后重新阅读。
- 只预读下一张，最多缓存三张，并同时限制总字节与像素。切换取消无关读取，关闭释放图片对象；密码和图片数据不写入阅读记录。

## 支持范围

沿现有 ZIP、TAR 系列、普通压缩流、WIM、ZPAQ 等有界预览路线，密码、分卷及快照按现有真实能力读取；没有新增图片或归档解码器。内置显示 PNG、JPEG、GIF、WebP、BMP，每张解压后最多 8 MiB、单边最多 8192、最多 1600 万像素；TAR 最多扫描 64 MiB。受限来源继续原提取后打开流程。

原单条展开、多选弹窗、自然继承和压缩/解压 50/50 布局保持。下一版 v1.5.58 处理阅读记忆、长列表、资料库往返和所选素材取回，再按既定顺序回归格式、算法、密码、卷型与容错兼容。
