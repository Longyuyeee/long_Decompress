## 发布步骤

八处身份已统一为 1.4.16，`node scripts/check-release-identity.mjs --expected 1.4.16 --tag v1.4.16` 与升版后普通生产构建通过。版本化资源为 `long_compress_shell_extension_1_4_16.dll`，SHA256 `9f3d1f1695f81983c36d6ff96c88a67745166b9263f814137db8709022aab007`；旧资源保存在 Git 历史。Windows 11 身份包因本机无签名环境按既有规则跳过，不冒称已生成；本版未改相关安装流程。

1. 八处版本统一至 1.4.16，重建版本化 Shell DLL，版本身份检查通过后提交候选 PR。
2. 等待必需的 Windows package 成功，下载并核对实际普通 NSIS 安装器的版本、大小和 SHA256。安装流程本身未改，复用既有安装生命周期证据，不改个人安装、历史或设置。
3. 按保护规则合入，正式标签指向合入提交；完成 Release 安装器、签名更新 ZIP、签名和 latest.json，回下载核对身份、摘要和更新清单。
4. 正式资产齐全后同步两份 README、中文说明和当前发布状态；保留原图标、旧标签及证据，不为回填文档重新打包。
