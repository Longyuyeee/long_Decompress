# v1.6.13 候选 · EGG 非固实图片预览与阅读

仅规划，尚未开发。完成非固实小文本后，接通原双栏内的单图查看和连续阅读，继续减少先提取再打开的步骤；不改变单条展开、多选弹窗、左右等宽和工具收纳。

1. **先完整读取所选图片**。复用现有 EGG 解码/CRC 及实际输入预算，按单图不超过 8 MiB、压缩载荷实际读取不超过 64 MiB、现有 PNG/JPEG/GIF/WebP/BMP 和像素范围实现；仅非固实条目。返回前须通过全部所选块的大小、CRC 和终止条件，不为一张图片解码无关大文件，不落地临时提取。
2. **再接密码和完整原生卷**。复用手动密码、保险箱、显式代码页及完整卷入口，密码候选只验证所选图片，记录真实来源和可用组合。无原工具图片原件时，明确标注自有受控样本，不能扩张历史互通承诺。
3. **最后接原连续阅读器**。翻页、缩放、坏图跳过、定位和当前页提取继续用原入口；关闭/换项取消，来源变化刷新。固实、过大、不支持或无法确认输入范围时给提取指引，不增加独立浏览中心或常驻配置区域。
4. **按增量封板**。只补所选图片、完整性、密码/卷组、取消/来源变化与必要宽窄窗口，复用已过的小文本、旧算法、安装和真实盘满依据。完成后同步 README、Release、支持口径及版本身份。

之后再按有效来源拆分 EGG 固实有界选读及大文本阶段，继续格式/算法、密码/分卷和容错主线。ALZ 方法 3、原工具图片/历史 Bzip2 大包、EGG 加密固实保留来源条件；不空发取材版本，不重复无效来源请求。
