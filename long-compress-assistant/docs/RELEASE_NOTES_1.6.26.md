# v1.6.26 · 密码固实 7Z 大日志直接读开头

带密码的固实 7Z 大日志，现在也能在原双栏直接阅读所选前 1 MiB，无需先提取整个共享块。

- 支持 AES + LZMA / LZMA2，准确定位首个或后续所选文件，只流式跳过必要的前置内容，保留所选日志开头。
- 内容加密、文件名加密和完整数字分卷贯通。沿用手动密码和密码保险箱；手动密码错误时直接提示，留空可尝试保险箱，不把部分阅读记为整包密码成功。
- 复用原文本窗口、滚动、编码识别、已读/声明大小和“提取后打开”；明确标注“部分内容 · 未校验整文件”，不冒称已验证前置内容、未读尾部、完整加密结束或整文件 CRC。
- 前置内容与显示开头合计限 64 MiB，实际输入、字典/解码头范围与候选整体 30 秒保持。共享总量超过 64 MiB 时，范围内靠前的大文本仍可部分阅读；超出前置范围给出提取指引。
- 编码边界、关闭取消、来源变化、缺卷和迟到结果丢弃沿原流程；完整小文本、图片和文件头仍保留原完整消费与校验条件。

保持单条展开、多选弹窗、左右等宽及现有主题/工具/快捷键，格式数量不变。下一阶段规划 7Z PPMd 非固实完整图文预览，尚未开发。
