# Long解压 v1.9.0

本版减少浏览大目录、预览压缩包和执行日常归档任务时的资源占用。

## 大目录和包内预览

- 双栏文件浏览器复用文件列表、排序和修改时间的显示结果，减少切换文件、勾选和刷新时的重复处理。
- ALZ、EGG 目录逐条输出，主程序直接读取目录数据。图片和文本预览减少临时副本，保留加密包、分卷和固实包原有的预览规则。

## 压缩、解压和资料管理

- 压缩分析保留有限的抽样文件；ZIP 分卷目录、RAR 格式识别和多种归档读取路径减少整段缓冲或重复分配。
- 图片预览和压缩、校验清单、密码备份导入、历史记录、归档资源库和资料对比减少中间数据占用。
- 空闲时减少文件夹监控的轮询。草稿就绪后通过事件通知界面，并保留启动恢复与定期补查。

首次安装请选择 Windows x64 的 `setup.exe`。已安装用户可在设置中心检查更新。[图文操作指南](https://github.com/Longyuyeee/long_Decompress/blob/v1.9.0/README.md#quick-start)
