# v1.6.32 · 固实 PPMd 大日志直接读开头

固实 PPMd 7Z 中的大日志，现在也能在原文本窗口先看前 1 MiB，再决定是否提取。

- 普通包、AES 内容/文件名加密和完整数字分卷贯通，继续使用原手动密码与保险箱。
- 跳过所选日志前面的共享内容，只保留所选开头；前置内容与开头合计超过 64 MiB 时，会提示先提取后打开。
- 沿原编码识别、滚动、“部分内容 / 未校验整文件”和提取入口。UTF-8/BOM、UTF-16、GBK 截断处保持完整字符。
- 精确 1 MiB 的小文本仍完整读取；开头预览不代替整文件校验，未读尾部损坏也不会被描述为完整成功。

保留单条展开、多选弹窗、左右等宽、主题、工具和快捷键。既有完整图文、整包阅读和通用提取保持；无新增依赖或格式计数变化。
