# v1.6.45 · 7Z Bzip2 大日志先看开头

普通和密码 Bzip2 7Z 中的大文本，现在可以在原双栏浏览器先看前 1 MiB，再决定是否提取全文。非固实与固实包同版接通。

- 支持内容加密、文件名加密、完整数字分卷及从非首卷进入，继续使用手动密码或密码保险箱。
- 流式跳过前置内容，只保留所选开头；前置内容与开头合计最多 64 MiB，达到目标后停止推进，超限仍可提取后打开。
- 沿用常见文本编码、字符边界和滚动，明确标示“部分内容 · 未校验整文件”，保留提取全文入口。
- 完整小文本和图片继续使用原完整读取路径；取消、来源变化、缺卷及明确手动密码错误继续沿原流程处理。

部分预览不代表所选完整文件、共享块、未读尾部或整包密码已校验。单条展开、多选弹窗、等宽双栏、主题/工具/快捷键保持，说明放原问号，格式数与依赖不变。下一阶段规划 7Z 创建时选择 LZMA2、LZMA 或 Bzip2，接通原密码、固实、分卷和转换流程。
