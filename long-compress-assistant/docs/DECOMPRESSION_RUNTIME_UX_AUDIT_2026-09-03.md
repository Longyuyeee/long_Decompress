# 解压运行态界面与跨盘事务审计（2026-09-03）

## 范围与基线

- 基线：公开 `v1.2.5`，`master@e4f79d2`；开发分支 `codex/decompression-runtime-ux`。
- 本轮只修复解压运行态信息架构、速度显示、跨盘根目录提交和密码尝试日志；没有提升版本、打标签或发布 Release。
- 冻结原则：进度数字缓动只属于显示层，任务存储和后端真实进度不伪造；源压缩包回收失败不得推翻已经提交成功的解压结果；密码明文不得进入日志。

## 六项需求逐条对齐

1. **低高度侧栏不再挤压**：窗口高度不超过 640 px 时，品牌区缩至 56 px，导航保持 40 px 点击高度，仅隐藏次要快捷键和版本行。920×520 实测导航 `clientHeight=scrollHeight=354`，8 个目的地全部在可视区域内。
2. **左下任务摘要重构**：环形进度、任务数、任务名、阶段、速度和当前文件均为单行省略；展开/最小化按钮固定在卡片右上角，不再占用文案流。活动任务截图中摘要为 70 px 高，`clientWidth=scrollWidth=189`。
3. **未展开任务补足信息**：运行态行新增阶段、当前文件、速度、缓动百分比及连续进度条；完成/失败任务不再保留容易误导的瞬时速度。
4. **展开详情消除结构性换行**：配置/执行栏在 920×520 下实测为 247/331 px，详情、配置、执行和存储预检的横向溢出均为 0；长路径与 18 条长日志均单行省略并通过 `title` 保留全文。原“目标存储预检”大卡改为 36 px 的“存储预检 / 状态 / 可用空间”摘要。
5. **速度和进度显示纠偏**：后端至少取得 250 ms 非终态观察窗口才发布吞吐，终态单样本不再计算天文速度；任务进入完成/失败/取消时清除速度和 ETA。显示层新增 360–900 ms ease-out 数字过渡，20.22→33.55 会经过中间值，权威任务进度保持原值。
6. **跨盘与密码流程**：Windows 盘符根目录没有父目录，旧逻辑会把 `H:\` 的暂存目录错误退回进程目录，最终跨卷 `rename` 触发 `os error 17`；现改为在所选盘根目录创建同卷暂存。内置 254 项字典仍逐项真实验证，但永久日志只保留 1/2/3、每 25 项和末项，实时候选继续由进度事件展示。
