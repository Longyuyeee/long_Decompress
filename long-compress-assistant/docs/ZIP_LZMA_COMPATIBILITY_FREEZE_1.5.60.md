# v1.5.60 ZIP LZMA 跨流程兼容封板记录

2026-10-22。实施见[路线](ARCHIVE_ROADMAP_1.5.60.md)，用户说明见[Release](RELEASE_NOTES_1.5.60.md)。

## 实际范围（功能已封板，进入发布）

- ZIP 方法 14 纳入独立普通/AES/ZipCrypto ZIP 编辑和资料对比。保留条目沿原方法，普通条目保留原压缩数据，密码条目重新编码；新增/替换与组包明确选择 Deflate/Store。时间、备注等继续原编辑能力，不冒称全元数据无损。
- 文件夹↔ZIP、ZIP↔ZIP 的实际 SHA-256、所选精确取回、补充取材、完整数字/标准卷、密码编码及原草稿/历史/失败接续沿同一路径。原件和已有输出保留，不提供原生分卷回写或损坏修复。
- 修复方法 14 仅按声明大小提前结束：真实 ZIP 标志传到可寻址和流式读取器。声明 EOS 时需要真正到达结束，并核对精确输出大小；无 EOS 的合法按大小流仍可读取。原属性先验证，再沿用小文件字典缩小行为，不新增字典/内存限额或产品依赖。CRC、加密包装及写入头/结束标记保持。
- 只扩展 ZIP LZMA；.lzma 单流、ZIPX（XZ）和其他方法维持原能力。原单条展开、多选弹窗、自然继承、压缩/解压 50/50、窄窗滚动和 schema 18 不变。

## 新增与受影响检查

九项不同 Rust 检查通过：普通条目的原压缩字节、方法/备注/时间/权限及新增内容；AES/ZipCrypto 和明确 CP936、保留/去密码/换密码、空文件；错误/缺密码及已有输出保留；实际内容核对；数字卷取材的精确范围、来源变化/缺卷及编辑卷型边界；CRC/大小/截断拒绝；真实有 EOS 和无 EOS 的原字节另存、标志保留及独立 7-Zip 回解；EOS 截断、匹配 CRC 的伪造前缀大小与异常属性/字典拒绝；流式读取的标志接续。

首次八项通过；最后一个样本封装遗漏 UTF-8 标志，纠正测试样本后接续该一项，并补受样本标志修正影响的两项；其余成功项保留，九项不同检查均完成。正向来源由真实 LZMA1 编码构造，包含合法无 EOS，不能用截断 EOS 伪装无 EOS；异常方法/属性修改只作为反例。

类型/Vite、八处版本身份、Shell DLL 通过。原生 `custom-protocol,desktop-e2e` 构建通过。四条真实桌面组合流程、18 条宽窄布局和 6 张代表图实看完成，见[原始记录](evidence/zip-lzma-compatibility-1.5.60/desktop-progress.json)。桌面程序 SHA-256：`5547db40d0a75383d71f646cff991b290f94ac7fcc6eaf3e304df062f55a15f6`，为上述原生桌面构建身份，不当作正式安装包身份。

1. 独立 7-Zip 生成真实 LZMA ZIP，单条右键整理、改名/移动与添加，沿原清单另存；独立 7-Zip 回解，新包保留 LZMA 方法，新增内容为所选 Deflate。
2. AES LZMA 错密码失败不生成输出，纠正原密码、设新 AES 密码后另存成功，保留原失败。独立回解内容正确，方法仍为 LZMA。
3. AES 数字卷从非首成员读取，缺密码未完成、填密码后实际内容相同。弹窗只取所选文件；正常退出/同资料重启，待处理草稿保留范围、密码为空，补密码后只产所选文件；历史再取回同样精确。
4. ZipCrypto 标准卷从非首成员进入 ZIP↔ZIP 内容对比，缺卷拒绝清单、补回后继续；所选引用组包明确去密码并按 Deflate 写出独立 ZIP。独立回解只包含所选内容，全部原独立包与卷组 SHA-256 保持。

桌面首次完成前两条及重启取回，历史操作脚本提前离开异步检查页且按同名记录定位到了旧版本样本；补等待和按真实输出路径定位后，仅接续历史部分和第四条。程序/交互没有因此调整，前面成功项及截图保留，所有桌面记录对应同一程序；之后只整理文档与记录。前端仅更新支持提示，不为静态文案新增重复单测。v1.5.38 的既有创建/转换和其他不受影响依据复用；不重跑旧全格式/密码/算法/媒体矩阵、真实盘满或个人安装。
