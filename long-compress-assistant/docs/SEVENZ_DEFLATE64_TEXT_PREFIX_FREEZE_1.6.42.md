# v1.6.42 · 非固实 Deflate64 大文本开头

## 完成范围

按[本版路线](ARCHIVE_ROADMAP_1.6.42.md)新增独立 read_deflate64_entry_prefix，接通普通或有序 AES → Deflate64 非固实大文本，最多返回前 1 MiB。确认唯一普通条目、声明大小与 coder/流/绑定/打包映射；固定 32 KiB 输入/输出，先取出已解码的窗口内容再补输入，不按巨大声明分配或读全文。使用无尺寸终止器的 InflaterManaged::new，检查已观察到的损坏、无进展及真实结束；即使解码器内部还有待取出内容，已知终止总量与声明冲突也会拒绝。达到开头上限即返回，未读尾部、完整输入消费、完整 CRC 与载荷 AES 消费不作完整成功声明。

密码载荷沿显式 PreviewAes::new_prefix，核对 AES 顺序/参数、声明长度和密文对齐；完整目录头和其他完整 AES 流消费回执保持。内容/文件名加密、原手动密码/保险箱、完整数字卷/非首卷接通；手动错误不回退，不凭预览记整包密码成功。实际输入 ≤64 MiB、候选整体 30 秒、读取中取消及来源绑定沿用；压缩/输出声明可以大于实际预算，实际读取和输出仍受限。

沿原双栏文本窗口、UTF-8/BOM/UTF-16LE/BE/GBK 边界与滚动，明确“部分内容 · 未校验整文件”，保留提取后打开及原选择性提取。完整小文本、图片和固实完整图文仍走独立完整路径；固实大文本继续给出提取下一步。只删除被替代的旧非固实大文本不支持断言，不放宽固实限制。单条展开、多选弹窗、50/50 双栏、主题/工具/快捷键保持，仅扩展原问号；无依赖、许可、格式计数或正式构建配置变化。

## 本版必要检查

7-Zip 26.02 新生成普通、AES 内容加密、文件名加密与完整加密数字分卷四组非固实原件，官方 26.04 独立逐文件回解 SHA-256，确认 Deflate64 / Solid -。复用冻结的公开日志内容，包含精确路径及相邻方括号路径、五种编码边界、精确 1 MiB/刚超出、完整小文本及二进制。另有明确 Solid + / Blocks 1、Copy 范围样本，普通/密码单日志和 65 MiB 原件均独立回解。压缩尾部与开头受控损坏由独立工具确认完整性失败，未读尾部只能作为部分预览，不代替完整读取。原件参数、工具哈希和逐文件结果见 tests/fixtures/archives/sevenz-deflate64-text-prefix-1642/manifest.json；生成脚本保留既有原件。

三项新适配单元通过：普通/显式部分 AES 三字节短读准确返回所选开头、不验证未读尾部 CRC；巨大声明仍仅按固定块读取；已知短流、读取中取消和其他完整 AES 回执不豁免；真实结束时包含内部剩余输出的已知总量仍须匹配声明。首轮发现已有解码输出时先补输入，导致不必要的尾部读取（60005 字节而非 32768），仅修改本版前缀补输入条件后，三项受影响新单元通过，保留初始日志。

六组后端通过：四组原件及每个卷成员、五种编码边界/精确大小；保险箱与明确手动错误/统计；受损尾部部分预览与完整读取失败、完整小文本 CRC、坏开头/固实/Copy/二进制下一步；取消/来源/缺卷与 65 MiB 大文本；映射/参数/AES/中途取消及明确未检查 CRC；仅补密码非固实和密码固实两项完整图文连续性，不重跑旧方法矩阵、安装或盘满。

类型/Vite、八处版本身份和 Shell DLL 通过。四组实际 Tauri 桌面通过：原窗口的部分标记/哈希/滚动与宽窄等宽双栏、提取全文入口可见，实际选择性提取完整日志 SHA 与原件一致且没有其他文件；普通/内容加密/非首加密卷及五种字符边界、手动密码与 65 MiB 大声明；坏尾部部分显示、完整检查失败和固实/Copy/二进制下一步、完整小文本；取消/来源变化与新请求。1100×650 与 760×520 两张截图已实看，正文可读、可滚动，部分提示/提取全文/关闭可达，无横向溢出，两栏等宽。候选 SHA-256 `b05bb355b2b22987d3d01b14ab61e2acdc71782a0a22ce0fe7d0c8b01ad83859`，见[证据](evidence/sevenz-deflate64-text-prefix-1.6.42/checks.json)。本地 VITE_DESKTOP_E2E=1、custom-protocol/desktop-e2e、opt-level=1/LTO=false，正式配置不改；入口 node scripts/test-tauri-desktop.mjs --sevenz-deflate64-text-prefix-1642-only。
