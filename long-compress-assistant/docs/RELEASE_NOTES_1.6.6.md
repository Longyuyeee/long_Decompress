# v1.6.6 · 记住窗口位置与大小

回应 [#248](https://github.com/Longyuyeee/long_Decompress/issues/248)：在高分辨率屏幕上调整好的窗口，重启后自动恢复，不必每次重新拉大。

- **记住上次的窗口**：自动保存正常窗口的位置和尺寸，最大化后重启仍保持最大化，点击还原则回到原来的大小。
- **托盘与最小化保持自然**：最小化和关闭到托盘不会覆盖正常尺寸；普通启动显示窗口，开机启动仍隐藏到托盘，唤醒后使用记住的位置。
- **换屏后仍能找到窗口**：按当前显示器缩放和可用工作区恢复；原屏断开、分辨率降低或窗口越界时，调整到可见范围。记录缺失或损坏时使用默认窗口。

无需打开额外设置。保留单条展开、多选弹窗、左右等宽及现有退出确认，不改变各工作区功能。本版不增加格式或算法；ALZ 大包读取与方法 3、EGG 加密固实继续按真实来源推进。
