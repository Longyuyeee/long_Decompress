# v1.7.32 · ZIP / ZIPX 保留 UTC 修改时间

新建或转换 ZIP / ZIPX 时，现在会保存文件及明确目录的 UTC 修改时间，与上一版的读取和恢复衔接，保留可确认的奇数秒，减少跨时区读回造成的时间偏差。

- 普通包、密码包和标准/数字分卷沿原创建流程记录日期，空目录与同名来源分别保留各自时间。
- 同时保留旧工具可读的 DOS 本地日期；超出本版 UTC 范围时沿原日期策略并给出准确提示，原件保持。
- 读取与写入的确认范围为 1970 至 2038 的整数秒；本版不记录亚秒，不增加格式或算法，界面与现有交互保持。

见[本版范围](ARCHIVE_ROADMAP_1.7.32.md)、[实现与检查](ZIP_UTC_WRITE_FREEZE_1.7.32.md)。下一阶段 [v1.7.33 流式 BZip2 ZIP 丢目录部分取回](ARCHIVE_ROADMAP_1.7.33.md)仅规划，回到兼容与容错主线。
