# Long解压 v1.1.11

v1.1.11 聚焦大型分卷压缩包的真实解压可靠性和执行可感知性，修复 v1.1.10 可能把加密检测超时误判为加密、继而长时间尝试密码字典的问题。

## 主要修复

- 分卷加密检测由完整读取改为结构化目录元数据检查，最多等待 15 秒；超时或检查失败会明确中止，不再被当作“已加密”。
- 只有明确的 `Encrypted = +` 或 7-Zip 密码错误才会进入自动解锁，普通分卷不会检索保险箱或运行内置字典。
- 通用 7-Zip 解压持续解析回车刷新进度，展示两位小数百分比和当前正在处理的文件。
- 自动解锁详情展示保险箱、导入词表和内置字典的候选来源、序号、字符特征、匹配结果和耗时；密码明文不会进入日志或历史任务。
- 解压详情新增已产出内容、预计展开大小和展开速度，结束后以实际输出目录大小校正；压缩详情新增真实输出大小、压缩比和空间变化。
- 新增可选的“解压后移入系统回收站”，仅在完整事务成功后处理源压缩包；分卷会整组移动，失败、取消或部分解压不会删除源文件。

## 真实验证

- 用户提供的五卷 `rural-vitalization-micro-frontend.zip.001` 至 `.005` 共约 2.5 GB，当前代码判断为未加密，没有进入密码流程。
- 真实样本在受控执行窗口内产生非零进度和当前文件事件；测试结束时主动取消并清理临时输出，源分卷保持不变。
- ZIP、7Z 真实压缩解压往返、前端单元测试、Rust 定向测试、类型检查、生产构建和 release 构建纳入发布门禁。

## Windows 集成边界

项目没有商业 Windows Authenticode 代码签名证书，因此公开安装包不包含 Windows 11 第一层菜单身份包；经典“显示更多选项”菜单继续支持。自动更新资产仍使用项目独立更新密钥签名验证完整性。
